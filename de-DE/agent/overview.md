# Kimi Agent – Überblick

Kimi Agent ist ein autonomer KI-Assistent, der komplexe Aufgaben durchgängig erledigt. Angetrieben von Kimi K3 nutzt er über 20 Tools, um Websites zu erstellen, Dokumente zu generieren, Daten zu analysieren und vieles mehr.

## Produktentwicklung
- **5. September 2025**: Kimi K2 veröffentlicht – 32 Mrd. aktive / 1 Bio. Parameter insgesamt
- **26. September 2025**: „OK Computer“-Agent-Modus eingeführt
- **27. Januar 2026**: Kimi K2.5 veröffentlicht – verbesserte Office-Fähigkeiten und Agent-Funktionen
- **Februar 2026**: Öffentliche Beta von Kimi Claw gestartet
- **20. April 2026**: Kimi K2.6 veröffentlicht und als Open Source freigegeben – führend bei Coding, langfristiger Ausführung und Agent Swarm
- **16. Juli 2026**: Kimi K3 veröffentlicht – das weltweit erste offene Modell der 3T-Klasse (2,8 Bio. Parameter, native Bildverarbeitung, 1-Million-Token-Kontext) und Kimis leistungsstärkstes Modell, das Chat, Agent und Agent Swarm antreibt; verfügbar über die Kimi-App, kimi.com, Kimi Work, Kimi Code und die Kimi API, mit vollständigen Gewichten am 27. Juli 2026

## Kernfunktionen
| Funktion | Beschreibung |
|---------|-------------|
| **Websites** | Responsive Web-Apps erstellen und bereitstellen |
| **Docs** | Bearbeitung und Erstellung von Word, PDF und Markdown |
| **Sheets** | Datenanalyse und Visualisierung mit Excel/CSV |
| **Slides** | Automatisierte PPT-Erstellung |
| **Deep Research** | Forschungsberichte mit über 10.000 Wörtern |
| **Agent Swarm** | Bis zu 300 parallel arbeitende Subagenten |
| **Kimi Claw** | Cloud-Automatisierung mit über 5.000 Skills |

## Wie funktioniert es?
1. **Aufgabenplanung**: Zerlegt Ihre Anfrage in Teilaufgaben
2. **Tool-Aufruf**: Setzt bei Bedarf über 20 Tools ein
3. **Autonome Ausführung**: Erledigt Recherche, Design und Entwicklung
4. **Fehlerbehandlung**: Korrigiert sich selbst, ohne dass ein Eingriff nötig ist
5. **Ergebnisse**: Office-Dateien, Web-Apps oder Berichte

## Erste Schritte
- **Web**: [kimi.com/agent](https://www.kimi.com/agent)
- **Mobil**: Öffnen Sie die Kimi-App und wählen Sie in der Modellauswahl-Schaltfläche das Modell K3 oder K3 Swarm
Beschreiben Sie Ihre Aufgabe klar, verfolgen Sie den Fortschritt der Ausführung und laden Sie anschließend die Ergebnisse herunter oder teilen Sie sie.

## Anwendungsfälle
- Website-Entwicklung (ganz ohne Programmierung)
- Content-Erstellung mit Multimedia
- Dokumentenvergleich und -übersetzung
- Datenanalyse (Excel mit bis zu 1.000 Zeilen)
- Folienerstellung
- Dokumentenkonvertierung
