# Agent-Kontingent & Abrechnung

<Callout type="info">
Der Agent-Modus nutzt das Kontingentsystem von Kimi. Alle Mitgliedsvorteile umfassen zwei Kontingent-Pools: Kimi Code verwendet einen eigenen Kontingent-Pool; andere Mitgliedsfunktionen (Agent, Deep Research, Slides, Docs, Sheets, Kimi Claw usw.) teilen sich einen gemeinsamen Kontingent-Pool, wobei das Kontingent anhand des tatsächlichen Tokenverbrauchs abgezogen wird.
</Callout>

## Abrechnungsmodell
- **Zwei Kontingent-Pools**: Alle Mitgliedsvorteile umfassen zwei Kontingent-Pools. Kimi Code verwendet einen eigenen Kontingent-Pool; andere Mitgliedsfunktionen teilen sich einen Pool – verteilen Sie die Nutzung ganz nach Belieben
- **Nutzungsbasierte Abrechnung**: Der Kontingentverbrauch hängt von Komplexität und Dauer der Aufgabe ab (also vom Tokenverbrauch) – einfache Aufgaben kosten weniger, komplexe mehr
- **Monatliche Erneuerung**: Das Kontingent wird monatlich zurückgesetzt, abgestimmt auf Ihren Abrechnungszyklus
- **Verbrauchsreihenfolge**: Bonuskontingent (z. B. Testguthaben, Aktionsprämien) wird zuerst verbraucht, danach folgt das Tarifkontingent

<Callout type="tip">
**Beispiel**: Mit einem Moderato-Tarif verbraucht die Erstellung einer einfachen PPT etwa 1–2 % des Kontingents, während eine einzelne Deep Research-Sitzung rund 5–10 % beanspruchen kann.
</Callout>

## Was passiert, wenn das Kontingent aufgebraucht ist?
Wenn Ihr Kontingent erschöpft ist:
- Eine gerade laufende Aufgabe wird normal abgeschlossen
- Bei neuen Aufgaben erscheint der Hinweis „Kontingent unzureichend"
- Ihre Möglichkeiten:
  - Warten, bis sich Ihr monatliches Kontingent automatisch erneuert
  - Auf eine höhere Mitgliedsstufe upgraden, um mehr Kontingent zu erhalten

## Wie überprüfe ich meinen Kontingentverbrauch?
- **Web**: Profil → Einstellungen → Abonnement
- **App**: Profil → Mitgliedstarif → Abonnement
Was Sie einsehen können:
1. Aktuellen Kontingentstand (als Prozentwert)
2. Datum der nächsten Erneuerung
3. Die letzten 10 Nutzungseinträge (Zeitstempel, genutzte Funktion, Verbrauch in Prozent)

<Callout type="info">
Nutzungseinträge können geringfügig verzögert erscheinen. Maßgeblich ist stets die tatsächliche Kontingentanzeige.
</Callout>

## Verbraucht eine fehlgeschlagene Aufgabe trotzdem Kontingent?
- Das Kontingent wird nach erfolgreicher Ausführung einer Aufgabe anhand des tatsächlichen Verbrauchs abgezogen
- Schlägt eine Aufgabe aufgrund eines Systemfehlers fehl (kein gültiges Ergebnis zurückgegeben), klicken Sie auf die Schaltfläche **👎**, um dies zu melden. Nach Prüfung wird das entsprechende Kontingent erstattet
