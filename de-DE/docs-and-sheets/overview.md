# Kimi Docs & Kimi Sheets

<Callout type="info">
Am 27. Januar 2026 hat Moonshot AI Kimi K2.5 veröffentlicht und damit die Produktivitätsfunktionen von Kimi Agent erheblich erweitert. Kimi Agent „beherrscht Office“ nun mit durchgängiger Dateiausgabe für Word, PDF, Excel und Slides.
</Callout>

Kimi K2.5 liefert in Office-Szenarien spürbar bessere Ausgabequalität und effizientere Tool-Aufrufe – besonders bei strukturierter Ausgabe mit durchgängigen Verarbeitungsfähigkeiten:
| Format | Funktionen |
|--------|-------------|
| **Word** | Intelligente Formatierung und Änderungsverfolgung |
| **PDF** | Visuelle Gestaltung und kombinierte Text-Bild-Layouts |
| **Excel** | Datenanalyse und Finanzmodellierung |
| **Slides** | Automatische Erstellung und visuelles Storytelling |

## Kimi Docs
Kimi Docs verfügt über starke Textanpassungsfähigkeiten und ein systematisches Verständnis von Office-Workflows.
### Wichtige Funktionen
**Word-Dokumente:**
- Erstellen langer, professioneller Dokumente: Whitepapers, Forschungsberichte, Verträge, Angebote
- Einfügen von Kommentaren und Überarbeitungsvorschlägen in bestehende Word-Dokumente
- Umgang mit Überschriftenhierarchien, Absatzabständen, Zitaten und Listenformatierung
- Verdichten einer 30.000 Wörter umfassenden Abschlussarbeit zu einer präzisen Zusammenfassung
**PDF-Dokumente:**
- Erstellen reich bebilderter, professioneller PDF-Berichte mit Deckblatt, Inhaltsverzeichnis, Fließtext und Bildunterschriften
- Erneutes Bearbeiten und Umformatieren bestehender PDFs ohne professionelle Satzsoftware
- Extrahieren bestimmter Informationen aus hundertseitigen PDFs
- Vergleichen feiner Unterschiede zwischen mehreren Vertragsversionen
### Wie verwendet man Kimi Docs?
**Einstiegspunkte:**
- Allgemein: Klicken Sie auf die Verknüpfungen für Docs, Sheets oder Slides in der Seitenleiste oder im Chatfeld
- Speziell: Klicken Sie auf die Schaltfläche „Docs“ unten im Chatfeld
### Methode 1: Die Seite Kimi Docs besuchen

<Frames
  src="./images/overview/screenshot-1.png"
  alt="screenshot 1"
/>

1. **Browser öffnen**: Chrome, Safari, Edge, Firefox oder ein anderer gängiger Browser
2. **Aufrufen**: [kimi.com/docs](https://www.kimi.com/docs)
3. **Anmelden**: Melden Sie sich mit Ihrem Kimi-Konto an (Google oder E-Mail)
4. **Aufgabe eingeben**:
   - **Texteingabe**: Geben Sie eine Aufgabe in natürlicher Sprache ein
   - **Dokument hochladen** zur Bearbeitung
   - **Beispiele durchstöbern**: Klicken Sie auf „So eines erstellen“, passen Sie es an und senden Sie es
5. **Mit dem Erstellen beginnen**: Wählen Sie eine Vorlage oder erstellen Sie etwas im Dialog

<Frames
  src="./images/overview/screenshot-2.png"
  alt="screenshot 2"
/>

<Callout type="tip">
Beschreiben Sie Ihren Bedarf direkt, z. B.: „Erstelle mir einen XX-Bericht.“ Oder laden Sie eine bestehende Word-/PDF-/Excel-Datei hoch und geben Sie an, was geschehen soll. Laden Sie die Datei im Originalformat (.docx / .xlsx / .pdf) herunter, um sie lokal weiterzubearbeiten.
</Callout>

### Methode 2: Mobile App
Die Kimi-App ist für iOS und Android verfügbar. Tippen Sie auf die Taskleiste → wechseln Sie in den Docs-Modus.
#### Methode 3: Allgemeiner Agent-Modus
Wählen Sie das K3-Modell und geben Sie eine dokumentbezogene Aufgabe ein. Kimi ruft daraufhin Lese- und Schreibwerkzeuge auf.
## Kimi Sheets
Kimi Sheets versteht Zellbeziehungen sowie die Verknüpfungslogik zwischen Tabellenblättern und erzeugt .xlsx-Dateien direkt im Browser.
### Wichtige Funktionen
| Funktion | Beschreibung |
|------------|-------------|
| **Massendatenerfassung** | Daten aus Dokumenten extrahieren – z. B. Ausstellerinformationen aus einem PDF in eine 1.000-zeilige Excel-Datei übernehmen |
| **Zusammenführung mehrerer Quellen** | 50 verschiedene Abteilungs-Excel-Berichte zu einer einzigen Unternehmensübersicht zusammenführen |
| **Eingabe in natürlicher Sprache** | Eigenständige Web-Suche mit intelligenter Tabellenerstellung |

### Wie verwendet man Kimi Sheets?
Klicken Sie auf die Schaltfläche „Agent“ unten im Chatfeld oder wählen Sie die Verknüpfung „Sheets“ in der Seitenleiste.

<Frames
  src="./images/overview/screenshot-4.png"
  alt="screenshot 4"
/>

Sie können sagen: *„Durchsuche das Web und stelle die neuesten Publikationen zum Thema XX in einem Excel-Dokument zusammen“* oder eine bestehende Excel-/CSV-Datei hochladen und angeben, was geschehen soll. Vorschau online ansehen und anschließend die .xlsx-Datei herunterladen.
## Zielgruppe
| Zielgruppe | Anwendungsfälle |
|:---|:---|
| **Büroprofis** | Schnelles Erstellen von Arbeitsvorschlägen, Briefing-Unterlagen und Sitzungsprotokollen |
| **Forschende** | Recherchematerialien, Interviewaufzeichnungen und Branchenberichte zu Whitepapers zusammenführen |
| **Akademiker** | Aufsätze und Literaturübersichten in Zusammenfassungen umwandeln; Versuchsdaten berechnen |
| **Juristen** | Leistungsstarke Prüf- und Anmerkungsfunktionen für die Überarbeitung juristischer Dokumente nutzen |
| **Unternehmer** | Geschäftspläne, Kooperationsangebote und Investorenunterlagen im Handumdrehen erstellen |
| **Investmentanalysten** | DCF-Modellierung, Finanzprognosen und Bewertungsanalysen per natürlicher Sprache vorantreiben |
| **Marketing & Operations** | Daten aus mehreren Kanälen, Wettbewerbsvergleiche und Kampagnenauswertungen bündeln |
