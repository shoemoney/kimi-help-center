# Plugins

Plugins verbinden externe Tools mit Kimi, damit Kimi Apps und Dienste zum Erledigen von Aufgaben nutzen kann. Sobald Sie ein Plugin installiert haben, kann Kimi bei der Bearbeitung einer Aufgabe die entsprechende Drittanbieter-Funktion direkt aufrufen – zum Beispiel Finanzdaten abfragen, Office-Software bedienen oder Design-Tools nutzen. Sie können Kimi ausdrücklich bitten, ein bestimmtes Plugin zu verwenden; wenn es passt, ruft Kimi ein Plugin auch automatisch auf.

## Wo Sie Plugins verwenden können

Sie können Plugins verwenden, wenn Sie das Modell auf **K3** oder **K3 Swarm** umstellen, sowie in den Szenarien **Deep Research, Websites und PPT**.

Plugins lassen sich auch in der **Kimi Work Desktop-App** verwenden; die integrierte Plugin-Liste auf dem Desktop finden Sie im [Kimi Work Plugin-Center](/kimi-work/plugin-center).

<Callout type="info">
Plugins werden in Unterhaltungen mit Kimi Claw oder Kimi Plus derzeit noch nicht unterstützt.
</Callout>

## Plugins installieren

- **Einstiegspunkte**: im Web die Registerkarte **Plugins** in der Seitenleiste, das **+** im Eingabefeld oder die Eingabe von "/"; auf Mobilgeräten das **+** im Eingabefeld oder "/".
- Suchen oder stöbern Sie im Plugin-Marktplatz, öffnen Sie die Details eines Plugins und klicken Sie auf Installieren.
- Einige Plugins erfordern eine **OAuth-Autorisierung** (Sie werden zur Anmeldung beim Drittanbieter weitergeleitet; nach erfolgreicher Autorisierung können Sie das Plugin verwenden); einige Plugins sind **vorinstalliert** und müssen nicht manuell installiert werden.
- **Plugins nur für Unternehmen**: Nutzer ohne Unternehmenskonto können sie sehen, die Schaltfläche „Installieren“ ist jedoch ausgegraut.
- Wenn Sie abgemeldet sind, können Sie keine Plugins installieren oder verwenden.

## Plugins verwenden

- Geben Sie nach der Installation "/" in das Eingabefeld ein oder klicken Sie auf **+** → Plugins und wählen Sie dann das Plugin aus, um es aufzurufen; Sie können **mehrere Plugins gleichzeitig aufrufen**.
- Sie können auch einfach beschreiben, was Sie benötigen (zum Beispiel: „Suche dieses Unternehmen auf Tianyancha“), und Kimi wählt automatisch das passende Plugin aus.
- Wenn Kimi die Tools eines Plugins aufruft, erscheint in der Antwort „Verwendet das xx-Plugin“.

## Plugin-Kategorien und -Liste

Der Plugin-Marktplatz ist in die folgenden Kategorien unterteilt. Welche Plugins Sie tatsächlich sehen, hängt von **Region (Inland/Ausland)** und **Oberfläche** ab; manche Plugins erscheinen in mehr als einer Kategorie.

- **Finanzen**: Finanzanlageanalyse, Investmentbanking & Private Equity, Unternehmensfinanzen & Rechnungswesen, Wind Financial Data, S&P Global Market Intelligence, Hundsun Gildata, Tonghuashun iFinD, SEC, Globale Finanzdatenbank, World Bank Open Data, IMF-Datenbank (Internationaler Währungsfonds), Stripe, Tianyancha
- **Produktivität**: Notion, Baidu Netdisk
- **Entwicklung**: GitHub, Supabase, Neon, Cloudflare
- **Kreativ**: Inspirationspool, Bilderstellung, Videoerstellung, Audioerstellung, Canva
- **Allgemein**: Vivify

## Credits

Einige Plugins rufen Tools oder Dienste auf, um eine Aufgabe zu erledigen, und **verbrauchen abhängig von der tatsächlichen Nutzung Credits Ihres Abonnements**; für Plugins ohne Aufrufkosten fallen keine zusätzlichen Gebühren an.

## Daten und Berechtigungen

- Wenn Sie ein Plugin auswählen oder Kimi ausdrücklich bitten, ein Plugin zu verwenden, priorisiert Kimi die von diesem Plugin bereitgestellten Tools und erstellt seine Antwort anhand der von diesen Tools zurückgegebenen Ergebnisse; nach dem Verbinden eines Plugins greift Kimi im von Ihnen autorisierten Umfang auf relevante Inhalte zu.
- Wird ein Plugin von einem Drittanbieter bereitgestellt, legt dieses Unternehmen seine Regeln zur Datenverarbeitung eigenständig fest. Die Daten unterliegen dessen Nutzungsbedingungen und Datenschutzerklärung – wir empfehlen, diese vor der Autorisierung zu prüfen.
- Sie können **ein Plugin jederzeit deinstallieren oder die Autorisierung widerrufen**. Nach der Deinstallation wird die zugehörige OAuth-Autorisierung widerrufen; um das Plugin wieder zu verwenden, müssen Sie es erneut installieren und autorisieren.

## FAQ

### Verbrauchen Plugins meine Abonnement-Credits?
Manche ja. Wenn Kimi die Tools oder Dienste eines Plugins aufruft, um eine Aufgabe zu erledigen, werden Credits abhängig von der tatsächlichen Nutzung verbraucht; für Plugins ohne Aufrufkosten fallen keine zusätzlichen Gebühren an.

### Kann ich mehrere Plugins gleichzeitig verwenden?
Ja. Sie können mehrere Plugins gleichzeitig über "/" oder **+** aufrufen.

### Warum sehe ich ein bestimmtes Plugin nicht?
Die verfügbaren Plugins variieren je nach Region (Inland/Ausland) und Oberfläche; außerdem stehen einige Plugins nur Unternehmenskunden zur Verfügung.
