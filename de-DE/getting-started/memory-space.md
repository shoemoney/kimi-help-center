# Memory Space

## Was ist das Gedächtnis?
Kimi hat wirklich gelernt zuzuhören – je mehr Sie erzählen, desto besser versteht es Sie. So funktioniert es:

Kimi reagiert nicht nur auf das, was gerade im Chatfenster steht. Über alle Gespräche hinweg merkt es sich die wichtigen Details – Ihre Vorlieben, Gewohnheiten, Ihren Stil …

Mit fortlaufender Nutzung lernt Kimi kontinuierlich über alle Sitzungen hinweg dazu und verfeinert ständig sein Verständnis von Ihnen.

Sie müssen sich nicht wiederholen. Kimi bezieht von sich aus mit ein, „worüber wir bereits gesprochen haben“, und liefert so relevantere und stimmigere Antworten.

## Was wird gespeichert?
Kimi verwendet ein eigens trainiertes Modell, um gezielt Gesprächsinhalte zu speichern, die für Sie von Nutzen sind.

Bevor Kimi etwas speichert, stellt es sich zwei Fragen:
- Wer ist dieser Nutzer?
- Was ist diesem Nutzer wichtig, was bevorzugt er oder was möchte er vermeiden?

Kimi speichert **keine** unbefugten privaten Informationen (z. B. Gesundheitsdaten, Passwörter, Adressen), es sei denn, Sie weisen es ausdrücklich dazu an.

## Wie das Gedächtnis ausgelöst wird
Das Gedächtnis ist inzwischen eine integrierte Funktion – ein natürliches Gespräch genügt, um es auszulösen.

Möglichkeiten, Kimis Gedächtnis zu aktualisieren oder zu verwalten:

**(1) Direkte Anweisungen im Gespräch (am gebräuchlichsten)**

Sie können das Gedächtnis mit Befehlen in natürlicher Sprache aktualisieren:

| Aktion | Was Sie sagen können | Kimis Reaktion |
|:---|:---|:---|
| Gedächtnis ergänzen | „Merke dir, dass ich Kaffee mag“<br>„Notiere, dass meine Personalnummer 9527 ist“<br>„Merke dir, dass ich Projektmanager bin“ | Kimi ruft das Gedächtnis-Tool auf, um es zu speichern |
| Gedächtnis aktualisieren | „Korrektur – ich bin nach New York gezogen“<br>„Update: Ich bin jetzt Senior Engineer“ | Kimi ersetzt den alten Gedächtniseintrag |
| Gedächtnis löschen | „Vergiss, dass ich Kaffee mag“<br>„Lösche den Gedächtniseintrag zu meiner Personalnummer“<br>„Lösche alle Gedächtniseinträge“ | Kimi entfernt den angegebenen oder alle Einträge |

Hinweis: Das Gedächtnis liegt vollständig in Ihrer Hand. Es wird nicht für das Modelltraining verwendet und kann jederzeit deaktiviert oder gelöscht werden.

**(2) Verwaltung über die Einstellungen (Benutzeroberfläche)**

Sie können das Gedächtnis auch über die Einstellungen verwalten:
- Web / Mobil: Einstellungen → Personalisierung → Memory Space
- Hier können Sie alle gespeicherten Gedächtniseinträge einsehen
- Sie können jeden Eintrag, den Sie nicht mehr benötigen, manuell löschen

### Gedächtniseinträge hinzufügen
Gedächtniseinträge werden im Gespräch automatisch ausgelöst. Zum Beispiel:
- „Mein Name ist xxx, Freunde nennen mich xxxx“
- „Ich bin Mathematiklehrer an einer Grundschule, daher müssen die Unterrichtsmaterialien kindgerecht sein“
- „Bitte verwende in deinen Antworten keine Emojis mehr“
- „Ich programmiere meist in C++“
- „Wiederhole dich nicht und verwende keine übermäßige Zeichensetzung“

Wenn es etwas gibt, das Kimi sich ausdrücklich merken soll, betonen Sie es:
- „Merke dir, dass …“
- „Bitte behalte im Hinterkopf …“
- „… vergiss das nicht“

### Gedächtniseinträge aktualisieren
Gehen Sie zu Profil → Einstellungen → Personalisierung → Memory Space, um einzelne Gedächtniseinträge zu bearbeiten.

### Gedächtniseinträge löschen (vergessen)
Gehen Sie zu Profil → Einstellungen → Personalisierung → Memory Space und klicken Sie bei einzelnen Einträgen auf Löschen.
