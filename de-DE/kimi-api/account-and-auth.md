# Konto & Authentifizierung

<Callout type="info">
Häufige Fragen zu Kimi API-Entwicklerkonten, Verifizierung und Authentifizierung.
</Callout>

## Kann ein persönliches Konto eine Geschäftsrechnung erhalten?
Ein persönliches Konto **kann nicht direkt eine Geschäftsrechnung erhalten**. Wenn Sie eine Geschäftsrechnung benötigen, stellen Sie Ihr Konto zunächst auf ein Organisationskonto um. Nach erfolgreicher Verifizierung können Sie Rechnungen auf den Namen Ihrer Organisation anfordern.

## Wie stelle ich ein persönliches Konto auf ein Organisationskonto um?
1. Melden Sie sich in der Konsole von [platform.kimi.ai](https://platform.kimi.ai) an.
2. Öffnen Sie **Kontoeinstellungen → Verifizierung**.
3. Wählen Sie **Organisationsverifizierung** aus und geben Sie die erforderlichen Informationen ein.
4. Reichen Sie den Antrag zur Prüfung ein — nach der Genehmigung wird Ihr Konto automatisch umgewandelt.

<Callout type="tip">
Vorhandenes Guthaben und Nutzungsdaten bleiben nach dem Upgrade erhalten.
</Callout>

## Unterschied zwischen persönlicher und Organisationsverifizierung
| Aspekt | Persönlich | Organisation |
| --- | --- | --- |
| Rechnungstyp | Persönliche Rechnung | Geschäfts-/Umsatzsteuerrechnung |
| Rate Limits | Standard | Für höhere quotas berechtigt |
| Geschäftsverträge | — | Vertragsabschluss möglich |
| Mengenrabatte | — | Auf Anfrage verfügbar |
| Technischer Support | Standard | Support mit Priorität |

## Wie kann ich Einspruch gegen eine Kontosperrung einlegen?
Wenn Ihr API-Konto wegen eines Richtlinienverstoßes gesperrt wurde:
1. Senden Sie eine E-Mail an **support@moonshot.ai** mit der Betreffzeile "Einspruch gegen API-Kontosperrung".
2. Geben Sie Ihre Kontoinformationen (registrierte E-Mail-Adresse) sowie eine Begründung für Ihren Einspruch an.
3. Das Team prüft Ihren Fall und antwortet innerhalb von 1–3 Werktagen.

<Callout type="info">
**Support-E-Mail**: support@moonshot.ai
</Callout>

## Wie ändere ich die registrierte E-Mail-Adresse?
Um Ihre registrierte E-Mail-Adresse zu ändern, wenden Sie sich an den Support:
1. Senden Sie eine E-Mail an **support@moonshot.ai** mit der Betreffzeile "Antrag auf Änderung der E-Mail-Adresse".
2. Geben Sie sowohl Ihre aktuelle als auch Ihre neue E-Mail-Adresse an.
3. Zur Sicherheit Ihres Kontos kann eine Identitätsprüfung erforderlich sein.

## Vorteile einer abgeschlossenen Verifizierung
- **Höhere Rate Limits**: Verifizierte Nutzer können höhere API-Aufrufraten erhalten.
- **Voller Funktionszugriff**: Einige erweiterte Funktionen stehen möglicherweise nur verifizierten Nutzern zur Verfügung.
- **Rechnungsunterstützung**: Verifizierte Konten können Rechnungen anfordern.
- **Technischer Support**: Verifizierte Nutzer erhalten technischen Support mit höherer Priorität.
