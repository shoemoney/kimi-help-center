# Dateiübertragung

Kimi Claw unterstützt das Senden und Empfangen von Dateien.

## Dateien an Kimi Claw senden

Sie können Bilder, Dokumente und andere Dateien über Kimi an Kimi Claw senden. Kimi Claw nutzt seine integrierten Tools, um sie anzusehen und zu verarbeiten.

## Dateien von Kimi Claw empfangen

Die neueste Version von Kimi ermöglicht es Kimi Claw, Dateien an Sie zurückzusenden. Falls die Dateiübermittlung nicht funktioniert, stellen Sie sicher, dass Sie die neueste Version des Kimi-Plugins verwenden.

## Dateien im Workspace verwalten

Sie können die von Kimi Claw erzeugten Dateien auch über den **Workspace** im Web durchsuchen und herunterladen. Der Workspace speichert alle Dateien, die während des Betriebs von Kimi Claw entstehen, sodass Sie jederzeit darauf zugreifen können.
