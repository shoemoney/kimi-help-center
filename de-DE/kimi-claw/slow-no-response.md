# Keine Antwort oder langsam?

<Callout type="info">
Wenn Kimi Claw nicht antwortet oder ungewöhnlich langsam reagiert, kann das mehrere Ursachen haben. Folgen Sie der untenstehenden Anleitung zur Fehlerbehebung.
</Callout>

## Häufige Ursachen

| Ursache | Beschreibung |
|-------|-------------|
| **Bridge-Verbindung getrennt** | Die Verbindung zwischen Kimi Claw und dem Server ist abgebrochen; das Gateway muss neu gestartet werden |
| **Ressourcen ausgelastet** | Die Serverlast ist hoch; Antworten können sich verzögern |
| **Instanz offline** | Die Kimi-Claw-Instanz ist offline gegangen und muss repariert werden |

## So beheben Sie das Problem

Gehen Sie diese Schritte der Reihe nach durch, bis das Problem gelöst ist:

1. **Senden Sie eine weitere Nachricht** — Manchmal handelt es sich nur um eine kurze Verzögerung; eine Folgenachricht kann eine Antwort auslösen
2. **Aktualisieren Sie die Seite** — Schließen Sie die Kimi-Claw-Konversation und öffnen Sie sie erneut
3. **Starten Sie das Gateway neu** — Gehen Sie zu den **Einstellungen** und klicken Sie auf **Kimi Claw neu starten**. Warten Sie, bis es wieder online ist
4. **Automatische Reparatur** — Klicken Sie in den Einstellungen auf **Kimi Claw reparieren**. Das System erkennt und behebt Konfigurationsprobleme automatisch
5. **Ausgangseinstellungen wiederherstellen** — Wenn nichts anderes hilft, wählen Sie in den Einstellungen **Ausgangseinstellungen wiederherstellen**

## Über das Wiederherstellen der Ausgangseinstellungen

<Callout type="warning">
Dadurch wird Kimi Claw auf den Werkszustand zurückgesetzt, aber:

- **Bleibt erhalten:** Arbeitsbereichsdateien und Langzeit-Memory
- **Muss neu konfiguriert werden:** Verbindungen zu Chat-Plattformen (Telegram usw.) müssen erneut eingerichtet werden
</Callout>
