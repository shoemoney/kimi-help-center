# Vorteile von Kimi Code

Kimi Code ist ein im Kimi-Abo enthaltener Dienst, der Coding-bezogene Unterstützung und Funktionen bietet, damit Mitglieder Programmieraufgaben in ihrem persönlichen Entwicklungsworkflow effizienter erledigen können.

> Bitte beachten Sie, dass dieser Vorteil ausschließlich für die persönliche Entwicklung gedacht ist, nicht für Entwicklungsszenarien in Unternehmen. Für Unternehmensanforderungen besuchen Sie bitte die [Kimi Offene Plattform](https://platform.kimi.ai/).

## Abrechnung

- Die Nutzung von Kimi Code ist **in Ihrer Abogebühr enthalten** – es fallen keine zusätzlichen Kosten an.
- Kimi Code **nutzt dieselben Credits wie Ihr Kimi-Mitgliedschaftstarif** – Anfragen aus der CLI, aus VS Code und aus Drittanbieter-Tools zählen alle darauf; verschiedene Tarife enthalten unterschiedliche Credit-Mengen.
- Das System verbraucht zuerst Bonus-Credits, bevor die Tarif-Credits genutzt werden.

<Callout type="warning">
**Ein neues Mitgliedschaftssystem steht kurz bevor.** Die Kimi-Mitgliedschaftsvorteile und die Kimi-Code-Vorteile werden getrennt, sodass Sie sie bei Bedarf separat erwerben können – flexibler. **Bestehende Abonnenten sind nicht betroffen.** Wenn Sie die kombinierten Vorteile weiter nutzen möchten, erwerben Sie Ihren aktuellen Tarif, bevor das neue System live geht.
</Callout>

## Credit-Erneuerung

Credits werden in einem **7-Tage**-Zyklus erneuert:

- Ab Ihrem Abodatum (D1) werden die Credits alle 7 Tage erneuert.
- Erneuerungszeiträume: D1–D7, D8–D14, D15–D21, D22–D28.
- Nicht genutzte Credits werden **nicht** in den nächsten Zyklus übertragen.

> Planen Sie Ihre wöchentliche Nutzung, um Ihre Credits optimal auszuschöpfen.

## Unterstützte Tools

Die Vorteile von Kimi Code stehen mit den folgenden Tools zur Verfügung:

| Tool | Beschreibung |
| --- | --- |
| **Kimi Code CLI** | Der offizielle KI-Agent von Kimi für die Kommandozeile |
| **Claude Code** | Anthropics Coding-Assistent für die Kommandozeile |
| **Roo Code** | KI-Coding-Erweiterung für VS Code |

Über die oben genannten Tools hinaus können Abonnenten Kimi Code über einen API Key auch in weitere Tools von Drittanbietern (z. B. OpenCode) einbinden – Details siehe [Verwendung mit Coding-Agents von Drittanbietern](/kimi-code/third-party-agents). Bei der Verwendung von Drittanbieter-Tools muss die echte Identität des Tools beibehalten werden; das Fälschen der Client-Kennung (User-Agent) gilt als Verstoß und kann zur Sperrung der Mitgliedschaftsvorteile führen.

## Extra Usage

Wenn Ihre Abo-Credits aufgebraucht sind, können Sie mit Ihrem **Extra-Usage**-Guthaben weiter Anfragen stellen, ohne auf eine Erneuerung zu warten. Nur Abonnenten können es aktivieren, und **Kimi im Web und Kimi Code teilen sich dasselbe Extra-Usage-Guthaben** (einmal aufladen, in beiden nutzen). Die vollständigen Bedingungen finden Sie in der [Extra-Usage-Vereinbarung](https://www.kimi.com/user/agreement/extra-usage-rules-cn).

### Aufladewege

- **Über die Hauptseite**: Öffnen Sie die Kimi-[Aboseite](https://www.kimi.com/membership/subscription?tab=quota), scrollen Sie zum Modul „Extra Usage" am unteren Rand, wählen Sie einen Betrag und schließen Sie die Zahlung ab.
- **Über die Kimi Code Console**: Sobald Ihre Wochen- oder 5-Stunden-Nutzung **80 %** übersteigt, erscheint auf der Fortschrittskarte eine Schaltfläche **Extra Usage kaufen**, die Sie zur Aboseite führt.

### Aktivieren und verwalten

Aktivieren Sie den Schalter „Extra Usage"; wenn Ihre Abo-Credits aufgebraucht sind, zieht das System automatisch vom Extra-Usage-Guthaben ab. Klicken Sie im Modul auf **Einstellungen**, um ein **monatliches Ausgabenlimit** zu aktivieren und den Höchstbetrag für diesen Monat festzulegen; der Fortschrittsbalken zeigt den Extra-Usage-Verbrauch dieses Monats in Echtzeit.

### Abrechnung und Regeln

- **Abrechnung**: nach tatsächlicher Nutzung – je mehr gelesen und generiert wird und je komplexer die Aufgabe, desto höher die Kosten. Das Guthaben wird in RMB angezeigt, mit den auf der Plattform angezeigten Tarifen. Die Extra-Usage-Preise liegen nahe den offiziellen API-Preisen der [Kimi Open Platform](https://platform.kimi.com); bei hoher Nutzung ist ein Abo-Upgrade meist günstiger.
- **Abzugsreihenfolge**: Zuerst werden zeitlich begrenzte Credits wie das Abo abgezogen; **Extra Usage wird zuletzt** als Reserve abgezogen. Einmal aktiviert, wird Extra Usage auch bei ausgeschöpftem Abo-Credit nahtlos verbraucht – Aufgaben stoppen nicht und brechen nicht ab.
- **Ausgabenlimit**: Aktivieren Sie in den Einstellungen ein „monatliches Ausgabenlimit", um zu begrenzen, wie viel Extra Usage in diesem Monat ausgegeben werden kann; ohne Limit gibt es keine Obergrenze.
- **Gültigkeit und Ansammlung**: Das Guthaben verfällt nicht und lässt sich über mehrere Aufladungen ansammeln; es bleibt nach Ablauf des Abos nutzbar, aber während der Unterbrechung können Sie nicht aufladen – schließen Sie zuerst wieder ein Abo ab.

<Callout type="info">
Abrechnungsbeispiel (nur als grobe Größenordnung; tatsächliche Tarife gemäß Plattform): eine einfache Anfrage (z. B. „Empfiehl einen Rocksong") kostet etwa **¥0,03**; eine komplexe mehrstufige Aufgabe (z. B. „Plane einen einwöchigen Roadtrip von Chengdu nach West-Sichuan") kostet etwa **¥1,6**. Aufladelimits: mindestens ¥25 pro Aufladung, bis zu 10-mal und ¥3.000 pro Tag, mit einer Guthaben-Obergrenze von ¥10.000.
</Callout>

### Nutzung prüfen

- **Kimi Web / App**: Einstellungen → Abo & Rechnungen → [Mein Guthaben](https://www.kimi.com/membership/subscription?tab=quota).
- **Kimi Code Console**: Sobald Extra Usage aktiviert ist, melden Sie sich in der [Console](https://www.kimi.com/code/console) an, um Guthaben und Nutzung zu sehen.
- **Kimi Code CLI**: Geben Sie `/usage` in der Kommandozeile ein, um es direkt abzufragen.

### Extra-Usage-FAQ

- **Nutzen Kimi im Web und Kimi Code dieselbe Extra-Usage-Wallet?** Ja – das Guthaben wird von beiden gemeinsam genutzt; einmal aufladen, in beiden verwenden.
- **Was wird zuerst abgezogen, Extra Usage oder Abo-Credits?** Zuerst zeitlich begrenzte Credits wie das Abo; Extra Usage wird erst als Reserve abgezogen, wenn alle zeitlich begrenzten Credits aufgebraucht sind.
- **Kann ich bei Erreichen eines Limits oder bei Drosselung weiterarbeiten?** Ja. Einmal aktiviert, sind Sie von Abo-Limits unabhängig – bei Erreichen eines Limits wird nahtlos auf das Extra-Usage-Guthaben umgeschaltet, Aufgaben stoppen nicht, und es wird nur Extra Usage abgezogen, ohne die Erneuerung Ihrer Mitgliedschafts-Credits zu beeinflussen.
- **Verfällt ungenutztes Guthaben oder lässt es sich ansammeln?** Es verfällt nicht und lässt sich ansammeln; es bleibt nach Ablauf des Abos nutzbar, aber während der Unterbrechung ist kein Aufladen möglich.
- **Ist Extra Usage für Enterprise verfügbar?** Noch nicht unterstützt.
