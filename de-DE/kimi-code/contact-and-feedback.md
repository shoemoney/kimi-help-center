# Kontakt & Feedback

## Feedback-Kanäle

Wenn bei der Nutzung von Kimi Code Probleme auftreten oder du Vorschläge hast, kannst du uns über die folgenden Kanäle Feedback geben.

### Option 1: Feedback direkt in der CLI senden

Gib im interaktiven Modus der Kimi Code CLI den Befehl `/feedback` ein, um Feedback zu übermitteln. Das System erfasst automatisch Informationen zu deiner aktuellen Umgebung, damit du das Problem präziser beschreiben kannst.

### Option 2: GitHub Issues

Öffne [Kimi CLI GitHub Issues](https://github.com/MoonshotAI/kimi-cli/issues) und suche zunächst, ob bereits ein ähnliches Problem gemeldet wurde. Falls nicht, kannst du ein neues Issue erstellen und ausführlich beschreiben, was passiert ist.

### Option 3: Feedback per E-Mail

Du kannst dem Kimi Code-Team auch per E-Mail an [code@moonshot.ai](mailto:code@moonshot.ai) schreiben, um Probleme zu melden. Füge bitte möglichst viele der folgenden Informationen bei:

- **Problembeschreibung**: Beschreibe klar, welches Problem aufgetreten ist oder welche Funktion du dir wünschst
- **Schritte zur Reproduktion**: Wie sich das Problem Schritt für Schritt auslösen lässt
- **Umgebungsinformationen**: Betriebssystem und Version der Kimi Code CLI (mit `kimi --version` prüfen)
- **Fehlerprotokolle**: Falls eine Fehlermeldung angezeigt wird, füge sie bitte vollständig ein

### Option 4: Der Feishu-Gruppe beitreten
Scanne den QR-Code, um der Feishu-Gruppe beizutreten

## Fehlerbehebung vor dem Absenden von Feedback

Bevor du Feedback einreichst, empfehlen wir, Folgendes zu prüfen:

- Ob du auf die neueste Version der Kimi Code CLI aktualisiert hast (mit `kimi --version` prüfen)
- Ob deine Netzwerkverbindung funktioniert und du auf `api.kimi.com` zugreifen kannst
- Ob dein API-Schlüssel gültig und nicht abgelaufen ist
- Ob das Arbeitsverzeichnis korrekt ist und Kimi die Berechtigung hat, auf die relevanten Dateien zuzugreifen
