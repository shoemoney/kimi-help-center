# Dashboard

Ein Dashboard ist ein Container für Widgets. Es bringt die Widgets, die Ihnen am wichtigsten sind, in einer dauerhaften, personalisierten Ansicht zusammen, die um ein Thema, ein Projekt oder ein Ziel organisiert ist. Ein Dashboard ist an keine einzelne Konversation gebunden — Sie können es jederzeit öffnen und seine Widgets aus jedem Chat verwalten.

## Dashboards erstellen und verwalten

1. Klicken Sie in der linken Seitenleiste auf „Dashboard“, um das Dashboard-Menü zu öffnen;
2. Klicken Sie auf „Create“ und geben Sie einen Namen (erforderlich) und eine Beschreibung (optional) ein;
3. Jeder Nutzer kann bis zu 2 Dashboards erstellen.

In einem leeren Dashboard können Sie direkt beschreiben, welches Widget Sie möchten, und Kimi baut es in dieses Dashboard ein.

<Callout type="warning">
Das Löschen eines Dashboards löscht auch alle darin enthaltenen Widgets und die zugehörigen Widget Tasks. Dies kann nicht rückgängig gemacht werden — gehen Sie daher vorsichtig vor.
</Callout>

## Layout und Annotationen

- Jedes Dashboard kann bis zu 20 Widgets aufnehmen. Verschieben Sie sie per Drag-and-Drop und passen Sie ihre Größe nach Belieben an.
- Klicken Sie auf „Refresh“, um den Inhalt der Widgets im Dashboard zu aktualisieren.
- Klicken Sie auf „Annotate“, um den Annotationsmodus zu öffnen: Wählen Sie ein beliebiges Element in einem Widget aus, um eine positionsbezogene Annotation zu erstellen und Ihr Feedback festzuhalten. Annotationen werden in chronologischer Reihenfolge aufgelistet, bis zu 10 Einträge; klicken Sie auf eine gespeicherte Annotation, um sie erneut zu bearbeiten.

## Widgets in einem Dashboard verwalten

Fahren Sie mit dem Mauszeiger über ein Widget, um:

- auf „Expand“ zu klicken und den Namen und Typ des Widgets anzuzeigen;
- bei einem Live Widget die gebundene Widget Task zu verwalten: Aufgabenname und Beschreibung anzeigen, sie ein- oder ausschalten und die 10 letzten Ausführungen (Ausführungszeit und Status) überprüfen;
- auf „…“ zu klicken und zu wählen:
  - **Delete**: Entfernt das Widget dauerhaft aus dem ursprünglichen Chat und allen Dashboards — dies kann nicht rückgängig gemacht werden;
  - **Pin to Desktop**: Heftet das Widget als eigenständiges Fenster mit anpassbarer Größe an Ihren Computer-Desktop an; das Fenster wird automatisch geschlossen, wenn Sie die App beenden.

## Ein Dashboard aus einem Chat öffnen

Das Modell kann eine Dashboard-Karte in einem Chat einblenden. Klicken Sie auf die Karte, um die entsprechende Dashboard-Seite im rechten Seitenbereich zu öffnen, ohne die aktuelle Konversation zu verlassen.
