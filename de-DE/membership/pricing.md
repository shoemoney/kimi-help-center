## Credit-Zuteilung

Alle Kimi-Mitgliedschaftsfunktionen greifen auf einen gemeinsamen Credit-Pool zu, abgerechnet nach token-Nutzung. Kimi Code hat zusätzlich ein eigenes wöchentliches rate limit von 5 Stunden, das nur für Kimi Code gilt und andere Funktionen nicht beeinflusst. Im Chat ist K2.6 kostenlos und verbraucht keine Credits. Höhere Stufen enthalten einen entsprechend größeren Credit-Pool und unterstützen dadurch häufigere und komplexere Workflows. Details finden Sie unter [Credit-Update und Nutzungsregeln](/membership/update-rules).

## Häufige Fragen zu Credits

### Was ist die Gebühr „Claw-云主机“ in Höhe von 0.6%, die jeden Tag um 16:00 Uhr abgebucht wird?

Dies sind die Sandbox-Betriebskosten Ihres Kimi Claw-Cloud-Hosts. Kimi Claw ist ein OpenClaw-Deployment in der Cloud: Jedes Mal, wenn Sie Claw aufrufen, startet das System eine isolierte Cloud-Sandbox, um Code auszuführen, den Browser zu bedienen oder Tools aufzurufen. Sandboxes sind kein „kostenloser Standby-Betrieb“ — sie werden kontinuierlich nach Laufzeit und Ressourcenverbrauch abgerechnet. Auch wenn Sie gerade keine Aufgaben ausführen, behält ein bereitgestellter Cloud-Host seine Laufzeitumgebung und Daten, sodass täglich etwa 0.6% Ihrer Mitgliedschafts-Credits abgebucht werden; die Abrechnung erfolgt um 16:00 Uhr.

Wenn Sie Kimi Claw eine Weile nicht nutzen möchten, speichern Sie wichtige Dateien wie memory, soul und workspace-Dateien zuerst lokal und löschen Sie anschließend den Cloud-Host. Nach dem Löschen fallen keine weiteren Gebühren an, und Sie können jederzeit neu bereitstellen.

### Was ist die Gebühr „Agent Website - Cloud Service“ in Höhe von 0.08%?

Dies ist die Cloud-Service-Gebühr für eine Website, die Sie mit Agent veröffentlicht haben. Eine veröffentlichte Website belegt kontinuierlich Cloud-Ressourcen, um online und erreichbar zu bleiben, daher werden etwa 0.08% Ihrer Mitgliedschafts-Credits abgebucht. Wenn Sie die Website nicht mehr online benötigen, klicken Sie auf „Unpublish“, um die Gebühren zu beenden.
