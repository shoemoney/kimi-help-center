# Was ist der Unterschied zwischen Kimi, Kimi Work, Kimi Code und Kimi Claw? Welches Produkt sollte ich nutzen?

Kimi umfasst einen sofort einsatzbereiten Online-Assistenten sowie mehrere Produkte für unterschiedliche Nutzer und Szenarien. Sie basieren auf denselben Kernfunktionen von Kimi; die wichtigsten Unterschiede liegen darin, **wo du sie nutzt, für wen sie gedacht sind und worin sie besonders stark sind**.

## Auf einen Blick

| Produkt | Was es ist | Am besten geeignet für / Szenarien | Wo du es nutzt |
|---|---|---|---|
| **Kimi** (Web / App) | Ein Online-KI-Assistent, der Chat und Agent verbindet | Alltägliche Fragen und Antworten, Schreiben, Suche, Website-Erstellung / PPT / Dokumente und Tabellen, Deep Research und mehr | Web, mobile App |
| **Kimi Work** | Ein **lokaler Agent** für Wissensarbeiter (Desktop) | Arbeiten mit lokalen Dateien auf deinem Computer, Automatisieren von Aufgaben über Desktop-Apps hinweg, Erledigen lang laufender Aufgaben | Mac- / Windows-Client |
| **Kimi Code** | Eine Coding-Assistant-Suite für **Entwickler** | Code schreiben und Codebasen pflegen | CLI, VS Code-Erweiterung |
| **Kimi Claw** | Eine **Cloud-Automatisierungsplattform ohne Deployment** | 7×24-Cloud-Automatisierung im Dauerbetrieb, Bots mit Integration in Feishu / WeChat und mehr | Cloud (kein Server erforderlich) |

## Welches Produkt sollte ich nutzen?

- **Für alltägliche Chats, Schreiben, Suche oder wenn du Kimi Websites erstellen, PPTs und Tabellen anlegen oder Deep Research durchführen lassen möchtest** → nutze **Kimi** (Web / App).
- **Wenn Kimi lokale Dateien auf deinem Computer lesen und schreiben, mehrere Desktop-Apps übergreifend automatisieren oder lange Aufgaben ausführen soll** → nutze **Kimi Work** (Desktop).
- **Wenn du Entwickler bist und vor allem Unterstützung beim Schreiben von Code oder bei der Pflege von Projekten brauchst** → nutze **Kimi Code**.
- **Wenn du einen Cloud-Bot möchtest, der dauerhaft verfügbar ist, automatisch läuft und sich mit Feishu / WeChat sowie anderen Plattformen verbinden kann** → nutze **Kimi Claw**.

<Callout type="tip">
Die Online-Erfahrung von Kimi bringt „Chat“ und „Agent“ bereits zusammen – du musst nicht zwischen ihnen wechseln. In der Desktop-App Kimi Work gibt es zwei Modi: „Work“ (ein Agent-Modus mit Fokus auf Ergebnissen) und „Chat“ (schnelle Unterhaltungen).
</Callout>

## Welche Mitgliedschaft sollte ich wählen?

Die Vorteile deiner Mitgliedschaft sind mit deinem Kimi-Konto verknüpft. **Kimi Code nutzt einen separaten credit pool**, während andere Mitgliedschaftsfunktionen (Chat, Agent, Deep Research und mehr) denselben credit pool verwenden. Details zu Plänen und Preisen findest du auf der [Seite zu Mitgliedschaftsabos](/membership/membership-pricing).

Wenn du Kimi vor allem für **Alltagsarbeit + gelegentliche Aufgaben** nutzt, deckt ein passender Kimi-Mitgliedschaftsplan die meisten Szenarien in Web / App / Kimi Work ab. Entwickler, die **häufig Code schreiben**, sollten außerdem besonders auf die Vorteile von Kimi Code achten.
