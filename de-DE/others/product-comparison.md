# Was ist der Unterschied zwischen Kimi, Kimi Work, Kimi Code und Kimi Claw? Welches Produkt sollte ich verwenden?

Kimi umfasst einen sofort einsatzbereiten Online-Assistenten sowie mehrere Produkte für unterschiedliche Nutzer und Szenarien. Sie alle nutzen die Kernfunktionen von Kimi; die wichtigsten Unterschiede liegen darin, **wo Sie sie verwenden, für wen sie gedacht sind und worin sie am besten sind**.

## Auf einen Blick

| Produkt | Was es ist | Am besten geeignet für / Szenarien | Wo Sie es verwenden |
|---|---|---|---|
| **Kimi** (Web / App) | Ein Online-KI-Assistent, der Chat und Agent verbindet | Alltägliche Fragen und Antworten, Schreiben, Suche, Website-Erstellung / PPT / Dokumente und Tabellen, Deep Research und mehr | Web, mobile App |
| **Kimi Work** | Ein **lokaler Agent** für Wissensarbeiter (Desktop) | Arbeiten mit lokalen Dateien auf Ihrem Computer, Automatisieren von Aufgaben über Desktop-Apps hinweg, Ausführen lang laufender Aufgaben | Mac-/Windows-Client |
| **Kimi Code** | Eine Coding-Assistant-Suite für **Entwickler** | Code schreiben und Codebasen pflegen | CLI, VS Code-Erweiterung |
| **Kimi Claw** | Eine Plattform für **Cloud-Automatisierung ohne Deployment** | Rund um die Uhr laufende Cloud-Automatisierung, Bots mit Integration in Feishu / WeChat und mehr | Cloud (kein Server erforderlich) |

## Welches Produkt sollte ich verwenden?

- **Für alltägliche Chats, Schreiben, Suche oder wenn Kimi Websites erstellen, PPTs und Tabellen anlegen oder Deep Research durchführen soll** → verwenden Sie **Kimi** (Web / App).
- **Wenn Kimi lokale Dateien auf Ihrem Computer lesen und schreiben, mehrere Desktop-Apps übergreifend automatisieren oder lange Aufgaben ausführen soll** → verwenden Sie **Kimi Work** (Desktop).
- **Wenn Sie Entwickler sind und vor allem Unterstützung beim Schreiben von Code oder bei der Pflege von Projekten brauchen** → verwenden Sie **Kimi Code**.
- **Wenn Sie einen ständig verfügbaren Cloud-Bot möchten, der automatisch läuft und sich mit Feishu / WeChat sowie anderen Plattformen verbinden kann** → verwenden Sie **Kimi Claw**.

<Callout type="tip">
Die Online-Erfahrung von Kimi vereint „Chat“ und „Agent“ bereits – Sie müssen nicht zwischen beiden wechseln. In der Desktop-App Kimi Work gibt es zwei Modi: „Work“ (ein Agent-Modus mit Fokus auf Ergebnissen) und „Chat“ (schnelle Unterhaltungen).
</Callout>

## Welche Mitgliedschaft sollte ich wählen?

Die Vorteile einer Mitgliedschaft sind an Ihr Kimi-Konto gebunden. Alle Mitgliedschaftsfunktionen (Chat, Agent, Deep Research, Kimi Code und mehr) **nutzen denselben credit-Pool**; für Kimi Code gilt zusätzlich ein eigener rate limit von 5 Stunden pro Woche, der nur für Kimi Code gilt. Details zu Tarifen und Preisen finden Sie auf der [Seite zu Mitgliedschaftsabos](/membership/membership-pricing).

Wenn Sie Kimi vor allem für **Alltagsarbeit und gelegentliche Aufgaben** nutzen, deckt ein passender Kimi-Mitgliedschaftstarif die meisten Szenarien in Web / App / Kimi Work ab. Entwickler, die **häufig Code schreiben**, sollten außerdem besonders auf die Vorteile von Kimi Code achten.
