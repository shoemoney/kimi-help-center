# Häufig gestellte Fragen (FAQ) zu Skills

## Warum ist die Schaltfläche „Skill erstellen“ deaktiviert?

Dafür kann es folgende Gründe geben:
1. Die hochgeladene Datei oder die Skill-Beschreibung ist unvollständig.
2. Das Dateiformat oder die Anzahl entspricht nicht den Anforderungen.
3. Das System hat festgestellt, dass Ihr Konto-Kontingent aufgebraucht ist.

## Wie verbraucht das Erstellen von Skills Kontingent?

Das Erstellen eines Skills verbraucht Ihre **Tokens**, die entweder aus Ihren geschenkten Suchanfragen oder aus Ihrem offiziellen Mitgliedschaftskontingent stammen können.

**Abzugsreihenfolge**:
1. Geschenkte Suchanfragen werden zuerst verwendet.
2. Sind keine geschenkten Suchanfragen verfügbar, wird das Mitgliedschaftskontingent genutzt.

<Callout type="info">
Schlägt der Erstellungsvorgang fehl, werden keine Tokens abgezogen. Tokens werden erst bei erfolgreicher Erstellung verbraucht.
</Callout>

## Gibt es Beschränkungen für Anzahl oder Häufigkeit der Erstellungen?

Ja, um die Systemstabilität und faire Nutzung zu gewährleisten, gelten folgende Beschränkungen:

1. **Beschränkung der Parallelität**: Maximal **3 Aufgaben** (in Erstellung + Fehlgeschlagen) können gleichzeitig laufen. Wenn Sie dieses Limit erreichen, werden Sie aufgefordert, es nach einiger Zeit erneut zu versuchen.
2. **Tageslimit**: Jeder Nutzer kann pro Tag maximal **10 Konvertierungen von „Office-Dokument zu Skill“** durchführen (einschließlich Wiederholungen). Bei Überschreitung dieses Limits wird eine Hinweismeldung angezeigt.

## Was soll ich tun, wenn das Erstellen eines Skills fehlschlägt?

* Sie können die fehlgeschlagene Skill-Karte entweder **erneut versuchen** oder **löschen**.
* Fehlgeschlagene Versuche verbrauchen kein Kontingent.
* Die ursprüngliche Skill-Beschreibung wird auf der fehlgeschlagenen Karte angezeigt, damit Sie verschiedene Aufgaben unterscheiden können.

## Welche Benennungsanforderungen gelten für neue Skills?

Neue Skill-Namen müssen folgenden Regeln entsprechen:
1. **Dürfen vorhandene Skills nicht duplizieren**: Dazu zählen offizielle Skills und alle Skills, die Sie bereits hinzugefügt haben.
   - Wenn Sie beispielsweise die Skills A, B und C besitzen, erfordert das Erstellen eines neuen Skills namens A eine Umbenennung, um Konflikte zu vermeiden.
2. **Zeichenlänge**: Maximal 25 Zeichen.
3. **Erlaubte Zeichen**: Nur englische Kleinbuchstaben, Bindestriche `-` und Unterstriche `_`.

<Callout type="info">
Das Befolgen dieser Regeln stellt sicher, dass Ihr Skill erfolgreich hinzugefügt wird, und vermeidet Verwechslungen mit vorhandenen Skills.
</Callout>

## Was passiert, wenn ein Skill-Name als „bereits in Verwendung“ gemeldet wird?

Beim Erstellen eines neuen Skills prüft das System, ob der eingegebene Name mit vorhandenen Skills kollidiert – einschließlich offizieller Skills und solcher, die Sie bereits hinzugefügt haben.
Wird ein Konflikt erkannt, erscheint ein Popup mit der Meldung:
> Der Skill-Name `/skill-name` ist bereits in Verwendung. Bitte benennen Sie ihn um, um Verwechslungen zu vermeiden.

Sie können nun entweder einen neuen Skill-Namen eingeben und auf **Umbenennen und hinzufügen** klicken oder auf **Abbrechen** klicken, um die Erstellung zu verwerfen.

## Was passiert, wenn ich einen Namenskonflikt nicht löse?

Das System lässt das Hinzufügen von Skills mit doppelten Namen nicht zu. Wenn Sie den Namenskonflikt nicht lösen, können Sie die Skill-Erstellung nicht abschließen.
