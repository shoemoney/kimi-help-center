# Funktionsübersicht zu Kimi Websites

## Was ist Kimi Websites?

Kimi Websites ist das Full-Stack-Produkt von Kimi Agent zum Erstellen von Websites, unterstützt von Kimi K3, einem multimodalen visuellen Agentic-AI-Modell. Die Kernfunktion ist visuelles Programmieren (Vibe Coding): Sie können aus natürlicher Sprache, einem Design-Mockup oder einer Bildschirmaufzeichnung eine vollständige Full-Stack-Website generieren, online in der Vorschau anzeigen und mit einem Klick veröffentlichen.

Mit Kimi Websites generierte Websites können Folgendes enthalten:

- **Frontend**: HTML-Seitenstruktur, CSS-Layouts und -Styles sowie JavaScript-Interaktionslogik (Bewegungseffekte, Animationen usw.)
- **Backend**: Persistente Datenbankspeicherung, Benutzeranmeldung und Authentifizierung
- **Engineering**: Automatische Versionsverwaltung, Full-Stack-Vorschau und öffentliche Bereitstellung

### Produktfunktionen

| Funktion        | Beschreibung                                                  |
|----------------|--------------------------------------------------------------|
| Website-Erstellung per Dialog | Beschreiben Sie in natürlicher Sprache, was Sie benötigen, und die KI generiert automatisch eine Full-Stack-Website |
| Bild-/Videoverständnis | Laden Sie ein Design-Mockup, einen Screenshot oder eine Bildschirmaufzeichnung hoch; die KI analysiert die Datei automatisch und generiert Seiten daraus |
| Persistente Speicherung | Erstellt automatisch eine Backend-Datenbank mit dauerhaftem Lesen, Schreiben und Verwalten von Daten |
| Datenbankverwaltung | Stellt ein visuelles Datenbank-Panel für grundlegende Datenoperationen wie Anzeigen, Bearbeiten und Löschen bereit |
| Benutzeranmeldung | Unterstützt die Anmeldung mit einem Kimi-Konto und kann über die Datenbank auch ein Anmeldesystem mit Benutzername und Passwort erstellen |
| Versionsverwaltung | Die KI erstellt automatisch Versions-Commits (git commit) und unterstützt das Zurücksetzen auf beliebige frühere Versionen |
| Full-Stack-Vorschau | Unterstützt eine vollständige Vorschau von Frontend und Backend; in manchen Szenarien muss die Sandbox-Umgebung manuell gestartet werden |
| Bearbeitung über mehrere Dialogrunden | Unterstützt iterative Änderungen in mehrstufigen Gesprächen und ermöglicht den Vergleich verschiedener Versionen |
| Visuelle Bearbeitung | Markieren oder umkreisen Sie Elemente auf der Vorschauseite und senden Sie anschließend alle Vorschläge auf einmal an Kimi |
| Veröffentlichung und Deployment | Nachdem Sie manuell auf „Veröffentlichen“ geklickt haben, wird die Website im öffentlichen Internet bereitgestellt; vor der Veröffentlichung ist sie nur als Vorschau verfügbar. Full-Stack-Deployment wird unterstützt |
| Benutzerdefinierte URL | Passen Sie die Subdomain der Website an, zum Beispiel `abc` in `abc.ok.kimi.link` |
| Teilen und Zugriffskontrolle | Erhalten Sie mit einem Klick einen öffentlichen Freigabelink oder setzen Sie die Website auf privat/nur für Sie sichtbar |
| Vorlagenauswahl | Bietet mehrere voreingestellte Vorlagen, damit Sie schnell mit dem Erstellen beginnen können |
| Code-Export | Unterstützt das Herunterladen des vollständigen Projektpakets (einschließlich Frontend und Backend) für ein selbst verwaltetes Deployment |

Besuchen Sie die dedizierte Kimi Websites-Seite

1. Öffnen Sie einen Browser: Verwenden Sie einen gängigen Browser wie Chrome, Safari, Edge oder Firefox.
2. Öffnen Sie die offizielle Zugriffsadresse: die dedizierte Kimi Websites-Seite: [https://www.kimi.com/zh/websites](https://www.kimi.com/zh/websites) (unterstützt Oberflächen auf Chinesisch und Englisch)
3. Melden Sie sich bei Ihrem Konto an: Melden Sie sich mit einem Kimi-Konto an (Registrierung per Mobilnummer oder E-Mail wird unterstützt)
4. Geben Sie Ihre Aufgabe zur Website-Erstellung ein. Kimi Websites bietet drei zentrale Möglichkeiten, eine Website zu erstellen:
   1. **Texteingabe**: Geben Sie die Aufgabe in das Dialogfeld ein und beschreiben Sie die gewünschte Website in natürlicher Sprache;
   2. **Bild-/Website-remix**: Laden Sie ein Design-Mockup oder einen Screenshot einer Website hoch, die Ihnen gefällt, um die entsprechende Funktion auszulösen;
   3. **Vorlagenbasierte Website-Erstellung**: Erstellen Sie schnell eine Standard-Website, indem Sie eine voreingestellte Vorlage auswählen und die Inhalte bearbeiten;
5. Starten Sie die Erstellung: Öffnen Sie die Websites-Funktionsoberfläche, wählen Sie eine Vorlage aus oder erstellen Sie die Website direkt im Gespräch.

## Schritte

### Eine Website per Dialog erstellen

Beschreiben Sie im Eingabefeld in natürlicher Sprache, was Sie benötigen; Kimi versteht die Anfrage und führt sie aus. Drei Erstellungsmethoden werden unterstützt:

| Methode             | Beschreibung                              |
|--------------------|------------------------------------------|
| Textbeschreibung   | Geben Sie die Website-Anforderungen direkt ein; die KI generiert die Website automatisch |
| Analyse von Design-Mockups | Laden Sie ein Design-Mockup hoch; die KI erkennt es und erstellt es als Webseite nach |
| Standard-Websites schnell erstellen | Wählen Sie eine voreingestellte Vorlage und bearbeiten Sie die Inhalte |

Kimi Websites aktiviert webapp-building SKILL, einen Multi-Turn-Codegenerierungs-Agent, der auf die Erstellung von Websites spezialisiert ist. Er führt den folgenden Workflow selbstständig aus:

1. Anforderungsanalyse: Analysiert automatisch Funktionsmodule, visuellen Stil und Interaktionslogik der Website
2. Aufgabenplanung: Unterteilt die Arbeit in Teilaufgaben wie Design, Entwicklung und Vorbereitung von Assets
3. Technische Lösung: Wählt automatisch eine geeignete technische Architektur aus (zum Beispiel React + Tailwind CSS)
4. Asset-Generierung: Generiert bei Bedarf visuelle Assets wie Bilder und Icons
5. Code-Erstellung: Schreibt Seitenstruktur, Styling und Interaktionscode
6. Mehrstufige Optimierung: Passt die Website auf Basis der Vorschau eigenständig an, bis sie vollständig ist

### Oberfläche des Vorschau-Panels

Nachdem die Website generiert wurde, öffnet sich rechts das Vorschau-Panel; außerdem erscheinen Versionskarten im Gespräch. Die wichtigsten Bedienelemente sind:

**Obere Symbolleiste des Vorschau-Panels** (von links nach rechts):

| Schaltfläche | Funktion |
|--------|----------|
| Vorschau / Code | Zwischen visueller Vorschau und Quellcode-/Dateibaumansicht wechseln |
| Bearbeiten | In den Bearbeitungsmodus wechseln; klicken Sie auf einen Bereich, den Sie ändern möchten, fügen Sie Anmerkungen hinzu und senden Sie sie an Kimi |
| Teilen | Website veröffentlichen, Link kopieren, URL anpassen oder Veröffentlichung zurücknehmen |
| Vollbildvorschau | Website im Vollbild anzeigen |
| Vorschaumodus wechseln | Zwischen Desktop- und Mobilansicht umschalten |
| Aktualisieren | Vorschau neu laden |
| Benutzerfeedback | Probleme melden, die während der Nutzung auftreten; Sie können Text eingeben und Screenshots hochladen |
| Schließen | Vorschau-Panel einklappen |

**Versionskarten im Gespräch**: Zeigen den Namen der Website, die Versionsnummer (zum Beispiel V2) und die URL an. Klicken Sie auf **Vorschau**, um die entsprechende Version zu öffnen; klicken Sie auf **Wiederherstellen**, um zu dieser Version zurückzukehren. Über die Karte **Alle Dateien** können Sie die vollständigen Projektdateien anzeigen oder herunterladen. Ausführliche Hinweise zur Nutzung der einzelnen Schaltflächen finden Sie in den entsprechenden Abschnitten unten.

### Code-Deployment und Veröffentlichung
| Deployment-Methode | Beschreibung                                           |
|-------------------|------------------------------------------------------|
| One-Click-Veröffentlichung | Klicken Sie auf die Schaltfläche „Veröffentlichen“, um die Website im öffentlichen Internet bereitzustellen und einen zugänglichen Online-Link zu generieren (vor der Veröffentlichung nur als Vorschau verfügbar) |
| Herunterladen und bereitstellen | Laden Sie das Code-Paket herunter und stellen Sie es auf Ihrem eigenen Server bereit |
| Benutzerdefinierte URL | Ändern Sie die standardmäßige zufällige URL in einen einprägsamen Namen, zum Beispiel indem Sie `abc` in `abc.ok.kimi.link` anpassen |

> **Über „Benutzerdefinierte URL“**: 3–30 Zeichen, nur Kleinbuchstaben, Zahlen und Bindestriche. Darf nicht mit einem Bindestrich beginnen oder enden und darf nicht nur aus Ziffern bestehen. Einige reservierte Wörter (wie `kimi`, `www`, `login` usw.) sind nicht verfügbar. Wenn der Name belegt oder nicht verfügbar ist, wählen Sie bitte einen anderen.

> **Zu den Grenzen von „Herunterladen und bereitstellen“**: **Anmeldung mit Kimi-Konto** und **plattformverwaltete Cloud-Datenbank** werden von der Kimi-Plattform bereitgestellt und werden nicht mit dem exportierten Code migriert. Wenn Sie den Code auf Ihrem eigenen Server bereitstellen, muss die Anmeldemethode auf ein Benutzername-/Passwort-Schema auf Basis Ihrer eigenen Datenbank umgestellt werden; außerdem müssen die Daten in Ihre eigene Datenbank migriert werden. Für rein öffentlichen Zugriff empfehlen wir, direkt **One-Click-Veröffentlichung** zu verwenden; Anmeldung mit Kimi-Konto und Cloud-Daten funktionieren dann weiterhin normal. Details finden Sie unter [Warum funktioniert die von mir erstellte Website nicht?](/websites/websites-why-not-working).

#### Veröffentlichen, teilen und Veröffentlichung zurücknehmen
Vor der Veröffentlichung kann die Website nur im Gespräch in der Vorschau angezeigt werden. Damit andere darauf zugreifen können, klicken Sie oben rechts im Vorschau-Panel auf **Teilen**, um das Veröffentlichungs-Panel zu öffnen:

1. **Benutzerdefinierte URL**: Sie können den Namen in der Standard-URL ändern, zum Beispiel in `yourname.ok.kimi.link`;
2. Klicken Sie auf **Link kopieren**, um die öffentliche URL zu erhalten, oder auf **Website öffnen**, um sie in einem neuen Tab anzuzeigen. Nach der Veröffentlichung zeigt der obere Bereich des Panels **Veröffentlicht** an, und alle Personen mit dem Link können darauf zugreifen;
3. Um die Website offline zu nehmen, wählen Sie im Menü **…** oben rechts im Panel **Veröffentlichung zurücknehmen** aus. Die Website ist dann nicht mehr öffentlich zugänglich (Code und Daten bleiben erhalten, und Sie können sie jederzeit erneut veröffentlichen).

### Bearbeitung über mehrere Dialogrunden

Wenn Sie mit einem bestimmten Teil nicht zufrieden sind, klicken Sie im Vorschaufenster auf die Bearbeiten-Schaltfläche, um ihn weiter zu verfeinern.
Sie können Kimi auch Anweisungen in natürlicher Sprache senden und die Bearbeitung mit Agent fortsetzen.
Sobald Sie das Ergebnis bestätigen, laden Sie den vollständigen HTML/CSS/JS-Code herunter und stellen ihn direkt bereit, oder verfeinern ihn weiter in einem Editor.

## Für wen ist es gedacht?

- Entwickler: Entwerfen Sie Produktprototypen und Frontend-Demos und reduzieren Sie den Aufwand für den Aufbau von Grund auf erheblich.
- Gründer: Erstellen Sie bei begrenzten Ressourcen schnell offizielle Websites, Landingpages und Produktpräsentationsseiten.
- Produktmanager: Verwandeln Sie ein PRD oder Design-Mockup rasch in einen vorführbaren interaktiven Prototyp, ohne auf Entwicklungsplanung warten zu müssen.
- Nichttechnische Nutzer: Programmierkenntnisse sind nicht erforderlich. Beschreiben Sie Ihre Idee oder laden Sie ein Referenzbild hoch – vom Konzept bis zur ausführbaren Webseite.
