# Agent Credits and Billing

Agent mode is billed against Kimi’s unified credit system. All membership features (Agent, Deep Research, PPT, Docs, Sheets, Kimi Code, Kimi Work, Kimi Claw, etc.) share one credit pool, with credits deducted based on actual token consumption.

## Billing method

- **Shared credit pool**: All membership features share a single credit pool, which you can allocate freely. Kimi Code also has a separate usage limit of 5 hours per week; this applies only to Kimi Code and does not affect other membership features
- **Actual usage billing**: Credit consumption depends on the complexity and duration of the task (that is, token usage). Simple tasks use fewer credits, while complex tasks use more
- **Credit refresh**: Credits refresh monthly, in line with your subscription cycle
- **Usage priority**: Complimentary credits, such as trial credits or campaign rewards, are used first, followed by plan credits

<Callout type="tip">
Example: With the Moderato plan, generating a simple PPT may use about 1–2% of your credits, while running one Deep Research task may use about 5–10%.
</Callout>

## What if I run out of credits?

When your credits are used up:

- Tasks already in progress can be completed normally
- New tasks will show an Insufficient Balance message
- You can choose to:
  - Wait for your credits to refresh automatically each month
  - Upgrade to a higher-tier membership plan for more credits

## Will credits be deducted if a task fails?

- Credits are not deducted when a task fails
- After a task is completed successfully, credits are deducted based on actual consumption
