# Agent Credits and Billing

Agent mode is billed using Kimi’s unified credits. Membership benefits for all plans include two credit pools: Kimi Code uses its own dedicated credit pool, while other membership features (Agent, Deep Research, PPT, Docs, Sheets, Kimi Claw, and more) share one credit pool. Credits are deducted based on actual token consumption.

## Billing Method

- **Two credit pools**: Membership benefits for all plans include two credit pools. Kimi Code uses its own dedicated credit pool, while other membership features share one credit pool that you can allocate freely
- **Actual usage-based deduction**: Credit consumption depends on the complexity and duration of the task, namely token usage. Simple tasks use fewer credits; complex tasks use more
- **Credit refresh**: Credits refresh monthly, in line with your subscription cycle
- **Usage priority**: Gift credits, such as trial credits or campaign rewards, are used first, followed by plan credits

<Callout type="tip">
For example, with the Moderato plan, generating a simple PPT may use about 1-2% of your credits, while one Deep Research task may use about 5-10%.
</Callout>

## What if I run out of credits?

When your credits are exhausted:

- Tasks already in progress can still be completed normally
- New tasks will show an insufficient credits prompt
- You can choose to:
  - Wait for your credits to refresh automatically each month
  - Upgrade to a higher-tier membership for more credits

## Are credits deducted if a task fails?

- No credits are deducted if a task fails
- After a task succeeds, credits are deducted based on actual consumption
