# FAQ: Creating Skills

## Why can’t I click the “Create Skills” button?

Possible reasons include:  
1. The uploaded file or Skill description is incomplete;  
2. The file format or number of files does not meet the requirements;  
3. The system has detected that your account credit has been used up.

## How does creating Skills consume credit?

Creating a Skill consumes your **token**, including gifted attempts or official membership credit. If you have remaining token, click “Create Skill” to start creating it.   

**Deduction order**:  
1. Gifted attempts are deducted first.  
2. If there are no gifted attempts left, official membership credit is deducted.  

<Callout type="info">
If creation fails, no fee will be deducted. One token is deducted only after the Skill is created successfully.
</Callout>

## Are there limits on how often or how many times I can create Skills?

Yes. To keep the system stable and ensure fair use, the following limits apply:

1. **Concurrent task limit**: You can have up to **3 tasks** running at the same time (creating + creation failed). If the limit has been reached, creating another Skill will trigger a message saying that up to three tasks can run concurrently.

## What should I do if Skill creation fails?
 
- You can **retry** or **delete the current Skill card**;  
- Failed creation will not be charged. One token is deducted only after the Skill is created successfully;  
- The failed Skill card will show the Skill description for that attempt, making it easier to tell different tasks apart.

## What does it mean if the Skill name is already in use?

When you create a new Skill, the system checks whether the name you entered duplicates an existing Skill, including official Skills and Skills you have added yourself.  
If a duplicate name is found, a pop-up will appear:  
> Skill name `/skill-name` is already in use. Please rename it to avoid confusion.  

You can then enter a new Skill name and click **Rename and add**, or click **Cancel** to abandon this creation.

## What are the requirements for a new Skill name?

A new Skill name must meet the following rules:  
1. **It must not duplicate an existing Skill name**: This includes any duplicate Skill name in the current input box, as well as other Skills you have already added.  
   - For example, if Skills A/B/C already exist and you create a new Skill named A, you must change the name.  
2. **Length limit**: Up to 25 characters.  
3. **Character requirements**: Only lowercase English letters, hyphens `-`, and underscores `_` are supported.  

<Callout type="info">
Following these rules helps ensure your Skill is added successfully and avoids confusion with existing Skills.
</Callout>

## What happens if I don’t change a duplicate Skill name?

The system does not allow Skills with duplicate names to be added. If you do not change the duplicate name, you will not be able to complete Skill creation.
