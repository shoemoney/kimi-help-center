# Top-ups and Invoicing

Below are common questions about Kimi API billing and finance.

## How are charges calculated?

Kimi API is billed by token usage, with input tokens and output tokens priced separately. Prices vary by model, and web search incurs an additional charge of ¥0.03 per use. For detailed pricing, see [platform.kimi.com/docs/pricing/chat](https://platform.kimi.com/docs/pricing/chat).

## Can I top up with WeCom or Alipay?

The API console supports the following top-up methods:

- **Alipay**: Pay by scanning a QR code or logging in to your Alipay account.
- **WeChat Pay**: Pay by scanning a QR code.
- **Corporate bank transfer**: Verified enterprise users can apply to top up by corporate bank transfer. Please contact the sales team for the corporate account details.

After you top up, the balance is credited in real time and can be used for API calls immediately.

## How do I request an invoice?

1. Log in to the [https://platform.kimi.com/](https://platform.kimi.com/) console.
2. Go to the “Billing → Invoice Management” page.
3. Select the top-up records you need to invoice.
4. Fill in the invoice information (individual/enterprise) and submit the application.
5. The e-invoice will be sent to the email address you provide.

Supported invoice types:

- Individual general e-invoice
- Enterprise general e-invoice
- Enterprise special VAT invoice (enterprise verification required)
