# Creating Skills: Frequently Asked Questions

## Why is the "Create Skill" button disabled?

This may happen due to the following reasons:
* The uploaded file or skill description is incomplete.
* The file format or quantity does not meet requirements.
* The system has detected that your account quota has been exhausted.

## How does creating a Skill consume quota?

Creating a skill consumes **tokens**, which can be from your gifted searches or your official membership quota. 

**Deduction Order:**
1.  Gifted searches are prioritized.
2.  If gifted searches are unavailable, membership quota is used.

<Callout type="info">
If the creation process fails, no tokens will be deducted. Tokens are only consumed upon successful creation.
</Callout>

## Are there limits on the number or frequency of creations?

Yes, to ensure system stability and fair usage:

1.  **Concurrency Limit**: A maximum of **3 tasks** (Creating + Failed) can run in parallel. If you reach this limit, you must wait before starting a new one.
2.  **Daily Limit**: Each user can perform a maximum of **10 "Office Doc to Skill" conversions** per day (including retries).

## What should I do if a Skill creation fails?

* You can choose to **Retry** or **Delete** the failed skill card.
* Failed attempts do not consume quota.
* The original description will be displayed on the failed card to help you distinguish between tasks.

## What are the naming requirements for a new Skill?

Skill names must adhere to the following rules:
* **Uniqueness**: It cannot duplicate the name of an official skill or any skill you have already added.
* **Length**: Maximum of 25 characters.
* **Characters**: Only lowercase English letters, hyphens `-`, and underscores `_` are supported.

## What happens if I don't resolve a naming conflict?

The system does not allow skills with duplicate names to be added. If the conflict is not resolved by renaming, the creation process cannot be completed.
