# Using Skills in Kimi Claw

## What are Skills in Claw?

Kimi Claw is an AI agent that runs persistently on your device. Skills give Claw a "work manual" — so it knows exactly how to handle specific tasks, what steps to follow, and what output format and standards you prefer.

Think of Skills as personalized training for Claw: the Skills you install shape how it works.

## Get and Manage Skills

### Download Skills from Kimi

You can download official or custom Skills from the Kimi platform directly to Claw:

1. Open Kimi Claw and go to the **Skills** section.
2. Browse the Skill list, click the one you want, and select **Download to Claw**.
3. Once downloaded, the Skill is ready to use in Claw immediately.

<Callout type="info">
Skills don't update automatically. If a Skill has been updated, you'll need to download it again manually to get the latest version.
</Callout>

### Sync Skills from Kimi Agent

If you've already added Skills in Kimi Agent mode on the web, Claw can sync and display them directly — no need to set them up again.

When Claw detects a version mismatch between the two, it shows an **Update available** prompt next to the Skill. Click it to sync to the latest version.

### Browse Clawhub

Kimi Claw includes a built-in **Clawhub** skill library with a curated collection of high-quality Skills for common work scenarios:

- **Information gathering**: News digests, competitor comparisons, meeting note templates
- **Analysis**: Stock and industry research, data interpretation, risk extraction
- **Workflow management**: End-to-end flows from requirements to output

Browse or search Clawhub for Skills that fit your work, then click to install.

## Invoke a Skill

The same three methods available on the web work in Claw's input box:

- Type `/` to open the Skill list and select one
- Click the **＋** button next to the input box and pick from the menu
- Type the Skill name directly

<Callout type="warning">
The Skills entry point is not currently available in third-party OpenClaw, local Claw, or desktop Claw.
</Callout>

### Example: Teach Claw your market briefing format

Suppose you compile industry updates every day but always have to re-explain the same structure:

1. Type `/skill-creator` in the input box and tell Kimi: "Whenever you help me put together a market briefing, always filter for authoritative sources first, then organize findings into three sections — Opportunities, Risks, and Data — and close with one actionable recommendation."
2. Kimi turns this workflow into a custom Skill and saves it.
3. Next time, just say "Summarize today's EV industry news" and Claw will automatically follow that structure — no further instructions needed.

## Teach Claw Your Way of Working

Beyond using ready-made Skills, you can "train" Claw with your own accumulated knowledge and methods so it works your way on an ongoing basis. There are three main approaches:

**Give it a process**: Walk Claw through the exact steps you follow for a type of task.

**Give it standards**: Tell Claw what matters most to you — accuracy, speed, actionability, or risk control.

**Give it a template**: Describe the output format you want. For example, if your daily standup note always follows "What I did → Problems encountered → Tomorrow's plan → Help needed," just tell Claw once and it will structure every future standup the same way.

<Callout type="tip">
Combining Skills with a customized working style means Kimi Claw consistently delivers faster, more accurate results in exactly the format you expect.
</Callout>

## Mobile Usage

A few things to keep in mind when using Skills on mobile:

- If you've added Skills on the web, the plus menu will show a Skills entry. Tapping it inserts the Skill name as text into the input box.
- If no Skills have been added on the web, the Skills entry won't appear in the mobile plus menu.
- If a conversation contains Skill-generated content, a notice will appear: **Skill output generated — to add Skills, please visit Kimi on the web**.

For Skill management tasks like creating, editing, or deleting, we recommend using the web version. Mobile is best suited for invoking Skills you've already set up.
