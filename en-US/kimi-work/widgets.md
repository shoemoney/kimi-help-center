# Widgets

A widget is an interactive page generated by the model and presented instantly in a chat. You don't need to give explicit deliverable instructions — the model creates a widget when it fits the scenario (for example, showing a map, drafting an email, organizing a recipe, or visualizing data), helping you understand the answer faster and more intuitively.

Widgets can connect to local data or external plugins for continuous updates, and can be saved to your [Dashboard](/kimi-work/dashboard) for long-term viewing and management.

## Generating a Widget

1. Describe what you need in natural language in a chat, for example:

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "Create a daily US tech news digest widget for me, updated every day at 9 AM",
    },
  ]}
/>

2. While it is being generated, you can watch the widget page take shape step by step;
3. Once generated, the widget is ready to interact with right in the chat.

## Widget Tasks and Live Widgets

- **Widget Task**: a task that runs automatically when specific conditions are met — it can be triggered on a schedule or by an event.
- **Live Widget**: a widget bound to a widget task, whose content updates automatically with each run of the task. For example, once the "Daily US Tech News Digest" widget is bound to a task that runs every morning, its content refreshes automatically every day.

<Callout type="info">
There is a limit on how many widget tasks can run at the same time, and it varies by plan. When you reach the limit, pause some tasks from the Dashboard page before creating new ones.
</Callout>

## Saving to Dashboard

After a widget is generated, hover over it and select "Save to Dashboard" to save it to a dashboard. One widget can exist in multiple dashboards at the same time.

In the Dashboard, you can also view the task bound to a live widget, toggle it on or off, and check its 10 most recent runs. See [Dashboard](/kimi-work/dashboard).
