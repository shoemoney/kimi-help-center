# Membership plans overview

Kimi offers four membership tiers — designed to scale with your needs, from everyday productivity to power-user workflows.

All Kimi membership features share a single credit pool. Website deployment, Deep Research, Slides, Kimi Code, Kimi Work, Kimi Claw, and other membership features all draw down membership credits, including K2.6 conversations in Chat.

## How billing works

- **Credit pool** — All membership features (website deployment, Deep Research, Slides, Kimi Code, Kimi Work, Kimi Claw, K3, and K3 Swarm) share a single credit pool, metered by token usage. Using up credits on any one feature affects the others.
- **Kimi Code rate limit** — Kimi Code also has a 5-hour / weekly rate limit that applies only to Kimi Code and does not affect other membership features.
- **Monthly refresh** — Credits reset at the start of each billing cycle.
