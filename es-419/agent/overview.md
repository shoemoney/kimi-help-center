# Descripción general de K2.6 Agent

Kimi K2.6 Agent es un asistente de IA autónomo que gestiona tareas complejas de principio a fin. Impulsado por el modelo K2.6, usa más de 20 herramientas para crear sitios web, generar documentos, analizar datos y mucho más.

## Evolución del producto
- **5 de septiembre de 2025**: Lanzamiento de Kimi K2: 32B de parámetros activos / 1T en total
- **26 de septiembre de 2025**: Lanzamiento del modo Agent «OK Computer»
- **27 de enero de 2026**: Lanzamiento de Kimi K2.5: mejoras en las habilidades de Office y en las capacidades del Agent
- **Febrero de 2026**: Lanzamiento de la beta pública de Kimi Claw

## Capacidades principales
| Función | Descripción |
|---------|-------------|
| **Sitios web** | Genera e implementa aplicaciones web responsivas |
| **Documentos** | Edición y generación de Word, PDF y Markdown |
| **Hojas de cálculo** | Análisis y visualización de datos en Excel/CSV |
| **Diapositivas** | Generación automatizada de PPT |
| **Deep Research** | Informes de investigación de más de 10,000 palabras |
| **K2.6 Agent Swarm** | Hasta 300 subagentes trabajando en paralelo |
| **Kimi Claw** | Automatización en la nube con más de 5,000 habilidades |

## ¿Cómo funciona?
1. **Planificación de tareas**: Descompone tu solicitud en subtareas
2. **Invocación de herramientas**: Usa más de 20 herramientas según se necesite
3. **Ejecución autónoma**: Completa investigación, diseño y desarrollo
4. **Manejo de errores**: Se autocorrige sin que intervengas
5. **Entregables**: Archivos de Office, aplicaciones web o informes

## Primeros pasos
- **Web**: [kimi.com/agent](https://www.kimi.com/agent)
- **Móvil**: App de Kimi → Barra de tareas → Modo Agent
Describe tu tarea con claridad, observa el progreso de la ejecución y luego descarga o comparte los resultados.

## Casos de uso
- Desarrollo de sitios web (sin necesidad de programar)
- Generación de contenido con multimedia
- Comparación y traducción de documentos
- Análisis de datos (Excel de hasta 1,000 filas)
- Generación de diapositivas
- Conversión de documentos
