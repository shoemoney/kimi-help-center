# Créditos y facturación de Agent

<Callout type="info">
El modo Agent usa el sistema de créditos de Kimi. Todas las funciones de la membresía (Agent, Deep Research, Slides, Docs, Sheets, Kimi Code, Kimi Work, Kimi Claw, etc.) comparten un único fondo de créditos, y los créditos se descuentan según el consumo real de token.
</Callout>

## Modelo de facturación
- **Fondo de créditos compartido**: Todas las funciones de la membresía comparten un único fondo de créditos; úsalo como prefieras. Kimi Code también tiene su propio rate limit de 5 horas por semana, que aplica solo a Kimi Code y no afecta a las demás funciones
- **Pago por uso**: El consumo de créditos depende de la complejidad y la duración de la tarea (es decir, del uso de token): las tareas simples cuestan menos y las complejas, más
- **Renovación mensual**: Los créditos se restablecen cada mes, de acuerdo con tu ciclo de suscripción
- **Prioridad de uso**: Primero se consumen los créditos de bonificación (por ejemplo, créditos de prueba o recompensas promocionales) y luego los créditos del plan

<Callout type="tip">
**Ejemplo**: Con un plan Moderato, generar un PPT simple puede consumir alrededor del 1–2% de los créditos, mientras que una sola sesión de Deep Research puede usar cerca del 5–10%.
</Callout>

## ¿Qué pasa cuando se agotan los créditos?
Cuando tus créditos se agotan:
- Cualquier tarea en curso se completará con normalidad
- Las tareas nuevas mostrarán un aviso de "créditos insuficientes"
- Tus opciones:
  - Esperar a que tus créditos mensuales se renueven automáticamente
  - Cambiar a una membresía de nivel superior para obtener más créditos

## ¿Cómo consultar el uso de créditos?
- **Web**: Perfil → Configuración → Suscripción
- **App**: Perfil → Plan de membresía → Suscripción
Qué puedes ver:
1. saldo actual de créditos (como porcentaje)
2. Próxima fecha de renovación
3. Últimos 10 registros de uso (marca de tiempo, función utilizada, porcentaje consumido)

<Callout type="info">
Los registros de uso pueden tener un pequeño retraso. Consulta la visualización actual de créditos para obtener la información más reciente.
</Callout>

## ¿Una tarea fallida también consume créditos?
- Los créditos se descuentan después de que una tarea se ejecuta correctamente, según el consumo real
- Si una tarea falla por un error del sistema (no se devuelve un resultado válido), haz clic en el botón **👎** para reportarlo. Tras la verificación, se reembolsarán los créditos correspondientes
