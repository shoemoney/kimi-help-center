# Plugins

Los plugins conectan herramientas externas a Kimi para que pueda usar apps y servicios al completar tareas. Después de instalar un plugin, Kimi puede recurrir directamente a la capacidad de terceros correspondiente mientras completa una tarea: por ejemplo, consultar datos financieros, manejar software de oficina o usar herramientas de diseño. Puedes pedir explícitamente que se use un plugin específico; Kimi también llamará uno automáticamente cuando corresponda.

## Dónde puedes usar plugins

Puedes usar plugins al cambiar el modelo a **K3** o **K3 Swarm**, y en los escenarios **Deep Research, Websites y PPT**.

También puedes usar plugins en la **app de escritorio Kimi Work**; para ver la lista de plugins integrados en escritorio, consulta el [Centro de plugins de Kimi Work](/kimi-work/plugin-center).

<Callout type="info">
Los plugins aún no son compatibles con las conversaciones de Kimi Claw ni de Kimi Plus.
</Callout>

## Instalación de plugins

- **Puntos de entrada**: en la web, la pestaña **Plugins** de la barra lateral, el **+** del cuadro de entrada o escribe "/"; en móvil, el **+** del cuadro de entrada o "/".
- Busca o explora el marketplace de plugins, abre los detalles de un plugin y haz clic en instalar.
- Algunos plugins requieren **autorización OAuth** (se te redirige al inicio de sesión del tercero; una vez autorizado, puedes usarlo); algunos plugins vienen **preinstalados** y no requieren instalación manual.
- **Plugins exclusivos para empresas**: los usuarios no empresariales pueden verlos, pero el botón "Instalar" aparece deshabilitado.
- No puedes instalar ni usar plugins si no has iniciado sesión.

## Uso de plugins

- Después de instalarlos, escribe "/" en el cuadro de entrada o haz clic en **+** → Plugins, y selecciona el plugin para invocarlo; puedes **invocar varios plugins a la vez**.
- También puedes simplemente describir lo que necesitas (por ejemplo, "busca esta empresa en Tianyancha"), y Kimi elegirá automáticamente el plugin adecuado.
- Cuando Kimi llama a las herramientas de un plugin, muestra "Usando el plugin xx" en su respuesta.

## Categorías y lista de plugins

El marketplace de plugins está organizado en las siguientes categorías. Los plugins que ves en la práctica varían según la **región (local / internacional)** y el **entorno**, y algunos aparecen en más de una categoría.

- **Finanzas**: Análisis de inversiones financieras, Banca de inversión y capital privado, Finanzas corporativas y contabilidad, Datos financieros de Wind, S&P Global Market Intelligence, Hundsun Gildata, Tonghuashun iFinD, SEC, Base de datos financiera global, Datos abiertos del Banco Mundial, Base de datos del IMF (Fondo Monetario Internacional), Stripe, Tianyancha
- **Productividad**: Notion, Baidu Netdisk
- **Desarrollo**: GitHub, Supabase, Neon, Cloudflare
- **Creatividad**: Banco de inspiración, Generación de imágenes, Generación de video, Generación de audio, Canva
- **General**: Vivify

## Credits

Algunos plugins llaman a herramientas o servicios para completar una tarea y **consumen tus credits de membresía según el uso real**; los plugins sin costo de llamada no generan cargos adicionales.

## Datos y permisos

- Cuando seleccionas un plugin o pides explícitamente usarlo, Kimi prioriza las herramientas que ofrece ese plugin y genera su respuesta con base en los resultados que devuelven esas herramientas; después de conectar un plugin, Kimi accede al contenido relevante dentro del alcance que autorizas.
- Si un plugin lo proporciona un tercero, las reglas de tratamiento de datos las define de manera independiente esa empresa, y los datos quedan sujetos a sus términos de servicio y política de privacidad; te recomendamos revisarlos antes de autorizar.
- Puedes **desinstalar un plugin o revocar la autorización en cualquier momento**. Después de desinstalarlo, se revoca la autorización OAuth relacionada; para volver a usar el plugin, tendrás que reinstalarlo y autorizarlo de nuevo.

## Preguntas frecuentes

### ¿Los plugins consumen mis credits de membresía?
Algunos sí. Cuando Kimi llama a las herramientas o servicios de un plugin para completar una tarea, se consumen credits según el uso real; los plugins sin costo de llamada no generan cargos adicionales.

### ¿Puedo usar varios plugins a la vez?
Sí. Puedes invocar varios plugins a la vez mediante "/" o **+**.

### ¿Por qué no veo un plugin determinado?
Los plugins disponibles varían según la región (local / internacional) y el entorno; además, algunos plugins solo están disponibles para usuarios empresariales.
