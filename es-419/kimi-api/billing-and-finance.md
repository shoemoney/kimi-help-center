# Facturación y finanzas

<Callout type="info">
Preguntas frecuentes sobre facturación, precios y pagos de Kimi API.
</Callout>

## ¿Cuál es la estructura de precios?
Kimi API se factura según los tokens consumidos: los tokens de entrada y de salida tienen precios por separado. El precio varía según el modelo, y la búsqueda web tiene un cargo adicional de $0.004 por invocación.

<Callout type="tip">
Para conocer los precios en detalle, consulta [platform.kimi.ai/docs/pricing/chat](https://platform.kimi.ai/docs/pricing/chat).
</Callout>

## ¿Qué métodos de pago se aceptan?
La consola de API admite los siguientes métodos de pago:
| Método | Detalles |
| --- | --- |
| **Tarjeta de crédito/débito** | Visa, Mastercard y otras tarjetas principales |
| **Transferencia bancaria** | Los usuarios verificados como organización pueden solicitar una transferencia bancaria; contacta al equipo de ventas para obtener los datos bancarios |

Los fondos recargados están disponibles de inmediato para usar la API.
## ¿Cómo solicito una factura?
1. Inicia sesión en la consola de [platform.kimi.ai](https://platform.kimi.ai).
2. Ve a **Facturación → Gestión de facturas**.
3. Selecciona los registros de recarga para los que necesitas una factura.
4. Completa los datos de la factura (personales o empresariales) y envía la solicitud.
5. Recibirás una factura electrónica en tu correo electrónico.
