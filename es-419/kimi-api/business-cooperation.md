# Cooperación comercial y ventas

<Callout type="info">
Opciones de colaboración para clientes empresariales: desde descuentos por volumen hasta SLA personalizados.
</Callout>

La API de Kimi ofrece una variedad de opciones de colaboración para clientes empresariales, con el fin de satisfacer necesidades comerciales de cualquier escala.
## ¿Cómo contactar al equipo de ventas?
Visita [platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales) para enviar un formulario de contacto. Nuestro equipo de ventas se comunicará contigo en un plazo de 1 a 2 días hábiles.

<Callout type="tip">
**Incluye en tu envío**:
- Nombre de la empresa e industria
- Volumen de uso estimado
- Casos de uso principales
- Modelo de colaboración preferido
</Callout>

## Firma de contrato
Los usuarios con organización verificada pueden formalizar un acuerdo de servicio con Moonshot:
- Hay disponibles tanto acuerdos de servicio estándar como contratos personalizados.
- Después de firmar, obtienes acceso a pagos por transferencia bancaria y SLA de nivel empresarial.
- Comunícate con el equipo de ventas para conocer los detalles del proceso.

## Descuentos por volumen
Los clientes empresariales con un alto volumen de uso pueden solicitar descuentos exclusivos:
| Requisito | Detalles |
| --- | --- |
| **Elegibilidad** | Verificación de la organización + contrato firmado |
| **Niveles de descuento** | Según el volumen de uso comprometido y la duración del contrato |
| **Solicitud** | Solicítalo a través del equipo de ventas con tu uso mensual estimado |

## Servicio de API empresarial
El servicio de API empresarial se basa en la oferta de API estándar e incluye:
- **Mayores rate limits y quotas de concurrencia**
- **Canal de soporte técnico dedicado**
- **Garantías de SLA personalizadas**
- **Acceso anticipado a nuevas funciones**
