# Cooperación comercial y ventas

<Callout type="info">
Opciones de colaboración para clientes empresariales: desde descuentos por volumen hasta SLA personalizados.
</Callout>

Kimi API ofrece distintas opciones de colaboración para clientes empresariales, pensadas para cubrir necesidades de negocio a cualquier escala.
## ¿Cómo contactar al equipo de ventas?
Visita [platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales) para enviar un formulario de contacto. Nuestro equipo de ventas se comunicará contigo en un plazo de 1 a 2 días hábiles.

<Callout type="tip">
**Incluye en tu solicitud**:
- Nombre de la empresa e industria
- Volumen de uso estimado
- Casos de uso principales
- Modelo de colaboración preferido
</Callout>

## Firma del contrato
Los usuarios con organización verificada pueden celebrar un acuerdo formal de servicio con Moonshot:
- Hay disponibles tanto acuerdos de servicio estándar como contratos personalizados.
- Después de la firma, obtendrás acceso a pagos por transferencia bancaria y SLA de nivel empresarial.
- Contacta al equipo de ventas para revisar el proceso específico.

## Descuentos por volumen
Los clientes empresariales de alto volumen pueden solicitar descuentos exclusivos:
| Requisito | Detalles |
| --- | --- |
| **Elegibilidad** | Verificación de organización + contrato firmado |
| **Niveles de descuento** | Según el volumen de uso comprometido y la duración del contrato |
| **Solicitud** | Solicita el descuento a través del equipo de ventas con tu uso mensual estimado |

## Servicio API empresarial
El servicio API empresarial amplía la oferta estándar de API con:
- **Rate limits más altos y quotas de concurrency**
- **Canal dedicado de soporte técnico**
- **Garantías de SLA personalizadas**
- **Acceso anticipado a nuevas funciones**
