# Descripción general de Kimi API

La plataforma Kimi API ofrece a los desarrolladores potentes capacidades de modelos de lenguaje de gran escala, para que puedas integrar AI rápidamente en tus productos y servicios.

## Descripción general de la plataforma

Kimi API funciona con los modelos de lenguaje de gran escala propietarios de Moonshot, y ofrece generación de texto, conversaciones de varios turnos, análisis de archivos, Web Search y otras capacidades esenciales. La plataforma es compatible con el formato de OpenAI API, lo que permite a los desarrolladores migrar e integrar con un esfuerzo mínimo.

**URL de la plataforma**: [platform.kimi.ai](https://platform.kimi.ai)

## Público objetivo

- **Desarrolladores independientes**: Crea rápidamente proyectos y herramientas personales con AI.
- **Equipos de ingeniería empresariales**: Incorpora capacidades de AI en productos empresariales para mejorar la experiencia del usuario y la eficiencia operativa.
- **Startups**: Accede a capacidades de AI de primer nivel a bajo costo para acelerar la iteración del producto.

## Casos de uso principales

- **Atención al cliente inteligente**: Preguntas y respuestas automatizadas con conocimiento del contexto para mejorar la eficiencia del soporte y la satisfacción del cliente.
- **Generación de contenido**: Redacción de artículos, textos de marketing, generación de código y otros flujos de trabajo creativos.
- **Análisis de datos**: Interpretación de documentos, análisis de informes, extracción de conocimiento y resúmenes.
- **Preguntas y respuestas sobre conocimiento**: Sistemas inteligentes de recuperación y respuesta a preguntas impulsados por repositorios de documentos privados.

## Inicio rápido

1. Visita [platform.kimi.ai](https://platform.kimi.ai) para registrar una cuenta de desarrollador.
2. Crea una clave de API en la consola.
3. Consulta la documentación de la API para realizar tu primera llamada.
4. Elige el modelo y los parámetros adecuados para tu caso de uso.
