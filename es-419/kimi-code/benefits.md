# Beneficios de Kimi Code

Kimi Code es un servicio incluido en el plan de membresía de Kimi que ofrece soporte y funciones de programación para ayudar a los miembros a completar sus tareas de codificación de manera más eficiente en su flujo de trabajo de desarrollo personal.

> Ten en cuenta que este beneficio está pensado únicamente para uso de desarrollo personal, no para escenarios de desarrollo empresarial. Si tienes necesidades empresariales, visita la [Plataforma abierta de Kimi](https://platform.kimi.ai/).

## Facturación

- El uso de Kimi Code está **incluido en tu cuota de suscripción**: no se aplican cargos adicionales.
- Kimi Code **comparte los mismos créditos que tu plan de suscripción de Kimi**: las solicitudes desde la CLI, VS Code y herramientas de terceros se descuentan todas de ellos; cada plan incluye una cantidad diferente de créditos.
- El sistema da prioridad a los créditos de bonificación antes de consumir los créditos del plan.

<Callout type="warning">
**Pronto llegará un nuevo sistema de membresía.** Los beneficios de la membresía de Kimi y los beneficios de Kimi Code se separarán, para que puedas comprarlos por separado según tus necesidades: más flexible. **Los suscriptores actuales no se ven afectados.** Si quieres seguir usando los beneficios combinados, compra tu plan actual antes de que se lance el nuevo sistema.
</Callout>

## Renovación de créditos

Los créditos se renuevan en un ciclo de **7 días**:

- A partir de la fecha de tu suscripción (D1), los créditos se renuevan cada 7 días.
- Períodos de renovación: D1–D7, D8–D14, D15–D21, D22–D28.
- Los créditos no utilizados **no** se trasladan al siguiente ciclo.

> Planifica tu uso semanal para aprovechar al máximo tus créditos.

## Herramientas compatibles

Los beneficios de Kimi Code están disponibles con las siguientes herramientas:

| Herramienta | Descripción |
| --- | --- |
| **Kimi Code CLI** | El agente de IA oficial de línea de comandos de Kimi |
| **Claude Code** | El asistente de codificación de línea de comandos de Anthropic |
| **Roo Code** | Extensión de codificación con IA para VS Code |

Usar tu API Key de Kimi Code con plataformas o herramientas no incluidas en la lista anterior puede considerarse un uso indebido y dar lugar a restricciones de acceso. Utiliza las herramientas compatibles que se enumeran arriba para obtener la mejor experiencia y cobertura.

## Extra Usage

Cuando se agoten los créditos de tu suscripción, puedes seguir haciendo solicitudes usando tu saldo de **Extra Usage** sin esperar a la renovación. Solo los miembros suscritos pueden activarlo, y **Kimi en la web y Kimi Code comparten el mismo saldo de Extra Usage** (recarga una vez y úsalo en ambos). Consulta los términos completos en el [Acuerdo de Extra Usage](https://www.kimi.com/user/agreement/extra-usage-rules-cn).

### Puntos de recarga

- **Desde el sitio principal**: abre la [página de Suscripción](https://www.kimi.com/membership/subscription?tab=quota) de Kimi, desplázate hasta el módulo «Extra Usage» al final, elige un monto y completa el pago.
- **Desde la Kimi Code Console**: cuando tu uso semanal o de 5 horas supere el **80 %**, la tarjeta de progreso mostrará un botón **Comprar Extra Usage** que te lleva a la página de suscripción.

### Activar y gestionar

Activa el interruptor «Extra Usage»; cuando se agoten los créditos de tu suscripción, el sistema descontará automáticamente de tu saldo de Extra Usage. Haz clic en **Configuración** en el módulo para activar un **límite de gasto mensual** y fijar el máximo que puedes gastar este mes; la barra de progreso muestra el consumo de Extra Usage del mes en tiempo real.

### Facturación y reglas

- **Facturación**: se cobra según el uso real: cuanto más contenido se lea y genere y más compleja sea la tarea, mayor será el costo. El saldo se muestra en RMB, con las tarifas indicadas en la plataforma. El precio de Extra Usage es cercano al precio oficial de la API de la [Kimi Open Platform](https://platform.kimi.com); con un uso intensivo, mejorar tu suscripción suele ser más económico.
- **Prioridad de descuento**: primero se descuentan los créditos con límite de tiempo, como la suscripción; **Extra Usage se descuenta al final** como reserva. Una vez activado, aunque tus créditos de suscripción estén agotados, Extra Usage se consume sin interrupciones y las tareas no se detienen ni fallan.
- **Límite de gasto**: activa un «límite de gasto mensual» en la configuración para limitar cuánto Extra Usage se puede gastar este mes; sin él, no hay límite.
- **Validez y acumulación**: el saldo no caduca y se acumula entre recargas; sigue siendo utilizable después de que venza la suscripción, pero no puedes recargar durante la interrupción: vuelve a suscribirte primero para recargar de nuevo.
- **Reembolsos**: por lo general, no reembolsable, no transferible ni canjeable.

<Callout type="info">
Ejemplo de facturación (orden de magnitud aproximado; tarifas reales según la plataforma): una solicitud simple (p. ej., «recomienda una canción de rock») cuesta alrededor de **¥0,03**; una tarea compleja de varios pasos (p. ej., «planifica un viaje por carretera de una semana de Chengdu al oeste de Sichuan») cuesta alrededor de **¥1,6**. Límites de recarga: mínimo ¥25 por recarga, hasta 10 veces y ¥3000 por día, con un saldo máximo de ¥10 000.
</Callout>

### Consultar tu consumo

- **Kimi web / app**: Configuración → Suscripción y facturas → [Mis créditos](https://www.kimi.com/membership/subscription?tab=quota).
- **Kimi Code Console**: una vez activado Extra Usage, inicia sesión en la [Console](https://www.kimi.com/code/console) para ver tu saldo y consumo.
- **Kimi Code CLI**: escribe `/usage` en la línea de comandos para consultarlo directamente.

### Preguntas frecuentes sobre Extra Usage

- **¿Kimi en la web y Kimi Code usan la misma billetera de Extra Usage?** Sí: el saldo se comparte entre ambos; recarga una vez y úsalo en cualquiera.
- **¿Qué se descuenta primero, Extra Usage o los créditos de suscripción?** Primero los créditos con límite de tiempo, como la suscripción; Extra Usage solo se descuenta como reserva una vez agotados todos los créditos con límite de tiempo.
- **¿Puedo continuar si alcanzo un límite o me limitan la tasa?** Sí. Una vez activado Extra Usage, no te afectan los límites de suscripción: al alcanzar cualquier límite, cambia sin interrupciones al saldo de Extra Usage, las tareas no se detienen y solo se descuenta Extra Usage, sin afectar la renovación de tus créditos de membresía.
- **¿El saldo no usado se transfiere y se acumula?** Sí: no caduca y se acumula; sigue siendo utilizable tras el vencimiento de la suscripción, pero no se puede recargar durante la interrupción.
- **¿Extra Usage está disponible para Enterprise?** Aún no es compatible.
- **¿Se reembolsa el saldo tras cerrar mi cuenta?** Escribe a [membership@moonshot.cn](mailto:membership@moonshot.cn) para solicitar un reembolso.
