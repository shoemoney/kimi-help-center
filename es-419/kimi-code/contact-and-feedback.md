# Contacto y comentarios

## Canales para enviar comentarios

Si tienes algún problema al usar Kimi Code o quieres compartir sugerencias, puedes hacerlo a través de los siguientes canales.

### Opción 1: Envía comentarios directamente desde la CLI

En el modo interactivo de Kimi Code CLI, ingresa el comando `/feedback` para enviar tus comentarios. El sistema recopilará automáticamente información sobre tu entorno actual, lo que te ayudará a describir el problema con mayor precisión.

### Opción 2: GitHub Issues

Visita [Kimi CLI GitHub Issues](https://github.com/MoonshotAI/kimi-cli/issues) y busca si ya existe un problema similar. Si no existe, puedes crear un nuevo Issue y describir en detalle lo que encontraste.

### Opción 3: Envía comentarios por correo electrónico

También puedes escribir al equipo de Kimi Code a [code@moonshot.ai](mailto:code@moonshot.ai) para reportar problemas. Incluye tanta información como sea posible de la siguiente lista:

- **Descripción del problema**: Describe con claridad el problema que encontraste o la función que te gustaría tener
- **Pasos para reproducirlo**: Cómo activar el problema paso a paso
- **Información del entorno**: Sistema operativo y versión de Kimi Code CLI (ejecuta `kimi --version` para verificarla)
- **Registros de error**: Si aparece un mensaje de error, pégalo completo

## Solución de problemas antes de enviar comentarios

Antes de enviar tus comentarios, te recomendamos verificar lo siguiente:

- Si actualizaste Kimi Code CLI a la versión más reciente (ejecuta `kimi --version` para verificarla)
- Si tu conexión de red funciona correctamente y puedes acceder a `api.kimi.com`
- Si tu API Key es válida y no ha vencido
- Si el directorio de trabajo es correcto y Kimi tiene permiso para acceder a los archivos correspondientes
