# Descripción general de Kimi Work

Kimi Work es un agente local de propósito general para trabajadores del conocimiento, disponible en el modo "Trabajo" del cliente de escritorio de Kimi (Mac / Windows).

Lleva al entorno de escritorio —familiar para quienes trabajan a diario con información— las capacidades de agente que Kimi Code ya demostró en escenarios de ingeniería: no necesitas abrir una terminal, escribir comandos ni configurar entornos. Solo describe tu objetivo en lenguaje natural, y Kimi Work descompone la tarea, ejecuta pasos en paralelo, llama herramientas, usa el navegador, crea y organiza carpetas, y entrega resultados como documentos, hojas de cálculo y presentaciones, todo en tu propia computadora.

Kimi Code está pensado para desarrolladores que escriben código; Kimi Work está diseñado para trabajadores del conocimiento y cubre principalmente escenarios cotidianos como mover información, organizar archivos, analizar datos y producir informes.

## Capacidades principales

- **Núcleo de agente local**: Usa Kimi Code como núcleo y el modelo Kimi K3, y ofrece los fundamentos de un agente local, incluida la instalación y el uso de habilidades, así como la ejecución de tareas programadas.
- **Habilidades profesionales**: Hereda las habilidades profesionales del Kimi Agent en línea, como la creación de sitios web y PPT, y también permite recomendar habilidades de terceros y cargar habilidades locales.
- **Plugins y bases de datos profesionales**: Usa apps y servicios externos dentro de Kimi, como Canva, Notion y WPS, y conéctate a bases de datos profesionales de finanzas, investigación, derecho y otros campos.
- **Widgets**: Páginas interactivas generadas por el modelo en un chat, que pueden conectarse a datos locales o plugins externos para actualizarse continuamente, lo que vuelve las respuestas más visuales y fáciles de entender. Consulta [Widgets](/kimi-work/widgets).
- **Tablero (Dashboard)**: Reúne los widgets que más te importan en una sola vista persistente y personalizada, organizada en torno a un tema, proyecto u objetivo, lista para consultar y administrar en cualquier momento. Consulta [Tablero](/kimi-work/dashboard).
- **Kimi WebBridge**: Una solución integrada para operar el navegador tal como lo haría una persona.
- **Agent Swarm**: Según la complejidad de la tarea, arma de forma autónoma un equipo de hasta 300 subagentes para encargarse de tareas más complejas y de mayor duración.
- **Ejecución de tareas de largo alcance**: Impulsada por la ejecución de tareas de largo alcance del modelo Kimi K3, admite decenas de horas de trabajo autónomo y miles de llamadas autónomas a herramientas.

## Interfaz e interacción

- El cliente tiene dos modos: "Trabajo" y "Chat". La barra lateral del modo Trabajo incluye: Nueva tarea, Tablero, Plugins, Habilidades, Tareas programadas, WebBridge, Proyectos y Chat.
- Escribe "/" en el cuadro de entrada para usar rápidamente las habilidades, y "@" para agregar contexto.
- Cuenta con control de permisos, y puedes elegir cómo autorizar:
  - **Solicitar permiso**: pedir autorización antes de actuar
  - **Permitir todo**: ejecutar directamente sin pedir autorización
- Alterna entre dos modos de ejecución: "Agent" y "Agent Swarm".

## Notas de versión

Kimi Work se lanzó el 3 de junio de 2026 y actualmente está en beta, con iteraciones frecuentes. Ha incorporado gradualmente funciones como vista previa de archivos, guardado automático de borradores, modo Objetivo, el Centro de plugins, los widgets y el tablero. Desde la versión 3.1.0, Kimi Work funciona con el modelo Kimi K3. Las pruebas actuales se centran en la descomposición de tareas, el paralelismo multiagente, las llamadas a herramientas, la operación del navegador, el manejo de archivos locales y la generación de entregables extensos; la estabilidad de ejecución, la calidad de los resultados y la experiencia de usuario seguirán mejorando con base en los comentarios de los usuarios beta.
