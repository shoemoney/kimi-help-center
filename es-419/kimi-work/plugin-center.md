# Centro de plugins

## Plugins integrados de bases de datos profesionales

Kimi Work incluye plugins integrados de bases de datos profesionales para finanzas, derecho y el ámbito académico, que ofrecen a los profesionales fuentes autorizadas y confiables con datos nacionales y globales:

- **Datos financieros**: Wind Financial Data Service, Hundsun Gildata financial data, S&P Global Market Intelligence, bases de datos financieras globales, la base de datos del IMF (Fondo Monetario Internacional), Straight Flush (Tonghuashun), entre otros
- **Negocios / legal**: Tianyancha, Huayu Yuandian, entre otros

## Plugins seleccionados de apps externas

El Centro de plugins ofrece plugins opcionales seleccionados oficialmente, entre ellos:

- **Colaboración de oficina**: Baidu Netdisk, DingTalk, Feishu, WPS
- **Diseño**: Canva
- **Notas**: Notion
- **Desarrollo web**: Cloudflare
- **Otros**: Kimi Computer Use (la IA controla el escritorio para operaciones a nivel del sistema), GitHub, Neon (una plataforma de base de datos PostgreSQL en la nube), Supabase (una plataforma de backend y base de datos de código abierto), entre otros

Una vez instalado un plugin, Kimi Work puede operar directamente estas herramientas de oficina habituales y reemplazar acciones repetitivas con una sola instrucción en lenguaje natural.

## Cómo habilitarlos

1. Abre la versión más reciente del cliente de escritorio de Kimi, cambia al modo "Work" en la barra lateral izquierda y haz clic en "Plugins" para entrar al Centro de plugins;
2. Busca e instala los plugins que necesites en "Installed" y "Featured plugins";
3. Escribe una barra diagonal "/" en el cuadro de entrada y selecciona el plugin que quieras invocar.
