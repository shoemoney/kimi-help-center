# Resumen de planes de membresía

Kimi ofrece cuatro niveles de membresía, pensados para crecer contigo: desde la productividad diaria hasta los flujos de trabajo de usuarios avanzados.

Todas las funciones de la membresía de Kimi comparten una sola bolsa de créditos. La implementación de sitios web, Deep Research, Slides, Kimi Code, Kimi Work, Kimi Claw y otras funciones de membresía consumen créditos de esa misma bolsa. En el chat, K2.6 es gratis para todos los usuarios y no consume créditos.

## Cómo funciona la facturación

- **Bolsa de créditos** — Todas las funciones de membresía (implementación de sitios web, Deep Research, Slides, Kimi Code, Kimi Work, Kimi Claw, K3 y K3 Swarm) comparten una sola bolsa de créditos, medida según el uso de token. Si agotas créditos en una función, las demás también se ven afectadas.
- **rate limit de Kimi Code** — Kimi Code también tiene un rate limit de 5 horas / semanal que se aplica únicamente a Kimi Code y no afecta otras funciones de membresía.
- **Renovación mensual** — Los créditos se restablecen al inicio de cada ciclo de facturación.
