# Detalles de precios

## Asignación de créditos

Todas las funciones de la membresía de Kimi comparten un único saldo de créditos, medido según el uso de tokens. Kimi Code también tiene su propio rate limit de 5 horas por semana, que se aplica únicamente a Kimi Code y no afecta a otras funciones. En Chat, K2.6 es gratis y no consume créditos. Los niveles superiores incluyen un saldo de créditos proporcionalmente mayor, lo que permite flujos de trabajo más frecuentes y complejos. Consulta [Reglas de actualización y uso de créditos](/membership/update-rules) para más detalles.

## Preguntas frecuentes sobre los credits

### ¿Qué es el cargo del 0.6% de “Claw-云主机” que se deduce todos los días a las 16:00?

Es el costo de ejecución del sandbox de tu host en la nube de Kimi Claw. Kimi Claw es una implementación de OpenClaw en la nube: cada vez que invocas a Claw, el sistema inicia un sandbox aislado en la nube para ejecutar código, operar el navegador o llamar herramientas. Los sandboxes no son un “standby gratuito”: se facturan de forma continua según el tiempo de ejecución y el consumo de recursos. Incluso cuando no estás ejecutando tareas activamente, un host en la nube implementado conserva su entorno de ejecución y sus datos, por lo que cada día se deduce aproximadamente el 0.6% de los credits de tu membresía, con liquidación a las 16:00.

Si no planeas usar Kimi Claw durante un tiempo, guarda primero de forma local los archivos importantes, como los de memory, soul y workspace, y luego elimina el host en la nube; después de eliminarlo no se aplican más cargos y puedes volver a implementarlo en cualquier momento.

### ¿Qué es el cargo del 0.08% de “Agent Website - Cloud Service”?

Es la tarifa de servicio en la nube de un sitio web que publicaste con Agent. Un sitio web publicado ocupa recursos de la nube de forma continua para permanecer en línea y accesible, por lo que se deduce aproximadamente el 0.08% de los credits de tu membresía. Si ya no necesitas que el sitio web esté en línea, haz clic en “Unpublish” para detener los cargos.
