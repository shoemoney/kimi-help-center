## Asignación de créditos

Todas las funciones de la membresía de Kimi comparten un único saldo de créditos, medido según el uso de tokens. Kimi Code también tiene su propio rate limit de 5 horas por semana, que se aplica únicamente a Kimi Code y no afecta a otras funciones. Las conversaciones de K2.6 en Chat también se facturan con créditos. Los niveles superiores incluyen un saldo de créditos proporcionalmente mayor, lo que permite flujos de trabajo más frecuentes y complejos. Consulta [Reglas de actualización y uso de créditos](/membership/update-rules) para más detalles.

## Preguntas frecuentes sobre los credits

### ¿Cómo puedo consultar mi uso de créditos?

- **Web**: Haz clic en tu avatar en la esquina inferior izquierda → Configuración → Suscripción
- **App**: Perfil → Plan de membresía → Suscripción

Puedes ver tu saldo actual de créditos en porcentaje, la próxima hora de renovación y tus últimos 1,000 registros de uso, incluidos la hora de uso, la función y el porcentaje consumido.

<Callout type="tip">
Los detalles de uso pueden mostrarse con un breve retraso. Consulta el saldo de créditos actual como referencia.
</Callout>

### ¿Qué pasa si agoto mis créditos?

Las tareas que ya están en curso pueden completarse con normalidad. Las tareas nuevas mostrarán un aviso de créditos insuficientes. Puedes:

- Esperar a que los créditos se renueven automáticamente cada mes (el límite independiente de 5 horas/semanal de Kimi Code también se restablece por su cuenta y solo afecta a Kimi Code)
- Subir a un plan de membresía superior para obtener más créditos
- Comprar un [paquete de uso adicional](/membership/membership-extra-usage): una vez activado, pagas según tu consumo y no necesitas esperar a que se renueven los créditos
- Participar en campañas oficiales para recibir créditos de bonificación

### ¿Puedo usar todos mis créditos en una sola función?

Sí. Todas las funciones de la membresía comparten una sola bolsa de créditos, que puedes distribuir como prefieras. Ten en cuenta que, si una función agota todos los créditos, esto también afectará a las demás. Kimi Code también tiene su propio rate limit independiente de 5 horas/semanal, que se aplica únicamente a Kimi Code.

### ¿Qué es el cargo del 0.6% de “Claw-云主机” que se deduce todos los días a las 16:00?

Es el costo de ejecución del sandbox de tu host en la nube de Kimi Claw. Kimi Claw es una implementación de OpenClaw en la nube: cada vez que invocas a Claw, el sistema inicia un sandbox aislado en la nube para ejecutar código, operar el navegador o llamar herramientas. Los sandboxes no son un “standby gratuito”: se facturan de forma continua según el tiempo de ejecución y el consumo de recursos. Incluso cuando no estás ejecutando tareas activamente, un host en la nube implementado conserva su entorno de ejecución y sus datos, por lo que cada día se deduce aproximadamente el 0.6% de los credits de tu membresía, con liquidación a las 16:00.

Si no planeas usar Kimi Claw durante un tiempo, guarda primero de forma local los archivos importantes, como los de memory, soul y workspace, y luego elimina el host en la nube; después de eliminarlo no se aplican más cargos y puedes volver a implementarlo en cualquier momento.

### ¿Qué es el cargo del 0.08% de “Agent Website - Cloud Service”?

Es la tarifa de servicio en la nube de un sitio web que publicaste con Agent. Un sitio web publicado ocupa recursos de la nube de forma continua para permanecer en línea y accesible, por lo que se deduce aproximadamente el 0.08% de los credits de tu membresía. Si ya no necesitas que el sitio web esté en línea, haz clic en “Unpublish” para detener los cargos.
