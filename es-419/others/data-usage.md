# ¿Mis datos de conversación se usarán para entrenar el modelo?

Siempre que los datos se procesen con tecnología de cifrado segura, se desidentifiquen estrictamente y no sea posible volver a identificar a una persona específica, la plataforma podrá usar los datos de entrada, las instrucciones y las respuestas generadas por los usuarios para el entrenamiento del modelo, con el fin de optimizar su rendimiento y la experiencia del producto.

Si no deseas que tus datos de conversación se usen para el entrenamiento, puedes escribir a [support@moonshot.ai](mailto:support@moonshot.ai) y presentar una solicitud; una vez verificada tu identidad, dejaremos de usar tu contenido para el entrenamiento del modelo.
