# Credits Agent et facturation

<Callout type="info">
Le mode Agent utilise le système de credits de Kimi. Toutes les fonctionnalités incluses dans l’abonnement (Agent, Deep Research, Slides, Docs, Sheets, Kimi Code, Kimi Work, Kimi Claw, etc.) puisent dans une réserve unique de credits, déduits selon la consommation réelle de tokens.
</Callout>

## Modèle de facturation
- **Réserve de credits partagée** : toutes les fonctionnalités incluses dans l’abonnement utilisent une même réserve de credits — répartissez votre usage comme vous le souhaitez. Kimi Code dispose également de son propre rate limit de 5 heures par semaine, qui s’applique uniquement à Kimi Code et n’a aucune incidence sur les autres fonctionnalités
- **Paiement à l’usage** : la consommation de credits dépend de la complexité et de la durée de la tâche (c’est-à-dire de l’utilisation de tokens) — les tâches simples coûtent moins, les tâches complexes coûtent davantage
- **Renouvellement mensuel** : les credits sont réinitialisés chaque mois, en phase avec votre cycle d’abonnement
- **Ordre de consommation** : les credits bonus (par exemple credits d’essai ou récompenses promotionnelles) sont utilisés en premier, puis les credits du forfait

<Callout type="tip">
**Exemple** : avec un forfait Moderato, générer un PPT simple peut consommer environ 1 à 2 % des credits, tandis qu’une seule session Deep Research peut en utiliser environ 5 à 10 %.
</Callout>

## Que se passe-t-il lorsque les credits sont épuisés ?
Lorsque vos credits sont épuisés :
- Toute tâche déjà en cours se termine normalement
- Les nouvelles tâches affichent un message « credits insuffisants »
- Vous pouvez alors :
  - Attendre le renouvellement automatique de vos credits mensuels
  - Passer à un abonnement de niveau supérieur pour obtenir davantage de credits

## Comment consulter l’utilisation des credits ?
- **Web** : Profil → Paramètres → Abonnement
- **App** : Profil → Forfait d’abonnement → Abonnement
Vous pouvez consulter :
1. le solde actuel de credits (en pourcentage)
2. La prochaine date de renouvellement
3. Les 10 derniers relevés d’utilisation (horodatage, fonctionnalité utilisée, pourcentage consommé)

<Callout type="info">
Les relevés d’utilisation peuvent apparaître avec un léger décalage. Pour obtenir l’information la plus à jour, référez-vous à l’affichage réel des credits.
</Callout>

## Une tâche échouée consomme-t-elle tout de même des credits ?
- Les credits sont déduits une fois la tâche exécutée avec succès, en fonction de la consommation réelle
- Si une tâche échoue à cause d’une erreur système (aucun résultat valide renvoyé), cliquez sur le bouton **👎** pour la signaler. Après vérification, les credits correspondants seront remboursés
