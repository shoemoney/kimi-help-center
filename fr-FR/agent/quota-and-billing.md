# Quota et facturation de l'Agent

<Callout type="info">
Le mode Agent utilise le système de quota de Kimi. Tous les avantages d'abonnement incluent deux réserves de quota : Kimi Code dispose d'une réserve de quota distincte ; les autres fonctionnalités d'abonnement (Agent, Deep Research, Slides, Docs, Sheets, Kimi Claw, etc.) partagent une même réserve de quota, le quota étant déduit selon la consommation réelle de tokens.
</Callout>

## Modèle de facturation
- **Deux réserves de quota** : tous les avantages d'abonnement incluent deux réserves de quota. Kimi Code dispose d'une réserve de quota distincte ; les autres fonctionnalités d'abonnement partagent une même réserve de quota — répartissez votre utilisation à votre guise
- **Paiement à l'usage** : la consommation de quota dépend de la complexité et de la durée de la tâche (c'est-à-dire de l'utilisation de tokens) — les tâches simples coûtent moins cher, les tâches complexes plus cher
- **Renouvellement mensuel** : le quota est réinitialisé chaque mois, en phase avec votre cycle d'abonnement
- **Ordre de consommation** : le quota bonus (par exemple, crédits d'essai, récompenses promotionnelles) est consommé en premier, suivi du quota du forfait

<Callout type="tip">
**Exemple** : avec un forfait Moderato, générer un PPT simple peut consommer environ 1 à 2 % de votre quota, tandis qu'une seule session de Deep Research peut en utiliser environ 5 à 10 %.
</Callout>

## Que se passe-t-il une fois le quota épuisé ?
Lorsque votre quota est épuisé :
- Toute tâche en cours s'achèvera normalement
- Les nouvelles tâches afficheront un message « quota insuffisant »
- Vos options :
  - Attendre le renouvellement automatique mensuel de votre quota
  - Passer à un abonnement de niveau supérieur pour obtenir davantage de quota

## Comment vérifier l'utilisation du quota ?
- **Web** : Profil → Paramètres → Abonnement
- **Application** : Profil → Forfait d'abonnement → Abonnement
Ce que vous pouvez consulter :
1. Le solde de quota actuel (en pourcentage)
2. La prochaine date de renouvellement
3. Les 10 derniers relevés d'utilisation (horodatage, fonctionnalité utilisée, pourcentage de consommation)

<Callout type="info">
Les relevés d'utilisation peuvent présenter un léger délai. Référez-vous à l'affichage réel du quota pour obtenir les informations les plus à jour.
</Callout>

## Une tâche échouée consomme-t-elle malgré tout du quota ?
- Le quota est déduit après l'exécution réussie d'une tâche, selon la consommation réelle
- Si une tâche échoue en raison d'une erreur système (aucun résultat valide renvoyé), cliquez sur le bouton **👎** pour la signaler. Après vérification, le quota correspondant vous sera remboursé
