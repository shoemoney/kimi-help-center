# Crédits et facturation de l'Agent

<Callout type="info">
Le mode Agent utilise le système de crédits de Kimi. Tous les avantages d'abonnement incluent deux réserves de crédits : Kimi Code dispose d'une réserve de crédits distincte ; les autres fonctionnalités d'abonnement (Agent, Deep Research, Diapositives, Documents, Feuilles de calcul, Kimi Claw, etc.) partagent une même réserve de crédits, les crédits étant déduits selon la consommation réelle de tokens.
</Callout>

## Modèle de facturation
- **Deux réserves de crédits** : tous les avantages d'abonnement incluent deux réserves de crédits. Kimi Code dispose d'une réserve de crédits distincte ; les autres fonctionnalités d'abonnement partagent une même réserve de crédits — répartissez votre utilisation à votre guise
- **Paiement à l'usage** : la consommation de crédits dépend de la complexité et de la durée de la tâche (c'est-à-dire de l'utilisation de tokens) — les tâches simples coûtent moins cher, les tâches complexes plus cher
- **Renouvellement mensuel** : les crédits sont réinitialisés chaque mois, en phase avec votre cycle d'abonnement
- **Ordre de consommation** : les crédits bonus (par exemple, crédits d'essai, récompenses promotionnelles) sont consommés en premier, suivis des crédits du forfait

<Callout type="tip">
**Exemple** : avec un forfait Moderato, générer un PPT simple peut consommer environ 1 à 2 % de vos crédits, tandis qu'une seule session de Deep Research peut en utiliser environ 5 à 10 %.
</Callout>

## Que se passe-t-il une fois les crédits épuisés ?
Lorsque vos crédits sont épuisés :
- Toute tâche en cours s'achèvera normalement
- Les nouvelles tâches afficheront un message « crédits insuffisants »
- Vos options :
  - Attendre le renouvellement automatique mensuel de vos crédits
  - Passer à un abonnement de niveau supérieur pour obtenir davantage de crédits

## Comment vérifier l'utilisation des crédits ?
- **Web** : Profil → Paramètres → Abonnement
- **Application** : Profil → Forfait d'abonnement → Abonnement
Ce que vous pouvez consulter :
1. Le solde de crédits actuel (en pourcentage)
2. La prochaine date de renouvellement
3. Les 10 derniers relevés d'utilisation (horodatage, fonctionnalité utilisée, pourcentage de consommation)

<Callout type="info">
Les relevés d'utilisation peuvent présenter un léger délai. Référez-vous à l'affichage réel des crédits pour obtenir les informations les plus à jour.
</Callout>

## Une tâche échouée consomme-t-elle malgré tout des crédits ?
- Les crédits sont déduits après l'exécution réussie d'une tâche, selon la consommation réelle
- Si une tâche échoue en raison d'une erreur système (aucun résultat valide renvoyé), cliquez sur le bouton **👎** pour la signaler. Après vérification, les crédits correspondants vous seront remboursés
