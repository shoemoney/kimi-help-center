# Impossible de télécharger ou d'enregistrer un rapport Deep Research ?

<Callout type="info">
Deep Research génère deux types de rapports, qui peuvent tous deux être enregistrés.
</Callout>

## Rapport de recherche textuel

Cliquez sur le bouton **« Télécharger »** ou **« Copier »** dans le coin supérieur droit. Le rapport peut être enregistré localement ou collé pour être réutilisé.

**Formats d'export** : PDF et Word

## Rapport visuel

Cliquez sur **« Aperçu » → « Partager » → « Copier le lien » → ouvrez dans un navigateur → clic droit « Enregistrer sous »** pour l'enregistrer au format HTML, PDF ou autre.

<Callout type="tip">
**Fonctionnalités du rapport visuel** :
- **Aperçu** : cliquez sur « Aperçu » pour basculer entre l'affichage bureau et mobile
- **Code source HTML** : cliquez sur Aperçu → basculez en « Mode code » pour copier le code source
- **Partage public** : cliquez sur Partager pour générer un lien de partage public
</Callout>
