# Contact et commentaires

**Q : Où puis-je envoyer mes commentaires ?**

Choisissez le canal approprié en fonction du type de commentaire :

| Type de commentaire | Canal |
|--------------|---------|
| Problèmes liés au produit | Sur le web : cliquez sur votre avatar (en bas à gauche) → Commentaires utilisateur → Aide et commentaires. Dans l'application : Profil → Paramètres → Commentaires |
| Commentaires sur la qualité des conversations | Après une conversation, cliquez sur le bouton **👎** et décrivez le type de problème ainsi que l'écart précis |
| Recours / signalements liés au compte | [support@moonshot.ai](mailto:support@moonshot.ai) |
| Demandes des médias | [pr@kimi.com](mailto:pr@kimi.com) |
| Assistance Kimi API | Connectez-vous à la [Kimi Open Platform](https://platform.moonshot.ai/) pour accéder aux contacts du service client et à la communauté des développeurs |
