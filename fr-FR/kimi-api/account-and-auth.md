# Compte et authentification

<Callout type="info">
Questions fréquentes sur les comptes développeur de l'API Kimi, la vérification et l'authentification.
</Callout>

## Un compte personnel peut-il obtenir une facture professionnelle ?
Un compte personnel **ne peut pas recevoir directement de facture professionnelle**. Si vous avez besoin d'une facture professionnelle, commencez par faire passer votre compte au statut de compte d'organisation. Une fois la vérification effectuée, vous pourrez demander des factures au nom de votre organisation.

## Comment passer d'un compte personnel à un compte d'organisation ?
1. Connectez-vous à la console [platform.moonshot.ai](https://platform.moonshot.ai).
2. Accédez à **Paramètres du compte → Vérification**.
3. Sélectionnez **Vérification de l'organisation** et renseignez les informations requises.
4. Soumettez le dossier pour examen — une fois approuvé, votre compte sera automatiquement converti.

<Callout type="tip">
Le solde existant et les données d'utilisation sont conservés après la mise à niveau.
</Callout>

## Différence entre la vérification personnelle et la vérification d'organisation
| Aspect | Personnel | Organisation |
| --- | --- | --- |
| Type de facture | Facture personnelle | Facture professionnelle / avec TVA |
| Rate limits | Standard | Éligible à des quotas plus élevés |
| Contrats commerciaux | — | Signature de contrat possible |
| Remises sur volume | — | Disponibles sur demande |
| Support technique | Standard | Support prioritaire |

## Comment contester une suspension de compte ?
Si votre compte API a été suspendu pour non-respect de la politique :
1. Envoyez un e-mail à **support@moonshot.ai** avec pour objet « API Account Appeal ».
2. Indiquez les informations de votre compte (adresse e-mail enregistrée) ainsi qu'une description de votre réclamation.
3. L'équipe examinera votre demande et vous répondra sous 1 à 3 jours ouvrés.

<Callout type="info">
**E-mail du support** : support@moonshot.ai
</Callout>

## Comment modifier l'adresse e-mail enregistrée ?
Pour modifier votre adresse e-mail enregistrée, contactez le support :
1. Envoyez un e-mail à **support@moonshot.ai** avec pour objet « Email Change Request ».
2. Indiquez votre adresse e-mail actuelle ainsi que la nouvelle.
3. Une vérification d'identité pourra être requise afin de garantir la sécurité du compte.

## Avantages d'une vérification complète
- **Rate limits plus élevés** : les utilisateurs vérifiés sont éligibles à des taux d'appels API plus élevés.
- **Accès complet aux fonctionnalités** : certaines fonctionnalités avancées peuvent être réservées aux utilisateurs vérifiés.
- **Prise en charge des factures** : les comptes vérifiés peuvent demander des factures.
- **Support technique** : les utilisateurs vérifiés bénéficient d'un support technique prioritaire.
