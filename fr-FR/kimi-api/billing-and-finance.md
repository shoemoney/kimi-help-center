# Facturation et finances

<Callout type="info">
Questions fréquentes sur la facturation, les tarifs et les paiements de l’API Kimi.
</Callout>

## Quelle est la structure tarifaire ?
L’API Kimi est facturée au token consommé : les tokens d’entrée et les tokens de sortie sont tarifés séparément. Les tarifs varient selon le modèle, et la Web Search entraîne des frais supplémentaires de 0,004 $ par invocation.

<Callout type="tip">
Pour connaître les tarifs détaillés, consultez [platform.kimi.ai/docs/pricing/chat](https://platform.kimi.ai/docs/pricing/chat).
</Callout>

## Quels moyens de paiement sont pris en charge ?
La console API prend en charge les moyens de paiement suivants :
| Moyen | Détails |
| --- | --- |
| **Carte de crédit/débit** | Visa, Mastercard et autres grandes cartes |
| **Virement bancaire** | Les utilisateurs dont l’organisation a été vérifiée peuvent demander à payer par virement bancaire — contactez l’équipe commerciale pour obtenir les coordonnées bancaires |

Les fonds crédités sont disponibles immédiatement pour l’utilisation de l’API.
## Comment demander une facture ?
1. Connectez-vous à la console [platform.kimi.ai](https://platform.kimi.ai).
2. Accédez à **Facturation → Gestion des factures**.
3. Sélectionnez les recharges pour lesquelles vous avez besoin d’une facture.
4. Renseignez les informations de facturation (particulier ou entreprise), puis envoyez la demande.
5. Une facture électronique vous sera envoyée par e-mail.
