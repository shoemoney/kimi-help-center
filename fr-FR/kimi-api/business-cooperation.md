# Partenariats commerciaux et ventes

<Callout type="info">
Options de partenariat pour les clients entreprises — des remises sur volume aux SLA personnalisés.
</Callout>

Kimi API propose aux clients entreprises différents modes de partenariat pour répondre aux besoins métier, quelle que soit l’échelle.
## Comment contacter l’équipe commerciale ?
Rendez-vous sur [platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales) pour remplir le formulaire de contact. Notre équipe commerciale vous répondra sous 1 à 2 jours ouvrés.

<Callout type="tip">
**À inclure dans votre demande** :
- Nom de l’entreprise et secteur d’activité
- Volume d’utilisation estimé
- Principaux cas d’utilisation
- Modèle de partenariat souhaité
</Callout>

## Signature du contrat
Les utilisateurs dont l’organisation a été vérifiée peuvent conclure un accord de service formel avec Moonshot :
- Des accords de service standard comme des contrats personnalisés sont disponibles.
- Une fois le contrat signé, vous accédez au paiement par virement bancaire et à des SLA de niveau entreprise.
- Contactez l’équipe commerciale pour discuter de la procédure à suivre.

## Remises sur volume
Les clients entreprises à fort volume peuvent demander des remises exclusives :
| Condition | Détails |
| --- | --- |
| **Éligibilité** | Vérification de l’organisation + contrat signé |
| **Niveaux de remise** | Selon le volume d’utilisation engagé et la durée du contrat |
| **Demande** | À effectuer auprès de l’équipe commerciale avec une estimation de l’utilisation mensuelle |

## Service API entreprise
Le service API entreprise enrichit l’offre API standard avec :
- **Des rate limits plus élevés et des quotas de concurrency supérieurs**
- **Un canal de support technique dédié**
- **Des garanties SLA personnalisées**
- **Un accès anticipé aux nouvelles fonctionnalités**
