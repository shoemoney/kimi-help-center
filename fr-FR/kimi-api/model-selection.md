# Sélection et comparaison des modèles

<Callout type="info">
Choisissez le modèle Kimi API le mieux adapté selon ses capacités, sa rapidité et sa tarification.
</Callout>

Kimi API propose plusieurs modèles parmi lesquels les développeurs peuvent choisir.
## Modèles disponibles
Consultez [platform.kimi.ai/docs/models](https://platform.kimi.ai/docs/models) pour obtenir la liste complète des modèles et leurs spécifications détaillées.
Pour choisir un modèle, vous pouvez tenir compte des critères suivants :
| Critère | À prendre en compte |
| --- | --- |
| **Longueur du contexte** | Privilégiez les modèles à grand contexte pour traiter de longs documents |
| **Vitesse de réponse** | Optez pour des modèles légers dans les scénarios sensibles à la latence |
| **Qualité de génération** | Choisissez des modèles haut de gamme pour le raisonnement complexe et l’écriture créative |
| **Tarification** | Sélectionnez un modèle économique en fonction de votre budget et du volume prévu |

## Modèles de vision
Les modèles de vision prennent en charge les images en entrée pour la génération de légendes, l’OCR, l’interprétation de graphiques, et bien plus encore :

<Callout type="info">
- Chaque image est facturée à un tarif fixe de **1,024 tokens**, quelles que soient ses dimensions ou sa résolution
- Formats pris en charge : JPEG, PNG, WebP, etc.
- Les images peuvent être transmises via une URL ou un encodage Base64
</Callout>

## Fonctionnalités non prises en charge actuellement

<Callout type="warning">
- **Multimodal vidéo** : l’entrée vidéo directe n’est pas encore prise en charge
- **API de génération PPT** : pas encore disponible via API
- **API Deep Research** : pas encore disponible via API
</Callout>

Pour suivre l’évolution de ces fonctionnalités, consultez les annonces de la plateforme.
