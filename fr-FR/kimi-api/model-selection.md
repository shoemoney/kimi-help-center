# Choix et comparaison des modèles

<Callout type="info">
Choisissez le modèle Kimi API adapté selon ses capacités, sa rapidité et son tarif.
</Callout>

Kimi API propose plusieurs modèles parmi lesquels les développeurs peuvent choisir.
## Modèles disponibles
Consultez [platform.kimi.ai/docs/models](https://platform.kimi.ai/docs/models) pour la liste complète des modèles et leurs spécifications détaillées.
Au moment de choisir un modèle, vous pouvez tenir compte des éléments suivants :
| Critère | À prendre en compte |
| --- | --- |
| **Longueur du contexte** | Privilégiez les modèles à grand contexte pour le traitement de longs documents |
| **Vitesse de réponse** | Optez pour des modèles légers dans les scénarios sensibles à la latence |
| **Qualité de génération** | Choisissez des modèles de gamme supérieure pour le raisonnement complexe et la rédaction créative |
| **Tarif** | Sélectionnez le modèle le plus rentable selon votre budget et votre volume |

## Modèles de vision
Les modèles de vision acceptent les images en entrée pour le sous-titrage, l'OCR, l'interprétation de graphiques, et plus encore :

<Callout type="info">
- Chaque image est facturée à un tarif fixe de **1 024 tokens**, quelles que soient ses dimensions ou sa résolution
- Formats pris en charge : JPEG, PNG, WebP, etc.
- Les images peuvent être transmises par URL ou par encodage Base64
</Callout>

## Fonctionnalités non encore prises en charge

<Callout type="warning">
- **Multimodal vidéo** : l'entrée vidéo directe n'est pas encore prise en charge
- **API de génération de PPT** : pas encore disponible via l'API
- **API Deep Research** : pas encore disponible via l'API
</Callout>

Pour suivre l'évolution de ces fonctionnalités, consultez les annonces de la plateforme.
