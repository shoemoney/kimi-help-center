# Avantages de Kimi Code

Kimi Code est un service inclus dans l'offre d'abonnement Kimi, qui propose une assistance et des fonctionnalités liées au code pour aider les abonnés à réaliser plus efficacement leurs tâches de programmation dans leur flux de développement personnel.

> Veuillez noter que cet avantage est destiné uniquement à un usage de développement personnel, et non à des scénarios de développement en entreprise. Pour les besoins professionnels, rendez-vous sur la [Plateforme ouverte de Kimi](https://platform.kimi.ai/).

## Facturation

- L'utilisation de Kimi Code est **incluse dans vos frais d'abonnement** — aucuns frais supplémentaires ne s'appliquent.
- Kimi Code **partage les mêmes crédits que votre formule d'abonnement Kimi** — les requêtes issues de la CLI, de VS Code et des outils tiers y sont toutes décomptées ; les différentes offres incluent des montants de crédits différents.
- Le système privilégie les crédits bonus avant de consommer les crédits de l'offre.

<Callout type="warning">
**Un nouveau système d'abonnement arrive bientôt.** Les avantages de l'abonnement Kimi et les avantages Kimi Code seront séparés, afin que vous puissiez les acheter séparément selon vos besoins — plus flexible. **Les abonnés actuels ne sont pas affectés.** Si vous souhaitez continuer à utiliser les avantages combinés, achetez votre formule actuelle avant le lancement du nouveau système.
</Callout>

## Renouvellement des crédits

Les crédits se renouvellent selon un cycle de **7 jours** :

- À partir de votre date d'abonnement (J1), les crédits se renouvellent tous les 7 jours.
- Périodes de renouvellement : J1–J7, J8–J14, J15–J21, J22–J28.
- Les crédits non utilisés **ne sont pas** reportés au cycle suivant.

> Planifiez votre utilisation hebdomadaire pour tirer le meilleur parti de vos crédits.

## Outils pris en charge

Les avantages de Kimi Code sont disponibles avec les outils suivants :

| Outil | Description |
| --- | --- |
| **Kimi Code CLI** | L'agent IA officiel en ligne de commande de Kimi |
| **Claude Code** | L'assistant de code en ligne de commande d'Anthropic |
| **Roo Code** | Extension de code IA pour VS Code |

Utiliser votre clé API Kimi Code avec des plateformes ou des outils ne figurant pas dans la liste ci-dessus peut être considéré comme un usage abusif et entraîner une restriction d'accès. Veuillez utiliser les outils pris en charge mentionnés ci-dessus pour bénéficier de la meilleure expérience et d'une couverture optimale.

## Extra Usage

Une fois les crédits de votre abonnement épuisés, vous pouvez continuer à envoyer des requêtes grâce à votre solde **Extra Usage**, sans attendre le renouvellement. Seuls les membres abonnés peuvent l'activer, et **Kimi sur le web et Kimi Code partagent le même solde Extra Usage** (rechargez une fois, utilisez dans les deux). Consultez les conditions complètes dans l'[accord Extra Usage](https://www.kimi.com/user/agreement/extra-usage-rules-cn).

### Points de recharge

- **Depuis le site principal** : ouvrez la [page Abonnement](https://www.kimi.com/membership/subscription?tab=quota) de Kimi, faites défiler jusqu'au module « Extra Usage » en bas, choisissez un montant et finalisez le paiement.
- **Depuis la Kimi Code Console** : dès que votre usage hebdomadaire ou sur 5 heures dépasse **80 %**, la carte de progression affiche un bouton **Acheter Extra Usage** qui vous mène à la page d'abonnement.

### Activer et gérer

Activez le commutateur « Extra Usage » ; lorsque les crédits de votre abonnement sont épuisés, le système débite automatiquement votre solde Extra Usage. Cliquez sur **Paramètres** dans le module pour activer un **plafond de dépenses mensuel** et définir le montant maximal pour le mois ; la barre de progression affiche en temps réel la consommation d'Extra Usage du mois.

### Facturation et règles

- **Facturation** : selon l'usage réel — plus il y a de contenu lu et généré et plus la tâche est complexe, plus le coût est élevé. Le solde est affiché en RMB, aux tarifs indiqués sur la plateforme. Les tarifs d'Extra Usage sont proches des prix officiels de l'API de la [Kimi Open Platform](https://platform.kimi.com) ; en cas d'usage intensif, mettre à niveau votre abonnement est généralement plus économique.
- **Ordre de prélèvement** : les crédits à durée limitée comme l'abonnement sont prélevés en premier ; **Extra Usage est prélevé en dernier**, en réserve. Une fois activé, même si vos crédits d'abonnement sont épuisés, Extra Usage est consommé sans interruption : les tâches ne s'arrêtent pas et n'échouent pas.
- **Plafond de dépenses** : activez un « plafond de dépenses mensuel » dans les paramètres pour limiter le montant d'Extra Usage dépensé ce mois-ci ; sans cela, il n'y a pas de plafond.
- **Validité et cumul** : le solde n'expire pas et se cumule au fil des recharges ; il reste utilisable après l'expiration de l'abonnement, mais vous ne pouvez pas recharger pendant l'interruption — réabonnez-vous d'abord pour recharger à nouveau.
- **Remboursement** : généralement non remboursable, non transférable et non échangeable.

<Callout type="info">
Exemple de facturation (ordre de grandeur indicatif ; tarifs réels selon la plateforme) : une requête simple (par ex. « recommande une chanson rock ») coûte environ **¥0,03** ; une tâche complexe en plusieurs étapes (par ex. « planifie un road trip d'une semaine de Chengdu au Sichuan occidental ») coûte environ **¥1,6**. Limites de recharge : minimum ¥25 par recharge, jusqu'à 10 fois et ¥3 000 par jour, avec un solde plafonné à ¥10 000.
</Callout>

### Vérifier votre consommation

- **Kimi web / app** : Paramètres → Abonnement et factures → [Mes crédits](https://www.kimi.com/membership/subscription?tab=quota).
- **Kimi Code Console** : une fois Extra Usage activé, connectez-vous à la [Console](https://www.kimi.com/code/console) pour voir votre solde et votre consommation.
- **Kimi Code CLI** : tapez `/usage` en ligne de commande pour vérifier directement.

### FAQ Extra Usage

- **Kimi sur le web et Kimi Code utilisent-ils le même portefeuille Extra Usage ?** Oui — le solde est partagé entre les deux ; rechargez une fois, utilisez dans les deux.
- **Qu'est-ce qui est prélevé en premier, Extra Usage ou les crédits d'abonnement ?** Les crédits à durée limitée comme l'abonnement d'abord ; Extra Usage n'est prélevé qu'en réserve, une fois tous les crédits à durée limitée épuisés.
- **Puis-je continuer en cas d'atteinte d'une limite ou de limitation de débit ?** Oui. Une fois Extra Usage activé, vous n'êtes plus affecté par les limites d'abonnement — à chaque limite atteinte, le système bascule sans interruption sur le solde Extra Usage, les tâches ne s'arrêtent pas, et seul Extra Usage est débité sans affecter le renouvellement de vos crédits d'abonnement.
- **Le solde inutilisé est-il reportable et cumulable ?** Oui — il n'expire pas et se cumule ; il reste utilisable après l'expiration de l'abonnement, mais aucune recharge n'est possible pendant l'interruption.
- **Extra Usage est-il disponible pour Enterprise ?** Pas encore pris en charge.
- **Le solde est-il remboursé après la fermeture de mon compte ?** Veuillez écrire à [membership@moonshot.cn](mailto:membership@moonshot.cn) pour demander un remboursement.
