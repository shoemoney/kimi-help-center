# Contact et retours

## Canaux de retour

Si vous rencontrez un problème lors de l’utilisation de Kimi Code ou si vous avez des suggestions, vous pouvez nous en faire part via les canaux suivants.

### Option 1 : Envoyer un retour directement depuis le CLI

Dans le mode interactif de Kimi Code CLI, saisissez la commande `/feedback` pour envoyer votre retour. Le système collectera automatiquement les informations sur votre environnement actuel, afin de vous aider à décrire le problème plus précisément.

### Option 2 : GitHub Issues

Rendez-vous sur [Kimi CLI GitHub Issues](https://github.com/MoonshotAI/kimi-cli/issues) et effectuez une recherche pour vérifier si un problème similaire existe déjà. Si ce n’est pas le cas, vous pouvez créer une nouvelle Issue et décrire en détail ce que vous avez rencontré.

### Option 3 : Retour par e-mail

Vous pouvez également écrire à l’équipe Kimi Code à l’adresse [code@moonshot.ai](mailto:code@moonshot.ai) pour signaler un problème. Merci d’inclure autant que possible les informations suivantes :

- **Description du problème** : décrivez clairement le problème rencontré ou la fonctionnalité souhaitée
- **Étapes de reproduction** : indiquez comment déclencher le problème, étape par étape
- **Informations sur l’environnement** : système d’exploitation et version de Kimi Code CLI (exécutez `kimi --version` pour vérifier)
- **Journaux d’erreur** : s’il y a un message d’erreur, veuillez le coller dans son intégralité

### Option 4 : Rejoindre le groupe Feishu
Scannez le QR code pour rejoindre le groupe Feishu

## Vérifications avant d’envoyer un retour

Avant d’envoyer votre retour, nous vous recommandons de vérifier les points suivants :

- Que vous avez bien installé la dernière version de Kimi Code CLI (exécutez `kimi --version` pour vérifier)
- Que votre connexion réseau fonctionne et que vous pouvez accéder à `api.kimi.com`
- Que votre clé API est valide et n’a pas expiré
- Que le répertoire de travail est correct et que Kimi dispose de l’autorisation d’accéder aux fichiers concernés
