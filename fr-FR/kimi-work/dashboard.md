# Dashboard

Un dashboard est un conteneur de widgets. Il rassemble les widgets qui comptent le plus pour vous dans une vue unique, persistante et personnalisée, organisée autour d’un sujet, d’un projet ou d’un objectif. Un dashboard n’est lié à aucune conversation en particulier : vous pouvez l’ouvrir à tout moment et gérer ses widgets depuis n’importe quelle conversation.

## Créer et gérer des dashboards

1. Cliquez sur « Dashboard » dans la barre latérale gauche pour ouvrir le menu Dashboard ;
2. Cliquez sur « Create » et renseignez un nom (obligatoire) et une description (facultative) ;
3. Chaque utilisateur peut créer jusqu’à 2 dashboards.

Sur un dashboard vide, vous pouvez décrire directement le widget souhaité, et Kimi le construira dans ce dashboard.

<Callout type="warning">
Supprimer un dashboard supprime également tous les widgets qu’il contient et leurs tâches de widget associées. Cette action est irréversible : procédez avec prudence.
</Callout>

## Mise en page et annotations

- Chaque dashboard peut contenir jusqu’à 20 widgets. Faites-les glisser pour les réorganiser et redimensionnez-les à votre convenance.
- Cliquez sur « Refresh » pour actualiser le contenu des widgets du dashboard.
- Cliquez sur « Annotate » pour passer en mode annotation : sélectionnez n’importe quel élément d’un widget pour créer une annotation positionnée et consigner vos remarques. Les annotations sont listées par ordre chronologique, jusqu’à 10 entrées ; cliquez sur une annotation enregistrée pour la modifier à nouveau.

## Gérer les widgets d’un dashboard

Survolez un widget pour :

- Cliquer sur « Expand » pour afficher le nom et le type du widget ;
- Pour un live widget, gérer la tâche de widget associée : consulter le nom et la description de la tâche, l’activer ou la désactiver, et vérifier ses 10 dernières exécutions (date d’exécution et statut) ;
- Cliquer sur « … » pour choisir :
  - **Delete** : supprime définitivement le widget de la conversation d’origine et de tous les dashboards — cette action est irréversible ;
  - **Pin to Desktop** : épingle le widget sur le bureau de votre ordinateur dans une fenêtre autonome à la taille personnalisable ; la fenêtre se ferme automatiquement lorsque vous quittez l’application.

## Ouvrir un dashboard depuis une conversation

Le modèle peut afficher une carte de dashboard dans une conversation. Cliquez sur la carte pour ouvrir la page du dashboard correspondante dans le panneau latéral droit, sans quitter la conversation en cours.
