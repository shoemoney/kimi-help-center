# Centre des plugins

## Plugins intégrés de bases de données professionnelles

Kimi Work intègre des plugins de bases de données professionnelles couvrant la finance, le droit et le monde académique. Ils offrent aux professionnels des sources fiables et reconnues, avec des données aussi bien nationales qu’internationales :

- **Données financières** : Wind Financial Data Service, données financières Hundsun Gildata, S&P Global Market Intelligence, bases de données financières mondiales, base de données du FMI (Fonds monétaire international), Straight Flush (Tonghuashun), et plus encore
- **Entreprises / juridique** : Tianyancha, Huayu Yuandian, et plus encore

## Sélection de plugins d’applications externes

Le Centre des plugins propose des plugins facultatifs, sélectionnés officiellement, notamment :

- **Collaboration bureautique** : Baidu Netdisk, DingTalk, Feishu, WPS
- **Design** : Canva
- **Notes** : Notion
- **Développement web** : Cloudflare
- **Autres** : Kimi Computer Use (l’IA contrôle le bureau pour effectuer des opérations au niveau du système), GitHub, Neon (une plateforme de base de données PostgreSQL dans le cloud), Supabase (une plateforme open source de backend et de base de données), et plus encore

Une fois un plugin installé, Kimi Work peut piloter directement ces outils bureautiques courants et remplacer des actions répétitives par une simple instruction en langage naturel.

## Activer un plugin

1. Ouvrez la dernière version du client de bureau Kimi, passez en mode « Travail » dans la barre latérale gauche, puis cliquez sur « Plugins » pour accéder au Centre des plugins ;
2. Recherchez et installez les plugins dont vous avez besoin dans « Installés » et « Plugins recommandés » ;
3. Saisissez une barre oblique « / » dans la zone de saisie, puis sélectionnez le plugin à appeler.
