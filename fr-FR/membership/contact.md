# Nous contacter

Besoin d'aide ? Voici comment nous joindre.

## Assistance facturation et abonnement

**E-mail :** membership@moonshot.ai

Idéal pour :

- Des crédits qui n'apparaissent pas après un achat
- Des problèmes de paiement ou de facturation
- Le changement, la rétrogradation ou la résiliation d'une formule
- Les demandes de factures

Les membres payants bénéficient d'une réponse prioritaire. Merci d'indiquer l'adresse e-mail de votre compte et de joindre toute capture d'écran utile afin d'accélérer la résolution de votre demande.

## Assistance générale

**E-mail :** support@moonshot.ai

Idéal pour :

- Les questions sur les fonctionnalités du produit
- Les problèmes techniques rencontrés avec Kimi
- Les questions liées au compte (hors facturation)
- Les suggestions de fonctionnalités et les retours

## Assistance pour le service API

**E-mail :** api-service@moonshot.ai.
Vous pouvez également vous rendre sur la [communauté Kimi OpenPlatform](https://forum.moonshot.ai/)

Idéal pour :

- Les questions relatives à l'API
- Les problèmes techniques rencontrés avec l'API Kimi
- Les suggestions de fonctionnalités et les retours

## Retours depuis l'application

Vous pouvez aussi nous transmettre vos retours directement dans Kimi :

- **Web :** cliquez sur le bouton **Retour** dans le coin inférieur gauche, décrivez votre problème, puis envoyez.
- **Mobile :** accédez à **Profil → Aide et retours → Envoyer un retour**.

Les signalements effectués depuis l'application joignent automatiquement le contexte de votre appareil et de votre compte, ce qui nous aide à diagnostiquer les problèmes plus rapidement.
