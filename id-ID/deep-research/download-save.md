# Tidak bisa mengunduh atau menyimpan laporan Deep Research?

<Callout type="info">
Deep Research menghasilkan dua jenis laporan, dan keduanya bisa disimpan.
</Callout>

## Laporan riset berbentuk teks

Klik tombol **"Unduh"** atau **"Salin"** di pojok kanan atas. Laporan bisa disimpan ke perangkat atau ditempel untuk digunakan.

**Format ekspor**: PDF dan Word

## Laporan visual

Klik **"Pratinjau" → "Bagikan" → "Salin tautan" → buka di peramban → klik kanan "Simpan sebagai"** untuk menyimpan sebagai HTML, PDF, atau format lainnya.

<Callout type="tip">
**Fitur Laporan Visual**:
- **Pratinjau**: Klik "Pratinjau" untuk beralih antara tampilan desktop dan seluler
- **Kode sumber HTML**: Klik Pratinjau → beralih ke "Mode kode" untuk menyalin kode sumber
- **Berbagi publik**: Klik Bagikan untuk membuat tautan berbagi publik
</Callout>
