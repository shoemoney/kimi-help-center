# Kimi Docs & Kimi Sheets

<Callout type="info">
Pada 27 Januari 2026, Moonshot AI merilis Kimi K2.5, yang membawa peningkatan besar pada kemampuan produktivitas Kimi Agent. Kini Kimi Agent "menguasai Office" dengan output file end-to-end untuk Word, PDF, Excel, dan Slides.
</Callout>

Kimi K2.5 menghadirkan peningkatan signifikan pada kualitas output dan efisiensi pemanggilan tool dalam skenario perkantoran, terutama pada output terstruktur dengan kemampuan pemrosesan end-to-end:
| Format | Kemampuan |
|--------|-------------|
| **Word** | Pemformatan cerdas dan pelacakan revisi |
| **PDF** | Desain visual dan tata letak gabungan teks-gambar |
| **Excel** | Analisis data dan pemodelan keuangan |
| **Slides** | Pembuatan otomatis dan penceritaan visual |

## Kimi Docs
Kimi Docs memiliki kemampuan adaptasi teks yang kuat serta pemahaman sistematis terhadap alur kerja Office.
### Kemampuan utama
**Dokumen Word:**
- Membuat dokumen profesional berformat panjang: white paper, laporan riset, kontrak, proposal
- Menyisipkan komentar dan saran revisi ke dalam dokumen Word yang ada
- Mengelola hierarki judul, spasi paragraf, sitasi, dan pemformatan daftar
- Memadatkan tesis 30.000 kata menjadi ringkasan yang tepat
**Dokumen PDF:**
- Membuat laporan PDF profesional yang kaya ilustrasi dengan sampul, daftar isi, isi, dan keterangan gambar
- Mengedit ulang dan memformat ulang PDF yang ada tanpa perangkat lunak tata letak profesional
- Mengekstrak informasi spesifik dari PDF ratusan halaman
- Membandingkan perbedaan halus di antara berbagai versi kontrak
### Cara menggunakan Kimi Docs?
**Titik Akses:**
- Umum: Klik pintasan Docs, Sheets, atau Slides di bilah samping atau kotak obrolan
- Khusus: Klik tombol "Docs" di bagian bawah kotak obrolan
### Cara 1: kunjungi halaman Kimi Docs

<Frames
  src="./images/overview/screenshot-1.png"

1. **Buka browser**: Chrome, Safari, Edge, Firefox, atau browser populer lainnya
2. **Kunjungi**: [kimi.com/docs](https://www.kimi.com/docs)
3. **Masuk**: Masuk dengan akun Kimi Anda (Google atau email)
4. **Masukkan tugas**:
   - **Input teks**: Ketik tugas dalam bahasa alami
   - **Unggah dokumen** untuk diedit
   - **Jelajahi contoh**: Klik "Make one like this," sesuaikan, lalu kirim
5. **Mulai membuat**: Pilih template atau buat melalui percakapan

<Callout type="tip">
Jelaskan kebutuhan Anda secara langsung, misalnya, "Buatkan saya laporan XX." Atau unggah file Word/PDF/Excel yang ada dan tentukan operasinya. Unduh file dalam format aslinya (.docx / .xlsx / .pdf) untuk melanjutkan pengeditan secara lokal.
</Callout>

### Cara 2: aplikasi seluler
Aplikasi Kimi tersedia di iOS dan Android. Ketuk Taskbar → beralih ke mode Docs Agent.
#### Cara 3: mode Agent umum
Beralih ke mode K2.6 Agent dan masukkan tugas terkait dokumen. Kimi akan memanggil tool untuk membaca dan menulis.
## Kimi Sheets
Kimi Sheets memahami relasi antarsel, logika keterkaitan lintas-lembar, dan menghasilkan file .xlsx langsung di browser.
### Kemampuan utama
| Kemampuan | Deskripsi |
|------------|-------------|
| **Entri data massal** | Mengekstrak data dari dokumen — misalnya, menarik info peserta pameran dari PDF ke file Excel 1.000 baris |
| **Konsolidasi multi-sumber** | Menggabungkan 50 laporan Excel dari berbagai departemen menjadi satu ringkasan perusahaan |
| **Input bahasa alami** | Pencarian web mandiri dengan pembuatan spreadsheet cerdas |

### Cara menggunakan Kimi Sheets?
Klik tombol "Agent" di bagian bawah kotak obrolan, atau pilih pintasan "Sheets" di bilah samping.

<Frames
  src="./images/overview/screenshot-4.png"
  alt="screenshot 4"
/>

Anda bisa mengatakan: *"Cari di web dan kompilasikan publikasi terbaru di bidang XX ke dalam dokumen Excel,"* atau unggah file Excel/CSV yang ada dan tentukan operasinya. Pratinjau secara online, lalu unduh file .xlsx.
