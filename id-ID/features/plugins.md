# Plugin

Plugin menghubungkan alat eksternal ke Kimi agar Kimi dapat menggunakan aplikasi dan layanan untuk menyelesaikan tugas. Setelah Anda menginstal plugin, Kimi dapat langsung memanggil kemampuan pihak ketiga yang sesuai saat menyelesaikan tugas — misalnya, mencari data keuangan, mengoperasikan perangkat lunak perkantoran, atau memakai alat desain. Anda dapat secara eksplisit meminta penggunaan plugin tertentu, dan Kimi juga akan memanggilnya secara otomatis bila diperlukan.

## Tempat Anda dapat menggunakan plugin

Anda dapat menggunakan plugin saat beralih ke model **K3** atau **K3 Swarm**, serta dalam skenario **Deep Research, Websites, dan PPT**.

Anda juga dapat menggunakan plugin di **aplikasi desktop Kimi Work**; untuk daftar plugin bawaan di desktop, lihat [Pusat Plugin Kimi Work](/kimi-work/plugin-center).

<Callout type="info">
Plugin belum didukung dalam percakapan Kimi Claw atau Kimi Plus.
</Callout>

## Menginstal plugin

- **Titik masuk**: di web, tab **Plugin** pada bilah samping, tombol **+** di kotak input, atau ketik "/"; di seluler, tombol **+** di kotak input atau "/".
- Cari atau jelajahi marketplace plugin, buka detail plugin, lalu klik instal.
- Beberapa plugin memerlukan **otorisasi OAuth** (Anda akan diarahkan ke proses masuk pihak ketiga; setelah diotorisasi, plugin dapat digunakan); beberapa plugin sudah **terpasang sebelumnya** dan tidak perlu diinstal secara manual.
- **Plugin khusus enterprise**: pengguna non-enterprise dapat melihatnya, tetapi tombol "Instal" berwarna abu-abu.
- Anda tidak dapat menginstal atau menggunakan plugin saat belum masuk.

## Menggunakan plugin

- Setelah menginstal, ketik "/" di kotak input atau klik **+** → Plugin, lalu pilih plugin untuk memanggilnya; Anda dapat **memanggil beberapa plugin sekaligus**.
- Anda juga cukup menjelaskan kebutuhan Anda (misalnya, "cari perusahaan ini di Tianyancha"), dan Kimi akan memilih plugin yang tepat secara otomatis.
- Saat Kimi memanggil alat milik sebuah plugin, balasannya akan menampilkan "Menggunakan plugin xx".

## Kategori dan daftar plugin

Marketplace plugin disusun ke dalam kategori berikut. Plugin yang benar-benar Anda lihat dapat berbeda berdasarkan **wilayah (domestik / luar negeri)** dan **antarmuka**, dan sebagian plugin muncul di lebih dari satu kategori.

- **Keuangan**: Analisis Investasi Keuangan, Perbankan Investasi & Ekuitas Swasta, Keuangan Perusahaan & Akuntansi, Wind Financial Data, S&P Global Market Intelligence, Hundsun Gildata, Tonghuashun iFinD, SEC, Global Financial Database, World Bank Open Data, Basis Data IMF (International Monetary Fund), Stripe, Tianyancha
- **Produktivitas**: Notion, Baidu Netdisk
- **Pengembangan**: GitHub, Supabase, Neon, Cloudflare
- **Kreatif**: Kumpulan Inspirasi, Pembuatan Gambar, Pembuatan Video, Pembuatan Audio, Canva
- **Umum**: Vivify

## Credit

Sebagian plugin memanggil alat atau layanan untuk menyelesaikan tugas dan **mengonsumsi credit keanggotaan Anda berdasarkan penggunaan aktual**; plugin tanpa biaya pemanggilan tidak menimbulkan biaya tambahan.

## Data dan izin

- Saat Anda memilih atau secara eksplisit meminta penggunaan plugin, Kimi memprioritaskan alat yang disediakan plugin tersebut dan menyusun jawaban berdasarkan hasil yang dikembalikan oleh alat-alat itu; setelah plugin terhubung, Kimi mengakses konten relevan dalam cakupan yang Anda otorisasi.
- Jika plugin disediakan oleh pihak ketiga, aturan pemrosesan datanya ditetapkan secara independen oleh perusahaan tersebut, dan data tunduk pada ketentuan layanan serta kebijakan privasinya — kami menyarankan Anda meninjaunya sebelum memberi otorisasi.
- Anda dapat **menghapus plugin atau mencabut otorisasi kapan saja**. Setelah plugin dihapus, otorisasi OAuth terkait akan dicabut; untuk menggunakan plugin lagi, Anda perlu menginstal ulang dan memberi otorisasi kembali.

## FAQ

### Apakah plugin mengonsumsi credit keanggotaan saya?
Sebagian ya. Saat Kimi memanggil alat atau layanan milik plugin untuk menyelesaikan tugas, credit dikonsumsi berdasarkan penggunaan aktual; plugin tanpa biaya pemanggilan tidak menimbulkan biaya tambahan.

### Bisakah saya menggunakan beberapa plugin sekaligus?
Bisa. Anda dapat memanggil beberapa plugin sekaligus melalui "/" atau **+**.

### Mengapa saya tidak bisa melihat plugin tertentu?
Plugin yang tersedia dapat berbeda berdasarkan wilayah (domestik / luar negeri) dan antarmuka; selain itu, sebagian plugin hanya tersedia untuk pengguna enterprise.
