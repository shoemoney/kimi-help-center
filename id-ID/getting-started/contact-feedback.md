# Kontak & masukan

**T: Di mana saya bisa menyampaikan masukan?**

Pilih saluran yang sesuai dengan jenis masukan Anda:

| Jenis Masukan | Saluran |
|--------------|---------|
| Masalah produk | Di web: klik avatar Anda (kiri bawah) → User Feedback → Help & Feedback. Di aplikasi: Profil → Pengaturan → Masukan |
| Masukan kualitas obrolan | Setelah percakapan, klik tombol **👎** lalu jelaskan jenis masalah dan penyimpangan spesifiknya |
| Banding / laporan akun | [support@moonshot.ai](mailto:support@moonshot.ai) |
| Pertanyaan media | [pr@kimi.com](mailto:pr@kimi.com) |
| Dukungan Kimi API | Masuk ke [Kimi Open Platform](https://platform.moonshot.ai/) untuk kontak layanan pelanggan dan komunitas developer |
