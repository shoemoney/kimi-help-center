# Pemilihan & perbandingan model

<Callout type="info">
Pilih model Kimi API yang tepat berdasarkan kemampuan, kecepatan, dan harga.
</Callout>

Kimi API menyediakan beragam model yang bisa dipilih oleh para pengembang.
## Model yang tersedia
Kunjungi [platform.kimi.ai/docs/models](https://platform.kimi.ai/docs/models) untuk daftar model lengkap beserta spesifikasi terperincinya.
Saat memilih model, Anda dapat mempertimbangkan:
| Dimensi | Pertimbangan |
| --- | --- |
| **Panjang Konteks** | Pilih model berkonteks besar untuk memproses dokumen panjang |
| **Kecepatan Respons** | Model ringan untuk skenario yang sensitif terhadap latensi |
| **Kualitas Hasil** | Model kelas atas untuk penalaran kompleks dan penulisan kreatif |
| **Harga** | Pilih model yang hemat biaya sesuai anggaran dan volume |

## Model visual
Model visual mendukung masukan gambar untuk pembuatan keterangan, OCR, interpretasi grafik, dan banyak lagi:

<Callout type="info">
- Setiap gambar ditagih dengan tarif tetap **1.024 token**, terlepas dari dimensi atau resolusinya
- Format yang didukung: JPEG, PNG, WebP, dll.
- Gambar dapat dikirim melalui URL atau enkode Base64
</Callout>
