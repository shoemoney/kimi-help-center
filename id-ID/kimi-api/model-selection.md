# Pemilihan & perbandingan model

<Callout type="info">
Pilih model Kimi API yang tepat berdasarkan kemampuan, kecepatan, dan harga.
</Callout>

Kimi API menyediakan beberapa model yang dapat dipilih developer.
## Model yang tersedia
Kunjungi [platform.kimi.ai/docs/models](https://platform.kimi.ai/docs/models) untuk melihat daftar model lengkap beserta spesifikasi detailnya.
Saat memilih model, Anda dapat mempertimbangkan:
| Dimensi | Pertimbangan |
| --- | --- |
| **Panjang Konteks** | Pilih model dengan konteks besar untuk pemrosesan dokumen panjang |
| **Kecepatan Respons** | Gunakan model ringan untuk skenario yang sensitif terhadap latensi |
| **Kualitas Generasi** | Gunakan model kelas lebih tinggi untuk penalaran kompleks dan penulisan kreatif |
| **Harga** | Pilih model yang hemat biaya sesuai anggaran dan volume penggunaan |

## Model visi
Model visi mendukung input gambar untuk pembuatan keterangan gambar, OCR, interpretasi bagan, dan lainnya:

<Callout type="info">
- Setiap gambar ditagih dengan tarif tetap sebesar **1.024 token**, terlepas dari dimensi atau resolusinya
- Format yang didukung: JPEG, PNG, WebP, dll.
- Gambar dapat dikirim melalui URL atau encoding Base64
</Callout>

- **API Pembuatan PPT**: Belum tersedia melalui API
