# Transfer file

Kimi Claw mendukung pengiriman dan penerimaan file.

## Mengirim file ke Kimi Claw

Kamu bisa mengirim gambar, dokumen, dan file lainnya ke Kimi Claw melalui Kimi. Kimi Claw akan memanfaatkan perangkat bawaannya untuk melihat dan memproses file tersebut.

## Menerima file dari Kimi Claw

Versi terbaru Kimi memungkinkan Kimi Claw mengirimkan file kembali kepadamu. Jika pengiriman file tidak berfungsi, pastikan kamu menggunakan plugin Kimi versi terbaru.

## Mengelola file di workspace

Kamu juga bisa menelusuri dan mengunduh file yang dihasilkan Kimi Claw melalui **Workspace** di web. Workspace menyimpan semua file yang dibuat selama Kimi Claw bekerja, sehingga bisa kamu akses kapan saja.
