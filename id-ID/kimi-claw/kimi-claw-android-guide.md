# Ikhtisar Kimi Claw Android

Artikel ini menjelaskan cara menerapkan OpenClaw ke ponsel Android dan mengubah ponsel yang tidak terpakai menjadi asisten AI jarak jauh 24/7. Anda dapat mengendalikan ponsel dari jarak jauh, menggunakan aplikasi, terhubung ke rumah pintar, serta membuat asisten personal melalui aplikasi pesan seperti Kimi, Feishu, dan WeChat.

Sebaiknya terapkan Kimi Claw Android pada ponsel yang tidak terpakai agar tidak terjadi konflik izin dengan penggunaan harian. Jangan memutakhirkan versi OpenClaw secara manual; pembaruan resmi yang sudah disesuaikan akan dikirim melalui pembaruan versi dalam aplikasi.

## Unduh dan instal
### Unduh Kimi Claw Android

Anda dapat mengunduhnya dengan cara berikut:

#### Metode 1: Pindai kode QR untuk mengunduh dari halaman web.
Masuk ke [kimi.com](https://kimi.com), temukan pintu masuk "Unduh Kimi Claw Android", lalu gunakan ponsel Android Anda untuk memindai kode QR di halaman tersebut dan mengunduh.

<Frames
  src="./images/kimi-claw-android-guide/img-03.png"
/>

#### Metode 2: Unduh langsung dari Google Play
Cari "Kimi Claw" di toko aplikasi seluler dan selesaikan pengunduhan

#### Metode 3: Unduh Kimi App di perangkat seluler
Buka Kimi App, klik Kimi Claw Android, dan Anda juga dapat menautkan instance OpenClaw yang sudah ada.

### Konfigurasi Awal 

Saat pertama kali membuka Kimi Claw Android, Anda akan melihat halaman sambutan. Setelah memahami informasi penting berikut, klik "Mulai Konfigurasi" untuk masuk ke proses penyiapan.

- Penerapan OpenClaw Cepat - Terapkan OpenClaw ke ponsel lokal untuk berkomunikasi melalui Kimi, Feishu, dll.
- Disarankan menggunakan ponsel yang tidak terpakai - Kimi Claw Android memerlukan jaringan yang stabil untuk berjalan, dan disarankan menggunakan ponsel yang tidak terpakai
- Gunakan dengan aman - OpenClaw dapat melibatkan risiko privasi dan keamanan, jadi gunakan dengan hati-hati.

Setelah memilih Setuju atas Kebijakan Privasi dan Perjanjian Pengguna, lanjutkan.

#### Langkah 1: Berikan izin
Kimi Claw Android memerlukan izin berikut agar dapat berjalan stabil di latar belakang. Klik "Otorisasi" satu per satu untuk menyelesaikan pemberian izin.

| Izin | Penjelasan |
| --- | --- |
| Notifikasi sistem | Menampilkan status gateway dan pengingat |
| Izin ruang penyimpanan | Memerlukan ruang tersedia minimal 5GB |
| Izin berjalan di latar belakang | Menjaga gateway tetap berjalan saat beralih ke latar belakang |

Karena jalur pengaturan berbeda-beda pada tiap merek ponsel, berikut langkah umumnya:

1. Klik "Buka Pengaturan" untuk melompat ke halaman pengaturan ponsel
2. Masuk ke daftar manajemen aplikasi dan pilih Kimi Claw Android
3. Aktifkan sakelar mulai otomatis
4. Pilih "Izinkan Sepenuhnya Perilaku Latar Belakang" di Manajemen Konsumsi Daya
5. Kembali ke Kimi Claw Android, klik "Saya sudah selesai" untuk melanjutkan instalasi

#### Langkah 2: Konfigurasikan Akun Kimi

1. Klik "Buka Konfigurasi" untuk melompat ke Kimi App guna melakukan otorisasi
2. Setelah otorisasi, Kimi akan otomatis membuat kunci API Kimi Coding Plan untuk Kimi Claw Android
3. Jika Anda pengguna gratis, Anda perlu mengaktifkan hak keanggotaan terlebih dahulu. Klik "Buka Upgrade" untuk mengaktifkan keanggotaan Anda.

#### Langkah 3: Instal OpenClaw

#### Pencadangan dan Pemulihan

Kimi Claw Android menyediakan fungsi pencadangan otomatis dan manual untuk memastikan riwayat serta konfigurasi OpenClaw Anda tidak hilang.

Pencadangan Otomatis

Kimi Claw Android akan secara otomatis mencadangkan riwayat dan konfigurasi OpenClaw saat ini secara berkala, lalu mengemasnya ke dalam file terkompresi untuk disimpan. Tidak diperlukan operasi manual; sistem akan menyelesaikannya secara otomatis di latar belakang.

Pencadangan Manual:

Jika ingin merekam keadaan pada momen tertentu, Anda juga dapat mengklik Cadangkan secara aktif untuk menyimpan snapshot riwayat dan konfigurasi saat ini secara manual. Klik  Cadangkan  untuk mengekspor semua cadangan konfigurasi saat ini.

**Pulihkan Konfigurasi:**

Kimi Claw Android mendukung pemulihan ke status konfigurasi sebelumnya. Sistem juga mendukung status pencadangan otomatis maupun status pencadangan aktif Kimi Claw Android.

Dalam skenario berikut, Anda dapat memulihkan ke status sebelumnya menggunakan fungsi pemulihan:

- Saat menghapus instalasi atau menginstal ulang aplikasi menyebabkan catatan riwayat hilang, catatan lama dapat dipulihkan
- Saat perlu mengganti konfigurasi Claw, Anda dapat memulihkannya ke status konfigurasi yang sebelumnya disimpan
- Saat mengganti ponsel dan menerapkan ulang, cukup impor file cadangan untuk memulihkan

Klik file cadangan yang sesuai di daftar cadangan, dan Anda dapat otomatis memulihkan catatan riwayat serta konfigurasi ke titik waktu tersebut, sehingga catatan lama tidak terhapus.

## Konfigurasikan saluran chat

### Kimi
Kimi adalah saluran komunikasi default, dan akan otomatis terhubung setelah konfigurasi akun Kimi selesai dalam proses Onboarding, tanpa perlu operasi tambahan.

Setelah instalasi dan konfigurasi selesai, Kimi Claw Android Anda akan otomatis muncul di halaman Peralihan Bot pada klien Web (kimi.com). Setelah diklik untuk beralih, avatar dan utas chat akan ikut beralih secara sinkron.

Kimi Claw Android hanya mendukung pengeditan nama Bot dan penghapusan Bot di manajemen Bot.

### Feishu
<Frames
  src="./images/kimi-claw-android-guide/img-25.png"
/>

Mendukung tiga metode koneksi:

Metode 1: Buka Feishu untuk membuat

Klik "Buka Feishu untuk Membuat", selesaikan pembuatan aplikasi di Feishu sesuai petunjuk, dan status akan otomatis diperbarui menjadi "Terhubung".

Metode 2: Pindai kode QR untuk membuat

1. Klik "Pindai Kode QR untuk Membuat"
2. Gunakan Feishu untuk memindai kode QR
3. Selesaikan pembuatan aplikasi Feishu di browser

**Metode 3: Masukkan informasi Bot secara manual**

1. Klik "Masukkan Informasi Bot Secara Manual"
2. Masukkan App ID dan App Secret
3. Klik "Tambahkan" untuk menyelesaikan koneksi

### WeChat
Saluran WeChat perlu terlebih dahulu menginstal WeChat Claw di sisi WeChat, dan Kimi Claw Android akan berkomunikasi melalui terminal WeChat Claw

Anda perlu terlebih dahulu menyelesaikan instalasi WeChat Claw sesuai panduan resmi WeChat. Instalasi selesai ketika WeChat ClawBot muncul di halaman chat.

Masuk ke Kimi Claw Android, hubungkan ke saluran WeChat, lalu selesaikan proses dengan memindai kode QR menggunakan WeChat

## Otomatisasi

Salah satu kemampuan inti Kimi Claw Android adalah mengendalikan aplikasi di ponsel untuk menyelesaikan berbagai tugas. Setelah mengirim instruksi ke Claw melalui saluran chat seperti Kimi, Feishu, dan WeChat, Claw akan otomatis membuka aplikasi yang sesuai di ponsel, menjalankan serangkaian operasi layaknya pengguna sungguhan, lalu menyelesaikan tugas yang Anda tentukan.

### Cara Kerja

Saat Anda mengirim instruksi tugas ke Claw melalui saluran chat, Claw akan:

1. Memahami kebutuhan tugas Anda
2. Otomatis membuka aplikasi yang sesuai di ponsel
3. Menyelesaikan tugas langkah demi langkah dengan menyimulasikan operasi pengguna (mengklik, menggeser, memasukkan teks, dll.)
4. Mengambil tangkapan layar selama proses eksekusi untuk memudahkan Anda meninjau prosesnya
5. Melaporkan hasil eksekusi kepada Anda setelah tugas selesai

### Skenario Penggunaan Umum

#### Belanja dan Konsumsi

Mencari produk, menambahkan ke keranjang, melihat pesanan, mengambil diskon, dan sebagainya di platform seperti Taobao, Tmall, dan Meituan.

#### Perjalanan dan Navigasi

Mengecek tarif taksi, melihat jadwal kereta bawah tanah, mencari hotel terdekat, memesan perjalanan, dan sebagainya di Amap.

#### Sosial dan Konten

Memeriksa pesan, menelusuri konten, mencari produk, melakukan operasi interaktif, dan sebagainya di platform seperti WeChat, Rednote, dan Douyin.

Berikut adalah referensi untuk Kimi Claw Android.

### Instalasi dan Konfigurasi

#### Apa yang harus saya lakukan jika instalasi OpenClaw gagal?

- Pastikan ruang penyimpanan mencukupi (minimal 5GB), dan jangan keluar dari aplikasi atau mengunci layar selama proses instalasi
- Klik "Instal Ulang" untuk mencoba lagi
- Jika gagal berkali-kali, klik "Ada masalah, buka umpan balik" untuk mengirimkan masalah

#### Setelah otorisasi izin, status tidak diperbarui?

- Pada beberapa merek ponsel, pemberian izin memerlukan restart aplikasi agar berlaku
- Kembali ke Kimi Claw Android. Jika status belum diperbarui, Anda dapat mencoba menutup dan membuka kembali App

#### Apakah pengguna gratis dapat menggunakannya?

- Saat ini, Anda perlu mengaktifkan hak keanggotaan Kimi Allegretto atau lebih tinggi untuk menggunakan Kimi Claw Android
- Klik "Buka Upgrade" pada langkah konfigurasi akun Kimi untuk membukanya

#### Saat memulihkan konfigurasi, muncul pesan "File konfigurasi tidak valid"?

- File cadangan mungkin rusak atau berasal dari versi yang tidak kompatibel
- Gunakan "Konfigurasi Sekali Klik Kimi App" untuk mengonfigurasi ulang

### Konektivitas dan Stabilitas

#### Mengapa status gateway selalu menampilkan "Memulai"?

- Periksa apakah koneksi jaringan normal
- Pastikan semua izin yang diperlukan (notifikasi, optimasi baterai, penyimpanan, mulai otomatis) telah diberikan
- Coba klik "Cadangkan dan Mulai Ulang" di pengaturan untuk memulai ulang layanan gateway

#### Apakah gateway tiba-tiba terputus?

- Periksa apakah ponsel masuk ke mode hemat daya sehingga aplikasi latar belakang dibersihkan
- Pastikan "Abaikan optimasi baterai" dan "Izin mulai otomatis" telah diberikan dengan benar
- Periksa status gateway di Dashboard. Jika menampilkan "Berhenti", klik Mulai Ulang

#### Apakah koneksi Kimi Claw Android terputus setelah ponsel dikunci?

- Ini biasanya terjadi karena strategi optimasi baterai ponsel menyebabkan aplikasi latar belakang dihentikan
- Pastikan pengaturan berikut telah diselesaikan:
  - Abaikan Optimasi Baterai - Diotorisasi
  - Izin mulai sendiri — Diaktifkan
  - Manajemen Konsumsi Daya — Pilih "Izinkan Sepenuhnya Perilaku Latar Belakang"

### Saluran dan Komunikasi

#### Apakah beberapa saluran chat dapat dihubungkan secara bersamaan?

- Ya. Anda dapat menghubungkan beberapa saluran seperti Kimi, Feishu, WeChat, dll. secara bersamaan
- Cukup klik "+ Hubungkan" di manajemen saluran Dashboard untuk menambahkannya
- Pertahankan setidaknya satu saluran untuk memastikan komunikasi normal

#### Setelah memindai kode QR Feishu, status terus menunggu pembaruan?

- Pastikan Anda telah menyelesaikan proses pembuatan aplikasi Feishu di browser
- Jika belum ada pembaruan dalam waktu lama, Anda dapat mencoba terhubung dengan memasukkan informasi Bot secara manual

#### Koneksi WeChat gagal?

- Pastikan kredensial WeChat Claw diisi dengan benar dan sesuai dengan nilai dari penyiapan sisi WeChat
- Ikuti panduan penyiapan resmi WeChat Claw untuk membuat ulang dan mengikat ulang kredensial jika diperlukan
- Periksa apakah jaringan seluler dapat mengakses layanan WeChat secara normal

#### Mengapa saya tidak dapat melihat Kimi Claw Android di Kimi App?

- Pastikan proses Onboarding telah sepenuhnya selesai (pemberian izin → instalasi OpenClaw → konfigurasi akun Kimi)
- Periksa apakah status gateway di Dashboard adalah "Terhubung"
- Coba segarkan daftar Bot di Kimi App

### Penggunaan Fungsi

#### Mengapa beberapa aplikasi tidak dapat dioperasikan dari jarak jauh?

- Demi keamanan, aplikasi keuangan seperti perbankan, pembayaran, sekuritas, dan asuransi telah otomatis diblokir aksesnya oleh sistem
- Untuk daftar lengkap, lihat Bab 6 "Daftar Aplikasi yang Dibatasi".

#### Mengapa perlu menggunakan ponsel yang tidak terpakai?

- Kimi Claw Android dapat menggunakan izin operasi ponsel saat berjalan, yang mungkin memengaruhi penggunaan normal Anda
- Menggunakan ponsel cadangan dapat menghindari konflik izin dan melindungi data pribadi Anda

#### Bagaimana cara menerapkan ulang setelah mengganti ponsel?

1. Ekspor file konfigurasi di Dashboard → Pengaturan → Cadangkan & Pulihkan pada ponsel lama
2. Instal Kimi Claw Android di ponsel baru
3. Pilih "Pulihkan Konfigurasi" pada Langkah 3 dan impor file cadangan sebelumnya.

#### Bagaimana cara melihat status berjalan Kimi Claw Android?

- Di antarmuka utama Dashboard, Anda dapat melihat status gateway dan waktu berjalan
- Klik "Log real-time" untuk melihat log operasi terperinci
- Melalui fungsi pencarian dan pemfilteran level pada log, masalah dapat ditemukan dengan cepat

### Upgrade dan Versi

#### Bagaimana cara meng-upgrade Kimi Claw Android?

- Periksa dan upgrade ke versi terbaru di Dashboard → Pengaturan → "Upgrade Versi"
- Disarankan melakukan upgrade dalam lingkungan Wi-Fi

#### Bisakah saya meng-upgrade versi OpenClaw secara manual?

- Upgrade manual tidak disarankan. Upgrade manual dapat menyebabkan masalah kompatibilitas
- Pihak resmi akan mendorong upgrade melalui notifikasi dalam aplikasi setelah penyesuaian selesai

## Umpan Balik dan Bantuan

Jika Anda mengalami masalah atau memiliki saran saat menggunakan:

### Umpan balik dalam aplikasi

- Dashboard → Pengaturan → Umpan Balik Pengguna
- Halaman Instalasi OpenClaw → "Jika Anda mengalami masalah, berikan umpan balik"

Berikan informasi berikut saat mengirim umpan balik:

- ID Kimi Claw Android Anda (terlihat saat mengklik saluran Kimi)
- Model Perangkat dan Versi Android
- Deskripsi masalah dan tangkapan layar

<Callout type="info">
Menyertakan ID Kimi Claw Android membantu teknisi menemukan masalah dengan cepat, jadi harap sertakan saat memberikan umpan balik.
</Callout>
