# Tidak merespons atau lambat?

<Callout type="info">
Jika Kimi Claw tidak membalas atau terasa sangat lambat, ada beberapa kemungkinan penyebabnya. Ikuti langkah pemecahan masalah di bawah ini.
</Callout>

## Penyebab umum

| Penyebab | Keterangan |
|-------|-------------|
| **Bridge terputus** | Koneksi antara Kimi Claw dan server terputus; gateway perlu dimulai ulang |
| **Resource sibuk** | Beban server tinggi; respons mungkin tertunda |
| **Instance offline** | Instance Kimi Claw telah offline dan perlu diperbaiki |

## Cara mengatasinya？

Ikuti langkah-langkah ini secara berurutan hingga masalah teratasi:

1. **Kirim pesan lagi** — Terkadang ini hanya jeda sesaat; pesan susulan dapat memicu respons
2. **Muat ulang halaman** — Tutup lalu buka kembali percakapan Kimi Claw
3. **Mulai ulang gateway** — Buka **Settings** lalu klik **Restart Kimi Claw**. Tunggu hingga kembali online
4. **Perbaikan otomatis** — Di Settings, klik **Repair Kimi Claw**. Sistem akan mendeteksi dan memperbaiki masalah konfigurasi secara otomatis
5. **Pulihkan pengaturan awal** — Jika semua cara gagal, pilih **Restore Initial Settings** di Settings

## Tentang memulihkan pengaturan awal

<Callout type="warning">
Ini akan mengembalikan Kimi Claw ke kondisi pabrik, tetapi:

- **Tetap dipertahankan:** Berkas workspace dan Memory jangka panjang
- **Perlu dikonfigurasi ulang:** Koneksi platform chat (Telegram, dll.) harus diatur kembali
</Callout>
