# Manfaat Kimi Code

Kimi Code adalah layanan yang termasuk dalam paket keanggotaan Kimi, menyediakan dukungan dan fitur terkait coding untuk membantu anggota menyelesaikan tugas pemrograman dengan lebih efisien dalam alur kerja pengembangan pribadi mereka.

> Perlu diperhatikan bahwa manfaat ini hanya ditujukan untuk penggunaan pengembangan pribadi, bukan untuk skenario pengembangan tingkat perusahaan. Untuk kebutuhan perusahaan, silakan kunjungi [Platform Terbuka Kimi](https://platform.kimi.ai/).

## Penagihan

- Penggunaan Kimi Code **sudah termasuk dalam biaya langganan Anda** — tanpa biaya tambahan.
- Kimi Code **menggunakan kredit yang sama dengan paket keanggotaan Kimi Anda** — permintaan dari CLI, VS Code, dan tool pihak ketiga semuanya dihitung dari kredit tersebut; setiap paket menyediakan jumlah kredit yang berbeda.
- Sistem memprioritaskan penggunaan kredit bonus sebelum kredit dari paket.

<Callout type="warning">
**Sistem keanggotaan baru akan segera hadir.** Manfaat keanggotaan Kimi dan manfaat Kimi Code akan dipisahkan, sehingga Anda dapat membelinya secara terpisah sesuai kebutuhan — lebih fleksibel. **Pelanggan saat ini tidak terpengaruh.** Jika ingin terus menggunakan manfaat gabungan, beli paket Anda saat ini sebelum sistem baru diluncurkan.
</Callout>

## Pembaruan kredit

Kredit diperbarui dalam siklus **7 hari**:

- Mulai dari tanggal langganan Anda (D1), kredit diperbarui setiap 7 hari.
- Periode pembaruan: D1–D7, D8–D14, D15–D21, D22–D28.
- Kredit yang tidak terpakai **tidak** dialihkan ke siklus berikutnya.

> Rencanakan penggunaan mingguan Anda untuk memanfaatkan kredit secara maksimal.

## Tool yang didukung

Manfaat Kimi Code tersedia dengan tool berikut:

| Tool | Deskripsi |
| --- | --- |
| **Kimi Code CLI** | Agen AI command-line resmi dari Kimi |
| **Claude Code** | Asisten coding command-line dari Anthropic |
| **Roo Code** | Ekstensi coding AI untuk VS Code |

Selain tool di atas, pelanggan juga dapat menggunakan API Key untuk menghubungkan Kimi Code ke lebih banyak tool pengembangan pihak ketiga (seperti OpenCode). Lihat [Menggunakan agen coding pihak ketiga](/kimi-code/third-party-agents) untuk detailnya. Saat menggunakan tool pihak ketiga, harap pertahankan identitas asli tool tersebut; memalsukan identifier klien (User-Agent) akan dianggap sebagai pelanggaran dan dapat menyebabkan benefit keanggotaan Anda ditangguhkan.

## Extra Usage

Ketika kredit langganan Anda habis, Anda dapat terus mengirim permintaan menggunakan saldo **Extra Usage** tanpa menunggu pembaruan. Hanya anggota berlangganan yang dapat mengaktifkannya, dan **Kimi di web dan Kimi Code berbagi saldo Extra Usage yang sama** (isi ulang sekali, gunakan di keduanya). Lihat ketentuan lengkap di [Perjanjian Extra Usage](https://www.kimi.com/user/agreement/extra-usage-rules-cn).

### Titik pengisian ulang

- **Dari situs utama**: buka [halaman Langganan](https://www.kimi.com/membership/subscription?tab=quota) Kimi, gulir ke modul «Extra Usage» di bagian bawah, pilih jumlah, dan selesaikan pembayaran.
- **Dari Kimi Code Console**: begitu penggunaan mingguan atau 5 jam Anda melebihi **80%**, kartu progres menampilkan tombol **Beli Extra Usage** yang membawa Anda ke halaman langganan.

### Mengaktifkan dan mengelola

Aktifkan sakelar «Extra Usage»; ketika kredit langganan habis, sistem otomatis memotong dari saldo Extra Usage Anda. Klik **Pengaturan** pada modul untuk mengaktifkan **batas pengeluaran bulanan** dan menetapkan jumlah maksimum yang dapat dibelanjakan bulan ini; bilah progres menampilkan konsumsi Extra Usage bulan ini secara real-time.

### Penagihan dan aturan

- **Penagihan**: berdasarkan penggunaan aktual — semakin banyak konten yang dibaca dan dihasilkan serta semakin kompleks tugasnya, semakin tinggi biayanya. Saldo ditampilkan dalam RMB, dengan tarif seperti yang ditampilkan di platform. Harga Extra Usage mendekati harga API resmi [Kimi Open Platform](https://platform.kimi.com); untuk penggunaan berat, meningkatkan langganan biasanya lebih hemat.
- **Prioritas pemotongan**: kredit berbatas waktu seperti langganan dipotong lebih dulu; **Extra Usage dipotong terakhir** sebagai cadangan. Setelah diaktifkan, meski kredit langganan habis, Extra Usage dikonsumsi tanpa hambatan dan tugas tidak berhenti atau error.
- **Batas pengeluaran**: aktifkan «batas pengeluaran bulanan» di pengaturan untuk membatasi berapa banyak Extra Usage yang dapat dibelanjakan bulan ini; tanpa itu, tidak ada batas.
- **Masa berlaku dan akumulasi**: saldo tidak kedaluwarsa dan terakumulasi antar pengisian ulang; tetap dapat digunakan setelah langganan berakhir, tetapi Anda tidak dapat mengisi ulang selama masa jeda — berlangganan kembali terlebih dahulu untuk mengisi ulang.
- **Pengembalian dana**: umumnya tidak dapat dikembalikan, dialihkan, atau diuangkan.

<Callout type="info">
Contoh penagihan (hanya untuk gambaran besaran; tarif sebenarnya sesuai platform): permintaan sederhana (mis. «rekomendasikan lagu rock») berbiaya sekitar **¥0,03**; tugas kompleks multi-langkah (mis. «rencanakan perjalanan darat seminggu dari Chengdu ke Sichuan barat») berbiaya sekitar **¥1,6**. Batas pengisian ulang: minimum ¥25 per pengisian, hingga 10 kali dan ¥3.000 per hari, dengan saldo maksimum ¥10.000.
</Callout>

### Memeriksa penggunaan Anda

- **Kimi web / app**: Pengaturan → Langganan & Faktur → [Kredit Saya](https://www.kimi.com/membership/subscription?tab=quota).
- **Kimi Code Console**: setelah Extra Usage aktif, masuk ke [Console](https://www.kimi.com/code/console) untuk melihat saldo dan penggunaan Anda.
- **Kimi Code CLI**: ketik `/usage` di baris perintah untuk memeriksanya langsung.

### FAQ Extra Usage

- **Apakah Kimi di web dan Kimi Code menggunakan dompet Extra Usage yang sama?** Ya — saldo dibagikan di antara keduanya; isi ulang sekali dan gunakan di mana saja.
- **Mana yang dipotong lebih dulu, Extra Usage atau kredit langganan?** Kredit berbatas waktu seperti langganan lebih dulu; Extra Usage hanya dipotong sebagai cadangan setelah semua kredit berbatas waktu habis.
- **Jika saya mencapai batas atau dibatasi, bisakah saya melanjutkan?** Ya. Setelah Extra Usage aktif, Anda tidak terpengaruh oleh batas langganan: saat batas apa pun tercapai, sistem beralih tanpa hambatan ke saldo Extra Usage, tugas tidak berhenti, dan hanya Extra Usage yang dipotong tanpa memengaruhi pembaruan kredit keanggotaan Anda.
- **Apakah saldo yang tidak terpakai dapat diteruskan dan diakumulasi?** Ya — tidak kedaluwarsa dan terakumulasi; tetap dapat digunakan setelah langganan berakhir, tetapi tidak dapat diisi ulang selama masa jeda.
- **Apakah Extra Usage tersedia untuk Enterprise?** Belum didukung.
