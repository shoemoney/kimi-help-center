# Kontak & Umpan Balik

## Saluran umpan balik

Jika mengalami kendala saat menggunakan Kimi Code atau memiliki saran, Anda dapat menyampaikan umpan balik melalui saluran berikut.

### Opsi 1: Kirim umpan balik langsung di CLI

Dalam mode interaktif Kimi Code CLI, masukkan perintah `/feedback` untuk mengirim umpan balik. Sistem akan otomatis mengumpulkan informasi tentang lingkungan Anda saat ini, sehingga Anda dapat menjelaskan masalah dengan lebih akurat.

### Opsi 2: GitHub Issues

Kunjungi [Kimi CLI GitHub Issues](https://github.com/MoonshotAI/kimi-cli/issues) dan lakukan pencarian untuk melihat apakah masalah serupa sudah ada. Jika belum, Anda dapat membuat Issue baru dan menjelaskan secara rinci apa yang Anda alami.

### Opsi 3: Umpan balik melalui email

Anda juga dapat mengirim email kepada tim Kimi Code di [code@moonshot.ai](mailto:code@moonshot.ai) untuk melaporkan masalah. Harap sertakan informasi berikut selengkap mungkin:

- **Deskripsi masalah**: Jelaskan dengan jelas masalah yang Anda alami atau fitur yang Anda inginkan
- **Langkah reproduksi**: Cara memicu masalah langkah demi langkah
- **Informasi lingkungan**: Sistem operasi dan versi Kimi Code CLI (jalankan `kimi --version` untuk memeriksa)
- **Log kesalahan**: Jika ada pesan kesalahan, tempelkan secara lengkap

## Pemecahan masalah sebelum mengirim umpan balik

Sebelum mengirim umpan balik, sebaiknya periksa hal-hal berikut:

- Apakah Anda sudah memperbarui ke versi terbaru Kimi Code CLI (jalankan `kimi --version` untuk memeriksa)
- Apakah koneksi jaringan Anda berfungsi dan apakah Anda dapat mengakses `api.kimi.com`
- Apakah API Key Anda valid dan belum kedaluwarsa
- Apakah direktori kerja sudah benar dan Kimi memiliki izin untuk mengakses file terkait
