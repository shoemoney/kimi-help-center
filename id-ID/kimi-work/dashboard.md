# Dashboard

Dashboard adalah wadah untuk widget. Dashboard menghadirkan widget yang paling Anda butuhkan dalam satu tampilan personal yang persisten, ditata berdasarkan topik, proyek, atau tujuan. Dashboard tidak terikat pada satu percakapan tertentu — Anda dapat membukanya kapan saja, dan mengelola widget-nya dari chat mana pun.

## Membuat dan Mengelola Dashboard

1. Klik "Dashboard" di sidebar kiri untuk membuka menu Dashboard;
2. Klik "Create" lalu isi nama (wajib) dan deskripsi (opsional);
3. Setiap pengguna dapat membuat hingga 2 dashboard.

Pada dashboard kosong, Anda dapat langsung mendeskripsikan widget yang diinginkan, dan Kimi akan membuatkannya ke dalam dashboard tersebut.

<Callout type="warning">
Menghapus dashboard juga menghapus semua widget di dalamnya beserta widget task terkait. Tindakan ini tidak dapat dibatalkan — lakukan dengan hati-hati.
</Callout>

## Tata Letak dan Anotasi

- Setiap dashboard dapat menampung hingga 20 widget. Seret untuk mengatur ulang posisinya dan ubah ukurannya sesuai keinginan.
- Klik "Refresh" untuk memperbarui konten widget di dashboard.
- Klik "Annotate" untuk masuk ke mode anotasi: pilih elemen apa pun dalam widget untuk membuat anotasi posisional dan mencatat masukan Anda. Anotasi dicantumkan berurutan berdasarkan waktu, maksimal 10 entri; klik anotasi tersimpan untuk mengeditnya kembali.

## Mengelola Widget di Dashboard

Arahkan kursor ke widget untuk:

- Klik "Expand" untuk melihat nama dan jenis widget;
- Untuk live widget, kelola widget task yang terikat padanya: lihat nama dan deskripsi tugas, aktifkan atau nonaktifkan, dan periksa 10 run terakhir (waktu dan status run);
- Klik "…" untuk memilih:
  - **Delete**: menghapus widget secara permanen dari chat asal dan semua dashboard — tidak dapat dibatalkan;
  - **Pin to Desktop**: menyematkan widget ke desktop komputer Anda sebagai jendela mandiri dengan ukuran yang dapat disesuaikan; jendela akan tertutup otomatis saat Anda keluar dari aplikasi.

## Membuka Dashboard dari Chat

Model dapat menampilkan kartu dashboard di dalam chat. Klik kartu tersebut untuk membuka halaman dashboard yang sesuai di panel sisi kanan, tanpa meninggalkan percakapan saat ini.
