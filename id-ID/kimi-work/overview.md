# Ikhtisar Kimi Work

Kimi Work adalah Agent lokal serbaguna untuk pekerja berbasis pengetahuan, tersedia dalam mode "Work" di klien desktop Kimi (Mac / Windows).

Kimi Work membawa kemampuan Agent yang telah teruji melalui Kimi Code dalam skenario engineering ke interaksi desktop yang akrab bagi pekerja berbasis pengetahuan sehari-hari: Anda tidak perlu membuka terminal, menulis perintah, atau mengatur environment. Cukup jelaskan tujuan Anda dalam bahasa alami, lalu Kimi Work akan menguraikan tugas, menjalankan langkah-langkah secara paralel, memanggil tools, menggunakan browser, membuat dan menata folder, serta menghasilkan keluaran kerja seperti dokumen, spreadsheet, dan slide deck — semuanya di komputer Anda sendiri.

Kimi Code melayani developer yang menulis kode; Kimi Work melayani pekerja berbasis pengetahuan, terutama untuk skenario harian seperti memindahkan informasi, menata file, menganalisis data, dan menyusun laporan.

## Kemampuan Utama

- **Kernel Agent lokal**: Ditenagai oleh Kimi Code sebagai kernelnya dan model Kimi K3, menghadirkan fondasi Agent lokal, termasuk memasang dan menggunakan Skills serta menjalankan tugas terjadwal.
- **Skills Profesional**: Mewarisi Skills profesional dari Kimi Agent online, seperti pembuatan situs web dan PPT, serta mendukung rekomendasi Skills pihak ketiga dan pengunggahan Skills lokal.
- **Plugin dan basis data profesional**: Gunakan aplikasi dan layanan eksternal di dalam Kimi, seperti Canva, Notion, dan WPS, serta hubungkan ke basis data profesional di bidang keuangan, riset, hukum, dan bidang lainnya.
- **Widget (Widgets)**: Halaman interaktif yang dihasilkan model di dalam chat, dapat terhubung ke data lokal atau plugin eksternal untuk pembaruan berkelanjutan, membuat jawaban lebih visual dan mudah dipahami. Lihat [Widget](/kimi-work/widgets).
- **Dasbor (Dashboard)**: Menghadirkan widget yang paling Anda butuhkan dalam satu tampilan personal yang persisten, ditata berdasarkan topik, proyek, atau tujuan, siap dilihat dan dikelola kapan saja. Lihat [Dasbor](/kimi-work/dashboard).
- **Kimi WebBridge**: Solusi operasi browser bawaan yang menggunakan browser layaknya manusia.
- **Agent Swarm**: Berdasarkan kompleksitas tugas, secara otonom menyusun tim hingga 300 sub-agent untuk menangani tugas yang lebih kompleks dan berjalan lebih lama.
- **Eksekusi tugas berdurasi panjang**: Ditenagai oleh eksekusi tugas berdurasi panjang dari model Kimi K3, mendukung puluhan jam kerja otonom dan ribuan pemanggilan tool otonom.

## Antarmuka dan Interaksi

- Klien memiliki dua mode, "Work" dan "Chat". Sidebar mode Work mencakup: Tugas Baru, Dasbor, Plugins, Skills, Tugas Terjadwal, WebBridge, Proyek, dan Chat.
- Ketik "/" di kotak input untuk menggunakan Skills dengan cepat, dan "@" untuk menambahkan konteks.
- Kontrol izin tersedia, dan Anda dapat memilih cara memberi otorisasi:
  - **Minta izin**: meminta otorisasi sebelum bertindak
  - **Izinkan semua**: berjalan langsung tanpa meminta otorisasi
- Beralih di antara dua mode eksekusi: "Agent" dan "Agent Swarm".

## Catatan Versi

Kimi Work diluncurkan pada 3 Juni 2026 dan saat ini berada dalam Beta dengan iterasi yang sering. Fitur-fitur seperti pratinjau file, penyimpanan draf otomatis, mode Goal, Pusat Plugin, widget, dan dasbor telah ditambahkan secara bertahap. Sejak versi 3.1.0, Kimi Work ditenagai oleh model Kimi K3. Fokus pengujian saat ini berada pada penguraian tugas, paralelisme multi-agent, pemanggilan tool, operasi browser, penanganan file lokal, dan pembuatan hasil akhir yang panjang; stabilitas eksekusi, kualitas hasil, dan pengalaman pengguna akan terus ditingkatkan berdasarkan masukan dari pengguna beta.
