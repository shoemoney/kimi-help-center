# Pusat Plugin

## Plugin Basis Data Profesional Bawaan

Kimi Work dilengkapi plugin basis data profesional bawaan untuk bidang keuangan, hukum, dan akademik, sehingga para profesional dapat mengakses sumber yang otoritatif dan tepercaya, mencakup data domestik maupun global:

- **Data keuangan**: Wind Financial Data Service, Hundsun Gildata financial data, S&P Global Market Intelligence, basis data keuangan global, basis data IMF (International Monetary Fund), Straight Flush (Tonghuashun), dan lainnya
- **Bisnis / hukum**: Tianyancha, Huayu Yuandian, dan lainnya

## Plugin Aplikasi Eksternal Terkurasi

Pusat Plugin menyediakan plugin opsional yang dikurasi secara resmi, antara lain:

- **Kolaborasi kantor**: Baidu Netdisk, DingTalk, Feishu, WPS
- **Desain**: Canva
- **Catatan**: Notion
- **Pengembangan web**: Cloudflare
- **Lainnya**: Kimi Computer Use (AI mengendalikan desktop untuk operasi tingkat sistem), GitHub, Neon (platform basis data PostgreSQL berbasis cloud), Supabase (platform backend dan basis data open-source), dan lainnya

Setelah plugin terinstal, Kimi Work dapat mengoperasikan alat kantor umum ini secara langsung, menggantikan tindakan berulang dengan satu instruksi bahasa alami.

## Cara Mengaktifkan

1. Buka klien desktop Kimi terbaru, beralih ke mode "Kerja" di bilah sisi kiri, lalu klik "Plugin" untuk masuk ke Pusat Plugin;
2. Temukan dan instal plugin yang Anda butuhkan di bagian "Terpasang" dan "Plugin unggulan";
3. Ketik garis miring "/" di kotak input, lalu pilih plugin yang ingin Anda panggil.
