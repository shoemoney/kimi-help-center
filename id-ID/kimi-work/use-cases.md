# Kasus Penggunaan

## Keuangan: Analisis Strategi Investasi

Minta Kimi Work meneliti kepemilikan Warren Buffett selama 10 tahun terakhir, merangkum strategi investasinya, lalu membuat "Skill Investasi Buffett". Setelah Skill terpasang, hubungkan ke sumber data keuangan profesional Kimi untuk menganalisis apakah kepemilikan dan strategi Anda sendiri sejalan dengan pendekatan investasi nilai ala Buffett.

**Alur kerja**: Riset ▶ Buat Skill ▶ Pasang Skill ▶ Gunakan Skill dan panggil sumber data keuangan profesional untuk analisis

## Riset: Pemrosesan Data dan Bantuan Penulisan Makalah

Minta Kimi Work bertindak sebagai peneliti komputasi perkotaan: membersihkan dataset simulasi di komputer lokal Anda, merangkum karakteristik dan pola utamanya, membuat grafik akademik, lalu membantu menyelesaikan makalah berdasarkan data yang sudah dibersihkan dan grafik tersebut.

**Alur kerja**: Pembersihan data lokal ▶ Pembuatan grafik ▶ Bantuan penulisan makalah

## Perkantoran: Riset Pasar dan Output Siap Serah

Minta Kimi Work membaca rencana produk, prototipe desain industri, dan rencana GTM di folder lokal, lalu menggunakan WebBridge untuk masuk ke situs web dasbor data berlangganan di browser guna melakukan riset. Kimi Work melakukan riset mendalam tentang pasar secara keseluruhan, hukum dan regulasi luar negeri, serta kondisi bisnis para pesaing, lalu — dengan memadukan dasbor proprietary — menganalisis 2.400+ ulasan pengguna untuk menghasilkan laporan analisis pasar e-commerce lintas batas setebal 128 halaman. Setelah itu, Kimi Work memanggil Skill PPT khusus untuk mengubah isi laporan dan prototipe desain lokal menjadi deck presentasi dengan sekali klik.

**Alur kerja**: Baca file lokal ▶ Lihat database berlangganan di browser lokal ▶ Buat laporan mendalam ▶ Panggil Skill PPT ▶ Hasilkan rencana untuk klien
