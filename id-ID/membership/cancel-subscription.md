# Batalkan langganan

Anda dapat membatalkan perpanjangan otomatis kapan saja. Setelah dibatalkan, manfaat keanggotaan Anda tetap aktif hingga akhir siklus penagihan saat ini.

## Bagaimana cara membatalkan perpanjangan otomatis?

Pilih metode yang sesuai dengan cara Anda berlangganan pada awalnya:

### Melalui situs web atau aplikasi Kimi

1. Masuk ke Kimi (web atau seluler).
2. Buka **Settings → Subscription**.
3. Klik **Cancel Auto-Renewal** atau **Manage Subscription**.
4. Konfirmasikan pembatalan.

### Melalui Apple ID (iOS / Mac)

1. Di iPhone Anda, buka **Settings** dan ketuk nama Anda di bagian atas.
2. Ketuk **Subscriptions**.
3. Temukan **Kimi** lalu ketuk **Cancel Subscription**.

Di Mac: Buka App Store → klik profil Anda → **Account Settings** → temukan Kimi di bawah **Subscriptions** → **Manage** → **Cancel Subscription**.

### Melalui Google Play (Android)

1. Buka aplikasi **Google Play Store**.
2. Ketuk ikon profil Anda → **Payments & subscriptions** → **Subscriptions**.
3. Temukan **Kimi** lalu ketuk **Cancel subscription**.
4. Ikuti petunjuk di layar untuk mengonfirmasi.

> Setelah dibatalkan, manfaat Anda tetap aktif sampai akhir periode berbayar. Anda dapat berlangganan kembali kapan saja melalui halaman Kimi Subscription.
