# Hubungi kami

Butuh bantuan? Berikut cara menghubungi kami.

## Dukungan penagihan & keanggotaan

**Email:** membership@moonshot.ai

Cocok untuk:

- Credit tidak muncul setelah pembelian
- Masalah pembayaran atau tagihan
- Peningkatan, penurunan, atau pembatalan paket
- Permintaan faktur

Anggota berbayar mendapatkan prioritas respons. Sertakan email akun Anda beserta tangkapan layar yang relevan agar kami dapat menyelesaikan masalah Anda lebih cepat.

## Dukungan umum

**Email:** support@moonshot.ai

Cocok untuk:

- Pertanyaan seputar fitur produk
- Masalah teknis saat menggunakan Kimi
- Pertanyaan terkait akun (selain penagihan)
- Permintaan fitur dan masukan

## Dukungan layanan API

**Email:** api-service@moonshot.ai.
Anda juga dapat mengunjungi [Kimi OpenPlatform Community](https://forum.moonshot.ai/)

Cocok untuk:

- Pertanyaan terkait API
- Masalah teknis saat menggunakan Kimi API
- Permintaan fitur dan masukan

## Masukan di dalam produk

Anda juga dapat mengirimkan masukan langsung di dalam Kimi:

- **Web:** Klik tombol **Feedback** di sudut kiri bawah, jelaskan masalah Anda, lalu kirim.
- **Seluler:** Buka **Profile → Help & Feedback → Submit Feedback**.

Laporan di dalam produk secara otomatis menyertakan konteks perangkat dan akun Anda, yang membantu kami mendiagnosis masalah lebih cepat.
