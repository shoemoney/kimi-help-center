# Ringkasan paket keanggotaan

Kimi menawarkan empat tingkat keanggotaan — dirancang untuk mengikuti kebutuhan Anda, mulai dari produktivitas harian hingga alur kerja pengguna tingkat lanjut.

Semua fitur keanggotaan Kimi menggunakan satu kumpulan credit yang sama. Deployment situs web, Deep Research, Slides, Kimi Code, Kimi Work, Kimi Claw, dan fitur keanggotaan lainnya semuanya memakai credit keanggotaan, termasuk percakapan K2.6 di Chat.

## Cara kerja penagihan

- **Kumpulan credit** — Semua fitur keanggotaan (deployment situs web, Deep Research, Slides, Kimi Code, Kimi Work, Kimi Claw, K3, dan K3 Swarm) berbagi satu kumpulan credit yang sama, dihitung berdasarkan penggunaan token. Menghabiskan credit pada salah satu fitur akan memengaruhi fitur lainnya.
- **rate limit Kimi Code** — Kimi Code juga memiliki rate limit 5 jam / mingguan yang hanya berlaku untuk Kimi Code dan tidak memengaruhi fitur keanggotaan lainnya.
- **Pembaruan bulanan** — Credit direset pada awal setiap siklus penagihan.
