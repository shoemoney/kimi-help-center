## Alokasi credit

Semua fitur keanggotaan Kimi berbagi satu pool credit, yang dihitung berdasarkan penggunaan token. Kimi Code juga memiliki rate limit tersendiri 5 jam / mingguan yang hanya berlaku untuk Kimi Code dan tidak memengaruhi fitur lain. Di Chat, K2.6 gratis dan tidak mengonsumsi credit. Tingkat yang lebih tinggi menyertakan pool credit yang lebih besar secara proporsional, sehingga mendukung workflow yang lebih sering dan kompleks. Lihat [Pembaruan Credit & Aturan Penggunaan](/membership/update-rules) untuk detailnya.

## FAQ Credit

### Bagaimana cara memeriksa penggunaan credit saya?

- **Web**: Klik avatar Anda di pojok kiri bawah → Pengaturan → Langganan
- **App**: Saya → Paket Keanggotaan → Langganan

Anda dapat melihat saldo credit Anda saat ini dalam persentase, waktu pembaruan berikutnya, dan hingga 1.000 riwayat penggunaan terbaru, termasuk waktu penggunaan, fitur, dan persentase konsumsi.

<Callout type="tip">
Detail penggunaan mungkin mengalami sedikit keterlambatan. Silakan merujuk pada tampilan credit saat ini.
</Callout>

### Bagaimana jika credit saya habis?

Tugas yang sedang berjalan dapat diselesaikan seperti biasa. Tugas baru akan menampilkan pemberitahuan credit tidak mencukupi. Anda dapat:

- Menunggu credit diperbarui secara otomatis setiap bulan (batas penggunaan 5 jam/mingguan milik Kimi Code juga diperbarui sendiri dan hanya memengaruhi Kimi Code)
- Upgrade ke paket keanggotaan yang lebih tinggi untuk mendapatkan lebih banyak credit
- Membeli [paket Extra Usage](/membership/membership-extra-usage): setelah diaktifkan, Anda membayar sesuai pemakaian dan tidak perlu menunggu credit diperbarui
- Mengikuti kampanye resmi untuk mendapatkan credit bonus

### Bisakah saya menggunakan seluruh credit saya untuk satu fitur saja?

Bisa. Semua fitur keanggotaan berbagi satu pool credit yang sama, dan Anda dapat mengalokasikannya sesuai keinginan. Perlu diingat, jika satu fitur menghabiskan seluruh credit, fitur lainnya juga akan terpengaruh. Kimi Code juga memiliki rate limit tersendiri 5 jam/mingguan yang hanya berlaku untuk Kimi Code.

### Apa itu biaya 「Claw-云主机」 sebesar 0.6% yang dipotong setiap hari pukul 16.00?

Ini adalah biaya operasional sandbox dari cloud host Kimi Claw Anda. Kimi Claw adalah deployment OpenClaw di cloud: setiap kali Anda memanggil Claw, sistem menjalankan sandbox cloud yang terisolasi untuk mengeksekusi kode, mengoperasikan browser, atau memanggil tool. Sandbox bukanlah “standby gratis”—sandbox ditagih secara terus-menerus berdasarkan runtime dan konsumsi resource. Bahkan ketika Anda tidak sedang aktif menjalankan tugas, cloud host yang telah di-deploy tetap mempertahankan runtime environment dan datanya, sehingga sekitar 0.6% dari credit keanggotaan Anda dipotong setiap hari, yang diselesaikan pada pukul 16.00.

Jika Anda tidak berencana menggunakan Kimi Claw untuk sementara waktu, simpan terlebih dahulu file penting seperti memory, soul, dan file workspace secara lokal, lalu hapus cloud host; tidak ada biaya lagi setelah penghapusan, dan Anda dapat men-deploy ulang kapan saja.

### Apa itu biaya “Agent Website - Cloud Service” sebesar 0.08%?

Ini adalah biaya layanan cloud untuk website yang Anda publikasikan dengan Agent. Website yang dipublikasikan terus menggunakan resource cloud agar tetap online dan dapat diakses, sehingga sekitar 0.08% dari credit keanggotaan Anda dipotong. Jika Anda tidak lagi memerlukan website tersebut online, klik “Unpublish” untuk menghentikan biayanya.
