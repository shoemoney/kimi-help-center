# Penjelasan penggunaan dan pembagian data

## Apakah data percakapan digunakan untuk pelatihan model?

Dengan prasyarat bahwa data diproses menggunakan teknologi enkripsi yang aman, dide-identifikasi secara ketat, dan tidak dapat diidentifikasi ulang sebagai individu tertentu, platform dapat menggunakan data input, instruksi, dan respons yang dihasilkan pengguna untuk pelatihan model guna mengoptimalkan kinerja model dan pengalaman produk.

## Bagaimana cara menolak pelatihan model?

Jika Anda tidak ingin data percakapan Anda digunakan untuk pelatihan, Anda dapat menghubungi layanan pelanggan melalui [membership@moonshot.ai](mailto:membership@moonshot.ai) dan mengajukan permintaan; kami akan menyelesaikan pendaftaran penolakan dalam waktu 30 hari kalender setelah memverifikasi identitas Anda, dan berhenti menggunakan konten Anda untuk pelatihan model.

## Apa dampaknya setelah menolak pelatihan model?

- **Penolakan seragam di tingkat akun**: saat ini belum tersedia opsi untuk menolak per percakapan atau per file.
- **Tidak memengaruhi penggunaan**: menolak pelatihan tidak memengaruhi Anda untuk terus menggunakan berbagai layanan Kimi; akun, benefit keanggotaan, dan riwayat percakapan Anda tetap tidak berubah.
- **Ruang lingkup pemberlakuan**: setelah pendaftaran selesai, data percakapan historis Anda maupun data baru berikutnya tidak akan lagi dimasukkan ke dalam dataset pelatihan model.

## Apakah data akan dibagikan kepada pihak ketiga?

Tanpa persetujuan Anda, kecuali diwajibkan oleh hukum atau diperlukan untuk mewujudkan fungsi produk, kami tidak akan membagikan, menjual, atau memberikan data percakapan pribadi Anda kepada pihak ketiga mana pun (termasuk perusahaan afiliasi, mitra, pengiklan, dll.), maupun menggunakannya untuk tujuan yang tidak terkait dengan penyediaan layanan. Ketentuan selengkapnya dapat dilihat pada Pasal 4.2 [Kebijakan Privasi Kimi](https://www.kimi.com/user/agreement/userPrivacy?version=v2).

## Di mana data saya disimpan? Apakah aman?

Data Anda disimpan di lingkungan server yang berlokasi di Tiongkok daratan dan memenuhi standar keamanan. Kami menerapkan langkah teknis dan manajerial seperti enkripsi data serta kontrol akses untuk mencegah akses, kebocoran, atau kehilangan yang tidak sah.

## Apakah data pengguna enterprise digunakan untuk pelatihan model?

Salah satu komitmen inti Kimi Business (versi enterprise) adalah bahwa data enterprise tidak masuk ke dalam proses pelatihan model, serta ruang pribadi dan ruang enterprise sepenuhnya terpisah. Jika Anda memerlukan kontrak enterprise atau demo produk, silakan hubungi tim penjualan enterprise: [sales@kimi.ai](mailto:sales@kimi.ai).
