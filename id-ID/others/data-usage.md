# Apakah data percakapan saya akan digunakan untuk pelatihan model?

Dengan prasyarat bahwa data diproses menggunakan teknologi enkripsi yang aman, dide-identifikasi secara ketat, dan tidak dapat diidentifikasi ulang sebagai individu tertentu, platform dapat menggunakan data input, instruksi, dan respons yang dihasilkan pengguna untuk pelatihan model guna mengoptimalkan kinerja model dan pengalaman produk.

Jika Anda tidak ingin data percakapan Anda digunakan untuk pelatihan, Anda dapat menghubungi layanan pelanggan melalui [support@moonshot.ai](mailto:support@moonshot.ai) dan mengajukan permintaan; setelah kami memverifikasi identitas Anda, kami akan berhenti menggunakan konten Anda untuk pelatihan model.
