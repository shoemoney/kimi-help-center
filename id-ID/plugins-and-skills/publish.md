# Cara Mempublikasikan Plugin ke Marketplace Resmi

Jika Anda ingin mengirimkan plugin pribadi yang telah Anda buat dan uji secara dasar ke marketplace plugin resmi Kimi, buka halaman detail plugin, klik tombol “✉️” di pojok kanan atas, pilih “Apply for official marketplace publication” di formulir masukan, dan cantumkan alamat email Anda.

Setelah terkirim, pengajuan akan diteruskan ke tim peninjau Kimi. Kami akan mengevaluasi plugin berdasarkan konten dan hasil pengujiannya, serta menghubungi Anda melalui alamat email yang diberikan jika diperlukan materi tambahan atau diskusi lebih lanjut.
