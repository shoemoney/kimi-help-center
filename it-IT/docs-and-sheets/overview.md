# Kimi Docs e Kimi Sheets

<Callout type="info">
Il 27 gennaio 2026, Moonshot AI ha rilasciato Kimi K2.5, introducendo importanti aggiornamenti alle capacità di produttività di Kimi Agent. Kimi Agent ora "padroneggia Office" con la generazione end-to-end di file Word, PDF, Excel e Slides.
</Callout>

Kimi K2.5 offre una qualità di output e un'efficienza nelle chiamate degli strumenti notevolmente migliorate negli scenari d'ufficio, in particolare nell'output strutturato grazie a capacità di elaborazione end-to-end:
| Formato | Capacità |
|--------|-------------|
| **Word** | Formattazione intelligente e tracciamento delle revisioni |
| **PDF** | Design visivo e impaginazioni con testo e immagini |
| **Excel** | Analisi dei dati e modellazione finanziaria |
| **Slides** | Generazione automatica e narrazione visiva |

## Kimi Docs
Kimi Docs offre solide capacità di adattamento del testo e una comprensione sistematica dei flussi di lavoro di Office.
### Capacità principali
**Documenti Word:**
- Genera documenti professionali di lunga estensione: white paper, report di ricerca, contratti, proposte
- Inserisce commenti e suggerimenti di revisione nei documenti Word esistenti
- Gestisce gerarchie di titoli, spaziatura dei paragrafi, citazioni e formattazione degli elenchi
- Sintetizza una tesi di 30.000 parole in un riassunto preciso
**Documenti PDF:**
- Genera report PDF professionali e ricchi di illustrazioni, con copertina, indice, corpo del testo e didascalie
- Rielabora e riformatta i PDF esistenti senza software di impaginazione professionale
- Estrae informazioni specifiche da PDF di centinaia di pagine
- Confronta differenze sottili tra più versioni di un contratto
### Come usare Kimi Docs?
**Punti di accesso:**
- Generale: clicca sulle scorciatoie Docs, Sheets o Slides nella barra laterale o nella casella di chat
- Dedicato: clicca sul pulsante "Docs" in fondo alla casella di chat
### Metodo 1: visita la pagina di Kimi Docs

  src="./images/overview/screenshot-1.png"

1. **Apri il browser**: Chrome, Safari, Edge, Firefox o qualsiasi altro browser principale
2. **Vai a**: [kimi.com/docs](https://www.kimi.com/docs)
3. **Accedi**: effettua l'accesso con il tuo account Kimi (Google o email)
4. **Inserisci un'attività**:
   - **Inserimento testo**: digita un'attività in linguaggio naturale
   - **Carica un documento** da modificare
   - **Sfoglia gli esempi**: clicca su "Creane uno così", personalizza e poi invia
5. **Inizia a creare**: scegli un modello o crea tramite conversazione

<Callout type="tip">
Descrivi direttamente le tue esigenze, ad esempio: "Creami un report XX". Oppure carica un file Word/PDF/Excel esistente e specifica le operazioni. Scarica il file nel formato originale (.docx / .xlsx / .pdf) per continuare a modificarlo in locale.
</Callout>

### Metodo 2: app per dispositivi mobili
L'app Kimi è disponibile su iOS e Android. Tocca la Taskbar → passa alla modalità Docs Agent.
#### Metodo 3: modalità Agent generale
Passa alla modalità K2.6 Agent e inserisci un'attività relativa a un documento. Kimi richiamerà gli strumenti di lettura e scrittura.
## Kimi Sheets
Kimi Sheets comprende le relazioni tra le celle e la logica di collegamento tra fogli, generando file .xlsx direttamente nel browser.
### Capacità principali
| Capacità | Descrizione |
|------------|-------------|
| **Inserimento dati in blocco** | Estrae dati dai documenti — ad esempio, recupera le informazioni sugli espositori da un PDF e le trasferisce in un file Excel di 1.000 righe |
| **Consolidamento da più fonti** | Unisce 50 report Excel di reparti diversi in un'unica sintesi aziendale |
| **Inserimento in linguaggio naturale** | Ricerca web autonoma con generazione intelligente di fogli di calcolo |

### Come usare Kimi Sheets?
Clicca sul pulsante "Agent" in fondo alla casella di chat oppure seleziona la scorciatoia "Sheets" nella barra laterale.

<Frames
  src="./images/overview/screenshot-4.png"
  alt="screenshot 4"
/>

Puoi dire: *"Cerca sul web e raccogli in un documento Excel le pubblicazioni più recenti nel campo XX"*, oppure caricare un file Excel/CSV esistente e specificare le operazioni. Visualizza l'anteprima online, poi scarica il file .xlsx.
