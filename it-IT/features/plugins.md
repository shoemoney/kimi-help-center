# Plugin

I plugin collegano strumenti esterni a Kimi, così può usare app e servizi per completare le attività. Dopo aver installato un plugin, Kimi può richiamare direttamente la funzionalità di terze parti corrispondente mentre svolge un'attività — ad esempio consultare dati finanziari, operare su software per ufficio o usare strumenti di design. Puoi chiedere esplicitamente di usare un plugin specifico; quando è opportuno, Kimi può anche richiamarlo automaticamente.

## Dove puoi usare i plugin

Puoi usare i plugin quando passi al modello **K3** o **K3 Swarm**, e negli scenari **Deep Research, Websites e PPT**.

Puoi usare i plugin anche nell'app desktop **Kimi Work**; per l'elenco dei plugin integrati su desktop, consulta il [Centro plugin di Kimi Work](/kimi-work/plugin-center).

<Callout type="info">
I plugin non sono ancora supportati nelle conversazioni Kimi Claw o Kimi Plus.
</Callout>

## Installare i plugin

- **Punti di accesso**: sul web, la scheda **Plugin** nella barra laterale, il pulsante **+** nella casella di input oppure digita "/"; su mobile, il pulsante **+** nella casella di input oppure "/".
- Cerca o sfoglia il marketplace dei plugin, apri i dettagli di un plugin e fai clic su Installa.
- Alcuni plugin richiedono **autorizzazione OAuth** (verrai indirizzato all'accesso di terze parti; una volta autorizzato, potrai usarli); altri plugin sono **preinstallati** e non richiedono installazione manuale.
- **Plugin solo per aziende**: gli utenti non aziendali possono vederli, ma il pulsante "Installa" è disattivato.
- Non puoi installare o usare plugin se non hai effettuato l'accesso.

## Usare i plugin

- Dopo l'installazione, digita "/" nella casella di input oppure fai clic su **+** → Plugin, quindi seleziona il plugin per invocarlo; puoi **invocare più plugin contemporaneamente**.
- Puoi anche semplicemente descrivere ciò di cui hai bisogno (ad esempio, "cerca questa azienda su Tianyancha") e Kimi sceglierà automaticamente il plugin più adatto.
- Quando Kimi richiama gli strumenti di un plugin, nella risposta mostra "Sto usando il plugin xx".

## Categorie ed elenco dei plugin

Il marketplace dei plugin è organizzato nelle categorie seguenti. I plugin effettivamente visibili variano in base a **regione (mercato nazionale / estero)** e **superficie**, e alcuni plugin compaiono in più di una categoria.

- **Finanza**: Analisi degli investimenti finanziari, Investment Banking e Private Equity, Finanza aziendale e contabilità, Wind Financial Data, S&P Global Market Intelligence, Hundsun Gildata, Tonghuashun iFinD, SEC, Database finanziario globale, World Bank Open Data, Database IMF (Fondo Monetario Internazionale), Stripe, Tianyancha
- **Produttività**: Notion, Baidu Netdisk
- **Sviluppo**: GitHub, Supabase, Neon, Cloudflare
- **Creatività**: Bacino di ispirazione, Generazione di immagini, Generazione di video, Generazione audio, Canva
- **Generale**: Vivify

## Credit

Alcuni plugin richiamano strumenti o servizi per completare un'attività e **consumano i credit del tuo abbonamento in base all'uso effettivo**; i plugin senza costi di chiamata non comportano addebiti extra.

## Dati e autorizzazioni

- Quando selezioni un plugin o chiedi esplicitamente di usarlo, Kimi dà priorità agli strumenti forniti da quel plugin e genera la risposta in base ai risultati restituiti da tali strumenti; dopo aver collegato un plugin, Kimi accede ai contenuti pertinenti entro l'ambito che hai autorizzato.
- Se un plugin è fornito da terze parti, le regole di trattamento dei dati sono stabilite autonomamente da quella società e i dati sono soggetti ai suoi termini di servizio e alla sua privacy policy: ti consigliamo di consultarli prima di concedere l'autorizzazione.
- Puoi **disinstallare un plugin o revocare l'autorizzazione in qualsiasi momento**. Dopo la disinstallazione, la relativa autorizzazione OAuth viene revocata; per usare di nuovo il plugin, dovrai reinstallarlo e autorizzarlo di nuovo.

## FAQ

### I plugin consumano i credit del mio abbonamento?
Alcuni sì. Quando Kimi richiama gli strumenti o i servizi di un plugin per completare un'attività, i credit vengono consumati in base all'uso effettivo; i plugin senza costi di chiamata non comportano addebiti extra.

### Posso usare più plugin contemporaneamente?
Sì. Puoi invocare più plugin contemporaneamente tramite "/" o **+**.

### Perché non vedo un determinato plugin?
I plugin disponibili variano in base a regione (mercato nazionale / estero) e superficie; inoltre, alcuni plugin sono disponibili solo per utenti aziendali.
