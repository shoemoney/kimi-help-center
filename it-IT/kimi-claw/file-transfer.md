# Trasferimento di file

Kimi Claw consente di inviare e ricevere file.

## Inviare file a Kimi Claw

Puoi inviare immagini, documenti e altri file a Kimi Claw tramite Kimi, che utilizzerà i suoi strumenti integrati per visualizzarli ed elaborarli.

## Ricevere file da Kimi Claw

L'ultima versione di Kimi consente a Kimi Claw di rinviarti i file. Se la consegna dei file non funziona, assicurati di utilizzare la versione più recente del plugin Kimi.

## Gestire i file nello spazio di lavoro

Puoi anche sfogliare e scaricare i file generati da Kimi Claw tramite lo **Spazio di lavoro** sul web. Lo Spazio di lavoro conserva tutti i file prodotti durante il funzionamento di Kimi Claw, sempre a tua disposizione.
