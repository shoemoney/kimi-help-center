# Vantaggi di Kimi Code

Kimi Code è un servizio incluso nel piano di abbonamento Kimi, che offre supporto e funzionalità per la programmazione, aiutando gli iscritti a completare più efficacemente le attività di sviluppo nel proprio flusso di lavoro personale.

> Ricorda che questo vantaggio è pensato esclusivamente per lo sviluppo personale, non per scenari di sviluppo aziendale. Per esigenze aziendali, visita la [Piattaforma aperta di Kimi](https://platform.kimi.ai/).

## Fatturazione

- L'utilizzo di Kimi Code è **incluso nel costo dell'abbonamento**: non vengono applicati costi aggiuntivi.
- Kimi Code **usa gli stessi crediti del tuo piano di abbonamento Kimi**: le richieste dalla CLI, da VS Code e dagli strumenti di terze parti vengono tutte conteggiate su di essi; piani diversi includono quantità di crediti differenti.
- Il sistema dà priorità al consumo dei crediti bonus prima di quelli del piano.

<Callout type="warning">
**È in arrivo un nuovo sistema di abbonamento.** I vantaggi dell'abbonamento Kimi e i vantaggi di Kimi Code verranno separati, così potrai acquistarli separatamente in base alle tue esigenze — più flessibile. **Gli abbonati attuali non sono interessati.** Se desideri continuare a usare i vantaggi combinati, acquista il tuo piano attuale prima del lancio del nuovo sistema.
</Callout>

## Rinnovo dei crediti

I crediti si rinnovano con un ciclo di **7 giorni**:

- A partire dalla data di abbonamento (D1), i crediti si rinnovano ogni 7 giorni.
- Periodi di rinnovo: D1–D7, D8–D14, D15–D21, D22–D28.
- I crediti non utilizzati **non** vengono riportati al ciclo successivo.

> Pianifica il tuo utilizzo settimanale per sfruttare al meglio i crediti.

## Strumenti supportati

I vantaggi di Kimi Code sono disponibili con i seguenti strumenti:

| Strumento | Descrizione |
| --- | --- |
| **Kimi Code CLI** | L'agente AI ufficiale Kimi da riga di comando |
| **Claude Code** | L'assistente di programmazione da riga di comando di Anthropic |
| **Roo Code** | Estensione di programmazione AI per VS Code |

Utilizzare la tua API Key di Kimi Code con piattaforme o strumenti non elencati qui sopra può essere considerato un uso improprio e comportare la limitazione dell'accesso. Per la migliore esperienza e copertura, utilizza gli strumenti supportati indicati sopra.

## Extra Usage

Quando i crediti del tuo abbonamento si esauriscono, puoi continuare a inviare richieste usando il tuo saldo **Extra Usage**, senza attendere il rinnovo. Solo gli abbonati possono attivarlo, e **Kimi sul web e Kimi Code condividono lo stesso saldo Extra Usage** (ricarica una volta, usalo in entrambi). Consulta i termini completi nell'[Accordo Extra Usage](https://www.kimi.com/user/agreement/extra-usage-rules-cn).

### Punti di ricarica

- **Dal sito principale**: apri la [pagina Abbonamento](https://www.kimi.com/membership/subscription?tab=quota) di Kimi, scorri fino al modulo «Extra Usage» in fondo, scegli un importo e completa il pagamento.
- **Dalla Kimi Code Console**: quando l'utilizzo settimanale o su 5 ore supera l'**80%**, la scheda di avanzamento mostra un pulsante **Acquista Extra Usage** che porta alla pagina di abbonamento.

### Attivazione e gestione

Attiva l'interruttore «Extra Usage»; quando i crediti dell'abbonamento si esauriscono, il sistema preleva automaticamente dal saldo Extra Usage. Fai clic su **Impostazioni** nel modulo per attivare un **limite di spesa mensile** e impostare l'importo massimo per il mese; la barra di avanzamento mostra in tempo reale il consumo di Extra Usage del mese.

### Fatturazione e regole

- **Fatturazione**: in base all'uso effettivo — più contenuti vengono letti e generati e più complessa è l'attività, maggiore è il costo. Il saldo è mostrato in RMB, con le tariffe indicate sulla piattaforma. I prezzi di Extra Usage sono vicini a quelli ufficiali dell'API della [Kimi Open Platform](https://platform.kimi.com); con un uso intenso, l'upgrade dell'abbonamento è di solito più conveniente.
- **Ordine di addebito**: vengono prelevati prima i crediti a tempo come l'abbonamento; **Extra Usage viene prelevato per ultimo** come riserva. Una volta attivato, anche con i crediti dell'abbonamento esauriti, Extra Usage viene consumato senza interruzioni e le attività non si fermano né vanno in errore.
- **Limite di spesa**: attiva un «limite di spesa mensile» nelle impostazioni per limitare quanto Extra Usage può essere speso questo mese; senza di esso, non c'è limite.
- **Validità e cumulo**: il saldo non scade e si cumula tra le ricariche; resta utilizzabile dopo la scadenza dell'abbonamento, ma non puoi ricaricare durante l'interruzione — riabbonati prima per ricaricare di nuovo.
- **Rimborsi**: in genere non rimborsabile, non trasferibile e non convertibile.

<Callout type="info">
Esempio di fatturazione (ordine di grandezza indicativo; tariffe reali secondo la piattaforma): una richiesta semplice (ad es. «consiglia una canzone rock») costa circa **¥0,03**; un'attività complessa in più passaggi (ad es. «pianifica un viaggio in auto di una settimana da Chengdu al Sichuan occidentale») costa circa **¥1,6**. Limiti di ricarica: minimo ¥25 per ricarica, fino a 10 volte e ¥3.000 al giorno, con un saldo massimo di ¥10.000.
</Callout>

### Verificare il consumo

- **Kimi web / app**: Impostazioni → Abbonamento e fatture → [I miei crediti](https://www.kimi.com/membership/subscription?tab=quota).
- **Kimi Code Console**: una volta attivato Extra Usage, accedi alla [Console](https://www.kimi.com/code/console) per vedere saldo e consumo.
- **Kimi Code CLI**: digita `/usage` nella riga di comando per verificarlo direttamente.

### FAQ su Extra Usage

- **Kimi sul web e Kimi Code usano lo stesso portafoglio Extra Usage?** Sì: il saldo è condiviso tra entrambi; ricarica una volta e usalo in entrambi.
- **Cosa viene addebitato per primo, Extra Usage o i crediti dell'abbonamento?** Prima i crediti a tempo come l'abbonamento; Extra Usage viene addebitato come riserva solo una volta esauriti tutti i crediti a tempo.
- **Se raggiungo un limite o vengo limitato, posso continuare?** Sì. Una volta attivato Extra Usage non sei più soggetto ai limiti dell'abbonamento: al raggiungimento di qualsiasi limite si passa senza interruzioni al saldo Extra Usage, le attività non si fermano e viene addebitato solo Extra Usage, senza incidere sul rinnovo dei crediti di abbonamento.
- **Il saldo non utilizzato si riporta e si cumula?** Sì: non scade e si cumula; resta utilizzabile dopo la scadenza dell'abbonamento, ma non è possibile ricaricare durante l'interruzione.
- **Extra Usage è disponibile per Enterprise?** Non ancora supportato.
- **Il saldo viene rimborsato dopo la chiusura dell'account?** Scrivi a [membership@moonshot.ai](mailto:membership@moonshot.ai) per richiedere un rimborso.
