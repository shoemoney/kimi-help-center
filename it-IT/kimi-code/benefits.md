# Vantaggi di Kimi Code

Kimi Code è un servizio incluso nel piano di abbonamento Kimi, che offre supporto e funzionalità per la programmazione, aiutando gli iscritti a completare più efficacemente le attività di sviluppo nel proprio flusso di lavoro personale.

> Ricorda che questo vantaggio è pensato esclusivamente per lo sviluppo personale, non per scenari di sviluppo aziendale. Per esigenze aziendali, visita la [Piattaforma aperta di Kimi](https://platform.kimi.ai/).

## Fatturazione

- L'utilizzo di Kimi Code è **incluso nel costo dell'abbonamento**: non vengono applicati costi aggiuntivi.
- Ogni richiesta consuma crediti dal tuo **pool di crediti esclusivo di Kimi Code**; piani diversi includono quantità di crediti differenti.
- Il sistema dà priorità al consumo dei crediti bonus prima di quelli del piano.

## Rinnovo dei crediti

I crediti si rinnovano con un ciclo di **7 giorni**:

- A partire dalla data di abbonamento (D1), i crediti si rinnovano ogni 7 giorni.
- Periodi di rinnovo: D1–D7, D8–D14, D15–D21, D22–D28.
- I crediti non utilizzati **non** vengono riportati al ciclo successivo.

> Pianifica il tuo utilizzo settimanale per sfruttare al meglio i crediti.

## Strumenti supportati

I vantaggi di Kimi Code sono disponibili con i seguenti strumenti:

| Strumento | Descrizione |
| --- | --- |
| **Kimi Code CLI** | L'agente AI ufficiale Kimi da riga di comando |
| **Claude Code** | L'assistente di programmazione da riga di comando di Anthropic |
| **Roo Code** | Estensione di programmazione AI per VS Code |

Utilizzare la tua API Key di Kimi Code con piattaforme o strumenti non elencati qui sopra può essere considerato un uso improprio e comportare la limitazione dell'accesso. Per la migliore esperienza e copertura, utilizza gli strumenti supportati indicati sopra.
