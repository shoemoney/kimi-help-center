# Contatti e feedback

## Canali per il feedback

Se riscontri problemi durante l’uso di Kimi Code o hai suggerimenti, puoi inviarci il tuo feedback tramite i canali indicati di seguito.

### Opzione 1: inviare feedback direttamente dalla CLI

Nella modalità interattiva della CLI di Kimi Code, inserisci il comando `/feedback` per inviare un feedback. Il sistema raccoglierà automaticamente le informazioni sull’ambiente corrente, così potrai descrivere il problema con maggiore precisione.

### Opzione 2: GitHub Issues

Visita [Kimi CLI GitHub Issues](https://github.com/MoonshotAI/kimi-cli/issues) e cerca se esiste già un problema simile. In caso contrario, puoi creare una nuova issue e descrivere nel dettaglio ciò che hai riscontrato.

### Opzione 3: feedback via email

Puoi anche scrivere al team di Kimi Code all’indirizzo [code@moonshot.ai](mailto:code@moonshot.ai) per segnalare problemi. Includi, se possibile, le seguenti informazioni:

- **Descrizione del problema**: descrivi chiaramente il problema riscontrato o la funzionalità che vorresti
- **Passaggi per riprodurlo**: indica passo dopo passo come generare il problema
- **Informazioni sull’ambiente**: sistema operativo e versione della CLI di Kimi Code (esegui `kimi --version` per verificarla)
- **Log di errore**: se compare un messaggio di errore, incollalo integralmente

## Controlli preliminari prima di inviare feedback

Prima di inviare un feedback, ti consigliamo di verificare quanto segue:

- Di aver aggiornato Kimi Code CLI all’ultima versione (esegui `kimi --version` per verificarla)
- Che la connessione di rete funzioni e che tu possa accedere a `api.kimi.com`
- Che la tua API Key sia valida e non sia scaduta
- Che la directory di lavoro sia corretta e che Kimi disponga dei permessi per accedere ai file pertinenti

## Altri canali di contatto

| Tipo di feedback | Canale |
|---------|------|
