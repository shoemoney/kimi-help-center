# Centro plugin

## Plugin integrati per database professionali

Kimi Work include plugin integrati per database professionali in ambito finanziario, legale e accademico, offrendo ai professionisti fonti autorevoli e affidabili, con dati sia nazionali sia globali:

- **Dati finanziari**: Wind Financial Data Service, dati finanziari Hundsun Gildata, S&P Global Market Intelligence, database finanziari globali, database dell’IMF (Fondo Monetario Internazionale), Straight Flush (Tonghuashun) e altro ancora
- **Business / legale**: Tianyancha, Huayu Yuandian e altro ancora

## Plugin selezionati per app esterne

Il Centro plugin offre plugin opzionali selezionati ufficialmente, tra cui:

- **Collaborazione d’ufficio**: Baidu Netdisk, DingTalk, Feishu, WPS
- **Design**: Canva
- **Note**: Notion
- **Sviluppo web**: Cloudflare
- **Altri**: Kimi Computer Use (l’IA controlla il desktop per operazioni a livello di sistema), GitHub, Neon (una piattaforma di database PostgreSQL nel cloud), Supabase (una piattaforma backend e database open-source) e altro ancora

Una volta installato un plugin, Kimi Work può usare direttamente questi strumenti d’ufficio comuni, sostituendo le azioni ripetitive con un’unica istruzione in linguaggio naturale.

## Come attivarli

1. Apri l’ultima versione del client desktop Kimi, passa alla modalità "Work" nella barra laterale sinistra e fai clic su "Plugin" per accedere al Centro plugin;
2. Trova e installa i plugin che ti servono nelle sezioni "Installati" e "Plugin in evidenza";
3. Digita una barra "/" nella casella di input e seleziona il plugin che vuoi richiamare.
