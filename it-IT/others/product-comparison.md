# Che differenza c’è tra Kimi, Kimi Work, Kimi Code e Kimi Claw? Quale dovrei usare?

Kimi include un assistente online pronto all’uso, oltre a diversi prodotti pensati per utenti ed esigenze differenti. Tutti condividono le funzionalità di base di Kimi; le differenze principali riguardano **dove li usi, a chi sono destinati e in cosa danno il meglio**.

## In breve

| Product | What it is | Best for / scenarios | Where to use it |
|---|---|---|---|
| **Kimi** (web / App) | Un assistente IA online che combina chat e Agent | Domande e risposte quotidiane, scrittura, ricerca, creazione di siti web / PPT / documenti e fogli, Deep Research e altro ancora | Web, App mobile |
| **Kimi Work** | Un **Agent locale** per professionisti della conoscenza (desktop) | Lavorare con file locali sul computer, automatizzare attività tra app desktop, portare a termine attività di lunga durata | client Mac / Windows |
| **Kimi Code** | Una suite di assistenza alla programmazione per **sviluppatori** | Scrivere codice e mantenere codebase | CLI, estensione VS Code |
| **Kimi Claw** | Una piattaforma di **automazione cloud senza deployment** | Automazione cloud sempre attiva 7×24, bot integrati con Feishu / WeChat e altro ancora | Cloud (nessun server richiesto) |

## Quale dovrei usare?

- **Per chat quotidiane, scrittura, ricerca o per chiedere a Kimi di creare siti web, PPT e fogli, oppure di svolgere Deep Research** → usa **Kimi** (web / App).
- **Se ti serve che Kimi legga e scriva file locali sul tuo computer, automatizzi attività tra più app desktop o esegua compiti lunghi** → usa **Kimi Work** (desktop).
- **Se sei uno sviluppatore e ti serve soprattutto aiuto per scrivere codice o mantenere progetti** → usa **Kimi Code**.
- **Se vuoi un bot cloud sempre attivo, che funzioni automaticamente e possa connettersi a Feishu / WeChat e altre piattaforme** → usa **Kimi Claw**.

<Callout type="tip">
L’esperienza online di Kimi integra già “chat” e “Agent”: non devi passare dall’una all’altro. Nell’app desktop Kimi Work sono disponibili due modalità: “Work” (una modalità Agent orientata ai risultati da consegnare) e “Chat” (conversazioni rapide).
</Callout>

## Quale abbonamento dovrei scegliere?

I vantaggi dell’abbonamento sono collegati al tuo account Kimi. Tutte le funzionalità incluse nell’abbonamento (chat, Agent, Deep Research, Kimi Code e altro) **condividono lo stesso pool di credit**; Kimi Code ha inoltre un proprio rate limit di 5 ore / settimanale, valido solo per Kimi Code. Per i dettagli dei piani e i prezzi, consulta la [pagina degli abbonamenti](/membership/membership-pricing).

Se il tuo utilizzo riguarda soprattutto **lavoro quotidiano + attività occasionali**, un piano di abbonamento Kimi adeguato coprirà la maggior parte degli scenari su web / App / Kimi Work. Gli sviluppatori che **scrivono codice di frequente** dovrebbero prestare particolare attenzione anche ai vantaggi di Kimi Code.
