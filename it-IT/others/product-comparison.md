# Qual è la differenza tra Kimi, Kimi Work, Kimi Code e Kimi Claw? Quale dovrei usare?

Kimi include un assistente online pronto all’uso, oltre a diversi prodotti pensati per utenti e scenari differenti. Condividono le funzionalità di base di Kimi; le differenze principali riguardano **dove li usi, a chi sono destinati e in cosa rendono al meglio**.

## In sintesi

| Prodotto | Che cos’è | Ideale per / scenari | Dove usarlo |
|---|---|---|---|
| **Kimi** (web / App) | Un assistente AI online che combina chat e Agent | Domande e risposte quotidiane, scrittura, ricerca, creazione di siti web / PPT / documenti e fogli di calcolo, Deep Research e altro ancora | Web, App mobile |
| **Kimi Work** | Un **Agent locale** per knowledge worker (desktop) | Lavorare con file locali sul computer, automatizzare attività tra app desktop, portare a termine attività di lunga durata | Client Mac / Windows |
| **Kimi Code** | Una suite di assistenza alla programmazione per **sviluppatori** | Scrivere codice e mantenere codebase | CLI, estensione VS Code |
| **Kimi Claw** | Una piattaforma di **automazione cloud senza deployment** | Automazione cloud sempre attiva 7×24, bot integrati con Feishu / WeChat e altro ancora | Cloud (nessun server richiesto) |

## Quale dovrei usare?

- **Per chat quotidiane, scrittura, ricerca o per chiedere a Kimi di creare siti web, PPT e fogli di calcolo, oppure svolgere Deep Research** → usa **Kimi** (web / App).
- **Se vuoi che Kimi legga e scriva file locali sul tuo computer, automatizzi attività tra più app desktop o esegua attività lunghe** → usa **Kimi Work** (desktop).
- **Se sei uno sviluppatore e ti serve soprattutto aiuto per scrivere codice o mantenere progetti** → usa **Kimi Code**.
- **Se vuoi un bot cloud sempre attivo, che funzioni automaticamente e possa collegarsi a Feishu / WeChat e ad altre piattaforme** → usa **Kimi Claw**.

<Callout type="tip">
L’esperienza online di Kimi unisce già “chat” e “Agent”: non devi passare dall’una all’altro. Nell’app desktop Kimi Work sono disponibili due modalità: “Work” (una modalità Agent orientata ai deliverable) e “Chat” (conversazioni rapide).
</Callout>

## Quale abbonamento dovrei scegliere?

I vantaggi dell’abbonamento sono collegati al tuo account Kimi. **Kimi Code usa un pool di credit separato**, mentre le altre funzionalità dell’abbonamento (chat, Agent, Deep Research e altro) condividono lo stesso pool di credit. Per i dettagli dei piani e i prezzi, consulta la [pagina degli abbonamenti](/membership/membership-pricing).

Se il tuo utilizzo riguarda soprattutto **lavoro quotidiano + attività occasionali**, un piano Kimi adatto coprirà la maggior parte degli scenari su web / App / Kimi Work. Gli sviluppatori che **scrivono codice di frequente** dovrebbero prestare particolare attenzione anche ai vantaggi di Kimi Code.
