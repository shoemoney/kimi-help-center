# Agent の機能・制限事項

<SeoMeta
  title="Agent の機能・制限事項 - Kimi ヘルプセンター"
  description="Kimi Agent の機能、使い方のコツ、制限事項、より良い結果を得るためのベストプラクティスを紹介します。"
/>

<Callout type="info">
**Kimi Agent** は、複数ステップの推論とツール連携を通じて複雑なタスクを自律的に実行する AI アシスタントです。このガイドでは、Agent モードを最大限に活用するためのベストプラクティス、制限事項、FAQ を説明します。
</Callout>

## 使い方のコツ

**(1) タスクを送信する前に**

プロジェクトの背景、利用シーン、特別な要件など、前提情報と制約を明確に伝えると、Kimi が意図をより正確に理解できます。

**(2) 実行中**

Kimi Agent はバックグラウンドで非同期に実行されます。Web ページが固まったり停止しているように見えたりしても、**「停止」をクリックしないでください**。クリックするとタスクの実行が中断されます。ページを離れてもタスクはバックグラウンドで継続し、完了時に通知が届きます。時間がかかることが予想されるタスク（例：Agent Swarm）では、しばらくお待ちください。

**(3) Web サイト関連のシナリオ**

Agent は、フロントエンド画面、バックエンドサービス、永続化ストレージのロジックを含むフルスタックのコンテンツを生成できます。プロジェクトが期待どおりに動作しない場合、多くはサンドボックスの起動、データベースの初期化、認証設定、または公開操作の不足に起因します。標準の Agent はクラウド上で実行されるため、ローカルファイルや企業イントラネットのシステムへ直接アクセスすることはできません。ローカルファイルやイントラネットへアクセスする場合は、Kimi Claw を使用してください。

<Callout type="tip">
**ローカルファイルにアクセスする必要がありますか？** ローカルファイルや企業イントラネットのシステムへ安全にアクセスするには、Kimi Claw を使用してください。詳しくは [Kimi Claw ドキュメント](/kimi-claw/overview)をご覧ください。
</Callout>

**(4) 複数ターンの会話とタスク調整**
複数回の対話や修正を重ねると、Agent が初期の細かな内容を「忘れる」ことがあります。まずタスクの枠組みと重要なポイントを固め、その後で段階的に調整していくのがおすすめです。

**(5) 大規模タスクの分割**
大規模で複雑なタスクは 2〜3 段階に分け、バッチごとに Kimi へ送信するか、Agent Swarm を使用してください。

**(6) ファイル出力の制限**
標準の Agent モードでは、通常 1 つのタスクにつき出力できるファイルは 1 つだけです（例：ドキュメントまたはスプレッドシート）。複数ファイル（例：Word 文書と PPT の両方）が必要な場合は、Agent Swarm を使用してください。

**(7) コンテキスト制限と出力量のバランス**
大規模言語モデルには 256K 文字のコンテキスト制限（中国語で約 40,000〜50,000 文字 / 英語で約 100,000 語）があるため、大量のファイルを処理する際は、入力量と出力量のバランスを取る必要があります。

<Callout type="warning">
**コンテキスト制限に関する注意**: Agent は 256K 文字のコンテキストウィンドウを使用します。最適な結果を得るには、コンテキストを簡潔にし、不要なファイルを詰め込みすぎないようにしてください。
</Callout>

## 重要な注意事項

<Callout type="warning">
**credit の使用量**: Agent タスクは共有プールの credit を消費します。Kimi Code もこの共有プールを使用しますが、Kimi Code にのみ適用される独自の 5 時間 / 週ごとの rate limit があります。各 Agent タスクは通常 1 credit 単位を消費します。メンバーシップ階層ごとの詳しい credit 情報については、[Credits & Billing](/agent/quota-and-billing)をご覧ください。

- プランに応じて月 60〜720 件の Agent タスク
</Callout>

- **実行時間**: Agent モードでは、1 つのタスクに通常 5〜20 分かかります。Agent Swarm のタスクはさらに時間がかかる場合があります。ページを離れても構いませんが、タスクを中断するために「停止」をクリックしないでください。
- **credit の使用量**: Agent タスクは共有プールの credit を消費し、Kimi Code も同じプールを使用します（Kimi Code には独自の 5 時間 / 週ごとの rate limit があります）。
- **簡単なタスク**: 簡単な Q&A には、より速く応答できる標準チャットモードをおすすめします。

<Callout type="warning">
**コンテンツの遵守事項**: Agent の機能には [Kimi User Service Agreement](https://www.kimi.com/user/agreement/modelUse?version=v2) が適用されます。禁止コンテンツの生成には対応していません。禁止コンテンツを送信すると、サービスの利用停止につながる場合があります。
</Callout>

## FAQ

**Q: Agent で何ができますか？**

Agent は複数のツール呼び出しを通じて、次のようなニーズに対応します。
- **テキスト生成・編集**: 記事、レポート、ドキュメントなどを生成できます。さまざまな文体や形式に対応しています。
- **Web 開発**: フルスタックのプロジェクト画面やサービスを構築できます。アプリ画面設計、バックエンド連携、データ永続化、データ可視化に対応します。
- **スライド生成**: 完成したプレゼンテーションを生成するための、Web ベースの専用 PPT ツールです。
- **コーディング支援**: 複数のプログラミング言語で、コード作成とデバッグを支援します。

**Q: Agent が作成した Web サイトが動作しないのはなぜですか？**

一般的に、完全なプロジェクトはフロントエンド画面、バックエンドサービス、データストレージの 3 つで構成されます。Agent は、この 3 層すべてにわたるフルスタックのプロジェクトコンテンツを生成できます。プロジェクトが期待どおりに動作しない場合、多くはサンドボックスの起動、データベースの初期化、認証設定、または公開操作の不足に起因します。

**Q: Agent の成果物には何がありますか？**

- タスク実行で生成された一式のファイル
- デプロイ済みのプロジェクトプレビューと公開版
- ダウンロード可能な Zip アーカイブ（`/mnt/okcomputer/output/` にあります）

**Q: Agent のコンテキスト長はどのくらいですか？**

Agent は **256K 文字** のコンテキスト長を使用します（中国語で約 40,000〜50,000 文字 / 英語で約 100,000 語）。

**Q: Agent の credit はどのように計算されますか？**

Kimi Code を含むすべてのメンバーシップ機能は、1 つの credit プールを共有します。各 Agent タスクは通常、1 credit 単位としてカウントされます。
