# Agent のクレジットと請求

<Callout type="info">
Agent モードでは Kimi の クレジット システムを使用します。すべてのメンバーシップ特典には 2 つの クレジットプールが含まれます。Kimi Code は専用の クレジットプールを使用し、その他のメンバーシップ機能（Agent、Deep Research、Slides、Docs、Sheets、Kimi Claw など）は 1 つの クレジットプールを共有し、実際の token 消費量に基づいて クレジット が差し引かれます。
</Callout>

## 請求モデル
- **2 つの クレジットプール**: すべてのメンバーシップ特典には 2 つの クレジットプールが含まれます。Kimi Code は専用の クレジットプールを使用し、その他のメンバーシップ機能は 1 つの クレジットプールを共有します。使い方は自由に配分できます
- **従量課金**: クレジット の消費量は、タスクの複雑さと所要時間（つまり token 使用量）によって変わります。シンプルなタスクほど少なく、複雑なタスクほど多く消費します
- **毎月更新**: クレジット はサブスクリプションの請求サイクルに合わせて毎月リセットされます
- **使用の優先順位**: ボーナス クレジット（例: トライアル クレジット、プロモーション特典）が先に消費され、その後にプラン クレジット が消費されます

<Callout type="tip">
**例**: Moderato プランの場合、シンプルな PPT の生成では クレジット の約 1〜2% を消費する一方、1 回の Deep Research セッションでは約 5〜10% を使用することがあります。
</Callout>

## クレジット がなくなるとどうなりますか？
クレジット を使い切った場合:
- 進行中のタスクは通常どおり完了します
- 新しいタスクでは「クレジット 不足」の通知が表示されます
- 対処方法:
  - 毎月の クレジット が自動更新されるのを待つ
  - より多くの クレジット が含まれる上位メンバーシップにアップグレードする

## クレジット の使用状況を確認するには？
- **Web**: プロフィール → 設定 → サブスクリプション
- **App**: プロフィール → メンバーシッププラン → サブスクリプション
確認できる内容:
1. 現在の クレジット 残高（パーセンテージ）
2. 次回更新日
3. 直近 10 件の使用記録（タイムスタンプ、使用した機能、消費率）

<Callout type="info">
使用記録の反映には少し時間がかかる場合があります。最新の情報は、実際の クレジット 表示をご確認ください。
</Callout>

## 失敗したタスクでも クレジット は消費されますか？
- クレジット は、タスクが正常に実行された後、実際の消費量に基づいて差し引かれます
- システムエラーによりタスクが失敗した場合（有効な結果が返されなかった場合）は、**👎** ボタンをクリックして報告してください。確認後、該当する クレジット が返還されます
