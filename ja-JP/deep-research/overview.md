# Deep Research

<Callout type="info">
**Deep Research** は、Kimi-Researcherモデルを搭載したKimi初のAgent製品です。単に質問に答えるだけでなく、本物のリサーチャーのように、タスクの計画からレポートの納品まで、一連の作業を自律的に完了します。
</Callout>

## Kimi-Researchの仕組み

Kimi-Researcherは、どの質問に対しても調査パイプライン全体を独立して実行します。
| ステップ | 説明 |
| --- | --- |
| **Clarification（確認質問）** | 問題の輪郭をより明確にするため、能動的に追加質問を行います |
| **深い推論** | 1タスクあたり平均23回の推論ステップで、要件を整理し解決します |
| **能動的な検索** | 約74個のキーワードを計画し、206件のURLを発見したうえで、品質が最も高い上位3.2%のコンテンツに絞り込みます |
| **Iterative reasoning（反復推論）** | 結果を評価し、追加検索が必要かどうかを判断します |
| **ツール呼び出し** | ブラウザ、コード実行、その他のツールを呼び出してデータを処理します |
| **レポート生成** | 情報を統合し、引用付きの構造化された長文レポートにまとめます |

<Callout type="info">
Deep Researchは非同期で動作し、段階的な推論、検索、執筆に10〜25分かかります。
</Callout>

## 成果物
各調査タスクでは、2つの成果物が生成されます。
### 1. テキスト調査レポート
- 平均長：1万語以上
- 追跡可能な高品質ソース約26件
- 引用は本文中に埋め込み表示され、クリックすると出典へ移動できます

## 活用例

<Callout type="tip">
**特に適した用途**：投資分析、業界調査、学術トピック、戦略立案、規制レビュー、知識の体系化
</Callout>

| カテゴリ | 例 |
| --- | --- |
| **専門的な調査** | 投資分析、業界調査、学術トピック、戦略立案 |
| **情報の統合** | 規制レビュー、複雑な文書検索、複数ソースの集約 |
| **知識・教育** | 教材作成、体系的な調査、テーマの深掘り |
| **日常的な探究** | 関心のあるトピックについて学ぶ |

<Callout type="warning">
**適していない用途**：創作執筆（小説、脚本）、占い、履歴書作成、固定形式のテンプレート、編集可能なスライド
</Callout>

## Deep Researchの使い方
**入口**：
- **Web**：[kimi.com/deep-research](https://www.kimi.com/deep-research)
- **モバイル**：Kimiアプリ → タスクバー → Deep Research Agentモード
**手順**：
1. 調査したい質問を入力して送信します
2. 方向性を確認するための追加質問に回答します（または「すべて含める」をクリックしてスキップします）
3. 検索キーワード、推論プロセス、訪問したURLをリアルタイムで確認します
4. 完了すると、2つの成果物を受け取れます。
   - **Deep Researchレポート**（Markdown）：目次と追跡可能な出典を含む1万語以上のレポート
   - **ビジュアルレポート**（HTML）：インタラクティブで公開共有可能なビジュアルレポート
5. 必要に応じてプレビュー、ダウンロード（PDF/Word）、共有を行います
## より良い結果を得るためのヒント
### 1. 範囲を絞る
送信前に、次のような条件を指定すると効果的です。
- **期間**：「2023年から現在まで」
- **地域範囲**：「米国市場のみ」
- **ソース種別**：「公式レポートと学術論文を優先」
- **質問の分解**：大きな質問をサブ質問に分ける

### 2. 確認段階で方向性を調整する
- 扱ってほしくない方向性を明示する
- 注目したい具体的な観点や切り口を追加する
- 複雑な質問には背景情報を添える

<Callout type="warning">
確認への回答は簡潔かつ具体的にしてください。長すぎたり不明瞭だったりすると、調査の方向性がずれることがあります。
</Callout>

### 3. 実行中はしばらく待つ
Deep Researchは通常10〜25分かかります。システムはバックグラウンドで動作するため、ページを開いたまま待つ必要はありません。

<Callout type="warning">
**「出力を停止」はクリックしないでください** — 調査が終了してしまいます。ページが反応していないように見える場合は、更新するだけでかまいません。
</Callout>

## 重要な注意事項
1. **実行時間**：10〜25分。タスクは非同期で実行され、完了時に通知されます
2. **creditの返金**：ツール呼び出しエラーの場合は自動的に返金されます。調査の方向性がずれた場合はフィードバックを送信してください
3. **入力品質**：簡潔で明確に定義された質問ほど、より良い結果が得られます
4. **適用範囲**：簡単なQ&Aには、より速く応答できる通常のチャットモードをご利用ください
5. **規約**：[Kimi User Service Agreement（Kimiユーザーサービス契約）](https://www.kimi.com/user/agreement/modelUse?version=v2)が適用されます
