# Deep Research のユースケースとプロンプト例

## ユースケース概要

| シナリオ | プロンプト例 |
|:---|:---|
| 業界／市場調査 | 2025年における国内ヒューマノイドロボット分野の競争環境と主要企業を調査してください |
| 競合分析 | Notion と Obsidian のプロダクト戦略の違いを比較・分析してください |
| 投資デューデリジェンス | 過去2年間における主要 LLM 企業の資金調達ラウンドと評価額の変化をまとめてください |
| 学術文献レビュー | RAG 技術の発展経緯と、現在の主な最適化の方向性をたどってください |
| 政策分析 | 最新のデータセキュリティ規制が海外展開企業に与える影響を分析してください |
| 個人の意思決定 | 動画編集用のノートパソコンを購入したいので、有力な選択肢を調べてください |
