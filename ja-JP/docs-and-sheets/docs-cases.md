# Kimi Docsのユースケースとプロンプト例

<Callout type="info">
原稿レビューから専門翻訳、PDFデザインまで、Kimi Docsで使えるユースケースとプロンプト例。
</Callout>

## レビューエキスパート

緻密な原稿査読者のように、Kimiは修正フィードバックを整理し、文書内の該当箇所を特定して、詳細なコメントと提案を自動で挿入します。

**プロンプト例**:

<CodePreview
  files={[
    {
      name: "prompt.md",
      language: "markdown",
      content: "あなたはスマートシティと地域計画を専門とするベテランの原稿査読者です。\n以下に具体的な査読コメントを示します。これらの指摘を丁寧に分析し、\n添付のWord文書内で対応する段落や図を特定したうえで、\n問題点と詳細な修正提案をコメントとして挿入してください。注意：\nコメントはAIではなく人間が書いたように自然な文章にし、箇条書き形式は避けてください。\n\n詳細コメント付きの元原稿を出力してください。",
    },
  ]}
/>

## 専門翻訳

疲れ知らずの翻訳者のように、Kimiは50ページの英語PDFを1ページずつフランス語に翻訳し、出力ではすべての数式とコードを保持します。

**プロンプト例**:

<CodePreview
  files={[
    {
      name: "prompt.md",
      language: "markdown",
      content: "StanfordのCS336コースの第1回課題PDF（英語）を探し、それを\nフランス語のPDFに変換してください。フランス語版では、すべてのコードと数式を保持してください。\n翻訳は自然で流暢にし、内容の省略や追加はしないでください。",
    },
  ]}
/>

## PDFデザイン・出版サービス

レイアウトデザイナーのように、Kimiはビジュアル表現の設計を支援し、テキストと画像を自動で配置して、出版品質のPDFポートフォリオを生成します。

<CodePreview
  files={[
    {
      name: "prompt.md",
      language: "markdown",
      content: "あなたは現代美術、特にピカソ研究を専門とするキュレーション出版AIです。\nあなたの課題：豊富な図版を使い、なぜピカソが何度も見直されるべきなのかを鑑賞者が理解できるようにしてください。\n\nPDFとして直接出力してください。\n\nI. 中核要件\n豊富な図版\nすべての時代区分、すべての参照作家、すべての運動に補足画像を付けること\n出典のある画像を優先すること\n出典画像が入手できない場合のみ、高精細なAI生成画像を使用すること\n\nII. ビジュアルシステム\nMAPロゴを全面ウォーターマークとして使用\n非対称レイアウト\n局所的な崩しを制御した明快なグリッド\n高コントラストの白黒＋原色アクセント\n\nIII. コンテンツ構成（全セクションを生成）\n1. 表紙\nピカソ\n展覧会サブタイトル（英語＆中国語）\nMAPロゴのウォーターマーク\n\n2. なぜピカソなのか（画像付き）\n異なる時期のピカソのポートレート\n異なる時期の作品を並置\n\n3. 時代区分と運動（画像中心）\n各時代区分には8～12点の画像を含めること：\n青の時代\nばら色の時代\nキュビスム（分析的／総合的）\n戦争と政治\n晩年の実験\n\n画像タイプ：\n作品全体\nディテールの切り抜き\n構造分解図（必要に応じてAI生成）\n\n4. 主要作品\n25作品以上\n個々の作品は全ページを使ってもよい\n構造、遠近法、解体を重視\n\n5. ピカソの見方\n画像に基づく比較解説\n同じ主題の左右比較\n\n6. 展示室とリズム\n高密度の鑑賞ゾーン\n思索のための緩衝ゾーン\n\n7. MAPの現代における位置づけ\n上海にピカソが必要な理由\nこの時代に取り上げる意義",
