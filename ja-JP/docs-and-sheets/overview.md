# Kimi Docs & Kimi Sheets

<Callout type="info">
2026年1月27日、Moonshot AI は Kimi K2.5 をリリースし、Kimi Agent の生産性機能を大幅に強化しました。Kimi Agent は Word、PDF、Excel、スライドのエンドツーエンドのファイル出力に対応し、いまや「Office を使いこなす」存在になりました。
</Callout>

Kimi K2.5 は、Office 利用シーンにおける出力品質とツール呼び出し効率を大きく高めています。特に、エンドツーエンド処理を伴う構造化出力で力を発揮します。
| 形式 | 機能 |
|--------|-------------|
| **Word** | インテリジェントな書式設定と変更履歴の管理 |
| **PDF** | ビジュアルデザインとテキスト・画像を組み合わせたレイアウト |
| **Excel** | データ分析と財務モデリング |
| **スライド** | 自動生成と視覚的なストーリーテリング |

## Kimi Docs
Kimi Docs は、テキストへの高い適応力と、Office ワークフローに対する体系的な理解を備えています。
### 主な機能
**Word ドキュメント:**
- ホワイトペーパー、調査レポート、契約書、提案書など、長文のプロフェッショナル文書を生成
- 既存の Word ドキュメントにコメントや修正提案を挿入
- 見出し階層、段落間隔、引用、リスト書式を処理
- 30,000語の論文を的確な要約に圧縮
**PDF ドキュメント:**
- 表紙、目次、本文、図表キャプションを備えた、図版豊富なプロフェッショナル PDF レポートを生成
- 専門的な組版ソフトなしで既存の PDF を再編集・再レイアウト
- 100ページ規模の PDF から特定の情報を抽出
- 複数の契約書バージョン間にある微妙な違いを比較
### Kimi Docs の使い方
**入口:**
- 一般: サイドバーまたはチャットボックスの Docs、Sheets、Slides ショートカットをクリック
- 専用: チャットボックス下部の「Docs」ボタンをクリック
### 方法 1: Kimi Docs ページにアクセスする

<Frames
  src="./images/overview/screenshot-1.png"
  alt="スクリーンショット 1"
/>

1. **ブラウザを開く**: Chrome、Safari、Edge、Firefox、または主要なブラウザ
2. **移動先**: [kimi.com/docs](https://www.kimi.com/docs)
3. **ログイン**: Kimi アカウント（Google またはメール）でサインイン
4. **タスクを入力**:
   - **テキスト入力**: 自然言語でタスクを入力
   - **ドキュメントをアップロード**して編集
   - **例を見る**: 「Make one like this」をクリックし、カスタマイズして送信
5. **作成を開始**: テンプレートを選ぶか、会話しながら作成

<Frames
  src="./images/overview/screenshot-2.png"
  alt="スクリーンショット 2"
/>

<Callout type="tip">
「XX のレポートを作成して」など、必要な内容をそのまま伝えてください。既存の Word/PDF/Excel ファイルをアップロードし、実行したい操作を指定することもできます。元の形式のファイル（.docx / .xlsx / .pdf）をダウンロードして、ローカルで引き続き編集できます。
</Callout>

### 方法 2: モバイルアプリ
Kimi アプリは iOS と Android で利用できます。タスクバーをタップし、Docs Agent モードに切り替えます。
#### 方法 3: 汎用 Agent モード
K2.6 Agent モードに切り替え、ドキュメント関連のタスクを入力します。Kimi が読み取り・書き込みツールを呼び出します。
## Kimi Sheets
Kimi Sheets はセル間の関係やシートをまたぐ連携ロジックを理解し、ブラウザ上で .xlsx ファイルを直接生成します。
### 主な機能
| 機能 | 説明 |
|------------|-------------|
| **大量データ入力** | ドキュメントからデータを抽出します。例: PDF から出展者情報を取り出し、1,000行の Excel ファイルに整理 |
| **複数ソースの統合** | 50部門分の Excel レポートを、会社全体のサマリー1つに統合 |
| **自然言語入力** | 自律的な Web 検索と、インテリジェントなスプレッドシート生成 |

### Kimi Sheets の使い方
チャットボックス下部の「Agent」ボタンをクリックするか、サイドバーの「Sheets」ショートカットを選択します。

<Frames
  src="./images/overview/screenshot-4.png"
  alt="スクリーンショット 4"
/>

たとえば、*「Web を検索して、XX 分野の最新論文を Excel ドキュメントにまとめて」* と指示できます。既存の Excel/CSV ファイルをアップロードし、実行したい操作を指定することもできます。オンラインでプレビューしてから、.xlsx ファイルをダウンロードしてください。
