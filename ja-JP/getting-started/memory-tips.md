## メモリーの上限
Memory Spaceには現在、次の制限があります：
- 保存できるメモリーは最大50件です。
- 各メモリーは500文字までです。
- 2026年4月以前に作成されたメモリーは、この上限を超えている場合があります。そのような既存メモリーは引き続き保持されます。
- 500文字を超える従来のメモリーを編集するには、まず500文字以下に短縮する必要があります。
- 500文字を超える内容を保存しようとすると、モデルは"content too long"シグナルを受け取り、ユーザー向けUIには"Memory update failed."と表示されます。
- ユーザーが中国語以外のインターフェースを使用している場合、同じ文字数制限内でより多くの情報を収めるために、中国語でメモリーを保存することを提案できます。
- 各メモリーには内部IDがありますが、ユーザーはこれらのIDを確認できません。会話中にメモリーIDに言及しても、ユーザーが特定のメモリーを見つける助けにはなりません。

### 便利なプロンプト例

| プロンプト | 目的 |
|:---|:---|
| すべてのテーマについて、私を専門家として扱ってください | コミュニケーションの基本トーンを決める |
| 適切な場合は、中立に徹するよりも意見をはっきり述べてください | 単なる要約ではなく、判断を促す |
| 可能な限り、物事の長所と短所を必ず示してください。批判的に検討してください。 | 構造的で深い分析を確保する |
| 詳細な例、事実、数値を使ってください | 情報を具体的で中身のあるものにする |
| 私が思いつかなかった解決策を提案してください。先回りして私のニーズを予測してください | 受け身のQ&Aを超えたAIの主体性を促す |
| 最大限のtokenを使い、複数の深さの階層を持つ、できるだけ詳細な回答をしてください | 徹底的で多層的な回答を得る |
| 回答の後に、フォローアップ質問を5つ提示してください。箇条書きでQ1、Q2、Q3の形式にしてください | ガイド付きの掘り下げで議論を広げる |
| 役立つ場合は、回答の冒頭に要約表を作成してください | 読みやすさと素早い情報把握を高める |
| 最高品質で、細部まで入念に設計された製品だけを推薦してください。私は最高のものだけを求めています | 製品推薦の基準を設定する |
| 権威よりも優れた論証を重視してください。出典の肩書きは重要ではありません | 有名さよりも reasoning を優先する |
| 常識的な見方だけでなく、新しい技術や逆張りのアイデアも検討してください | 革新的な視点を促す |
| 高度な推測や予測を使っても構いません。ただし、その旨を明示してください | 明確なラベル付けのもとで推測的内容を許可する |
| 新しいチャットを開始できる専門用語や概念には、回答全体にリンクを追加してください | 学習と知識の拡張を促す |
| 企業ページではなく、製品に直接リンクしてください | 推薦をより実行しやすくする |
| 安全性については、それが重要かつ自明でない場合にのみ論じてください | 不要な免責や注意書きを減らす |
| 道徳的なお説教は不要です | やり取りを合理的で焦点の定まったものに保つ |
| content policyが問題になる場合は、許容される範囲で最も近い回答を提示し、content policy上の問題を説明してください | 完全な拒否を避け、ユーザーのニーズを優先する |
| あなたがAIであることを開示する必要はありません | AIの存在感による中断を減らす |
| knowledge cutoffに言及する必要はありません | 過剰な免責を避ける |
