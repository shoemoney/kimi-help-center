# Kimi の概要

<Callout type="info">
Kimi は Moonshot AI が開発した AIアシスタントです。ウェブ検索、深い思考、マルチモーダル推論、超長文コンテキストでの対話に標準で対応しています。
</Callout>

[Kimi.com](https://www.kimi.com/) にアクセスするか、Kimi アプリをダウンロードして、チャット、作成、調査、開発を始めましょう。開発者は [Kimi オープンプラットフォーム](https://platform.kimi.ai/) で API やツールを利用し、Kimi の機能を自分のアプリケーションに組み込めます。
## チャットとモデル
Kimi は複数のモデルを提供しています。入力ボックス上部のモデル切り替えボタンをクリックして切り替えます。
| モデル | 思考の強さ | 適した用途 |
|-------|-------------------|----------|
| **K2.6** | Standard / High | 応答が速く、すばやい会話や Q&A に最適 |
| **K3** | Low / High / Max | チャットと Agent タスク。総合的に最も高性能 |
| **K3 Swarm** | Low / High / Max | 大規模な検索やバッチ処理を一度に完了 |

<Callout type="tip">
オンライン検索を行うかどうかは、質問内容に基づいて Kimi が自動的に判断します。手動での切り替えは不要です。
</Callout>

## AIエージェント
Kimi は単なるチャットアシスタントではありません。タスクを自律的に計画し、実行できる AIエージェントです。
| エージェント | 説明 | リンク |
|-------|-------------|------|
| **General Agent** | ウェブサイト生成、スライド作成、Deep Research、ドキュメントやスプレッドシートの処理など、タスクを自動で計画・完了します | [kimi.com/agent](https://www.kimi.com/agent) |
| **Agent Swarm** | 最大4,000件の並列ツール呼び出しに対応し、300以上のサブエージェントを連携させて、大規模検索、長文執筆、バッチ処理を実行します | [kimi.com/agent-swarm](https://www.kimi.com/agent-swarm) |
| **Kimi Code** | 開発者向けのコーディングアシスタントスイートです。CLI ツールと VS Code 拡張機能を含みます | [kimi.com/code](https://www.kimi.com/code) |
| **Kimi Claw** | デプロイ不要のクラウド自動化プラットフォームです。5,000以上の組み込みスキル（ClawHub）を備えた常駐型 AIエージェントを30秒以内に起動できます | [kimi.com/bot](https://www.kimi.com/bot) |
| **Kimi Work** | ナレッジワーカー向けの汎用ローカル Agent です。Kimi Code を基盤とし、ローカル Agent の基本機能（スキル、スケジュールタスク）に加え、オンラインの Kimi Agent が持つウェブサイト構築、PPT、専門データベースを提供します | [kimi.com/products/kimi-work](https://www.kimi.com/products/kimi-work) |

## その他の主な機能
- **注目機能**: 写真での問題解決、音声通話、翻訳、文章作成支援
- **ファイル処理**: PDF、Word、Excel、PPT、画像、TXT、動画に対応（各ファイル最大100 MB）。1セッションにつき最大50ファイルまで扱えます
- **プリセット**: よく使うプロンプトを保存してすばやく呼び出せます。高品質で再利用しやすいプロンプトテンプレートに最適です
