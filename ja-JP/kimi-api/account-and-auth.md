# アカウントと認証

<Callout type="info">
Kimi API の開発者アカウント、認証、本人確認に関するよくある質問です。
</Callout>

## 個人アカウントで法人向けの請求書を受け取れますか？
個人アカウントでは、**法人向けの請求書を直接受け取ることはできません**。法人向けの請求書が必要な場合は、まずアカウントを組織アカウントにアップグレードしてください。認証が完了すると、組織名義で請求書を申請できます。

## 個人アカウントから組織アカウントへアップグレードするには？
1. [platform.moonshot.ai](https://platform.moonshot.ai) コンソールにログインします。
2. **アカウント設定 → 認証** に移動します。
3. **組織認証** を選択し、必要な情報を入力します。
4. 審査に提出します。承認されると、アカウントは自動的に切り替わります。

<Callout type="tip">
アップグレード後も、既存の残高と利用データは保持されます。
</Callout>

## 個人認証と組織認証の違い
| 項目 | 個人 | 組織 |
| --- | --- | --- |
| 請求書の種類 | 個人向け請求書 | 法人向け / VAT 請求書 |
| rate limit（レート制限） | 標準 | より高い quota（上限）の対象 |
| 法人契約 | — | 契約締結が可能 |
| ボリュームディスカウント | — | リクエストに応じて提供 |
| テクニカルサポート | 標準 | 優先サポート |

## アカウント停止に異議申し立てをするには？
ポリシー違反により API アカウントが停止された場合は、次の手順でお申し立てください。
1. 件名を "API Account Appeal" として、**support@moonshot.ai** までメールを送信します。
2. アカウント情報（登録済みメールアドレス）と、異議申し立ての内容を記載してください。
3. チームが内容を確認し、1～3 営業日以内に返信します。

<Callout type="info">
**サポートメール**: support@moonshot.ai
</Callout>

## 登録済みメールアドレスを変更するには？
登録済みメールアドレスを変更するには、サポートまでご連絡ください。
1. 件名を "Email Change Request" として、**support@moonshot.ai** までメールを送信します。
2. 現在のメールアドレスと新しいメールアドレスの両方を記載してください。
3. アカウントの安全を確保するため、本人確認が必要になる場合があります。

## 認証を完了するメリット
- **より高い rate limit（レート制限）**: 認証済みユーザーは、より高い API コール rate の対象になります。
- **すべての機能へのアクセス**: 一部の高度な機能は、認証済みユーザーのみ利用できる場合があります。
- **請求書サポート**: 認証済みアカウントは請求書を申請できます。
- **テクニカルサポート**: 認証済みユーザーには、より優先度の高いテクニカルサポートが提供されます。
