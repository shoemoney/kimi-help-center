# API トラブルシューティング

<Callout type="info">
Kimi API を利用する開発者向けのよくある問題と解決方法。
</Callout>

## 429 rate limit エラーへの対処方法

429 エラーは、リクエスト頻度が現在のアカウントの rate limit を超えたことを示します。解決するには、次の方法をお試しください。

- 指数バックオフによるリトライ戦略を実装する（再試行前に 1s、2s、4s… と待機する）。
- キューの仕組みを使って同時リクエスト数を制御する。
- 累計チャージ金額を増やし、rate limit のティアを引き上げる。
- より高いクレジットが必要な場合は、営業チームに問い合わせる。

## 401 認証エラーへの対処方法

401 エラーは、API Key 認証に失敗したことを示します。次の点を確認してください。

- API Key が正しくコピーされていることを確認する（先頭や末尾のスペースに注意）。
- リクエストヘッダーの形式が `Authorization: Bearer <your-api-key>` になっていることを確認する。
- API Key が削除または無効化されていないことを確認する — コンソールで確認できます。
- 別のプラットフォームのキーを使用していないことを確認する（Kimi API Keys は `sk-` で始まります）。

<Callout type="warning">
**API Key の形式**: Kimi API Keys は `sk-` で始まります。正しいキー形式を使用していることを確認してください。
</Callout>

## ファイルアップロードに料金は発生しますか？

ファイルアップロード自体は無料です。ただし、アップロードしたファイルを会話内で参照すると、その内容が token に解析され、入力 token として課金されます。ファイルが大きいほど生成される token も多くなります。

## 403 残高不足エラーへの対処方法

403 エラーは通常、アカウント残高が不足していることを示します。コンソールでチャージしてください — 入金後すぐに利用できます。残高照会 API を使って現在の残高を確認することもできます。

## レスポンスが途中で切れる場合は？

API レスポンスが不完全、または途中で切れている場合は、次を確認してください。

- `max_tokens` パラメーターの設定値が低すぎないか確認し、必要に応じて増やす。
- レスポンス内の `finish_reason` フィールドを確認する: `length` は token 上限により出力が途中で切れたことを示し、`stop` は正常に完了したことを示します。
- 長文生成の場合は、リクエストを複数のセグメントに分けることを検討する。

<Callout type="tip">
**`finish_reason` を確認**: `length` = 途中で切れた、`stop` = 正常に完了。
</Callout>

## ファイル API で画像をアップロードできますか？

はい。ファイルアップロード API は画像ファイルに対応しています。アップロード後、画像は会話内で参照できます。Vision モデルでは、URL または Base64 エンコードにより、メッセージ内で画像を直接渡すこともできます。

## Web Search の情報源は？

Kimi API の Web Search 機能は、インターネット上で公開されている情報をリアルタイムに取得します。結果は主要な検索エンジンにインデックスされたウェブページから取得されます。Web Search を 1 回呼び出すごとに、$0.004 の追加料金が発生します。

## Kimi 会員プランと API concurrency に関係はありますか？

<Callout type="warning">
**Kimi 会員プラン**（Allegretto など）と **API** は別々の課金システムです。会員プランに含まれるエージェントの並列実行数は Kimi のコンシューマー向け製品にのみ適用され、API rate limit とは関係ありません。API concurrency の上限は、アカウントの累計チャージ額のティアによって決まります。
</Callout>

## API と Kimi Web アプリの違い

| 観点 | Kimi Web アプリ | Kimi API |
| --- | --- | --- |
| **対象** | コンシューマー向け会話型プロダクト | 開発者向け統合インターフェース |
| **アクセス方法** | ブラウザー経由 | プログラムによる API 呼び出し |
| **課金** | 会員プラン/クレジット制 | token に応じた従量課金 |
| **アカウント** | ログイン情報は共通 | ログイン情報は共通 |
| **クレジット** | システム間で移行不可 | システム間で移行不可 |

## PPT 生成と Deep Research は API で利用できますか？

<Callout type="warning">
**PPT 生成**と **Deep Research** は、**現時点では API で利用できません**。これらの機能は現在、Kimi のコンシューマー向け製品でのみ利用できます。最新情報はプラットフォームのお知らせをご確認ください。
</Callout>

## オンプレミス展開はサポートされていますか？

Kimi API は現在、クラウドベースの API サービスのみを提供しており、**オンプレミスのプライベート展開には対応していません**。プライベート展開が必要な場合は、[platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales) から営業チームにお問い合わせください。

## 中国国外から Kimi API を呼び出せますか？

Kimi API は `api.moonshot.ai` を通じて国際的に利用できます。接続に問題がある場合は、営業チームに連絡し、お住まいの地域に最適な解決策についてご相談ください。
