# ビジネス提携・営業窓口

<Callout type="info">
エンタープライズのお客様向けの提携オプション。ボリュームディスカウントからカスタムSLAまで対応します。
</Callout>

Kimi API は、あらゆる規模のビジネスニーズに対応できるよう、エンタープライズのお客様向けに多様な提携オプションをご用意しています。
## 営業チームへのお問い合わせ方法
[platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales) にアクセスし、お問い合わせフォームを送信してください。営業チームより1〜2営業日以内にご連絡します。

<Callout type="tip">
**送信内容に含める項目**:
- 会社名と業種
- 想定利用量
- 主なユースケース
- 希望する提携モデル
</Callout>

## 契約締結
組織認証済みユーザーは、Moonshot と正式なサービス契約を締結できます。
- 標準サービス契約と個別契約のどちらにも対応しています。
- 契約締結後は、銀行振込によるお支払いとエンタープライズ水準のSLAをご利用いただけます。
- 具体的な手続きについては、営業チームまでお問い合わせください。

## ボリュームディスカウント
利用量の多いエンタープライズのお客様は、専用ディスカウントを申請できます。
| 条件 | 詳細 |
| --- | --- |
| **対象条件** | 組織認証 + 契約締結済み |
| **ディスカウントレベル** | コミット済み利用量と契約期間に応じて決定 |
| **申請方法** | 月間利用見込みを添えて営業チーム経由で申請 |

## エンタープライズ API サービス
エンタープライズ API サービスでは、標準 API に加えて以下をご利用いただけます。
- **より高い rate limit と concurrency quota**
- **専用の技術サポートチャネル**
- **カスタムSLA保証**
- **新機能への先行アクセス**
