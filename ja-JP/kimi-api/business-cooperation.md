# ビジネス提携・営業窓口

<Callout type="info">
エンタープライズのお客様向けの提携オプションです。ボリュームディスカウントからカスタム SLA までご用意しています。
</Callout>

Kimi API では、あらゆる規模のビジネスニーズに対応できるよう、エンタープライズのお客様向けにさまざまな提携オプションを提供しています。
## 営業チームへのお問い合わせ方法
[platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales) にアクセスし、お問い合わせフォームを送信してください。営業チームより 1〜2 営業日以内にご連絡します。

<Callout type="tip">
**送信時にご記入いただきたい内容**:
- 会社名と業種
- 想定される利用量
- 主なユースケース
- 希望する提携モデル
</Callout>

## 契約締結
組織認証済みユーザーは、Moonshot と正式なサービス契約を締結できます。
- 標準サービス契約とカスタム契約のいずれにも対応しています。
- 契約締結後は、銀行振込でのお支払いとエンタープライズレベルの SLA をご利用いただけます。
- 具体的な手続きについては、営業チームまでお問い合わせください。

## ボリュームディスカウント
利用量の多いエンタープライズのお客様は、専用割引を申請できます。
| 要件 | 詳細 |
| --- | --- |
| **対象条件** | 組織認証 + 契約締結済み |
| **割引レベル** | 確約利用量と契約期間に基づきます |
| **申請方法** | 月間想定利用量を添えて、営業チーム経由で申請してください |

## エンタープライズ API サービス
エンタープライズ API サービスでは、標準 API に加えて次の内容をご利用いただけます。
- **より大きな rate limit と concurrency quota**
- **専用のテクニカルサポート窓口**
- **カスタム SLA 保証**
- **新機能への早期アクセス**
