# モデルの選択と比較

<Callout type="info">
機能、速度、料金に応じて最適なKimi APIモデルを選択できます。
</Callout>

Kimi APIでは、開発者が用途に合わせて複数のモデルから選択できます。
## 利用可能なモデル
モデルの完全な一覧と詳細仕様については、[platform.kimi.ai/docs/models](https://platform.kimi.ai/docs/models) をご覧ください。
モデルを選ぶ際は、以下の点を検討してください。
| 観点 | 検討事項 |
| --- | --- |
| **コンテキスト長** | 長いドキュメントを処理する場合は、大きなコンテキストに対応したモデルを選択します |
| **応答速度** | レイテンシが重要な場面では、軽量モデルを選択します |
| **生成品質** | 複雑な推論や創造的な文章作成には、上位モデルを選択します |
| **料金** | 予算と利用量に応じて、費用対効果の高いモデルを選択します |

## ビジョンモデル
ビジョンモデルは画像入力に対応しており、キャプション生成、OCR、グラフの解釈などに利用できます。

<Callout type="info">
- 各画像は、サイズや解像度にかかわらず、一律 **1,024 tokens** として課金されます
- 対応形式：JPEG、PNG、WebP など
- 画像はURLまたはBase64エンコードで渡せます
</Callout>

## 現在未対応の機能

<Callout type="warning">
- **動画マルチモーダル**：動画の直接入力にはまだ対応していません
- **PPT生成API**：API経由ではまだ利用できません
- **Deep Research API**：API経由ではまだ利用できません
</Callout>

これらの機能に関する最新情報は、プラットフォームのお知らせをご確認ください。
