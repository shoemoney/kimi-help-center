# コアコンセプトとターミナル

## 主要コンセプト

| コンセプト | 説明 |
|---------|-------------|
| **メモリ** | Kimi Claw の長期記憶システムです。会話をまたいで、あなたの好み、習慣、重要な情報を保存します。 |
| **スキル** | ClawHub ライブラリからインストールできる機能モジュールです。Kimi Claw に特定分野の専門性を追加します。 |
| **HEARTBEAT** | タイマーで実行される定期バックグラウンドタスクです。繰り返しのリマインダー、データ取得、ダイジェスト作成に便利です。 |
| **アイデンティティ** | Kimi Claw の役割定義です。名前、職業、ペルソナを含み、自由にカスタマイズできます。 |
| **ソウル** | Kimi Claw の対話スタイルを形づくる、核となる性格特性と行動原則です。 |
| **ツール** | Kimi Claw が呼び出せる機能群です。Web 検索、ファイル操作、コード実行などが含まれます。 |
| **ユーザー** | あなたと Kimi Claw の関係性の定義です。対話パターンや情報共有のあり方を決めます。 |

## ターミナル

<Frames
  src="./images/concepts/screenshot-30.png"
  alt="スクリーンショット 30"
/>

Web の **設定 → ターミナル** からコマンドラインインターフェースを開き、コマンドを実行して Kimi Claw を直接操作できます。

または、実行したいコマンドを自然な言葉で Kimi Claw に伝えるだけでもかまいません。Kimi Claw が代わりに実行します。

> 注: ターミナルとプラグインは同じ接続チャネルを共有します。OpenClaw ゲートウェイを再起動すると、ターミナルの接続は切断されます。

## コマンドリファレンス

### システム

| コマンド | 説明 |
|---------|-------------|
| `/help` | ヘルプ情報を表示します |
| `/status` | 現在のシステム状態を確認します |
| `/ping` | 接続が生きているかテストします |
| `/cron` | 定期タスクを管理します |
| `/config` | 設定を表示または編集します |
| `/new` | 新しい会話を開始します（現在のコンテキストをクリアします） |
| `/reset` | Kimi Claw をリセットします |
| `/compact` | 現在の会話コンテキストを圧縮します |
| `/stop` | 現在実行中のタスクを停止します |

### スキル

| コマンド | 説明 |
|---------|-------------|
| `/skills` | スキルの閲覧、インストール、管理を行います |

### 定期タスク

| コマンド | 説明 |
|---------|-------------|
| `/cron` | タスクスケジュールを表示・管理します |

### メモリ

| コマンド | 説明 |
|---------|-------------|
| `/memory` | 長期メモリを表示・管理します |

### 設定とデバッグ

| コマンド | 説明 |
|---------|-------------|
| `/config` | システム設定を表示または編集します |
| `/logs` | 実行時ログを表示します |
| `/debug` | 詳細な診断のためにデバッグモードを有効にします |
