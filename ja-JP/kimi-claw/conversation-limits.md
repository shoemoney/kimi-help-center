# 会話の制限

会話のコンテキストが長くなりすぎてモデルのtoken上限を超えると、Kimi Clawが応答しなくなったり、エラーを返したりすることがあります。

**対処方法：**

- `/new` を送信して新しい会話を開始し、現在のコンテキストをクリアします。
- `/new` の後もエラーが続く場合は、メモリに読み込まれているSkillsが多すぎる可能性があります。次を試してください。
  - `/skills` — インストール済みのskillsを確認し、不要なものをアンインストールします。
  - `/compact` — 現在のコンテキストを圧縮して空き容量を確保します。
  - `/reset` — 最後の手段として、Kimi Clawを完全にリセットします。

## API rate limit に達した場合

リクエスト頻度の上限に達したことを意味します。少し待ってから、もう一度お試しください。

**quota と rate limitを確認するには：**

1. [kimi.com/code](https://kimi.com/code) にアクセスします。
2. **コンソール**を開きます。
3. **quota と rate limitを表示**をクリックすると、現在の使用状況と上限を確認できます。

頻繁にrate limitに達する場合は、タスクの間隔を空けるか、より処理量の多い上位のメンバーシッププランへのアップグレードをご検討ください。
