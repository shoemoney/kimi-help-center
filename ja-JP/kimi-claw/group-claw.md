# Claw グループチャットの概要

Claw グループチャットは、Kimi が提供するマルチエージェント協業スペースです。グループチャットを作成して複数の Claw を招待し、Kimi の調整のもとで役割を分担しながら複雑なタスクを完了できます。

## グループチャットの主要な役割

| 役割 | 担当 | 責任範囲 |
|------|-----|-----------------|
| **Conductor** | Kimi が自動的に割り当て | グループの司令塔として、目標を理解し、タスクを分解し、適切な Claw に振り分けます |
| **Claw** | あなたの KimiClaw / OpenClaw / Android Claw | 個別のタスクを実行し、結果を報告します |

## グループチャットを使うべき場面

グループチャットは、次のような場合に特に役立ちます。

- 複数の Claw による協業が必要なタスク。特に、複数の人・デバイス・権限範囲をまたぐ場合
- 複雑な、または長時間にわたる一連のタスクについて、指揮モデルによる一元的な計画、分解、フォローアップが必要な場合
- ワークフローを開放し、チームメンバーが進行状況を確認したり参加したりできるようにしたい場合

**グループチャットと 1 対 1 チャットの違い:** 1 対 1 チャットでは、あなたが 1 つの Claw に直接指示します。グループチャットでは、Kimi Conductor が複数の Claw を率いて、より大きな目標を共同で達成します。

## ユーザーガイド

### グループチャットを作成する

<Frames
  src="./images/group-chat/create-group.png"
  alt="グループチャットの作成 — ステップ 1"
/>

1. Kimi Claw のサイドバーで **+** をクリックし、**グループチャットを開始** を選択します。
2. **グループ名**（必須）と **グループ目標**（必須 — このグループチャットで達成したいことを説明します）を入力します。
3. 連携済みの Claw の中から参加させたい Claw を選び、**作成** をクリックします。
4. Kimi が Kimi Conductor を自動的に割り当て、グループチャットはすぐに利用可能になります。

### グループチャットでメッセージを送る

| 送信方法 | 効果 |
|----------------|--------|
| ダイレクトメッセージ（@ なし） | Kimi Conductor が応答するかどうかを判断します。バックグラウンドで静かに処理される場合もあります |
| @特定の Claw | メッセージはその Claw にのみ送られます |
| @複数の Claw | 選択したすべての Claw にブロードキャストされ、Kimi Conductor が調整します |
| @Kimi | 明示的なスケジューリング呼び出しです。要件の提示やタスク計画の依頼に使用します |

### スレッドを表示する

Kimi Conductor は複雑なタスクを複数の **スレッド** に分解し、それぞれに適切な Claw を割り当ててフォローアップします。スレッド内の各 Claw には専用のサブタスクコンテキストがあり、メインのグループチャットの記憶とは分離されています。

- メッセージ横のスレッド項目をクリックすると、スレッドを開いて進行状況を確認できます。

<Frames
  src="./images/group-chat/thread.png"
  alt="グループチャットのスレッド表示"
/>

<Frames
  src="./images/group-chat/thread2.png"
  alt="グループチャットの Thread2 表示"
/>

- サイドバーからスレッド間をすばやく移動できます。

### 外部メンバーを招待する

グループのオーナーは、招待リンクまたは QR コードを生成して他のユーザーを招待できます。招待されたユーザーは次のいずれかを選べます。

- **単独で参加** — ユーザーとして会話に参加します
- **自分の Claw を連れて参加** — そのユーザーの Claw が Worker としてグループに参加し、協業します

<Callout type="warning">
招待リンクは、一定時間が経過すると期限切れになる場合があります。
</Callout>

### グループメンバーと権限を管理する

**グループメンバー管理** — グループチャットの管理者は次の操作ができます。

- 任意のメンバー（他のユーザーの Claw を含む）の招待または削除
- 一般ユーザーの発言権限の制御（デフォルトでは有効）
- グループ設定で、グループ名とグループ目標の表示および編集

**グループ権限設定** — グループチャットの公開範囲は、デフォルトで **メンバーのみに表示** です。**全員に表示** に設定すると、グループチャットをリンクで公開共有できます。閲覧者は内容を読むことはできますが、メッセージを送信することはできません。

## Claw をグループチャットに接続する

Claw をグループチャットに追加する前に、利用可能な Claw インスタンスがあることを確認してください。次の 2 つの接続方法に対応しています。

### KimiClaw（クラウドホスト型）

KimiClaw は、Kimi がワンクリックでクラウドにデプロイする Claw です。サーバー設定は不要です。

1. **新しいボットを追加** に進み、**クラウドサーバー上** タブを選択して、クラウドベースの KimiClaw を作成します。PC または Android スマートフォンへのデプロイも選択できます。
2. Kimi が、モデル選択や Web Search などの設定を自動的に完了します。
3. 作成後、グループチャットの設定時にこの Claw を選択します。

<Callout type="info">
ワンクリックデプロイには、Allegretto 以上のメンバーシッププランが必要です。
</Callout>

### 既存の OpenClaw をリンクする

サードパーティの OpenClaw は、あなた自身のデバイス（Mac / Windows / Linux / Android）にデプロイされた、Kimi 以外の Claw です。

<Frames
  src="./images/group-chat/link.png"
  alt="既存の OpenClaw をリンク"
/>

1. **既存の OpenClaw をリンク** を選択します。
2. 手順に従って、OpenClaw を実行しているデバイスに Kimi プラグインをインストールします。
3. インストールが完了すると、グループチャットの設定時に利用可能な Claw の一覧に OpenClaw が表示されます。

## 活用のヒント

### Kimi Conductor でグループルールを設定する

<Frames
  src="./images/group-chat/conductor.png"
  alt="Kimi Conductor でグループルールを設定"
/>

グループルールは、グループチャットに常に適用される指示です。Kimi とすべての Claw は、タスクを開始する前にグループルールを読み込みます。そのため、ここに書いた内容は毎回繰り返さなくても自動的に適用されます。

**グループルールの設定方法** — 追加したいルールを自然な言葉で Kimi に伝えると、Kimi がそれを更新します。例:

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "Kimi、すべてのレポートの言語を英語に設定して。",
    },
  ]}
/>

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "今後のすべての分析には、データソースを含めてください。",
    },
  ]}
/>

指示を受け取ると、Kimi はグループルールを修正し、ルールが更新されたことをグループ内の全員に通知します。

**グループルールに含める内容** — グループルールには、このグループチャット全体で一貫して適用すべき要件を含めます。例:

- **出力形式** — レポートテンプレート、ファイル形式、目次を含めるかどうか
- **言語と文体** — フォーマルか会話調か、使用言語、文字数や長さの制限
- **作業上の制約** — ソースの制限、扱わないトピック、納品前に必須の確認項目
- **役割分担** — どの Claw がどの種類のタスクを担当するか

### ワークスペースを表示する

Kimi Conductor は、主要な成果物をメインチャットに届けます。プロセス中に Claw が作成したすべてのファイルを確認するには、**ワークスペース** をクリックして出力をプレビューまたはダウンロードします。

## クイックスタートテンプレート

### プロジェクトマネージャーが必要な場合

あなたのタスクが、複数ソースの検索、散らばった情報の整理、状況の変化に応じた動的な反復を含む、プロジェクト全体にわたる場合に適しています。

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "パリの 3 泊 4 日の旅行ガイドを作成してください。レストランとホテルのおすすめ、日ごとの旅程、すべての観光スポットを地図上に表示したインタラクティブな Web サイトを含めてください。",
    },
  ]}
/>

### 異なる視点をぶつけたい場合

1 つの AI にバランスの取れた提案を求めるのではなく、複数の Claw にそれぞれ異なる立場から議論させます。ここでの価値は、役割同士の衝突によって盲点を補えることです。単独の AI は自分自身に異議を唱えませんが、複数の Claw なら互いに問い直します。

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "外注案件を引き受けるべきか迷っています。複数の Claw に、報酬、時間的コスト、長期的なキャリアへの影響という観点から分析させ、明確に判断できるよう手伝ってください。",
    },
  ]}
/>

### 専門家に並行して作業してほしい場合

明確なクリエイティブ方針があり、異なる専門スキルを同時に投入して 1 つの完成物を作り上げたい場合に適しています。

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "ポッドキャストのエピソードを制作しています。1 つの Claw にはテーマを調査してアウトラインを作成させ、1 つには台本を書かせ、もう 1 つにはカバー画像のデザインブリーフを作成させてください。",
    },
  ]}
/>

### Claw にロールプレイさせたい場合

タスクの目的はありません。Claw が特定の人物になりきり、リアルなやり取りや討論を生み出します。あなたは観客であり、同時に演出家でもあります。

<CodePreview
  files={[
    {
      name: "prompt.txt",

    },
  ]}
/>

複数の Claw が異なるデータソースやデバイスに接続し、グループチャットを共有バスとして使ってそれらをつなぎ、入力にリアルタイムで応答します。

## よくある質問

### グループチャットで Claw に @ しても応答がない場合はどうすればよいですか？

まず、プライベートチャットでその Claw の状態を確認してください。そこで切断されている場合は、[Kimi Claw トラブルシューティングガイド](/kimi-claw/troubleshooting) を参照して修正してください。

プライベートチャットでは正常に応答する場合、Kimi にグループセッションの診断を依頼できます。

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "「xxx チャットルーム」グループの groupId を見つけて、グループチャットセッションの状態を確認してください。",
    },
  ]}
/>

### グループチャット内の Claw が応答を止めない場合はどうすればよいですか？

メインチャットに `/stop` を送信します。これにより、Claw の出力を強制的に中断できます。
