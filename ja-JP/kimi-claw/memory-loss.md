# 記憶の消失とコンテキスト

## 昨日の会話が消えたのはなぜですか？

OpenClaw は毎日 **午前 4:00** に会話を自動的にリセットします。コンテキストが長くなりすぎることで、ハルシネーションや回答品質の低下が起きるのを防ぐためです。

リセット時刻を変更したい場合は、`config.yaml` でスケジュールを調整できます。

**おすすめの使い方：** 好みの設定、プロジェクトの詳細、繰り返し使う指示など、重要な情報は Kimi Claw に明示的に保存するよう伝えてください：_「これを Memory に覚えておいて。」_ Memory に保存された情報は、会話がリセットされても保持されます。

## Kimi Claw が記憶を失った？

毎日午前 4 時のリセットにより、アクティブな会話コンテキストは消去されます。**Memory** に保存されていなかった内容は失われます。

**対処方法：**
- 会話中に _「X を Memory に覚えておいて」_ と伝えると、Kimi Claw が長期保存領域に書き込みます。
- 保存済みの記憶は **ワークスペース → AGENTS.md → #MEMORY** で確認できます。

- 保存済みの記憶を確認・管理するには、いつでも `/memory` コマンドを使用できます。

## サブスクリプション終了後、記憶はどのくらい保持されますか？

Memory ファイルはワークスペース内に保存されており、いつでも表示またはダウンロードできます。

- メンバーシップの有効期限が切れた後も、クラウドインスタンスは **7 日間保持** されます。
- 7 日以内に更新すれば、記憶、設定、スキルなどすべてのデータが完全に復元されます。
- 7 日を過ぎると、インスタンスが回収され、データが完全に削除される場合があります。
- より簡単に移行できるよう、記憶のエクスポート／バックアップ機能を開発中です。
