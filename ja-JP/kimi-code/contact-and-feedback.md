# お問い合わせ・フィードバック

## フィードバック窓口

Kimi Code のご利用中に問題が発生した場合やご意見・ご要望がある場合は、以下の窓口からフィードバックをお寄せください。

### 方法 1: CLI から直接フィードバックを送信する

Kimi Code CLI のインタラクティブモードで `/feedback` コマンドを入力すると、フィードバックを送信できます。システムが現在の環境情報を自動で収集するため、問題の状況をより正確に伝えられます。

### 方法 2: GitHub Issues

[Kimi CLI GitHub Issues](https://github.com/MoonshotAI/kimi-cli/issues) にアクセスし、同様の問題がすでに報告されていないか検索してください。見つからない場合は、新しい Issue を作成し、発生した内容を詳しく記載してください。

### 方法 3: メールでフィードバックする

問題の報告は、[code@moonshot.ai](mailto:code@moonshot.ai) 宛てに Kimi Code チームへメールでお送りいただくこともできます。その際は、可能な範囲で以下の情報を含めてください。

- **問題の説明**: 発生した問題、または希望する機能を明確に記載してください
- **再現手順**: 問題を発生させる手順を順を追って記載してください
- **環境情報**: オペレーティングシステムと Kimi Code CLI のバージョン（`kimi --version` を実行して確認できます）
- **エラーログ**: エラーメッセージがある場合は、全文を貼り付けてください

### 方法 4: Feishu グループに参加する
QR コードをスキャンして Feishu グループに参加してください

## フィードバック送信前の確認事項

フィードバックを送信する前に、以下をご確認ください。

- Kimi Code CLI を最新バージョンに更新しているか（`kimi --version` を実行して確認できます）
- ネットワーク接続が正常で、`api.kimi.com` にアクセスできるか
- API Key が有効で、有効期限が切れていないか
- 作業ディレクトリが正しく、Kimi が関連ファイルへアクセスする権限を持っているか
