# Kimi Code メンバーシップガイド

<Callout type="info">
Kimi Code は、Kimi メンバーシッププランに含まれる開発者向け特典で、高性能な AI コーディング機能を提供します。この特典は、Kimi Code CLI、Claude Code、Roo Code などの対応ツールから利用できます。
</Callout>

## 主なメリット

| メリット | 説明 |
|-----------|-------------|
| **幅広い互換性** | Kimi Code CLI、Claude Code、Roo Code など、主流のコーディングエージェントで利用できます |
| **Standard / HighSpeed の2段階** | 同じモデルで2つの速度を提供。HighSpeed は Standard の約 5〜6 倍の出力速度で、必要に応じて切り替え可能 |
| **超高速レスポンス** | 生成速度は最大 100 トークン/s。コーディング効率を大きく高めます |
| **高頻度concurrency** | プランに応じて 5 時間あたり約 300～1,200 リクエスト、最大 30 の同時ストリームに対応します |

## クイックスタート

ご利用状況に合った手順を選んでください。

- **初めての方**: [kimi.com/code](https://kimi.com/code) にアクセスしてサインインし、コーディングプランに登録します。
- **既存の登録者**: コンソールにアクセスして APIキーを管理し、Kimi Code の利用を開始します。

## APIキーの取得

1. [Kimi コンソール](https://kimi.com/code) にサインインします。
2. **APIキー**ページに移動します。
3. **新しい APIキーを作成**をクリックします。
4. APIキーをコピーし、安全な場所に保管してください（作成時に一度だけ表示されます）。

<Callout type="warning">
APIキーを他人と共有したり、公開コードリポジトリにコミットしたりしないでください。
</Callout>

## デバイス管理

- 各アカウントは複数のデバイスで利用できます。
- **30 日間非アクティブ**なデバイス認証は自動的に期限切れになります。再認証するには、もう一度 `/login` を実行してください。
- 認証済みデバイスはコンソールで確認・管理できます。

## モデルの切り替え方法

**HighSpeed モデルが利用可能になりました。** Kimi Code は **Standard** と **HighSpeed** の2段階を提供します。両者は同じモデルをベースにコーディング能力は同一で、同じ Base URL・API Key・メンバーシップ特典を共有します。HighSpeed は Standard の約 **5〜6 倍の出力速度**を実現し、即時応答や高速な反復が必要な場面ではワンクリックの切り替えでより快適なコーディング体験が得られます。主な違い：

| 項目 | Standard | HighSpeed |
| --- | --- | --- |
| モデル ID | `kimi-for-coding` | `kimi-for-coding-highspeed` |
| 出力速度 | 基準 | Standard の約 5〜6 倍 |
| クレジット消費 | 基準 | Standard の約 3 倍 |
| コーディング能力 | フル | Standard と同一 |
| 最適な用途 | 日常のコーディング作業 | 即時応答・高速な反復 |
| メンバーシップ | すべての Kimi Code メンバーが利用可 | [Allegretto](https://www.kimi.com/membership/pricing) 以上のプランが必要 |

対象モデルへの切り替え方法：

- **公式 Kimi Code CLI**：セッション内で `/model` と入力すると、設定を変更せずに Standard と HighSpeed を直接切り替えられます。
- **Kimi Code for VS Code**：入力バーのドロップダウンメニューから対象モデルを選択します。HighSpeed がまだ表示されない場合は、VS Code を再起動するか拡張機能を再インストールしてください。
- **サードパーティツール**：ツールの Model ID を対象モデルに設定します。その他の設定は変更不要です。各ツールでの場所は [サードパーティのコーディングエージェントでの利用](/kimi-code/third-party-agents) を参照してください。

<Callout type="info">
- **安定したモデル ID**：どちらの ID も安定した識別子で、モデルの改善に合わせてバックエンドが対応モデルを更新します。クライアント設定の変更は不要です。
- **正確に入力**：HighSpeed の ID は必ず `kimi-for-coding-highspeed` にしてください。入力ミスや別の値を設定すると、リクエストは標準の `kimi-for-coding` に静かにフォールバックします。エラーは出ませんが、高速化もされません。
- **権限がない場合は 401**：プランに HighSpeed アクセスが含まれていない場合、呼び出しは `401` を返します。Allegretto 以上にアップグレードしてください。
</Callout>

<Callout type="tip">
**全体の所要時間が 5〜6 倍速く感じないのはなぜ？** 「5〜6×」は**モデルの出力速度**（テキスト／コードの生成速度）を指します。コーディングタスクの総所要時間は「モデル出力 + ツール呼び出し（ファイルの読み書き、コマンド実行、Web 検索など）+ スクリプト実行」で構成されます。ツール呼び出しやスクリプト実行にかかる時間はプロジェクトやコマンドに依存し、HighSpeed はこの部分を変えません。したがって全体で 5〜6 倍に感じない場合は、通常そのターンでツール呼び出し／スクリプト実行が大部分を占めたためであり、モデルの生成が遅くなったわけではありません。
</Callout>
