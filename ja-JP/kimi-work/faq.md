# Kimi Work よくある質問

## Kimi Work と Web 版の違いは何ですか？

Kimi の Web アプリは、手早いチャットや質問に最適です。一方、Kimi Work は深いワークフローのために設計されたローカル Agent です。ローカルフォルダの読み取りと処理、WebBridge による自律的な Web 操作、バックグラウンドでの Python コード実行、スケジュールタスクの実行に対応します。いわば、システムレベルで働くデジタル従業員です。

## ローカルファイルにアクセスするとき、Kimi Work はどのようにプライバシーを保護しますか？

ファイルに対する権限は、すべてあなたが管理できます。Kimi Work には権限管理機能があり、認可方法を選択できます：

- **許可をリクエスト**: 操作前に認可を求めます — Kimi がローカルファイルを変更、上書き、またはその中でコードを実行する前に、明示的な承認を求めます；
- **すべて許可**: 認可を求めずに直接実行します。

「許可をリクエスト」を選ぶと、あなたの同意なしに何かが実行されることはありません。

## WebBridge（ブラウザ自動操作）は具体的に何をしてくれますか？

WebBridge により、Kimi は人と同じようにブラウザを操作できます。特定のサイトで最新ニュースを確認して要約したり、過去の株価データを取得してローカルの Excel に保存したりできます。クリック、スクロール、データ抽出を自律的に行うため、手作業にかかる何時間もの時間を節約できます。

## スケジュールタスクでは何ができますか？コンピューターがスリープ中でも実行されますか？

内蔵の Cron スケジューラは、LLM Agent の呼び出し、Python/Shell の実行などに対応しています。タスクは毎日、毎時、または条件に応じてトリガーできます。夜間でも途切れなくタスクを実行するには、設定で「コンピューターをスリープさせない」オプションをオンにするだけです。
