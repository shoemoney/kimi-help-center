# プラグインセンター

## 内蔵の専門データベースプラグイン

Kimi Work には、金融・法律・学術分野に対応した専門データベースプラグインが内蔵されています。国内外のデータを幅広く網羅し、プロフェッショナルが信頼できる権威ある情報源として活用できます。

- **金融データ**: Wind Financial Data Service、Hundsun Gildata financial data、S&P Global Market Intelligence、グローバル金融データベース、IMF（国際通貨基金）データベース、Straight Flush（Tonghuashun）など
- **企業・法務**: Tianyancha、Huayu Yuandian など

## 厳選された外部アプリプラグイン

プラグインセンターでは、公式に厳選された任意のプラグインを利用できます。主な例は次のとおりです。

- **オフィスコラボレーション**: Baidu Netdisk、DingTalk、Feishu、WPS
- **デザイン**: Canva
- **ノート**: Notion
- **Web 開発**: Cloudflare
- **その他**: Kimi Computer Use（AI がデスクトップを操作し、システムレベルの作業を実行）、GitHub、Neon（クラウド PostgreSQL データベースプラットフォーム）、Supabase（オープンソースのバックエンド／データベースプラットフォーム）など

プラグインをインストールすると、Kimi Work からこれらの一般的なオフィスツールを直接操作できるようになります。繰り返しの作業も、自然言語で一度指示するだけで実行できます。

## 有効化する方法

1. 最新版の Kimi デスクトップクライアントを開き、左サイドバーで「Work」モードに切り替えて、「プラグイン」をクリックし、プラグインセンターに入ります。
2. 「インストール済み」と「おすすめプラグイン」から、必要なプラグインを探してインストールします。
3. 入力ボックスにスラッシュ「/」を入力し、呼び出したいプラグインを選択します。
