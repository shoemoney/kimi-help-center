# リリースノート

このページでは Kimi Work のバージョン更新内容（新機能・変更・修正）を記録し、継続的に更新します。最新版のダウンロード：[kimi.com/products/kimi-work](https://www.kimi.com/products/kimi-work)

## 3.2.6（2026-09-07）

**変更**

- プラグイン詳細ページに MCP 接続状態の表示と接続管理を追加
- アプリ終了前に、実行中のスケジュールタスクを確認するようになりました

**修正**

- 設定の特定のページを開いた後に「戻る」をクリックしても反応しない問題を修正
- macOS で上書きインストールが誤ってブロックされる問題、Windows で CAD ファイルが誤ってメモ帳で開かれる問題を修正
- ダークモードでの一部ページの配色、Launcher のメッセージ重複、DOCX プレビューの幅適合などの問題を修正
- いくつかのバグを修正し、一部の操作体験と安定性を改善しました

## 3.2.5（2026-09-04）

**新機能**

- リモートコントロール機能を追加：スマートフォンからデスクトップの Kimi Work を操作できます
- Apps 機能を追加：Agent の Web 操作能力と効果の可視性を向上
- 会話内検索機能を追加：会話内で記録をすばやく検索できます

**変更**

- プラグイン／スキルマーケットを更新：表示ロジックを最適化し、プラグイン／スキル検索に対応
- 設定センターを刷新：Chat と Work モード間で互換性を確保

**修正**

- 一部のユーザーでログイン状態の表示が異常になる問題を修正
- いくつかのバグを修正し、一部の操作体験と安定性を改善しました

## 3.2.4（2026-08-31）

**変更**

- Web 検索やローカルファイルなどの情報源がメッセージ応答内で引用表示される際の表示を最適化
- メッセージ応答のフォントサイズと行間を最適化

**修正**

- ダークモードでの一部の体験上の問題を修正
- Windows 版のプロセス監視を最適化
- いくつかのバグを修正し、一部の操作体験と安定性を改善しました

## 3.2.3（2026-08-28）

**修正**

- デスクトップペットの細部を改善：ウィンドウの動作を最適化し、言語がアプリの切り替えにリアルタイムで追随するようになりました
- メッセージのエラー後に編集して再送信する際の会話状態の一貫性の問題を修正

## 3.2.2（2026-08-26）

**新機能**

- デスクトップペットを追加：Kimi がデスクトップペットとして寄り添い、インタラクションできます
- Slash ショートカットコマンドを追加：入力ボックスで compact（コンテキストを圧縮）、fork（会話を分岐）、goal（目標）コマンドに対応
- 実行権限に「デフォルト」オプションを追加：グローバルに「デフォルト」「手動で許可」「すべて許可」の 3 段階の権限が利用可能になりました

**変更**

- 内蔵ブラウザーの Agent コントロールをデフォルトで有効化
- 「チャット」エリアの会話はルートディレクトリを共有しなくなり、会話ごとに専用の作業ディレクトリが作成されます

**修正**

- 最初のメッセージ送信時に空の状態が一瞬表示される問題を修正
- いくつかのバグを修正し、一部の操作体験と安定性を改善しました

## 3.2.1（2026-08-21）

**新機能**

- グローバル Launcher を追加：グローバルショートカットで、いつでもどこでもデスクトップのフローティングカプセル入力ボックスを呼び出せます
  - 呼び出し時に Finder / エクスプローラーで選択中のファイルを自動で取り込み、画像の貼り付け、添付ファイルの追加、スクリーンショットのドラッグに対応
  - 「/」でプラグインとスキルのメニューを呼び出し（ピンイン検索対応）、ワークスペースを選択できます
  - ショートカットを押したまま話すと音声入力でき、送信後はミニカプセルに折りたたまれ、ワンクリックでメインアプリに戻って回答を確認できます
- メッセージキューを追加：Agent の回答中もメッセージを送り続けられ、新しいメッセージは自動でキューに入ります。ドラッグでの並べ替え、編集、削除、詳細プレビューに対応
- Work 入力ボックスで音声ディクテーションに対応：マイクをクリック、またはショートカットを押したままでディクテーションを開始でき、中国語と英語の混合認識に対応

**変更**

- メッセージ通知ロジックを更新：設定でメッセージ通知ルールを切り替えられます

**修正**

- 待機時の消費電力を最適化し、アプリのアイドル時のバックグラウンドリソース使用量を削減
- macOS で Dock アイコンが消える問題を修正
- いくつかのバグを修正し、一部の操作体験と安定性を改善しました

## 3.2.0（2026-08-19）

**新機能**

- Agent 内蔵ブラウザーを追加：ブラウザータブは会話に紐付けられてプレビューエリアに表示され、Agent がクリックや入力などの操作をブラウザー上で直接実行できます。Mac 版では、ローカルの Chrome から Cookie をインポートして既存のログイン状態を再利用できます（デフォルトはオフで、設定で有効化できます）
- 16 言語のローカライズ：クライアントの対応言語が中国語・英語の 2 言語から 16 言語に拡大されました

**変更**

- Kimi WebBridge のプラグイン化：実ブラウザー制御がプラグイン形式になりました。デフォルトはオフで、設定で有効化できます
- ダッシュボードの一覧ページを廃止し、上部のタブバーで切り替える方式に変更しました
- ダッシュボードがプレビューエリアのタイプになりました：会話のプレビューエリアでダッシュボードを開くことができ、複数のダッシュボードを並行して開けます

**修正**

- メッセージのストリーミング描画をアップグレード：長い返答がよりスムーズに表示されるようになりました
- いくつかのバグを修正し、一部の操作体験と安定性を改善しました

## 3.1.8（2026-08-11）

**新機能**

- メッセージ履歴ナビゲーション：長い会話の右側に新しいメッセージナビゲーションバーが表示され、過去のメッセージへすばやくジャンプできます
- 会話の分岐：任意のターンから新しいブランチを開始して探索を続けられます。元の会話の履歴も引き継がれます
- 編集と巻き戻し：直前のメッセージを編集して、返答を再生成できます
- プロジェクトフォルダ：会話をプロジェクトに移動・移出でき、プロジェクトをサイドバーのピン留めエリアに固定できます
- 透明なファイル編集：Agent がファイルを変更すると差分サマリーカードが生成され、変更を行ごとに確認してワンクリックでロールバックできます。ワークスペースのファイルはディスク上で変更されると自動更新されます
- スキルの発見と作成：Work 内でカスタムスキルを発見・作成でき、スキル検索にも対応しました
- デスクトップに固定したダッシュボードコンポーネントに、常に最前面表示の切り替えスイッチが追加されました

**変更**

- 新しい独立した会話ウィンドウで Chat に対応しました
- 入力欄の長すぎるユーザーメッセージが折りたたまれるようになりました

**修正**

- Windows での PDF ファイルリンクのプレビューを修正しました。ダークモードで Work 設定画面が白く点滅しなくなりました。Word クリップボードからの貼り付けで、画像添付ではなくテキストとして復元されるようになりました
- いくつかのバグを修正し、一部の操作体験と安定性を改善しました
