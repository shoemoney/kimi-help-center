# サブスクリプションの解約

自動更新はいつでも解約できます。解約後も、現在の請求期間が終了するまでは会員特典をご利用いただけます。

## 自動更新を解約するには？

最初に登録した方法に応じて、該当する手順をお選びください。

### Kimi のウェブサイトまたはアプリから

1. Kimi（ウェブまたはモバイル）にサインインします。
2. **設定 → サブスクリプション** に移動します。
3. **自動更新を解約** または **サブスクリプションを管理** をクリックします。
4. 解約を確定します。

### Apple ID（iOS / Mac）経由

1. iPhone で **設定** を開き、画面上部にある自分の名前をタップします。
2. **サブスクリプション** をタップします。
3. **Kimi** を探し、**サブスクリプションをキャンセル** をタップします。

Mac の場合：App Store を開く → プロフィールをクリック → **アカウント設定** → **サブスクリプション** で Kimi を探す → **管理** → **サブスクリプションをキャンセル**。

### Google Play（Android）経由

1. **Google Play Store** アプリを開きます。
2. プロフィールアイコンをタップ → **お支払いと定期購入** → **定期購入**。
3. **Kimi** を探し、**定期購入を解約** をタップします。
4. 画面の案内に従って確定します。

> 解約後も、有料期間が終了するまでは特典をご利用いただけます。Kimi のサブスクリプションページからいつでも再登録できます。
