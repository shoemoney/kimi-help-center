# お問い合わせ

お困りですか？お問い合わせ方法をご案内します。

## お支払い・メンバーシップのサポート

**Email:** membership@moonshot.ai

次のようなご相談に適しています：

- 購入後にcreditが反映されない
- 支払い・請求に関する問題
- プランのアップグレード、ダウングレード、解約
- 請求書の発行依頼

有料メンバーには優先して回答します。問題をより早く解決できるよう、アカウントのメールアドレスと関連するスクリーンショットを添えてご連絡ください。

## 一般サポート

**Email:** support@moonshot.ai

次のようなご相談に適しています：

- 製品機能に関する質問
- Kimi の利用中に発生した技術的な問題
- アカウントに関する質問（請求以外）
- 機能リクエストやフィードバック

## API サービスサポート

**Email:** api-service@moonshot.ai.
[Kimi OpenPlatform Community](https://forum.moonshot.ai/)もご利用いただけます。

次のようなご相談に適しています：

- API に関する質問
- Kimi API の利用中に発生した技術的な問題
- 機能リクエストやフィードバック

## 製品内フィードバック

Kimi 内から直接フィードバックを送信することもできます：

- **Web:** 左下の **フィードバック** ボタンをクリックし、問題の内容を入力して送信してください。
- **Mobile:** **プロフィール → ヘルプとフィードバック → フィードバックを送信** に進んでください。

製品内からの報告には、ご利用のデバイスやアカウントに関する情報が自動的に添付されるため、問題の診断をより迅速に行えます。
