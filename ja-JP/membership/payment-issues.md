# お支払いに関する問題

請求やお支払いでお困りですか？よくあるケースと解決方法をご案内します。

## 登録したのにメンバーになっていない場合

決済手続きを完了したにもかかわらず、メンバーシップが有効にならない場合は、以下をご確認ください。

| 問題 | 解決方法 |
|-------|----------|
| **承認 ≠ 請求確定** | お支払い方法によっては、別途承認手続きが必要な場合があります。銀行口座またはカードの明細で、実際に請求が確定しているか確認してください |
| **処理の遅延** | お支払いの反映には数分かかることがあります。少し待ってからページを更新してください |
| **別のアカウント** | 決済時に使用したものと同じ Kimi アカウントでサインインしていることを確認してください |

<Callout type="info">
請求が確定しているのにメンバーシップが有効にならない場合は、お支払いの領収書を添えて **membership@moonshot.ai** までメールでご連絡ください。
</Callout>

## お支払いに失敗した場合

よくある原因と対処方法は以下のとおりです。

| 原因 | 対処方法 |
|-------|-----|
| **残高不足** | アカウントまたはカードに十分な残高があることを確認してください |
| **カードの利用限度額** | 銀行により、1回あたりまたは1日あたりの利用限度額が設定されている場合があります。銀行に問い合わせるか、別のお支払い方法をお試しください |
| **ネットワークの問題** | インターネット接続を確認して、もう一度お試しください |
| **決済事業者のメンテナンス** | 決済事業者が一時的に利用できない場合があります。時間をおいて再度お試しください |
| **不正利用防止によるブロック** | セキュリティ上の理由で、銀行が取引をブロックしている場合があります。銀行に連絡し、請求を承認してください |

<Callout type="info">
問題が解決しない場合は、エラー画面のスクリーンショットを添えて **membership@moonshot.ai** までメールでご連絡ください。
</Callout>

## 覚えのない請求がある場合

Kimi からの覚えのない請求がある場合は、以下をご確認ください。

1. **サブスクリプションを確認** — Kimi にサインインし、有効なサブスクリプションを確認してください。自動更新プランに加入していたことを忘れている可能性があります
2. **トライアルからの移行** — 無料トライアルを開始し、終了前にキャンセルしなかった場合、システムにより自動的に有料サブスクリプションへ移行されます
3. **支払い承認を確認** — Apple ID、Google Play、またはカードの設定で、Kimi の定期請求がないか確認してください
4. **必要に応じてキャンセル** — 今後の請求を停止するには、[サブスクリプションをキャンセル](/membership/membership-cancel-subscription)をご覧ください

<Callout type="warning">
請求が不正なものだと思われる場合は、ただちに **membership@moonshot.ai** までメールでご連絡ください。確認いたします。
</Callout>
