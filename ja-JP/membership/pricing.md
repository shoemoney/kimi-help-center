## credit配分

Kimiのメンバーシップ機能はすべて1つのcreditプールを共有し、token使用量に応じて計測されます。Kimi Codeには、Kimi Codeのみに適用される独自の5時間ごと／週ごとのrate limitもあり、他の機能には影響しません。ChatではK2.6を無料で利用でき、creditは消費されません。上位プランほどcreditプールが比例して大きくなり、より頻繁で複雑なワークフローに対応できます。詳しくは[Credit更新・利用ルール](/membership/update-rules)をご覧ください。

## credit に関するよくある質問

### credit の使用状況はどこで確認できますか？

- **Web**: 左下のアバターをクリック → 設定 → サブスクリプション
- **アプリ**: マイページ → メンバーシッププラン → サブスクリプション

現在の credit 残高（％表示）、次回のリフレッシュ日時、直近1,000件の利用履歴（利用日時、機能、消費割合を含む）を確認できます。

<Callout type="tip">
利用状況の反映には多少の遅延が生じる場合があります。実際の credit 表示を参考にしてください。
</Callout>

### credit を使い切ってしまったらどうなりますか？

実行中のタスクはそのまま正常に完了します。新しいタスクを開始しようとすると、credit 不足の通知が表示されます。この場合、以下の方法をご利用いただけます。

- 毎月自動的に credit がリフレッシュされるのを待つ（Kimi Code 独自の5時間ごと／週ごとの利用上限も自動的にリセットされ、Kimi Code のみに影響します）
- 上位のメンバーシッププランにアップグレードして、より多くの credit を利用する
- [Extra Usage パック](/membership/membership-extra-usage) を購入する：有効化すると従量課金となり、credit のリフレッシュを待つ必要がなくなります
- 公式キャンペーンに参加してボーナス credit を獲得する

### すべての credit を1つの機能に使うことはできますか？

はい、可能です。すべてのメンバーシップ機能は1つの credit プールを共有しており、自由に配分できます。ただし、1つの機能で credit を使い切ると、ほかの機能にも影響が及ぶ点にご注意ください。なお、Kimi Code には独自の5時間ごと／週ごとの rate limit があり、これは Kimi Code のみに適用されます。

### 毎日 16:00 に差し引かれる「Claw-云主机」の 0.6% の料金は何ですか？

これは、Kimi Claw クラウドホストのサンドボックス実行コストです。Kimi Claw はクラウド上にデプロイされた OpenClaw であり、Claw を呼び出すたびに、システムは分離されたクラウドサンドボックスを起動して、コードの実行、ブラウザの操作、ツールの呼び出しを行います。サンドボックスは「無料のスタンバイ」ではなく、実行時間とリソース消費量に応じて継続的に課金されます。タスクを実行していないときでも、デプロイ済みのクラウドホストはランタイム環境とデータを保持しているため、メンバーシップ credit の約 0.6% が毎日差し引かれ、16:00 に精算されます。

しばらく Kimi Claw を利用する予定がない場合は、まず memory、soul、workspace などの重要なファイルをローカルに保存してから、クラウドホストを削除してください。削除後は課金されなくなり、いつでも再デプロイできます。

### 「Agent Website - Cloud Service」の 0.08% の料金は何ですか？

これは、Agent で公開したウェブサイトのクラウドサービス料金です。公開されたウェブサイトは、オンラインでアクセス可能な状態を維持するためにクラウドリソースを継続的に占有するため、メンバーシップ credit の約 0.08% が差し引かれます。ウェブサイトをオンラインで公開しておく必要がなくなった場合は、「Unpublish」をクリックして課金を停止してください。
