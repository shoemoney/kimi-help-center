# Kimi サポートへの問い合わせ方法

お問い合わせ内容に合った窓口を選ぶと、より迅速にサポートを受けられます。

## 有人サポート（WeCom）

WeChat 公式アカウント「**月之暗面Kimi**」をフォローし、下部メニューの「**お問い合わせ**」→「**サポートに連絡**」をタップすると、公式 WeCom 有人サポートチームを確認できます。

## メールサポート

| 問い合わせ内容 | メールアドレス |
|---|---|
| **有料会員に関する問題**（特典が付与されない、決済金額の異常、アップグレードまたはダウングレード、発票・請求書など） | membership@moonshot.ai |
| **一般的な質問**（製品機能に関する問い合わせ、技術的な問題、有料会員以外のアカウントに関する問題、機能の提案） | support@moonshot.ai |
| **アカウントの異議申し立て／苦情・通報** | support@moonshot.ai |
| **Kimi API 開発者サポート** | [Kimi Open Platform](https://platform.kimi.ai/) にログインし、サポート連絡先と開発者コミュニティをご確認ください |

<Callout type="tip">
メールでお問い合わせの際は、アカウント情報（登録済みの携帯電話番号またはメールアドレス）と、問題が確認できるスクリーンショットを添付してください。有料会員からのメールは優先的に対応し、問題の特定をより迅速に進めます。
</Callout>

## 製品内フィードバック

Kimi 内から直接フィードバックを送信することもできます。調査のため、システムが端末情報とアカウント情報を自動で添付します。

- **Web**: 左下の「アカウント → ユーザーフィードバック → ヘルプとフィードバック」をクリックします。
- **Mobile App**: 「アカウント → 設定 → フィードバック」に進みます。

## 回答品質に関するフィードバック

回答に満足できない場合は、回答の下にある「👎」をクリックし、問題の種類と具体的な内容を簡単にご記入ください。いただいたフィードバックは、品質向上に役立てています。

<Callout type="info">
会員関連の問題については、[会員に関する問い合わせ先](/membership/membership-contact)もご確認いただけます。メディアからのお問い合わせは、pr@kimi.com までメールでご連絡ください。
</Callout>
