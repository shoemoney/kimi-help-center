# 会話データはモデルのトレーニングに使用されますか？

安全な暗号化技術で処理され、厳格に匿名化され、特定の個人を再識別できないことを前提に、プラットフォームはユーザーの入力データ、指示、生成された応答をモデルトレーニングに使用し、モデルの精度と製品体験の向上を図る場合があります。

会話データをトレーニングに使用してほしくない場合は、[support@moonshot.ai](mailto:support@moonshot.ai) までカスタマーサポートにご連絡のうえ、ご希望をお伝えください。ご本人確認のうえ、お客様のコンテンツをモデルトレーニングに使用することを停止いたします。
