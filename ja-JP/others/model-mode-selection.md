# 選び方：K2.6 / K3 / K3 Cluster、思考強度、Agent

Kimi は、質問内容に応じてインターネットを使うかどうかを自動で判断するため、手動で切り替える必要はありません。選ぶ必要があるのは **モデル** と **思考強度** です。複雑なタスクでは、**Agent** や **Agent Cluster** も利用できます。

## 3 つのモデル選択肢

入力ボックス上部のモデル切り替えから選択します。

| モデル | 思考強度 | 向いている用途 | credit |
|---|---|---|---|
| **K2.6** | Standard / Advanced | すばやい会話や Q&A。応答速度を重視する場合 | **メンバーシップ credit は消費されません** |
| **K3** | Standard / Advanced / Extreme | 会話と Agent タスク。総合能力が最も高いモデル | credit から課金 |
| **K3 Cluster** | Standard / Advanced / Extreme | 大規模検索、バッチ処理、大量タスクの一括完了 | credit から課金 |

- **K3** は、`.pptx`、`.docx`、`.xlsx`、`.pdf` などの編集可能なドキュメントを最初から最後まで生成できます。**K2.6** は、すばやい Q&A 向けに最適化されており、PPT のアウトライン、Word の本文、コードなど、テキストのみを出力します。
- **画像 / 動画 / 音声生成** を行うには、「+」→ Plugins をクリックし、該当する機能を選んで **K3** と組み合わせて使用します。

## 思考強度：Standard / Advanced / Extreme

思考強度を高くするほど、モデルはより十分に推論し、一般的にはより賢い結果が得られます。ただし、その分 **消費する token も増えます**。

- **速度と credit 消費の少なさ** を重視する場合 → **Standard** を選択します。
- 複雑な分析や難しい問題で **より強い推論** が必要な場合 → **Advanced** または **Extreme** を選択します（Extreme は K3 / K3 Cluster で利用できます）。

## Agent と Agent Cluster

- **汎用 Agent**：Web サイト生成、PPT 作成、Deep Research（深度調査）、ドキュメントやスプレッドシートの処理などを含め、タスクを自動で計画し完了します。
- **Agent Cluster**：4,000 件を超える並列ツール呼び出しに対応し、最大 300 の sub-agents（Sub-agents）を自律的に並列調整できます。**大規模検索、長文執筆、バッチ処理** などの大規模タスクに最適です。

## シナリオ別の選び方

- **すばやい Q&A と日常的な会話** → K2.6（credit は消費しません）。
- **複雑な会話、ドキュメント作成 / PPT・スプレッドシート作成 / 複数ステップのタスク** → K3。
- **大規模検索、バッチ処理、非常に長い文章の執筆** → K3 Cluster。
- **credit を節約したい場合** → K2.6 を使うか、思考強度を「Standard」に設定します。

## FAQ

### 「Thinking Mode」はもう使えませんか？
Kimi では「会話」と「Agent」が 1 つの体験に統合されたため、別々のモードではなくなりました。「思考」は現在、**モデルと思考強度の選択** によって制御されます。たとえば K3 で高い思考強度を使うと、より丁寧な推論が得られます。

### K2.6 と K3 の違いは何ですか？
K2.6 はすばやい Q&A 向けに最適化されており、応答が速く、メンバーシップ credit を消費しません。K3 は総合能力が最も高く、複雑な会話や Agent タスクに優れ、編集可能なドキュメントを最初から最後まで生成できます。また、credit から課金されます。

### K3 と K3 Cluster の違いは何ですか？
K3 は通常の会話や Agent タスクに適しています。K3 Cluster は、数千件のツール呼び出しと数百の sub-agents による大規模な並列処理を使い、**大規模検索、バッチ処理、非常に長い文章の執筆** といった大量タスクに対応します。

### 1 回のターンでどのくらいの内容を処理できますか？
K2.6 は、1 ターンあたり約 128K tokens のコンテキスト（中国語でおよそ 50,000〜60,000 文字）に対応しています。K3 は 100 万 token のコンテキストウィンドウを提供します（最上位メンバーシップ特典が必要です）。詳しくは、[会話が中国語 200,000 文字を超えた場合はどうすればよいですか？](/others/chat-issues) を参照してください。
