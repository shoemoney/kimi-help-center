# アカウントとプロフィール設定

## 連携済みメールアドレスやサインイン方法は変更できますか？
はい。次の手順で進みます：
**Kimiアプリ** → **プロフィール** → **設定** → **アカウントセキュリティ** → **メールアドレス** → **変更**
画面の案内に従って現在のメールアドレスを確認し、新しいメールアドレスを入力して確認してください。
## もともとのサインイン方法を使えなくなった場合は？
[support@moonshot.ai](mailto:support@moonshot.ai) までメールでお問い合わせください。必要な所有権の確認が完了次第、アカウント移行をサポートします。
## 認証コードが届かない場合は？
以下の方法をお試しください：
1. 入力したメールアドレスまたは電話番号が正しいことを確認してください。
2. 認証コードの到着には数分かかる場合があります。しばらくお待ちください。
3. 5分経っても届かない場合は、「再送信」をクリックして新しいコードをリクエストしてください。

<Callout type="warning">
**注**: 現在、対応地域の電話番号とメールアドレスのみご利用いただけます。VoIP番号と固定電話番号には対応していません。
</Callout>

## プロフィールとアバターを編集するには？
次の手順で進みます：
**Kimiアプリ** → **プロフィール** → **設定** → **個人情報** → 名前、自己紹介、またはアバターを編集 → **保存**

<Callout type="warning">
**注**: アバターと表示名は、**30日間で最大10回まで**変更できます。変更のタイミングにご注意ください。
</Callout>
