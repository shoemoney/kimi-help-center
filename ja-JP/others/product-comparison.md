# Kimi、Kimi Work、Kimi Code、Kimi Clawの違いは？どれを使えばよいですか？

Kimiには、すぐに使えるオンラインアシスタントに加え、ユーザーや利用シーンに合わせて設計された複数のプロダクトがあります。いずれもKimiの中核機能を備えており、主な違いは**どこで使うか、誰に向いているか、何が得意か**です。

## 早見表

| Product | What it is | Best for / scenarios | Where to use it |
|---|---|---|---|
| **Kimi**（Web / アプリ） | チャットとエージェントを組み合わせたオンラインAIアシスタント | 日常的なQ&A、文章作成、検索、Webサイト構築 / PPT / ドキュメント・シート、Deep Researchなど | Web、モバイルアプリ |
| **Kimi Work** | ナレッジワーカー向けの**ローカルエージェント**（デスクトップ） | コンピューター上のローカルファイルを扱う作業、デスクトップアプリをまたいだタスク自動化、長時間タスクの実行 | Mac / Windowsクライアント |
| **Kimi Code** | **開発者**向けのコーディングアシスタントスイート | コード作成とコードベースの保守 | CLI、VS Code拡張機能 |
| **Kimi Claw** | **デプロイ不要のクラウド自動化**プラットフォーム | 7×24で常時稼働するクラウド自動化、Feishu / WeChatなどと連携するボット | クラウド（サーバー不要） |

## どれを使えばよいですか？

- **日常的なチャット、文章作成、検索、KimiによるWebサイト・PPT・シート作成、Deep Researchを使いたい場合** → **Kimi**（Web / アプリ）を使用します。
- **Kimiにコンピューター上のローカルファイルを読み書きさせたい、複数のデスクトップアプリをまたいで自動化したい、長時間タスクを実行したい場合** → **Kimi Work**（デスクトップ）を使用します。
- **開発者で、主にコード作成やプロジェクト保守の支援が必要な場合** → **Kimi Code**を使用します。
- **自動で稼働し続け、Feishu / WeChatなどのプラットフォームにも接続できる常時稼働のクラウドボットが欲しい場合** → **Kimi Claw**を使用します。

<Callout type="tip">
Kimiのオンライン体験では、「チャット」と「エージェント」がすでに一体化されています。両者を切り替える必要はありません。Kimi Workデスクトップアプリには、「Work」（成果物の作成に重点を置いたエージェントモード）と「Chat」（すばやい会話）の2つのモードがあります。
</Callout>

## どのメンバーシップを選べばよいですか？

メンバーシップ特典はKimiアカウントに紐づきます。すべてのメンバーシップ機能（チャット、エージェント、Deep Research、Kimi Codeなど）は**同じcreditプールを共有**します。また、Kimi CodeにはKimi Codeにのみ適用される独自の週5時間 / rate limitがあります。プランの詳細と料金については、[メンバーシップ登録ページ](/membership/membership-pricing)をご覧ください。

主な用途が**日常業務 + ときどき発生するタスク**であれば、適切なKimiメンバーシッププランでWeb / アプリ / Kimi Workのほとんどのシーンをカバーできます。**頻繁にコードを書く**開発者の方は、Kimi Codeの特典にも特に注目するとよいでしょう。
