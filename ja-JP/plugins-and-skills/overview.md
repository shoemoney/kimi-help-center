# Kimi プラグインとは？

プラグインは外部ツールを Kimi に接続し、アプリやサービスを使ってタスクを完了できるようにする仕組みです。プラグインをインストールすると、Kimi はタスクの実行中に対応するサードパーティ機能を直接呼び出せます。たとえば、金融データの照会、オフィスソフトの操作、デザインツールの利用などです。特定のプラグインを明示的に指定して使うこともできますし、Kimi が適切と判断したときに自動で呼び出すこともあります。

## Kimi プラグインとは

Kimi Plugin は [Kimi Code のプラグイン定義](https://www.kimi.com/code/docs/kimi-code-cli/customization/plugins.html#plugin-manifest) に従っており、以下のコンポーネントを 1 つ以上含めることができます。

| コンポーネント | 役割 |
| --- | --- |
| Skills | タスクを完了するために必要な知識、手順、使用方法のガイドを提供する |
| MCP | 外部のソフトウェア、サービス、データベース、API に接続する |
| Agents | 複雑なタスクを専門のサブ Agent に委任する |
| Hooks | 特定のイベントが発生したときに定義済みのアクションを自動実行する |
| Commands | 明確で再利用可能なコマンド形式の入口を提供する |
| System Prompt | プラグインが有効な間、メインの Agent にシステム指示を追加する |

現在、Kimi の Web 版がサポートするのはプラグイン内の MCP と Skills です。Kimi Work と Kimi Code は上記の完全なプラグイン定義に準拠し、より完全なプラグインコンポーネントの組み合わせをサポートしています。

**例：**

- **Notion Plugin** = Notion MCP + 使用方法ガイドの Skill
- **金融リサーチ Plugin** = 複数の金融 MCP + 複数の分析 Skill + カスタム Agent

## プラグインを利用できる場面

モデルを **K3** または **K3 Swarm** に切り替えた場合、および **Deep Research、Websites、PPT** のシナリオでプラグインを利用できます。

**Kimi Work デスクトップアプリ** でもプラグインを利用できます。デスクトップ版に内蔵されているプラグインの一覧は、[Kimi Work プラグインセンター](/kimi-work/plugin-center)をご覧ください。

<Callout type="info">
Kimi Claw と Kimi Plus の会話では、プラグインはまだサポートされていません。
</Callout>

## プラグインのインストール

- **入口**：入力ボックスの **+** を使うか、「/」と入力します。モバイルでも、入力ボックスの **+** または「/」を使います。
- プラグインマーケットプレイスで検索または閲覧し、プラグインの詳細を開いてインストールをクリックします。
- 一部のプラグインは **OAuth 認証** が必要です（サードパーティのログイン画面に移動し、認証が完了すると利用できます）。**プリインストール** 済みのプラグインもあり、手動インストールは不要です。
- **エンタープライズ限定プラグイン**：エンタープライズ以外のユーザーにも表示されますが、「インストール」ボタンがグレーアウトしています。
- ログアウト状態ではプラグインをインストール・利用できません。

## プラグインの使用

- インストール後、入力ボックスに「/」と入力するか、**+** → プラグインをクリックし、使いたいプラグインを選択して呼び出します。**複数のプラグインを同時に呼び出す** こともできます。
- 必要なことをそのまま説明するだけでも構いません（たとえば「Tianyancha でこの会社を調べて」）。Kimi が適切なプラグインを自動で選びます。
- Kimi がプラグインのツールを呼び出すとき、返信に「xx プラグインを使用中」と表示されます。

## プラグインのカテゴリーと一覧

プラグインマーケットプレイスは以下のカテゴリーで構成されています。実際に表示されるプラグインは **地域（国内 / 海外）** と **利用端末** によって異なり、一部のプラグインは複数のカテゴリーに表示されます。

- **金融**：Financial Investment Analysis、Investment Banking & Private Equity、Corporate Finance & Accounting、Wind Financial Data、S&P Global Market Intelligence、Hundsun Gildata、Tonghuashun iFinD、SEC、Global Financial Database、World Bank Open Data、IMF（国際通貨基金）データベース、Stripe、Tianyancha
- **仕事効率化**：Notion、Baidu Netdisk
- **開発**：GitHub、Supabase、Neon、Cloudflare
- **クリエイティブ**：Inspiration Pool、Image Generation、Video Generation、Audio Generation、Canva
- **汎用**：Vivify

## データと権限

- プラグインを選択または明示的に使用を指示すると、Kimi はそのプラグインが提供するツールを優先的に使用し、ツールが返す結果に基づいて回答を生成します。プラグインを接続すると、Kimi は認証した範囲内で関連コンテンツにアクセスします。
- サードパーティが提供するプラグインの場合、データ処理のルールはその企業が独自に定めており、データはその企業の利用規約とプライバシーポリシーの対象となります。認証前に確認することをおすすめします。
- **プラグインのアンインストールや認証の取り消しはいつでも可能です。** アンインストールすると、関連する OAuth 認証は取り消されます。再度利用するには、再インストールと再認証が必要です。

## よくある質問

### プラグインはメンバーシップのクレジットを消費しますか？
一部消費します。Kimi がプラグインのツールやサービスを呼び出してタスクを完了する際、実際の使用量に基づいてクレジットが消費されます。呼び出しコストのかからないプラグインでは追加料金は発生しません。

### 複数のプラグインを同時に使えますか？
はい。「/」または **+** で複数のプラグインを一度に呼び出せます。

### 特定のプラグインが表示されないのはなぜですか？
利用できるプラグインは地域（国内 / 海外）と利用端末によって異なります。また、一部のプラグインは個人ユーザーまたはエンタープライズユーザーのみに提供されています。

### ChatGPT、Claude など、他のプラットフォームのプラグインを使えますか？
はい。[個人プラグインの作成方法](/plugins-and-skills/create)をご覧ください。他のプラットフォームの既存プラグインファイルやプロジェクトリンクを Plugin Builder に提供し、案内に従って Kimi プラグインに変換できます。
