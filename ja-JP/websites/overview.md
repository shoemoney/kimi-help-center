# Kimi Websites

<Callout type="info">
**Kimi Websites** は、最新の Kimi K2.6 マルチモーダル視覚エージェントAIモデルを搭載した Kimi Agent のプロダクト機能です。中核となるのは **Vibe Coding**、つまり自然言語からWebサイトを生成し、オンラインにデプロイする機能です。
</Callout>

Kimi は、視覚入力（UIモックアップ、スクリーンショット、操作動画）と自然言語の指示を理解し、ユーザーの入力をそのまま実行可能なフロントエンドコードへ変換します。静的なUIだけでなく、動的なインタラクションも対象です。

## 機能概要

| 機能 | 説明 |
|---------|------------|
| **対話型サイト制作** | 作りたい内容を自然言語で説明すると、AIがWebサイトを自動生成します |
| **画像・動画理解** | デザインモックアップ、スクリーンショット、画面録画をアップロードすると、AIが解析してHTMLページを生成します |
| **自動デプロイ** | ワンクリックでデプロイし、すぐに公開できます |
| **複数ラウンド編集** | バージョン比較をしながら、Webサイトを反復的に修正できます |
| **ワンクリック共有** | アクセス可能なリンクを生成し、手軽に共有できます |
| **テンプレート選択** | 複数のプリセットテンプレートから選び、すぐにサイト制作を始められます |
| **コードのエクスポート** | パッケージ化されたHTML/CSS/JSファイルをダウンロードし、自分でホスティングできます |

## Kimi Websites の使い方

### 方法1：Kimi Websites ページにアクセスする

<Frames
  src="./images/overview/kimi-websites-homepage.png"
  alt="Kimi Websites ホームページ"
/>

1. **ブラウザを開く**：Chrome、Safari、Edge、Firefox など主要なブラウザを使用します
2. **アクセス先**：[kimi.com/websites](https://www.kimi.com/zh/websites)（中国語・英語に対応）
3. **ログイン**：Kimi アカウント（電話番号またはメールアドレス）でログインします
4. **タスクを入力**：

| 方法 | 説明 |
|----------|-------------|
| **テキスト入力** | 依頼内容を自然言語で入力します |
| **画像・サイトの複製** | デザインモックアップまたはスクリーンショットをアップロードします |
| **テンプレート利用** | プリセットテンプレートを選択し、内容を編集します |

5. **制作を開始**：テンプレートを選ぶか、会話から作成を始めます

<Frames
  src="./images/overview/screenshot-27.png"
  alt="スクリーンショット 27"
/>

### 方法2：モバイルアプリ

iOS、Android、HarmonyOS には、いずれも公式 Kimi アプリがあります。入力エリアで **タスクバー** をタップし、マルチモーダル生成ツールとエージェント機能を備えた **Websites Agent モード** に切り替えます。

### 方法3：K2.6 Agent モードを使う

K2.6 Agent モードに切り替え、Webサイト制作タスクを入力します。Kimi が視覚コーディング機能とコード実行ツールを呼び出します。

## Kimi Websites の仕組み

### ステップ1：会話でWebサイトを作成する

作りたい内容を自然言語で説明します。次の3つの作成方法に対応しています。

| 方法 | 説明 |
|--------|------------|
| **テキストで説明** | Webサイトの要件を直接入力すると、AIが自動生成します |
| **デザインモックアップ解析** | デザインファイルをアップロードすると、AIが認識してWebページとして再現します |
| **テンプレートで素早く作成** | プリセットテンプレートを選択し、内容を編集します |

### ステップ2：構築プロセス

<Frames
  src="./images/overview/screenshot-26.png"
  alt="スクリーンショット 26"
/>

Kimi website は **Webアプリ構築SKILL** を起動します。これは、複数ラウンドのコード生成に特化したエージェントです。
1. **要件分析**：Webサイトのモジュール、ビジュアルスタイル、インタラクションロジックを分析します
2. **タスク計画**：デザイン、開発、アセット準備のサブタスクに分解します
3. **技術スタック選定**：適切なアーキテクチャ（例：React + Tailwind CSS）を選びます
4. **アセット生成**：画像、アイコン、その他のビジュアルアセットを生成します
5. **コード構築**：ページ構造、スタイル、インタラクションコードを記述します
6. **複数ラウンド最適化**：プレビュー結果に基づいて自律的に調整し、完成まで仕上げます

### ステップ3：プレビューと調整
- **ライブプレビュー**：ブラウザですぐ確認できるHTMLデモURLを生成します
- **対話による編集**：会話を続けて変更を依頼できます。例：*"ナビバーをダークにして"*

<Callout type="tip">
**例**：*"配色がいまひとつです。白黒という条件は外して、普通のWebサイトらしい見た目にしてください。"*
Kimi はToDoリストを再整理し、制作を続けます。
</Callout>

### ステップ4：オンラインでビジュアル編集
- **複数ラウンド最適化**：会話を重ねながら細部を微調整できます
- **編集モード**：
  - **注釈モード**：領域をクリックして、自然言語の注釈を追加します
  - **選択モード**：任意の要素を選択し、注釈を追加します
  - 矩形、矢印、ブラシ、色の切り替えを使って修正提案をマークできます
- すべての修正提案をまとめて Kimi に送信します
### ステップ5：デプロイと公開
| デプロイ方法 | 説明 |
|-------------------|------------|
| **自動デプロイ** | ワンクリックでデプロイし、オンラインリンクを生成します |
| **ダウンロードしてセルフホスティング** | パッケージ化されたコードファイルをダウンロードし、自分のサーバーにデプロイします |
| **カスタムドメイン** | 生成したWebサイトを自分のドメインに紐付けます |

生成後は、次の操作ができます。
- 異なるデプロイバージョンをクリックして、バージョンファイルをダウンロードする
- 共有ボタンをクリックして公開デプロイ済みリンクを取得する（または非公開に設定する）
- 編集ボタンをクリックして修正を続ける
- 完全なHTML/CSS/JSコードをダウンロードし、そのままデプロイする、またはさらに調整する

## 対象ユーザー
| 対象ユーザー | 利用シーン |
|----------|----------|
| **開発者** | プロダクトのプロトタイプやフロントエンドデモを設計し、ゼロから構築する時間を大幅に削減できます |
| **起業家** | 限られたリソースで、ランディングページ、製品紹介サイト、会社サイトをすばやく作成できます |
| **プロダクトマネージャー** | PRDやデザインモックアップを、デモ可能なインタラクティブプロトタイプへ迅速に変換できます |
| **非エンジニアのユーザー** | コーディングは不要です。アイデアを説明するか参考画像をアップロードするだけで、構想を動くWebページにできます |
