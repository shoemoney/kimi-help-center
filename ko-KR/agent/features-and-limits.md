# Agent 기능 및 제한 사항

<SeoMeta
  title="Agent 기능 및 제한 사항 - Kimi 도움말 센터"
  description="Kimi Agent의 기능, 활용 팁, 제한 사항, 최적의 결과를 위한 모범 사례를 알아보세요."
/>

<Callout type="info">
**Kimi Agent**는 AI 기반 어시스턴트로, 다단계 추론과 도구 연동을 통해 복잡한 작업을 자율적으로 수행합니다. 이 가이드에서는 Agent mode를 최대한 잘 활용할 수 있도록 모범 사례, 제한 사항, FAQ를 안내합니다.
</Callout>

## 활용 팁

**(1) 작업을 제출하기 전에**

프로젝트 배경, 사용 사례, 특별 요구 사항 등 배경 정보와 제약 조건을 명확히 알려 주세요. 그래야 Kimi가 사용자의 의도를 더 정확하게 이해할 수 있습니다.

**(2) 실행 중에는**

Kimi Agent는 백그라운드에서 비동기로 실행됩니다. 웹페이지가 멈춘 것처럼 보이거나 진행이 정체된 것처럼 보여도 **"Stop"을 클릭하지 마세요**. 작업 실행이 중단됩니다. 페이지를 떠나도 작업은 백그라운드에서 계속 실행되며, 완료되면 알림을 받게 됩니다. 오래 걸릴 것으로 예상되는 작업(예: Agent Swarm)은 조금만 기다려 주세요.

**(3) 웹사이트 시나리오**

Agent는 프런트엔드 인터페이스, 백엔드 서비스, 영구 저장소 로직을 포함한 풀스택 콘텐츠를 생성할 수 있습니다. 프로젝트가 예상대로 실행되지 않는 경우에는 대개 샌드박스 시작, 데이터베이스 초기화, 인증 설정, 게시 작업 누락과 관련된 문제입니다. 표준 Agent는 클라우드에서 실행되므로 로컬 파일이나 기업 인트라넷 시스템에 직접 접근할 수 없습니다. 로컬 파일 또는 인트라넷 접근이 필요하다면 Kimi Claw를 사용하세요.

<Callout type="tip">
**로컬 파일에 접근해야 하나요?** 로컬 파일과 기업 인트라넷 시스템에 안전하게 접근하려면 Kimi Claw를 사용하세요. 자세한 내용은 [Kimi Claw 문서](/kimi-claw/overview)를 참고하세요.
</Callout>

**(4) 여러 차례의 대화와 작업 조정**
여러 차례 대화하고 수정하는 과정에서 Agent가 초반의 일부 세부 사항을 "잊을" 수 있습니다. 먼저 작업의 틀과 핵심 사항을 정한 뒤, 단계적으로 조정하는 것이 좋습니다.

**(5) 큰 작업 나누기**
규모가 크고 복잡한 작업은 2~3단계로 나누어 Kimi에 순차적으로 제출하거나 Agent Swarm을 사용하세요.

**(6) 파일 출력 제한**
표준 Agent mode에서는 일반적으로 작업 하나당 파일 하나만 출력할 수 있습니다(예: 문서 또는 스프레드시트). 여러 파일이 필요한 경우(예: Word 문서와 PPT를 모두 생성)에는 Agent Swarm을 사용하세요.

**(7) 컨텍스트 제한과 출력 균형**
대규모 언어 모델의 256K 문자 컨텍스트 제한(중국어 약 40,000~50,000자 / 영어 약 100,000단어) 때문에, 많은 양의 파일을 처리할 때는 입력량과 출력량의 균형을 맞춰야 합니다.

<Callout type="warning">
**컨텍스트 제한 참고**: Agent는 256K 문자 컨텍스트 창을 사용합니다. 최적의 결과를 얻으려면 컨텍스트를 간결하게 제공하고 불필요한 파일을 과도하게 넣지 마세요.
</Callout>

## 중요 참고 사항

<Callout type="warning">
**credit 사용량**: Agent 작업은 공유 풀의 credit을 사용합니다. Kimi Code도 이 공유 풀을 사용하지만, Kimi Code에만 적용되는 별도의 5시간 / 주간 rate limit이 있습니다. 각 Agent 작업은 일반적으로 1 credit 단위를 사용합니다. 멤버십 등급별 자세한 credit 정보는 [credit 및 결제](/agent/quota-and-billing)를 참고하세요.

- 요금제에 따라 월 60–720개의 Agent 작업
</Callout>

- **실행 시간**: Agent mode에서 단일 작업은 보통 5~20분이 걸립니다. Agent Swarm 작업은 더 오래 걸릴 수 있습니다. 페이지를 떠나도 괜찮습니다. 다만 Stop을 클릭해 작업을 중단하지 마세요.
- **credit 사용량**: Agent 작업은 Kimi Code도 함께 사용하는 공유 풀의 credit을 사용합니다(Kimi Code에는 별도의 5시간 / 주간 rate limit이 있습니다).
- **간단한 작업**: 단순한 질의응답에는 더 빠르게 응답받을 수 있는 표준 채팅 mode를 권장합니다.

<Callout type="warning">
**콘텐츠 규정 준수**: Agent 기능에는 [Kimi User Service Agreement](https://www.kimi.com/user/agreement/modelUse?version=v2)가 적용됩니다. 금지된 콘텐츠 생성은 지원되지 않으며, 금지된 콘텐츠를 제출하면 서비스 이용이 중지될 수 있습니다.
</Callout>

## FAQ

**Q: Agent로 무엇을 할 수 있나요?**

Agent는 여러 도구 호출을 통해 다음과 같은 요구를 처리합니다.
- **텍스트 생성 및 편집**: 다양한 글쓰기 스타일과 형식을 지원하며 기사, 보고서, 문서 등을 생성합니다.
- **웹 개발**: 풀스택 프로젝트 인터페이스와 서비스를 구축하며, 앱 인터페이스 디자인, 백엔드 연동, 데이터 영속성, 데이터 시각화를 지원합니다.
- **슬라이드 생성**: 완성된 프레젠테이션을 생성하기 위한 전용 웹 기반 PPT 도구를 제공합니다.
- **코딩 지원**: 여러 프로그래밍 언어로 코드 작성과 디버깅을 도와줍니다.

**Q: Agent가 만든 웹사이트가 왜 작동하지 않나요?**

완성된 프로젝트는 일반적으로 프런트엔드 인터페이스, 백엔드 서비스, 데이터 저장소의 세 부분으로 구성됩니다. Agent는 이 세 계층 전반에 걸쳐 풀스택 프로젝트 콘텐츠를 생성할 수 있습니다. 프로젝트가 예상대로 실행되지 않는 경우에는 대개 샌드박스 시작, 데이터베이스 초기화, 인증 설정, 게시 작업 누락과 관련된 문제입니다.

**Q: Agent의 산출물은 무엇인가요?**

- 완료된 작업 실행 파일
- 배포된 프로젝트 미리보기 및 게시 버전
- 다운로드 가능한 Zip 아카이브(`/mnt/okcomputer/output/`에 위치)

**Q: Agent의 컨텍스트 길이는 얼마인가요?**

Agent는 **256K 문자**의 컨텍스트 길이를 사용합니다(중국어 약 40,000~50,000자 / 영어 약 100,000단어).

**Q: Agent credit은 어떻게 계산되나요?**

Kimi Code를 포함한 모든 멤버십 기능은 하나의 credit 풀을 공유합니다. 각 Agent 작업은 일반적으로 1 credit 단위로 계산됩니다.
