# Agent 기능 및 제한 사항

<SeoMeta
  title="Agent 기능 및 제한 사항 - Kimi 도움말 센터"
  description="Kimi Agent의 기능, 사용 팁, 제한 사항, 최적의 결과를 얻기 위한 모범 사례를 알아보세요."
/>

<Callout type="info">
**Kimi Agent**는 다단계 추론과 도구 연동을 통해 복잡한 작업을 자율적으로 수행하는 AI 기반 어시스턴트입니다. 이 가이드에서는 Agent 모드를 최대한 활용할 수 있도록 모범 사례, 제한 사항, 자주 묻는 질문을 안내합니다.
</Callout>

## 사용 팁

**(1) 작업 제출 전**

프로젝트 맥락, 사용 사례, 특수 요구 사항 등 배경 정보와 제약 조건을 명확히 알려 주세요. Kimi가 의도를 더 정확하게 이해하는 데 도움이 됩니다.

**(2) 실행 중**

Kimi Agent는 백그라운드에서 비동기로 실행됩니다. 웹페이지가 멈춘 것처럼 보이거나 진행이 정체된 것처럼 보여도 **"중지"를 클릭하지 마세요**. 작업 실행이 중단됩니다. 페이지를 떠나도 작업은 백그라운드에서 계속 실행되며, 완료되면 알림을 받게 됩니다. 오래 걸릴 것으로 예상되는 작업(예: K2.6 Agent Swarm [베타])은 여유를 가지고 기다려 주세요.

**(3) 웹사이트 시나리오**

Agent는 프런트엔드 인터페이스, 백엔드 서비스, 영구 저장 로직을 포함한 풀스택 콘텐츠를 생성할 수 있습니다. 프로젝트가 예상대로 실행되지 않는 경우, 일반적으로 샌드박스 시작, 데이터베이스 초기화, 인증 설정 또는 게시 작업 누락과 관련된 문제입니다. 표준 Agent는 클라우드에서 실행되므로 로컬 파일이나 기업 인트라넷 시스템에 직접 접근할 수 없습니다. 로컬 파일이나 인트라넷 접근이 필요하다면 Kimi Claw를 사용하세요.

<Callout type="tip">
**로컬 파일에 접근해야 하나요?** 로컬 파일과 기업 인트라넷 시스템에 안전하게 접근하려면 Kimi Claw를 사용하세요. 자세한 내용은 [Kimi Claw 문서](/kimi-claw/overview)를 참고하세요.
</Callout>

**(4) 여러 차례의 대화와 작업 조정**
여러 차례 대화하고 수정하는 과정에서 Agent가 초기 세부 사항 일부를 "잊을" 수 있습니다. 먼저 작업의 틀과 핵심 사항을 정한 뒤, 점진적으로 조정하는 것이 좋습니다.

**(5) 대규모 작업 분해**
크고 복잡한 작업은 2~3단계로 나누어 Kimi에 순차적으로 제출하거나, K2.6 Agent Swarm [베타]를 사용하세요.

**(6) 파일 출력 제한**
표준 Agent 모드에서는 일반적으로 작업 하나당 파일 하나(예: 문서 또는 스프레드시트)만 출력할 수 있습니다. 여러 파일(예: Word 문서와 PPT 모두)이 필요하다면 K2.6 Agent Swarm [베타]를 사용하세요.

**(7) 컨텍스트 한도와 출력 균형**
대규모 언어 모델의 256K자 컨텍스트 한도(중국어 약 40,000~50,000자 / 영어 약 100,000단어)로 인해, 대량의 파일을 처리할 때는 입력량과 출력량의 균형을 맞춰야 합니다.

<Callout type="warning">
**컨텍스트 한도 참고**: Agent는 256K자 컨텍스트 창을 사용합니다. 최적의 결과를 얻으려면 간결한 컨텍스트를 제공하고 불필요한 파일을 과도하게 넣지 마세요.
</Callout>

## 중요 참고 사항

<Callout type="warning">
**quota 사용량**: Agent 작업은 공유 풀(기타 멤버십 기능)에서 quota를 소비합니다. Kimi Code는 별도의 quota 풀을 사용합니다. 각 Agent 작업은 일반적으로 quota 1단위를 소비합니다. 멤버십 등급별 자세한 quota 정보는 [Quota 및 결제](/agent/quota-and-billing)를 참고하세요.
무료 등급: 월 6회 Agent 작업
유료 등급: 요금제에 따라 월 60~720회 Agent 작업
</Callout>

- **실행 시간**: Agent 모드에서는 단일 작업이 보통 5~20분 정도 걸립니다. K2.6 Agent Swarm [베타] 작업은 더 오래 걸릴 수 있습니다. 페이지를 떠나도 괜찮지만, Stop을 클릭해 작업을 중단하지 마세요.
- **quota 사용량**: Agent 작업은 공유 풀에서 quota를 소비합니다. Kimi Code는 별도의 quota 풀을 사용합니다. 
- **간단한 작업**: 간단한 질의응답에는 더 빠른 응답을 위해 표준 채팅 모드를 권장합니다.

<Callout type="warning">
**콘텐츠 규정 준수**: Agent 기능에는 [Kimi 사용자 계약](https://www.kimi.com/user/agreement/modelUse?version=v2)이 적용됩니다. 금지된 콘텐츠 생성은 지원되지 않으며, 금지된 콘텐츠를 제출하면 서비스가 정지될 수 있습니다.
</Callout>

## FAQ

**Q: Agent는 무엇을 할 수 있나요?**

Agent는 여러 도구 호출을 통해 다음과 같은 요구를 처리합니다.
- **텍스트 생성 및 편집**: 다양한 글쓰기 스타일과 형식을 지원하며 글, 보고서, 문서 등을 생성합니다.
- **웹 개발**: 앱 인터페이스 디자인, 백엔드 연동, 데이터 영속성, 데이터 시각화를 지원하며 풀스택 프로젝트 인터페이스와 서비스를 구축합니다.
- **슬라이드 생성**: 완성도 높은 프레젠테이션을 생성하기 위한 전용 웹 기반 PPT 도구를 제공합니다.
- **코딩 지원**: 여러 프로그래밍 언어로 코드 작성과 디버깅을 돕습니다.

**Q: Agent가 만든 웹사이트가 왜 작동하지 않나요?**

완전한 프로젝트는 일반적으로 프런트엔드 인터페이스, 백엔드 서비스, 데이터 저장소의 세 부분으로 구성됩니다. Agent는 이 세 계층 전반에 걸친 풀스택 프로젝트 콘텐츠를 생성할 수 있습니다. 프로젝트가 예상대로 실행되지 않는 경우, 일반적으로 샌드박스 시작, 데이터베이스 초기화, 인증 설정 또는 게시 작업 누락과 관련된 문제입니다.

**Q: Agent의 산출물은 무엇인가요?**

- 완료된 작업 실행 파일
- 배포된 프로젝트 미리보기 및 게시 버전
- 다운로드 가능한 Zip 압축 파일(`/mnt/okcomputer/output/`에 위치)

**Q: Agent의 컨텍스트 길이는 얼마인가요?**

Agent는 **256K자**의 컨텍스트 길이(중국어 약 40,000~50,000자 / 영어 약 100,000단어)를 사용합니다.

**Q: Agent quota는 어떻게 계산되나요?**

Agent, PPT 및 기타 멤버십 기능은 하나의 quota 풀을 공유합니다. Kimi Code는 별도의 quota 풀을 사용합니다. 각 Agent 작업은 일반적으로 quota 1단위로 계산됩니다. 현재 quota와 사용량은 [멤버십 Credits](https://www.kimi.com/membership-credits)에서 확인할 수 있습니다.
