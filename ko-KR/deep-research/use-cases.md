# Deep Research 활용 사례 및 프롬프트 라이브러리

## 활용 사례 개요

| 시나리오 | 예시 프롬프트 |
|:---|:---|
| 산업 / 시장 조사 | 2025년 국내 휴머노이드 로봇 산업의 경쟁 구도와 주요 플레이어를 조사해 주세요 |
| 경쟁 분석 | Notion과 Obsidian의 제품 전략 차이를 비교·분석해 주세요 |
| 투자 실사 | 최근 2년간 주요 LLM 기업의 투자 라운드와 밸류에이션 변화를 정리해 주세요 |
| 학술 문헌 리뷰 | RAG 기술의 발전 과정과 현재의 주요 최적화 방향을 추적해 주세요 |
| 정책 분석 | 최신 데이터 보안 규제가 해외 진출 기업에 미치는 영향을 분석해 주세요 |
| 개인 의사결정 | 영상 편집용 노트북을 구매하려고 합니다. 주요 후보를 조사해 주세요 |
