## 검토 전문가

꼼꼼한 원고 심사자처럼 Kimi는 수정 의견을 항목별로 분석하고, 문서에서 관련 구절을 정확히 찾아 상세한 코멘트와 제안을 자동으로 삽입합니다.

**프롬프트 예시**:

## PDF 디자인 및 출판 서비스

레이아웃 디자이너처럼 Kimi는 시각적 특징을 기획하고, 텍스트와 이미지를 자동으로 배치하며, 출판 품질의 PDF 포트폴리오를 생성하도록 도와줍니다.

<CodePreview
  files={[
    {
      name: "prompt.md",
      language: "markdown",
      content: "당신은 현대미술, 특히 피카소 연구를 전문으로 하는 큐레이션 출판 AI입니다.\n과제: 풍부한 이미지를 활용해 관람자가 왜 피카소를 거듭 다시 보아야 하는지 이해하도록 도와주세요.\n\nPDF로 바로 출력하세요.\n\nI. 핵심 요구 사항\n풍부한 이미지\n모든 시기, 모든 작가 참조, 모든 사조에는 이를 뒷받침하는 이미지가 있어야 함\n출처가 있는 이미지를 우선 사용\n출처 이미지를 구할 수 없는 경우에만 고품질 AI 생성 이미지 사용\n\nII. 비주얼 시스템\nMAP 로고를 전체 페이지 워터마크로 사용\n비대칭 레이아웃\n국지적 변주를 통제한 명확한 그리드\n고대비 흑백 + 원색 포인트\n\nIII. 콘텐츠 구조(모든 섹션 생성)\n1. 표지\nPicasso\n전시 부제(영어 및 중국어)\nMAP 로고 워터마크\n\n2. 왜 피카소인가(이미지 포함)\n여러 시기의 피카소 초상\n서로 다른 시기의 작품 병치\n\n3. 시기와 사조(이미지 중심)\n각 시기는 8~12장의 이미지를 포함해야 함:\n청색 시대\n장밋빛 시대\n입체주의(분석적 / 종합적)\n전쟁과 정치\n후기 실험\n\n이미지 유형:\n작품 전체\n세부 크롭\n구조 해체 다이어그램(필요 시 AI 생성)\n\n4. 주요 작품\n25점 이상\n개별 작품은 전체 페이지를 차지해도 됨\n구조, 원근법, 해체를 강조\n\n5. 피카소를 보는 법\n이미지 기반 비교 설명\n같은 주제를 나란히 비교해 보여주기\n\n6. 전시장과 리듬\n고밀도 감상 구역\n사색을 위한 완충 구역\n\n7. ## 더 많은 시나리오와 프롬프트 예시

| 시나리오 | 프롬프트 예시 |
|------|-----------|
| **전문 보고서** | 시장 규모, 경쟁 구도, 정책 환경, 투자 제안을 포괄하는 "2026년 중국 저고도 경제 산업 백서"를 McKinsey 스타일의 Word 문서로 작성해 주세요 |
| **계약서 검토** | [contract.docx 업로드] 변호사의 관점에서 이 계약서를 검토하고, 위험 조항을 식별한 뒤 코멘트를 삽입해 주세요 |
| **재무 모델링** | 매출 전망, 비용 구조, 현금 흐름을 포함한 3개년 SaaS 재무 예측 모델을 Word로 작성해 주세요 |
| **장문 요약** | 이 30,000단어 분량의 학술 논문을 5,000단어 분량의 경영진용 요약문으로 압축해 Word 형식으로 작성해 주세요 |
| **다중 버전 비교** | [계약서 V1 및 V2 업로드] 두 버전을 비교하고, 모든 변경 사항을 영향 설명과 함께 나열한 뒤 Word로 출력해 주세요 |
