# Kimi Docs & Kimi Sheets

<Callout type="info">
2026년 1월 27일, Moonshot AI는 Kimi K2.5를 출시하며 Kimi Agent의 생산성 기능을 크게 끌어올렸습니다. 이제 Kimi Agent는 Word, PDF, Excel, Slides 파일을 처음부터 끝까지 출력하며 "Office를 완전히 다룰" 수 있습니다.
</Callout>

Kimi K2.5는 Office 작업 환경에서 출력 품질과 도구 호출 효율을 크게 개선했으며, 특히 처음부터 끝까지 처리 가능한 구조화된 출력에서 강점을 보입니다.
| 형식 | 기능 |
|--------|-------------|
| **Word** | 지능형 서식 지정 및 수정 사항 추적 |
| **PDF** | 시각 디자인 및 텍스트·이미지 혼합 레이아웃 |
| **Excel** | 데이터 분석 및 재무 모델링 |
| **Slides** | 자동 생성 및 시각적 스토리텔링 |

## Kimi Docs
Kimi Docs는 문서 성격에 맞춰 텍스트를 다듬는 능력이 뛰어나며, Office 업무 흐름을 체계적으로 이해합니다.
### 주요 기능
**Word 문서:**
- 백서, 연구 보고서, 계약서, 제안서 등 긴 전문 문서 생성
- 기존 Word 문서에 댓글과 수정 제안 삽입
- 제목 계층, 문단 간격, 인용, 목록 서식 처리
- 30,000단어 분량의 논문을 정밀한 요약으로 압축
**PDF 문서:**
- 표지, 목차, 본문, 그림 캡션을 갖춘 풍부한 시각 자료의 전문 PDF 보고서 생성
- 전문 조판 소프트웨어 없이 기존 PDF 재편집 및 서식 재구성
- 수백 페이지 PDF에서 특정 정보 추출
- 여러 계약서 버전 간의 미묘한 차이 비교
### Kimi Docs 사용 방법
**시작 방법:**
- 일반: 사이드바 또는 채팅 상자의 Docs, Sheets, Slides 바로가기를 클릭합니다
- 전용: 채팅 상자 하단의 "Docs" 버튼을 클릭합니다
### 방법 1: Kimi Docs 페이지 방문

1. **브라우저 열기**: Chrome, Safari, Edge, Firefox 또는 주요 브라우저 사용
2. **이동하기**: [kimi.com/docs](https://www.kimi.com/docs)
3. **로그인**: Kimi 계정(Google 또는 이메일)으로 로그인
4. **작업 입력**:
   - **텍스트 입력**: 자연어로 작업을 입력합니다
   - **문서 업로드** 후 편집합니다
   - **예시 둘러보기**: "이렇게 만들어 줘"를 클릭하고 맞춤 설정한 뒤 전송합니다
5. **작성 시작**: 템플릿을 선택하거나 대화로 생성합니다

  src="./images/overview/screenshot-2.png"

</Callout>

### 방법 2: 모바일 앱
Kimi 앱은 iOS와 Android에서 사용할 수 있습니다. Taskbar를 탭한 뒤 Docs Agent 모드로 전환하세요.
#### 방법 3: 일반 Agent 모드
K2.6 Agent 모드로 전환한 뒤 문서 관련 작업을 입력하세요. Kimi가 읽기 및 쓰기 도구를 호출합니다.
## Kimi Sheets
Kimi Sheets는 셀 간 관계와 시트 간 연결 로직을 이해하며, 브라우저에서 .xlsx 파일을 바로 생성합니다.
### 주요 기능
| 기능 | 설명 |
|------------|-------------|
| **대량 데이터 입력** | 문서에서 데이터를 추출합니다. 예를 들어 PDF의 전시업체 정보를 1,000행 Excel 파일로 가져옵니다 |
| **여러 출처 통합** | 서로 다른 50개 부서의 Excel 보고서를 하나의 회사 요약본으로 병합합니다 |
| **자연어 입력** | 자율적인 웹 검색으로 지능형 스프레드시트를 생성합니다 |

### Kimi Sheets 사용 방법
채팅 상자 하단의 "Agent" 버튼을 클릭하거나 사이드바에서 "Sheets" 바로가기를 선택하세요.

## 대상 사용자
| 대상 | 활용 사례 |
|:---|:---|
| **직장인** | 업무 제안서, 브리핑 자료, 회의록을 빠르게 생성 |
| **연구원** | 연구 자료, 인터뷰 기록, 업계 보고서를 백서로 통합 |
| **학술 연구자** | 논문과 문헌 리뷰를 요약본으로 변환하고 실험 데이터 계산 |
| **법률 전문가** | 강력한 검토 및 주석 기능을 활용해 법률 문서 수정 |
| **창업가** | 사업 계획서, 파트너십 제안서, 투자자 자료를 빠르게 제작 |
| **투자 애널리스트** | 자연어로 DCF 모델링, 재무 예측, 가치 평가 분석 수행 |
| **마케팅·운영 담당자** | 다중 채널 데이터, 경쟁사 비교, 캠페인 성과 분석을 집계 |
