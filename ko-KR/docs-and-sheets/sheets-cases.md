# Kimi Sheets 활용 사례

<Callout type="info">
재무 가치평가부터 스토리보드 제작까지, Kimi Sheets의 활용 사례와 프롬프트 예시를 소개합니다.

Kimi는 재무 애널리스트처럼 실제 재무 데이터를 수집하고, DCF 가치평가 모델을 구축해 기업 가치평가를 시뮬레이션합니다.

## 스토리보드 제작

Kimi는 스토리보드 아티스트처럼 재생 시간, 샷 설명, 내레이션, 효과음, 참고 프레임을 포함한 Excel 형식의 영상 스토리보드 대본을 만듭니다.

## 추가 시나리오 및 예시 프롬프트

| 시나리오 | 예시 프롬프트 |
|------|-----------|
| 재무 모델링 | XX Company의 DCF 가치평가를 수행하세요 — 전체 과정과 데이터를 Excel에 정리하고, 출처를 인용하며, 성장률 같은 핵심 가정의 근거를 설명하세요 |
| 산업 데이터 비교 | 국내 NEV 상위 20개 기업을 조사하세요 — 시가총액, 2025년 판매량, 주력 모델, 최근 뉴스를 비교표로 정리하세요 |
| 문헌 정리 | 최근 3개월간 LLM 추론 최적화 관련 논문을 검색하세요 — 제목, 저자, 핵심 방법론, 주요 기여를 Excel에 정리하세요 |
| 다중 시트 병합 | [월별 매출 Excel 파일 12개 업로드] 이 12개 시트를 연간 요약으로 병합하고, 전월 대비 성장률을 계산하며, 수식을 사용해 시트 간 연결을 구성하세요 |
| 영업 리드 추출 | [전시회 PDF/이미지 업로드] 모든 참가 업체 정보를 추출해 회사명, 연락처, 제품 카테고리가 포함된 1,000행 규모의 영업 리드 Excel 파일로 정리하세요 |
| 프로젝트 관리 | 작업 목록, 담당자, 진행 상태, Gantt 차트, 시트 간 연결이 포함된 PMO 프로젝트 관리용 Excel을 만드세요 |
| 데이터 시각화 | 이 매출 데이터 Excel을 추세선 차트, 지역별 분포 차트, 완료율 도넛 차트가 포함된 시각적 대시보드로 변환하세요 |
