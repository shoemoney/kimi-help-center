# Skills란 무엇인가요?

<Frames
  src="./images/skills/what_is_skill.png"
  alt="what_is_skill"
/>

Skills는 AI 에이전트의 역량 범위를 넓히도록 설계된 재사용 가능한 지식 패키지입니다. 각 스킬에는 다음이 포함됩니다.

- **작업 방식 및 운영 지침** — 특정 작업 유형에 맞춘 방법론.
- **모범 사례 및 표준** — 따라야 할 업계 표준과 내부 프로토콜.
- **스크립트, 도구 및 참고 리소스** — 실행을 돕는 선택적 도구와 자료.

## 어떻게 사용하나요?

대화가 시작되면 Agent는 사용 가능한 스킬 목록과 각 스킬의 이름, 간단한 설명을 확인합니다. 현재 작업과 관련 있는 스킬이 있으면 Agent가 전체 지침을 불러와 그에 따라 실행합니다.

## 사용자 여정

스킬을 발견하고 직접 만드는 데 이르는 전체 흐름은 다음과 같습니다.

1. **스킬 찾기** — Skills 패널에서 공식 및 추천 스킬을 살펴보고 상황에 맞는 스킬을 찾습니다.
2. **스킬 설치** — "+" 버튼을 클릭하면 스킬이 즉시 추가됩니다.
3. **스킬 호출** — 채팅 입력창에 `/`를 입력해 스킬을 선택하거나, Kimi가 사용자의 요청을 바탕으로 자동으로 스킬을 실행하도록 합니다.
4. **직접 만들기** — 기존 스킬이 요구 사항에 맞지 않으면 문서를 업로드하거나 원하는 내용을 설명해 맞춤 스킬을 생성할 수 있습니다. 또는 `/skill-creator`를 사용해 대화로 스킬을 만들 수 있습니다.

## Skills는 어떻게 작동하나요?

요청을 보내면 Kimi Agent가 현재 작업에 특정 스킬이 필요한지 판단합니다. 필요하다고 판단되면 해당 스킬을 자동으로 불러오고, 그 지침에 따라 작업을 완료합니다.

스킬은 작업과 관련이 있을 때만 불러오므로, 다른 대화의 맥락을 방해하지 않습니다.

## Skills와 직접 프롬프트 입력의 차이는 무엇인가요?

주간 보고서 작성을 예로 들면 다음과 같습니다.
- **직접 프롬프트 입력**: Kimi Agent에게 직접 요청하면, Kimi Agent가 형식에 대해 이해한 바를 바탕으로 작성합니다.
- **Skills 사용**: 주간 보고서 스킬을 설치해 두면 매번 지침을 반복하지 않아도 모든 결과물이 미리 정한 구조, 어조, 분량을 따릅니다.

| | 직접 프롬프트 입력 | 스킬 사용 |
|---|---|---|
| **매번 요구 사항을 설명해야 하나요?** | 예 | 아니요, 자동으로 적용됩니다 |
| **출력 형식의 안정성** | 달라질 수 있음 | 정의한 대로 일관됨 |
| **가장 적합한 사용 사례** | 일회성·임시 작업 | 반복적이고 고정된 워크플로 |
| **설정이 필요한가요?** | 아니요 | 생성 또는 설치가 필요합니다 |

## 스킬 유형

### (1) 공식 스킬 및 추천 스킬

**공식 스킬**: Moonshot AI가 만들고 유지 관리하며, 모든 사용자가 사용할 수 있습니다. Kimi는 관련 상황에서 공식 스킬을 자동으로 실행합니다.

대표적인 공식 스킬은 다음과 같습니다.
- `docx` — Word 문서를 만들고 편집합니다. 문서 생성, 편집, 댓글, 수정, 각주, 목차, Markdown에서 Word로 변환 등 모든 .docx 작업에 적합합니다.
- `deep-research` — 툴킷을 사용해 심층 조사를 수행하고 장문 보고서를 작성합니다. 최소 10회의 반복 검색 주기, 재귀적 성찰, 필수 IPython 시각화가 필요합니다.

**추천 스킬**: 한 번의 클릭으로 추가할 수 있도록 선별된 시나리오 기반 스킬입니다. 투자 리서치, 문서 서식 지정 등 자주 쓰이는 사용 사례를 다룹니다.

대표적인 추천 스킬은 다음과 같습니다.
- `sop-writer` — 비즈니스 프로세스를 완성도 높은 표준 운영 절차(SOP) 문서로 변환합니다. 프로세스 흐름도, RACI 매트릭스, 상세 운영 단계, 예외 처리를 포함합니다.
- `event-etf-study` — 개념이나 이벤트에서 출발해 관련 주식을 식별하고, 시가총액 가중 ETF 지수를 구축하며, 이벤트 기간의 시장 가치 변화를 분석하고, 대화형 HTML 대시보드를 생성합니다. 사용자가 테마주, 테마 ETF, 이벤트 기반 분석 또는 이벤트 리서치에 대해 문의할 때 사용됩니다.

**Office 문서로 스킬 만들기**: 문서를 업로드해 스킬을 생성하고 스타일 테마를 손쉽게 재현합니다.

### (2) 오픈 소스 스킬

오픈 소스 커뮤니티에서 적합한 Skills를 다운로드하거나 설치해 Local Agents(예: Kimi Code) 또는 Cloud Agents(예: Kimi Claw)와 함께 사용할 수 있습니다.

**주요 AI Skill Hub 플랫폼**

| 플랫폼 | URL | 설명 |
|----------|-----|-------------|
| SkillsMP | https://skillsmp.com | GitHub에서 SKILL.md 패키지를 가져오는 AI 에이전트 스킬 마켓플레이스입니다. Claude Code 및 OpenAI Codex CLI와 호환됩니다 |
| SkillsLLM | https://skillsllm.com | Claude Code, Codex CLI, ChatGPT를 위한 1,600개 이상의 보안 검증 스킬을 제공하는 오픈 소스 AI 에이전트 스킬 마켓플레이스입니다 |
| LobeHub Skills | https://lobehub.com/skills | Claude Code, Codex CLI, ChatGPT와 호환되는 SKILL.md 패키지를 탐색하고 배포할 수 있습니다 |

### (3) 맞춤 스킬

개인 워크플로와 특정 도메인 작업을 위해 직접 만든 맞춤 스킬입니다. 예를 들면 다음과 같습니다.
- 문서나 프레젠테이션에 특정 스타일 가이드를 적용합니다.
- 고정 템플릿을 바탕으로 이메일이나 커뮤니케이션 콘텐츠를 생성합니다.
- 회의록을 특정 형식으로 정리합니다.
- 특정 데이터 분석 워크플로를 실행합니다.
