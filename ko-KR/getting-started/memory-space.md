# Memory Space

## 메모리란 무엇인가요?
Kimi는 이제 진짜로 귀 기울이는 법을 배웠습니다. 대화를 나눌수록 당신을 더 잘 이해하죠. 작동 방식은 다음과 같습니다.

Kimi는 현재 채팅창에 있는 내용에만 반응하지 않습니다. 여러 대화를 거치며 당신의 선호, 습관, 스타일처럼 중요한 정보를 기억해 둡니다.

계속 사용할수록 Kimi는 대화가 바뀌어도 꾸준히 학습하며, 당신을 이해하는 방식을 계속 다듬어 갑니다.

같은 말을 반복할 필요가 없습니다. Kimi는 "이전에 나눈 이야기"를 능동적으로 고려해 더 관련성 높고 일관된 답변을 제공합니다.

## 무엇을 기억하나요?
Kimi는 별도로 학습된 모델을 사용해, 사용자에게 가치 있는 대화 내용을 선별적으로 기억합니다.

무언가를 기록하기 전에 Kimi는 스스로 두 가지를 묻습니다.
- 이 사용자는 어떤 사람인가?
- 이 사용자는 무엇에 관심이 있고, 무엇을 선호하며, 무엇을 피하고 싶어 하는가?

Kimi는 사용자가 명시적으로 요청하지 않는 한 승인되지 않은 개인정보(예: 건강 정보, 비밀번호, 주소)를 **기억하지 않습니다**.

## 메모리를 작동시키는 방법
메모리는 이제 기본으로 내장된 기능입니다. 자연스럽게 대화하기만 해도 작동합니다.

Kimi의 메모리를 업데이트하거나 관리하는 방법은 다음과 같습니다.

**(1) 대화 중 직접 지시하기(가장 일반적)**

자연어 명령으로 메모리를 업데이트할 수 있습니다.

| 작업 | 이렇게 말해 보세요 | Kimi의 반응 |
|:---|:---|:---|
| 메모리 추가 | "내가 커피를 좋아한다는 걸 기억해 줘"<br>"내 사번이 9527이라고 기록해 둬"<br>"내가 프로젝트 매니저라는 걸 기억해 줘" | Kimi가 메모리 도구를 호출해 저장합니다 |
| 메모리 업데이트 | "정정할게. 나 New York으로 이사했어"<br>"업데이트: 나는 이제 시니어 엔지니어야" | Kimi가 기존 메모리를 새 내용으로 바꿉니다 |
| 메모리 삭제 | "내가 커피를 좋아한다는 건 잊어줘"<br>"내 사번에 대한 메모리를 삭제해 줘"<br>"모든 메모리를 지워줘" | Kimi가 지정한 메모리 또는 모든 메모리를 삭제합니다 |

참고: 메모리는 전적으로 사용자가 제어합니다. 모델 학습에는 사용되지 않으며, 언제든 끄거나 지울 수 있습니다.

**(2) 설정(UI)에서 관리하기**

설정 화면에서도 메모리를 관리할 수 있습니다.
- Web / Mobile: 설정 → 개인화 → Memory Space
- 저장된 모든 메모리 항목을 확인할 수 있습니다
- 더 이상 필요 없는 메모리는 직접 삭제할 수 있습니다

### 메모리 추가하기
메모리는 대화 중 자동으로 작동합니다. 예를 들면 다음과 같습니다.
- "내 이름은 xxx이고, 친구들은 나를 xxxx라고 불러"
- "나는 초등학교 수학 교사라서 수업 자료는 아이들이 이해하기 쉬워야 해"
- "답변에 이모지는 쓰지 말아 줘"
- "나는 보통 C++로 코딩해"
- "같은 말을 반복하지 말고 문장 부호를 과하게 쓰지 마"

### 메모리 업데이트하기
프로필 → 설정 → 개인화 → Memory Space로 이동해 개별 메모리 항목을 편집하세요.

### 메모리 삭제하기(잊게 하기)
프로필 → 설정 → 개인화 → Memory Space로 이동한 뒤 개별 항목에서 삭제를 클릭하세요.
