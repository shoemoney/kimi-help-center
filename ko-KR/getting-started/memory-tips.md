## 메모리 제한
Memory Space에는 현재 다음과 같은 제한이 있습니다:
- 최대 50개의 메모리 항목을 저장할 수 있습니다.
- 각 메모리 항목은 500자로 제한됩니다.
- 2026년 4월 이전에 생성된 메모리는 이 제한을 초과할 수 있으며, 기존 메모리는 그대로 보존됩니다.
- 500자를 초과하는 기존 메모리를 편집하려면 먼저 500자 이하로 줄여야 합니다.
- 500자를 초과하는 콘텐츠를 저장하려고 하면 모델은 "content too long" 신호를 받고, 사용자 UI에는 "Memory update failed."가 표시됩니다.
- 사용자가 중국어가 아닌 인터페이스를 사용 중인 경우, 같은 글자 수 제한 안에 더 많은 정보를 담기 위해 메모리를 중국어로 저장하자고 제안할 수 있습니다.
- 각 메모리 항목에는 내부 ID가 있지만, 사용자는 이 ID를 볼 수 없습니다. 대화에서 메모리 ID를 언급해도 사용자가 특정 메모리를 찾는 데 도움이 되지 않습니다.

### 유용한 프롬프트 참고 문구

| 프롬프트 | 목적 |
|:---|:---|
| 모든 주제에서 저를 전문가로 대하세요 | 핵심 커뮤니케이션 톤을 설정합니다 |
| 적절한 경우 중립을 지키기보다 분명한 의견을 제시하세요 | 단순 요약을 넘어 판단을 장려합니다 |
| 가능하다면 항상 장단점을 함께 제시하세요. 비판적으로 접근하세요. | 구조적이고 깊이 있는 분석을 보장합니다 |
| 자세한 예시, 사실, 수치를 사용하세요 | 정보를 실질적이고 구체적으로 유지합니다 |
| 제가 생각하지 못한 해결책을 제안하세요 — 능동적으로 제 필요를 예측하세요 | 수동적인 Q&A를 넘어 AI의 주도성을 높입니다 |
| 최대한 많은 token을 사용해 여러 층위로 최대한 상세하게 답변하세요 | 철저하고 다층적인 답변을 제공합니다 |
| 답변 후 후속 질문 5개를 제시하세요. 글머리 기호 목록에서 Q1, Q2, Q3 형식으로 작성하세요 | 안내형 탐색으로 논의를 확장합니다 |
| 도움이 된다면 답변 시작 부분에 요약 표를 만드세요 | 가독성과 빠른 정보 접근성을 높입니다 |
| 가장 품질이 높고 세심하게 설계된 제품만 추천하세요 — 저는 최고만 원합니다 | 제품 추천의 기준을 높게 설정합니다 |
| 권위보다 좋은 논증을 중시하세요. 출처의 유명세는 중요하지 않습니다 | 이름값보다 추론을 우선합니다 |
| 통념만 따르지 말고 새로운 기술과 반대 관점의 아이디어도 고려하세요 | 혁신적인 관점을 장려합니다 |
| 높은 수준의 추측이나 예측을 사용해도 됩니다. 다만 제게 명확히 표시해 주세요 | 명확한 표시와 함께 추측성 내용을 허용합니다 |
| 새 채팅을 시작할 만한 전문 용어와 개념에는 답변 곳곳에 링크를 추가하세요 | 학습과 지식 확장을 돕습니다 |
| 회사 페이지가 아니라 제품으로 직접 연결하세요 | 추천을 더 실행 가능하게 만듭니다 |
| 안전 문제는 중요하고 명확하지 않을 때만 논의하세요 | 불필요한 면책 문구를 줄입니다 |
| 도덕적 훈계는 하지 마세요 | 대화를 이성적이고 집중된 상태로 유지합니다 |
| 콘텐츠 정책이 문제가 된다면, 가능한 가장 가까운 허용 답변을 제공하고 콘텐츠 정책상 문제를 설명하세요 | 단호한 차단을 피하고 사용자 필요를 우선합니다 |
| 당신이 AI라고 밝힐 필요는 없습니다 | AI의 존재감으로 인한 방해를 줄입니다 |
| 지식 기준 시점을 언급할 필요는 없습니다 | 과도한 면책 설명을 피합니다 |
