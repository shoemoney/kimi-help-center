# 프롬프트 기본 사항

<Callout type="info">
프롬프트는 Kimi에게 보내는 텍스트 지시문입니다. 질문, 설명, 요구 사항 모음, 또는 완성된 작업 브리프가 될 수 있습니다. Kimi는 프롬프트를 바탕으로 사용자의 의도를 파악하고, 답변을 구성하며, 작업을 수행합니다.

한마디로 말해 **어떻게 묻느냐가 Kimi의 답변을 결정합니다.** 명확하고 구체적인 프롬프트는 거의 언제나 더 정확하고 가치 있는 답변으로 이어집니다.
</Callout>

## 좋은 프롬프트의 4가지 핵심 요소

### 1. 역할과 맥락 정의하기

사용자가 누구이며 어떤 상황에 있는지 Kimi에게 알려 주면, Kimi가 적절한 깊이와 어조를 맞추는 데 도움이 됩니다.

| 모호한 프롬프트 | 더 나은 프롬프트 |
|-------------|--------------|
| AI에 관한 글을 써 줘 | 저는 기술 미디어 편집자입니다. 일반 독자를 대상으로 이해하기 쉽고 흥미로운 문체의 2,000단어짜리 AI 해설 기사가 필요합니다 |
| 데이터 분석을 도와줘 | 저는 시장 분석가입니다. 이 Excel 파일에서 채널별 전환율을 분석해 주세요. 전월 대비 변화에 중점을 두어 주세요 |

### 2. 작업을 구체적으로 설명하기

설명이 구체적일수록 수정 반복이 줄어듭니다. 좋은 작업 설명에는 보통 다음이 포함됩니다.

- **해야 할 일**: 명확한 동작(분석, 요약, 번역, 생성, 비교 등)
- **출력 형식**: 표, 목록, 단락, 코드, Markdown 등
- **범위와 제약 조건**: 단어 수, 항목 수, 기간, 지역 범위 등
- **품질 요구 사항**: 학술적 어조, 대화체, 간결함, 상세함 등

### 4. 복잡한 작업은 단계로 나누기
복잡한 작업은 더 작은 단계로 나누고, Kimi가 순서대로 진행하도록 안내하세요.

    },
  ]}
/>

## 실전 팁
### 후속 질문과 반복 활용하기
첫 답변이 만족스럽지 않나요? 전체 맥락을 다시 설명할 필요 없이 이어서 요청하면 됩니다.
- "2번 항목을 더 자세히 설명해 줘"
- "어조를 더 격식 있게 바꿔 줘"
- "데이터 출처를 추가해 줘"
- "다른 관점에서 다시 분석해 줘"
### 파일과 링크 활용하기
Kimi는 PDF, Word 문서, Excel 파일, 이미지 등 다양한 파일 업로드를 지원합니다. URL을 직접 붙여 넣을 수도 있습니다. 파일과 프롬프트를 함께 사용하면 효율이 크게 높아집니다.
| 작업 | 프롬프트 예시 |
|------|---------------|
| PDF 요약 | "이 PDF의 핵심 내용을 요약해 줘" |
| 데이터 분석 | "이 Excel 데이터를 바탕으로 매출 추세를 분석해 줘" |
| URL에서 추출 | "링크의 이 글을 읽고 핵심 시사점을 추출해 줘" |

### 출력 형식 지정하기
원하는 형식을 Kimi에게 정확히 알려 주세요.
| 필요 사항 | 프롬프트 예시 |
|------|---------------|
| 비교표 | "A와 B의 장단점을 표로 비교해 줘" |
| 코드 출력 | "주석을 포함해 Python으로 구현해 줘" |
| 구조화된 목록 | "번호 매긴 목록으로 정리하고, 각 항목은 20단어 미만으로 작성해 줘" |
| Markdown | "제목 계층을 갖춘 Markdown 형식으로 출력해 줘" |

### 반복되는 선호 사항은 메모리 활용하기
반복해서 사용하는 선호 사항이나 요구 사항이 있다면 Kimi의 **메모리** 기능으로 장기적으로 기억하게 할 수 있습니다.
- "제가 React 스택을 선호하는 프론트엔드 엔지니어라는 점을 기억해 줘"
- "항상 영어로, Markdown 형식을 사용해 답변해 줘"
- "기술 질문에 답할 때는 코드 예시를 포함해 줘"

<Callout type="tip">
이렇게 하면 같은 내용을 반복해서 말할 필요가 없습니다. Kimi가 앞으로의 대화에서 이러한 선호 사항을 자동으로 적용합니다.
</Callout>

## 흔한 실수
| 실수 | 더 나은 접근 방식 |
|---------|----------------|
| 관련 없는 여러 작업을 한 메시지에 몰아넣기 | 각 독립 작업마다 새 세션을 시작해 맥락을 깔끔하게 유지하세요 |
| 지나치게 모호한 프롬프트(예: "뭔가 써 줘") | 무엇을, 누구를 위해, 어떤 문체로, 어느 정도 길이로 쓸지 지정하세요 |
| 첫 시도에 완벽한 결과를 기대하기 | 먼저 초안을 만든 뒤 후속 요청으로 다듬어 가세요 |
| AI 출력 내용을 사실 확인하지 않기 | 날짜, 데이터, 사실 주장은 항상 검증하세요 |
