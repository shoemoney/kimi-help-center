# Agentic Search

<Callout type="info">
Kimi의 Agentic Search는 End-to-End Agentic RL 아키텍처를 기반으로 합니다. 기존의 도구 오케스트레이션 방식과 달리 AI가 언제 검색할지, 어떤 도구를 호출할지, 전략을 어떻게 조정할지를 스스로 판단하므로 복잡한 정보 수집 및 처리 작업을 수행할 수 있습니다.
</Callout>

기존의 키워드 매칭 검색과 비교해 Kimi의 검색 기능은 두 차례 큰 진화를 거쳤습니다.
- **Explorer Search**(2024년 10월)는 대규모 언어 모델의 의미 이해와 실시간 정보 검색을 결합해 복잡한 질문을 자동으로 분해하고 출처를 추적했습니다.
- **Agentic Search**는 한 단계 더 나아가 자율적 계획 수립과 도구 호출을 수행하며, 금융 데이터 조회, 학술 문헌 검색, 이미지 검색 등 다양한 멀티모달 작업을 지원합니다.

## 핵심 기능

### 1. 최신성과 권위의 결합
주요 언론사, 정부 발표, 금융 데이터 플랫폼, 학술 저널 데이터베이스 등 검증된 신뢰 출처 100개 이상을 대상으로 실시간 웹 검색을 수행해, 정보가 최신이면서도 권위 있게 유지되도록 합니다.

### 2. 출처 표시
검색을 기반으로 한 모든 답변에는 참고 출처 링크가 포함됩니다. 링크를 클릭해 원문 페이지를 확인하고 정확성과 맥락을 충분히 검증할 수 있습니다.

### 3. 글로벌 정보 접근
여러 언어로 자연어 대화를 지원합니다. Kimi는 일본어 기술 문서, 프랑스어 뉴스 등 비영어권 출처도 선제적으로 검색하고 다국어 정보를 자동으로 종합할 수 있습니다.

## 추천 활용 사례

- 실시간 뉴스와 업데이트(속보, 주식 시장 데이터, 정책 변경)
- 사실 확인(온라인 루머, 역사 데이터, 통계 방법론)
- 전문 리서치(경쟁사 정보, 학술 최전선, 산업 표준)

## 권위 있는 출처 배지

Kimi의 Web Search는 관련성, 권위, 최신성이라는 세 가지 기준으로 출처를 선별합니다. 위험한 사이트, 중복 배포 콘텐츠, 저품질 웹 콘텐츠, 환각 정보를 자동으로 걸러내 신뢰할 수 있는 결과를 제공합니다.

Kimi의 엄격한 심사를 통과한 고품질 출처는 답변에 권위 배지(예: 공식 웹사이트 인증, 학술 인증, 미디어 인증 아이콘)로 표시되어, 신뢰도가 높은 정보를 빠르게 식별할 수 있습니다.

**출처 선별 방식**:
- **제외 대상**: 저품질 집계 사이트, 검증되지 않은 개인 미디어, 만료된 캐시 페이지
- **우선 대상**: 정부 기관 웹사이트, 권위 있는 언론, 학술 저널, 공식 금융 보고 채널

## 스마트 검색

### 이미지 검색

Kimi는 이미지 기반 검색과 이해를 지원합니다. 이미지를 업로드하면 Kimi가 이미지 검색 도구를 자동으로 호출해 내용을 식별하고 관련 정보를 찾아줍니다.

**예시 질문**:
- "여기가 어디야?"
- "이 밈에서 무슨 일이 벌어지고 있어? / 이 사람이 뭐라고 말하는 거야?"
- "진짜 McDonald's를 찾아줘"

**사용 방법**:
- 이미지를 직접 업로드합니다(JPG, PNG 등 형식 지원).
- 프롬프트에 이미지 내용을 설명하거나 이미지 관련 질문을 입력합니다.
- Kimi가 이미지 인식과 Web Search를 결합해 이미지의 출처, 유사 이미지, 관련 정보를 제공합니다.

**대표 시나리오**:
- 알 수 없는 물체, 랜드마크, 제품 모델 식별
- 이미지의 출처나 원본 찾기
- 차트 또는 스크린샷의 데이터 분석 및 관련 배경 정보 검색

## 팁

<Callout type="warning">
- **공개적으로 접근 가능한** 링크를 우선 사용하세요(예: 뉴스 페이지, 공개 PDF 문서).
- 일부 **비밀번호로 보호된** 페이지나 크롤링이 제한된 페이지는 접근하지 못할 수 있습니다.
- **동적으로 로드되는** 페이지의 경우 Kimi가 초기 HTML 콘텐츠만 가져올 수 있습니다.
- Kimi는 **공유된 대화 링크를 다시 읽을 수 없습니다**(즉, 다른 Kimi 채팅으로 연결되는 링크).
</Callout>
