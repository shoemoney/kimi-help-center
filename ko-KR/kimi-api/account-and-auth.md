# 계정 및 인증

<Callout type="info">
Kimi API 개발자 계정, 인증 심사 및 인증에 관한 자주 묻는 질문입니다.
</Callout>

## 개인 계정으로 사업자 세금계산서를 받을 수 있나요?
개인 계정으로는 **사업자 세금계산서를 직접 발급받을 수 없습니다**. 사업자 세금계산서가 필요하다면 먼저 계정을 조직 계정으로 업그레이드하세요. 인증 심사가 완료되면 조직 명의로 세금계산서를 요청할 수 있습니다.

## 개인 계정을 조직 계정으로 업그레이드하려면 어떻게 해야 하나요?
1. [platform.kimi.ai](https://platform.kimi.ai) 콘솔에 로그인합니다.
2. **계정 설정 → 인증**으로 이동합니다.
3. **조직 인증**을 선택하고 필요한 정보를 입력합니다.
4. 심사를 제출합니다. 승인되면 계정이 자동으로 전환됩니다.

<Callout type="tip">
업그레이드 후에도 기존 잔액과 사용량 데이터는 그대로 유지됩니다.
</Callout>

## 개인 인증과 조직 인증의 차이
| 항목 | 개인 | 조직 |
| --- | --- | --- |
| 세금계산서 유형 | 개인 청구서 | 사업자 / 부가가치세 세금계산서 |
| Rate Limits | 표준 | 더 높은 quota 적용 가능 |
| 비즈니스 계약 | — | 계약 체결 가능 |
| 대량 이용 할인 | — | 요청 시 제공 가능 |
| 기술 지원 | 표준 | 우선 지원 |

## 계정 정지에 이의 제기하려면 어떻게 해야 하나요?
정책 위반으로 API 계정이 정지된 경우:
1. **support@moonshot.ai**로 이메일을 보내고 제목은 "API 계정 이의 제기"로 작성합니다.
2. 계정 정보(등록 이메일 주소)와 이의 제기 내용을 포함합니다.
3. 담당 팀이 검토한 뒤 영업일 기준 1~3일 이내에 답변합니다.

<Callout type="info">
**지원 이메일**: support@moonshot.ai
</Callout>

## 등록 이메일을 변경하려면 어떻게 해야 하나요?
등록 이메일을 변경하려면 지원팀에 문의하세요.
1. **support@moonshot.ai**로 이메일을 보내고 제목은 "이메일 변경 요청"으로 작성합니다.
2. 현재 이메일 주소와 새 이메일 주소를 모두 알려주세요.
3. 계정 보안을 위해 본인 확인이 필요할 수 있습니다.

## 인증 완료 시 혜택
- **더 높은 Rate Limits**: 인증된 사용자는 더 높은 API 호출 한도를 적용받을 수 있습니다.
- **전체 기능 이용**: 일부 고급 기능은 인증된 사용자에게만 제공될 수 있습니다.
- **세금계산서 지원**: 인증된 계정은 세금계산서를 요청할 수 있습니다.
- **기술 지원**: 인증된 사용자는 더 높은 우선순위의 기술 지원을 받습니다.
