# 청구 및 결제

<Callout type="info">
Kimi API 청구, 요금 및 결제에 관해 자주 묻는 질문입니다.
</Callout>

## 요금 체계는 어떻게 되나요?
Kimi API는 사용한 token 수를 기준으로 과금되며, input token과 output token은 각각 별도로 요금이 책정됩니다. 요금은 모델에 따라 다르며, Web Search는 호출당 $0.004의 추가 요금이 부과됩니다.

<Callout type="tip">
자세한 요금은 [platform.kimi.ai/docs/pricing/chat](https://platform.kimi.ai/docs/pricing/chat)에서 확인하세요.
</Callout>

## 어떤 결제 수단을 지원하나요?
API 콘솔에서는 다음 결제 수단을 지원합니다.
| 결제 수단 | 세부 정보 |
| --- | --- |
| **신용/직불 카드** | Visa, Mastercard 및 기타 주요 카드 |
| **전신 송금** | 조직 인증을 완료한 사용자는 전신 송금을 요청할 수 있습니다. 은행 계좌 정보는 영업팀에 문의하세요. |

충전한 금액은 API 사용에 즉시 반영됩니다.
## 인보이스는 어떻게 요청하나요?
1. [platform.kimi.ai](https://platform.kimi.ai) 콘솔에 로그인합니다.
2. **청구 → 인보이스 관리**로 이동합니다.
3. 인보이스가 필요한 충전 내역을 선택합니다.
4. 인보이스 정보(개인 또는 사업자)를 입력한 뒤 제출합니다.
5. 전자 인보이스가 이메일로 발송됩니다.
