# 비즈니스 협력 및 영업

<Callout type="info">
기업 고객을 위한 협력 방안 — 대량 사용 할인부터 맞춤형 SLA까지.
</Callout>

Kimi API는 모든 규모의 비즈니스 요구를 충족할 수 있도록 기업 고객에게 다양한 협력 방안을 제공합니다.
## 영업팀 문의 방법
[platform.moonshot.ai/contact-sales](https://platform.moonshot.ai/contact-sales)에서 문의 양식을 제출해 주세요. 영업팀이 영업일 기준 1~2일 이내에 연락드립니다.

<Callout type="tip">
**제출 시 포함할 내용**:
- 회사명 및 업종
- 예상 사용량
- 주요 사용 사례
- 희망 협력 모델
</Callout>

## 계약 체결
조직 인증을 완료한 사용자는 Moonshot과 정식 서비스 계약을 체결할 수 있습니다.
- 표준 서비스 계약과 맞춤 계약을 모두 이용할 수 있습니다.
- 계약 체결 후에는 계좌 이체 결제와 기업용 SLA를 이용할 수 있습니다.
- 구체적인 절차는 영업팀에 문의해 주세요.

## 대량 사용 할인
사용량이 많은 기업 고객은 전용 할인을 신청할 수 있습니다.
| 요건 | 세부 정보 |
| --- | --- |
| **자격** | 조직 인증 + 계약 체결 |
| **할인 단계** | 약정 사용량 및 계약 기간 기준 |
| **신청** | 예상 월간 사용량을 포함해 영업팀을 통해 신청 |

## 엔터프라이즈 API 서비스
엔터프라이즈 API 서비스는 표준 API 제공 범위에 다음을 더합니다.
- **더 높은 rate limit 및 concurrency quota**
- **전용 기술 지원 채널**
- **맞춤형 SLA 보장**
- **신규 기능 조기 이용**
