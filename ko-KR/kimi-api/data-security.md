# 데이터 처리 및 보안

<Callout type="info">
Kimi API의 사용자 데이터 보안 및 개인정보 보호 FAQ입니다.
</Callout>

Kimi API는 사용자 데이터 보안과 개인정보 보호를 매우 중요하게 여깁니다.
## 사용자 데이터가 모델 학습에 사용되나요?

<Callout type="warning">
**아니요.** API를 통해 제출된 사용자 데이터(입력 내용 및 모델 출력 포함)는 **Kimi 모델을 학습하거나 개선하는 데 사용되지 않습니다**. 고객님의 데이터는 현재 API 요청을 처리하는 데에만 사용되며, 학습 목적으로 영구 저장되지 않습니다.
</Callout>

## 비공개 데이터의 보안은 어떻게 보장되나요?
Kimi API는 고객님의 비공개 데이터를 보호하기 위해 여러 조치를 적용합니다.
| 조치 | 설명 |
| --- | --- |
| **전송 중 암호화** | 모든 API 통신에 HTTPS/TLS를 사용합니다 |
| **데이터 격리** | 서로 다른 사용자의 데이터를 엄격하게 분리합니다 |
| **학습에 미사용** | API 데이터는 모델 학습에 사용되지 않습니다 |
| **접근 제어** | 인가된 접근만 허용하도록 API Key 인증을 사용합니다 |
| **컴플라이언스 인증** | 플랫폼은 관련 보안 인증을 취득했습니다 |

<Callout type="tip">
더 높은 수준의 보안이 필요하다면 영업팀에 문의하여 엔터프라이즈급 보안 솔루션에 대해 알아보세요.
</Callout>

## 콘텐츠 안전성 검토
Kimi API에는 콘텐츠 안전성 검토 메커니즘이 기본으로 포함되어 있습니다.
- 시스템이 금지된 콘텐츠(불법 활동, 폭력, 노골적인 자료 등)를 자동으로 감지하고 필터링합니다
- 검토가 트리거되면 API는 적절한 오류 응답을 반환합니다
- 콘텐츠 검토 과정에서 원본 데이터가 저장되거나 노출되지 않습니다
- 검토가 잘못 트리거되었다고 생각되면 `request_id`와 함께 지원팀에 문의하세요
## 업로드한 파일은 어떻게 삭제하나요?
파일 API로 업로드한 파일은 언제든지 삭제할 수 있습니다.

<CodePreview
  files={[

/>

요청 헤더에 API Key를 포함하고 삭제할 파일 ID를 제공하세요. 삭제된 파일은 더 이상 참조할 수 없으며, 해당 데이터는 서버에서 제거됩니다.

<Callout type="info">
콘솔의 파일 관리 페이지에서도 업로드한 파일을 확인하고 삭제할 수 있습니다.
</Callout>
