# Kimi API 개요

Kimi API 플랫폼은 개발자에게 강력한 대규모 언어 모델 기능을 제공하여, 제품과 서비스에 AI를 빠르게 통합할 수 있도록 돕습니다.

## 플랫폼 개요

Kimi API는 Moonshot의 독자적인 대규모 언어 모델을 기반으로 하며, 텍스트 생성, 멀티턴 대화, 파일 파싱, Web Search 등 핵심 기능을 제공합니다. 이 플랫폼은 OpenAI API 형식과 호환되므로 개발자가 최소한의 노력으로 마이그레이션하고 통합할 수 있습니다.

**플랫폼 URL**: [platform.moonshot.ai](https://www.platform.moonshot.ai)

## 대상 사용자

- **개인 개발자**: AI 기반 개인 프로젝트와 도구를 빠르게 구축할 수 있습니다.
- **엔터프라이즈 엔지니어링 팀**: 엔터프라이즈 제품에 AI 기능을 내장해 사용자 경험과 운영 효율을 높일 수 있습니다.
- **스타트업**: 합리적인 비용으로 최고 수준의 AI 기능을 활용해 제품 반복 개발 속도를 높일 수 있습니다.

## 주요 사용 사례

- **지능형 고객 서비스**: 맥락을 이해하는 자동 Q&A로 지원 효율과 고객 만족도를 높입니다.
- **콘텐츠 생성**: 글 작성, 마케팅 카피, 코드 생성 등 다양한 창작 워크플로를 지원합니다.
- **데이터 분석**: 문서 해석, 보고서 분석, 지식 추출, 요약을 수행합니다.
- **지식 Q&A**: 비공개 문서 저장소를 기반으로 지능형 검색 및 질의응답 시스템을 구축합니다.

## 빠른 시작

1. [platform.moonshot.ai](https://platform.moonshot.ai)에 방문해 개발자 계정을 등록합니다.
2. 콘솔에서 API 키를 생성합니다.
3. API 문서를 참고해 첫 호출을 실행합니다.
4. 사용 사례에 맞는 모델과 매개변수를 선택합니다.
