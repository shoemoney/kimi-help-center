# 핵심 개념 및 터미널

## 주요 개념

| 개념 | 설명 |
|---------|-------------|
| **메모리** | Kimi Claw의 장기 기억 시스템입니다. 대화가 이어져도 사용자의 선호, 습관, 중요한 정보를 저장합니다. |
| **스킬** | ClawHub 라이브러리에서 설치할 수 있는 기능 모듈로, Kimi Claw에 특정 분야의 전문 역량을 더해 줍니다. |
| **HEARTBEAT** | 타이머에 따라 백그라운드에서 실행되는 예약 작업입니다. 반복 알림, 데이터 가져오기, 요약에 유용합니다. |
| **정체성** | Kimi Claw의 역할 정의입니다. 이름, 직업, 페르소나를 사용자가 자유롭게 설정할 수 있습니다. |
| **소울** | Kimi Claw의 대화 방식을 형성하는 핵심 성격 특성과 행동 원칙입니다. |
| **도구** | Kimi Claw가 호출할 수 있는 기능 모음입니다. 웹 검색, 파일 처리, 코드 실행 등이 포함됩니다. |
| **사용자** | 사용자와 Kimi Claw 사이의 관계 정의로, 상호작용 방식과 정보 공유 범위를 좌우합니다. |

## 터미널

  src="./images/concepts/screenshot-30.png"
  alt="스크린샷 30"

웹에서 **설정 → 터미널**을 통해 명령줄 인터페이스를 열고, 명령을 실행해 Kimi Claw를 직접 제어할 수 있습니다.

또는 Kimi Claw에게 실행할 명령을 자연어로 말해도 됩니다. Kimi Claw가 대신 실행해 줍니다.

> 참고: 터미널과 플러그인은 동일한 연결 채널을 공유합니다. OpenClaw 게이트웨이를 재시작하면 터미널 연결이 끊어집니다.

## 명령어 참조

### 시스템

| 명령어 | 설명 |
|---------|-------------|
| `/help` | 도움말 정보를 표시합니다 |
| `/status` | 현재 시스템 상태를 확인합니다 |
| `/ping` | 연결이 살아 있는지 테스트합니다 |
| `/cron` | 예약 작업을 관리합니다 |
| `/config` | 설정을 보거나 편집합니다 |
| `/new` | 새 대화를 시작합니다(현재 컨텍스트 삭제) |
| `/reset` | Kimi Claw를 재설정합니다 |
| `/compact` | 현재 대화 컨텍스트를 압축합니다 |
| `/stop` | 현재 실행 중인 작업을 중지합니다 |

### 스킬

| 명령어 | 설명 |
|---------|-------------|
| `/skills` | 스킬을 탐색, 설치, 관리합니다 |

### 예약 작업

| 명령어 | 설명 |
|---------|-------------|
| `/cron` | 작업 일정을 확인하고 관리합니다 |

### 메모리

| 명령어 | 설명 |
|---------|-------------|
| `/memory` | 장기 기억을 확인하고 관리합니다 |

### 설정 및 디버깅

| 명령어 | 설명 |
|---------|-------------|
| `/config` | 시스템 설정을 보거나 편집합니다 |
| `/logs` | 런타임 로그를 확인합니다 |
| `/debug` | 자세한 진단을 위해 디버그 모드를 활성화합니다 |
