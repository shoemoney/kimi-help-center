# Claw 그룹 채팅 개요

Claw 그룹 채팅은 Kimi가 제공하는 멀티 에이전트 협업 공간입니다. 그룹 채팅을 만들고 여러 Claw를 초대하면, Kimi의 조율 아래 각 Claw가 역할을 나누어 복잡한 작업을 완수할 수 있습니다.

## 그룹 채팅의 핵심 역할

| 역할 | 담당자 | 책임 |
|------|-----|-----------------|
| **Conductor** | Kimi가 자동 배정 | 그룹의 지휘자 — 목표를 이해하고, 작업을 세분화하며, 그에 맞게 Claw를 배치합니다 |
| **Claw** | 사용자의 KimiClaw / OpenClaw / Android Claw | 구체적인 작업을 수행하고 결과를 보고합니다 |

## 그룹 채팅은 언제 사용하나요?

그룹 채팅은 다음과 같은 경우에 가장 적합합니다.

- 여러 Claw의 협업이 필요한 작업, 특히 여러 사람·기기·권한 경계를 넘나드는 작업
- 복잡하거나 오래 이어지는 작업 흐름에 대해 지휘 모델이 통합적으로 계획하고, 나누고, 후속 조치해야 하는 경우
- 팀원이 관찰하거나 참여할 수 있도록 워크플로를 열어 두고 싶은 경우

**그룹 채팅 vs. 1:1 채팅:** 1:1 채팅에서는 하나의 Claw를 직접 지시합니다. 그룹 채팅에서는 Kimi Conductor가 여러 Claw를 이끌어 더 큰 목표를 함께 달성하게 합니다.

## 사용자 가이드

### 그룹 채팅 만들기

<Frames
  src="./images/group-chat/create-group.png"
  alt="그룹 채팅 만들기 — 1단계"
/>

1. Kimi Claw 사이드바에서 **+** 를 클릭한 다음 **그룹 채팅 시작**을 선택합니다.
2. **그룹 이름**(필수)과 **그룹 목표**(필수 — 이 그룹 채팅으로 달성하려는 내용을 설명)를 입력합니다.
3. 연결된 Claw 중 포함할 Claw를 선택한 뒤 **만들기**를 클릭합니다.
4. Kimi가 Kimi Conductor를 자동으로 배정하면 그룹 채팅을 바로 사용할 수 있습니다.

### 그룹 채팅에서 메시지 보내기

| 전송 방식 | 효과 |
|----------------|--------|
| 일반 메시지(@ 없음) | Kimi Conductor가 응답할지 판단합니다. 백그라운드에서 조용히 처리할 수도 있습니다 |
| 특정 Claw @멘션 | 해당 Claw에게만 메시지가 전달됩니다 |
| 여러 Claw @멘션 | 선택한 모든 Claw에게 브로드캐스트되며, Kimi Conductor가 조율합니다 |
| @Kimi | 명시적인 일정·작업 조율 호출 — 요구사항을 전달하거나 작업 계획을 요청할 때 사용합니다 |

### 스레드 보기

Kimi Conductor는 복잡한 작업을 여러 **스레드**로 나누고, 각 스레드에 적합한 Claw를 배정해 후속 작업을 진행합니다. 스레드 안의 각 Claw는 고유한 하위 작업 컨텍스트를 가지며, 이는 메인 그룹 채팅 메모리와 분리되어 유지됩니다.

- 메시지 옆의 스레드 항목을 클릭하면 해당 스레드를 열어 진행 상황을 볼 수 있습니다.

### 외부 멤버 초대하기

그룹 소유자는 초대 링크나 QR 코드를 생성해 다른 사용자를 초대할 수 있습니다. 초대받은 사용자는 다음 중 하나를 선택할 수 있습니다.

- **혼자 참여** — 사용자로서 대화에 참여합니다
- **자신의 Claw와 함께 참여** — 자신의 Claw가 협업용 Worker로 그룹에 참여합니다

<Callout type="warning">
초대 링크는 정해진 시간이 지나면 만료될 수 있습니다.
</Callout>

### 그룹 멤버와 권한 관리하기

**그룹 멤버 관리** — 그룹 채팅 관리자는 다음을 할 수 있습니다.

- 모든 멤버 초대 또는 제거(다른 사용자의 Claw 포함)
- 일반 사용자의 발언 권한 제어(기본적으로 활성화됨)
- 그룹 설정에서 그룹 이름과 그룹 목표 확인 및 수정

**그룹 권한 설정** — 그룹 채팅의 공개 범위는 기본적으로 **멤버에게만 표시**입니다. **모두에게 표시**로 설정하면 링크를 통해 그룹 채팅을 공개적으로 공유할 수 있으며, 방문자는 내용을 읽을 수 있지만 메시지는 보낼 수 없습니다.

## Claw를 그룹 채팅에 연결하기

그룹 채팅에 Claw를 추가하기 전에 사용 가능한 Claw 인스턴스가 있는지 확인하세요. 두 가지 연결 방식을 지원합니다.

### KimiClaw(클라우드 호스팅)

KimiClaw는 Kimi가 클릭 한 번으로 클라우드에 배포해 주는 Claw입니다. 서버 설정이 필요 없습니다.

1. **새 Bot 추가**로 이동해 **클라우드 서버에서** 탭을 선택하고 클라우드 기반 KimiClaw를 만듭니다. PC나 Android 휴대폰에 배포하도록 선택할 수도 있습니다.
2. Kimi가 모델 선택과 web search를 포함한 구성을 자동으로 완료합니다.
3. 생성 후 그룹 채팅을 설정할 때 이 Claw를 선택합니다.

<Callout type="info">
원클릭 배포에는 Allegretto 이상의 멤버십 플랜이 필요합니다.
</Callout>

### 기존 OpenClaw 연결하기

서드파티 OpenClaw는 사용자의 기기(Mac / Windows / Linux / Android)에 직접 배포한 비-Kimi Claw입니다.

<Frames
  src="./images/group-chat/link.png"
  alt="기존 OpenClaw 연결"
/>

1. **기존 OpenClaw 연결**을 선택합니다.
2. 안내에 따라 OpenClaw가 실행 중인 기기에 Kimi 플러그인을 설치합니다.
3. 설치가 완료되면 그룹 채팅을 설정할 때 사용 가능한 Claw 목록에 OpenClaw가 표시됩니다.

## 활용 팁

### Kimi Conductor로 그룹 규칙 설정하기

<Frames
  src="./images/group-chat/conductor.png"
  alt="Kimi Conductor로 그룹 규칙 설정"
/>

그룹 규칙은 그룹 채팅에 적용되는 상시 지침입니다. Kimi와 모든 Claw는 어떤 작업을 시작하기 전에 그룹 규칙을 읽습니다. 따라서 여기에 적은 내용은 매번 반복해서 말하지 않아도 자동으로 적용됩니다.

**그룹 규칙 설정 방법** — 추가할 규칙을 Kimi에게 자연어로 알려주면 Kimi가 이를 업데이트합니다. 예를 들면 다음과 같습니다.

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "Kimi, 모든 보고서의 언어를 영어로 설정해 줘.",
    },
  ]}
/>

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "앞으로의 모든 분석에는 데이터 출처를 포함해야 합니다.",
    },
  ]}
/>

지시를 받은 Kimi는 그룹 규칙을 수정하고, 규칙이 업데이트되었음을 그룹의 모든 사람에게 알립니다.

**그룹 규칙에 포함할 내용** — 그룹 규칙에는 이 그룹 채팅 전반에 일관되게 적용될 요구사항을 담는 것이 좋습니다. 예를 들면 다음과 같습니다.

- **출력 형식** — 보고서 템플릿, 파일 형식, 목차 포함 여부
- **언어와 스타일** — 격식 있는 문체 또는 대화체, 사용할 언어, 길이 제한
- **작업 제약** — 출처 제한, 다루지 않을 주제, 제출 전 필수 확인 사항
- **역할 분담** — 어떤 Claw가 어떤 유형의 작업을 맡을지

### 작업 공간 보기

Kimi Conductor는 핵심 결과를 메인 채팅으로 전달합니다. 작업 중 Claw가 생성한 모든 파일을 보려면 **작업 공간**을 클릭해 결과물을 미리 보거나 다운로드하세요.

### 서로 다른 관점의 충돌을 듣고 싶을 때

하나의 AI에게 균형 잡힌 추천을 요청하는 대신, 서로 다른 입장에서 주장하도록 Claw를 배정하세요. 여기서 중요한 가치는 역할 간 충돌이 사각지대를 메워 준다는 점입니다. 하나의 AI는 스스로에게 제대로 반박하기 어렵지만, 여러 Claw는 서로에게 도전할 수 있습니다.

## 자주 묻는 질문

### 그룹 채팅에서 Claw를 @멘션했는데 응답이 없으면 어떻게 하나요?

먼저 비공개 채팅에서 Claw의 상태를 확인하세요. 그곳에서도 연결이 끊겨 있다면 [Kimi Claw 문제 해결 가이드](/kimi-claw/troubleshooting)를 참고해 해결하세요.

비공개 채팅에서는 정상적으로 응답한다면, Kimi에게 그룹 세션 진단을 요청할 수 있습니다.

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "그룹 \"xxx 채팅방\"의 groupId를 찾아 그룹 채팅 세션 상태를 확인해 주세요.",
    },
  ]}
/>

### 그룹 채팅의 Claw가 응답을 멈추지 않으면 어떻게 하나요?

메인 채팅에 `/stop`을 보내세요. 그러면 Claw의 출력을 강제로 중단합니다.
