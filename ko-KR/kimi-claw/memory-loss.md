# 메모리 손실과 컨텍스트

## 어제 나눈 대화가 왜 사라졌나요?

OpenClaw는 매일 **오전 4:00**에 대화를 자동으로 초기화합니다. 컨텍스트가 지나치게 길어져 환각이 발생하거나 답변 품질이 떨어지는 일을 막기 위해서입니다.

초기화 시간을 조정해야 한다면 `config.yaml`에서 일정을 수정할 수 있습니다.

**권장 방법:** 선호 사항, 프로젝트 세부 정보, 반복해서 적용할 지시처럼 중요한 내용은 Kimi Claw에게 명시적으로 저장하라고 알려 주세요. _"이 내용을 Memory에 기억해 둬."_ Memory에 저장된 정보는 대화가 초기화되어도 유지됩니다.

## Kimi Claw가 기억을 잃었나요?

매일 오전 4시에 진행되는 초기화는 활성 대화 컨텍스트를 지웁니다. 어떤 내용이 **Memory**에 저장되어 있지 않았다면 사라집니다.

**해결 방법:**
- 대화 중에 _"X를 Memory에 기억해 둬"_ 라고 말하면 Kimi Claw가 장기 저장소에 기록합니다.
- 저장된 메모리는 **작업공간 → AGENTS.md → #MEMORY**에서 확인할 수 있습니다.

- 저장된 메모리를 보고 관리하려면 언제든 `/memory` 명령을 사용하세요.

## 구독이 끝난 뒤 메모리는 얼마나 오래 보관되나요?

Memory 파일은 Workspace에 저장되며, 언제든지 보거나 다운로드할 수 있습니다.

- 멤버십이 만료된 뒤에도 클라우드 인스턴스는 **7일 동안 보관**됩니다.
- 7일 이내에 갱신하면 메모리, 구성, 스킬을 포함한 모든 데이터가 완전히 복원됩니다.
- 7일이 지나면 인스턴스가 회수될 수 있으며 데이터는 영구적으로 삭제될 수 있습니다.
- 더 쉬운 마이그레이션을 위해 메모리 내보내기/백업 기능을 개발 중입니다.
