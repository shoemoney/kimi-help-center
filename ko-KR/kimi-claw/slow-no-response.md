# 응답이 없거나 느린가요?

<Callout type="info">
Kimi Claw가 답하지 않거나 평소보다 유난히 느리다면 몇 가지 원인이 있을 수 있습니다. 아래 문제 해결 절차를 따라 확인해 보세요.
</Callout>

## 일반적인 원인

| 원인 | 설명 |
|-------|-------------|
| **브리지 연결 끊김** | Kimi Claw와 서버 간 연결이 끊어졌습니다. 게이트웨이를 다시 시작해야 합니다 |
| **리소스 혼잡** | 서버 부하가 높아 응답이 지연될 수 있습니다 |
| **인스턴스 오프라인** | Kimi Claw 인스턴스가 오프라인 상태가 되었으며 복구가 필요합니다 |

## 어떻게 해결하나요?

문제가 해결될 때까지 아래 단계를 순서대로 진행하세요.

1. **메시지를 다시 보내기** — 일시적인 지연일 수 있습니다. 후속 메시지를 보내면 응답이 다시 시작될 수 있습니다
2. **페이지 새로고침** — Kimi Claw 대화를 닫았다가 다시 여세요
3. **게이트웨이 다시 시작** — **설정**으로 이동해 **Kimi Claw 재시작**을 클릭하세요. 다시 온라인 상태가 될 때까지 기다립니다
4. **자동 복구** — 설정에서 **Kimi Claw 복구**를 클릭하세요. 시스템이 구성 문제를 자동으로 감지하고 수정합니다
5. **초기 설정 복원** — 다른 방법으로 해결되지 않으면 설정에서 **초기 설정 복원**을 선택하세요

## 초기 설정 복원 안내

<Callout type="warning">
이 작업은 Kimi Claw를 공장 초기 상태로 되돌립니다. 다만 다음 사항은 참고하세요.

- **보존됨:** 작업 공간 파일 및 장기 메모리
- **재설정 필요:** 채팅 플랫폼 연결(Telegram 등)은 다시 설정해야 합니다
</Callout>
