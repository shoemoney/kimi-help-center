# 일반 문제 해결

이 페이지에서는 Kimi Claw의 일반적인 오류 코드와 자가 복구 방법을 안내합니다.

## 일반적인 오류 코드

| 코드 | 의미 | 조치 방법 |
|------|---------|------------|
| **400** | 잘못된 요청 — 입력 형식이 올바르지 않거나 매개변수가 유효하지 않습니다 | 메시지에 지원되지 않는 콘텐츠가 포함되어 있는지 확인한 뒤 다시 시도하세요. |
| **401** | 인증되지 않음 — 인증에 실패했습니다 | Kimi에서 로그아웃한 뒤 다시 로그인하세요. 문제가 계속되면 Kimi Claw 설정에서 API 자격 증명을 확인하세요. |
| **403** | 금지됨 — 권한이 부족합니다 | 현재 멤버십 등급에서 사용 중인 기능을 지원하는지 확인하세요. 계정에 제한이 걸려 있지 않은지도 확인하세요. |
| **429** | Too Many Requests — rate limit을 초과했습니다 | 몇 분 기다린 뒤 다시 시도하세요. quota 확인 방법은 [대화 한도](/kimi-claw/conversation-limits)를 참고하세요. |
| **500** | Internal Server Error — 서버에서 문제가 발생했습니다 | 잠시 기다렸다가 다시 시도하세요. 같은 문제가 반복되면 아래 자가 복구 옵션을 사용하거나 지원팀에 문의하세요. |

## 자가 복구 옵션

Kimi Claw는 웹의 **설정**에서 사용할 수 있는 기본 복구 도구를 제공합니다.

| 옵션 | 기능 |
|--------|--------------|
| **Kimi Claw 다시 시작** | 게이트웨이 연결을 다시 시작합니다. 대부분의 일시적인 문제(브리지 연결 해제, 임시 멈춤)를 해결합니다. |
| **Kimi Claw 복구** | 설정 문제를 감지하고 수정하는 자동 진단을 실행합니다. 단순 재시작으로 해결되지 않을 때 사용해 보세요. |
| **초기 설정 복원** | Kimi Claw를 기본 상태로 재설정합니다. 워크스페이스 파일과 메모리는 유지되지만 채팅 플랫폼 연결(Telegram 등)은 다시 설정해야 합니다. 최후의 수단으로 사용하세요. |

## 에스컬레이션 절차

자가 복구 옵션으로 문제가 해결되지 않으면 다음을 진행하세요.

1. Terminal에서 `/logs`를 실행해 최근 오류 출력을 캡처합니다.
2. `/debug`를 실행해 상세 진단을 활성화합니다.
3. 오류 세부 정보와 관련 로그를 첨부해 **support@moonshot.ai**로 문의하세요.
