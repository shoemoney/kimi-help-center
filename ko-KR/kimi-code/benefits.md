# Kimi Code 혜택

Kimi Code는 Kimi 멤버십 플랜에 포함된 서비스로, 코딩 관련 지원과 기능을 제공해 개인 개발 워크플로에서 프로그래밍 작업을 더 효율적으로 완료할 수 있도록 돕습니다.

> 이 혜택은 기업 개발 환경이 아닌 개인 개발 용도로만 제공된다는 점에 유의하세요. 기업 용도가 필요하다면 [Kimi 오픈 플랫폼](https://platform.kimi.ai/)을 방문하세요.

## 요금

- Kimi Code 사용량은 **구독료에 포함**되어 있으며, 추가 요금이 부과되지 않습니다.
- Kimi Code는 **Kimi 멤버십 플랜과 동일한 크레딧을 공유합니다** — CLI, VS Code, 서드파티 도구에서의 요청이 모두 여기에서 차감되며, 플랜마다 포함된 크레딧 양이 다릅니다.
- 시스템은 플랜 credit을 소모하기 전에 보너스 credit을 우선 사용합니다.

<Callout type="warning">
**새로운 멤버십 체계가 곧 출시됩니다.** Kimi 멤버십 혜택과 Kimi Code 혜택이 분리되어, 필요에 따라 각각 구매할 수 있게 됩니다 — 더 유연해집니다. **현재 구독 중인 사용자는 영향을 받지 않습니다.** 통합 혜택을 계속 사용하려면 새 체계가 출시되기 전에 현재 플랜을 구매하세요.
</Callout>

## 크레딧 갱신

Credit은 **7일** 주기로 갱신됩니다.

- 구독일(D1)을 기준으로 credit이 7일마다 갱신됩니다.
- 갱신 기간: D1–D7, D8–D14, D15–D21, D22–D28.
- 사용하지 않은 credit은 다음 주기로 이월되지 **않습니다**.

> 주간 사용량을 계획해 credit을 최대한 활용하세요.

## 지원 도구

Kimi Code 혜택은 다음 도구에서 사용할 수 있습니다.

| 도구 | 설명 |
| --- | --- |
| **Kimi Code CLI** | Kimi 공식 명령줄 AI 에이전트 |
| **Claude Code** | Anthropic의 명령줄 코딩 어시스턴트 |
| **Roo Code** | VS Code용 AI 코딩 확장 프로그램 |

위에 나열된 도구 외에도, 구독자는 API Key를 통해 Kimi Code를 OpenCode 등 더 많은 서드파티 개발 도구에 연결할 수 있습니다. 자세한 내용은 [서드파티 코딩 에이전트와 함께 사용하기](/kimi-code/third-party-agents)를 참고하세요. 서드파티 도구를 사용할 때는 도구의 실제 신원을 유지해야 합니다. 클라이언트 식별자(User-Agent)를 위조하는 행위는 위반으로 간주되어 멤버십 혜택이 정지될 수 있습니다.

## Extra Usage

구독 크레딧이 모두 소진되어도 갱신을 기다리지 않고 **Extra Usage** 잔액으로 요청을 계속 보낼 수 있습니다. 구독 회원만 활성화할 수 있으며, **웹 Kimi와 Kimi Code는 동일한 Extra Usage 잔액을 공유합니다**(한 번 충전하면 양쪽에서 사용). 전체 약관은 [Extra Usage 약관](https://www.kimi.com/user/agreement/extra-usage-rules-cn)을 참고하세요.

### 충전 경로

- **메인 사이트에서**: Kimi [구독 페이지](https://www.kimi.com/membership/subscription?tab=quota)를 열고 하단의 「Extra Usage」 모듈까지 스크롤한 뒤 금액을 선택하고 결제를 완료합니다.
- **Kimi Code Console에서**: 주간 또는 5시간 사용량이 **80%**를 초과하면 진행률 카드에 구독 페이지로 이동하는 **Extra Usage 구매** 버튼이 표시됩니다.

### 활성화 및 관리

「Extra Usage」 스위치를 켜면 구독 크레딧이 소진될 때 시스템이 자동으로 Extra Usage 잔액에서 차감합니다. 모듈의 **설정**을 클릭하면 **월 지출 한도**를 활성화하고 이번 달 사용 가능한 최대 금액을 설정할 수 있으며, 진행률 표시줄에 이번 달 Extra Usage 사용량이 실시간으로 표시됩니다.

### 청구 및 규칙

- **청구**: 실제 사용량 기준 — 읽고 생성하는 내용이 많고 작업이 복잡할수록 비용이 높아집니다. 잔액은 위안화(RMB)로 표시되며 요율은 플랫폼 표시 기준입니다. Extra Usage 가격은 [Kimi Open Platform](https://platform.kimi.com)의 공식 API 가격에 가깝고, 사용량이 많은 경우 구독 업그레이드가 보통 더 경제적입니다.
- **차감 우선순위**: 구독 등 기간제 크레딧이 먼저 차감되고, **Extra Usage는 마지막**에 예비로 차감됩니다. 활성화 후에는 구독 크레딧이 모두 소진되어도 Extra Usage가 끊김 없이 사용되어 작업이 멈추거나 오류가 나지 않습니다.
- **지출 한도**: 설정에서 「월 지출 한도」를 활성화하여 이번 달 Extra Usage 지출을 제한할 수 있습니다. 설정하지 않으면 한도가 없습니다.
- **유효기간 및 누적**: 잔액은 만료되지 않고 충전할 때마다 누적됩니다. 구독 종료 후에도 사용할 수 있지만 중단 기간에는 충전할 수 없으므로 먼저 다시 구독한 뒤 충전하세요.
- **환불**: 일반적으로 환불, 양도, 현금화가 불가합니다.

<Callout type="info">
청구 예시(규모 파악용이며 실제 요율은 플랫폼 기준): 간단한 요청(예: 「록 음악 한 곡 추천해 줘」)은 약 **¥0.03**, 복잡한 다단계 작업(예: 「청두에서 서부 쓰촨까지 일주일 자동차 여행 계획해 줘」)은 약 **¥1.6**입니다. 충전 한도: 1회 최소 ¥25, 하루 최대 10회·¥3,000, 잔액 상한 ¥10,000.
</Callout>

### 사용량 확인

- **Kimi 웹 / 앱**: 설정 → 구독 및 청구서 → [내 크레딧](https://www.kimi.com/membership/subscription?tab=quota).
- **Kimi Code Console**: Extra Usage 활성화 후 [Console](https://www.kimi.com/code/console)에 로그인하여 잔액과 사용량을 확인합니다.
- **Kimi Code CLI**: 명령줄에 `/usage`를 입력하면 바로 확인할 수 있습니다.

### Extra Usage 자주 묻는 질문

- **웹 Kimi와 Kimi Code는 동일한 Extra Usage 지갑을 사용하나요?** 예 — 잔액이 양쪽에서 공유되며, 한 번 충전하면 어느 쪽에서든 사용할 수 있습니다.
- **Extra Usage와 구독 크레딧 중 무엇이 먼저 차감되나요?** 구독 등 기간제 크레딧이 먼저이며, Extra Usage는 모든 기간제 크레딧이 소진된 후에만 예비로 차감됩니다.
- **한도에 도달하거나 속도 제한이 걸려도 계속할 수 있나요?** 예. Extra Usage를 활성화하면 구독 한도의 영향을 받지 않습니다. 어떤 한도에 도달하든 끊김 없이 Extra Usage 잔액으로 전환되어 작업이 멈추지 않으며, Extra Usage만 차감되고 멤버십 크레딧 갱신에는 영향을 주지 않습니다.
- **사용하지 않은 잔액은 이월되고 누적되나요?** 예 — 만료되지 않고 누적됩니다. 구독 종료 후에도 사용할 수 있지만 중단 기간에는 충전할 수 없습니다.
- **Extra Usage는 Enterprise에서 사용할 수 있나요?** 아직 지원하지 않습니다.
- **계정을 삭제하면 잔액이 환불되나요?** [membership@moonshot.ai](mailto:membership@moonshot.ai)으로 이메일을 보내 환불을 요청하세요.
