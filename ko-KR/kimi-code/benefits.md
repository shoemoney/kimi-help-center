# Kimi Code 혜택

Kimi Code는 Kimi 멤버십 플랜에 포함된 서비스로, 코딩 관련 지원과 기능을 제공해 개인 개발 워크플로에서 프로그래밍 작업을 더 효율적으로 완료할 수 있도록 돕습니다.

> 이 혜택은 기업 개발 환경이 아닌 개인 개발 용도로만 제공된다는 점에 유의하세요. 기업 용도가 필요하다면 [Kimi 오픈 플랫폼](https://www.platform.moonshot.ai/)을 방문하세요.

## 요금

- Kimi Code 사용량은 **구독료에 포함**되어 있으며, 추가 요금이 부과되지 않습니다.
- 각 요청은 **Kimi Code 전용 quota 풀**에서 credit을 소모하며, 플랜마다 포함된 credit 양이 다릅니다.
- 시스템은 플랜 credit을 소모하기 전에 보너스 credit을 우선 사용합니다.

## Credit 갱신

Credit은 **7일** 주기로 갱신됩니다.

- 구독일(D1)을 기준으로 credit이 7일마다 갱신됩니다.
- 갱신 기간: D1–D7, D8–D14, D15–D21, D22–D28.
- 사용하지 않은 credit은 다음 주기로 이월되지 **않습니다**.

> 주간 사용량을 계획해 credit을 최대한 활용하세요.

## 지원 도구

Kimi Code 혜택은 다음 도구에서 사용할 수 있습니다.

| 도구 | 설명 |
| --- | --- |
| **Kimi Code CLI** | Kimi 공식 명령줄 AI 에이전트 |
| **Claude Code** | Anthropic의 명령줄 코딩 어시스턴트 |
| **Roo Code** | VS Code용 AI 코딩 확장 프로그램 |

위에 나열되지 않은 플랫폼이나 도구에서 Kimi Code API Key를 사용하면 오남용으로 간주되어 접근이 제한될 수 있습니다. 최상의 경험과 적용 범위를 위해 위에 나열된 지원 도구를 사용하세요.
