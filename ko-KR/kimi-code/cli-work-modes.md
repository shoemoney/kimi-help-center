# 작업 모드

## 계획 모드

계획 모드는 AI가 코딩을 시작하기 전에 구현 계획을 세울 수 있게 해 주는 읽기 전용 계획 모드입니다. 잘못된 방향으로 작업해 시간을 낭비하는 일을 줄여 줍니다.

계획 모드에서 AI는 읽기 전용 도구(`Glob`, `Grep`, `ReadFile`)만 사용해 코드베이스를 탐색할 수 있습니다. 파일을 수정하거나 명령을 실행할 수는 없습니다. AI는 전용 계획 파일에 계획을 작성한 뒤 승인을 요청합니다. 사용자는 이를 승인하거나 거절할 수 있으며, 수정 의견을 남길 수도 있습니다.

### 계획 모드로 들어가기

계획 모드로 들어가는 방법은 네 가지입니다.

- **시작 옵션**: `kimi --plan`을 사용해 새 세션을 곧바로 계획 모드로 시작합니다
- **키보드 단축키**: `Shift-Tab`을 눌러 계획 모드를 켜거나 끕니다
- **슬래시 명령**: `/plan` 또는 `/plan on`을 입력합니다
- **AI 요청**: 복잡한 작업의 경우 AI가 `EnterPlanMode` 도구를 통해 계획 모드 진입을 요청할 수 있습니다. 사용자는 수락하거나 거절할 수 있습니다

구성 파일에서 `default_plan_mode = true`를 설정하면 새 세션이 기본적으로 항상 계획 모드에서 시작됩니다.

계획 모드에 들어가면 프롬프트가 `📋`로 바뀌고, 하단 상태 표시줄에 파란색 `plan` 표시가 나타납니다.

### 계획 검토 및 승인

AI가 계획 작성을 마치면 `ExitPlanMode`를 통해 승인을 요청합니다. 승인 패널에는 전체 계획이 표시됩니다. 사용자는 다음 작업을 할 수 있습니다.

- **실행 승인**: 계획에 여러 구현 경로가 포함되어 있으면 AI가 사용자가 선택할 수 있도록 2–3개의 라벨이 붙은 옵션(예: "계획 A" 또는 "계획 B (권장)")을 제시합니다. 하나를 선택하면 AI가 계획 모드를 종료하고 해당 경로를 실행합니다. 경로가 하나뿐이면 **승인** 버튼이 표시됩니다
- **거절**: 계획을 거절하고 계획 모드에 머뭅니다. 대화에서 피드백을 제공할 수 있습니다
- **거절하고 종료**: 계획을 거절하고 동시에 계획 모드를 종료합니다
- **수정**: 수정 의견을 입력합니다. AI가 그에 맞춰 계획을 업데이트한 뒤 다시 제출합니다

전체 화면 페이저에서 전체 계획을 보려면 `Ctrl-E`를 누르세요.

### 계획 모드 관리

`/plan` 명령으로 계획 모드를 관리할 수 있습니다.

- `/plan`: 계획 모드를 켜거나 끕니다
- `/plan on`: 계획 모드를 켭니다
- `/plan off`: 계획 모드를 끕니다
- `/plan view`: 현재 계획을 봅니다
- `/plan clear`: 현재 계획 파일을 지웁니다

## Thinking mode

Thinking mode는 AI가 응답하기 전에 더 깊이 사고하도록 해 주므로 복잡한 문제에 적합합니다.

`/model` 명령을 사용해 모델과 Thinking mode를 전환할 수 있습니다. 모델을 선택한 뒤 해당 모델이 Thinking mode를 지원하면, 시스템에서 활성화 여부를 묻습니다. 시작할 때 `--thinking` 옵션으로 활성화할 수도 있습니다.
