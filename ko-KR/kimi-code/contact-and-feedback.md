# 문의 및 피드백

## 피드백 채널

Kimi Code를 사용하다가 문제가 생기거나 제안하고 싶은 점이 있다면 아래 채널로 피드백을 보내 주세요.

### 방법 1: CLI에서 바로 피드백 보내기

Kimi Code CLI의 대화형 모드에서 `/feedback` 명령어를 입력해 피드백을 제출할 수 있습니다. 시스템이 현재 환경 정보를 자동으로 수집하므로 문제를 더 정확하게 설명하는 데 도움이 됩니다.

### 방법 2: GitHub Issues

[Kimi CLI GitHub Issues](https://github.com/MoonshotAI/kimi-cli/issues)에 방문해 비슷한 문제가 이미 등록되어 있는지 먼저 검색해 보세요. 없다면 새 Issue를 만들어 겪은 상황을 자세히 설명할 수 있습니다.

### 방법 3: 이메일 피드백

문제 신고는 [code@moonshot.ai](mailto:code@moonshot.ai)로 Kimi Code 팀에 이메일을 보내도 됩니다. 가능하다면 아래 정보를 최대한 포함해 주세요.

- **문제 설명**: 겪은 문제나 원하는 기능을 명확하게 설명해 주세요
- **재현 단계**: 문제를 발생시키는 방법을 단계별로 적어 주세요
- **환경 정보**: 운영체제와 Kimi Code CLI 버전(`kimi --version`으로 확인)
- **오류 로그**: 오류 메시지가 있다면 전체 내용을 그대로 붙여 주세요

### 방법 4: Feishu 그룹 참여
QR 코드를 스캔해 Feishu 그룹에 참여하세요

## 피드백 제출 전 문제 해결 확인

피드백을 제출하기 전에 다음 사항을 확인하는 것을 권장합니다.

- Kimi Code CLI를 최신 버전으로 업데이트했는지 확인(`kimi --version`으로 확인)
- 네트워크 연결이 정상이며 `api.kimi.com`에 접속할 수 있는지 확인
- API Key가 유효하고 만료되지 않았는지 확인
- 작업 디렉터리가 올바르며 Kimi가 관련 파일에 접근할 권한을 가지고 있는지 확인

## 기타 문의 채널

|---------|------|

| 미디어 문의 | [pr@kimi.com](mailto:pr@kimi.com) |
