# 시작하기 전에

Kimi Code를 사용하려면 먼저 몇 가지 기본 개념을 알아두는 것이 좋습니다. 설치와 사용이 훨씬 수월해집니다.

## 터미널이란 무엇인가요?

**터미널**은 텍스트 명령어를 입력해 컴퓨터를 조작하는 창입니다.

“텍스트 기반 파일 관리자”라고 생각하면 쉽습니다. 터미널에서는 마우스로 아이콘을 클릭하는 대신 `ls`, `cd`, `mkdir` 같은 명령어를 입력해 폴더 내용을 확인하고, 디렉터리를 이동하고, 파일을 만드는 등의 작업을 합니다.

### 터미널을 여는 방법

| 운영체제 | 여는 방법 |
|---------|---------|
| **macOS** | `Cmd + Space`를 누르고 "터미널" 또는 "Terminal"을 입력한 뒤 Enter를 누릅니다 |
| **Windows** | `Win + R`을 누르고 `powershell` 또는 `wt`를 입력합니다.<br>또는 시작 메뉴에서 "PowerShell"/"터미널"을 검색합니다 |
| **Linux** | `Ctrl + Alt + T`를 누르거나 애플리케이션 메뉴에서 "터미널"을 찾습니다 |

### 운영체제를 확인하는 방법

- **macOS**: 화면 왼쪽 위의 Apple 아이콘을 클릭한 뒤 → "이 Mac에 관하여"를 선택합니다
- **Windows**: `Win + Pause/Break`를 누르거나 "내 PC"를 마우스 오른쪽 버튼으로 클릭한 뒤 → "속성"을 선택합니다
- **Linux**: 터미널에서 `uname -a` 또는 `cat /etc/os-release`를 실행합니다

## PowerShell이란 무엇인가요?

**PowerShell**은 Windows에서 흔히 사용하는 터미널 도구입니다. 기본 명령 프롬프트(CMD)보다 더 강력합니다. Windows에서는 Kimi Code CLI를 반드시 PowerShell에서 설치하고 사용해야 합니다.

Windows에는 서로 다른 “명령줄” 도구가 두 가지 있습니다. 혼동하지 마세요.

| 도구 | 설명 | 적합한가요? |
|-----|------|---------|
| **CMD (Command Prompt)** | Windows의 가장 기본적인 명령줄 도구 | ❌ 권장하지 않음 |
| **PowerShell** | 더 강력하고 현대적인 명령줄 도구 | ✅ 권장 |

> **팁**: Kimi Code CLI 설치 명령은 반드시 PowerShell에서 실행해야 합니다. CMD에서는 제대로 실행되지 않을 수 있습니다.

## 작업 디렉터리

Kimi Code CLI가 시작되면 현재 폴더를 **작업 디렉터리**로 사용합니다. 해당 작업 디렉터리 안의 파일만 읽고 수정할 수 있습니다.

**시작하기 전에 터미널에서 현재 경로를 확인하세요**:

- 터미널 프롬프트에는 보통 `~/projects/my-app$`처럼 현재 디렉터리가 표시됩니다
- 전체 경로를 보려면 `pwd`(macOS/Linux) 또는 `cd`(Windows)를 입력합니다
- `cd <folder-name>`으로 대상 프로젝트 디렉터리에 들어간 뒤 `kimi`를 실행합니다

> **예시**: 프로젝트가 `~/Documents/my-project`에 있다고 가정해 보겠습니다. 다음 순서로 시작하세요.
> 1. 터미널을 엽니다
> 2. `cd ~/Documents/my-project`를 입력합니다
> 3. `kimi`를 입력해 시작합니다

## 명령을 실행하는 방법

터미널이나 PowerShell에서 명령을 실행하는 방법은 간단합니다.

1. **명령 복사**: 문서에서 명령 텍스트를 복사합니다
   - macOS/Linux: `curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash`
   - Windows: `irm https://code.kimi.com/kimi-code/install.ps1 | iex`
2. **터미널에 붙여넣기**: 터미널 창에서 마우스 오른쪽 버튼을 클릭하거나 `Cmd/Ctrl + V`를 눌러 붙여넣습니다
3. **Enter 누르기**: `Enter` 키를 눌러 명령을 실행합니다
4. **완료될 때까지 기다리기**: 터미널에 실행 과정과 결과가 표시됩니다

> **참고**: 터미널에서 `Ctrl+C`는 보통 **현재 실행 중인 명령을 중단**하는 단축키이며, 텍스트를 복사하지 않습니다. 복사하려면 `Cmd/Ctrl + Shift + C`, 붙여넣으려면 `Cmd/Ctrl + Shift + V`를 사용하거나 마우스 오른쪽 버튼 메뉴를 이용하세요.

> **팁**: 명령 실행 중 비밀번호 입력을 요청받으면 터미널에는 아무 문자도 표시되지 않습니다. 정상적인 보안 방식입니다. 비밀번호를 입력한 뒤 Enter를 누르면 됩니다.

## CLI란 무엇인가요?

**CLI**는 **C**ommand-**L**ine **I**nterface의 약자입니다. 그래픽 인터페이스에서 버튼을 클릭하는 대신 텍스트 명령어를 입력해 도구를 사용하는 방식을 뜻합니다.

Kimi Code CLI는 명령줄 도구입니다. 터미널에서 `kimi`를 입력해 시작한 뒤, 텍스트 명령으로 AI와 상호작용하며 코드 읽기, 파일 수정, 명령 실행 등의 도움을 받을 수 있습니다.

## 네트워크 환경

Kimi Code를 사용하려면 Kimi 서버에 접속할 수 있어야 합니다. 네트워크 환경에 다음과 같은 제한이 있다면 설정을 조정해야 할 수 있습니다.

- **회사/학교 네트워크**: 일부 인트라넷 환경에서는 외부 API 접속을 제한할 수 있습니다. proxy가 있다면 설정에서 proxy 주소를 지정할 수 있습니다.
- **VPN/proxy**: 전역 proxy를 사용하는 경우 `api.kimi.com` 또는 `api.moonshot.cn`으로 가는 요청을 가로채거나 방해하지 않는지 확인하세요.
- **방화벽**: 시스템이나 라우터 방화벽이 터미널 프로그램의 네트워크 접근을 차단하고 있지 않은지 확인하세요.

## 보안 고려 사항

Kimi Code CLI는 강력한 AI Agent입니다. 다음과 같은 작업을 수행할 수 있습니다.

- 컴퓨터의 파일 내용을 **읽기**
- 코드와 설정 파일 **수정**
- 의존성 설치나 테스트 실행 같은 Shell 명령 **실행**

**사용할 때는 다음 사항을 꼭 기억하세요**:

- **민감한 디렉터리에서 시작하지 마세요**: 비밀번호, 키, 개인적인 비공개 파일이 들어 있는 디렉터리에서는 Kimi Code CLI를 실행하지 않는 것이 좋습니다.
- **작업을 신중히 검토하세요**: Kimi Code는 파일을 수정하거나 명령을 실행하기 전에 확인을 요청합니다. 습관적으로 “동의”를 클릭하지 마세요.
- **이해한 뒤 진행하세요**: 어떤 작업이 어떤 영향을 미칠지 확신이 서지 않는다면, 계속할지 결정하기 전에 Kimi Code에게 정확히 무엇을 할 것인지 설명해 달라고 요청하세요.
- **중요한 코드는 백업하세요**: 중요한 프로젝트에서 Kimi Code를 사용하기 전에는 Git 같은 버전 관리에 코드를 커밋해 두는 것을 권장합니다. 그러면 언제든 되돌릴 수 있습니다.

> **권장 사항**: 처음 사용할 때는 테스트 프로젝트나 프로젝트 사본에서 Kimi Code CLI를 사용해 보세요. 작동 방식에 익숙해진 뒤 실제 운영 프로젝트에 사용하는 것이 좋습니다.
