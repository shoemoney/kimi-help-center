# Dashboard

Dashboard는 widget을 담는 컨테이너입니다. 가장 관심 있는 widget을 하나의 영속적이고 개인화된 보기로 모아 주제, 프로젝트 또는 목표 중심으로 정리합니다. Dashboard는 특정 대화에 종속되지 않아 언제든 열 수 있고, 어떤 채팅에서든 widget을 관리할 수 있습니다.

## Dashboard 생성 및 관리

1. 왼쪽 사이드바에서 "Dashboard"를 클릭해 Dashboard 메뉴를 엽니다.
2. "Create"를 클릭하고 이름(필수)과 설명(선택)을 입력합니다.
3. 사용자당 최대 2개의 dashboard를 생성할 수 있습니다.

빈 dashboard에서 원하는 widget을 바로 설명하면 Kimi가 해당 dashboard에 만들어 줍니다.

<Callout type="warning">
Dashboard를 삭제하면 그 안의 모든 widget과 연결된 widget task도 함께 삭제됩니다. 이 작업은 되돌릴 수 없으니 주의해서 진행하세요.
</Callout>

## 레이아웃과 주석

- 각 dashboard에는 최대 20개의 widget을 배치할 수 있습니다. 드래그해 재배열하고 원하는 대로 크기를 조정하세요.
- "Refresh"를 클릭하면 dashboard의 widget 콘텐츠가 업데이트됩니다.
- "Annotate"를 클릭하면 주석 모드로 진입합니다. widget 안의 임의 요소를 선택해 위치 기반 주석을 만들고 피드백을 기록할 수 있습니다. 주석은 시간 순으로 최대 10개까지 표시되며, 저장된 주석을 클릭하면 다시 편집할 수 있습니다.

## Dashboard에서 Widget 관리하기

Widget에 마우스를 올리면 다음 작업을 할 수 있습니다.

- "Expand"를 클릭해 widget의 이름과 유형을 확인합니다.
- Live widget의 경우 바인딩된 widget task를 관리할 수 있습니다. 작업 이름과 설명을 확인하고, 켜거나 끄고, 최근 10회 실행 기록(실행 시간 및 상태)을 확인합니다.
- "…"를 클릭해 다음을 선택합니다.
  - **Delete**: 원본 채팅과 모든 dashboard에서 widget을 영구 삭제하며, 되돌릴 수 없습니다.
  - **Pin to Desktop**: widget을 독립 창으로 컴퓨터 바탕화면에 고정하며, 창 크기를 조정할 수 있습니다. 앱을 종료하면 창이 자동으로 닫힙니다.

## 채팅에서 Dashboard 열기

모델이 채팅에 dashboard 카드를 표시할 수 있습니다. 카드를 클릭하면 현재 대화를 떠나지 않고 오른쪽 패널에서 해당 dashboard 페이지가 열립니다.
