# Kimi Work 자주 묻는 질문

## Kimi Work는 웹 버전과 무엇이 다른가요?

Kimi 웹 앱이 빠른 채팅과 간단한 질의에 적합하다면, Kimi Work는 깊이 있는 워크플로를 위해 설계된 로컬 에이전트입니다. 로컬 폴더를 읽고 처리하며, WebBridge를 통해 웹을 자율적으로 탐색하고, 백그라운드에서 Python 코드를 실행하며, 예약 작업도 수행합니다. 시스템 차원에서 일하는 디지털 직원이라고 할 수 있습니다.

## Kimi Work는 로컬 파일에 접근할 때 제 개인정보를 어떻게 보호하나요?

파일에 대한 통제권은 전적으로 사용자에게 있습니다. Kimi Work는 세 단계 권한 제어 기능을 제공하며, 사용자가 승인 방식을 직접 선택할 수 있습니다.

- **기본값**: 일상적인 작업은 자동으로 실행됩니다. Kimi가 로컬 파일을 수정하거나 덮어쓰거나 그 안에서 코드를 실행하는 등 민감한 작업을 하기 전에 명시적인 승인을 요청합니다.
- **수동 허용**: 작업 전에 승인을 요청합니다.
- **모두 허용**: 승인 요청 없이 바로 실행합니다.

"수동 허용"을 선택하면 사용자의 동의 없이 어떤 작업도 이루어지지 않습니다.

## WebBridge(브라우저 자동화)는 정확히 무엇을 해주나요?

WebBridge는 Kimi가 사람처럼 브라우저를 사용할 수 있게 해줍니다. 특정 웹사이트의 최신 뉴스를 확인해 요약하라고 하거나, 과거 주가 데이터를 수집해 로컬 Excel 파일에 저장하라고 지시할 수 있습니다. 클릭, 스크롤, 데이터 추출을 자율적으로 수행해 수작업에 들던 시간을 크게 줄여줍니다.

## 예약 작업으로 무엇을 할 수 있나요? 컴퓨터가 절전 상태여도 실행되나요?

예약 작업을 사용하면 Kimi가 정해진 시간에 고정 작업을 자동으로 실행합니다. 매일, 매주, 매월 또는 일회성(반복 없음) 일정으로 설정할 수 있어 일일 브리핑, 주간 모니터링, 정기 정리에 유용합니다.

Kimi Work 데스크톱에서 예약 작업은 **로컬에서** 실행되며, **앱이 열려 있을 때만** 수행됩니다. 컴퓨터가 절전 상태이거나 종료되어 있거나, 앱이 닫혀 있는 동안 놓친 트리거는 다음에 앱을 열어도 **소급 실행되지 않습니다**. 따라서 밤새 작업을 실행해야 한다면 컴퓨터와 Kimi Work 앱을 계속 실행해 두세요. (반면 Kimi에서 만든 작업은 클라우드에서 실행되므로 클라이언트를 계속 열어 둘 필요가 없습니다.)

자세한 내용은 [예약 작업](/features/scheduled-tasks)을 참조하세요.
