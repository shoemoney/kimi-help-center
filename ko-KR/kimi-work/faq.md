# Kimi Work 자주 묻는 질문

## Kimi Work는 웹 버전과 무엇이 다른가요?

Kimi 웹 앱이 빠른 채팅과 질의에 적합하다면, Kimi Work는 깊이 있는 워크플로를 위해 설계된 로컬 Agent입니다. 로컬 폴더를 읽고 처리하며, WebBridge를 통해 웹을 자율적으로 탐색하고, 백그라운드에서 Python 코드를 실행하며, 예약 작업도 수행합니다. 시스템 수준의 디지털 직원이라고 할 수 있습니다.

## Kimi Work는 로컬 파일에 접근할 때 제 개인정보를 어떻게 보호하나요?

파일에 대한 통제권은 전적으로 사용자에게 있습니다. Kimi Work는 권한 제어 기능을 제공하며, 사용자가 승인 방식을 선택할 수 있습니다.

- **권한 요청**: 작업 전에 승인을 요청합니다. Kimi가 로컬 파일을 수정하거나 덮어쓰거나 그 안에서 코드를 실행하기 전에 명시적인 승인을 요청합니다.
- **모두 허용**: 승인 요청 없이 바로 실행합니다.

"권한 요청"을 선택하면 사용자의 동의 없이 어떤 작업도 이루어지지 않습니다.

## WebBridge(브라우저 자동화)는 정확히 무엇을 해줄 수 있나요?

WebBridge는 Kimi가 사람처럼 브라우저를 사용할 수 있게 해줍니다. 특정 웹사이트의 최신 뉴스를 확인해 요약하게 하거나, 과거 주가 데이터를 수집해 로컬 Excel에 저장하도록 지시할 수 있습니다. 클릭, 스크롤, 데이터 추출을 자율적으로 수행해 수작업에 들던 시간을 크게 줄여줍니다.

## 예약 작업으로 무엇을 할 수 있나요? 컴퓨터가 잠자기 상태여도 실행되나요?

내장 Cron 스케줄러는 LLM 에이전트 호출, Python/Shell 실행 등을 지원합니다. 작업은 매일, 매시간 또는 조건에 따라 실행되도록 설정할 수 있습니다. 밤새 작업이 끊김 없이 실행되도록 하려면 설정에서 "컴퓨터 절전 방지" 옵션을 켜기만 하면 됩니다.
