# 목표 모드

목표 모드는 에이전트가 하나의 목표를 향해 계속 작업하도록 해 줍니다(최대 24시간). 프로젝트 어시스턴트처럼 과제를 멈추지 않고 앞으로 밀고 나갑니다.

## 작동 방식: 루프 메커니즘

- **목표 지향 자율 루프**: 명확한 종착점만 설정하면 Kimi가 자동으로 연속 루프에 들어가 목표에 도달할 때까지 스스로 진행합니다. 수동 개입은 필요 없습니다.
- **스스로 진화하는 전략**: 실행 중 에이전트는 현재 상태를 목표와 계속 비교하며, 접근 방식을 수렴시키고 발전시킵니다.
- **목표 이탈도, 상태 누적도 없음**: 에이전트는 먼저 목표에서 “성공으로 간주할 기준”을 추출하고 안정적으로 추적합니다. 모델은 모든 결정을 동일한 종착점을 기준으로 내리며, 실제 현재 상태에만 근거해 행동합니다. 기준점이 고정되어 있으므로 방향을 벗어나지 않습니다.
- **사람이 개입 가능한 루프**: AI의 진행 과정은 완전히 투명하며, 언제든 루프를 중단할 수 있습니다. 방향이 어긋나거나 막힌 것 같다면 현재 상태를 조정하거나 지시를 추가해 방향을 잡아 주면 에이전트가 계속 진행합니다.

## 활성화 방법

1. 최신 Kimi 데스크톱 클라이언트를 열고 왼쪽 사이드바에서 "Work" 모드로 전환합니다.
2. 입력 상자 왼쪽 아래의 "+"를 클릭하고 "목표"를 선택합니다.
3. 완료까지 시간이 오래 걸리는 목표를 입력하면 Kimi가 작업을 계속 추진하기 시작합니다.

## 적합한 작업

목표 모드는 명확한 목표, 불확실한 경로, 여러 차례의 시도 필요성, 검증 가능한 결과라는 네 가지 조건을 모두 갖춘 작업에 가장 잘 맞습니다. 예를 들어 코드 마이그레이션, 방대한 자료 정리, 논문 결과 재현, 개인 지식 베이스 구축 등이 있습니다.

<Callout type="tip">
예: Kimi Work는 몇 시간에 걸쳐 논문 80편, PDF 2,000쪽, 100만 단어 분량의 자료를 자동으로 정리해 Obsidian 지식 베이스로 만들 수 있습니다.
</Callout>
