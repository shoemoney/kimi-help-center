# 릴리스 노트

이 페이지는 Kimi Work의 버전 업데이트 내용(새로운 기능, 변경 사항, 수정)을 기록하며 지속적으로 업데이트됩니다. 최신 버전 다운로드: [kimi.com/products/kimi-work](https://www.kimi.com/products/kimi-work)

## 3.2.4 (2026-08-31)

**변경 사항**

- 웹 검색 및 로컬 파일 등의 소스가 메시지 답장에 인용 표시되는 방식을 최적화했습니다
- 메시지 답장의 글자 크기와 줄 간격을 최적화했습니다

**수정 사항**

- 다크 모드에서 일부 사용 경험 문제를 수정했습니다
- Windows에서 프로세스 감시를 최적화했습니다
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다

## 3.2.3 (2026-08-28)

**새로운 기능**

- 플러그인 마켓에 “새 플러그인” 진입점 추가: 마켓에서 바로 플러그인을 만들 수 있습니다

**수정 사항**

- 데스크톱 펫 디테일 개선: 창 동작을 최적화하고, 언어가 앱 전환을 실시간으로 따라가도록 개선했습니다
- 오류 발생 후 메시지를 편집하여 다시 볼 때 대화 상태 일관성이 깨지던 문제를 수정했습니다
- 상주 기능의 전력 소비를 최적화했습니다
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다

## 3.2.2 (2026-08-26)

**새로운 기능**

- 데스크톱 펫 추가: Kimi가 데스크톱 펫으로 함께하며 상호작용합니다
- Slash 단축 명령 추가: 입력창에서 compact(컨텍스트 압축), fork(대화 분기), goal(목표) 명령을 지원합니다
- 실행 권한에 “기본값” 옵션 추가: 이제 전역적으로 “기본값”, “수동 허용”, “모두 허용” 세 단계 권한을 사용할 수 있습니다

**변경 사항**

- 내장 브라우저의 Agent 제어가 기본으로 활성화됩니다
- “채팅” 영역의 대화가 더 이상 루트 디렉터리를 공유하지 않으며, 각 대화마다 별도의 작업 디렉터리가 생성됩니다

**수정 사항**

- 첫 메시지 전송 시 빈 상태가 잠깐 표시되던 문제를 수정했습니다
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다

## 3.2.1 (2026-08-21)

**새로운 기능**

- 전역 Launcher 추가: 전역 단축키로 언제 어디서나 데스크톱 플로팅 캡슐 입력창을 호출할 수 있습니다
  - 호출 시 Finder / 파일 탐색기에서 현재 선택한 파일을 자동으로 가져오며, 이미지 붙여넣기, 첨부 파일 추가, 스크린샷 드래그를 지원합니다
  - “/”를 입력해 플러그인과 스킬 메뉴를 열고(병음 검색 지원) 작업 공간을 선택할 수 있습니다
  - 단축키를 길게 눌러 음성으로 입력할 수 있으며, 전송 후에는 미니 캡슐로 접히고 한 번의 클릭으로 메인 앱으로 돌아가 답변을 확인할 수 있습니다
- 메시지 큐 추가: Agent가 답변하는 동안에도 메시지를 계속 볼 수 있으며, 새 메시지는 자동으로 대기열에 쌓이고 드래그 재정렬, 편집, 삭제, 상세 미리 보기를 지원합니다
- Work 입력창 음성 받아쓰기 지원: 마이크를 클릭하거나 단축키를 길게 눌러 받아쓰기를 시작할 수 있으며, 중국어-영어 혼합 인식을 지원합니다

**변경 사항**

- 메시지 알림 로직 업데이트: 설정에서 메시지 알림 규칙을 전환할 수 있습니다

**수정 사항**

- 대기 전력 소비를 최적화해 앱 유휴 시 백그라운드 리소스 사용량을 줄였습니다
- macOS에서 Dock 아이콘이 사라지던 문제를 수정했습니다
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다

## 3.2.0 (2026-08-19)

**새로운 기능**

- Agent 내장 브라우저 추가: 브라우저 탭이 대화에 바인딩되어 미리 보기 영역에 표시되며, Agent가 클릭, 입력 등의 작업으로 브라우저를 직접 조작할 수 있습니다. Mac에서는 로컬 Chrome에서 쿠키를 가져와 기존 로그인 세션을 재사용할 수 있습니다(기본적으로 꺼져 있으며 설정에서 활성화할 수 있습니다)
- 16개 언어 현지화: 클라이언트가 중국어와 영어만 지원하던 것에서 16개 언어를 지원하게 되었습니다

**변경 사항**

- Kimi WebBridge가 플러그인으로 전환되었습니다: 실제 브라우저 제어가 플러그인 형태로 이동되었으며, 기본적으로 꺼져 있고 설정에서 활성화할 수 있습니다
- 대시보드 목록 페이지가 제거되었으며, 이제 상단 탭 바로 대시보드를 전환합니다
- 대시보드가 미리 보기 영역 유형으로 변경되어 대화 미리 보기 영역에서 대시보드를 열 수 있으며, 여러 대시보드를 병렬로 열 수 있습니다

**수정 사항**

- 메시지 스트리밍 렌더링 업그레이드: 긴 답변이 더 부드럽게 렌더링됩니다
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다

## 3.1.8 (2026-08-11)

**새로운 기능**

- 메시지 기록 탐색: 긴 대화 오른쪽에 새로운 메시지 탐색 바가 추가되어 이전 메시지로 빠르게 돌아갈 수 있습니다
- 대화 브랜치: 임의의 턴에서 새 브랜치를 시작해 원래 대화의 채팅 기록을 이어받아 계속 탐색할 수 있습니다
- 편집 및 되감기: 마지막 메시지를 편집하고 답변을 다시 생성할 수 있습니다
- 프로젝트 폴더: 대화를 프로젝트로 이동하거나 프로젝트에서 꺼낼 수 있고, 프로젝트를 사이드바 고정 영역에 고정할 수 있습니다
- 투명한 파일 편집: Agent가 파일을 수정하면 diff 요약 카드가 생성되어 변경 내용을 줄 단위로 검토하고 한 번의 클릭으로 롤백할 수 있습니다. 워크스페이스 파일은 디스크에서 변경되면 자동으로 새로고침됩니다
- Skill 검색 및 생성: Work에서 커스텀 skill을 찾고 생성할 수 있으며, skill 검색을 지원합니다
- 데스크톱에 고정된 대시보드 컴포넌트에 상단 고정 토글이 추가되었습니다

**변경 사항**

- 새 독립 대화 창에서 Chat을 지원합니다
- 입력창의 지나치게 긴 사용자 메시지가 접히도록 변경되었습니다

**수정 사항**

- Windows에서 PDF 파일 링크 미리보기 문제를 수정했습니다. 다크 모드에서 Work 설정이 더 이상 흰색으로 깜빡이지 않습니다. Word 클립보드에서 붙여넣을 때 이미지 첨부 대신 텍스트로 복원됩니다
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다
