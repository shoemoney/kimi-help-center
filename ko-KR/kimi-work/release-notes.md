# 릴리스 노트

이 페이지는 Kimi Work의 버전 업데이트 내용(새로운 기능, 변경 사항, 수정)을 기록하며 지속적으로 업데이트됩니다. 최신 버전 다운로드: <a href="https://www.kimi.com/products/kimi-work">kimi.com/products/kimi-work</a>

## 3.1.10 (2026-08-16)

**수정 사항**

- 일부 Windows 사용자에게서 업그레이드 중 앱이 충돌하던 문제를 수정했습니다

## 3.1.9 (2026-08-15)

**새로운 기능**

- 개인 플러그인 마켓 출시: 플러그인 마켓에 "개인 플러그인" 섹션이 추가되어 개인 개발자의 플러그인을 둘러보고 설치할 수 있습니다

**수정 사항**

- 스트리밍 Markdown 콘텐츠가 간헐적으로 새로고침되지 않는 문제를 수정했습니다
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다

## 3.1.8 (2026-08-11)

**새로운 기능**

- 메시지 기록 탐색: 긴 대화 오른쪽에 새로운 메시지 탐색 바가 추가되어 이전 메시지로 빠르게 돌아갈 수 있습니다
- 대화 브랜치: 임의의 턴에서 새 브랜치를 시작해 원래 대화의 채팅 기록을 이어받아 계속 탐색할 수 있습니다
- 편집 및 되감기: 마지막 메시지를 편집하고 답변을 다시 생성할 수 있습니다
- 프로젝트 폴더: 대화를 프로젝트로 이동하거나 프로젝트에서 꺼낼 수 있고, 프로젝트를 사이드바 고정 영역에 고정할 수 있습니다
- 투명한 파일 편집: Agent가 파일을 수정하면 diff 요약 카드가 생성되어 변경 내용을 줄 단위로 검토하고 한 번의 클릭으로 롤백할 수 있습니다. 워크스페이스 파일은 디스크에서 변경되면 자동으로 새로고침됩니다
- Skill 검색 및 생성: Work에서 커스텀 skill을 찾고 생성할 수 있으며, skill 검색을 지원합니다
- 데스크톱에 고정된 대시보드 컴포넌트에 상단 고정 토글이 추가되었습니다

**변경 사항**

- 새 독립 대화 창에서 Chat을 지원합니다
- 입력창의 지나치게 긴 사용자 메시지가 접히도록 변경되었습니다

**수정 사항**

- Windows에서 PDF 파일 링크 미리보기 문제를 수정했습니다. 다크 모드에서 Work 설정이 더 이상 흰색으로 깜빡이지 않습니다. Word 클립보드에서 붙여넣을 때 이미지 첨부 대신 텍스트로 복원됩니다
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다

## 3.1.7 (2026-08-05)

**새로운 기능**

- 메시지 단위 사용자 피드백 지원: 어시스턴트 답변의 개별 메시지에 좋아요 또는 싫어요를 남길 수 있습니다

**변경 사항**

- 데스크톱에 고정된 보드 컴포넌트의 강제 상단 고정이 해제되었습니다

**수정 사항**

- 일부 버그를 수정하고 일부 인터랙션을 개선했습니다

## 3.1.6 (2026-07-29)

**새로운 기능**

- PPT 슬라이드 편집기 출시: 워크스페이스에서 바로 열어 편집하면 수정 내용이 그대로 반영됩니다
- 미리 보기 영역의 파일과 브라우저의 스크린샷 주석을 지원하며, 완성 후 Agent에 바로 보내 수정을 요청할 수 있습니다
- Windows 버전 저장 디스크 마이그레이션 지원: Work 데이터를 다른 디스크로 이전할 수 있습니다
- Windows 버전 설치 시 설치 위치를 직접 선택할 수 있습니다

**변경 사항**

- 일부 token efficiency 문제를 개선했습니다

**수정 사항**

- 일부 버그를 수정하고 일부 인터랙션을 개선했습니다
