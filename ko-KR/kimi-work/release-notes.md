# 릴리스 노트

이 페이지는 Kimi Work의 버전 업데이트 내용(새로운 기능, 변경 사항, 수정)을 기록하며 지속적으로 업데이트됩니다. 최신 버전 다운로드: [kimi.com/products/kimi-work](https://www.kimi.com/products/kimi-work)

## 3.2.11 (2026-09-18)

**변경 사항**

- 상세 패널에서 하위 Agent 실행 과정을 표시할 수 있습니다

**수정 사항**

- Windows에서 인앱 업데이트 후 시작 메뉴 바로 가기가 끊어지던 문제를 수정했습니다
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다

## 3.2.10 (2026-09-16)

**수정 사항**

- Windows 공유 대상 동반 패키지를 긴급 제거해 시작 즉시 충돌하던 문제를 수정했습니다. 공유 기능은 3.2.11에서 수정 후 복귀했습니다
- 기본 제공 스킬의 표시 이름과 설명이 인터페이스 언어로 현지화됩니다: “/” 메뉴가 현지화된 이름으로 필터링하며, 미제공 언어는 영어로 폴백합니다
- 폴더 첨부 카드를 클릭하면 작업 공간 파일 트리에서 해당 디렉터리로 이동합니다
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다

## 3.2.9 (2026-09-14)

**새로운 기능**

- 일부 파일 형식에서 Kimi와 공유 및 열기 지원:
  - Kimi에 공유: WeChat 등 앱의 공유 메뉴에서 파일/콘텐츠를 바로 Kimi로 보낼 수 있습니다
  - Kimi로 열기: 지원되는 파일을 우클릭하고 Kimi로 열기를 선택할 수 있습니다
- 데스크톱 펫 업그레이드: UI가 완전히 새로워졌으며, 대화 말풍선에서 바로 빠른 답장을 보낼 수 있어 메인 창을 열지 않고도 대화를 이어갈 수 있습니다
- PDF 뷰어에 색인 패널 추가: 목차와 페이지 번호 이동 지원
- 전원 모드에 “화면 꺼짐 후에도 깨어 있기” 추가: 화면은 꺼져도 시스템은 계속 실행되어 원격 제어와 백그라운드 작업이 중단되지 않습니다

**변경 사항**

- 업로드한 파일과 입력창에서 “@”로 링크한 파일을 클릭해 오른쪽 작업 공간에서 미리 보기를 열 수 있습니다
- 이미지 미리 보기에서 복사 / 저장 작업을 지원합니다

**수정 사항**

- 큐 편집 복구, 브라우저 충돌 후 탐색 잠금 해제 등 여러 경쟁 상태를 수정했습니다
- 앱 기능의 다크 모드 색상 문제를 수정했습니다
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다

## 3.2.8 (2026-09-12)

**변경 사항**

- 절전 방지 설정을 세 가지 옵션으로 제공: 화면이 꺼져도 계속 실행, 화면 항상 켜기, 끄기

**수정 사항**

- 설정 창을 복원한 후 화면이 하얗게 표시되던 문제를 수정했습니다
- 긴 스크린샷 썸네일을 최적화해 미리 보기 메모리 사용량을 줄였습니다
- 로그인 새로 고침 경쟁 상태를 수정해 이전 요청이 로그인 상태를 잘못 지우거나 새 자격 증명을 덮어쓰는 것을 방지했습니다
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다

## 3.2.7 (2026-09-11)

**새로운 기능**

- 스크린샷 기능 강화: Launcher 스크린샷에서 스크롤 캡처 지원; 스크린샷 편집에서 원클릭 OCR 텍스트 추출; 스크린샷을 항상 위에 떠 있는 작은 창으로 데스크톱에 고정 가능
- 대화 설정 주입: Work 새 대화에 대화 설정이 자동으로 적용됩니다
- 창의 아무 위치에나 파일을 드래그해 첨부 가능, 폴더도 지원
- 웹사이트 배포 플러그인 추가: 설치 후 로컬 웹사이트 프로젝트를 한 단계로 클라우드에 배포할 수 있습니다

**변경 사항**

- Windows 자동 시작이 시스템 트레이에만 상주하고 더 이상 메인 창이 뜨지 않습니다
- Markdown 테이블 새 디자인: 넓은 테이블은 가로 스크롤 지원
- 알림 센터에서 한 번의 클릭으로 모두 읽음 처리 지원
- 원격 제어 메시지를 세그먼트로 표시하고, 하위 Agent 카드와 산출물 카드를 데스크톱과 동일하게 정렬

**수정 사항**

- 마이크가 없는 기기에서는 음성 입력이 자동으로 비활성화되고, 마이크를 뽑으면 받아쓰기가 중지됩니다
- 플러그인 업로드 기능이 사라지던 문제를 수정했습니다
- 메일/전화 링크를 열 수 없을 때 명확히 알려주며, 조용히 실패하지 않습니다
- 크레딧 소진 시 예약 작업 페이지가 멈추던 문제를 수정했습니다
- 데스크톱 펫 성능 및 드래그 수정
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다

## 3.2.1 (2026-08-21)

**새로운 기능**

- 전역 Launcher 추가: 전역 단축키로 언제 어디서나 데스크톱 플로팅 캡슐 입력창을 호출할 수 있습니다
  - 호출 시 Finder / 파일 탐색기에서 현재 선택한 파일을 자동으로 가져오며, 이미지 붙여넣기, 첨부 파일 추가, 스크린샷 드래그를 지원합니다
  - “/”를 입력해 플러그인과 스킬 메뉴를 열고(병음 검색 지원) 작업 공간을 선택할 수 있습니다
  - 단축키를 길게 눌러 음성으로 입력할 수 있으며, 전송 후에는 미니 캡슐로 접히고 한 번의 클릭으로 메인 앱으로 돌아가 답변을 확인할 수 있습니다
- 메시지 큐 추가: Agent가 답변하는 동안에도 메시지를 계속 보낼 수 있으며, 새 메시지는 자동으로 대기열에 쌓이고 드래그 재정렬, 편집, 삭제, 상세 미리 보기를 지원합니다
- Work 입력창 음성 받아쓰기 지원: 마이크를 클릭하거나 단축키를 길게 눌러 받아쓰기를 시작할 수 있으며, 중국어-영어 혼합 인식을 지원합니다

**변경 사항**

- 메시지 알림 로직 업데이트: 설정에서 메시지 알림 규칙을 전환할 수 있습니다

**수정 사항**

- 대기 전력 소비를 최적화해 앱 유휴 시 백그라운드 리소스 사용량을 줄였습니다
- macOS에서 Dock 아이콘이 사라지던 문제를 수정했습니다
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다

## 3.2.0 (2026-08-19)

**새로운 기능**

- Agent 내장 브라우저 추가: 브라우저 탭이 대화에 바인딩되어 미리 보기 영역에 표시되며, Agent가 클릭, 입력 등의 작업으로 브라우저를 직접 조작할 수 있습니다. Mac에서는 로컬 Chrome에서 쿠키를 가져와 기존 로그인 세션을 재사용할 수 있습니다(기본적으로 꺼져 있으며 설정에서 활성화할 수 있습니다)
- 16개 언어 현지화: 클라이언트가 중국어와 영어만 지원하던 것에서 16개 언어를 지원하게 되었습니다

**변경 사항**

- Kimi WebBridge가 플러그인으로 전환되었습니다: 실제 브라우저 제어가 플러그인 형태로 이동되었으며, 기본적으로 꺼져 있고 설정에서 활성화할 수 있습니다
- 대시보드 목록 페이지가 제거되었으며, 이제 상단 탭 바로 대시보드를 전환합니다
- 대시보드가 미리 보기 영역 유형으로 변경되어 대화 미리 보기 영역에서 대시보드를 열 수 있으며, 여러 대시보드를 병렬로 열 수 있습니다

**수정 사항**

- 메시지 스트리밍 렌더링 업그레이드: 긴 답변이 더 부드럽게 렌더링됩니다
- 일부 버그를 수정하고 일부 인터랙션과 안정성을 개선했습니다
