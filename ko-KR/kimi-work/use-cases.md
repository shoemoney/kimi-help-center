# 사용 사례

## 금융: 투자 전략 분석

Kimi Work에 지난 10년간 워런 버핏의 보유 종목을 조사하게 하고, 그의 투자 전략을 요약한 뒤 "버핏 투자 스킬"을 생성하게 할 수 있습니다. 스킬을 설치한 후 Kimi의 전문 금융 데이터 소스와 연결하면, 자신의 보유 종목과 전략이 버핏의 가치투자 방식에 얼마나 부합하는지 분석할 수 있습니다.

**워크플로**: 조사 ▶ 스킬 생성 ▶ 스킬 설치 ▶ 스킬을 사용해 전문 금융 데이터 소스를 호출하여 분석

## 연구: 데이터 처리와 논문 작성 지원

Kimi Work가 도시 컴퓨팅 연구자처럼 작업하게 할 수 있습니다. 로컬 컴퓨터에 있는 시뮬레이션 데이터셋을 정리하고, 핵심 특성과 패턴을 요약하며, 학술용 차트를 작성한 뒤, 정리된 데이터와 차트를 바탕으로 논문 작성을 도와줍니다.

**워크플로**: 로컬 데이터 정리 ▶ 차트 작성 ▶ 논문 작성 지원

## 오피스: 시장 조사 및 납품용 결과물 작성

Kimi Work가 로컬 폴더의 제품 기획서, 산업 디자인 프로토타입, GTM 계획을 읽은 다음, WebBridge를 사용해 브라우저에서 구독 중인 데이터 대시보드 웹사이트에 로그인하여 조사하게 할 수 있습니다. 전체 시장, 해외 법규, 경쟁사 사업 현황을 심층 조사하고, 자사 대시보드와 결합해 2,400개 이상의 사용자 리뷰를 분석한 뒤 128페이지 분량의 크로스보더 이커머스 시장 분석 보고서를 생성합니다. 이어 전용 PPT 스킬을 호출해 보고서 내용과 로컬 디자인 프로토타입을 한 번의 클릭으로 프레젠테이션 자료로 변환합니다.

**워크플로**: 로컬 파일 읽기 ▶ 로컬 브라우저에서 구독 데이터베이스 확인 ▶ 심층 보고서 생성 ▶ PPT 스킬 호출 ▶ 클라이언트용 기획안 출력
