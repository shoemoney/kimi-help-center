# 구독 취소

자동 갱신은 언제든지 취소할 수 있습니다. 취소 후에도 멤버십 혜택은 현재 결제 주기가 끝날 때까지 유지됩니다.

## 자동 갱신은 어떻게 취소하나요?

처음 구독했던 방식에 맞는 방법을 선택하세요.

### Kimi 웹사이트 또는 앱에서

1. Kimi에 로그인합니다(웹 또는 모바일).
2. **설정 → 구독**으로 이동합니다.
3. **자동 갱신 취소** 또는 **구독 관리**를 클릭합니다.
4. 취소를 확인합니다.

### Apple ID를 통해(iOS / Mac)

1. iPhone에서 **설정**을 열고 상단의 본인 이름을 탭합니다.
2. **구독**을 탭합니다.
3. **Kimi**를 찾아 **구독 취소**를 탭합니다.

Mac에서: App Store 열기 → 프로필 클릭 → **계정 설정** → **구독** 항목에서 Kimi 찾기 → **관리** → **구독 취소**.

### Google Play를 통해(Android)

1. **Google Play 스토어** 앱을 엽니다.
2. 프로필 아이콘 탭 → **결제 및 구독** → **구독**.
3. **Kimi**를 찾아 **구독 취소**를 탭합니다.
4. 화면의 안내에 따라 확인합니다.

> 취소 후에도 결제한 기간이 끝날 때까지 혜택이 유지됩니다. Kimi 구독 페이지에서 언제든지 다시 구독할 수 있습니다.
