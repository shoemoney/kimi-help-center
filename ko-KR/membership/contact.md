# 문의하기

도움이 필요하신가요? 문의 방법을 안내해 드립니다.

## 결제 및 멤버십 지원

**이메일:** membership@moonshot.ai

다음과 같은 경우에 적합합니다.

- 구매 후 credit이 표시되지 않는 경우
- 결제 또는 청구 관련 문제
- 요금제 업그레이드, 다운그레이드 또는 해지
- 청구서 요청

유료 회원은 우선적으로 응답해 드립니다. 문제를 더 빠르게 해결할 수 있도록 계정 이메일과 관련 스크린샷을 함께 보내 주세요.

## 일반 지원

**이메일:** support@moonshot.ai

다음과 같은 경우에 적합합니다.

- 제품 기능 관련 문의
- Kimi 사용 중 발생한 기술적 문제
- 계정 관련 문의(결제 제외)
- 기능 요청 및 의견

## API 서비스 지원

**이메일:** api-service@moonshot.ai.
[Kimi OpenPlatform 커뮤니티](https://forum.moonshot.ai/)를 이용하셔도 됩니다.

다음과 같은 경우에 적합합니다.

- API 관련 문의
- Kimi API 사용 중 발생한 기술적 문제
- 기능 요청 및 의견

## 제품 내 의견 보내기

Kimi 안에서 바로 의견을 보내실 수도 있습니다.

- **웹:** 왼쪽 하단의 **의견 보내기** 버튼을 클릭하고 문제를 설명한 뒤 제출하세요.
- **모바일:** **프로필 → 도움말 및 의견 → 의견 보내기** 로 이동하세요.

제품 내에서 보내신 보고에는 기기 및 계정 정보가 자동으로 첨부되어, 문제를 더 빠르게 진단하는 데 도움이 됩니다.
