# 멤버십 플랜 개요

Kimi는 무료 플랜을 포함한 다섯 가지 멤버십 등급을 제공하여, 일상적인 업무 처리부터 파워 유저의 워크플로까지 다양한 요구에 맞춰 확장할 수 있습니다. 모든 플랜의 각 멤버십 기능(Agent 시리즈, Kimi Code 등)은 token 사용량에 따라 측정되는 **하나의 크레딧 풀**을 공유합니다.

\* 일반적인 작업의 token 소모량을 기준으로 한 대략적인 수치입니다. 월별 credit을 동일 기능에 대한 작업 횟수로 환산한 값으로, 참고용입니다.

<Callout type="tip">
모든 크레딧 한도를 동일한 기능에 사용하세요
</Callout>

## 결제 방식

- **하나의 공유 크레딧 풀** — 모든 멤버십 기능(Agent 시리즈, Kimi Code 등)이 token 사용량에 따라 측정되는 하나의 크레딧 풀을 공유합니다.
- **월별 갱신** — credit은 각 청구 주기가 시작될 때 초기화됩니다.
- **사용 우선순위** — 보너스 credit이 먼저 소진된 후 플랜 credit이 사용됩니다.
