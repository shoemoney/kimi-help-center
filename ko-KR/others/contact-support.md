# Kimi 지원팀에 어떻게 문의하나요?

문제에 맞는 채널을 선택해 주시면 더 빠르게 도와드릴 수 있습니다.

## 상담원 지원(WeCom)

WeChat 공식 계정 “**月之暗面Kimi**”를 팔로우한 뒤, 하단 메뉴에서 “**문의하기**” → “**지원팀 문의**”를 탭하면 공식 WeCom 상담원 지원팀을 찾을 수 있습니다.

## 이메일 지원

| 문제 유형 | 이메일 |
|---|---|
| **유료 멤버십 문제**(혜택 미지급, 비정상적인 결제 차감, 업그레이드 또는 다운그레이드, 파피아오/인보이스 등) | membership@moonshot.ai |
| **일반 문의**(제품 기능 문의, 기술적 문제, 비유료 계정 문제, 기능 제안) | support@moonshot.ai |
| **계정 이의 제기 / 불만 및 신고** | support@moonshot.ai |
| **Kimi API 개발자 지원** | [Kimi 오픈 플랫폼](https://platform.kimi.ai/)에 로그인해 지원 연락처와 개발자 커뮤니티 정보를 확인하세요 |

<Callout type="tip">
이메일을 보내실 때는 계정 정보(가입한 휴대폰 번호 또는 이메일 주소)와 문제 화면의 스크린샷을 함께 첨부해 주세요. 유료 멤버십 회원의 이메일은 우선 처리되며, 이를 통해 문제를 더 빠르게 파악할 수 있습니다.
</Callout>

## 제품 내 피드백

Kimi에서 직접 피드백을 제출할 수도 있습니다. 조사를 돕기 위해 시스템에서 기기 및 계정 정보를 자동으로 포함합니다.

- **Web**: 왼쪽 하단에서 “계정 → 사용자 피드백 → 도움말 및 피드백”을 클릭하세요.
- **Mobile App**: “계정 → 설정 → 피드백”으로 이동하세요.

## 답변 품질 피드백

답변이 만족스럽지 않다면 답변 아래의 “👎”를 클릭하고 문제 유형과 구체적인 내용을 간단히 설명해 주세요. 보내주신 피드백은 서비스 개선에 큰 도움이 됩니다.

<Callout type="info">
멤버십 관련 문제는 [멤버십 문제 문의 정보](/membership/membership-contact)에서도 확인할 수 있습니다. 미디어 문의는 pr@kimi.com으로 이메일을 보내 주세요.
</Callout>
