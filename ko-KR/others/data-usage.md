# 데이터 사용 및 공유 안내

## 대화 데이터가 모델 학습에 사용되나요?

보안 암호화 기술로 처리하고 철저히 비식별화하여 특정 개인을 재식별할 수 없다는 전제 하에, 플랫폼은 모델 성능과 제품 경험을 최적화하기 위해 사용자의 입력 데이터, 지시 및 생성된 답변을 모델 학습에 사용할 수 있습니다.

## 모델 학습을 거부하려면 어떻게 하나요?

대화 데이터가 학습에 사용되는 것을 원하지 않으시면 [membership@moonshot.ai](mailto:membership@moonshot.ai)로 고객센터에 문의하여 요청해 주세요. 본인 확인 후 역일 기준 30일 이내에 거부 등록을 완료하여 고객님의 콘텐츠가 모델 학습에 사용되는 것을 중단하겠습니다.

## 모델 학습을 거부하면 어떤 영향이 있나요?

- **계정 단위 일괄 거부**: 현재는 대화별 또는 파일별 선택 거부를 지원하지 않습니다.
- **사용에 영향 없음**: 학습을 거부하더라도 Kimi의 모든 서비스를 계속 이용할 수 있으며, 계정, 멤버십 혜택 및 기존 대화 기록은 그대로 유지됩니다.
- **적용 범위**: 등록 완료 후에는 기존 대화 데이터와 이후 새로 추가되는 데이터 모두 모델 학습 데이터 세트에 포함되지 않습니다.

## 데이터가 제3자와 공유되나요?

고객님의 동의, 법률상 요구 또는 제품 기능 구현에 필요한 경우가 아니라면, 당사는 어떤 제3자(계열사, 파트너, 광고주 등 포함)와도 고객님의 개인 대화 데이터를 공유, 판매 또는 제공하지 않으며 서비스 제공과 무관한 목적으로 사용하지 않습니다. 자세한 내용은 [Kimi 개인정보 처리방침](https://www.kimi.com/user/agreement/userPrivacy?version=v2) 제4.2조를 참고하세요.

## 내 데이터는 어디에 저장되나요? 안전한가요?

고객님의 데이터는 중국 내에 위치한, 보안 표준을 충족하는 서버 환경에 저장됩니다. 당사는 데이터 암호화, 접근 통제 등 기술적·관리적 조치를 통해 무단 접근, 유출 또는 분실을 방지합니다.

## 기업 사용자의 데이터도 모델 학습에 사용되나요?

Kimi Business(기업용 버전)의 핵심 약속 중 하나는 기업 데이터가 모델 학습 과정에 투입되지 않으며, 개인 공간과 기업 공간이 완전히 분리된다는 점입니다. 데이터 처리 계약(DPA), 기업 계약 또는 제품 데모가 필요하시면 기업 영업팀([sales@kimi.ai](mailto:sales@kimi.ai))에 문의해 주세요.
