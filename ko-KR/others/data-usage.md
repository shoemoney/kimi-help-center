# 대화 데이터가 모델 학습에 사용되나요?

안전한 암호화 기술로 처리하고 철저하게 비식별화하여 특정 개인을 재식별할 수 없다는 전제 하에, 플랫폼은 모델 성능과 제품 경험을 최적화하기 위해 사용자의 입력 데이터, 명령 및 생성된 답변을 모델 학습에 사용할 수 있습니다.

대화 데이터가 학습에 사용되는 것을 원하지 않으시면 [support@moonshot.ai](mailto:support@moonshot.ai)로 고객센터에 문의하여 요청해 주세요. 본인 확인 후 고객님의 콘텐츠를 모델 학습에 사용하는 것을 중단하겠습니다.
