# Kimi, Kimi Work, Kimi Code, Kimi Claw는 무엇이 다른가요? 무엇을 사용해야 할까요?

Kimi에는 바로 사용할 수 있는 온라인 어시스턴트와, 사용자와 상황에 맞춰 설계된 여러 제품이 포함되어 있습니다. 모두 Kimi의 핵심 역량을 공유하지만, 핵심 차이는 **어디에서 쓰는지, 누구를 위한 것인지, 무엇에 특히 강한지**에 있습니다.

## 한눈에 보기

| 제품 | 무엇인가요 | 적합한 용도 / 상황 | 어디에서 사용하나요 |
|---|---|---|---|
| **Kimi** (웹 / 앱) | 채팅과 에이전트를 결합한 온라인 AI 어시스턴트 | 일상 Q&A, 글쓰기, 검색, 웹사이트 제작 / PPT / 문서와 시트, Deep Research 등 | 웹, 모바일 앱 |
| **Kimi Work** | 지식 업무 사용자를 위한 **로컬 에이전트**(데스크톱) | 컴퓨터의 로컬 파일 작업, 여러 데스크톱 앱을 넘나드는 작업 자동화, 오래 걸리는 작업 수행 | Mac / Windows 클라이언트 |
| **Kimi Code** | **개발자**를 위한 코딩 어시스턴트 제품군 | 코드 작성 및 코드베이스 유지보수 | CLI, VS Code 확장 프로그램 |
| **Kimi Claw** | **배포가 필요 없는 클라우드 자동화** 플랫폼 | 24시간 365일 상시 실행되는 클라우드 자동화, Feishu / WeChat 등과 연동되는 봇 | 클라우드(서버 필요 없음) |

## 무엇을 사용해야 하나요?

- **일상적인 채팅, 글쓰기, 검색을 하거나 Kimi에게 웹사이트 제작, PPT와 시트 생성, Deep Research 수행을 맡기고 싶다면** → **Kimi**(웹 / 앱)를 사용하세요.
- **Kimi가 내 컴퓨터의 로컬 파일을 읽고 쓰거나, 여러 데스크톱 앱을 넘나들며 자동화하거나, 오래 걸리는 작업을 실행해야 한다면** → **Kimi Work**(데스크톱)를 사용하세요.
- **개발자이며 주로 코드 작성이나 프로젝트 유지보수에 도움을 받고 싶다면** → **Kimi Code**를 사용하세요.
- **자동으로 실행되고 Feishu / WeChat 및 기타 플랫폼에 연결할 수 있는 상시 동작 클라우드 봇이 필요하다면** → **Kimi Claw**를 사용하세요.

<Callout type="tip">
Kimi의 온라인 경험에서는 이미 “채팅”과 “에이전트”가 하나로 연결되어 있어 둘 사이를 따로 전환할 필요가 없습니다. Kimi Work 데스크톱 앱에는 두 가지 모드가 있습니다. 결과물 중심의 에이전트 모드인 “Work”와 빠른 대화를 위한 “Chat”입니다.
</Callout>

## 어떤 멤버십을 선택해야 하나요?

멤버십 혜택은 Kimi 계정에 연결됩니다. **Kimi Code는 별도의 credit 풀을 사용**하며, 그 외 멤버십 기능(채팅, 에이전트, Deep Research 등)은 동일한 credit 풀을 공유합니다. 요금제 세부 정보와 가격은 [멤버십 구독 페이지](/membership/membership-pricing)에서 확인하세요.

사용 패턴이 주로 **일상 업무 + 가끔 필요한 작업**이라면, 적절한 Kimi 멤버십 요금제로 웹 / 앱 / Kimi Work의 대부분 상황을 충분히 처리할 수 있습니다. **자주 코드를 작성하는** 개발자라면 Kimi Code 혜택도 특히 눈여겨보는 것이 좋습니다.
