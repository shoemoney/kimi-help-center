# Kimi, Kimi Work, Kimi Code, Kimi Claw는 어떻게 다르고, 무엇을 써야 하나요?

Kimi에는 바로 사용할 수 있는 온라인 어시스턴트와, 사용자와 상황에 맞춰 설계된 여러 제품이 포함되어 있습니다. 모두 Kimi의 핵심 역량을 공유하지만, 가장 큰 차이는 **어디에서 쓰는지, 누구를 위한 것인지, 무엇에 가장 강한지**입니다.

## 한눈에 보기

| 제품 | 무엇인가요 | 적합한 용도 / 상황 | 어디에서 사용하나요 |
|---|---|---|---|
| **Kimi** (웹 / App) | 채팅과 에이전트를 결합한 온라인 AI 어시스턴트 | 일상적인 Q&A, 글쓰기, 검색, 웹사이트 제작 / PPT / 문서와 시트, Deep Research 등 | 웹, 모바일 App |
| **Kimi Work** | 지식 근로자를 위한 **로컬 에이전트**(데스크톱) | 컴퓨터의 로컬 파일 작업, 데스크톱 앱 간 작업 자동화, 오래 걸리는 작업 수행 | Mac / Windows 클라이언트 |
| **Kimi Code** | **개발자**를 위한 코딩 어시스턴트 제품군 | 코드 작성과 코드베이스 유지보수 | CLI, VS Code 확장 프로그램 |
| **Kimi Claw** | **배포가 필요 없는 클라우드 자동화** 플랫폼 | 7×24 상시 실행되는 클라우드 자동화, Feishu / WeChat 등과 연동되는 봇 | 클라우드(서버 불필요) |

## 무엇을 써야 하나요?

- **일상적인 채팅, 글쓰기, 검색, 또는 Kimi에게 웹사이트 제작, PPT와 시트 생성, Deep Research를 맡기고 싶다면** → **Kimi**(웹 / App)를 사용하세요.
- **Kimi가 컴퓨터의 로컬 파일을 읽고 쓰거나, 여러 데스크톱 앱을 넘나들며 자동화하거나, 긴 작업을 실행해야 한다면** → **Kimi Work**(데스크톱)를 사용하세요.
- **개발자이고 주로 코드 작성이나 프로젝트 유지보수에 도움이 필요하다면** → **Kimi Code**를 사용하세요.
- **항상 켜져 자동으로 실행되고 Feishu / WeChat 등 다른 플랫폼과 연결되는 클라우드 봇을 원한다면** → **Kimi Claw**를 사용하세요.

<Callout type="tip">
Kimi의 온라인 환경에서는 이미 “채팅”과 “에이전트”가 하나로 통합되어 있어 둘 사이를 전환할 필요가 없습니다. Kimi Work 데스크톱 앱에는 두 가지 모드가 있습니다. “Work”(결과물 완성에 초점을 둔 에이전트 모드)와 “Chat”(빠른 대화)입니다.
</Callout>

## 어떤 멤버십을 선택해야 하나요?

멤버십 혜택은 Kimi 계정에 연결됩니다. 모든 멤버십 기능(채팅, 에이전트, Deep Research, Kimi Code 등)은 **동일한 credit 풀을 공유**합니다. 단, Kimi Code에는 Kimi Code에만 적용되는 별도의 주 5시간 rate limit이 있습니다. 요금제 상세 정보와 가격은 [멤버십 구독 페이지](/membership/membership-pricing)를 참고하세요.

사용 목적이 주로 **일상 업무 + 가끔 필요한 작업**이라면, 적절한 Kimi 멤버십 요금제로 웹 / App / Kimi Work 전반의 대부분 상황을 충분히 커버할 수 있습니다. **코드를 자주 작성하는** 개발자라면 Kimi Code 혜택도 특히 살펴보는 것이 좋습니다.
