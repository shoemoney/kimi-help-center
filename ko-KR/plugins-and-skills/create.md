# 개인 플러그인 만들기

Kimi Work에서는 내장 **Plugin Builder** 스킬을 사용해 한 문장 아이디어, 외부 플러그인 저장소, 웹페이지를 나만의 플러그인으로 만들 수 있습니다. 어떤 방법을 선택하든 플러그인은 동일한 경로로 전달됩니다. **생성/변환 → 개인 플러그인 마켓플레이스("Personal" 탭)에 등록 → +를 클릭해 설치 → 대화에서 사용**. 설치가 완료되면 재시작 없이 현재 대화에서 바로 사용할 수 있습니다.

시작하기 전에 최신 [Kimi Work](https://www.kimi.ai/products/kimi-work) 데스크톱 앱이 설치되어 있는지 확인하세요. Plugin Builder는 내장 스킬이라 별도 설치가 필요 없습니다. 대화에서 "/"를 입력해 호출하거나, 플러그인 마켓플레이스에서 "Custom plugin"을 클릭해 메인 대화에서 생성을 시작할 수 있습니다.

## 한 문장으로 새 플러그인 만들기

"아이디어는 있지만 기존 코드가 없는" 경우에 적합합니다. 원하는 기능을 설명하기만 하면 됩니다. Plugin Builder가 스캐폴딩, 필드 입력, 로컬 검증, 등록까지 자동으로 처리하므로 파일을 직접 작성할 필요가 없습니다.

1. **필요한 것을 설명하세요.** 대화에서 Plugin Builder를 호출하고 플러그인이 해야 할 일을 한 문장으로 설명합니다. 예를 들어 "기업 등록 정보를 조회하는 플러그인을 만들어 줘"처럼 요청하세요. 이름, 설명, 카테고리처럼 추론 가능한 필드는 자동으로 채워지고, MCP 서버 URL이나 아이콘처럼 추론할 수 없는 정보만 확인을 거칩니다.
2. **빌드가 완료될 때까지 기다리세요.** Plugin Builder가 로컬에서 플러그인 파일을 생성하고, 구조 및 스펙 검증을 자동으로 통과시킨 뒤, 개인 플러그인 마켓플레이스에 등록합니다.
3. **설치하고 사용하세요.** **Plugins → Personal**을 열어 방금 만든 플러그인을 찾고 +를 클릭해 설치합니다. 설치가 완료되면 현재 대화에서 바로 사용할 수 있으며, 언제든 "/"로 호출할 수 있습니다.

## 마켓플레이스 또는 저장소에서 플러그인 가져오기

플러그인 저장소 링크를 Plugin Builder에 보내면 자동으로 인식해 형식을 변환하고 "Personal" 탭에 설치합니다. 가져온 플러그인은 공식 마켓플레이스에 영향을 주지 않으며 언제든 제거할 수 있습니다.

1. **지원하는 플러그인 형식:** Plugin Builder는 다음 출처의 플러그인 매니페스트를 인식해 모두 Kimi 네이티브 `kimi.plugin.json` 형식으로 변환합니다.

| 형식 | 참고 |
| --- | --- |
| `kimi.plugin.json` | Kimi 네이티브 형식: 필수 필드가 보정됩니다 |
| 다른 에이전트 플랫폼의 플러그인 매니페스트 | `.codex-plugin/plugin.json`, `.claude-plugin/plugin.json` 같은 디렉터리의 `plugin.json` 파일 및 해당 플랫폼이 제공하는 마켓플레이스 인덱스 파일 |
| `server.json` | MCP 공식 레지스트리 형식: MCP 서비스만 포함하는 플러그인으로 변환됩니다 |
| 일반 `plugin.json` | 플러그인 루트 디렉터리에 있는 일반 매니페스트 |

2. **가져오는 방법:** 저장소 링크를 Plugin Builder에 보내세요. 다음과 같은 저장소 형태를 자동으로 인식합니다.

- **단일 플러그인 저장소**: 저장소 전체가 하나의 플러그인으로 변환됩니다.
- **다중 플러그인 저장소(monorepo)**: 각 하위 디렉터리가 각각의 플러그인으로 변환됩니다.
- **플러그인 마켓플레이스/인덱스 저장소**(plugins.json 또는 marketplace.json 인덱스가 있는 저장소): 인덱스의 모든 항목이 펼쳐져 일괄 변환됩니다.
- **Skills 전용 저장소**: 플러그인 매니페스트 없이 스킬 파일만 있는 저장소는 스킬형 플러그인으로 패키징됩니다.

3. **Personal 탭에서 설치:** 처리가 끝나면 Plugin Builder가 사용 가능한 플러그인을 알려 줍니다. **Plugins → Personal**로 이동해 해당 카드에서 "Install"을 클릭하면 대화에서 사용할 수 있습니다.

**가져온 플러그인 관리:**

- **플러그인 업데이트**: 원본 저장소가 업데이트되었거나 이름이나 설명을 바꾸고 싶다면 Plugin Builder에 말하기만 하면 됩니다. 다시 변환하거나 수정한 뒤 재등록해 줍니다.
- **제거/삭제**: "Personal" 탭에서 제거하면 플러그인이 비활성화됩니다. 제거 후에도 항목은 탭에 남아 있으므로 완전히 없애려면 항목을 삭제하세요.
- **소스 디렉터리**: 변환된 결과물은 로컬 워크스페이스의 plugins/ 디렉터리에 보관됩니다. 이곳이 플러그인의 "소스 파일"이며, Plugin Builder는 이를 기반으로 이후 업데이트를 진행하므로 수동으로 삭제하지 마세요.

## 웹페이지를 플러그인으로 만들기

"자주 쓰는 사이트에 공개 API가 없지만 Kimi가 데이터를 가져오고 조작해 줬으면 하는" 경우에 적합합니다. URL을 Plugin Builder에 보내고 필요한 것을 설명하세요. 예를 들어 "XX 웹사이트를 플러그인으로 만들어 줘. XX를 검색하고 싶어"처럼 요청할 수 있습니다. 사이트를 분석하고 플러그인을 실행하는 데는 두 가지 브라우저 옵션이 있습니다.

| 방법 | 적합한 경우 | 필요한 것 |
| --- | --- | --- |
| **내장 브라우저(기본값)** | 대부분의 웹사이트. Kimi Work의 내장 브라우저로 사이트를 분석하고 플러그인을 실행합니다 | 설치할 것이 없습니다. 로그인이 필요한 경우 내장 브라우저에서 한 번만 로그인하면 됩니다 |
| **WebBridge(wb)** | Chrome에 이미 로그인한 계정을 재사용하는 경우 | WebBridge를 먼저 설치하고 이를 사용해 Chrome을 구동해야 합니다 |

1. **사이트 분석.** Plugin Builder가 선택한 브라우저에서 URL을 엽니다. 페이지에 로그인이 필요하면 브라우저에서 한 번 로그인하도록 요청합니다. 비밀번호, 쿠키 또는 기타 자격 증명을 요구하지 않습니다.
2. **API를 리버스 엔지니어링해 플러그인 생성.** 페이지의 핵심 기능을 실제로 조작하고 네트워크 요청을 캡처해 사이트의 내부 데이터 API를 파악한 뒤, 쿼리 스크립트가 내장된 스킬형 플러그인을 생성합니다.
3. **검증, 등록, 설치.** 이전 방법들과 동일합니다. 플러그인이 검증을 통과하면 "Personal" 탭에 등록됩니다. +를 클릭해 설치하고 사용을 시작하세요.

이후에는 "XX를 조회해 줘"라고 말하기만 하면 Kimi가 플러그인을 사용해 브라우저에서 직접 데이터를 가져와 결과를 정리해 줍니다. 사이트의 API가 변경되어 플러그인이 작동하지 않으면 Plugin Builder에 사이트를 다시 분석해 플러그인을 업데이트하도록 요청하세요.

**한 단락 프롬프트:**

<Callout type="warning">
내장 브라우저 방식은 Kimi Work의 내장 브라우저 기능에 의존합니다. 업그레이드 안내가 표시되면 데스크톱 앱을 최신 버전으로 업데이트하세요. WebBridge 방식은 WebBridge가 컴퓨터와 Chrome에 먼저 설치되어 있어야 합니다.
</Callout>
