# 공식 마켓플레이스에 플러그인 게시하기

직접 만들고 기본 테스트를 마친 개인 플러그인을 Kimi 공식 플러그인 마켓플레이스에 제출하려면 플러그인 상세 페이지를 열고 오른쪽 상단의 "✉️" 버튼을 클릭한 뒤, 피드백 양식에서 "공식 마켓플레이스 게시 신청"을 선택하고 이메일 주소를 입력하세요.

제출 후 신청 내용은 Kimi 심사 팀에 공유됩니다. 플러그인의 콘텐츠와 테스트 결과를 바탕으로 평가하며, 추가 자료나 논의가 필요한 경우 입력하신 이메일 주소로 연락드립니다.
