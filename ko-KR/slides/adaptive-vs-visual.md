# 적응형 모드와 비주얼 모드의 차이

Kimi Slides는 두 가지 생성 모드를 제공합니다. 필요에 가장 잘 맞는 모드를 선택하세요.

| | 적응형 | 비주얼 |
|--|---------|---------|
| **디자인 방식** | Kimi가 레이아웃과 스타일을 지능적으로 생성 | 미리 제작된 템플릿에서 선택 |
| **적합한 용도** | 개성 있고 독창적인 디자인 | 빠르고 효율적인 결과물 |
| **예상 소요 시간** | 30~60분 | 5~10분 |

## 적응형 모드

Kimi가 레이아웃과 스타일을 지능적으로 디자인합니다. AI가 콘텐츠에 맞춰 색상, 글꼴, 아이콘, 차트 스타일을 자동으로 매칭하며, 비즈니스·학술·테크·미니멀 등 다양한 스타일 프리셋을 지원합니다. 독창적인 시각적 아이덴티티와 맞춤형 프레젠테이션이 필요한 경우에 적합합니다.

## 비주얼 모드

미리 만들어진 라이브러리에서 템플릿을 선택합니다. Nano Banana Pro 기반의 비주얼 모드는 프레젠테이션을 빠르게 제작하는 데 최적입니다. 템플릿은 비즈니스, 교육, 테크 등 다양한 분야를 아우릅니다. 템플릿을 선택하면 Kimi가 콘텐츠를 자동으로 채워 완성된 자료를 생성합니다.

## 시나리오와 템플릿 선택 방법

적응형 모드는 학술 연구, 비즈니스 인사이트, 마케팅·홍보 등 다양한 시나리오 옵션을 제공하여 실제 사용 사례에 더욱 잘 맞는 프레젠테이션을 생성하도록 돕습니다.
- 각 시나리오에는 프리셋 템플릿이 함께 제공됩니다. 특정 템플릿을 선택하면 해당 템플릿의 스타일로 프레젠테이션이 생성됩니다.

  src="./images/profile.png"

/>

- 맞춤 템플릿을 사용하려면 PPTX 파일을 업로드하고 생성 요구 사항을 설명하기만 하면 됩니다. 특정 시나리오나 공식 프리셋 템플릿을 선택할 필요가 없습니다.
