# Kimi Slides가 프레젠테이션을 생성하는 방식

Kimi Slides는 레이아웃과 스타일을 지능적으로 디자인합니다. AI가 콘텐츠에 맞춰 색상, 글꼴, 아이콘, 차트 스타일을 자동으로 매칭하며, 다양한 스타일 프리셋(비즈니스, 학술, 테크, 미니멀 등)을 지원합니다. 독창적인 시각적 아이덴티티와 맞춤형 프레젠테이션이 필요한 경우에 적합합니다. 생성에는 보통 30~60분이 소요됩니다.

## 시나리오와 템플릿 선택 방법

Kimi Slides는 학술 연구, 비즈니스 인사이트, 마케팅·홍보 등 다양한 시나리오 옵션을 제공하여 실제 사용 사례에 더욱 잘 맞는 프레젠테이션을 생성하도록 돕습니다.
- 각 시나리오에는 프리셋 템플릿이 함께 제공됩니다. 특정 템플릿을 선택하면 해당 템플릿의 스타일로 프레젠테이션이 생성됩니다.

<Frames
  src="./images/profile.png"
  alt="profile"
/>

- 맞춤 템플릿을 사용하려면 PPTX 파일을 업로드하고 생성 요구 사항을 설명하기만 하면 됩니다. 특정 시나리오나 공식 프리셋 템플릿을 선택할 필요가 없습니다.
