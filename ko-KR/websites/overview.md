# Kimi Websites

<Callout type="info">
**Kimi Websites**는 최신 Kimi K3 멀티모달 비주얼 에이전트 AI 모델을 기반으로 하는 Kimi Agent 제품 기능입니다. 핵심 역량은 **Vibe Coding**으로, 자연어로부터 웹사이트를 생성하고 온라인에 배포합니다.
</Callout>

Kimi는 시각적 입력(UI 시안, 스크린샷, 인터랙션 영상)과 자연어 지시를 이해하여 사용자 입력을 완전하고 실행 가능한 프런트엔드 코드로 변환합니다. 정적 UI뿐만 아니라 동적인 인터랙티브 동작까지 모두 다룹니다.

## 기능 개요

| 기능 | 설명 |
|---------|------------|
| **대화형 사이트 구축** | 자연어로 필요한 내용을 설명하면 AI가 웹사이트를 자동으로 생성합니다 |
| **이미지/영상 이해** | 디자인 시안/스크린샷/화면 녹화를 업로드하면 AI가 분석하여 HTML 페이지를 생성합니다 |
| **자동 배포** | 원클릭 배포로 즉시 게시합니다 |
| **여러 차례 편집** | 버전 비교와 함께 웹사이트를 반복적으로 수정합니다 |
| **원클릭 공유** | 손쉽게 공유할 수 있는 접속 링크를 생성합니다 |
| **템플릿 선택** | 다양한 프리셋 템플릿으로 빠르게 사이트 구축을 시작합니다 |
| **코드 내보내기** | 패키징된 HTML/CSS/JS 파일을 다운로드하여 직접 호스팅합니다 |

## Kimi Websites는 어떻게 사용하나요?

### 방법 1: Kimi Websites 페이지 방문

<Frames
  src="./images/overview/kimi-websites-homepage.png"
  alt="Kimi websites homepage"
/>

1. **브라우저 열기**: Chrome, Safari, Edge, Firefox 등 주요 브라우저를 사용하세요
2. **접속**: [kimi.com/websites](https://www.kimi.com/zh/websites) (한국어 및 영어 지원)
3. **로그인**: Kimi 계정(휴대폰 번호 또는 이메일)으로 로그인하세요
4. **작업 입력**:

| 방식 | 설명 |
|----------|-------------|
| **텍스트 입력** | 자연어로 요청을 입력하세요 |
| **이미지/사이트 복제** | 디자인 시안이나 스크린샷을 업로드하세요 |
| **템플릿 기반** | 프리셋 템플릿을 선택하고 내용을 수정하세요 |

5. **구축 시작**: 템플릿을 선택하거나 대화로 시작하세요

<Frames
  src="./images/overview/screenshot-27.png"
  alt="screenshot 27"
/>

### 방법 2: 모바일 앱

iOS, Android, HarmonyOS 모두 공식 Kimi 앱을 제공합니다. 입력 영역에서 **작업 표시줄**을 탭한 뒤 **Websites 모드**로 전환하면 멀티모달 생성 도구와 Agent 기능을 사용할 수 있습니다.

### 방법 3: 일반 Agent 모드

K3 모델을 선택하고 웹사이트 구축 작업을 입력하세요. Kimi가 비주얼 코딩 역량과 코드 실행 도구를 호출합니다.

## Kimi Websites는 어떻게 작동하나요?

### 1단계: 대화로 웹사이트 만들기

자연어로 필요한 내용을 설명하세요. 세 가지 생성 방법을 지원합니다:

| 방법 | 설명 |
|--------|------------|
| **텍스트 설명** | 웹사이트 요구사항을 직접 입력하면 AI가 자동으로 생성합니다 |
| **디자인 시안 분석** | 디자인 파일을 업로드하면 AI가 인식하여 웹 페이지로 재현합니다 |
| **템플릿 빠른 구축** | 프리셋 템플릿을 선택하고 내용을 수정합니다 |

### 2단계: 구축 과정

<Frames
  src="./images/overview/screenshot-26.png"
  alt="screenshot 26"
/>

Kimi Websites는 **webapp-building SKILL**을 활성화합니다. 이는 전용 다중 라운드 코드 생성 에이전트입니다:
1. **요구사항 분석**: 웹사이트 모듈, 시각적 스타일, 인터랙션 로직을 분석합니다
2. **작업 계획**: 디자인, 개발, 에셋 준비 하위 작업으로 분해합니다
3. **기술 스택 선택**: 적절한 아키텍처(예: React + Tailwind CSS)를 선택합니다
4. **에셋 생성**: 이미지, 아이콘 등 시각적 에셋을 생성합니다
5. **코드 구축**: 페이지 구조, 스타일링, 인터랙션 코드를 작성합니다
6. **여러 차례 최적화**: 미리보기 결과를 바탕으로 완성될 때까지 스스로 조정합니다

### 3단계: 미리보기 및 조정
- **실시간 미리보기**: HTML 데모 URL을 생성하여 브라우저에서 바로 확인합니다
- **대화형 편집**: 대화를 이어가며 변경을 요청하세요. 예: *"내비게이션 바를 어둡게 만들어줘"*

<Callout type="tip">
**예시**: *"색상이 별로네요. 흑백 요구사항을 빼고 평범해 보이는 웹사이트로 만들어주세요."*
Kimi가 할 일 목록을 재구성하고 구축을 이어갑니다.
</Callout>

### 4단계: 온라인 비주얼 편집
- **여러 차례 최적화**: 지속적인 대화를 통해 세부 사항을 미세 조정합니다
- **편집 모드**:
  - **주석 모드**: 영역을 클릭하여 자연어 주석을 추가합니다
  - **선택 모드**: 원하는 요소를 선택하고 주석을 추가합니다
  - 사각형, 화살표, 브러시, 색상 전환을 사용하여 수정 제안을 표시합니다
- 모든 수정 제안을 한 번에 Kimi에게 전송합니다
### 5단계: 배포 및 게시
| 배포 방법 | 설명 |
|-------------------|------------|
| **자동 배포** | 원클릭 배포로 온라인 링크를 생성합니다 |
| **다운로드 및 자체 호스팅** | 패키징된 코드 파일을 다운로드하여 자체 서버에 배포합니다 |
| **사용자 지정 도메인** | 생성된 웹사이트를 자신의 도메인에 연결합니다 |

생성 후에는 다음을 할 수 있습니다:
- 여러 배포 버전을 클릭하여 버전 파일을 다운로드
- 공유 버튼을 클릭하여 공개 배포 링크 얻기(또는 비공개로 설정)
- 편집 버튼을 클릭하여 수정 이어가기
- 전체 HTML/CSS/JS 코드를 다운로드하여 바로 배포하거나 추가로 다듬기

## 대상 사용자
| 사용자 | 활용 사례 |
|----------|----------|
| **개발자** | 제품 프로토타입과 프런트엔드 데모를 설계하여 처음부터 구축하는 시간을 대폭 단축 |
| **창업자** | 제한된 자원으로 랜딩 페이지, 제품 소개, 회사 웹사이트를 빠르게 구축 |
| **제품 관리자** | PRD나 디자인 시안을 시연 가능한 인터랙티브 프로토타입으로 신속하게 전환 |
| **비기술 사용자** | 코딩 없이 아이디어를 설명하거나 참고 이미지를 업로드하여 콘셉트에서 작동하는 웹 페이지까지 완성 |
