# Kimi Websites 풀스택 기능

## 풀스택 웹사이트 구축 업그레이드

완성도 있는 웹사이트는 보통 **프런트엔드 인터페이스, 백엔드 서비스, 데이터 저장소**의 세 부분으로 구성됩니다. Kimi Websites는 풀스택 웹사이트 구축 기능으로 업그레이드되어, 프런트엔드 페이지부터 백엔드 데이터베이스까지 웹사이트 생성과 배포를 엔드투엔드로 지원합니다.

| 기능         | 설명                                                           |
|--------------|----------------------------------------------------------------|
| 프런트엔드 생성     | HTML/CSS/JavaScript 페이지 구조, 스타일링, 상호작용 로직                    |
| 백엔드 데이터베이스   | 백엔드 데이터베이스를 자동으로 구축하며, 영구 데이터 읽기/쓰기와 시각적 관리를 지원               |
| 사용자 로그인     | Kimi 계정 로그인을 지원하며, 데이터베이스를 통해 계정·비밀번호 로그인 시스템도 구축 가능           |
| 버전 관리     | AI가 자동으로 버전을 커밋하고, 원하는 이전 버전으로 되돌리기를 지원                      |
| 풀스택 미리보기     | 완전한 프런트엔드 및 백엔드 미리보기를 지원하며, 일부 시나리오에서는 샌드박스 환경을 수동으로 시작해야 함                   |
| 게시 및 배포   | "게시"를 수동으로 클릭해 공개 인터넷에 배포합니다. 게시 전에는 사이트를 미리보기로만 확인할 수 있습니다. 풀스택 콘텐츠 배포를 지원합니다  |

## Agent 산출물

- 프런트엔드 및 백엔드 코드를 포함한 전체 작업 실행 파일
- 온라인에서 미리보고 게시할 수 있는 풀스택 웹사이트
- `/mnt/agents/output/app/` 디렉터리에 있는 다운로드 가능한 Zip 패키지

## 현재 제한 사항

다음 시나리오는 아직 지원되지 않으며, 향후 버전에서 순차적으로 제공될 예정입니다.

- Stripe 및 PayPal과 같은 타사 결제 연동
- Google 및 GitHub와 같은 타사 OAuth 로그인. 현재는 Kimi 계정 로그인 또는 데이터베이스 기반 사용자 이름/비밀번호 로그인만 지원됩니다
- 외부 SaaS 서비스 연결과 같은 복잡한 서버 측 API 연동
