# Visão geral do K2.6 Agent

O Kimi K2.6 Agent é um assistente de IA autônomo que executa tarefas complexas de ponta a ponta. Movido pelo modelo K2.6, ele usa mais de 20 ferramentas para criar sites, gerar documentos, analisar dados e muito mais.

## Evolução do produto
- **5 de setembro de 2025**: Lançamento do Kimi K2 — 32B de parâmetros ativos / 1T no total
- **26 de setembro de 2025**: Lançamento do modo Agent "OK Computer"
- **27 de janeiro de 2026**: Lançamento do Kimi K2.5 — melhorias nas habilidades de Office e nos recursos do Agent
- **Fevereiro de 2026**: Lançamento do beta público do Kimi Claw

## Principais recursos
| Recurso | Descrição |
|---------|-------------|
| **Sites** | Crie e publique aplicativos web responsivos |
| **Documentos** | Edição e geração em Word, PDF e Markdown |
| **Planilhas** | Análise e visualização de dados em Excel/CSV |
| **Apresentações** | Geração automatizada de PPT |
| **Deep Research** | Relatórios de pesquisa com mais de 10.000 palavras |
| **K2.6 Agent Swarm** | Até 300 subagentes trabalhando em paralelo |
| **Kimi Claw** | Automação na nuvem com mais de 5.000 habilidades |

## Como funciona?
1. **Planejamento da tarefa**: Divide sua solicitação em subtarefas
2. **Acionamento de ferramentas**: Usa mais de 20 ferramentas conforme necessário
3. **Execução autônoma**: Realiza pesquisa, design e desenvolvimento
4. **Tratamento de erros**: Corrige-se sozinho, sem intervenção do usuário
5. **Entregas**: Arquivos do Office, aplicativos web ou relatórios

## Como começar
- **Web**: [kimi.com/agent](https://www.kimi.com/agent)
- **Celular**: app Kimi → barra de tarefas → modo Agent
Descreva sua tarefa com clareza, acompanhe o progresso da execução e depois baixe ou compartilhe os resultados.

## Casos de uso
- Desenvolvimento de sites (sem precisar programar)
- Geração de conteúdo com recursos multimídia
- Comparação e tradução de documentos
- Análise de dados (Excel com até 1.000 linhas)
- Geração de apresentações
- Conversão de documentos
