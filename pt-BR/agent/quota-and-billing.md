# Créditos e cobrança do Agent

<Callout type="info">
O modo Agent usa o sistema de créditos da Kimi. Todos os benefícios de assinatura incluem dois pools de créditos: o Kimi Code usa um pool de créditos separado; os demais recursos de assinatura (Agent, Deep Research, Slides, Docs, Sheets, Kimi Claw etc.) compartilham um único pool de créditos, com os créditos deduzidos conforme o consumo real de tokens.
</Callout>

## Modelo de cobrança
- **Dois pools de créditos**: todos os benefícios de assinatura incluem dois pools de créditos. O Kimi Code usa um pool de créditos separado; os demais recursos de assinatura compartilham um único pool de créditos — distribua o uso como preferir
- **Pagamento por uso**: o consumo de créditos depende da complexidade e da duração da tarefa (ou seja, do uso de tokens) — tarefas simples custam menos, tarefas complexas custam mais
- **Renovação mensal**: os créditos são renovados mensalmente, alinhados ao seu ciclo de assinatura
- **Prioridade de uso**: os créditos bônus (por exemplo, créditos de avaliação, recompensas promocionais) são consumidos primeiro, seguidos pelos créditos do plano

<Callout type="tip">
**Exemplo**: com um plano Moderato, gerar um PPT simples pode consumir cerca de 1–2% dos créditos, enquanto uma única sessão de Deep Research pode usar cerca de 5–10%.
</Callout>

## O que acontece quando os créditos acabam?
Quando seus créditos se esgotam:
- Qualquer tarefa em andamento será concluída normalmente
- Novas tarefas exibirão um aviso de "créditos insuficiente"
- Suas opções:
  - Aguardar a renovação automática mensal dos créditos
  - Fazer upgrade para um plano de assinatura superior e obter mais créditos

## Como verificar o uso dos créditos?
- **Web**: Perfil → Configurações → Assinatura
- **App**: Perfil → Plano de Assinatura → Assinatura
O que você pode visualizar:
1. Saldo atual de créditos (em porcentagem)
2. Próxima data de renovação
3. Os últimos 10 registros de uso (data e hora, recurso utilizado, porcentagem consumida)

<Callout type="info">
Os registros de uso podem ter um breve atraso. Para informações mais atualizadas, consulte a exibição real dos créditos.
</Callout>

## Uma tarefa que falhou ainda consome créditos?
- Os créditos são deduzidos após uma tarefa ser executada com sucesso, com base no consumo real
- Se uma tarefa falhar por um erro do sistema (sem retorno de resultado válido), clique no botão **👎** para reportá-la. Após verificação, os créditos correspondentes serão reembolsados
