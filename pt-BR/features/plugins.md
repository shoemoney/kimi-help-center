# Plugins

Plugins conectam ferramentas externas ao Kimi para que ele use aplicativos e serviços na execução de tarefas. Depois que você instala um plugin, o Kimi pode acionar diretamente o recurso de terceiro correspondente durante uma tarefa — por exemplo, consultar dados financeiros, operar softwares de escritório ou usar ferramentas de design. Você pode pedir explicitamente para usar um plugin específico, e o Kimi também acionará um plugin automaticamente quando for apropriado.

## Onde você pode usar plugins

Você pode usar plugins ao alternar o modelo para **K3** ou **K3 Swarm**, e nos cenários **Deep Research, Websites e PPT**.

Você também pode usar plugins no app para desktop **Kimi Work**; para ver a lista de plugins integrada ao desktop, consulte a [Central de Plugins do Kimi Work](/kimi-work/plugin-center).

<Callout type="info">
Plugins ainda não são compatíveis com conversas no Kimi Claw ou no Kimi Plus.
</Callout>

## Como instalar plugins

- **Pontos de entrada**: na web, a aba **Plugins** na barra lateral, o **+** na caixa de entrada ou digitando "/"; no celular, o **+** na caixa de entrada ou "/".
- Pesquise ou navegue no marketplace de plugins, abra os detalhes de um plugin e clique para instalar.
- Alguns plugins exigem **autorização via OAuth** (você será levado ao login do terceiro; depois de autorizar, poderá usar o plugin); alguns plugins são **pré-instalados** e não exigem instalação manual.
- **Plugins exclusivos para empresas**: usuários não empresariais podem vê-los, mas o botão "Instalar" fica desativado.
- Você não pode instalar nem usar plugins sem estar conectado à sua conta.

## Como usar plugins

- Depois de instalar, digite "/" na caixa de entrada ou clique em **+** → Plugins e selecione o plugin para acioná-lo; você pode **acionar vários plugins ao mesmo tempo**.
- Você também pode simplesmente descrever o que precisa (por exemplo, "consulte esta empresa no Tianyancha"), e o Kimi escolherá automaticamente o plugin adequado.
- Quando o Kimi aciona as ferramentas de um plugin, ele mostra "Usando o plugin xx" na resposta.

## Categorias e lista de plugins

O marketplace de plugins é organizado nas categorias abaixo. Os plugins que você vê de fato variam conforme a **região (mercado doméstico / exterior)** e o **ambiente**, e alguns plugins aparecem em mais de uma categoria.

- **Finanças**: Análise de investimentos financeiros, Banco de investimento e Private Equity, Finanças corporativas e Contabilidade, Wind Financial Data, S&P Global Market Intelligence, Hundsun Gildata, Tonghuashun iFinD, SEC, Banco de Dados Financeiros Global, World Bank Open Data, Banco de dados do FMI (Fundo Monetário Internacional), Stripe, Tianyancha
- **Produtividade**: Notion, Baidu Netdisk
- **Desenvolvimento**: GitHub, Supabase, Neon, Cloudflare
- **Criatividade**: Banco de inspirações, Geração de imagens, Geração de vídeo, Geração de áudio, Canva
- **Geral**: Vivify

## Créditos

Alguns plugins acionam ferramentas ou serviços para concluir uma tarefa e **consomem créditos da sua assinatura de acordo com o uso real**; plugins sem custo de chamada não geram cobranças extras.

## Dados e permissões

- Quando você seleciona ou pede explicitamente para usar um plugin, o Kimi prioriza as ferramentas fornecidas por esse plugin e gera a resposta com base nos resultados retornados por elas; depois de conectar um plugin, o Kimi acessa o conteúdo relevante dentro do escopo autorizado por você.
- Se um plugin for fornecido por terceiros, as regras de tratamento de dados serão definidas de forma independente por essa empresa, e os dados ficarão sujeitos aos termos de serviço e à política de privacidade dela — recomendamos analisá-los antes de autorizar.
- Você pode **desinstalar um plugin ou revogar a autorização a qualquer momento**. Depois da desinstalação, a autorização OAuth relacionada é revogada; para usar o plugin novamente, será necessário reinstalá-lo e autorizar outra vez.

## FAQ

### Os plugins consomem créditos da minha assinatura?
Alguns, sim. Quando o Kimi aciona as ferramentas ou serviços de um plugin para concluir uma tarefa, os créditos são consumidos de acordo com o uso real; plugins sem custo de chamada não geram cobranças extras.

### Posso usar vários plugins ao mesmo tempo?
Sim. Você pode acionar vários plugins ao mesmo tempo por meio de "/" ou **+**.

### Por que não consigo ver determinado plugin?
Os plugins disponíveis variam conforme a região (mercado doméstico / exterior) e o ambiente; além disso, alguns plugins estão disponíveis apenas para usuários empresariais.
