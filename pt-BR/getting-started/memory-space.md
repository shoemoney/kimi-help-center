# Memory Space

## O que é a memória?
O Kimi realmente aprendeu a ouvir — quanto mais você conversa, melhor ele entende você. Veja como funciona:

O Kimi não responde apenas ao que está na caixa de chat atual. Em todas as conversas, ele registra os detalhes importantes — suas preferências, hábitos, estilo…

Com o uso contínuo, o Kimi aprende a cada sessão, aprimorando constantemente a forma como entende você.

Você não precisa se repetir. O Kimi leva em conta de forma proativa "o que já conversamos" para oferecer respostas mais relevantes e coerentes.

## O que fica memorizado?
O Kimi usa um modelo treinado separadamente para memorizar de forma seletiva o conteúdo das conversas que traz valor para você.

Antes de registrar qualquer coisa, o Kimi faz a si mesmo duas perguntas:
- Quem é este usuário?
- Com o que este usuário se importa, o que prefere ou o que quer evitar?

O Kimi **não** memoriza informações privadas não autorizadas (por exemplo, dados de saúde, senhas, endereços), a menos que você peça explicitamente.

## Como acionar a memória
A memória agora é um recurso nativo — basta uma conversa natural para acioná-la.

Formas de atualizar ou gerenciar a memória do Kimi:

**(1) Instruções diretas na conversa (mais comum)**

Você pode atualizar a memória usando comandos em linguagem natural:

| Ação | O que você pode dizer | Resposta do Kimi |
|:---|:---|:---|
| Adicionar memória | "Lembre-se de que eu gosto de café"<br>"Anote que meu ID de funcionário é 9527"<br>"Lembre-se de que sou gerente de projetos" | O Kimi aciona a ferramenta de memória para salvar |
| Atualizar memória | "Correção — me mudei para Nova York"<br>"Atualização: agora sou engenheiro sênior" | O Kimi substitui a memória antiga |
| Excluir memória | "Esqueça que eu gosto de café"<br>"Apague a memória sobre meu ID de funcionário"<br>"Limpe todas as memórias" | O Kimi remove as memórias indicadas ou todas elas |

Observação: a memória está totalmente sob seu controle. Ela não é usada para treinar o modelo e pode ser desativada ou apagada a qualquer momento.

**(2) Gerenciar pelas Configurações (interface)**

Você também pode gerenciar a memória pela interface de configurações:
- Web / Celular: Configurações → Personalização → Memory Space
- Aqui você pode visualizar todas as memórias salvas
- Você pode excluir manualmente qualquer memória que não precise mais

### Adicionando memórias
As memórias são acionadas automaticamente na conversa. Por exemplo:
- "Meu nome é xxx, meus amigos me chamam de xxxx"
- "Sou professor de matemática do ensino fundamental, então os materiais das aulas precisam ser adequados para crianças"
- "Por favor, pare de usar emojis nas suas respostas"
- "Eu costumo programar em C++"
- "Não se repita nem use pontuação em excesso"

Se houver algo que você queira especificamente que o Kimi lembre, enfatize:
- "Lembre-se de que…"
- "Por favor, tenha em mente…"
- "…não se esqueça disso"

### Atualizando memórias
Vá em Perfil → Configurações → Personalização → Memory Space para editar memórias individuais.

### Excluindo (esquecendo) memórias
Vá em Perfil → Configurações → Personalização → Memory Space e clique em excluir em cada memória.
