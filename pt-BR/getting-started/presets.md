# Predefinições

As predefinições são o recurso de prompts rápidos do Kimi, que permite salvar prompts usados com frequência e acioná-los com um único clique em qualquer sessão — chega de digitar a mesma coisa repetidamente.

## Quando usar predefinições?

- **Tarefas formatadas recorrentes**: por exemplo, quando você sempre precisa que o Kimi gere atas de reunião, relatórios semanais ou e-mails em um modelo específico
- **Prompts de alta qualidade reutilizáveis**: salve prompts bem ajustados para obter resultados consistentes e repetíveis
- **Atalhos para instruções comuns**: comandos do dia a dia como "Resuma este artigo", "Traduza para o inglês" ou "Organize em uma tabela"

## Como adicionar uma predefinição？

1. Abra o [kimi.com](https://www.kimi.com/) ou o aplicativo do Kimi
2. Clique no botão **"+"** à esquerda da caixa de entrada do chat ou localize o ponto de acesso **Predefinições**
3. Clique em **"Adicionar predefinição"**
4. Insira um título (para identificar com facilidade) e o conteúdo (o texto completo do prompt)
5. Salve

## Como usar uma predefinição

Na caixa de entrada de qualquer sessão, clique no ponto de acesso Predefinições e selecione uma predefinição salva. O conteúdo será preenchido automaticamente na caixa de entrada. Você pode enviá-lo como está ou editá-lo ainda mais antes de enviar.

## Gerenciamento de predefinições

- **Editar**: clique em uma predefinição existente para modificá-la
- **Excluir**: remova as predefinições que você não precisa mais
- **Reordenar**: mova as predefinições mais usadas para o topo para acessá-las rapidamente

## Dicas

- Salve prompts de alta qualidade e bem testados como Predefinições para garantir resultados consistentes e confiáveis sempre
- Prepare algumas Predefinições para diferentes cenários de trabalho (redação, análise, tradução etc.) para alternar entre modos rapidamente
- As Predefinições aceitam textos longos — até instruções complexas com vários passos podem ser salvas
