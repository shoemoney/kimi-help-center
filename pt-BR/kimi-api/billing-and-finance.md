# Cobrança e finanças

<Callout type="info">
Perguntas frequentes sobre cobrança, preços e pagamentos da Kimi API.
</Callout>

## Como funciona a estrutura de preços?
A Kimi API é cobrada por token consumido — tokens de entrada e tokens de saída têm preços separados. Os valores variam conforme o modelo, e a busca na web gera uma cobrança adicional de US$ 0,004 por chamada.

<Callout type="tip">
Para ver os preços detalhados, acesse [platform.kimi.ai/docs/pricing/chat](https://platform.kimi.ai/docs/pricing/chat).
</Callout>

## Quais formas de pagamento são aceitas?
O console da API aceita as seguintes formas de pagamento:
| Forma | Detalhes |
| --- | --- |
| **Cartão de crédito/débito** | Visa, Mastercard e outros cartões principais |
| **Transferência bancária** | Usuários com organização verificada podem solicitar transferência bancária — entre em contato com a equipe de vendas para obter os dados bancários |

Os fundos adicionados por recarga ficam disponíveis imediatamente para uso da API.
## Como solicito uma nota fiscal?
1. Faça login no console [platform.kimi.ai](https://platform.kimi.ai).
2. Acesse **Cobrança → Gerenciamento de notas fiscais**.
3. Selecione os registros de recarga para os quais você precisa de nota fiscal.
4. Preencha os dados da nota fiscal (pessoa física ou jurídica) e envie.
5. Uma nota fiscal eletrônica será enviada para o seu e-mail.
