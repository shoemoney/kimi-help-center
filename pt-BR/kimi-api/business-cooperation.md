# Cooperação comercial e vendas

<Callout type="info">
Opções de parceria para clientes corporativos — de descontos por volume a SLAs personalizados.
</Callout>

A Kimi API oferece diversas opções de parceria para clientes corporativos, atendendo a necessidades de negócios em qualquer escala.
## Como falar com a equipe de vendas?
Acesse [platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales) para enviar um formulário de contato. Nossa equipe de vendas retornará em até 1–2 dias úteis.

<Callout type="tip">
**Inclua no envio**:
- Nome da empresa e setor
- Volume de uso estimado
- Principais casos de uso
- Modelo de parceria preferido
</Callout>

## Assinatura de contrato
Usuários com organização verificada podem firmar um contrato formal de serviço com a Moonshot:
- Estão disponíveis tanto contratos de serviço padrão quanto contratos personalizados.
- Após a assinatura, você passa a ter acesso a pagamentos por transferência bancária e SLAs de nível corporativo.
- Fale com a equipe de vendas para alinhar o processo específico.

## Descontos por volume
Clientes corporativos com alto volume de uso podem solicitar descontos exclusivos:
| Requisito | Detalhes |
| --- | --- |
| **Elegibilidade** | Verificação da organização + contrato assinado |
| **Níveis de desconto** | Com base no volume de uso contratado e na duração do contrato |
| **Solicitação** | Solicite pela equipe de vendas, informando o uso mensal estimado |

## Serviço de API corporativa
O serviço de API corporativa amplia a oferta da API padrão com:
- **Rate limits e quotas de concurrency mais altos**
- **Canal dedicado de suporte técnico**
- **Garantias de SLA personalizadas**
- **Acesso antecipado a novos recursos**
