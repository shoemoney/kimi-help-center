# Seleção e comparação de modelos

<Callout type="info">
Escolha o modelo certo da API Kimi com base em capacidade, velocidade e preço.
</Callout>

A API Kimi oferece diversos modelos para os desenvolvedores escolherem.
## Modelos disponíveis
Acesse [platform.moonshot.ai/docs/introduction](https://www.platform.moonshot.ai/docs/introduction) para ver a lista completa de modelos e as especificações detalhadas.
Ao escolher um modelo, leve em conta:
| Dimensão | Consideração |
| --- | --- |
| **Tamanho do contexto** | Escolha modelos com contexto amplo para processar documentos longos |
| **Velocidade de resposta** | Modelos leves para cenários sensíveis à latência |
| **Qualidade da geração** | Modelos de nível superior para raciocínio complexo e escrita criativa |
| **Preço** | Escolha o modelo com melhor custo-benefício de acordo com o orçamento e o volume |

## Modelos de visão
Os modelos de visão aceitam imagens como entrada para legendagem, OCR, interpretação de gráficos e muito mais:

<Callout type="info">
- Cada imagem é cobrada a uma taxa fixa de **1.024 tokens**, independentemente das dimensões ou da resolução
- Formatos suportados: JPEG, PNG, WebP, etc.
- As imagens podem ser enviadas via URL ou codificação Base64
</Callout>

## Recursos ainda não suportados

<Callout type="warning">
- **Multimodal de vídeo**: a entrada direta de vídeo ainda não é suportada
- **API de geração de PPT**: ainda não disponível via API
- **API do Deep Research**: ainda não disponível via API
</Callout>

Para acompanhar as novidades sobre esses recursos, fique de olho nos anúncios da plataforma.
