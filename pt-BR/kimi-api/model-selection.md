# Seleção e comparação de modelos

<Callout type="info">
Escolha o modelo da Kimi API mais adequado considerando recursos, velocidade e preço.
</Callout>

A Kimi API oferece vários modelos para desenvolvedores escolherem.
## Modelos disponíveis
Acesse [platform.kimi.ai/docs/models](https://platform.kimi.ai/docs/models) para ver a lista completa de modelos e as especificações detalhadas.
Ao escolher um modelo, considere:
| Dimensão | Critério |
| --- | --- |
| **Tamanho do contexto** | Prefira modelos com contexto amplo para processar documentos longos |
| **Velocidade de resposta** | Use modelos leves em cenários sensíveis à latência |
| **Qualidade da geração** | Escolha modelos de nível superior para raciocínio complexo e escrita criativa |
| **Preço** | Selecione um modelo com bom custo-benefício conforme orçamento e volume |

## Modelos de visão
Modelos de visão aceitam entrada de imagens para legendagem, OCR, interpretação de gráficos e muito mais:

<Callout type="info">
- Cada imagem é cobrada por uma taxa fixa de **1.024 tokens**, independentemente das dimensões ou da resolução
- Formatos compatíveis: JPEG, PNG, WebP etc.
- As imagens podem ser enviadas por URL ou codificação Base64
</Callout>

## Recursos ainda não compatíveis

<Callout type="warning">
- **Vídeo multimodal**: entrada direta de vídeo ainda não é compatível
- **PPT Generation API**: ainda não disponível via API
- **Deep Research API**: ainda não disponível via API
</Callout>

Para acompanhar novidades sobre esses recursos, siga os anúncios da plataforma.
