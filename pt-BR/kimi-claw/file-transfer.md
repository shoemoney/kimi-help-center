# Transferência de arquivos

O Kimi Claw permite enviar e receber arquivos.

## Enviar arquivos para o Kimi Claw

Você pode enviar imagens, documentos e outros arquivos para o Kimi Claw pelo Kimi. Ele usará suas ferramentas integradas para visualizá-los e processá-los.

## Receber arquivos do Kimi Claw

A versão mais recente do Kimi permite que o Kimi Claw envie arquivos de volta para você. Se o envio de arquivos não estiver funcionando, verifique se você está usando a versão mais recente do plugin do Kimi.

## Gerenciar arquivos no espaço de trabalho

Você também pode navegar e baixar os arquivos gerados pelo Kimi Claw por meio do **Espaço de trabalho** na web. O Espaço de trabalho armazena todos os arquivos produzidos durante a operação do Kimi Claw, disponíveis para acesso a qualquer momento.
