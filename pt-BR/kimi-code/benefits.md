# Benefícios do Kimi Code

O Kimi Code é um serviço incluído no plano de assinatura do Kimi, que oferece suporte e recursos voltados para programação para ajudar os membros a concluir tarefas de programação com mais eficiência em seu fluxo de trabalho de desenvolvimento pessoal.

> Lembre-se de que este benefício destina-se exclusivamente ao uso em desenvolvimento pessoal, e não a cenários de desenvolvimento corporativo. Para necessidades corporativas, acesse a [Plataforma Aberta do Kimi](https://platform.kimi.ai/).

## Cobrança

- O uso do Kimi Code está **incluído na sua mensalidade de assinatura** — sem cobranças adicionais.
- O Kimi Code **usa os mesmos créditos do seu plano de assinatura Kimi** — as solicitações da CLI, do VS Code e de ferramentas de terceiros são todas descontadas deles; planos diferentes incluem quantidades diferentes de créditos.
- O sistema dá prioridade aos créditos bônus antes de consumir os créditos do plano.

<Callout type="warning">
**Um novo sistema de assinatura está chegando em breve.** Os benefícios da assinatura Kimi e os benefícios do Kimi Code serão separados, para que você possa comprá-los separadamente conforme a necessidade — mais flexível. **Os assinantes atuais não são afetados.** Se quiser continuar usando os benefícios combinados, adquira seu plano atual antes do lançamento do novo sistema.
</Callout>

## Renovação de créditos

Os créditos são renovados em ciclos de **7 dias**:

- A partir da data da sua assinatura (D1), os créditos são renovados a cada 7 dias.
- Períodos de renovação: D1–D7, D8–D14, D15–D21, D22–D28.
- Os créditos não utilizados **não** são transferidos para o ciclo seguinte.

> Planeje seu uso semanal para aproveitar ao máximo seus créditos.

## Ferramentas compatíveis

Os benefícios do Kimi Code estão disponíveis com as seguintes ferramentas:

| Ferramenta | Descrição |
| --- | --- |
| **Kimi Code CLI** | Agente de IA oficial de linha de comando do Kimi |
| **Claude Code** | Assistente de programação de linha de comando da Anthropic |
| **Roo Code** | Extensão de programação com IA para o VS Code |

Além das ferramentas acima, os assinantes também podem usar uma API Key para conectar o Kimi Code a mais ferramentas de desenvolvimento de terceiros (como o OpenCode). Consulte [Usando com agentes de codificação de terceiros](/kimi-code/third-party-agents) para mais detalhes. Ao usar ferramentas de terceiros, mantenha a identidade real da ferramenta; adulterar o identificador de cliente (User-Agent) será considerado uma violação e pode resultar na suspensão dos seus benefícios de assinatura.

## Extra Usage

Quando os créditos da sua assinatura se esgotarem, você pode continuar fazendo solicitações usando seu saldo de **Extra Usage**, sem esperar pela renovação. Apenas assinantes podem ativá-lo, e **o Kimi na web e o Kimi Code compartilham o mesmo saldo de Extra Usage** (recarregue uma vez e use em ambos). Consulte os termos completos no [Contrato de Extra Usage](https://www.kimi.com/user/agreement/extra-usage-rules-cn).

### Formas de recarga

- **Pelo site principal**: abra a [página de Assinatura](https://www.kimi.com/membership/subscription?tab=quota) do Kimi, role até o módulo «Extra Usage» no rodapé, escolha um valor e conclua o pagamento.
- **Pelo Kimi Code Console**: quando seu uso semanal ou de 5 horas ultrapassar **80%**, o cartão de progresso exibe um botão **Comprar Extra Usage** que leva à página de assinatura.

### Ativar e gerenciar

Ative a chave «Extra Usage»; quando os créditos da assinatura se esgotarem, o sistema deduz automaticamente do saldo de Extra Usage. Clique em **Configurações** no módulo para ativar um **limite de gasto mensal** e definir o valor máximo do mês; a barra de progresso mostra o consumo de Extra Usage do mês em tempo real.

### Cobrança e regras

- **Cobrança**: pelo uso real — quanto mais conteúdo lido e gerado e quanto mais complexa a tarefa, maior o custo. O saldo é exibido em RMB, com as tarifas mostradas na plataforma. Os preços do Extra Usage são próximos aos preços oficiais da API da [Kimi Open Platform](https://platform.kimi.com); para uso intenso, fazer upgrade da assinatura costuma ser mais econômico.
- **Ordem de dedução**: os créditos com prazo, como a assinatura, são deduzidos primeiro; o **Extra Usage é deduzido por último**, como reserva. Uma vez ativado, mesmo com os créditos da assinatura esgotados, o Extra Usage é consumido sem interrupções e as tarefas não param nem apresentam erro.
- **Limite de gasto**: ative um «limite de gasto mensal» nas configurações para limitar quanto de Extra Usage pode ser gasto no mês; sem ele, não há limite.
- **Validade e acúmulo**: o saldo não expira e acumula entre recargas; permanece utilizável após o vencimento da assinatura, mas não é possível recarregar durante a interrupção — reative a assinatura primeiro para recarregar novamente.

<Callout type="info">
Exemplo de cobrança (ordem de grandeza apenas; tarifas reais conforme a plataforma): uma solicitação simples (por ex., «recomende uma música de rock») custa cerca de **¥0,03**; uma tarefa complexa de várias etapas (por ex., «planeje uma viagem de carro de uma semana de Chengdu ao oeste de Sichuan») custa cerca de **¥1,6**. Limites de recarga: mínimo de ¥25 por recarga, até 10 vezes e ¥3.000 por dia, com saldo máximo de ¥10.000.
</Callout>

### Consultar seu consumo

- **Kimi web / app**: Configurações → Assinatura e faturas → [Meus créditos](https://www.kimi.com/membership/subscription?tab=quota).
- **Kimi Code Console**: uma vez ativado o Extra Usage, faça login no [Console](https://www.kimi.com/code/console) para ver seu saldo e consumo.
- **Kimi Code CLI**: digite `/usage` na linha de comando para consultar diretamente.

### Perguntas frequentes sobre Extra Usage

- **O Kimi na web e o Kimi Code usam a mesma carteira de Extra Usage?** Sim — o saldo é compartilhado entre ambos; recarregue uma vez e use em qualquer um.
- **O que é deduzido primeiro, o Extra Usage ou os créditos da assinatura?** Primeiro os créditos com prazo, como a assinatura; o Extra Usage só é deduzido como reserva depois de esgotados todos os créditos com prazo.
- **Se eu atingir um limite ou for limitado, posso continuar?** Sim. Uma vez ativado o Extra Usage, você não fica sujeito aos limites da assinatura: ao atingir qualquer limite, ele muda sem interrupções para o saldo de Extra Usage, as tarefas não param e só o Extra Usage é deduzido, sem afetar a renovação dos seus créditos de assinatura.
- **O saldo não usado é transferido e acumula?** Sim — não expira e acumula; permanece utilizável após o vencimento da assinatura, mas não é possível recarregar durante a interrupção.
- **O Extra Usage está disponível para Enterprise?** Ainda não é compatível.
