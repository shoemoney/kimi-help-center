# Benefícios do Kimi Code

O Kimi Code é um serviço incluído no plano de assinatura do Kimi, que oferece suporte e recursos voltados para programação para ajudar os membros a concluir tarefas de programação com mais eficiência em seu fluxo de trabalho de desenvolvimento pessoal.

> Lembre-se de que este benefício destina-se exclusivamente ao uso em desenvolvimento pessoal, e não a cenários de desenvolvimento corporativo. Para necessidades corporativas, acesse a [Plataforma Aberta do Kimi](https://www.platform.moonshot.ai/).

## Cobrança

- O uso do Kimi Code está **incluído na sua mensalidade de assinatura** — sem cobranças adicionais.
- Cada solicitação consome credits do seu **pool de créditos exclusivo do Kimi Code**; planos diferentes incluem quantidades diferentes de credits.
- O sistema dá prioridade aos credits bônus antes de consumir os credits do plano.

## Renovação de credits

Os credits são renovados em ciclos de **7 dias**:

- A partir da data da sua assinatura (D1), os credits são renovados a cada 7 dias.
- Períodos de renovação: D1–D7, D8–D14, D15–D21, D22–D28.
- Os credits não utilizados **não** são transferidos para o ciclo seguinte.

> Planeje seu uso semanal para aproveitar ao máximo seus credits.

## Ferramentas compatíveis

Os benefícios do Kimi Code estão disponíveis com as seguintes ferramentas:

| Ferramenta | Descrição |
| --- | --- |
| **Kimi Code CLI** | Agente de IA oficial de linha de comando do Kimi |
| **Claude Code** | Assistente de programação de linha de comando da Anthropic |
| **Roo Code** | Extensão de programação com IA para o VS Code |

Usar sua API Key do Kimi Code com plataformas ou ferramentas não listadas acima pode ser considerado uso indevido e resultar em acesso restrito. Para a melhor experiência e cobertura, utilize as ferramentas compatíveis listadas acima.
