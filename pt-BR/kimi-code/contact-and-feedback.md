# Contato e feedback

## Canais de feedback

Se você tiver algum problema ao usar o Kimi Code ou quiser fazer sugestões, envie seu feedback por um dos canais abaixo.

### Opção 1: enviar feedback diretamente pela CLI

No modo interativo da Kimi Code CLI, digite o comando `/feedback` para enviar feedback. O sistema coletará automaticamente informações sobre o seu ambiente atual, ajudando você a descrever o problema com mais precisão.

### Opção 2: Issues do GitHub

Acesse [Issues do GitHub do Kimi CLI](https://github.com/MoonshotAI/kimi-cli/issues) e pesquise para verificar se já existe um problema semelhante. Se não existir, você pode criar uma nova Issue e descrever em detalhes o que encontrou.

### Opção 3: feedback por e-mail

Você também pode enviar um e-mail para a equipe do Kimi Code em [code@moonshot.ai](mailto:code@moonshot.ai) para relatar problemas. Inclua o máximo possível das informações abaixo:

- **Descrição do problema**: descreva claramente o problema encontrado ou o recurso que você gostaria de ter
- **Passos para reproduzir**: como acionar o problema, passo a passo
- **Informações do ambiente**: sistema operacional e versão da Kimi Code CLI (execute `kimi --version` para verificar)
- **Logs de erro**: se houver uma mensagem de erro, cole-a integralmente

### Opção 4: entrar no grupo do Feishu
Escaneie o QR code para entrar no grupo do Feishu

## Solução de problemas antes de enviar feedback

Antes de enviar feedback, recomendamos verificar o seguinte:

- Se você atualizou para a versão mais recente da Kimi Code CLI (execute `kimi --version` para verificar)
- Se a sua conexão de rede está funcionando e se você consegue acessar `api.kimi.com`
- Se a sua API Key é válida e não expirou
- Se o diretório de trabalho está correto e se o Kimi tem permissão para acessar os arquivos relevantes
