# Visão geral do Kimi Work

Kimi Work é um Agent local de uso geral para profissionais do conhecimento, disponível no modo "Work" do cliente desktop Kimi (Mac / Windows).

Ele leva para as interações de desktop familiares aos profissionais do conhecimento no dia a dia os recursos de Agent já comprovados pelo Kimi Code em cenários de engenharia: você não precisa abrir um terminal, escrever comandos nem configurar ambientes. Basta descrever seu objetivo em linguagem natural, e o Kimi Work divide a tarefa, executa etapas em paralelo, chama ferramentas, usa o navegador, cria e organiza pastas e entrega produtos de trabalho como documentos, planilhas e apresentações — tudo no seu próprio computador.

O Kimi Code atende desenvolvedores que escrevem código; o Kimi Work atende profissionais do conhecimento, cobrindo principalmente cenários cotidianos como transferir informações, organizar arquivos, analisar dados e produzir relatórios.

## Principais recursos

- **Kernel de Agent local**: Desenvolvido com Kimi Code como kernel e o modelo Kimi K3, oferece os fundamentos de Agent local, incluindo a instalação e o uso de Skills e a execução de tarefas agendadas.
- **Skills profissionais**: Herda as Skills profissionais do Kimi Agent online, como criação de sites e de PPT, e também permite recomendar Skills de terceiros e carregar Skills locais.
- **Plugins e bancos de dados profissionais**: Use aplicativos e serviços externos dentro do Kimi, como Canva, Notion e WPS, e conecte-se a bancos de dados profissionais de finanças, pesquisa, direito e outras áreas.
- **Widgets**: Páginas interativas geradas pelo modelo em uma conversa, que podem se conectar a dados locais ou plugins externos para atualizações contínuas, tornando as respostas mais visuais e fáceis de entender. Consulte [Widgets](/kimi-work/widgets).
- **Dashboard**: Reúne os widgets mais importantes para você em uma única visualização persistente e personalizada, organizada em torno de um tema, projeto ou objetivo, pronta para ser consultada e gerenciada a qualquer momento. Consulte [Dashboard](/kimi-work/dashboard).
- **Kimi WebBridge**: Uma solução integrada de operação do navegador que usa o navegador como uma pessoa usaria.
- **Agent Swarm**: Com base na complexidade da tarefa, monta de forma autônoma uma equipe de até 300 subagentes para lidar com tarefas mais complexas e de execução mais longa.
- **Execução de tarefas de longo prazo**: Com a execução de tarefas de longo prazo do modelo Kimi K3, oferece suporte a dezenas de horas de trabalho autônomo e milhares de chamadas autônomas de ferramentas.

## Interface e interação

- O cliente tem dois modos, "Work" e "Chat". A barra lateral do modo Work inclui: Nova tarefa, Dashboard, Plugins, Skills, Tarefas agendadas, WebBridge, Projetos e Chat.
- Digite "/" na caixa de entrada para usar Skills rapidamente, e "@" para adicionar contexto.
- Há controle de permissões, e você pode escolher como autorizar:
  - **Solicitar permissão**: pedir autorização antes de agir
  - **Permitir tudo**: executar diretamente sem pedir autorização
- Alterne entre dois modos de execução: "Agent" e "Agent Swarm".

## Notas da versão

O Kimi Work foi lançado em 3 de junho de 2026 e está atualmente em Beta, com iterações frequentes. Ele vem adicionando progressivamente recursos como pré-visualização de arquivos, salvamento automático de rascunhos, modo Goal, Plugin Center, Widgets e Dashboard. Desde a versão 3.1.0, o Kimi Work é desenvolvido com o modelo Kimi K3. O foco atual dos testes está na decomposição de tarefas, paralelismo multiagente, chamadas de ferramentas, operação do navegador, manipulação de arquivos locais e geração de entregáveis longos; a estabilidade da execução, a qualidade das entregas e a experiência do usuário continuarão melhorando com base no feedback dos usuários beta.
