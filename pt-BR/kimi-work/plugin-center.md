# Central de plugins

## Plugins integrados de bases de dados profissionais

O Kimi Work traz plugins integrados de bases de dados profissionais nas áreas de finanças, direito e pesquisa acadêmica, oferecendo a profissionais fontes confiáveis e oficiais, com dados nacionais e globais:

- **Dados financeiros**: Wind Financial Data Service, dados financeiros Hundsun Gildata, S&P Global Market Intelligence, bases de dados financeiras globais, base de dados do FMI (Fundo Monetário Internacional), Straight Flush (Tonghuashun) e mais
- **Negócios / jurídico**: Tianyancha, Huayu Yuandian e mais

## Plugins selecionados de apps externos

A Central de plugins oferece plugins opcionais, selecionados oficialmente, incluindo:

- **Colaboração em escritório**: Baidu Netdisk, DingTalk, Feishu, WPS
- **Design**: Canva
- **Notas**: Notion
- **Desenvolvimento web**: Cloudflare
- **Outros**: Kimi Computer Use (a IA controla a área de trabalho para operações no nível do sistema), GitHub, Neon (uma plataforma de banco de dados PostgreSQL na nuvem), Supabase (uma plataforma de backend e banco de dados de código aberto) e mais

Depois que um plugin é instalado, o Kimi Work consegue operar essas ferramentas comuns de escritório diretamente, substituindo ações repetitivas por uma única instrução em linguagem natural.

## Como ativar

1. Abra a versão mais recente do cliente desktop do Kimi, mude para o modo "Trabalho" na barra lateral esquerda e clique em "Plugins" para acessar a Central de plugins;
2. Encontre e instale os plugins de que você precisa em "Instalados" e "Plugins em destaque";
3. Digite uma barra "/" na caixa de entrada e selecione o plugin que deseja chamar.
