# Faturas

A Kimi permite gerar faturas de forma autônoma para seus pagamentos de assinatura.

## Como obter uma fatura?

As faturas são enviadas automaticamente para o endereço de e-mail cadastrado junto ao seu provedor de pagamento (Airwallex, Stripe, Apple ou Google).

## Precisa de uma fatura revisada ou de detalhes adicionais?
- **E-mail:** envie para membership@moonshot.ai com as seguintes informações:
- Fatura original
- Dados de cobrança (nome da empresa, endereço, estado/província, e-mail, CNPJ/inscrição fiscal)

Usuários de Singapura: forneçam também o número de registro do GST
