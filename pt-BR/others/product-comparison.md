# Qual é a diferença entre Kimi, Kimi Work, Kimi Code e Kimi Claw? Qual devo usar?

Kimi inclui um assistente online pronto para uso, além de vários produtos pensados para diferentes usuários e cenários. Todos compartilham os recursos centrais do Kimi; as principais diferenças estão em **onde você os usa, para quem são indicados e no que se destacam**.

## Visão geral

| Produto | O que é | Indicado para / cenários | Onde usar |
|---|---|---|---|
| **Kimi** (web / app) | Um assistente de IA online que combina chat e Agente | Perguntas e respostas do dia a dia, redação, busca, criação de sites / PPT / documentos e planilhas, Deep Research e muito mais | Web, app móvel |
| **Kimi Work** | Um **Agente local** para profissionais do conhecimento (desktop) | Trabalhar com arquivos locais no seu computador, automatizar tarefas em aplicativos de desktop e executar tarefas de longa duração | Cliente para Mac / Windows |
| **Kimi Code** | Uma suíte de assistente de programação para **desenvolvedores** | Escrever código e manter bases de código | CLI, extensão do VS Code |
| **Kimi Claw** | Uma plataforma de **automação em nuvem sem implantação** | Automação em nuvem 24/7, sempre ativa, bots integrados ao Feishu / WeChat e muito mais | Nuvem (sem servidor necessário) |

## Qual devo usar?

- **Para conversas do dia a dia, redação, busca ou para pedir ao Kimi que crie sites, PPTs e planilhas ou faça Deep Research** → use **Kimi** (web / app).
- **Se você precisa que o Kimi leia e escreva arquivos locais no seu computador, automatize ações em vários aplicativos de desktop ou execute tarefas longas** → use **Kimi Work** (desktop).
- **Se você é desenvolvedor e precisa principalmente de ajuda para escrever código ou manter projetos** → use **Kimi Code**.
- **Se você quer um bot em nuvem sempre ativo, que rode automaticamente e possa se conectar ao Feishu / WeChat e a outras plataformas** → use **Kimi Claw**.

<Callout type="tip">
A experiência online do Kimi já une “chat” e “Agente”; você não precisa alternar entre eles. No aplicativo desktop do Kimi Work, há dois modos: “Trabalho” (um modo de Agente focado em entregáveis) e “Chat” (conversas rápidas).
</Callout>

## Qual assinatura devo escolher?

Os benefícios da assinatura ficam vinculados à sua conta Kimi. Todas as funcionalidades da assinatura (chat, Agente, Deep Research, Kimi Code e outras) **compartilham o mesmo pool de credit (créditos)**; o Kimi Code também tem seu próprio rate limit de 5 horas por semana, aplicável apenas ao Kimi Code. Para detalhes dos planos e preços, consulte a [página de assinatura](/membership/membership-pricing).

Se seu uso é principalmente **trabalho do dia a dia + tarefas ocasionais**, um plano de assinatura Kimi adequado cobrirá a maioria dos cenários em web / app / Kimi Work. Desenvolvedores que **escrevem código com frequência** também devem prestar atenção especial aos benefícios do Kimi Code.
