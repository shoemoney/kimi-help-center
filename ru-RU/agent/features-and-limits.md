# Возможности и ограничения Agent

<SeoMeta
  title="Возможности и ограничения Agent - Справочный центр Kimi"
  description="Узнайте о возможностях Kimi Agent, советах по использованию, ограничениях и лучших практиках для получения оптимальных результатов."
/>

<Callout type="info">
**Kimi Agent** — это AI-помощник, который самостоятельно выполняет сложные задачи с помощью многошагового рассуждения и интеграции инструментов. В этом руководстве собраны лучшие практики, ограничения и ответы на частые вопросы, чтобы вы могли эффективнее работать в режиме Agent.
</Callout>

## Советы по использованию

**(1) Перед отправкой задачи**

Четко опишите исходные данные и ограничения: контекст проекта, сценарий использования и особые требования. Так Kimi точнее поймет ваш замысел.

**(2) Во время выполнения**

Kimi Agent работает асинхронно в фоновом режиме. Если страница кажется зависшей или остановившейся, **не нажимайте «Стоп»** — это прервет выполнение задачи. Вы можете покинуть страницу: задача продолжит выполняться в фоне, а после завершения вы получите уведомление. Если задача должна занять много времени (например, Agent Swarm), пожалуйста, наберитесь терпения.

**(3) Сценарии для сайтов**

Agent умеет создавать фулстек-контент, включая frontend-интерфейсы, backend-сервисы и логику постоянного хранения данных. Если проект работает не так, как ожидалось, причина обычно связана с запуском sandbox, инициализацией базы данных, настройкой аутентификации или отсутствием действий для публикации. Стандартный Agent работает в облаке и не может напрямую обращаться к локальным файлам или корпоративным интранет-системам. Для доступа к локальным файлам или интранету используйте Kimi Claw.

<Callout type="tip">
**Нужен доступ к локальным файлам?** Используйте Kimi Claw для безопасного доступа к локальным файлам и корпоративным интранет-системам. Подробнее — в [документации Kimi Claw](/kimi-claw/overview).
</Callout>

**(4) Многоходовые диалоги и корректировка задач**
После нескольких ходов диалога и правок Agent может «забыть» часть ранних деталей. Лучше сначала задать рамки задачи и ключевые пункты, а затем вносить изменения постепенно.

**(5) Декомпозиция крупных задач**
Крупные и сложные задачи лучше разбивать на 2–3 этапа и отправлять Kimi пакетами либо использовать Agent Swarm.

**(6) Ограничения на файловый вывод**
В стандартном режиме Agent обычно можно получить только один файл на задачу (например, документ или таблицу). Если нужны несколько файлов (например, одновременно Word-документ и PPT), используйте Agent Swarm.

**(7) Лимиты контекста и баланс вывода**
Из-за лимита контекста больших языковых моделей в 256K символов (примерно 40 000–50 000 китайских иероглифов / около 100 000 английских слов) при обработке больших объемов файлов важно соблюдать баланс между объемом входных данных и результата.

<Callout type="warning">
**Примечание о лимите контекста**: Agent использует контекстное окно на 256K символов. Для лучших результатов давайте краткий контекст и не перегружайте задачу ненужными файлами.
</Callout>

## Важные примечания

<Callout type="warning">
**Использование кредитов**: задачи Agent расходуют кредиты из общего пула (общего с другими функциями подписки). Kimi Code использует отдельный пул кредитов. Обычно каждая задача Agent расходует 1 единицу кредита. Подробную информацию о кредитах для разных уровней подписки см. в разделе [кредиты и оплата](/agent/quota-and-billing).

- Бесплатный уровень: 6 задач Agent в месяц
- Платные уровни: 60–720 задач Agent в месяц в зависимости от вашего тарифа
</Callout>

- **Время выполнения**: в режиме Agent одна задача обычно занимает 5–20 минут. Задачи Agent Swarm могут выполняться дольше. Вы можете покинуть страницу — главное, не нажимайте «Стоп», чтобы не прервать задачу.
- **Использование кредитов**: задачи Agent расходуют кредиты из общего пула. Kimi Code использует отдельный пул кредитов. 
- **Простые задачи**: для простых вопросов и ответов рекомендуется стандартный режим чата — он отвечает быстрее.

<Callout type="warning">
**Соответствие контента правилам**: функции Agent регулируются [Соглашением об использовании сервиса Kimi](https://www.kimi.com/user/agreement/modelUse?version=v2). Создание запрещенного контента не поддерживается; отправка запрещенного контента может привести к приостановке доступа к сервису.
</Callout>

## FAQ

**В: Что умеет Agent?**

Agent решает следующие задачи с помощью нескольких вызовов инструментов:
- **Генерация и редактирование текста**: создает статьи, отчеты, документы и другие материалы с поддержкой разных стилей письма и форматов.
- **Веб-разработка**: создает интерфейсы и сервисы фулстек-проектов, включая дизайн интерфейса приложения, backend-интеграцию, сохранение данных и визуализацию данных.
- **Создание слайдов**: специальный веб-инструмент для PPT, позволяющий генерировать готовые презентации.
- **Помощь с кодом**: написание и отладка кода на разных языках программирования.

**В: Почему сайт, созданный Agent, не работает?**

Полный проект обычно состоит из трех частей: frontend-интерфейса, backend-сервисов и хранилища данных. Agent может генерировать фулстек-контент проекта на всех трех уровнях. Если проект работает не так, как ожидалось, причина обычно связана с запуском sandbox, инициализацией базы данных, настройкой аутентификации или отсутствием действий для публикации.

**В: Что Agent выдает в результате?**

- Файлы с полностью выполненной задачей
- Предпросмотр развернутого проекта и опубликованные версии
- ZIP-архив для скачивания (находится в `/mnt/okcomputer/output/`)

**В: Какова длина контекста Agent?**

Agent использует контекст длиной **256K символов** (примерно 40 000–50 000 китайских иероглифов / около 100 000 английских слов).

**В: Как рассчитываются кредиты Agent?**

Agent, PPT и другие функции подписки используют общий пул кредитов. Kimi Code использует отдельный пул кредитов. Каждая задача Agent обычно считается одной единицей кредита.
