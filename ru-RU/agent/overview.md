# Обзор K2.6 Agent

Kimi K2.6 Agent — автономный AI-помощник, который выполняет сложные задачи от начала до конца. Работая на модели K2.6, он использует более 20 инструментов для создания сайтов, подготовки документов, анализа данных и многого другого.

## Развитие продукта
- **5 сентября 2025 г.**: выпущен Kimi K2 — 32B активных / 1T параметров всего
- **26 сентября 2025 г.**: запущен Agent-режим "OK Computer"
- **27 января 2026 г.**: выпущен Kimi K2.5 — улучшены навыки работы с Office и возможности Agent
- **Февраль 2026 г.**: запущена публичная бета Kimi Claw

## Основные возможности
| Возможность | Описание |
|---------|-------------|
| **Сайты** | Создание и развертывание адаптивных веб-приложений |
| **Документы** | Редактирование и создание Word, PDF и Markdown |
| **Таблицы** | Анализ и визуализация данных Excel/CSV |
| **Презентации** | Автоматическое создание PPT |
| **Deep Research** | Исследовательские отчеты объемом 10 000+ слов |
| **K2.6 Agent Swarm** | До 300 Subagent работают параллельно |
| **Kimi Claw** | Облачная автоматизация с 5 000+ навыками |

## Как это работает？
1. **Планирование задачи**: разбивает ваш запрос на подзадачи
2. **Вызов инструментов**: использует более 20 инструментов по мере необходимости
3. **Автономное выполнение**: проводит исследование, проектирование и разработку
4. **Обработка ошибок**: исправляет ошибки самостоятельно, без вмешательства пользователя
5. **Результаты**: файлы Office, веб-приложения или отчеты

## Начало работы
- **Веб**: [kimi.com/agent](https://www.kimi.com/agent)
- **Мобильное приложение**: приложение Kimi → панель задач → режим Agent
Четко опишите задачу, следите за ходом выполнения, затем скачайте результаты или поделитесь ими.

## Сценарии использования
- Разработка сайтов (код писать не нужно)
- Создание контента с мультимедиа
- Сравнение и перевод документов
- Анализ данных (Excel до 1 000 строк)
- Создание презентаций
- Конвертация документов
