# Кредиты и оплата Agent

<Callout type="info">
Режим Agent использует систему кредитов Kimi. Во все подписки входят два пула кредитов: для Kimi Code действует отдельный пул; остальные функции подписки (Agent, Deep Research, Slides, Docs, Sheets, Kimi Claw и т. д.) используют общий пул, а кредиты списываются по фактическому расходу token.
</Callout>

## Модель тарификации
- **Два пула кредитов**: Во все подписки входят два пула кредитов. Для Kimi Code действует отдельный пул; остальные функции подписки используют один общий пул — распределяйте его как удобно
- **Оплата по фактическому использованию**: Расход кредитов зависит от сложности и длительности задачи (то есть от использования token): простые задачи требуют меньше кредитов, сложные — больше
- **Ежемесячное обновление**: Кредиты обновляются каждый месяц в соответствии с циклом вашей подписки
- **Приоритет расходования**: Сначала расходуются бонусные кредиты (например, пробные кредиты или промонаграды), затем кредиты тарифа

<Callout type="tip">
**Пример**: На тарифе Moderato создание простого PPT может израсходовать около 1–2% кредитов, а один сеанс Deep Research — примерно 5–10%.
</Callout>

## Что происходит, когда кредиты заканчиваются?
Когда кредиты исчерпаны:
- Все уже запущенные задачи завершатся в обычном режиме
- Для новых задач появится уведомление о недостатке кредитов
- Возможные варианты:
  - Дождаться автоматического ежемесячного обновления кредитов
  - Перейти на подписку более высокого уровня, чтобы получить больше кредитов

## Как проверить расход кредитов?
- **Web**: Профиль → Настройки → Подписка
- **App**: Профиль → План подписки → Подписка
Что можно посмотреть:
1. Текущий остаток кредитов (в процентах)
2. Дата следующего обновления
3. Последние 10 записей об использовании (время, использованная функция, процент расхода)

<Callout type="info">
Записи об использовании могут появляться с небольшой задержкой. Самую актуальную информацию смотрите в текущем отображении кредитов.
</Callout>

## Расходуются ли кредиты при неудачном выполнении задачи?
- Кредиты списываются после успешного выполнения задачи на основе фактического расхода
- Если задача не выполнена из-за системной ошибки (не получен корректный результат), нажмите кнопку **👎**, чтобы сообщить о проблеме. После проверки соответствующие кредиты будут возвращены
