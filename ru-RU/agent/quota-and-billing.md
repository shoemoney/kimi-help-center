# Квоты и оплата Agent

<Callout type="info">
Режим Agent использует систему квот Kimi. Во все подписки входят два пула квот: для Kimi Code действует отдельный пул; остальные функции подписки (Agent, Deep Research, Slides, Docs, Sheets, Kimi Claw и т. д.) используют общий пул, а квота списывается по фактическому расходу token.
</Callout>

## Модель тарификации
- **Два пула квот**: Во все подписки входят два пула квот. Для Kimi Code действует отдельный пул; остальные функции подписки используют один общий пул — распределяйте его как удобно
- **Оплата по фактическому использованию**: Расход квоты зависит от сложности и длительности задачи (то есть от использования token): простые задачи требуют меньше квоты, сложные — больше
- **Ежемесячное обновление**: Квота обновляется каждый месяц в соответствии с циклом вашей подписки
- **Приоритет расходования**: Сначала расходуется бонусная квота (например, пробные credit или промонаграды), затем квота тарифа

<Callout type="tip">
**Пример**: На тарифе Moderato создание простого PPT может израсходовать около 1–2% квоты, а один сеанс Deep Research — примерно 5–10%.
</Callout>

## Что происходит, когда квота заканчивается?
Когда квота исчерпана:
- Все уже запущенные задачи завершатся в обычном режиме
- Для новых задач появится уведомление о недостаточной квоте
- Возможные варианты:
  - Дождаться автоматического ежемесячного обновления квоты
  - Перейти на подписку более высокого уровня, чтобы получить больше квоты

## Как проверить расход квоты?
- **Web**: Профиль → Настройки → Подписка
- **App**: Профиль → План подписки → Подписка
Что можно посмотреть:
1. Текущий остаток квоты (в процентах)
2. Дата следующего обновления
3. Последние 10 записей об использовании (время, использованная функция, процент расхода)

<Callout type="info">
Записи об использовании могут появляться с небольшой задержкой. Самую актуальную информацию смотрите в текущем отображении квоты.
</Callout>

## Расходуется ли квота при неудачном выполнении задачи?
- Квота списывается после успешного выполнения задачи на основе фактического расхода
- Если задача не выполнена из-за системной ошибки (не получен корректный результат), нажмите кнопку **👎**, чтобы сообщить о проблеме. После проверки соответствующая квота будет возвращена
