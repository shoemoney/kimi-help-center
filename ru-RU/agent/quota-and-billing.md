# Кредиты и оплата Agent

<Callout type="info">
Режим Agent использует систему кредитов Kimi. Все функции подписки (Agent, Deep Research, Slides, Docs, Sheets, Kimi Code, Kimi Work, Kimi Claw и т. д.) расходуют единый пул кредитов; списание зависит от фактического потребления token.
</Callout>

## Модель оплаты
- **Единый пул кредитов**: все функции подписки расходуют общий пул кредитов — используйте их так, как вам удобно. Для Kimi Code также действует собственный rate limit 5 часов в неделю: он относится только к Kimi Code и не влияет на другие функции
- **Оплата по факту использования**: расход кредитов зависит от сложности и длительности задачи (то есть от использования token) — простые задачи обходятся дешевле, сложные дороже
- **Ежемесячное обновление**: кредиты сбрасываются каждый месяц в соответствии с циклом вашей подписки
- **Приоритет расходования**: сначала расходуются бонусные кредиты (например, пробные кредиты или промо-награды), затем кредиты тарифного плана

<Callout type="tip">
**Пример**: на тарифе Moderato создание простого PPT может израсходовать около 1–2% кредитов, а один сеанс Deep Research — примерно 5–10%.
</Callout>

## Что происходит, когда кредиты заканчиваются?
Когда кредиты исчерпаны:
- Любая уже запущенная задача завершится в обычном режиме
- Для новых задач появится уведомление «недостаточно кредитов»
- Что можно сделать:
  - Дождаться автоматического ежемесячного обновления кредитов
  - Перейти на более высокий уровень подписки, чтобы получить больше кредитов

## Как проверить расход кредитов?
- **Веб-версия**: Профиль → Настройки → Подписка
- **Приложение**: Профиль → Тарифный план → Подписка
Что можно посмотреть:
1. текущий баланс кредитов (в процентах)
2. дату следующего обновления
3. последние 10 записей об использовании (время, использованная функция, процент расхода)

<Callout type="info">
Записи об использовании могут появляться с небольшой задержкой. Самую актуальную информацию смотрите в фактическом отображении кредитов.
</Callout>

## Списываются ли кредиты за неудачную задачу?
- Кредиты списываются после успешного выполнения задачи исходя из фактического расхода
- Если задача завершилась неудачно из-за системной ошибки (не был получен корректный результат), нажмите кнопку **👎**, чтобы сообщить о проблеме. После проверки соответствующие кредиты будут возвращены
