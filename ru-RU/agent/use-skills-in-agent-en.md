# Использование навыков в режиме Agent

## Как вызывать навыки?

В поле ввода режима Kimi Agent Mode навыки можно вызвать тремя способами:

**Способ 1: используйте команду `/`**

Введите `/` в поле ввода, чтобы открыть список навыков. Нажмите на название навыка, чтобы вставить его. Также можно ввести ключевые слова после `/`, чтобы отфильтровать список.

**Способ 2: используйте меню «➕»**

Нажмите кнопку **➕** рядом с полем ввода. Выберите навык в меню, и его название будет вставлено в поле ввода как текст.

/>

**Способ 3: предоставьте выбор Kimi**

Просто опишите, что вам нужно. Kimi сам определит и запустит наиболее подходящий навык с учетом содержания задачи.

### Пример: создание отчета по SEO-анализу с помощью навыка

Допустим, вы контент-менеджер и хотите проанализировать SEO-показатели своего сайта:

1. Введите `/` в поле ввода, найдите и выберите навык `seo-analyzer`.
2. Продолжите ввод: `Please analyze https://help.com/zh-cn/help's SEO performance, list the main issues and optimization suggestions.`

<Frames
  src="./images/skills/SEO-en.png"
  alt="SEO-анализ"

3. После отправки Kimi автоматически выполнит поиск, систематизирует данные и выдаст структурированный отчет по процессу SEO-анализа.

Вам не нужно объяснять Kimi, как проводить анализ: порядок действий уже задан в навыке.

## Настройка навыков

Если рекомендованные Kimi навыки не подходят под ваши задачи, можно создать собственные — под конкретный рабочий процесс.

**Когда стоит создать собственный навык?**

- У вас есть повторяющаяся задача, которую нужно выполнять регулярно (например, еженедельные отчеты по конкурентам).
- Вы хотите, чтобы Kimi оформлял материалы в формате, принятом в вашей компании.
- У вас есть набор рабочих методов, которым Kimi должен следовать напрямую.

Хороший навык делает что-то одно — и делает это хорошо. Не пытайтесь уместить все требования в один навык.

### Вариант 1: из документа в навык

Если у вас уже есть готовые шаблоны, стандарты или примеры файлов, загрузите их напрямую — Kimi изучит материалы и создаст соответствующий навык.

1. В панели **Навыки** выберите **Документ Office в навык**.
2. Нажмите на область загрузки или перетащите в нее файлы. Поддерживаемые форматы: `docx`, `xlsx`, `pdf`, `pptx`, а также скриншоты документов. За одну загрузку можно добавить не более 3 файлов, каждый — до 100 MB.

<Frames
  src="./images/skills/document.png"
  alt="Загрузка документов для создания навыков"
/>

3. Заполните описание навыка: расскажите Kimi, что должен делать этот навык. Например: «Помоги мне оформлять еженедельные данные о продажах в стиле и формате этого шаблона».
4. Нажмите **Создать навык**.

### Вариант 2: создать вместе с Kimi

Если готовых документов нет, просто опишите требования в диалоге — Kimi шаг за шагом поможет вам создать навык.

Введите `/skill-creator` в поле ввода, а затем опишите, какой навык хотите создать. Kimi поможет оформить требования в полноценный навык.

<Frames
  src="./images/skills/create-skill-en.png"

### Управление существующими навыками

В панели **Навыки** перейдите на вкладку **Пользовательские навыки**, чтобы редактировать созданные навыки, обновлять документы или удалять навыки.

<Frames
  src="./images/skills/managing-skills.png"

/>

<Callout type="info">
Навыки поддерживаются в Agent Mode и Kimi Claw. Навыки с суффиксом `swarm` доступны только в сценариях Swarm (кластер Agent) и не отображаются в других контекстах.
</Callout>

## Как писать эффективные описания навыков

Kimi ориентируется на описание навыка, чтобы понять, «когда использовать этот навык». Чем яснее описание, тем точнее будет срабатывать навык.

Полное описание навыка должно включать:
- Основную функцию навыка.
- Сценарии, для которых он подходит.
- Триггерные слова, на которые он реагирует.
- Распознавание косвенных упоминаний потребности.
