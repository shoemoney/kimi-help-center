# Что такое навыки?

<Frames
  src="./images/skills/what_is_skill.png"
  alt="what_is_skill"
/>

Навыки — это переиспользуемые пакеты знаний, которые расширяют возможности ИИ-агента. Каждый навык включает:

- **Подходы к работе и операционные инструкции** — методики, адаптированные под конкретные типы задач.
- **Лучшие практики и стандарты** — отраслевые стандарты и внутренние регламенты, которым нужно следовать.
- **Скрипты, инструменты и справочные материалы** — дополнительные инструменты и материалы, помогающие выполнить задачу.

## Как пользоваться?

В начале диалога агент видит список доступных навыков с их названиями и краткими описаниями. Если навык подходит для текущей задачи, агент загружает полные инструкции и действует в соответствии с ними.

## Путь пользователя

От поиска навыков до создания собственных полный путь выглядит так:

1. **Найдите навыки** — просмотрите официальные и рекомендованные навыки на панели Skills, чтобы выбрать подходящий для вашего сценария.
2. **Установите навыки** — нажмите кнопку «+», чтобы мгновенно добавить навык.
3. **Вызовите навыки** — введите `/` в поле чата и выберите навык либо позвольте Kimi автоматически запустить подходящий навык по вашему запросу.
4. **Создайте собственный навык** — если существующие навыки не подходят, загрузите документы или опишите свои требования, чтобы сгенерировать пользовательский навык, либо используйте `/skill-creator` и создайте его в диалоге.

## Как работают навыки?

Когда вы отправляете запрос, Kimi Agent оценивает, нужен ли для текущей задачи определенный навык. Если да, он автоматически загружает соответствующий навык и выполняет задачу по его инструкциям.

Навыки загружаются только тогда, когда они действительно относятся к задаче, поэтому они не мешают контексту других диалогов.

## Навыки и прямой промптинг: в чем разница?

Возьмем в качестве примера написание еженедельного отчета:
- **Прямой промптинг**: вы напрямую просите Kimi Agent, и он пишет отчет, исходя из собственного понимания формата.
- **Использование навыков**: после установки навыка для еженедельных отчетов каждый результат будет соответствовать заранее заданной структуре, тону и объему — без необходимости повторять инструкции.

| | Прямой промптинг | Использование навыков |
|---|---|---|
| **Нужно каждый раз объяснять требования?** | Да | Нет, применяются автоматически |
| **Стабильность формата результата** | Может меняться | Постоянный, как задано |
| **Лучше всего подходит для** | Разовых, временных задач | Повторяющихся, фиксированных процессов |
| **Нужна настройка?** | Нет | Нужно создать или установить |

## Типы навыков

### (1) Официальные и рекомендованные навыки

**Официальные навыки**: создаются и поддерживаются Moonshot AI, доступны всем пользователям. Kimi автоматически запускает их в подходящих сценариях.

Распространенные официальные навыки:
- `docx` — создание и редактирование документов Word; подходит для любых задач с .docx, включая создание документов, редактирование, комментарии, исправления, сноски, оглавления и преобразование Markdown в Word.
- `deep-research` — проведение углубленного исследования и подготовка развернутых отчетов с помощью набора инструментов; требует не менее 10 итеративных циклов поиска, рекурсивной рефлексии и обязательной визуализации в IPython.

**Рекомендованные навыки**: отобранные навыки для конкретных сценариев, которые можно добавить одним кликом; покрывают распространенные случаи, например инвестиционные исследования и форматирование документов.

Распространенные рекомендованные навыки:
- `sop-writer` — преобразует бизнес-процессы в полноценные документы со стандартными операционными процедурами (SOP), включая блок-схемы процессов, матрицы RACI, подробные операционные шаги и обработку исключений.
- `event-etf-study` — на основе концепции или события определяет связанные акции, строит ETF-индекс, взвешенный по рыночной капитализации, анализирует изменения рыночной стоимости в окне события и создает интерактивные HTML-дашборды. Используется, когда пользователи спрашивают о концептуальных акциях, концептуальных ETF, event-driven анализе или исследовании событий.

**Офисный документ в навык**: загружайте документы, чтобы создавать навыки и легко воспроизводить стилевые темы.

### (2) Навыки с открытым исходным кодом

Скачивайте или устанавливайте подходящие Skills из open-source сообществ и используйте их вместе с Local Agents (например, Kimi Code) или Cloud Agents (например, Kimi Claw).

**Популярные платформы-хабы AI Skill**

| Платформа | URL | Описание |
|----------|-----|-------------|
| SkillsMP | https://skillsmp.com | Маркетплейс навыков для AI agent, который берет пакеты SKILL.md из GitHub и совместим с Claude Code и OpenAI Codex CLI |
| SkillsLLM | https://skillsllm.com | Open-source маркетплейс навыков для AI agent с более чем 1 600 навыками, прошедшими проверку безопасности, для Claude Code, Codex CLI и ChatGPT |
| LobeHub Skills | https://lobehub.com/skills | Просмотр и распространение пакетов SKILL.md, совместимых с Claude Code, Codex CLI и ChatGPT |

### (3) Пользовательские навыки

Пользовательские навыки, которые вы создаете для личных рабочих процессов и задач в конкретной предметной области, например:
- Применять к документам или презентациям определенные руководства по стилю.
- Создавать письма или коммуникационные материалы на основе фиксированных шаблонов.
- Оформлять протоколы встреч в определенном формате.
- Выполнять заданные процессы анализа данных.
