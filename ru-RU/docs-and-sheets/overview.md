# Kimi Docs и Kimi Sheets

<Callout type="info">
27 января 2026 года Moonshot AI выпустила Kimi K2.5 — крупное обновление продуктивных возможностей Kimi Agent. Теперь Kimi Agent «владеет Office»: он обеспечивает сквозной выпуск файлов Word, PDF, Excel и презентаций.
</Callout>

Kimi K2.5 заметно повышает качество результата и эффективность вызова инструментов в офисных сценариях, особенно при создании структурированных материалов со сквозной обработкой:
| Формат | Возможности |
|--------|-------------|
| **Word** | Интеллектуальное форматирование и отслеживание правок |
| **PDF** | Визуальный дизайн и макеты с сочетанием текста и изображений |
| **Excel** | Анализ данных и финансовое моделирование |
| **Slides** | Автоматическая генерация и визуальный сторителлинг |

## Kimi Docs
Kimi Docs хорошо адаптирует текст и системно понимает рабочие процессы Office.
### Основные возможности
**Документы Word:**
- Создание крупных профессиональных документов: white paper, исследовательских отчетов, договоров, коммерческих предложений
- Добавление комментариев и предложений по правкам в существующие документы Word
- Работа с иерархией заголовков, интервалами между абзацами, цитированием и форматированием списков
- Сжатие диссертации на 30 000 слов до точного резюме
**Документы PDF:**
- Создание профессиональных PDF-отчетов с богатым иллюстративным оформлением: обложкой, оглавлением, основным текстом и подписями к рисункам
- Повторное редактирование и переформатирование существующих PDF без профессионального ПО для верстки
- Извлечение нужной информации из PDF на сотни страниц
- Сравнение едва заметных различий между несколькими версиями договора
### Как пользоваться Kimi Docs?
**Точки входа:**
- Общий способ: нажмите ярлыки Docs, Sheets или Slides на боковой панели либо в окне чата
- Специальный способ: нажмите кнопку "Docs" внизу окна чата
### Способ 1: перейти на страницу Kimi Docs

<Frames
  src="./images/overview/screenshot-1.png"
  alt="скриншот 1"
/>

1. **Откройте браузер**: Chrome, Safari, Edge, Firefox или любой другой популярный браузер
2. **Перейдите по адресу**: [kimi.com/docs](https://www.kimi.com/docs)
3. **Войдите в аккаунт**: авторизуйтесь в своей учетной записи Kimi (через Google или email)
4. **Введите задачу**:
   - **Текстовый ввод**: опишите задачу естественным языком
   - **Загрузите документ** для редактирования
   - **Посмотрите примеры**: нажмите "Сделать похожий", настройте результат и отправьте запрос
5. **Начните создание**: выберите шаблон или создайте документ через диалог

<Frames
  src="./images/overview/screenshot-2.png"
  alt="скриншот 2"
/>

<Callout type="tip">
Опишите, что вам нужно, напрямую: например, "Создай для меня отчет по XX". Либо загрузите существующий файл Word/PDF/Excel и укажите, что с ним сделать. Скачайте файл в исходном формате (.docx / .xlsx / .pdf), чтобы продолжить редактирование локально.
</Callout>

### Способ 2: мобильное приложение
Приложение Kimi доступно на iOS и Android. Нажмите на панель задач → переключитесь в режим Docs Agent.
#### Способ 3: общий режим Agent
Переключитесь в режим K2.6 Agent и введите задачу, связанную с документами. Kimi вызовет инструменты чтения и записи.
## Kimi Sheets
Kimi Sheets понимает связи между ячейками, логику связей между листами и создает .xlsx-файлы прямо в браузере.
### Основные возможности
| Возможность | Описание |
|------------|-------------|
| **Массовый ввод данных** | Извлекает данные из документов — например, переносит сведения об экспонентах из PDF в Excel-файл на 1 000 строк |
| **Консолидация из нескольких источников** | Объединяет 50 Excel-отчетов разных отделов в единую сводку по компании |
| **Ввод естественным языком** | Автономный веб-поиск с интеллектуальным созданием таблиц |

### Как пользоваться Kimi Sheets?
Нажмите кнопку "Agent" внизу окна чата или выберите ярлык "Sheets" на боковой панели.

<Frames
  src="./images/overview/screenshot-4.png"
  alt="скриншот 4"
/>

Можно сказать: *"Найди в интернете и собери последние публикации по области XX в документ Excel,"* — или загрузить существующий файл Excel/CSV и указать нужные действия. Просмотрите результат онлайн, затем скачайте .xlsx-файл.
