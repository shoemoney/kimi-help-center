# Контакты и обратная связь

**В: Где можно оставить отзыв?**

Выберите подходящий канал в зависимости от темы обращения:

| Тип обращения | Канал |
|--------------|---------|
| Проблемы с продуктом | В веб-версии: нажмите на свой аватар в левом нижнем углу → Обратная связь → Помощь и обратная связь. В приложении: Профиль → Настройки → Обратная связь |
| Отзыв о качестве чата | После диалога нажмите кнопку **👎** и опишите тип проблемы и конкретное отклонение |
| Апелляции по аккаунту / жалобы | [support@moonshot.ai](mailto:support@moonshot.ai) |
| Запросы от СМИ | [pr@kimi.com](mailto:pr@kimi.com) |
| Поддержка Kimi API | Войдите на [Kimi Open Platform](https://platform.moonshot.ai/), чтобы найти контакты службы поддержки и сообщество разработчиков |
