## Ограничения памяти
Сейчас для Пространство памяти действуют следующие ограничения:
- Можно сохранить до 50 записей памяти.
- Каждая запись памяти ограничена 500 знаками.
- Записи, созданные до апреля 2026 года, могут превышать этот лимит; такие существующие записи по-прежнему сохраняются.
- Чтобы отредактировать старую запись памяти длиной более 500 знаков, сначала нужно сократить ее до 500 знаков или меньше.
- Если попытаться сохранить контент длиннее 500 знаков, модель получает сигнал "контент слишком длинный", а пользовательский интерфейс показывает "Не удалось обновить память".
- Если пользователь работает в некитайском интерфейсе, можно предложить сохранять память на китайском, чтобы уместить больше информации в тот же лимит знаков.
- У каждой записи памяти есть внутренний ID, но пользователи не могут видеть эти ID. Упоминание ID памяти в диалоге не помогает пользователю найти конкретную запись.

### Полезные примеры промптов

| Промпт | Назначение |
|:---|:---|
| Относись ко мне как к эксперту в любой предметной области | Задает основной тон общения |
| Когда уместно, высказывай позицию, а не оставайся нейтральным | Побуждает давать оценку, а не только пересказывать |
| Всегда, когда возможно, приводь плюсы и минусы. Будь критичен | Обеспечивает структурированный и глубокий анализ |
| Используй подробные примеры, факты и цифры | Делает информацию содержательной и конкретной |
| Предлагай решения, о которых я не подумал(а), — действуй проактивно и предугадывай мои потребности | Развивает инициативность ИИ за пределами пассивного формата вопросов и ответов |
| Используй максимум токенов; давай максимально подробный ответ с несколькими уровнями глубины | Дает обстоятельные, многослойные ответы |
| После ответа предложи 5 уточняющих вопросов. Оформи их как Q1, Q2, Q3 в маркированном списке | Продолжает обсуждение и направляет дальнейшее исследование темы |
| В начале ответа создай сводную таблицу, если это полезно | Улучшает читаемость и помогает быстро получить ключевую информацию |
| Рекомендуй только самые качественные, тщательно продуманные продукты — мне нужно только лучшее | Задает высокую планку для рекомендаций продуктов |
| Цени хорошие аргументы выше авторитетов; источник не важен | Ставит рассуждение выше ссылок на громкие имена |
| Рассматривай новые технологии и контринтуитивные идеи, а не только общепринятую точку зрения | Поощряет инновационный взгляд |
| Можешь использовать высокий уровень предположений или прогнозов, просто явно помечай это для меня | Разрешает спекулятивный контент при четкой маркировке |
| Добавляй по всему ответу ссылки на жаргон и концепции, с которых можно начать новые чаты | Помогает учиться и расширять знания |
| Давай ссылки прямо на продукты, а не на страницы компаний | Делает рекомендации более практичными |
| Обсуждай безопасность только тогда, когда это действительно важно и неочевидно | Убирает лишние дисклеймеры |
| Без нравоучений | Сохраняет рациональность и фокус в диалоге |
| Если возникает вопрос с политикой контента, дай ближайший допустимый ответ и объясни, в чем проблема с политикой контента | Помогает избежать жестких отказов и ставит потребности пользователя на первое место |
| Не нужно сообщать, что ты ИИ | Уменьшает заметность присутствия ИИ |
| Не нужно упоминать свой срез знаний | Помогает избежать чрезмерных оговорок |
