# Обзор Kimi

<Callout type="info">
Kimi — ИИ-ассистент, разработанный Moonshot AI. В него встроены веб-поиск, глубокое мышление, мультимодальные рассуждения и диалоги со сверхдлинным контекстом.
</Callout>

Перейдите на [Kimi.com](https://www.kimi.com/) или скачайте приложение Kimi, чтобы общаться, создавать материалы, проводить исследования и собирать проекты. Разработчики могут перейти на [открытую платформу Kimi](https://platform.kimi.ai/), где доступны API и инструменты для интеграции возможностей Kimi в собственные приложения.
## Чат и модели
Kimi предлагает несколько моделей. Нажмите кнопку переключения модели над полем ввода, чтобы сменить ее.
| Модель | Мощность рассуждений | Лучше всего подходит для |
|-------|-------------------|----------|
| **K2.6** | Стандартная / Высокая | Быстрого диалога и вопросов-ответов с более оперативными ответами |
| **K3** | Низкая / Высокая / Максимальная | Задач в чате и Agent; самая мощная в целом |
| **K3 Swarm** | Низкая / Высокая / Максимальная | Масштабного поиска и пакетной обработки, выполняемых за один проход |

<Callout type="tip">
Нужно ли искать в интернете, Kimi определяет автоматически на основе вашего вопроса — переключать вручную не требуется.
</Callout>

## ИИ-агенты
Kimi — это не просто чат-ассистент, а ИИ-агент, который умеет самостоятельно планировать и выполнять задачи:
| Агент | Описание | Ссылка |
|-------|-------------|------|
| **General Agent** | Самостоятельно планирует и выполняет задачи, включая создание сайтов и слайдов, Deep Research, обработку документов и электронных таблиц | [kimi.com/agent](https://www.kimi.com/agent) |
| **Agent Swarm** | Поддерживает до 4 000 параллельных вызовов инструментов и координирует более 300 субагентов для масштабного поиска, объемных текстов и пакетной обработки | [kimi.com/agent-swarm](https://www.kimi.com/agent-swarm) |
| **Kimi Code** | Набор инструментов для разработчиков: ассистент для программирования, CLI tool и расширение для VS Code | [kimi.com/code](https://www.kimi.com/code) |
| **Kimi Claw** | Облачная платформа автоматизации без развертывания: запускайте постоянного ИИ-агента менее чем за 30 секунд с более чем 5 000 встроенных навыков (ClawHub) | [kimi.com/bot](https://www.kimi.com/bot) |
| **Kimi Work** | Универсальный локальный Agent для специалистов умственного труда, построенный на основе Kimi Code: предоставляет базовые возможности локального Agent (навыки, запланированные задачи) вместе с созданием сайтов, PPT и профессиональными базами данных из онлайн-Kimi Agent | [kimi.com/products/kimi-work](https://www.kimi.com/products/kimi-work) |

## Другие ключевые возможности
- **Главное**: решение задач по фото, голосовые звонки, перевод, помощь с текстами
- **Работа с файлами**: поддерживаются PDF, Word, Excel, PPT, изображения, TXT и видео (до 100 МБ каждый), максимум 50 файлов за один сеанс
- **Пресеты**: сохраняйте часто используемые запросы для быстрого доступа — идеально для качественных многоразовых шаблонов промптов
