# Обзор Kimi

<Callout type="info">
Kimi — ИИ-ассистент, разработанный Moonshot AI. В него встроены веб-поиск, глубокое мышление, мультимодальные рассуждения и диалоги со сверхдлинным контекстом.
</Callout>

Перейдите на [Kimi.com](https://www.kimi.com/) или скачайте приложение Kimi, чтобы общаться, создавать материалы, проводить исследования и собирать проекты. Разработчики могут перейти на [открытую платформу Kimi](https://platform.kimi.ai/), где доступны API и инструменты для интеграции возможностей Kimi в собственные приложения.
## Режимы чата
| Режим | Описание |
|------|-------------|
| **Web search (Auto/Off)** | Подключается к интернету для получения актуальной информации и результатов веб-поиска |
| **K2.6 Instant** | Быстрые ответы на общие вопросы |
| **K2.6 Thinking** | Более глубокое многошаговое рассуждение и поиск — особенно полезно для программирования, логических и аналитических задач |

<Callout type="tip">
Для простых вопросов и ответов по документам можно отключить и веб-поиск, и режим мышления.
</Callout>

## ИИ-агенты
Kimi — это не просто чат-ассистент, а ИИ-агент, который умеет самостоятельно планировать и выполнять задачи:
| Агент | Описание | Ссылка |
|-------|-------------|------|
| **K2.6 Agent** | Самостоятельно планирует и выполняет задачи, включая создание сайтов и слайдов, Deep Research, обработку документов и электронных таблиц | [kimi.com/agent](https://www.kimi.com/agent) |
| **K2.6 Agent Swarm [Beta]** | Поддерживает до 4 000 параллельных вызовов инструментов и координирует более 300 субагентов для масштабного поиска, объемных текстов и пакетной обработки | [kimi.com/agent-swarm](https://www.kimi.com/agent-swarm) |
| **Kimi Code** | Набор инструментов для разработчиков: ассистент для программирования, CLI tool и расширение для VS Code | [kimi.com/code](https://www.kimi.com/code) |
| **Kimi Claw** | Облачная платформа автоматизации без развертывания: запускайте постоянного ИИ-агента менее чем за 30 секунд с более чем 5 000 встроенных навыков (ClawHub) | [kimi.com/bot](https://www.kimi.com/bot) |

## Другие ключевые возможности
- **Главное**: решение задач по фото, голосовые звонки, перевод, помощь с текстами
- **Работа с файлами**: поддерживаются PDF, Word, Excel, PPT, изображения, TXT и видео (до 100 МБ каждый), максимум 50 файлов за один сеанс
- **Пресеты**: сохраняйте часто используемые запросы для быстрого доступа — идеально для качественных многоразовых шаблонов промптов
