# Аккаунт и аутентификация

<Callout type="info">
Частые вопросы об аккаунтах разработчиков Kimi API, верификации и аутентификации.
</Callout>

## Может ли личный аккаунт получить счёт для юрлица?
Личный аккаунт **не может напрямую получить счёт для юрлица**. Если вам нужен такой счёт, сначала переведите аккаунт в статус организации. После верификации вы сможете запрашивать счета на имя вашей организации.

## Как перейти с личного аккаунта на аккаунт организации?
1. Войдите в консоль [platform.moonshot.ai](https://platform.moonshot.ai).
2. Перейдите в **Настройки аккаунта → Верификация**.
3. Выберите **Верификация организации** и заполните необходимые сведения.
4. Отправьте заявку на проверку — после одобрения аккаунт будет преобразован автоматически.

<Callout type="tip">
Текущий баланс и данные об использовании сохраняются после перехода.
</Callout>

## Разница между личной верификацией и верификацией организации
| Параметр | Личный аккаунт | Организация |
| --- | --- | --- |
| Тип счёта | Счёт на физическое лицо | Счёт для юрлица / счёт-фактура с НДС |
| Rate Limits | Стандартные | Возможность получить повышенные quotas |
| Договоры | — | Доступно заключение договора |
| Скидки за объём | — | Доступны по запросу |
| Техническая поддержка | Стандартная | Приоритетная поддержка |

## Как обжаловать блокировку аккаунта?
Если ваш API-аккаунт был заблокирован за нарушение правил:
1. Отправьте письмо на **support@moonshot.ai** с темой «Апелляция по аккаунту API».
2. Укажите данные аккаунта (email, использованный при регистрации) и опишите причину обращения.
3. Команда рассмотрит запрос и ответит в течение 1–3 рабочих дней.

<Callout type="info">
**Email поддержки**: support@moonshot.ai
</Callout>

## Как изменить email, указанный при регистрации?
Чтобы изменить зарегистрированный email, обратитесь в поддержку:
1. Отправьте письмо на **support@moonshot.ai** с темой «Запрос на изменение email».
2. Укажите текущий и новый адреса email.
3. Для безопасности аккаунта может потребоваться подтверждение личности.

## Преимущества прохождения верификации
- **Повышенные Rate Limits**: верифицированным пользователям могут быть доступны более высокие лимиты вызовов API.
- **Полный доступ к функциям**: некоторые расширенные возможности могут быть доступны только верифицированным пользователям.
- **Поддержка счетов**: верифицированные аккаунты могут запрашивать счета.
- **Техническая поддержка**: верифицированные пользователи получают более приоритетную техническую поддержку.
