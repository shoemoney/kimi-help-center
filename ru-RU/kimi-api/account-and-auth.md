# Аккаунт и аутентификация

<Callout type="info">
Частые вопросы об аккаунтах разработчиков Kimi API, проверке и аутентификации.
</Callout>

## Может ли личный аккаунт получить счёт для компании?
Личный аккаунт **не может напрямую получить счёт для компании**. Если вам нужен счёт для юридического лица, сначала переведите аккаунт в статус аккаунта организации. После проверки вы сможете запрашивать счета на имя вашей организации.

## Как перейти с личного аккаунта на аккаунт организации?
1. Войдите в консоль [platform.kimi.ai](https://platform.kimi.ai).
2. Перейдите в раздел **Настройки аккаунта → Проверка**.
3. Выберите **Проверка организации** и заполните необходимые сведения.
4. Отправьте заявку на рассмотрение — после одобрения аккаунт будет преобразован автоматически.

<Callout type="tip">
Текущий баланс и данные об использовании сохраняются после перехода.
</Callout>

## Разница между проверкой личного аккаунта и организации
| Аспект | Личный аккаунт | Организация |
| --- | --- | --- |
| Тип счёта | Счёт для физического лица | Счёт для компании / счёт-фактура с НДС |
| Лимиты запросов | Стандартные | Возможность получить более высокие квоты |
| Договоры с компанией | — | Доступно подписание договора |
| Скидки за объём | — | Доступны по запросу |
| Техническая поддержка | Стандартная | Приоритетная поддержка |

## Как обжаловать блокировку аккаунта?
Если ваш API-аккаунт был заблокирован за нарушение правил:
1. Напишите на **support@moonshot.ai** с темой письма «Апелляция по аккаунту API».
2. Укажите данные аккаунта (зарегистрированный адрес электронной почты) и опишите суть обращения.
3. Команда рассмотрит запрос и ответит в течение 1–3 рабочих дней.

<Callout type="info">
**Адрес поддержки**: support@moonshot.ai
</Callout>

## Как изменить зарегистрированный email?
Чтобы изменить зарегистрированный email, обратитесь в поддержку:
1. Напишите на **support@moonshot.ai** с темой письма «Запрос на смену email».
2. Укажите текущий и новый адреса электронной почты.
3. Для защиты аккаунта может потребоваться подтверждение личности.

## Преимущества прохождения проверки
- **Более высокие лимиты запросов**: подтверждённые пользователи могут получить повышенные лимиты вызовов API.
- **Полный доступ к функциям**: некоторые расширенные возможности могут быть доступны только подтверждённым пользователям.
- **Поддержка счетов**: подтверждённые аккаунты могут запрашивать счета.
- **Техническая поддержка**: подтверждённые пользователи получают техническую поддержку с более высоким приоритетом.
