# Устранение неполадок API

<Callout type="info">
Частые проблемы и способы их решения для разработчиков, использующих Kimi API.
</Callout>

## Как обработать ошибку 429 rate limit?

Ошибка 429 означает, что частота ваших запросов превысила rate limit текущего аккаунта. Чтобы исправить ситуацию:

- Реализуйте стратегию повторных попыток с экспоненциальной задержкой (перед повтором ждите 1 с, 2 с, 4 с…).
- Ограничьте количество одновременных запросов с помощью механизма очереди.
- Увеличьте общую сумму пополнений, чтобы перейти на более высокий уровень rate limit.
- Обратитесь в отдел продаж, если вам нужна более высокая quota.

## Как обработать ошибку 401 Authentication Error?

Ошибка 401 означает, что проверка ключа API не прошла. Проверьте следующее:

- Убедитесь, что ключ API скопирован правильно (обратите внимание на пробелы в начале и в конце).
- Проверьте формат заголовка запроса: `Authorization: Bearer <your-api-key>`.
- Убедитесь, что ключ API не удалён и не отключён — это можно проверить в консоли.
- Убедитесь, что вы не используете ключ с другой платформы (ключи Kimi API начинаются с `sk-`).

<Callout type="warning">
**Формат ключа API**: ключи Kimi API начинаются с `sk-`. Убедитесь, что используете ключ правильного формата.
</Callout>

## Взимается ли плата за загрузку файлов?

Сама загрузка файлов бесплатна. Однако, когда вы ссылаетесь на загруженный файл в диалоге, его содержимое разбирается на tokens и тарифицируется как входные tokens. Чем больше файл, тем больше tokens он создаёт.

## Как обработать ошибку 403 Insufficient Balance?

Ошибка 403 обычно означает, что на аккаунте недостаточно средств. Пополните баланс в консоли — средства станут доступны сразу. Также можно проверить текущий баланс через API запроса баланса.

## Что делать, если ответ обрезан?

Если ответ API неполный или обрезан:

- Проверьте, не слишком ли низкое значение задано для параметра `max_tokens`, и при необходимости увеличьте его.
- Посмотрите поле `finish_reason` в ответе: `length` означает, что вывод был обрезан из-за ограничения по tokens; `stop` означает, что ответ завершился штатно.
- При генерации длинного текста попробуйте разбить запрос на части.

<Callout type="tip">
**Проверьте `finish_reason`**: `length` = обрезано, `stop` = завершено штатно.
</Callout>

## Можно ли загружать изображения через файловый API?

Да. API загрузки файлов поддерживает изображения. После загрузки на изображения можно ссылаться в диалогах. С моделями с поддержкой зрения изображения также можно передавать прямо в сообщениях — по URL или в кодировке Base64.

## Откуда берутся источники для Web Search?

Функция Web Search в Kimi API получает общедоступную информацию из интернета в реальном времени. Результаты берутся с веб-страниц, проиндексированных крупными поисковыми системами. Каждый вызов Web Search оплачивается дополнительно и стоит $0.004.

## Связаны ли подписка Kimi и API concurrency?

<Callout type="warning">
**Планы подписки Kimi** (например, Allegretto) и **API** — это разные системы тарификации. Параллельная работа агентов, входящая в планы подписки, применяется только к пользовательским продуктам Kimi и не связана с API rate limit. Ограничения API concurrency зависят от уровня совокупного пополнения вашего аккаунта.
</Callout>

## Разница между API и веб-приложением Kimi

| Аспект | Веб-приложение Kimi | Kimi API |
| --- | --- | --- |
| **Назначение** | Диалоговый продукт для пользователей | Интеграционный интерфейс для разработчиков |
| **Доступ** | Через браузер | Программные вызовы API |
| **Тарификация** | Система подписки/credit | Оплата по факту использования, по tokens |
| **Аккаунт** | Общий вход | Общий вход |
| **Credits** | Не переносятся между системами | Не переносятся между системами |

## Доступны ли генерация PPT и Deep Research через API?

<Callout type="warning">
**Генерация PPT** и **Deep Research** **пока недоступны через API**. Сейчас эти функции доступны только в пользовательском продукте Kimi. Следите за объявлениями на платформе.
</Callout>

## Поддерживается ли локальное развертывание?

В настоящее время Kimi API предоставляет только облачные API-сервисы и **не поддерживает локальное приватное развертывание**. Если вам требуется приватное развертывание, свяжитесь с отделом продаж через [platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales).

## Можно ли вызывать Kimi API из-за пределов Китая?

Kimi API доступен по всему миру через `api.moonshot.ai`. Если у вас возникают проблемы с подключением, обратитесь в отдел продаж, чтобы подобрать оптимальное решение для вашего региона.
