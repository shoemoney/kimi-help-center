# Устранение неполадок API

<Callout type="info">
Типичные проблемы и способы их решения для разработчиков, использующих Kimi API.
</Callout>

## Как устранить ошибку 429 rate limit?

Ошибка 429 означает, что частота ваших запросов превысила rate limit текущего аккаунта. Что можно сделать:

- Реализуйте стратегию повторных попыток с экспоненциальной задержкой (подождите 1 с, 2 с, 4 с… перед следующей попыткой).
- Ограничьте количество одновременных запросов с помощью механизма очереди.
- Увеличьте суммарную сумму пополнений, чтобы перейти на более высокий уровень rate limit.
- Если вам нужна более высокая кредиты, обратитесь в отдел продаж.

## Как устранить ошибку 401 Authentication Error?

Ошибка 401 означает, что аутентификация по API Key не прошла. Проверьте следующее:

- Убедитесь, что API Key скопирован правильно (обратите внимание на пробелы в начале и в конце).
- Проверьте формат заголовка запроса: `Authorization: Bearer <your-api-key>`.
- Убедитесь, что API Key не был удален или отключен — это можно проверить в консоли.
- Убедитесь, что вы не используете ключ с другой платформы (Kimi API Keys начинаются с `sk-`).

<Callout type="warning">
**Формат API Key**: Kimi API Keys начинаются с `sk-`. Убедитесь, что используете ключ правильного формата.
</Callout>

## Взимается ли плата за загрузку файлов?

Сама загрузка файла бесплатна. Однако когда вы ссылаетесь на загруженный файл в диалоге, его содержимое разбирается на tokens и тарифицируется как входные tokens. Чем больше файл, тем больше tokens он дает.

## Как устранить ошибку 403 Insufficient Balance?

Ошибка 403 обычно означает, что на аккаунте недостаточно средств. Пополните баланс в консоли — средства станут доступны сразу. Также вы можете проверить текущий баланс через API запроса баланса.

## Что делать, если ответ обрезан?

Если ответ API неполный или обрезан:

- Проверьте, не задан ли параметр `max_tokens` слишком низким значением, и при необходимости увеличьте его.
- Посмотрите поле `finish_reason` в ответе: `length` означает, что вывод был обрезан из-за лимита tokens; `stop` означает, что генерация завершилась штатно.
- При генерации длинного текста попробуйте разбить запрос на части.

<Callout type="tip">
**Проверьте `finish_reason`**: `length` = обрезано, `stop` = завершено штатно.
</Callout>

## Можно ли загружать изображения через file API?

Да. API загрузки файлов поддерживает изображения. После загрузки на изображения можно ссылаться в диалогах. В моделях с поддержкой Vision также можно передавать изображения прямо в сообщениях — по URL или в кодировке Base64.

## Источники для web search?

Функция web search в Kimi API в реальном времени получает общедоступную информацию из интернета. Результаты берутся со страниц, проиндексированных крупными поисковыми системами. Каждый вызов web search стоит дополнительно $0.004.

## Есть ли связь между подпиской Kimi и API concurrency?

<Callout type="warning">
**Планы подписки Kimi** (например, Allegretto) и **API** — это разные системы тарификации. Параллелизм агентов, включенный в планы подписки, относится только к пользовательским продуктам Kimi и не связан с API rate limits. Лимиты API concurrency определяются уровнем суммарного пополнения вашего аккаунта.
</Callout>

## Разница между API и веб-приложением Kimi

| Аспект | Веб-приложение Kimi | Kimi API |
| --- | --- | --- |
| **Назначение** | Диалоговый продукт для пользователей | Интерфейс интеграции для разработчиков |
| **Доступ** | Через браузер | Программные вызовы API |
| **Тарификация** | Система подписки/кредиты | Оплата по факту использования tokens |
| **Аккаунт** | Общий вход | Общий вход |
| **Кредиты** | Не переносятся между системами | Не переносятся между системами |

## Доступны ли генерация PPT и Deep Research через API?

<Callout type="warning">
**Генерация PPT** и **Deep Research** **пока недоступны через API**. Сейчас эти функции доступны только в пользовательском продукте Kimi. Следите за обновлениями в объявлениях платформы.
</Callout>

## Поддерживается ли локальное развертывание?

В настоящее время Kimi API предоставляет только облачные API-сервисы и **не поддерживает локальное частное развертывание**. Если вам требуется частное развертывание, свяжитесь с отделом продаж через [platform.moonshot.ai/contact-sales](https://platform.moonshot.ai/contact-sales).

## Можно ли вызывать Kimi API из-за пределов Китая?

Kimi API доступен по всему миру через `api.moonshot.ai`. Если у вас возникли проблемы с подключением, обратитесь в отдел продаж, чтобы обсудить оптимальное решение для вашего региона.
