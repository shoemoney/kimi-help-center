# Баланс и использование

Kimi API предлагает несколько способов посмотреть баланс аккаунта и сведения об использовании, чтобы вам было проще отслеживать расход и затраты.

## Панель управления консоли

Войдите на [platform.kimi.ai](https://platform.kimi.ai) и перейдите в консоли на страницу **fee-detail** (сведения о платежах), чтобы посмотреть:

- Текущий баланс аккаунта
- Расшифровку ежедневного использования
- Использование и стоимость по каждой модели
- Динамику расходов за прошлые периоды

<Callout type="info">
Ежедневные начисления обновляются **до 7:00 утра следующего дня**. Данные об использовании в реальном времени могут отображаться с небольшой задержкой.
</Callout>

> **Примечание**: ежедневные начисления обновляются **до 7:00 утра следующего дня**. Данные об использовании в реальном времени могут отображаться с небольшой задержкой.

## API Token Estimation

Перед отправкой запроса можно воспользоваться API Token Estimation, чтобы оценить, сколько токенов израсходует вызов — это удобно для контроля затрат.

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "POST https://api.moonshot.ai/v1/tokenizers/estimate-token-count",
    },
  ]}
/>

Передайте тот же формат `messages`, что и в запросе Chat Completion, и API вернет оценочное количество токенов.

## API запроса баланса

Узнайте текущий баланс аккаунта напрямую через API:

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "GET https://api.moonshot.ai/v1/users/me/balance",
    },
  ]}
/>

Добавьте свой API Key в заголовок запроса, чтобы получить доступный баланс.

## Советы по мониторингу использования

<Callout type="tip">
**Рекомендации**:
- Регулярно проверяйте страницу fee-detail, чтобы отслеживать динамику расходов
- Интегрируйте Balance Query API и настройте пороговые уведомления о балансе
- Используйте API Token Estimation перед критически важными вызовами, чтобы заранее оценить затраты
</Callout>
