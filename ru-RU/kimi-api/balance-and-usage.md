# Баланс и использование

Kimi API предлагает несколько способов посмотреть баланс аккаунта и сведения об использовании, чтобы вам было проще отслеживать расход и затраты.

## Панель консоли

Войдите на [platform.kimi.ai](https://platform.kimi.ai) и откройте в консоли страницу **fee-detail** (детализация платежей), чтобы посмотреть:

- Текущий баланс аккаунта
- Разбивку использования по дням
- Использование и затраты по каждой модели
- Динамику расходов за прошлые периоды

<Callout type="info">
Ежедневные начисления обновляются до **7:00 утра следующего дня**. Данные об использовании в реальном времени могут отображаться с небольшой задержкой.
</Callout>

> **Примечание**: ежедневные начисления обновляются до **7:00 утра следующего дня**. Данные об использовании в реальном времени могут отображаться с небольшой задержкой.

## Token Estimation API

Перед отправкой запроса можно воспользоваться Token Estimation API, чтобы оценить, сколько token израсходует вызов, — это удобно для контроля затрат.

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "POST https://api.moonshot.ai/v1/tokenizers/estimate-token-count",
    },
  ]}
/>

Передайте тот же формат `messages`, что и в запросе Chat Completion, и API вернет примерное количество token.

## API запроса баланса

Запросите текущий баланс аккаунта напрямую через API:

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "GET https://api.moonshot.ai/v1/users/me/balance",
    },
  ]}
/>

Укажите API Key в заголовке запроса, чтобы получить доступный баланс.

## Рекомендации по мониторингу использования

<Callout type="tip">
**Рекомендации**:
- Регулярно проверяйте страницу fee-detail, чтобы отслеживать динамику расходов
- Интегрируйте API запроса баланса и настройте пороговые уведомления о балансе
- Используйте Token Estimation API перед критически важными вызовами, чтобы заранее оценить затраты
</Callout>
