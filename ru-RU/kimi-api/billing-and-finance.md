# Биллинг и финансы

<Callout type="info">
Частые вопросы о биллинге, тарифах и оплате в Kimi API.
</Callout>

## Как устроено ценообразование?
Kimi API тарифицируется по количеству израсходованных token (токенов): входные и выходные token оплачиваются отдельно. Стоимость зависит от модели, а за Web Search (веб-поиск) взимается дополнительная плата — $0.004 за каждый вызов.

<Callout type="tip">
Подробные тарифы см. на странице [platform.kimi.ai/docs/pricing/chat](https://platform.kimi.ai/docs/pricing/chat).
</Callout>

## Какие способы оплаты поддерживаются?
В консоли API доступны следующие способы оплаты:
| Способ | Подробнее |
| --- | --- |
| **Credit/Debit Card (кредитная/дебетовая карта)** | Visa, Mastercard и другие основные карты |
| **Банковский перевод** | Пользователи с подтвержденной организацией могут запросить оплату банковским переводом — за реквизитами обратитесь в отдел продаж |

Пополненные средства сразу доступны для использования API.
## Как запросить счет?
1. Войдите в консоль [platform.kimi.ai](https://platform.kimi.ai).
2. Перейдите в раздел **Биллинг → Управление счетами**.
3. Выберите записи о пополнениях, по которым нужен счет.
4. Укажите данные для счета (для физического лица или компании) и отправьте запрос.
5. Электронный счет будет отправлен на вашу почту.
