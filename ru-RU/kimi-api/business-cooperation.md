# Сотрудничество и продажи

<Callout type="info">
Варианты сотрудничества для корпоративных клиентов — от скидок за объём до индивидуальных SLA.
</Callout>

Kimi API предлагает корпоративным клиентам разные форматы сотрудничества, чтобы закрывать бизнес-задачи любого масштаба.
## Как связаться с отделом продаж?
Перейдите на [platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales) и отправьте форму заявки. Наша команда продаж свяжется с вами в течение 1–2 рабочих дней.

<Callout type="tip">
**Укажите в заявке**:
- Название компании и отрасль
- Ожидаемый объём использования
- Основные сценарии применения
- Предпочтительный формат сотрудничества
</Callout>

## Подписание договора
Пользователи, прошедшие верификацию организации, могут заключить с Moonshot официальный договор на обслуживание:
- Доступны как стандартные соглашения об обслуживании, так и индивидуальные договоры.
- После подписания вы сможете оплачивать услуги банковским переводом и получите доступ к SLA корпоративного уровня.
- Свяжитесь с отделом продаж, чтобы обсудить конкретный порядок действий.

## Скидки за объём
Корпоративные клиенты с большим объёмом использования могут запросить специальные скидки:
| Требование | Подробности |
| --- | --- |
| **Право на участие** | Верификация организации + подписанный договор |
| **Уровни скидок** | Зависят от согласованного объёма использования и срока договора |
| **Подача заявки** | Подайте заявку через отдел продаж, указав ожидаемый месячный объём использования |

## Корпоративный сервис API
Корпоративный сервис API расширяет стандартные возможности API и включает:
- **Более высокие rate limit и concurrency quota**
- **Выделенный канал технической поддержки**
- **Индивидуальные гарантии SLA**
- **Ранний доступ к новым функциям**
