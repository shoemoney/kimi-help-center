# Обработка и безопасность данных

<Callout type="info">
FAQ по безопасности пользовательских данных и защите конфиденциальности для Kimi API.
</Callout>

Kimi API уделяет безопасности пользовательских данных и защите конфиденциальности первостепенное внимание.
## Используются ли пользовательские данные для обучения моделей?

<Callout type="warning">
**Нет.** Пользовательские данные, отправленные через API (включая входной контент и ответы модели), **не используются для обучения или улучшения моделей Kimi**. Ваши данные применяются только для выполнения текущего API-запроса и не сохраняются на постоянной основе в целях обучения.
</Callout>

## Как обеспечивается безопасность конфиденциальных данных?
Kimi API использует несколько мер для защиты ваших конфиденциальных данных:
| Мера | Описание |
| --- | --- |
| **Шифрование при передаче** | Все взаимодействия с API выполняются через HTTPS/TLS |
| **Изоляция данных** | Данные разных пользователей строго изолированы друг от друга |
| **Не используются для обучения** | Данные API не используются для обучения моделей |
| **Контроль доступа** | Аутентификация по ключу API только для авторизованного доступа |
| **Сертификаты соответствия** | Платформа получила соответствующие сертификаты безопасности |

<Callout type="tip">
Если у вас повышенные требования к безопасности, свяжитесь с отделом продаж, чтобы узнать о решениях корпоративного уровня.
</Callout>

## Проверка безопасности контента
Kimi API включает встроенный механизм проверки безопасности контента:
- Система автоматически обнаруживает и фильтрует запрещённый контент (незаконная деятельность, насилие, материалы откровенного характера и т. д.)
- При срабатывании проверки API возвращает соответствующий ответ с ошибкой
- Проверка контента не сохраняет и не раскрывает ваши исходные данные
- Если вы считаете, что проверка сработала ошибочно, обратитесь в поддержку и укажите `request_id`
## Как удалить загруженные файлы?
Файлы, загруженные через API для файлов, можно удалить в любой момент:

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "DELETE https://api.moonshot.ai/v1/files/{file_id}",
    },
  ]}
/>

Добавьте свой ключ API в заголовок запроса и укажите ID файла, чтобы удалить его. После удаления на файл больше нельзя будет ссылаться, а его данные будут удалены с сервера.

<Callout type="info">
Вы также можете просматривать и удалять загруженные файлы на странице управления файлами в консоли.
</Callout>
