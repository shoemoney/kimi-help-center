# Коды ошибок API

<Callout type="info">
Распространённые коды ошибок при вызове Kimi API и способы их устранения.
</Callout>

## Справочник кодов ошибок

| Код ошибки | Значение | Как исправить |
| --- | --- | --- |
| 400 | Некорректный запрос | Проверьте формат тела запроса, имена и типы параметров. Частые причины: неверно сформированный JSON, отсутствие обязательных параметров, значения вне допустимого диапазона. |
| 401 | Не авторизовано | Убедитесь, что API-ключ указан верно, не истёк и не отключён. Проверьте формат заголовка: `Authorization: Bearer <your-api-key>`. |
| 403 | Доступ запрещён (недостаточно средств) | Баланс аккаунта исчерпан — пополните его в консоли. Аккаунт также может быть ограничен; при необходимости обратитесь в поддержку. |
| 404 | Не найдено | Проверьте путь URL запроса и имя модели. Убедитесь, что endpoint имеет вид `https://api.moonshot.ai/v1/...`. |
| 429 | Too Many Requests (слишком много запросов) | Превышен rate limit. Снизьте частоту запросов, реализуйте экспоненциальную задержку повторов или обратитесь в поддержку для повышения лимитов. |
| 500 | Internal Server Error (внутренняя ошибка сервера) | Временная проблема на сервере — повторите попытку позже. Если ошибка сохраняется, напишите на support@moonshot.ai и укажите `request_id`. |

## Общие рекомендации по устранению неполадок

<Callout type="tip">
1. **Проверьте полный текст ошибки**: В ответе JSON поле `error.message` содержит подробное описание.
2. **Запишите request_id**: Он поможет поддержке быстро найти проблему.
3. **Сверьтесь с официальной документацией**: Убедитесь, что вызовы соответствуют документации на [platform.kimi.ai](https://platform.kimi.ai).
4. **Реализуйте логику повторных попыток**: Для ошибок 429 и 500 используйте экспоненциальную задержку.
</Callout>
