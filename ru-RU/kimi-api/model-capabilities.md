# Возможности моделей

Ниже приведены ответы на частые вопросы о возможностях моделей Kimi API.

## Поддерживается ли режим JSON?

Да. Kimi API предоставляет режим JSON, который ограничивает вывод модели корректным JSON. Как использовать:

- Задайте параметр `response_format` со значением `{"type": "json_object"}` в запросе.
- Также явно укажите модели в prompt, что ответ должен быть в формате JSON, и опишите ожидаемую структуру.
- В режиме JSON модель гарантированно возвращает строку JSON, пригодную для разбора.

## Поддерживается ли дообучение моделей?

Kimi API **в настоящее время не поддерживает** дообучение моделей по инициативе пользователя. Если вам нужна индивидуальная модель, свяжитесь с отделом продаж через [platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales), чтобы узнать о вариантах корпоративной кастомизации.

## Поддерживается ли OCR?

Vision-модели Kimi API умеют понимать изображения и распознавать текст на них, давая результаты, близкие к OCR:

- Поддерживается распознавание текста на английском, китайском и многих других языках.
- Можно распознавать печатный текст и часть рукописного текста.
- Каждое изображение тарифицируется по фиксированной ставке — 1,024 токена.
- Помимо распознавания обычного текста, модели также могут интерпретировать таблицы, диаграммы и другой структурированный контент на изображениях.

## Поддерживаются ли TTS (преобразование текста в речь) и ASR (распознавание речи)?

Kimi API **в настоящее время не поддерживает** TTS или ASR. Для задач, связанных с речью, можно сочетать сторонний речевой сервис с Kimi API. Следите за объявлениями платформы о будущих обновлениях функций.
