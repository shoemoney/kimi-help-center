# Выбор и сравнение моделей

<Callout type="info">
Выберите подходящую модель Kimi API с учетом возможностей, скорости и стоимости.
</Callout>

Kimi API предлагает разработчикам несколько моделей на выбор.
## Доступные модели
Полный список моделей и подробные характеристики доступны на [platform.kimi.ai/docs/models](https://platform.kimi.ai/docs/models).
При выборе модели учитывайте:
| Параметр | На что обратить внимание |
| --- | --- |
| **Длина контекста** | Для обработки длинных документов выбирайте модели с большим контекстом |
| **Скорость ответа** | Для сценариев, чувствительных к задержкам, подойдут облегченные модели |
| **Качество генерации** | Для сложных рассуждений и творческих текстов выбирайте модели более высокого уровня |
| **Стоимость** | Подбирайте экономичную модель с учетом бюджета и объема использования |

## Модели для работы с изображениями
Модели для работы с изображениями поддерживают ввод изображений для описания, OCR, интерпретации графиков и других задач:

<Callout type="info">
- Каждое изображение тарифицируется фиксированно как **1 024 токена**, независимо от размера и разрешения
- Поддерживаемые форматы: JPEG, PNG, WebP и др.
- Изображения можно передавать по URL или в кодировке Base64
</Callout>

## Возможности, которые пока не поддерживаются

<Callout type="warning">
- **Видео-мультимодальность**: прямой ввод видео пока не поддерживается
- **PPT Generation API**: пока недоступен через API
- **Deep Research API**: пока недоступен через API
</Callout>

Следите за объявлениями платформы, чтобы узнать о появлении этих возможностей.
