# Обзор Kimi API

Платформа Kimi API предоставляет разработчикам мощные возможности больших языковых моделей, помогая быстро встраивать ИИ в продукты и сервисы.

## Обзор платформы

Kimi API работает на собственных больших языковых моделях Moonshot и поддерживает генерацию текста, многоходовые диалоги, разбор файлов, веб-поиск и другие ключевые возможности. Платформа совместима с форматом OpenAI API, поэтому разработчики могут перейти на неё и интегрировать её с минимальными усилиями.

**URL платформы**: [platform.moonshot.ai](https://www.platform.moonshot.ai)

## Для кого предназначена платформа

- **Независимые разработчики**: быстро создавайте персональные проекты и инструменты на базе ИИ.
- **Инженерные команды компаний**: встраивайте возможности ИИ в корпоративные продукты, чтобы улучшать пользовательский опыт и повышать операционную эффективность.
- **Стартапы**: получайте доступ к передовым возможностям ИИ по низкой цене и ускоряйте развитие продукта.

## Основные сценарии использования

- **Интеллектуальная клиентская поддержка**: автоматические ответы на вопросы с учётом контекста, повышающие эффективность поддержки и удовлетворённость клиентов.
- **Генерация контента**: написание статей, маркетинговые тексты, генерация кода и другие творческие рабочие процессы.
- **Анализ данных**: интерпретация документов, анализ отчётов, извлечение знаний и подготовка кратких сводок.
- **Вопросы и ответы по базе знаний**: интеллектуальный поиск и системы ответов на вопросы на основе частных репозиториев документов.

## Быстрый старт

1. Перейдите на [platform.moonshot.ai](https://platform.moonshot.ai) и зарегистрируйте аккаунт разработчика.
2. Создайте API-ключ в консоли.
3. Обратитесь к документации API и выполните первый запрос.
4. Выберите модель и параметры, подходящие для вашего сценария.
