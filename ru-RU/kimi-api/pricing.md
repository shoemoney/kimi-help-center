# Цены на API

<Callout type="info">
Тарификация Kimi API основана на расходе token; цены зависят от модели и используемых функций.
</Callout>

## Основы тарификации

- **Тарификация по token**: каждый вызов API оплачивается отдельно за входные token и выходные token
- **Единица измерения token**: 1M = 1,000,000 token
- **Цены зависят от модели**: чем шире возможности модели, тем выше стоимость за token — выбирайте модель, которая лучше всего подходит для вашей задачи

## Оплата дополнительных функций

| Функция | Дополнительная плата |
| --- | --- |
| **Web Search** | $0.004 за вызов (не зависит от расхода token) |

## Кэширование контекста

<Callout type="tip">
**Кэширование контекста** позволяет кэшировать часто используемый контекст, например системные промпты и справочные документы. Token, найденные в кэше, тарифицируются со скидкой, что фактически снижает затраты при повторяющемся контексте.
</Callout>

Подробные цены на кэширование контекста см. в официальной документации.

## Как оптимизировать расходы

<Callout type="tip">
- Задавайте параметр `max_tokens` с учётом задачи, чтобы избежать излишне длинных ответов
- Используйте кэширование контекста для повторяющихся системных промптов и контекста
- Подбирайте модель под сложность задачи — для простых задач используйте более лёгкие модели
- Оптимизируйте промпты, чтобы сократить лишние входные token
</Callout>
