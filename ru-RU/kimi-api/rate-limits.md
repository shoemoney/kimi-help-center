# Ограничения rate limit

Kimi API применяет ограничения rate limit к частоте запросов и concurrency, чтобы поддерживать стабильность платформы и справедливое использование. Уровень rate limit зависит от общей суммы пополнений вашего аккаунта.

## Уровни rate limit

Ограничения rate limit в API распределяются по уровням в зависимости от **общей суммы пополнений** вашего аккаунта: чем больше вы пополнили баланс, тем выше доступные лимиты. Конкретные пороги уровней, а также соответствующие ограничения RPM (requests per minute) и TPM (tokens per minute) смотрите в консоли [platform.kimi.ai](https://platform.kimi.ai).

## Как проверить текущие лимиты?

- Войдите в консоль API, чтобы посмотреть текущий уровень rate limit.
- Заголовки ответов API также содержат информацию о rate limit:
  - `X-RateLimit-Limit`: текущий верхний предел rate limit
  - `X-RateLimit-Remaining`: оставшееся количество доступных запросов
  - `X-RateLimit-Reset`: время сброса лимита

## Обработка ошибок 429

Когда частота ваших запросов превышает лимит, API возвращает код состояния 429. Рекомендуемые действия:

1. **Реализуйте экспоненциальную задержку повторов**: сначала подождите 1 секунду, затем при каждой повторной попытке удваивайте время ожидания (2 с, 4 с, 8 с…).
2. **Контролируйте concurrency**: используйте очереди запросов или семафоры, чтобы ограничить количество одновременных запросов.
3. **Объединяйте запросы**: объединяйте несколько небольших запросов в меньшее число более крупных.

## Запрос повышенных rate limit

Если потребности вашего бизнеса превышают текущие rate limit:

- **Пополните баланс для повышения уровня**: увеличьте общую сумму пополнений, и система автоматически повысит ваш уровень rate limit.
- **Свяжитесь с отделом продаж**: если у вас есть особые требования, обратитесь к команде продаж платформы через [platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales), чтобы запросить индивидуальную quota для rate limit.
