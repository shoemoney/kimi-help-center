# Rate limits (лимиты запросов)

Kimi API применяет rate limit（ограничение частоты запросов）s к частоте запросов и concurrency (параллельности выполнения), чтобы обеспечить стабильность платформы и справедливое использование. Уровни rate limit зависят от общей суммы пополнений вашего аккаунта.

## Уровни rate limit

Rate limits для API распределяются по уровням в зависимости от **общей суммы пополнений** вашего аккаунта: чем больше вы пополнили баланс, тем выше доступные вам лимиты. Точные пороги уровней, а также соответствующие ограничения RPM (запросов в минуту) и TPM (token в минуту) смотрите в консоли [platform.moonshot.ai](https://www.platform.moonshot.ai).

## Как посмотреть текущие лимиты?

- Войдите в консоль API, чтобы увидеть текущий уровень rate limit.
- В заголовках ответов API также передается информация о rate limit:
  - `X-RateLimit-Limit`: текущий верхний предел rate limit
  - `X-RateLimit-Remaining`: оставшееся число доступных запросов
  - `X-RateLimit-Reset`: время сброса лимита

## Обработка ошибок 429

Когда частота ваших запросов превышает лимит, API возвращает код состояния 429. Рекомендуемые действия:

1. **Реализуйте экспоненциальную задержку повторных попыток**: сначала подождите 1 секунду, затем при каждой следующей попытке удваивайте время ожидания (2s, 4s, 8s…).
2. **Контролируйте concurrency**: используйте очереди запросов или семафоры, чтобы ограничить число одновременных запросов.
3. **Объединяйте запросы в пакеты**: группируйте несколько небольших запросов в меньшее число более крупных.

## Запросить более высокие rate limits

Если потребности вашего бизнеса превышают текущие rate limits:

- **Пополните баланс для повышения уровня**: увеличьте общую сумму пополнений, и система автоматически повысит ваш уровень rate limit.
- **Свяжитесь с отделом продаж**: если у вас особые требования, обратитесь в отдел продаж платформы через [platform.moonshot.ai/contact-sales](https://www.platform.moonshot.ai/contact-sales), чтобы запросить индивидуальную rate quota.
