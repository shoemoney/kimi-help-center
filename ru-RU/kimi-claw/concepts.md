# Основные понятия и терминал

## Ключевые понятия

| Понятие | Описание |
|---------|-------------|
| **Память** | Система долговременной памяти Kimi Claw. Сохраняет ваши предпочтения, привычки и важную информацию между диалогами. |
| **Навыки** | Устанавливаемые модули возможностей из библиотеки ClawHub, которые дают Kimi Claw экспертные знания в отдельных областях. |
| **HEARTBEAT** | Фоновые задачи по расписанию, запускаемые по таймеру, — удобны для регулярных напоминаний, загрузки данных и сводок. |
| **Идентичность** | Определение роли Kimi Claw: имя, профессия, образ. Полностью настраивается вами. |
| **Душа** | Ключевые черты характера и принципы поведения, которые формируют стиль взаимодействия Kimi Claw. |
| **Инструменты** | Набор возможностей, которые может вызывать Kimi Claw: поиск в интернете, работа с файлами, выполнение кода и многое другое. |
| **Пользователь** | Определение отношений между вами и Kimi Claw, задающее модели взаимодействия и обмена информацией. |

## Терминал

<Frames
  src="./images/concepts/screenshot-30.png"
  alt="скриншот 30"
/>

В веб-версии вы можете открыть интерфейс командной строки через **Настройки → Терминал** и выполнять команды для прямого управления Kimi Claw.

Либо просто скажите Kimi Claw обычным языком, какую команду выполнить, — он запустит её за вас.

> Примечание: Терминал и плагины используют один и тот же канал подключения. Перезапуск gateway OpenClaw разорвёт соединение с Терминалом.

## Справочник команд

### Система

| Команда | Описание |
|---------|-------------|
| `/help` | Показать справочную информацию |
| `/status` | Посмотреть текущее состояние системы |
| `/ping` | Проверить, активно ли соединение |
| `/cron` | Управлять задачами по расписанию |
| `/config` | Посмотреть или изменить конфигурацию |
| `/new` | Начать новый диалог (очищает текущий контекст) |
| `/reset` | Сбросить Kimi Claw |
| `/compact` | Сжать контекст текущего диалога |
| `/stop` | Остановить выполняющуюся задачу |

### Навыки

| Команда | Описание |
|---------|-------------|
| `/skills` | Просматривать, устанавливать и управлять навыками |

### Задачи по расписанию

| Команда | Описание |
|---------|-------------|
| `/cron` | Просматривать расписание задач и управлять им |

### Память

| Команда | Описание |
|---------|-------------|
| `/memory` | Просматривать долговременную память и управлять ею |

### Конфигурация и отладка

| Команда | Описание |
|---------|-------------|
| `/config` | Посмотреть или изменить конфигурацию системы |
| `/logs` | Просмотреть журналы выполнения |
| `/debug` | Включить режим отладки для подробной диагностики |
