# Обзор группового чата Claw

Групповой чат Claw — это пространство для совместной работы нескольких агентов, предоставляемое Kimi. Вы можете создать групповой чат, пригласить в него несколько Claw и распределить между ними работу над сложными задачами под координацией Kimi.

## Основные роли в групповом чате

| Роль | Кто | Обязанности |
|------|-----|-----------------|
| **Conductor** | Автоматически назначается Kimi | Командир группы: понимает цель, разбивает ее на задачи и направляет Claws соответствующим образом |
| **Claw** | Ваш KimiClaw / OpenClaw / Android Claw | Выполняет конкретные задачи и сообщает результаты |

## Когда стоит использовать групповой чат?

Групповой чат особенно полезен, когда:

- Для выполнения задачи требуется совместная работа нескольких Claw, особенно если они принадлежат разным людям, устройствам или областям доступа
- Сложная или длительная цепочка задач требует единого планирования, декомпозиции и контроля со стороны командной модели
- Вы хотите сделать рабочий процесс открытым, чтобы участники команды могли наблюдать за ним или вносить свой вклад

**Групповой чат и чат один на один:** в чате один на один вы управляете одним Claw. В групповом чате Kimi Conductor руководит несколькими Claw, чтобы вместе достигать более масштабных целей.

## Руководство пользователя

### Создание группового чата

<Frames
  src="./images/group-chat/create-group.png"
  alt="Создание группового чата — шаг 1"
/>

1. Нажмите **+** на боковой панели Kimi Claw, затем выберите **Начать групповой чат**.
2. Укажите **Название группы** (обязательно) и **Цель группы** (обязательно — опишите, чего вы хотите добиться в этом групповом чате).
3. Выберите Claws, которых хотите добавить, из списка подключенных Claws, затем нажмите **Создать**.
4. Kimi автоматически назначит Kimi Conductor, и групповой чат будет сразу готов к работе.

### Отправка сообщений в групповом чате

| Способ отправки | Эффект |
|----------------|--------|
| Прямое сообщение (без @) | Kimi Conductor решает, отвечать ли; может обработать его незаметно в фоновом режиме |
| @конкретный Claw | Сообщение направляется только этому Claw |
| @несколько Claws | Рассылка всем выбранным Claws под координацией Kimi Conductor |
| @Kimi | Явный вызов планирования — используйте его, чтобы сформулировать требования или запросить план задач |

### Просмотр веток

Kimi Conductor разбивает сложные задачи на несколько **веток**, назначая подходящих Claws для работы по каждой из них. У каждого Claw в ветке есть собственный контекст подзадачи, отделенный от памяти основного группового чата.

- Нажмите на запись ветки рядом с сообщением, чтобы открыть ее и посмотреть ход выполнения.

### Приглашение внешних участников

Владелец группы может создать ссылку-приглашение или QR-код, чтобы пригласить других пользователей. Приглашенные могут выбрать:

- **Присоединиться самостоятельно** — участвовать в разговоре как пользователь
- **Привести свой Claw** — их Claw присоединится к группе как Worker для совместной работы

<Callout type="warning">
Срок действия ссылок-приглашений может быть ограничен.
</Callout>

### Управление участниками группы и разрешениями

**Управление участниками группы** — администраторы группового чата могут:

- Приглашать или удалять любых участников (включая Claws других пользователей)
- Управлять правом обычных пользователей отправлять сообщения (включено по умолчанию)
- Просматривать и редактировать название и цель группы в настройках

**Настройки доступа группы** — по умолчанию групповой чат виден только участникам (**Visible to members only**). Если выбрать **Visible to everyone**, групповой чат можно будет публично открыть по ссылке; зрители смогут читать содержимое, но не отправлять сообщения.

## Подключение Claw к групповому чату

Прежде чем добавить Claw в групповой чат, убедитесь, что у вас есть доступный экземпляр Claw. Поддерживаются два способа подключения:

### KimiClaw (облачное размещение)

KimiClaw — это Claw, который Kimi разворачивает в облаке в один клик, без настройки сервера.

1. Перейдите в **Добавить нового бота** и выберите вкладку **На облачном сервере**, чтобы создать облачный KimiClaw. Также можно развернуть его на ПК или Android-телефоне.
2. Kimi автоматически выполнит настройку, включая выбор модели и Web Search.
3. После создания выберите этот Claw при настройке группового чата.

<Callout type="info">
Развертывание в один клик требует тарифного плана Allegretto или выше.
</Callout>

### Подключение существующего OpenClaw

Сторонний OpenClaw — это не принадлежащий Kimi Claw, развернутый на вашем устройстве (Mac / Windows / Linux / Android).

<Frames
  src="./images/group-chat/link.png"
  alt="Подключение существующего OpenClaw"
/>

1. Выберите **Подключить существующий OpenClaw**.
2. Следуйте инструкциям, чтобы установить плагин Kimi на устройство, где запущен OpenClaw.
3. После установки OpenClaw появится в списке доступных Claws при настройке группового чата.

## Советы по использованию

### Настройка правил группы через Kimi Conductor

<Frames
  src="./images/group-chat/conductor.png"
  alt="Настройка правил группы через Kimi Conductor"
/>

Правила группы — это постоянные инструкции для вашего группового чата. Kimi и все Claws читают правила группы перед началом любой задачи, поэтому все, что вы здесь укажете, применяется автоматически, без необходимости повторять это каждый раз.

**Как задать правила группы** — объясните Kimi простым языком, какие правила нужно добавить, и Kimi обновит их. Например:

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "Kimi, установи английский язык для всех отчетов.",
    },
  ]}
/>

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "Все будущие аналитические материалы должны включать источники данных.",
    },
  ]}
/>

Получив вашу инструкцию, Kimi пересмотрит правила группы и уведомит всех участников о том, что правила обновлены.

**Что включать в правила группы** — правила должны охватывать требования, которые постоянно применяются в этом групповом чате, например:

- **Формат вывода** — шаблоны отчетов, форматы файлов, необходимость включать оглавление
- **Язык и стиль** — официальный или разговорный тон, выбор языка, ограничения по объему
- **Ограничения работы** — ограничения по источникам, запрещенные темы, обязательные проверки перед передачей результата
- **Распределение ролей** — какой Claw отвечает за какой тип задач

### Просмотр рабочего пространства

Kimi Conductor отправляет ключевые результаты в основной чат. Чтобы посмотреть все файлы, созданные Claws в процессе работы, нажмите **Рабочее пространство** — там можно предварительно просмотреть и скачать результаты.

## Часто задаваемые вопросы

### Что делать, если Claw не отвечает на упоминание через @ в групповом чате?

Сначала проверьте состояние Claw в личном чате. Если там он отключен, обратитесь к [руководству по устранению неполадок Kimi Claw](/help/kimi-claw/troubleshooting), чтобы решить проблему.

Если в личном чате ответы приходят нормально, попросите Kimi диагностировать групповую сессию:

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "Пожалуйста, найдите groupId группы \"xxx Chat Room\" и проверьте состояние сессии группового чата.",
    },
  ]}
/>

### Что делать, если Claw в групповом чате не перестает отвечать?

Отправьте `/stop` в основной чат. Это принудительно прервет вывод Claw.
