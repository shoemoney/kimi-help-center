# Удаление плагина Kimi

<Callout type="warning">
**Это относится только к самостоятельно размещённым устройствам OpenClaw**, которые вы связали с Kimi. Убедитесь, что запускаете команду на своём компьютере.
</Callout>

## Команда удаления

Выполните следующую команду на устройстве, где установлен OpenClaw:

<CodePreview
  files={[
    {
      name: "command.sh",
      language: "bash",
      content: "bash \u003c(curl -fsSL https://cdn.kimi.com/kimi-claw/uninstall.sh)",
    },
  ]}
/>

## Важное предупреждение

<Callout type="warning">
**Никогда не запускайте эту команду на экземпляре Kimi Claw, развёрнутом в один клик.**
Запуск скрипта удаления в облачном экземпляре Kimi Claw **навсегда разорвёт соединение** без возможности восстановления. Эта команда предназначена исключительно для удаления плагина Kimi с самостоятельно размещённых устройств OpenClaw.
</Callout>
