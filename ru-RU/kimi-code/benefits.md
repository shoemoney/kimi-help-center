# Преимущества Kimi Code

Kimi Code — сервис, включённый в план подписки Kimi. Он предоставляет инструменты и поддержку для работы с кодом, помогая участникам эффективнее выполнять задачи программирования в личном рабочем процессе.

> Обратите внимание: это преимущество предназначено только для личной разработки и не рассчитано на корпоративные сценарии. Для корпоративных задач перейдите на [открытую платформу Kimi](https://platform.kimi.ai/).

## Оплата

- Использование Kimi Code **включено в стоимость вашей подписки** — дополнительных платежей нет.
- Каждый запрос расходует кредиты из вашего **эксклюзивного пула кредитов Kimi Code**; в разных планах предусмотрен разный объём кредитов.
- Система сначала расходует бонусные кредиты, а затем кредиты вашего плана.

## Обновление кредитов

Кредиты обновляются по **7-дневному** циклу:

- Начиная с даты оформления подписки (D1), кредиты обновляются каждые 7 дней.
- Периоды обновления: D1–D7, D8–D14, D15–D21, D22–D28.
- Неиспользованные кредиты **не** переносятся на следующий цикл.

> Планируйте недельное использование так, чтобы максимально эффективно расходовать свои кредиты.

## Поддерживаемые инструменты

Преимущества Kimi Code доступны в следующих инструментах:

| Инструмент | Описание |
| --- | --- |
| **Kimi Code CLI** | Официальный командный AI-агент Kimi |
| **Claude Code** | Командный помощник Anthropic для работы с кодом |
| **Roo Code** | Расширение для AI-программирования в VS Code |

Использование ключа API Kimi Code с платформами или инструментами, не указанными выше, может считаться нарушением правил и привести к ограничению доступа. Для наилучшего результата и полного охвата возможностей используйте перечисленные выше поддерживаемые инструменты.
