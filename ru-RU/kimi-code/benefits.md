# Преимущества Kimi Code

Kimi Code — сервис, включённый в план подписки Kimi. Он предоставляет инструменты и поддержку для работы с кодом, помогая участникам эффективнее выполнять задачи программирования в личном рабочем процессе.

> Обратите внимание: это преимущество предназначено только для личной разработки и не рассчитано на корпоративные сценарии. Для корпоративных задач перейдите на [открытую платформу Kimi](https://platform.kimi.ai/).

## Оплата

- Использование Kimi Code **включено в стоимость вашей подписки** — дополнительных платежей нет.
- Kimi Code **использует те же кредиты, что и ваш тарифный план Kimi**: запросы из CLI, VS Code и сторонних инструментов — все они списываются с них; в разных планах предусмотрен разный объём кредитов.
- Система сначала расходует бонусные кредиты, а затем кредиты вашего плана.

<Callout type="warning">
**Скоро появится новая система подписки.** Преимущества подписки Kimi и преимущества Kimi Code будут разделены, чтобы вы могли приобретать их по отдельности по мере необходимости — это гибче. **Текущих подписчиков это не затрагивает.** Если хотите и дальше пользоваться объединёнными преимуществами, приобретите текущий тариф до запуска новой системы.
</Callout>

## Обновление кредитов

Кредиты обновляются по **7-дневному** циклу:

- Начиная с даты оформления подписки (D1), кредиты обновляются каждые 7 дней.
- Периоды обновления: D1–D7, D8–D14, D15–D21, D22–D28.
- Неиспользованные кредиты **не** переносятся на следующий цикл.

> Планируйте недельное использование так, чтобы максимально эффективно расходовать свои кредиты.

## Поддерживаемые инструменты

Преимущества Kimi Code доступны в следующих инструментах:

| Инструмент | Описание |
| --- | --- |
| **Kimi Code CLI** | Официальный командный AI-агент Kimi |
| **Claude Code** | Командный помощник Anthropic для работы с кодом |
| **Roo Code** | Расширение для AI-программирования в VS Code |

Помимо перечисленных выше инструментов, подписчики также могут использовать ключ API, чтобы подключить Kimi Code к другим сторонним инструментам разработки (например, OpenCode). Подробнее см. [Использование со сторонними агентами для написания кода](/kimi-code/third-party-agents). При использовании сторонних инструментов сохраняйте подлинную идентификацию инструмента — подмена идентификатора клиента (User-Agent) будет считаться нарушением и может привести к приостановке действия ваших членских преимуществ.

## Extra Usage

Когда кредиты подписки заканчиваются, вы можете продолжать отправлять запросы за счёт баланса **Extra Usage**, не дожидаясь обновления. Активировать его могут только подписчики, и **Kimi в вебе и Kimi Code используют один и тот же баланс Extra Usage** (пополните один раз — используйте в обоих). Полные условия см. в [Соглашении об Extra Usage](https://www.kimi.com/user/agreement/extra-usage-rules-cn).

### Способы пополнения

- **С основного сайта**: откройте [страницу подписки](https://www.kimi.com/membership/subscription?tab=quota) Kimi, прокрутите до модуля «Extra Usage» внизу, выберите сумму и завершите оплату.
- **Из Kimi Code Console**: как только недельный или 5-часовой расход превысит **80 %**, на карточке прогресса появится кнопка **Купить Extra Usage**, которая ведёт на страницу подписки.

### Включение и управление

Включите переключатель «Extra Usage»; когда кредиты подписки заканчиваются, система автоматически списывает средства с баланса Extra Usage. Нажмите **Настройки** в модуле, чтобы включить **месячный лимит расходов** и задать максимальную сумму на месяц; индикатор в реальном времени показывает расход Extra Usage за месяц.

### Тарификация и правила

- **Тарификация**: по фактическому использованию — чем больше прочитано и сгенерировано контента и чем сложнее задача, тем выше стоимость. Баланс отображается в юанях (RMB), по тарифам, указанным на платформе. Цены Extra Usage близки к официальным ценам API [Kimi Open Platform](https://platform.kimi.com); при интенсивном использовании обновление подписки обычно выгоднее.
- **Порядок списания**: сначала списываются ограниченные по времени кредиты, например подписки; **Extra Usage списывается в последнюю очередь** как резерв. После включения, даже если кредиты подписки исчерпаны, Extra Usage расходуется бесшовно, и задачи не прерываются и не завершаются с ошибкой.
- **Лимит расходов**: включите «месячный лимит расходов» в настройках, чтобы ограничить сумму Extra Usage за месяц; без него лимита нет.
- **Срок действия и накопление**: баланс не сгорает и накапливается при пополнениях; он остаётся доступным после окончания подписки, но пополнить во время перерыва нельзя — сначала оформите подписку заново.
- **Возврат**: как правило, не подлежит возврату, передаче и обналичиванию.

<Callout type="info">
Пример тарификации (лишь для оценки порядка величины; фактические тарифы — по платформе): простой запрос (например, «порекомендуй рок-песню») стоит примерно **¥0,03**; сложная многошаговая задача (например, «спланируй недельное автопутешествие из Чэнду в западную Сычуань») — примерно **¥1,6**. Лимиты пополнения: минимум ¥25 за раз, до 10 раз и ¥3 000 в день, максимальный баланс — ¥10 000.
</Callout>

### Проверка расхода

- **Kimi веб / приложение**: Настройки → Подписка и счета → [Мои кредиты](https://www.kimi.com/membership/subscription?tab=quota).
- **Kimi Code Console**: после включения Extra Usage войдите в [Console](https://www.kimi.com/code/console), чтобы увидеть баланс и расход.
- **Kimi Code CLI**: введите `/usage` в командной строке для прямой проверки.

### Частые вопросы об Extra Usage

- **Kimi в вебе и Kimi Code используют один кошелёк Extra Usage?** Да — баланс общий для обоих; пополните один раз и используйте в любом.
- **Что списывается первым — Extra Usage или кредиты подписки?** Сначала ограниченные по времени кредиты, например подписки; Extra Usage списывается как резерв только после исчерпания всех ограниченных по времени кредитов.
- **Можно ли продолжать при достижении лимита или троттлинге?** Да. После включения Extra Usage лимиты подписки на вас не влияют: при достижении любого лимита происходит бесшовное переключение на баланс Extra Usage, задачи не прерываются, списывается только Extra Usage, не влияя на обновление кредитов подписки.
- **Неиспользованный баланс переносится и накапливается?** Да — не сгорает и накапливается; остаётся доступным после окончания подписки, но во время перерыва пополнение невозможно.
- **Доступен ли Extra Usage для Enterprise?** Пока не поддерживается.
