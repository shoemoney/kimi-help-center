# Взаимодействие и ввод

Kimi Code CLI предлагает несколько способов взаимодействия, чтобы вам было удобнее эффективно работать с ИИ.

## Thinking mode

Режим Thinking Mode позволяет ИИ глубже обдумывать ответ — это особенно полезно для сложных задач.

- Используйте команду `/model`, чтобы переключать модели и включать или отключать Thinking Mode.
- Thinking Mode также можно включить при запуске с помощью флага `--thinking`.

## Многострочный ввод

Нажмите **Ctrl-J**, чтобы вставить перенос строки для многострочного ввода. Это удобно для длинных запросов или вставки многострочных фрагментов кода.

## Вставка из буфера обмена

Нажмите **Ctrl-V**, чтобы вставить содержимое из буфера обмена — поддерживаются и текст, и изображения. При вставке изображений ИИ может сразу интерпретировать их содержимое, например скриншоты, макеты дизайна или снимки экрана с ошибками.

## Slash-команды

Команды, начинающиеся с `/`, используются для управления сеансами, настройками и отладкой. Часто используемые команды:

| Команда | Описание |
| --- | --- |
| `/help` | Показать справку |
| `/login` | Войти и авторизоваться |
| `/model` | Переключить модель и Thinking Mode |
| `/sessions` | Показать список сеансов и переключаться между ними |
| `/clear` | Очистить текущий контекст |
| `/compact` | Сжать контекст |
| `/init` | Создать AGENTS.md |
| `/exit` | Выйти из CLI |

Если ввести `/` в поле ввода, автоматически появится список доступных команд.

## Автодополнение путей через @

Используйте символ `@` во вводе, чтобы сослаться на путь к файлу или каталогу — система автоматически предложит варианты:

ИИ автоматически прочитает содержимое указанного файла и использует его как контекст.

## Структурированные вопросы и ответы

В некоторых сценариях ИИ предложит структурированные варианты ввода. Используйте **клавиши со стрелками**, чтобы выбрать вариант, и нажмите **Enter** для подтверждения.

## Подтверждение действий

Когда ИИ нужно изменить файлы, выполнить команды оболочки или провести другие операции, он запросит ваше подтверждение. Возможные варианты:

| Вариант | Описание |
| --- | --- |
| **Разрешить** | Разрешить эту операцию |
| **Разрешить на время сеанса** | Разрешить похожие операции до конца текущего сеанса без дополнительных запросов |
| **Отклонить** | Отклонить эту операцию |

### Режим YOLO

Если вы доверяете действиям ИИ, можно использовать режим YOLO, чтобы пропускать все подтверждения:

<CodePreview
  files={[
    {

      language: "bash",
      content: "kimi --yolo",
    },
  ]}
/>

> В режиме YOLO ИИ будет автоматически выполнять все операции — используйте его с осторожностью. Рекомендуется только в контролируемых средах разработки.
