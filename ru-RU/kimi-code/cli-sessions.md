# Сессии и контекст

Kimi Code CLI поддерживает управление несколькими сессиями и сохранение контекста, чтобы вы могли в любой момент прервать работу и продолжить с того же места.

## Возобновление сессии

Вернуться к предыдущей сессии можно несколькими способами:

### Продолжить последнюю сессию

<CodePreview
  files={[
    {
      name: "command.sh",
      language: "bash",
      content: "kimi --continue",
    },
  ]}
/>

Используйте флаг `--continue` (или `-c`), чтобы продолжить последний диалог.
### Указать ID сессии

<CodePreview
  files={[
    {
      name: "command.sh",
      language: "bash",
      content: "kimi --session \u003csession-id\u003e",
    },
  ]}
/>

Используйте флаг `--session`, чтобы восстановить определенную сессию.

### Просмотреть и переключиться

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "/sessions",
    },
  ]}
/>

Выполните `/sessions` (или `/resume`), чтобы открыть список сессий и выбрать нужную для восстановления.
## Воспроизведение при запуске

При возобновлении сессии Kimi Code CLI автоматически воспроизводит историю диалога, помогая быстро вспомнить предыдущий контекст и ход работы.

## Сохранение состояния

Следующее состояние автоматически сохраняется и восстанавливается между сессиями:

- **Решения по подтверждениям**: решения, например «Разрешить для сессии», запоминаются.
- **Динамические sub-agents**: сохраняются конфигурации sub-agent, созданные во время сессии.
- **Дополнительные каталоги**: дополнительные рабочие каталоги, добавленные с помощью команд, также сохраняются.

Это позволяет без лишних действий продолжить прежнюю работу после возобновления сессии.

## Очистка и сжатие

Kimi Code CLI при необходимости автоматически сжимает контекст, чтобы диалог мог продолжаться. Контекстом также можно управлять вручную с помощью slash-команд:

### Очистить контекст

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "/clear",
    },
  ]}
/>

Введите `/clear` (или `/reset`), чтобы очистить весь контекст в текущей сессии и начать новый диалог:

### Сжать контекст

Введите `/compact`, чтобы сжать контекст: ключевая информация сохранится, а расход token уменьшится:

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "/compact",
    },
  ]}
/>

При сжатии можно добавить инструкции, указав AI, какую информацию сохранить в первую очередь:

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "/compact Сохранить обсуждение миграций базы данных",
    },
  ]}
/>

### Состояние контекста

В строке состояния внизу CLI в реальном времени отображается текущий уровень использования контекста, что помогает следить за его расходом. Если использование близко к пределу, примените `/compact`, чтобы сжать контекст и не потерять важную информацию.
