# Контакты и обратная связь

## Каналы обратной связи

Если при работе с Kimi Code у вас возникли проблемы или появились предложения, сообщите нам одним из следующих способов.

### Вариант 1: отправить отзыв прямо в CLI

В интерактивном режиме Kimi Code CLI введите команду `/feedback`, чтобы отправить отзыв. Система автоматически соберет сведения о текущем окружении — так вам будет проще точнее описать проблему.

### Вариант 2: GitHub Issues

Откройте [Kimi CLI GitHub Issues](https://github.com/MoonshotAI/kimi-cli/issues) и проверьте поиском, не сообщал ли кто-то уже о похожей проблеме. Если нет, создайте новый Issue и подробно опишите, с чем вы столкнулись.

### Вариант 3: отправить отзыв по email

Вы также можете написать команде Kimi Code на [code@moonshot.ai](mailto:code@moonshot.ai), чтобы сообщить о проблеме. По возможности укажите следующую информацию:

- **Описание проблемы**: четко опишите возникшую проблему или функцию, которую хотели бы видеть
- **Шаги для воспроизведения**: как пошагово вызвать проблему
- **Сведения об окружении**: операционная система и версия Kimi Code CLI (проверьте командой `kimi --version`)
- **Журналы ошибок**: если есть сообщение об ошибке, вставьте его полностью

### Вариант 4: вступить в группу Feishu
Отсканируйте QR-код, чтобы вступить в группу Feishu

## Что проверить перед отправкой отзыва

Перед отправкой отзыва рекомендуем проверить следующее:

- Обновлен ли Kimi Code CLI до последней версии (проверьте командой `kimi --version`)
- Работает ли сетевое подключение и доступен ли `api.kimi.com`
- Действителен ли ваш API-ключ и не истек ли срок его действия
- Правильно ли выбран рабочий каталог и есть ли у Kimi разрешение на доступ к нужным файлам
