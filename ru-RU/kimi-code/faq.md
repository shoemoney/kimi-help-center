# Часто задаваемые вопросы

## Переход с устаревшей версии

<Callout type="info">
Kimi Code CLI получил крупное обновление версии: переход с Python/uv на Node.js. Установка стала проще, запуск — быстрее, а интерфейс терминала был переработан. Устаревшая версия будет постепенно выводиться из эксплуатации, поэтому рекомендуем обновиться как можно скорее.
</Callout>

Если вы переходите с устаревшей версии, выполните шаги ниже: одной командой можно перенести конфигурацию, MCP-серверы и историю сессий в новую версию.

### Что изменилось

- **Больше не нужны Python / uv**: Kimi Code CLI заново построен на Node.js — среда Python не требуется, установка стала проще
- **Нативный бинарный файл, готовый к работе сразу**: быстрее запускается и занимает меньше ресурсов
- **Обновленный интерфейс терминала**: более плавная и отзывчивая работа
- **Полная миграция данных**: конфигурация, MCP-серверы и история сессий переносятся без лишних действий

### Как выполнить миграцию

Есть два способа выполнить миграцию.

При **первом запуске `kimi`** после установки kimi-code автоматически проверяется, есть ли данные kimi-cli в `~/.kimi/`. Если они найдены, появится запрос на миграцию: вы сможете перенести данные сразу, сделать это позже или больше не показывать запрос.

Также миграцию можно **запустить вручную в любой момент**:

<CodePreview
  files={[
    {
      name: "command.sh",
      language: "bash",
      content: "kimi migrate",
    },
  ]}
/>

Вы можете решить, переносить ли также чат-сессии. Если история пока не нужна, выберите **Только конфигурация**; если хотите перенести всё сразу, выберите **Конфигурация + N сессий**. В конце будет выведена сводка.

### Что происходит во время миграции

**Что переносится**: конфигурация (`config.toml`), настройки MCP-серверов, история ввода и выбранные вами чат-сессии.

**Что не переносится**: учетные данные OAuth и авторизации MCP-сервисов не копируются, поэтому после миграции потребуется снова выполнить `/login` и заново авторизовать MCP-серверы. Плагины kimi-cli также не входят в область миграции.

<Callout type="tip">
Миграция **никогда не изменяет и не удаляет** старые данные в `~/.kimi/`. kimi-cli продолжает работать как раньше, и обе версии не мешают друг другу. Миграцию можно запускать повторно — уже перенесенные сессии не будут импортированы снова.
</Callout>

После миграции сессии, импортированные из kimi-cli, помечаются тегом `[imported]` в списке выбора сессий, чтобы их было легко отличить от новых.

## Установка и аутентификация

### При выполнении `/login` нет доступных моделей

Если при выполнении `/login` вы видите сообщение «No models available for the selected platform», возможные причины следующие:

- **Недействительный или просроченный ключ API**: проверьте, правильно ли введен ключ API и остается ли он действительным.
- **Проблема с сетевым подключением**: убедитесь, что у вас есть доступ к адресу API-сервиса, например `api.kimi.com` или `api.moonshot.cn`.

**Обратите внимание на различия между платформами**

Преимущества подписки Kimi Code и [Открытая платформа Kimi](https://platform.kimi.com) используют разные Base URL. При настройке убедитесь, что Base URL соответствует API Key.

| Платформа | Base URL | Оплата | Создание ключа |
|------|---------|---------|-------------|
| **Kimi Code** | совместимо с Anthropic: `https://api.kimi.com/coding/` | подписка Kimi с включёнными кредитами | [Консоль Kimi Code](https://www.kimi.com/code/console) |
| **Открытая платформа Kimi** | `https://api.moonshot.cn/v1` | оплата по факту использования | [Открытая платформа Kimi](https://platform.kimi.com) |

### Ключ API недействителен

Возможные причины недействительности ключа API:

- **Ключ введен неверно**: проверьте, нет ли лишних пробелов или пропущенных символов.
- **Срок действия ключа истек или он был отозван**: проверьте статус ключа в консоли платформы.

### Подписка истекла или кредиты исчерпаны

Если вы используете платформу Kimi Code, текущий баланс кредитов и статус подписки можно проверить командой `/usage`. Если кредиты исчерпаны или срок подписки истек, продлите или обновите ее на странице [Kimi Code](https://kimi.com/code).

## Проблемы взаимодействия

### Не удается вставить изображение

Если при вставке изображения с помощью `Ctrl-V` появляется сообщение «Current model does not support image input», значит текущая модель не поддерживает ввод изображений.

Решения:

- **Переключитесь на модель с поддержкой изображений**: используйте модель с возможностью `image_in`.
- **Проверьте содержимое буфера обмена**: убедитесь, что в буфере действительно находятся данные изображения, а не путь к файлу изображения.

## Обновления

### Первый запуск на macOS выполняется медленно

При первом запуске новой программы macOS Gatekeeper выполняет проверку безопасности, из-за чего старт может занять больше времени. Решения:

- **Дождитесь завершения проверки**: проявите терпение при первом запуске; последующие запуски будут выполняться с обычной скоростью.
- **Добавьте в Developer Tools**: добавьте приложение терминала в **System Settings → Privacy & Security → Developer Tools**.

### Как обновить Kimi Code CLI

Выполните `kimi upgrade`, чтобы проверить наличие последней версии и увидеть варианты обновления. Выберите `Install update now`, чтобы выполнить обновление. Также можно обновиться напрямую через менеджер пакетов:

<CodePreview
  files={[
    {
      name: "command.sh",
      language: "bash",
      content: "npm install -g @moonshot-ai/kimi-code@latest",
    },
  ]}

## FAQ по расширению VS Code

Ниже собраны часто задаваемые вопросы о расширении Kimi Code для VS Code.

### VS Code сообщает, что рабочая область не открыта

Откройте папку в VS Code. Для корректной работы расширению Kimi Code для VS Code требуется рабочая область.

### VS Code сообщает, что CLI не найден

Установите Kimi Code CLI вручную и настройте `kimi.executablePath` в параметрах VS Code либо убедитесь, что встроенный CLI доступен.

### Не удается войти в VS Code

Попробуйте пропустить вход и вместо него использовать режим ключа API, проверьте сетевое подключение или повторите попытку позже через меню действий расширения Kimi Code.

### VS Code отправляет сообщения, но ответа нет

Убедитесь, что Kimi Code CLI доступен, модель настроена и в VS Code открыта папка рабочей области. Журналы ошибок можно посмотреть через «Kimi Code: Show Logs».

### Истекает время ожидания подключения VS Code

Если ответа нет в течение 30 секунд, сработает тайм-аут. Проверьте сеть и повторите попытку.

### Ошибка в VS Code перед отправкой сообщения

Некоторые ошибки не позволяют отправлять сообщения в VS Code: например, Kimi Code CLI не найден, версия слишком старая, вход не выполнен или сессия занята. Ошибка будет показана во всплывающем уведомлении, а введенный текст сохранится для повторной попытки.
