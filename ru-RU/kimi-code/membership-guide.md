# Руководство по подписке Kimi Code

<Callout type="info">
Kimi Code — это преимущество подписки Kimi для разработчиков, дающее доступ к высокопроизводительным возможностям AI-программирования. Вы можете пользоваться им через Kimi Code CLI, Claude Code, Roo Code и другие поддерживаемые инструменты.
</Callout>

## Основные преимущества

| Преимущество | Описание |
|-----------|-------------|
| **Широкая совместимость** | Работает с Kimi Code CLI, Claude Code, Roo Code и другими популярными coding agents |
| **Уровни Standard / HighSpeed** | Одна и та же модель на двух скоростях: HighSpeed выдаёт примерно в 5–6 раз более высокую скорость вывода, чем Standard, и переключается по запросу |
| **Сверхбыстрые ответы** | Скорость генерации до 100 токенов/s заметно повышает эффективность написания кода |
| **Высокочастотная concurrency** | Примерно 300–1 200 запросов за 5-часовое окно (в зависимости от вашего тарифа), до 30 одновременных потоков |

## Быстрый старт

Выберите подходящий сценарий:

- **Новые пользователи**: перейдите на [kimi.com/code](https://kimi.com/code), войдите в аккаунт и оформите подписку на тариф для разработки.
- **Действующие подписчики**: откройте консоль, чтобы управлять API-ключами и начать пользоваться Kimi Code.

## Как получить API-ключ

1. Войдите в [консоль Kimi](https://kimi.com/code).
2. Перейдите на страницу **API-ключи**.
3. Нажмите **Создать новый API-ключ**.
4. Скопируйте API-ключ и сохраните его в надежном месте (он показывается только один раз — при создании).

<Callout type="warning">
Не передавайте свой API-ключ другим людям и не добавляйте его в публичные репозитории кода.
</Callout>

## Управление устройствами

- Каждый аккаунт можно использовать на нескольких устройствах.
- Авторизации устройств, которые **неактивны 30 дней**, автоматически истекают; для повторной авторизации нужно снова выполнить `/login`.
- Авторизованные устройства можно просматривать и управлять ими в консоли.

## Как переключать модели

**Модель HighSpeed теперь доступна.** Kimi Code предлагает два уровня — **Standard** и **HighSpeed** — на одной и той же модели с идентичными возможностями программирования, использующие один Base URL, API Key и преимущества подписки. HighSpeed выдаёт примерно **в 5–6 раз более высокую скорость вывода**, чем Standard, поэтому, когда нужны мгновенные ответы и быстрые итерации, переключение одним щелчком даёт более плавный процесс написания кода. Основные различия:

| Параметр | Standard | HighSpeed |
| --- | --- | --- |
| ID модели | `kimi-for-coding` | `kimi-for-coding-highspeed` |
| Скорость вывода | Базовая | ~в 5–6 раз быстрее Standard |
| Расход кредитов | Базовый | ~в 3 раза больше, чем у Standard |
| Возможности кода | Полные | Как у Standard |
| Лучше всего для | Повседневных задач кодирования | Мгновенных ответов, быстрых итераций |
| Подписка | Доступно всем участникам Kimi Code | Требуется тариф [Allegretto](https://www.kimi.com/membership/pricing) или выше |

Способы переключения на нужную модель:

- **Официальная Kimi Code CLI**: введите `/model` в сессии, чтобы переключаться напрямую между Standard и HighSpeed — без изменения конфигурации.
- **Kimi Code для VS Code**: выберите нужную модель в выпадающем меню строки ввода; если HighSpeed ещё не отображается, перезапустите VS Code или переустановите расширение.
- **Сторонние инструменты**: задайте Model ID инструмента равным нужной модели; остальные настройки не меняются. Где это найти в каждом инструменте — см. [Использование в сторонних Coding Agent](/kimi-code/third-party-agents).

<Callout type="info">
- **Стабильные ID моделей**: оба ID — стабильные идентификаторы; бэкенд обновляет сопоставленную модель по мере улучшений, без изменения конфигурации клиента.
- **Вводите точно**: ID HighSpeed должен быть `kimi-for-coding-highspeed`. При опечатке или другом значении запрос молча откатывается к стандартному `kimi-for-coding` — без ошибки, но и без ускорения.
- **401 без доступа**: без доступа к HighSpeed вызов возвращает `401`; выполните апгрейд до Allegretto или выше.
</Callout>

<Callout type="tip">
**Почему задача в целом не ощущается в 5–6 раз быстрее?** «5–6×» относится к **скорости вывода модели** (насколько быстро генерируются текст/код). Общее время задачи кодирования складывается из «вывода модели + вызовов инструментов (чтение/запись файлов, выполнение команд, веб-поиск и т. д.) + выполнения скриптов»: длительность вызовов инструментов и выполнения скриптов зависит от вашего проекта и команд, и HighSpeed эту часть не меняет. Поэтому если в целом не ощущается ускорение в 5–6 раз, обычно это потому, что большую часть хода заняли вызовы инструментов / выполнение скриптов, а не потому, что генерация модели замедлилась.
</Callout>
