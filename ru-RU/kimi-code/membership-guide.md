# Руководство по подписке Kimi Code

<Callout type="info">
Kimi Code — это преимущество подписки Kimi для разработчиков, дающее доступ к высокопроизводительным возможностям AI-программирования. Вы можете пользоваться им через Kimi Code CLI, Claude Code, Roo Code и другие поддерживаемые инструменты.
</Callout>

## Основные преимущества

| Преимущество | Описание |
|-----------|-------------|
| **Широкая совместимость** | Работает с Kimi Code CLI, Claude Code, Roo Code и другими популярными coding agents |
| **Сверхбыстрые ответы** | Скорость генерации до 100 tokens/s заметно повышает эффективность написания кода |
| **Высокочастотная concurrency** | Примерно 300–1 200 запросов за 5-часовое окно (в зависимости от вашего тарифа), до 30 одновременных потоков |

## Быстрый старт

Выберите подходящий сценарий:

- **Новые пользователи**: перейдите на [kimi.com/code](https://kimi.com/code), войдите в аккаунт и оформите подписку на тариф для разработки.
- **Действующие подписчики**: откройте консоль, чтобы управлять API-ключами и начать пользоваться Kimi Code.

## Как получить API-ключ

1. Войдите в [консоль Kimi](https://kimi.com/code).
2. Перейдите на страницу **API-ключи**.
3. Нажмите **Создать новый API-ключ**.
4. Скопируйте API-ключ и сохраните его в надежном месте (он показывается только один раз — при создании).

<Callout type="warning">
Не передавайте свой API-ключ другим людям и не добавляйте его в публичные репозитории кода.
</Callout>

## Вход в один клик

В Kimi Code CLI можно использовать команду `/login` для быстрой авторизации без ручного копирования API-ключа:

Система автоматически выполнит авторизацию устройства и привязку аккаунта — весь процесс займет всего несколько секунд.

## Управление устройствами

- Каждый аккаунт можно использовать на нескольких устройствах.
- Авторизации устройств, которые **неактивны 30 дней**, автоматически истекают; для повторной авторизации нужно снова выполнить `/login`.
- Авторизованные устройства можно просматривать и управлять ими в консоли.
