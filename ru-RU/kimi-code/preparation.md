# Подготовка к работе

Перед тем как начать пользоваться Kimi Code, стоит разобраться в нескольких базовых понятиях. Это поможет без лишних сложностей установить Kimi Code и работать с ним.

## Что такое терминал?

**Терминал** — это окно, в котором вы управляете компьютером, вводя текстовые команды.

Можно представить его как «текстовый файловый менеджер»: вместо того чтобы нажимать мышью на значки, вы вводите команды вроде `ls`, `cd` и `mkdir`, чтобы просматривать содержимое папок, переходить между каталогами, создавать файлы и выполнять другие действия.

### Как открыть терминал

| Операционная система | Как открыть |
|---------|---------|
| **macOS** | Нажмите `Cmd + Space`, введите "Terminal" или "Терминал", затем нажмите Enter |
| **Windows** | Нажмите `Win + R`, введите `powershell` или `wt`;<br>либо найдите "PowerShell"/"Terminal" в меню «Пуск» |
| **Linux** | Нажмите `Ctrl + Alt + T` или найдите "Terminal" в меню приложений |

### Как узнать свою операционную систему

- **macOS**: нажмите значок Apple в левом верхнем углу экрана → "About This Mac"
- **Windows**: нажмите `Win + Pause/Break` или щёлкните правой кнопкой мыши "This PC" → "Properties"
- **Linux**: выполните в терминале `uname -a` или `cat /etc/os-release`

## Что такое PowerShell?

<Frames
  src="./images/preparation/preparation-02.png"
  alt="Иллюстрация PowerShell"
/>

**PowerShell** — широко используемый терминальный инструмент в Windows. Он мощнее стандартной командной строки (CMD). В Windows Kimi Code CLI нужно устанавливать и использовать именно в PowerShell.

В Windows есть два разных инструмента командной строки. Не путайте их:

| Инструмент | Описание | Подходит? |
|-----|------|---------|
| **CMD (Command Prompt)** | Самый базовый инструмент командной строки в Windows | ❌ Не рекомендуется |
| **PowerShell** | Более мощный и современный инструмент командной строки | ✅ Рекомендуется |

> **Совет**: команду установки Kimi Code CLI необходимо запускать в PowerShell. В CMD она может работать некорректно.

## Рабочий каталог

При запуске Kimi Code CLI использует текущую папку как **рабочий каталог**. Читать и изменять файлы он может только внутри этого рабочего каталога.

**Перед запуском проверьте текущий путь в терминале**:

- В приглашении терминала обычно показан текущий каталог, например `~/projects/my-app$`
- Введите `pwd` (macOS/Linux) или `cd` (Windows), чтобы увидеть полный путь
- С помощью `cd <folder-name>` перейдите в каталог нужного проекта, затем выполните `kimi`

> **Пример**: допустим, ваш проект находится в `~/Documents/my-project`. Запустите его так:
> 1. Откройте терминал
> 2. Введите `cd ~/Documents/my-project`
> 3. Введите `kimi`, чтобы запустить

## Как запускать команды

<Frames
  src="./images/preparation/preparation-03.png"
  alt="Иллюстрация выполнения команды"
/>

Запускать команды в терминале или PowerShell просто:

1. **Скопируйте команду**: скопируйте текст команды из документации
   - macOS/Linux: `curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash`
   - Windows: `irm https://code.kimi.com/kimi-code/install.ps1 | iex`
2. **Вставьте её в терминал**: щёлкните правой кнопкой мыши в окне терминала или нажмите `Cmd/Ctrl + V`
3. **Нажмите Enter**: нажмите клавишу `Enter`, чтобы выполнить команду
4. **Дождитесь завершения**: терминал покажет ход выполнения и результат

> **Примечание**: в терминале `Ctrl+C` обычно **прерывает текущую команду**, а не копирует текст. Чтобы скопировать, используйте `Cmd/Ctrl + Shift + C`; чтобы вставить — `Cmd/Ctrl + Shift + V`; также можно воспользоваться меню по правому клику.

> **Совет**: если во время выполнения команды вас попросят ввести пароль, терминал не будет показывать никакие символы. Это обычный механизм безопасности. Просто введите пароль и нажмите Enter.

## Что такое CLI?

<Frames
  src="./images/preparation/preparation-04.png"
  alt="Иллюстрация терминала"
/>

**CLI** означает **C**ommand-**L**ine **I**nterface — работу с инструментом через текстовые команды вместо кнопок в графическом интерфейсе.

Kimi Code CLI — это инструмент командной строки: вы вводите `kimi` в терминале, чтобы запустить его, а затем общаетесь с AI через текстовые команды. Так он может помогать читать код, изменять файлы, запускать команды и выполнять другие задачи.

## Сетевое окружение

Для работы с Kimi Code нужен доступ к серверам Kimi. Если в вашей сети есть одно из следующих ограничений, может понадобиться изменить настройки:

- **Сеть компании или учебного заведения**: в некоторых intranet-средах может быть ограничен доступ к внешним API. Если у вас есть прокси, укажите его адрес в конфигурации.
- **VPN/прокси**: если вы используете глобальный прокси, убедитесь, что он не перехватывает и не нарушает запросы к `api.kimi.com` или `api.moonshot.cn`.
- **Firewall**: проверьте, не блокирует ли системный firewall или firewall маршрутизатора сетевой доступ из программы терминала.

## Безопасность

Kimi Code CLI — мощный AI Agent. Он может:

- **Читать** содержимое файлов на вашем компьютере
- **Изменять** ваш код и конфигурационные файлы
- **Запускать** команды Shell, например устанавливать зависимости или запускать тесты

**При работе с ним помните о следующем**:

- **Не запускайте его в каталогах с конфиденциальными данными**: не используйте Kimi Code CLI в папках, где хранятся пароли, ключи или личные приватные файлы.
- **Внимательно проверяйте действия**: перед изменением файлов или запуском команд Kimi Code попросит ваше подтверждение. Не нажимайте «Agree» по привычке.
- **Сначала разберитесь, потом продолжайте**: если вы не уверены, к чему приведёт действие, попросите Kimi Code подробно объяснить, что именно он собирается сделать, и только затем решайте, продолжать ли.
- **Делайте резервные копии важного кода**: перед использованием Kimi Code в важном проекте рекомендуем зафиксировать код в системе контроля версий, например Git, чтобы при необходимости можно было откатиться.

> **Рекомендация**: в первый раз попробуйте Kimi Code CLI на тестовом проекте или копии вашего проекта. Когда освоитесь с принципом работы, используйте его в рабочих проектах.
