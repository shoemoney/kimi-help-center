# Kimi Code для VS Code: быстрый старт

<Callout type="warning">
**Уведомление о совместимости расширения VS Code**

В настоящее время Kimi Code for VS Code доступен для новой установки только пользователям устаревшего Python CLI. Пользователи, у которых расширение уже установлено, могут продолжать работать с ним после перехода на новый CLI. Установка для пользователей TS-версии CLI сейчас не поддерживается.
</Callout>

Kimi Code for VS Code — расширение, встроенное в Visual Studio Code. После установки вы сможете задавать вопросы прямо в редакторе, просматривать diff кода и быстро фиксировать изменения. 

Расширение умеет читать содержимое файлов, на которые вы ссылаетесь, и показывать предложения по изменениям в наглядном интерфейсе, выполняя их после вашего подтверждения. Весь процесс остаётся под вашим контролем и при этом заметно ускоряет разработку.

Расширение добавляет в VS Code нативную панель чата с поддержкой:
- Ссылок на файлы и папки через символ `@`.
- Сканирования проекта и управления контекстом с помощью команд `/`.
- Diff-представлений изменений файлов с возможностью отката.
- Интеграции MCP-серверов для вызова внешних инструментов.

---

## Установка

1.  **Предварительные условия**: вам нужна подписка на аккаунт Kimi или API-ключ Kimi.
2.  **Marketplace**: установите расширение через [VS Code Marketplace](vscode:extension/moonshot-ai.kimi-code).

<Callout type="tip">
Если после установки расширение не появилось, перезапустите VS Code или выполните команду **Developer: Reload Window** в палитре команд (Mac: `Cmd+Shift+P`, Win/Linux: `Ctrl+Shift+P`).
</Callout>

---

## Аутентификация

Kimi Code поддерживает два режима аутентификации. Переключаться между ними можно в любой момент через **значок шестерёнки**.

<Frames
  src="./images/vscode/kimi-code-gear-icon.png"
  alt="Настройки аутентификации"
  width={800}
  height={450}
/>

- **Режим аккаунта Kimi**: нажмите кнопку входа, чтобы авторизоваться через браузер.
- **Режим API-ключа**: если API-ключ уже настроен, нажмите, чтобы пропустить вход.

## Типовые сценарии

Чтение кода: введите `@`, чтобы выбрать файл или папку, попросите объяснить поток выполнения кода и продолжайте задавать уточняющие вопросы.

Рефакторинг: укажите целевой код, например `@src/feature/`, запросите план рефакторинга, просмотрите diff и выборочно подтвердите изменения; при необходимости используйте откат.

Отладка: вставьте сообщения об ошибках или stack trace, укажите связанные файлы, запросите диагностику и исправления, а затем подтвердите предложенные изменения.

Обзор проекта: укажите папку, например `@src/services/`, запросите карту модулей или сводку по архитектуре и продолжайте задавать вопросы о зависимостях или слабых местах.

## Команды и сочетания клавиш

Используйте `CodePreview`, чтобы быстро проверить команды или посмотреть основные сочетания клавиш:

<CodePreview
  files={[
    {
      name: "shortcuts.txt",
      language: "text",
      content: "Ctrl+Shift+K : Перейти в поле ввода Kimi\nAlt+K : Вставить ссылку на текущий файл\nCtrl+N : Новый диалог",
    },
  ]}
/>

| Сочетание клавиш | Функция |
| :--- | :--- |
| `Ctrl+Shift+K` / `Cmd+Shift+K` | Перейти в поле ввода Kimi |
| `Alt+K` | Вставить ссылку на текущий файл |
| `Ctrl+N` / `Cmd+N` | Новый диалог |
| `↑` / `↓` | Просмотр истории ввода |

<Callout type="info">
Введите **Kimi Code** в палитре команд, чтобы открыть дополнительные команды: открытие в новой вкладке, открытие на боковой панели или управление сеансами.
</Callout>
