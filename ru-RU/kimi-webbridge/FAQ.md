# Частые вопросы

## Установка и настройка

### При установке расширения появляется сообщение «Cannot add apps from this website»?

Убедитесь, что устанавливаете расширение из официального магазина (Chrome Web Store или Edge Add-ons). Если магазин недоступен, воспользуйтесь способом ручной установки, описанным на официальном сайте.

### После запуска команды подключения ничего не происходит?

Проверьте подключение к интернету. Если проблема сохраняется, перезапустите Kimi Claw Desktop и выполните команду снова.

### Можно ли использовать это на нескольких компьютерах?

Да, но на каждом компьютере нужно отдельно выполнить установку и настройку.

### Не могу найти Kimi Claw Desktop?

Kimi Claw Desktop — это Kimi Claw, развернутый на вашем локальном компьютере. Откройте Kimi Desktop, найдите Kimi Claw на левой боковой панели, создайте новый Claw и выберите «Deploy on my computer».

## Подключение и использование

### В статусе расширения отображается «Disconnected»?

Убедитесь, что браузерное расширение Kimi WebBridge успешно установлено, затем выполните действия для вашего способа настройки:

- **Kimi Desktop**: перезапустите Kimi Desktop и попробуйте снова

- **Другие локальные агенты**: повторно отправьте следующую команду в своем агенте, а после ее выполнения перезапустите агент:

Kimi WebBridge поддерживает операционную систему Windows, а команду установки можно выполнить в среде Linux:

### После установки WebBridge показывает предупреждение о совместимости с Chrome. Что это значит?

Если WebBridge нормально открывает страницы, но такие действия, как `snapshot`, `evaluate`, `screenshot` или `click`, постоянно завершаются с ошибкой, чаще всего причина — **конфликт с другими расширениями браузера**.

Особенно часто это происходит с инструментами для скрейпинга, вспомогательными расширениями для сайтов, расширениями для записи экрана и расширениями AI-ассистентов.

Рекомендуем выполнить следующие шаги для диагностики:

1. Откройте страницу управления расширениями в браузере
2. Временно отключите другие расширения
3. Оставьте включенным только Kimi WebBridge
4. Перезапустите браузер и попробуйте снова
5. Если WebBridge работает нормально, включайте остальные расширения по одному, чтобы определить, какое из них вызывает конфликт


### Не приведет ли WebBridge к утечке моих данных для входа?

Нет. Все выполняется локально на вашем устройстве — состояния входа и содержимое веб-страниц не покидают ваш компьютер. Агент получает доступ только к тем результатам операций, которые вы разрешаете.

### Почему операции завершаются с ошибкой?

Сложная структура страницы или динамическая загрузка могут приводить к сбоям. Попробуйте упростить инструкции или попросите агента сначала сделать снимок экрана, чтобы перед выполнением подтвердить состояние страницы.

### Какие браузеры поддерживаются?

Сейчас поддерживаются Chrome и Edge. Для наилучшей работы рекомендуем использовать последнюю версию.

## Работа с другими агентами

### Какие другие агенты поддерживаются?

WebBridge поддерживает все локальные агенты, включая Claude Code, Codex, Cursor, Kimi Code, Hermers Claw и другие.

### Одинакова ли настройка для разных агентов?

Команда настройки одна и та же для всех — достаточно выполнить одну команду curl для установки. Подробности смотрите в конфигурации Skill соответствующего агента.
