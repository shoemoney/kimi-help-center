# Как работает Kimi WebBridge

## Схема работы

Kimi WebBridge работает следующим образом:

1. **Локальный мостовой сервис**: на вашем компьютере запускается локальный сервис, который принимает инструкции от агента
2. **Расширение браузера**: выполняет нужные действия в браузере на основе Chrome DevTools Protocol
3. **Безопасная изоляция**: все действия выполняются локально — состояния входа и содержимое веб-страниц никогда не покидают ваше устройство

## Интерфейс расширения

Нажмите значок WebBridge на панели инструментов браузера, чтобы проверить текущий статус подключения:

**Подключено**: WebBridge работает корректно и может взаимодействовать с агентом.

**Не подключено**: проверьте настройки или повторно выполните команду подключения.

## Возможности

| Возможность | Описание |
|---------|-------------|
| Веб-навигация | Автоматически открывает указанные URL |
| Нажатие элементов | Имитирует клики по кнопкам, ссылкам и другим элементам страницы |
| Заполнение форм | Автоматически вводит текст и выбирает варианты |
| Скриншоты страниц | Делает снимок текущей страницы или выбранной области |
| Извлечение содержимого | Считывает текст страницы, таблицы и другие структурированные данные |
| Сохранение сеанса входа | Использует уже сохраненные в браузере состояния входа |

Сценарии использования:

- Сравнение цен в интернет-магазинах: автоматически ищет товары и сравнивает цены на нескольких платформах
- Поиск информации: глубоко просматривает веб-страницы и извлекает структурированную информацию
- Заполнение форм: автоматически заполняет различные онлайн-формы
- Ввод данных: автоматически упорядочивает веб-данные и вносит их в заданном формате

Больше сценариев см. на [официальном сайте Kimi WebBridge](https://www.kimi.com/features/webbridge).
