# История изменений

На этой странице публикуются обновления версий Kimi Work, включая новые функции, изменения и исправления. Страница регулярно обновляется. Скачать последнюю версию: [kimi.com/products/kimi-work](https://www.kimi.com/products/kimi-work)

## 3.2.12 (2026-09-21)

**Новое**

- Предпросмотр и редактирование файлов Office: просматривайте и редактируйте файлы PPT / XLSX на панели предпросмотра, изменения сохраняются сразу
- Выделить и спросить: выделяйте содержимое в документе, чтобы спросить Kimi или запросить изменения на месте
- Страница архивных задач переработана: поддерживаются поиск, сортировка, фильтрация и окончательное удаление

**Изменения**

- Ограничение на размер вложений в поле ввода снято

**Исправления**

- Исправлена проблема, из-за которой установщик Windows ошибочно удалял элемент автозапуска
- Исправлены некоторые ошибки и улучшены некоторые взаимодействия и стабильность

## 3.2.9 (2026-09-14)

**Новое**

- Отправка и открытие файлов с помощью Kimi теперь поддерживается для некоторых форматов файлов:
  - Поделиться с Kimi: отправляйте файлы и контент напрямую в Kimi из меню «Поделиться» приложений, таких как WeChat
  - Открыть с помощью Kimi: нажмите правой кнопкой мыши на поддерживаемые файлы и выберите открытие с помощью Kimi
- Обновление настольного питомца: полностью обновлённый UI с быстрыми ответами прямо в облачке диалога — продолжайте общение, не открывая главного окна
- Просмотрщик PDF обновлён новой панелью указателя, включая оглавление и переход по номеру страницы
- Новый вариант режима питания «Не спать после выключения экрана»: экран может выключаться, а система продолжает работать, поэтому удалённое управление и фоновые задачи не прерываются

**Изменения**

- Загруженные файлы и файлы, связанные через «@» в поле ввода, теперь можно нажать, чтобы открыть предпросмотр в правой рабочей области
- Предпросмотр изображений теперь поддерживает действия копирования / сохранения

**Исправления**

- Исправлены несколько состояний гонки, включая восстановление редактирования очереди и разблокировку навигации после сбоев браузера
- Исправлены проблемы с цветами в тёмном режиме для функций приложения
- Исправлены некоторые ошибки и улучшены некоторые взаимодействия и стабильность

## 3.2.7 (2026-09-11)

**Новое**

- Обновление скриншотов: длинные скриншоты с прокруткой в Launcher; извлечение текста OCR в один клик в редакторе скриншотов; закрепление скриншотов на рабочем столе в виде окон поверх всех остальных

- Исправлена проблема с отсутствием функции загрузки плагинов
- Ссылки на почту и телефон теперь выдают понятное сообщение, если их невозможно открыть, вместо молчаливого сбоя
- Исправлена проблема зависания страницы запланированных задач при исчерпании кредитов
- Исправлены производительность и перетаскивание настольного питомца
- Исправлены некоторые ошибки и улучшены некоторые взаимодействия и стабильность

## 3.2.1 (2026-08-21)

**Новое**

- Добавлен глобальный Launcher: вызывайте плавающее поле ввода в виде капсулы на рабочем столе в любое время и в любом месте глобальным сочетанием клавиш
  - При вызове автоматически подхватываются файлы, выбранные в Finder / Проводнике; поддерживаются вставка изображений, добавление вложений и перетаскивание снимков экрана

  - Удерживайте сочетание клавиш для голосового ввода; после отправки поле сворачивается в мини-капсулу, и вы можете одним нажатием вернуться в основное приложение, чтобы посмотреть ответ
- Добавлена очередь сообщений: пока Agent отвечает, вы можете продолжать отправлять сообщения; новые сообщения автоматически ставятся в очередь, поддерживаются перестановка перетаскиванием, редактирование, удаление и предпросмотр деталей
- Голосовой ввод в поле ввода Work: нажмите на микрофон или удерживайте сочетание клавиш, чтобы начать диктовку, — поддерживается смешанное китайско-английское распознавание

**Изменения**

- Обновлена логика уведомлений о сообщениях: правила уведомлений можно переключить в настройках

**Исправления**

- Исправлены некоторые ошибки и улучшены некоторые взаимодействия и стабильность

## 3.2.0 (2026-08-19)

**Новое**

- Добавлен встроенный браузер Agent: вкладки браузера привязываются к диалогам и находятся в области предпросмотра, а Agent может напрямую управлять браузером — нажимать, вводить текст и многое другое; на Mac также можно импортировать cookie из локального браузера Chrome, чтобы повторно использовать существующие сессии входа (по умолчанию отключено, можно включить в настройках)
- Локализация на 16 языках: клиент теперь поддерживает 16 языков вместо только китайского и английского

**Изменения**

- Kimi WebBridge теперь является плагином: управление реальным браузером перенесено в плагин, который по умолчанию отключён и может быть включён в настройках
- Страница списка дашбордов удалена; переключение между дашбордами теперь осуществляется через верхнюю панель вкладок
- Дашборд стал типом области предпросмотра: дашборды можно открывать в области предпросмотра чата, и несколько дашбордов могут быть открыты параллельно

**Исправления**

- Улучшен потоковый рендеринг сообщений: длинные ответы теперь отображаются более плавно
- Исправлены некоторые ошибки и улучшены некоторые взаимодействия и стабильность
