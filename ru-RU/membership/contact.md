# Свяжитесь с нами

Нужна помощь? Вот как с нами связаться.

## Поддержка по оплате и подписке

**Email:** membership@moonshot.ai

Подходит для вопросов о:

- Кредиты, которые не появились после покупки
- Проблемах с оплатой или списаниями
- Повышении, понижении или отмене тарифного плана
- Запросах счетов

Пользователи с платной подпиской получают приоритетный ответ. Укажите email своего аккаунта и приложите подходящие скриншоты — так мы сможем быстрее решить проблему.

## Общая поддержка

**Email:** support@moonshot.ai

Подходит для вопросов о:

- Возможностях продукта
- Технических проблемах при работе с Kimi
- Аккаунте, не связанных с оплатой
- Предложениях по функциям и обратной связи

## Поддержка API-сервиса

**Email:** api-service@moonshot.ai.
Также можно перейти в [Kimi OpenPlatform Community](https://forum.moonshot.ai/)

Подходит для вопросов о:

- Вопросах, связанных с API
- Технических проблемах при работе с Kimi API
- Предложениях по функциям и обратной связи

## Обратная связь в продукте

Вы также можете отправить отзыв прямо из Kimi:

- **Web:** нажмите кнопку **Обратная связь** в левом нижнем углу, опишите проблему и отправьте сообщение.
- **Mobile:** перейдите в **Профиль → Помощь и обратная связь → Отправить отзыв**.

Сообщения, отправленные из продукта, автоматически включают сведения об устройстве и аккаунте — это помогает нам быстрее разобраться в проблеме.
