# Обзор подписок

Kimi предлагает пять уровней подписки — включая бесплатный тариф — которые подходят для разных задач: от повседневной продуктивности до сценариев для продвинутых пользователей. Во все тарифы входят **два пула кредитов**: Kimi Code использует отдельный пул квот, а остальные функции подписки расходуют общий пул квот.

## Как работает оплата

- **Два пула кредитов** — Kimi Code использует отдельный пул квот, а остальные функции подписки расходуют общий пул квот; списание зависит от использования token.
- **Ежемесячное обновление** — кредиты сбрасываются в начале каждого платежного цикла.
- **Порядок списания** — сначала расходуются бонусные кредиты, затем кредиты тарифного плана.
