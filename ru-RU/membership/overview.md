# Обзор тарифов членства

Kimi предлагает четыре уровня членства — они рассчитаны на разные потребности: от повседневной продуктивности до сценариев для опытных пользователей.

Все функции членства Kimi используют единый пул кредитов. Развёртывание сайтов, Deep Research, Slides, Kimi Code, Kimi Work, Kimi Claw и другие функции членства расходуют кредиты членства. В Chat модель K2.6 бесплатна для всех пользователей и не расходует кредиты.

## Сравнение тарифов

| Функция | Moderato $19/мес. | Allegretto $39/мес. | Allegro $99/мес. | Vivace $199/мес. |
| --- | --- | --- | --- | --- |
| Кредиты Agent* | 60 | 150 | 360 | 720 |
| Одновременные задачи Agent | 2 | 2 | 4 | 4 |
| Приоритет скорости Agent | 4× | 4× | 4× | 4× |
| Agent Swarm (бета) | 25 использований | 50 использований | 120 использований | 240 использований |
| Одновременные подзадачи Agent Swarm | 2 | 4 | 4 | 8 |
| Кредиты Kimi Code | 1× | 5× | 15× | 30× |
| Kimi Claw | — | ✅ | ✅ | ✅ |
| Kimi Claw Android | — | ✅ | ✅ | ✅ |
| Профессиональная база данных | 2 000 вызовов | 5 000 вызовов | 12 000 вызовов | 24 000 вызовов |

\* Приблизительные значения основаны на типичном расходе token для задач. Ежемесячные кредиты пересчитываются в эквивалентное число задач для той же функции; данные приведены только для справки.

<Callout type="tip">
Используйте весь лимит кредитов для одной и той же функции
</Callout>

## Как работает оплата

- **Пул кредитов** — Все функции членства (развёртывание сайтов, Deep Research, Slides, Kimi Code, Kimi Work, Kimi Claw, K3 и K3 Swarm) используют единый пул кредитов, расход которого рассчитывается по использованию token. Если потратить кредиты на одну функцию, это скажется и на остальных.
- **Rate limit для Kimi Code** — Для Kimi Code также действует rate limit на 5 часов / неделю. Он распространяется только на Kimi Code и не влияет на другие функции членства.
- **Ежемесячное обновление** — Кредиты сбрасываются в начале каждого платёжного цикла.
