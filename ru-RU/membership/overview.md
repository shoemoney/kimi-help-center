# Обзор подписок

Kimi предлагает пять уровней подписки — включая бесплатный тариф — которые подходят для разных задач: от повседневной продуктивности до сценариев для продвинутых пользователей. Функции Agent и другие возможности подписки Kimi используют единый общий пул кредитов; у Kimi Code собственный отдельный пул кредитов. K2.6 не расходует кредиты.

| Кредиты Agent* | 6 | 60 | 150 | 360 | 720 |
| Параллельные задачи Agent | 1 | 2 | 2 | 4 | 4 |
| Приоритет скорости Agent | — | 4× | 4× | 4× | 4× |

| Параллельные подзадачи Agent Swarm | — | 2 | 4 | 4 | 8 |
| Кредиты Kimi Code | — | 1× | 5× | 15× | 30× |
| Kimi Claw | — | — | ✅ | ✅ | ✅ |

\* Приблизительные значения, рассчитанные по типичному расходу токенов на задачу. Ежемесячные кредиты пересчитаны в эквивалентное число задач для той же функции; приведено только для справки.

## Как работает оплата

- **Пул кредитов** — функции Agent и другие возможности подписки Kimi используют один общий пул кредитов; у Kimi Code собственный отдельный пул кредитов, который тарифицируется по использованию токенов.
- **Ежемесячное обновление** — кредиты сбрасываются в начале каждого платежного цикла.
