# Сведения о тарифах

Kimi предлагает четыре уровня подписки, каждый доступен с помесячной или годовой оплатой. При оплате за год вы экономите до **$480/год**.

## Краткий обзор тарифов

| Функция | Moderato ($19/мес.) | Allegretto ($39/мес.) | Allegro ($99/мес.) | Vivace ($199/мес.) |
|---------|-------------------|---------------------|-------------------|-------------------|
| credits для Agent* | 60 | 150 | 360 | 720 |
| Одновременные задачи Agent | 2 | 2 | 4 | 4 |
| Приоритет скорости Agent | 4× | 4× | 4× | 4× |
| Agent Swarm (бета) | 25 использований | 50 использований | 120 использований | 240 использований |
| Одновременные подзадачи Agent Swarm | 2 | 4 | 4 | 8 |
| credits Kimi Code | 1× | 5× | 15× | 30× |
| Kimi Claw | — | ✅ | ✅ | ✅ |
| Kimi Claw Android | — | ✅ | ✅ | ✅ |
| Профессиональная база данных | 2 000 вызовов | 5 000 вызовов | 12 000 вызовов | 24 000 вызовов |

\* Примерные значения рассчитаны на основе типичного потребления token для задач. Месячные credits пересчитаны в эквивалентное количество задач для той же функции; приведено только для справки.

## Помесячная и годовая оплата

| Тариф | Помесячно | Годовая оплата (в месяц) | Итого за год | Экономия |
| --- | --- | --- | --- | --- |
| Moderato | $19/мес. | $15/мес. | $180/год | $48/год |
| Allegretto | $39/мес. | $31/мес. | $372/год | $96/год |
| Allegro | $99/мес. | $79/мес. | $948/год | $240/год |
| Vivace | $199/мес. | $159/мес. | $1,908/год | $480/год |

## Распределение credit

Все функции подписки Kimi используют единый пул credit, расход которого измеряется по использованию token. Для Kimi Code также действует собственный 5-часовой еженедельный rate limit: он относится только к Kimi Code и не влияет на другие функции. В Chat модель K2.6 бесплатна и не расходует credit. Более высокие уровни включают пропорционально больший пул credit и подходят для более частых и сложных рабочих процессов. Подробности см. в разделе [Правила обновления и использования credit](/membership/update-rules).
