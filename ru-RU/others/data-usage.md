# Будут ли данные моих переписок использоваться для обучения модели?

При условии обработки с использованием безопасных технологий шифрования, строгой обезличенности и невозможности повторной идентификации конкретного человека платформа может использовать вводимые пользователями данные, инструкции и сгенерированные ответы для обучения модели, чтобы улучшить её качество и пользовательский опыт.

Если вы не хотите, чтобы данные ваших переписок использовались для обучения, вы можете обратиться в службу поддержки по адресу [support@moonshot.ai](mailto:support@moonshot.ai) и оставить соответствующий запрос; после подтверждения вашей личности мы прекратим использовать ваш контент для обучения модели.
