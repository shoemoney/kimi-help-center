# Чем отличаются Kimi, Kimi Work, Kimi Code и Kimi Claw? Что выбрать?

Kimi включает готового онлайн-помощника, а также несколько продуктов для разных пользователей и сценариев. У них общие базовые возможности Kimi; главное различие — **где вы ими пользуетесь, для кого они предназначены и с какими задачами справляются лучше всего**.

## Коротко

| Продукт | Что это | Для чего подходит / сценарии | Где использовать |
|---|---|---|---|
| **Kimi** (веб-версия / App) | Онлайн-помощник с AI, объединяющий чат и агента | Повседневные вопросы и ответы, тексты, поиск, создание сайтов / PPT / документов и таблиц, Deep Research и многое другое | Веб, мобильное приложение |
| **Kimi Work** | **Локальный агент** для специалистов, работающих со знаниями (desktop) | Работа с локальными файлами на компьютере, автоматизация задач в настольных приложениях, выполнение длительных задач | Клиент для Mac / Windows |
| **Kimi Code** | Набор помощников для программирования, созданный для **разработчиков** | Написание кода и сопровождение кодовых баз | CLI, расширение для VS Code |
| **Kimi Claw** | Облачная платформа автоматизации **без развертывания** | Круглосуточная облачная автоматизация 7×24, боты с интеграцией в Feishu / WeChat и другие сервисы | Облако (сервер не нужен) |

## Что выбрать?

- **Для повседневного общения, текстов, поиска, а также если нужно попросить Kimi создать сайт, подготовить PPT и таблицы или выполнить Deep Research** → используйте **Kimi** (веб-версия / App).
- **Если нужно, чтобы Kimi читал и записывал локальные файлы на вашем компьютере, автоматизировал работу в нескольких настольных приложениях или выполнял длительные задачи** → используйте **Kimi Work** (desktop).
- **Если вы разработчик и вам главным образом нужна помощь в написании кода или сопровождении проектов** → используйте **Kimi Code**.
- **Если вам нужен постоянно работающий облачный бот, который запускается автоматически и может подключаться к Feishu / WeChat и другим платформам** → используйте **Kimi Claw**.

<Callout type="tip">
В онлайн-версии Kimi уже объединены «чат» и «агент» — переключаться между ними не нужно. В настольном приложении Kimi Work есть два режима: «Работа» (режим агента, ориентированный на готовый результат) и «Чат» (быстрые диалоги).
</Callout>

## Какую подписку выбрать?

Преимущества подписки привязаны к вашему аккаунту Kimi. Все функции подписки (чат, агент, Deep Research, Kimi Code и другие) **используют один и тот же пул credit**; при этом у Kimi Code есть собственный rate limit — 5 часов в неделю, который применяется только к Kimi Code. Подробности о тарифах и ценах см. на [странице подписки](/membership/membership-pricing).

Если вы в основном используете Kimi для **повседневной работы и отдельных задач**, подходящий тариф Kimi покроет большинство сценариев в веб-версии / App / Kimi Work. Разработчикам, которые **часто пишут код**, также стоит отдельно обратить внимание на преимущества Kimi Code.
