# Как создать личный плагин

В Kimi Work вы можете использовать встроенный навык **Plugin Builder**, чтобы превратить идею в одном предложении, внешний репозиторий плагина или любую веб-страницу в собственный плагин. Какой бы способ вы ни выбрали, плагин попадает к вам одним и тем же путем: **создание / преобразование → регистрация в личном маркетплейсе плагинов (вкладка «Личные») → установка кнопкой + → использование в диалоге**. После установки плагин сразу доступен в текущем диалоге — перезапуск не требуется.

Прежде чем начать, убедитесь, что у вас установлена последняя версия настольного приложения [Kimi Work](https://www.kimi.ai/products/kimi-work). Plugin Builder — встроенный навык и не требует дополнительной установки: введите «/» в диалоге, чтобы вызвать его, или нажмите «Пользовательский плагин» в маркетплейсе плагинов, чтобы начать создание в основном диалоге.

## Создание нового плагина одним предложением

Идеально для случая «есть идея, но нет готового кода». Достаточно описать нужную возможность; Plugin Builder автоматически позаботится о каркасе, заполнении полей, локальной проверке и регистрации — вам не придется вручную создавать ни одного файла.

1. **Опишите, что вам нужно.** Вызовите Plugin Builder в диалоге и одним предложением объясните, что должен делать плагин, — например, «сделай мне плагин, который ищет регистрационные данные компаний». Поля, которые можно вывести автоматически, — название, описание, категория — будут заполнены сами; у вас уточнят только информацию, которую нельзя вывести, например URL сервера MCP или значок.
2. **Дождитесь завершения сборки.** Plugin Builder генерирует файлы плагина локально, автоматически проходит проверку структуры и спецификации, а затем регистрирует плагин в вашем личном маркетплейсе плагинов.
3. **Установите и используйте.** Откройте **«Плагины → Личные»**, найдите только что созданный плагин и нажмите +, чтобы установить. После установки он сразу доступен в текущем диалоге, и вы можете вызывать его в любой момент через «/».

## Импорт плагинов из маркетплейса или репозитория

Отправьте Plugin Builder ссылку на репозиторий плагина, и он автоматически распознает его, преобразует формат и установит на вкладку «Личные». Импортированные плагины не мешают официальному маркетплейсу и могут быть удалены в любой момент.

1. **Поддерживаемые форматы плагинов:** Plugin Builder распознает манифесты плагинов из следующих источников и преобразует их все в нативный формат Kimi `kimi.plugin.json`:

| Формат | Примечания |
| --- | --- |
| `kimi.plugin.json` | Нативный формат Kimi: обязательные поля исправляются |
| Манифесты плагинов других агентных платформ | Например, файлы `plugin.json` в каталогах вроде `.codex-plugin/plugin.json` или `.claude-plugin/plugin.json`, а также индексные файлы маркетплейсов этих платформ |
| `server.json` | Формат официального реестра MCP: преобразуется в плагин, содержащий только сервис MCP |
| Универсальный `plugin.json` | Универсальный манифест в корневом каталоге плагина |

2. **Как импортировать:** отправьте Plugin Builder ссылку на репозиторий. Он автоматически распознает следующие типы репозиториев:

- **Репозиторий одного плагина**: весь репозиторий преобразуется в один плагин;
- **Репозиторий с несколькими плагинами (monorepo)**: каждый подкаталог преобразуется в отдельный плагин;
- **Маркетплейс / индексный репозиторий плагинов** (репозиторий с индексом plugins.json или marketplace.json): каждая запись индекса разворачивается и преобразуется пакетно;
- **Репозиторий только с навыками**: репозиторий без манифеста плагина, содержащий только файлы навыков, упаковывается как плагин типа «навык».

3. **Установка со вкладки «Личные»:** когда обработка завершится, Plugin Builder сообщит, какие плагины можно использовать. Перейдите в **«Плагины → Личные»** и нажмите «Установить» на соответствующей карточке, чтобы начать использовать плагин в диалогах.

**Управление импортированными плагинами:**

- **Обновление плагина**: если исходный репозиторий обновился или вы хотите изменить название или описание, просто скажите Plugin Builder — он повторно преобразует или изменит плагин и зарегистрирует его заново.
- **Удаление**: удалите плагин со вкладки «Личные», чтобы отключить его; после удаления запись остается на вкладке — удалите запись, если хотите убрать ее полностью.
- **Исходный каталог**: результат преобразования хранится в каталоге plugins/ вашего локального рабочего пространства. Это «исходные файлы» плагина, на которые Plugin Builder опирается при будущих обновлениях, — не удаляйте его вручную.

## Превращение веб-страницы в плагин

Идеально для случая «у сайта, которым я часто пользуюсь, нет публичного API, но я хочу, чтобы Kimi получал оттуда данные и выполнял действия за меня». Отправьте URL в Plugin Builder и опишите, что вам нужно, — например, «преврати сайт XX в плагин; я хочу искать XX». Для анализа сайта и работы плагина есть два варианта браузера:

| Способ | Когда подходит | Что нужно |
| --- | --- | --- |
| **Встроенный браузер (по умолчанию)** | Большинство сайтов; для анализа сайта и работы плагина используется встроенный браузер Kimi Work | Ничего устанавливать не нужно; если требуется вход, один раз войдите во встроенном браузере |
| **WebBridge (wb)** | Повторное использование аккаунтов, в которые вы уже вошли в Chrome | Сначала установите WebBridge и управляйте Chrome через него |

1. **Анализ сайта.** Plugin Builder открывает URL в выбранном вами браузере. Если страница требует входа, он попросит вас один раз войти в браузере — он никогда не запрашивает ваш пароль, cookie или другие учетные данные.
2. **Обратный анализ API и генерация плагина.** Он фактически выполняет основные функции на странице, перехватывает сетевые запросы, вычисляет внутренние API данных сайта, а затем генерирует плагин типа «навык» со встроенными скриптами запросов.
3. **Проверка, регистрация, установка.** Как и в предыдущих способах: после прохождения проверки плагин регистрируется на вкладке «Личные»; нажмите +, чтобы установить его и начать использовать.

С этого момента достаточно сказать «найди мне XX», и Kimi использует плагин, чтобы получить данные прямо в браузере и упорядочить результаты. Если API сайта изменятся и плагин перестанет работать, попросите Plugin Builder повторно проанализировать сайт и обновить плагин.

**Промпт одним абзацем:**

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "/plugin-builder\nПреврати Hacker News (https://news.ycombinator.com) в плагин, который умеет:\n1. Поиск постов: по ключевому слову возвращать заголовки постов, ссылки, рейтинг и количество комментариев\n2. Главная страница: получать текущие топ-30 постов с главной страницы\n3.     },
  ]}
/>

<Callout type="warning">
Способ со встроенным браузером опирается на возможность встроенного браузера Kimi Work — если появится запрос на обновление, обновите настольное приложение до последней версии. Способ с WebBridge требует, чтобы WebBridge был предварительно установлен на компьютере и в Chrome.
</Callout>
