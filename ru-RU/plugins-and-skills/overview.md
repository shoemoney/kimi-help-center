# Что такое плагины Kimi?

Плагины подключают внешние инструменты к Kimi, чтобы он мог использовать приложения и сервисы для выполнения задач. После установки плагина Kimi может напрямую вызывать соответствующую стороннюю возможность во время выполнения задачи — например, запрашивать финансовые данные, работать с офисными программами или использовать инструменты дизайна. Вы можете явно попросить использовать конкретный плагин, а Kimi также будет вызывать его автоматически, когда это уместно.

## Что такое плагин Kimi

Плагин Kimi следует [определению плагина Kimi Code](https://www.kimi.com/code/docs/kimi-code-cli/customization/plugins.html#plugin-manifest) и может включать один или несколько следующих компонентов:

| Компонент | Назначение |
| --- | --- |
| Skills | Предоставляют знания, шаги и руководство по использованию, необходимые для выполнения задач |
| MCP | Подключают внешнее ПО, сервисы, базы данных или API |
| Agents | Делегируют сложные задачи специализированным субагентам |
| Hooks | Автоматически выполняют предустановленные действия при наступлении определенных событий |
| Commands | Предоставляют понятные, переиспользуемые командные точки входа |
| System Prompt | Добавляют системные инструкции главному Agent, пока плагин включен |

Веб-версия Kimi в настоящее время поддерживает MCP и Skills в плагинах. Kimi Work и Kimi Code следуют полному определению плагина выше и поддерживают более полные комбинации компонентов плагина.

**Примеры:**

- **Notion Plugin** = Notion MCP + навык с инструкциями по использованию
- **Плагин для финансовых исследований** = несколько финансовых MCP + несколько аналитических навыков + пользовательский Agent

## Где можно использовать плагины

Плагины доступны, если переключить модель на **K3** или **K3 Swarm**, а также в сценариях **Deep Research, Websites и PPT**.

Плагины также можно использовать в **настольном приложении Kimi Work**; список встроенных плагинов настольной версии см. в [Центре плагинов Kimi Work](/kimi-work/plugin-center).

<Callout type="info">
Плагины пока не поддерживаются в Kimi Claw и в диалогах Kimi Plus.
</Callout>

## Установка плагинов

- **Точки входа**: нажмите **+** в поле ввода или введите «/»; на мобильном устройстве — **+** в поле ввода или «/».
- Найдите плагин в маркетплейсе плагинов через поиск или просмотр, откройте страницу плагина и нажмите «Установить».
- Некоторые плагины требуют **авторизации OAuth** (вы будете перенаправлены на страницу входа стороннего сервиса; после авторизации плагином можно пользоваться); некоторые плагины **предустановлены** и не требуют ручной установки.
- **Плагины только для корпоративной версии**: пользователи некорпоративных версий видят их, но кнопка «Установить» неактивна.
- Без входа в аккаунт установка и использование плагинов невозможны.

## Использование плагинов

- После установки введите «/» в поле ввода или нажмите **+** → «Плагины» и выберите нужный плагин для вызова; **можно вызывать несколько плагинов одновременно**.
- Можно также просто описать задачу (например, «проверь эту компанию через Tianyancha»), и Kimi автоматически подберет подходящий плагин.
- Когда Kimi вызывает инструменты плагина, в ответе отображается «Используется плагин xx».

## Категории и список плагинов

Маркетплейс плагинов организован по категориям ниже. Фактически видимые плагины зависят от **региона (внутренний / международный)** и **клиента**, а некоторые плагины отображаются сразу в нескольких категориях.

- **Финансы**: Financial Investment Analysis, Investment Banking & Private Equity, Corporate Finance & Accounting, Wind Financial Data, S&P Global Market Intelligence, Hundsun Gildata, Tonghuashun iFinD, SEC, Global Financial Database, World Bank Open Data, база данных IMF (International Monetary Fund), Stripe, Tianyancha
- **Продуктивность**: Notion, Baidu Netdisk
- **Разработка**: GitHub, Supabase, Neon, Cloudflare
- **Творчество**: Inspiration Pool, Image Generation, Video Generation, Audio Generation, Canva
- **Универсальные**: Vivify

## Данные и разрешения

- Когда вы выбираете плагин или явно просите его использовать, Kimi отдает приоритет инструментам, которые предоставляет этот плагин, и формирует ответ на основе возвращаемых ими результатов; после подключения плагина Kimi получает доступ к соответствующему контенту в пределах выданных вами разрешений.
- Если плагин предоставлен третьей стороной, правила обработки данных устанавливаются этой компанией самостоятельно, а данные регулируются ее условиями использования и политикой конфиденциальности — рекомендуем ознакомиться с ними перед авторизацией.
- Вы можете **удалить плагин или отозвать авторизацию в любой момент**. После удаления соответствующая авторизация OAuth отзывается; чтобы снова пользоваться плагином, потребуется повторная установка и авторизация.

## Частые вопросы

### Расходуют ли плагины кредиты подписки?
Некоторые расходуют. Когда Kimi вызывает инструменты или сервисы плагина для выполнения задачи, кредиты списываются по фактическому использованию; плагины без стоимости вызова не влекут дополнительных списаний.

### Можно ли использовать несколько плагинов одновременно?
Да. Через «/» или **+** можно вызвать сразу несколько плагинов.

### Почему я не вижу какой-то плагин?
Набор доступных плагинов зависит от региона (внутренний / международный) и клиента; кроме того, некоторые плагины доступны только пользователям личной или корпоративной версии.

### Можно ли использовать в Kimi плагины из ChatGPT, Claude или других платформ?
Да. См. [Как создать личный плагин](/plugins-and-skills/create): предоставьте Plugin Builder существующие файлы плагина или ссылку на проект с другой платформы и следуйте инструкциям, чтобы преобразовать его в плагин Kimi.
