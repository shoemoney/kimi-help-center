# Обзор функции Kimi Websites

## Что такое Kimi Websites

Kimi Websites — продукт Kimi Agent для создания full-stack-сайтов на базе Kimi K3, мультимодальной визуальной agentic AI-модели. Его ключевая возможность — визуальное программирование (Vibe Coding): вы можете сгенерировать полноценный full-stack-сайт по описанию на естественном языке, дизайн-макету или записи экрана, затем просмотреть его онлайн и опубликовать в один клик.

Сайты, созданные в Kimi Websites, могут включать:

- **Frontend**: структуру страниц HTML, макеты и стили CSS, а также логику взаимодействий JavaScript (эффекты движения, анимации и т. д.)
- **Backend**: постоянное хранение данных в базе, вход пользователей и аутентификацию
- **Инженерная часть**: автоматическое управление версиями, full-stack-предпросмотр и публичное развертывание

### Возможности продукта

| Возможность        | Описание                                                  |
|----------------|--------------------------------------------------------------|
| Создание сайта в диалоге | Опишите, что вам нужно, на естественном языке, и AI автоматически сгенерирует full-stack-сайт |
| Понимание изображений и видео | Загрузите дизайн-макет, скриншот или запись экрана, и AI автоматически разберет их и создаст страницы |
| Постоянное хранение | Автоматически создает backend-базу данных с постоянным чтением, записью и управлением данными |
| Управление базой данных | Предоставляет визуальную панель базы данных для базовых операций: просмотра, редактирования и удаления |
| Вход пользователей | Поддерживает вход через аккаунт Kimi, а также может построить систему входа по имени пользователя и паролю на базе данных |
| Управление версиями | AI автоматически создает коммиты версий (git commit) и позволяет откатываться к любой предыдущей версии |
| Full-stack-предпросмотр | Поддерживает полноценный предпросмотр frontend и backend; в некоторых сценариях требуется вручную запустить sandbox-среду |
| Многоэтапное редактирование | Поддерживает итеративные изменения в многоходовых диалогах и позволяет сравнивать разные версии |
| Визуальное редактирование | Выделяйте элементы на странице предпросмотра кругом или пометками, а затем отправляйте все предложения Kimi сразу |
| Публикация и развертывание | После ручного нажатия «Опубликовать» сайт размещается в публичном интернете; до публикации доступен только предпросмотр. Поддерживается full-stack-развертывание |
| Пользовательский URL | Настройте поддомен сайта, например `abc` в `abc.ok.kimi.link` |
| Общий доступ и контроль доступа | Получите публичную ссылку для отправки в один клик или сделайте сайт приватным, видимым только вам |
| Выбор шаблона | Предлагает несколько готовых шаблонов, чтобы вы могли быстро начать работу |
| Экспорт кода | Поддерживает загрузку полного пакета проекта (включая frontend и backend) для самостоятельного развертывания |

## Как пользоваться

### Способ 1: доступ через веб
Откройте специальную страницу Kimi Websites

<Frames
  src="./images/overview/kimi-websites-homepage.png"
  alt="Главная страница Kimi Websites"
/>

1. Откройте браузер: используйте популярный браузер, например Chrome, Safari, Edge или Firefox.
2. Перейдите по официальному адресу: специальная страница Kimi Websites: [https://www.kimi.com/zh/websites](https://www.kimi.com/zh/websites) (поддерживает интерфейсы на китайском и английском языках)
3. Войдите в аккаунт: авторизуйтесь с аккаунтом Kimi (поддерживается регистрация по номеру телефона или email)
4. Введите задачу по созданию сайта. Kimi Websites предлагает три основных способа создать сайт:
   1. **Текстовый ввод**: введите задачу в диалоговое окно и опишите нужный сайт на естественном языке;
   2. **remix изображения/сайта**: загрузите дизайн-макет или скриншот понравившегося сайта, чтобы запустить соответствующую функцию;
   3. **Создание сайта по шаблону**: быстро создайте стандартный сайт, выбрав готовый шаблон и отредактировав содержимое;
5. Начните создание: перейдите в интерфейс функции Websites, выберите шаблон или создайте сайт напрямую через диалог.

Kimi Websites активирует webapp-building SKILL — многоходового агента генерации кода, предназначенного для создания сайтов. Он самостоятельно выполняет следующий рабочий процесс:

1. Разбор требований: автоматически анализирует функциональные модули сайта, визуальный стиль и логику взаимодействий
2. Планирование задач: разбивает работу на подзадачи, такие как дизайн, разработка и подготовка ресурсов
3. Техническое решение: автоматически выбирает подходящую техническую архитектуру (например, React + Tailwind CSS)
4. Генерация ресурсов: при необходимости создает визуальные материалы, такие как изображения и иконки
5. Создание кода: пишет структуру страниц, стили и код взаимодействий
6. Многоэтапная оптимизация: самостоятельно вносит корректировки по результатам предпросмотра, пока сайт не будет готов

### Интерфейс панели предпросмотра

После генерации сайта справа открывается панель предпросмотра, а в диалоге также появляются карточки версий. Основные элементы управления:

**Верхняя панель инструментов предпросмотра** (слева направо):

| Кнопка | Функция |
|--------|----------|
| Предпросмотр / Код | Переключение между визуальным предпросмотром и представлением исходного кода/дерева файлов |
| Редактировать | Переход в режим редактирования: нажмите область, которую хотите изменить, добавьте заметки-аннотации и отправьте их Kimi |
| Опубликовать | Если сайт еще не опубликован, нажмите «Опубликовать», чтобы сделать его публичным |
| Поделиться | После публикации используйте карточку общего доступа, чтобы скопировать ссылку, настроить поддомен, открыть сайт, нажать «…» для снятия с публикации или нажать «Обновить публикацию», когда доступна новая версия |
| Полноэкранный предпросмотр | Просмотр сайта на весь экран |
| Переключить режим предпросмотра | Переключение между десктопным и мобильным видами |
| Обновить | Перезагрузить предпросмотр |
| Обратная связь | Отправить проблемы, возникшие во время использования; можно ввести текст и загрузить скриншоты |
| Закрыть | Свернуть панель предпросмотра |

**Карточки версий в диалоге**: показывают название сайта, номер версии (например, V2) и URL. Нажмите **Предпросмотр**, чтобы открыть соответствующую версию; нажмите **Восстановить**, чтобы откатиться к этой версии. Карточка **Все файлы** позволяет просмотреть или скачать полные файлы проекта. Подробное использование каждой кнопки описано в соответствующих разделах ниже.

### Развертывание кода и публикация
| Способ развертывания | Описание                                           |
|-------------------|------------------------------------------------------|
| Публикация в один клик | Нажмите кнопку «Опубликовать», чтобы развернуть сайт в публичном интернете и создать доступную онлайн-ссылку (до публикации доступен только предпросмотр) |
| Скачать и развернуть | Скачайте пакет кода и разверните его на собственном сервере |
| Пользовательский URL | Замените случайный URL по умолчанию на запоминающееся имя, например настроив `abc` в `abc.ok.kimi.link` |

> **О «Пользовательском URL»**: 3–30 символов, только строчные буквы, цифры и дефисы. Нельзя начинать или заканчивать дефисом, а также использовать только цифры. Некоторые зарезервированные слова (например, `kimi`, `www`, `login` и т. д.) недоступны. Если имя занято или недоступно, выберите другое.

> **О границах функции «Скачать и развернуть»**: **вход через аккаунт Kimi** и **облачная база данных под управлением платформы** предоставляются платформой Kimi и не переносятся вместе с экспортированным кодом. Если вы развертываете код на собственном сервере, способ входа нужно заменить на схему с именем пользователя и паролем на базе вашей собственной базы данных, а данные также перенести в вашу базу данных. Если нужен только публичный доступ, рекомендуем напрямую использовать **публикацию в один клик**: вход через аккаунт Kimi и облачные данные продолжат работать как обычно. Подробнее см. в разделе [Почему созданный мной сайт не работает?](/websites/websites-why-not-working).

#### Публикация, общий доступ и снятие с публикации
До публикации сайт можно просматривать только в диалоге. Чтобы открыть доступ другим, нажмите **Поделиться** в правом верхнем углу панели предпросмотра и откройте панель публикации:

1. **Пользовательский URL**: можно изменить имя в URL по умолчанию, например на `yourname.ok.kimi.link`;
2. Нажмите **Скопировать ссылку**, чтобы получить публичный URL, или **Открыть сайт**, чтобы посмотреть его в новой вкладке. После публикации вверху панели отображается **Опубликовано**, и любой, у кого есть ссылка, сможет открыть сайт;
3. Чтобы снять сайт с публикации, выберите **Снять с публикации** в меню **…** в правом верхнем углу панели. Сайт больше не будет доступен публично (код и данные сохраняются, и вы сможете опубликовать его снова в любое время).

### Многоэтапное редактирование

Если вас не устраивает конкретная часть, нажмите кнопку редактирования в окне предпросмотра и продолжайте дорабатывать ее.
Вы также можете отправлять Kimi инструкции на естественном языке и продолжать редактирование с Agent.
Когда результат будет готов, скачайте полный HTML/CSS/JS-код и сразу разверните его либо продолжите доводить в редакторе.

## Для кого это

- Разработчики: проектируйте прототипы продуктов и frontend-демо, значительно сокращая время на создание с нуля.
- Предприниматели: быстро создавайте официальные сайты, landing pages и страницы презентации продукта при ограниченных ресурсах.
- Продакт-менеджеры: быстро превращайте PRD или дизайн-макет в интерактивный прототип для демонстрации, не дожидаясь постановки в план разработки.
- Пользователи без технических навыков: знание программирования не требуется. Опишите идею или загрузите референсное изображение — и пройдите путь от концепции до запускаемой веб-страницы.
