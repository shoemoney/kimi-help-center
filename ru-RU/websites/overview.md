# Обзор функции Kimi Websites

## Что такое Kimi Websites

Kimi Websites — продукт Kimi Agent для создания full-stack сайтов на базе Kimi K3, мультимодальной визуальной agentic AI-модели. Его ключевая возможность — визуальное программирование (Vibe Coding): вы можете сгенерировать полноценный full-stack сайт по описанию на естественном языке, дизайн-макету или записи экрана, затем просмотреть его онлайн и опубликовать в один клик.

Сайты, созданные в Kimi Websites, могут включать:

- **Frontend**: структуру HTML-страниц, CSS-макеты и стили, а также логику взаимодействия на JavaScript (эффекты движения, анимации и т. д.)
- **Backend**: постоянное хранение данных в базе, вход пользователей и аутентификацию
- **Инженерные возможности**: автоматическое управление версиями, full-stack предпросмотр и публичную публикацию

### Возможности продукта

| Возможность        | Описание                                                  |
|----------------|--------------------------------------------------------------|
| Создание сайта в диалоге | Опишите, что вам нужно, на естественном языке — AI автоматически сгенерирует full-stack сайт |
| Понимание изображений и видео | Загрузите дизайн-макет, скриншот или запись экрана — AI автоматически разберет их и создаст страницы |
| Постоянное хранение данных | Автоматически создает backend-базу данных с постоянным чтением, записью и управлением данными |
| Управление базой данных | Предоставляет визуальную панель базы данных для базовых операций: просмотра, редактирования и удаления |
| Вход пользователей | Поддерживает вход через аккаунт Kimi, а также может создать систему входа по имени пользователя и паролю через базу данных |
| Управление версиями | AI автоматически создает коммиты версий (git commit) и поддерживает откат к любой исторической версии |
| Full-stack предпросмотр | Поддерживает полноценный предпросмотр frontend и backend; в некоторых сценариях требуется вручную запустить sandbox-среду |
| Многоитерационное редактирование | Поддерживает последовательные изменения в диалоге и позволяет сравнивать разные версии |
| Визуальное редактирование | Обведите или отметьте элементы на странице предпросмотра, а затем отправьте все предложения Kimi сразу |
| Публикация и деплой | После ручного нажатия «Publish» сайт размещается в публичном интернете; до публикации доступен только предпросмотр. Поддерживается full-stack деплой |
| Пользовательский URL | Настройте поддомен сайта, например `abc` в `abc.ok.kimi.link` |
| Поделиться и контроль доступа | Получите публичную ссылку в один клик или сделайте сайт приватным — видимым только вам |
| Выбор шаблона | Предлагает несколько готовых шаблонов для быстрого старта |
| Экспорт кода | Поддерживает скачивание полного пакета проекта (включая frontend и backend) для самостоятельного деплоя |

## Как пользоваться

### Способ 1: доступ через Web
Перейдите на отдельную страницу Kimi Websites

<Frames
  src="./images/overview/kimi-websites-homepage.png"
  alt="Главная страница Kimi Websites"
/>

1. Откройте браузер: используйте популярный браузер, например Chrome, Safari, Edge или Firefox.
2. Откройте официальный адрес доступа: отдельная страница Kimi Websites: [https://www.kimi.com/zh/websites](https://www.kimi.com/zh/websites) (поддерживаются интерфейсы на китайском и английском языках)
3. Войдите в аккаунт: авторизуйтесь с аккаунтом Kimi (поддерживается регистрация по номеру телефона или email)
4. Введите задачу по созданию сайта. Kimi Websites предлагает три основных способа создать сайт:
   1. **Текстовый ввод**: введите задачу в диалоговом окне и опишите нужный сайт на естественном языке;
   2. **remix изображения/сайта**: загрузите дизайн-макет или скриншот понравившегося сайта, чтобы запустить соответствующую функцию;
   3. **Создание сайта по шаблону**: быстро создайте типовой сайт, выбрав готовый шаблон и отредактировав контент;
5. Начните создание: войдите в интерфейс функции Websites, выберите шаблон или создайте сайт напрямую в диалоге.

Kimi Websites активирует webapp-building SKILL — многоитерационного агента генерации кода, предназначенного для создания сайтов. Он самостоятельно выполняет следующий процесс:

1. Разбор требований: автоматически анализирует функциональные модули сайта, визуальный стиль и логику взаимодействия
2. Планирование задач: разбивает работу на подзадачи, такие как дизайн, разработка и подготовка ассетов
3. Техническое решение: автоматически выбирает подходящую техническую архитектуру (например, React + Tailwind CSS)
4. Генерация ассетов: по необходимости генерирует визуальные ассеты — изображения, иконки и т. п.
5. Создание кода: пишет структуру страниц, стили и код взаимодействий
6. Многоитерационная оптимизация: самостоятельно корректирует результат по предпросмотру, пока сайт не будет готов

### Интерфейс панели предпросмотра

После генерации сайта справа открывается панель предпросмотра, а в диалоге появляются карточки версий. Основные элементы управления:

**Верхняя панель инструментов предпросмотра** (слева направо):

| Кнопка | Функция |
|--------|----------|
| Preview / Code | Переключение между визуальным предпросмотром и представлениями исходного кода/дерева файлов |
| Edit | Войти в режим редактирования; нажмите область, которую хотите изменить, добавьте заметки-аннотации и отправьте их Kimi |
| Share | Опубликовать сайт, скопировать ссылку, настроить URL или снять публикацию |
| Full-screen preview | Просмотреть сайт на весь экран |
| Switch preview mode | Переключаться между desktop- и mobile-представлениями |
| Refresh | Перезагрузить предпросмотр |
| User feedback | Отправить сведения о проблемах, возникших при использовании; можно ввести текст и загрузить скриншоты |
| Close | Свернуть панель предпросмотра |

**Карточки версий в диалоге**: показывают название сайта, номер версии (например, V2) и URL. Нажмите **Preview**, чтобы открыть соответствующую версию; нажмите **Restore**, чтобы откатиться к ней. Карточка **All Files** позволяет просмотреть или скачать полные файлы проекта. Подробное использование каждой кнопки описано в соответствующих разделах ниже.

### Деплой кода и публикация
| Способ деплоя | Описание                                           |
|-------------------|------------------------------------------------------|
| Публикация в один клик | Нажмите кнопку «Publish», чтобы разместить сайт в публичном интернете и сгенерировать доступную онлайн-ссылку (до публикации доступен только предпросмотр) |
| Скачать и развернуть | Скачайте пакет кода и разверните его на собственном сервере |
| Пользовательский URL | Замените случайный URL по умолчанию на запоминающееся имя, например настроив `abc` в `abc.ok.kimi.link` |

> **О "Custom URL"**: 3–30 символов, только строчные буквы, цифры и дефисы. Нельзя начинать или заканчивать дефисом, а также использовать имя, состоящее только из цифр. Некоторые зарезервированные слова (например, `kimi`, `www`, `login` и т. д.) недоступны. Если имя занято или недоступно, выберите другое.

> **О границах "Download and deploy"**: **вход через аккаунт Kimi** и **облачная база данных под управлением платформы** предоставляются платформой Kimi и не переносятся вместе с экспортированным кодом. Если вы разворачиваете код на собственном сервере, способ входа нужно заменить на схему с именем пользователя и паролем на базе вашей собственной базы данных, а данные также перенести в вашу базу. Если нужен только публичный доступ, рекомендуем сразу использовать **One-click publish**: вход через аккаунт Kimi и облачные данные продолжат работать штатно. Подробнее см. [Почему созданный мной сайт не работает?](/websites/websites-why-not-working).

#### Публикация, отправка ссылки и снятие публикации
До публикации сайт можно просматривать только в диалоге. Чтобы открыть доступ другим, нажмите **Share** в правом верхнем углу панели предпросмотра и откройте панель публикации:

1. **Custom URL**: можно изменить имя в URL по умолчанию, например на `yourname.ok.kimi.link`;
2. Нажмите **Copy Link**, чтобы получить публичный URL, или **Open Website**, чтобы открыть сайт в новой вкладке. После публикации вверху панели появится **Published**, и любой обладатель ссылки сможет открыть сайт;
3. Чтобы отключить сайт, выберите **Unpublish** в меню **…** в правом верхнем углу панели. Сайт больше не будет публично доступен (код и данные сохранятся, и вы сможете опубликовать его снова в любой момент).

### Многоитерационное редактирование

Если вас не устраивает конкретная часть, нажмите кнопку редактирования в окне предпросмотра и продолжайте дорабатывать ее.
Вы также можете отправлять Kimi инструкции на естественном языке и продолжать редактирование с Agent.
Когда результат подтвержден, скачайте полный код HTML/CSS/JS и разверните его напрямую либо продолжите шлифовку в редакторе.

## Для кого это

- Разработчики: проектируйте прототипы продуктов и frontend-демо, значительно сокращая время создания с нуля.
- Предприниматели: быстро создавайте официальные сайты, лендинги и страницы презентации продукта при ограниченных ресурсах.
- Product-менеджеры: быстро превращайте PRD или дизайн-макет в интерактивный прототип, который можно показать, не дожидаясь слота в разработке.
- Пользователи без технической подготовки: знания программирования не нужны. Опишите идею или загрузите референсное изображение — и перейдите от концепции к запускаемой веб-странице.
