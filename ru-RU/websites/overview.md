# Kimi Websites

<Callout type="info">
**Kimi Websites** — продуктовая функция Kimi Agent на базе новейшей мультимодальной визуальной агентной ИИ-модели Kimi K2.6. Ее ключевая возможность — **вайб-кодинг**: генерация сайтов на основе естественного языка и их публикация в интернете.
</Callout>

Понимая визуальные материалы (UI-макеты, скриншоты, видео взаимодействий) и инструкции на естественном языке, Kimi превращает запрос пользователя в полноценный исполняемый frontend-код — не только со статическим UI, но и с динамическим интерактивным поведением.

## Обзор функций

| Функция | Описание |
|---------|------------|
| **Создание сайта в диалоге** | Опишите, что вам нужно, на естественном языке — ИИ автоматически сгенерирует сайт |
| **Понимание изображений и видео** | Загружайте дизайн-макеты, скриншоты или записи экрана — ИИ распознает их и создаст HTML-страницы |
| **Автопубликация** | Публикация в один клик для мгновенного выхода в интернет |
| **Многошаговое редактирование** | Итеративная доработка сайта с сравнением версий |
| **Общий доступ в один клик** | Создание доступных ссылок для удобного обмена |
| **Выбор шаблона** | Несколько готовых шаблонов для быстрого старта |
| **Экспорт кода** | Скачивание упакованных HTML/CSS/JS-файлов для самостоятельного хостинга |

## Как пользоваться Kimi Websites?

### Способ 1: открыть страницу Kimi Websites

<Frames
  src="./images/overview/kimi-websites-homepage.png"
  alt="Главная страница Kimi Websites"
/>

1. **Откройте браузер**: используйте Chrome, Safari, Edge, Firefox или любой другой популярный браузер
2. **Перейдите на**: [kimi.com/websites](https://www.kimi.com/zh/websites) (поддерживаются китайский и английский языки)
3. **Войдите в аккаунт**: используйте свой аккаунт Kimi (номер телефона или электронную почту)
4. **Введите задачу**:

| Подход | Описание |
|----------|-------------|
| **Текстовый запрос** | Опишите задачу на естественном языке |
| **Клонирование изображения или сайта** | Загрузите дизайн-макет или скриншот |
| **На основе шаблона** | Выберите готовый шаблон и измените содержимое |

5. **Начните создание**: выберите шаблон или начните с диалога

<Frames
  src="./images/overview/screenshot-27.png"
  alt="скриншот 27"
/>

### Способ 2: мобильное приложение

Для iOS, Android и HarmonyOS есть официальное приложение Kimi. В области ввода нажмите **панель задач** → переключитесь в **режим Websites Agent**: в нем доступны инструменты мультимодальной генерации и агентные возможности.

### Способ 3: использовать режим K2.6 Agent

Переключитесь в режим K2.6 Agent и введите задачу на создание сайта. Kimi задействует свои возможности визуального кодинга и инструменты выполнения кода.

## Как работает Kimi Websites?

### Шаг 1: создайте сайт через диалог

Опишите, что вам нужно, на естественном языке. Поддерживаются три способа создания:

| Способ | Описание |
|--------|------------|
| **Текстовое описание** | Введите требования к сайту напрямую — ИИ сгенерирует его автоматически |
| **Разбор дизайн-макета** | Загрузите файл с дизайном — ИИ распознает его и воссоздаст как веб-страницу |
| **Быстрая сборка по шаблону** | Выберите готовый шаблон и измените содержимое |

### Шаг 2: процесс создания

<Frames
  src="./images/overview/screenshot-26.png"
  alt="скриншот 26"
/>

Kimi Websites активирует **SKILL для создания webapp** — специализированный многошаговый агент генерации кода:
1. **Анализ требований**: анализирует модули сайта, визуальный стиль и логику взаимодействий
2. **Планирование задач**: разбивает работу на подзадачи по дизайну, разработке и подготовке ресурсов
3. **Выбор технологического стека**: подбирает подходящую архитектуру (например, React + Tailwind CSS)
4. **Генерация ресурсов**: создает изображения, иконки и другие визуальные материалы
5. **Построение кода**: пишет структуру страниц, стили и код взаимодействий
6. **Многошаговая оптимизация**: самостоятельно корректирует результат по итогам предпросмотра до завершения работы

### Шаг 3: предпросмотр и правки
- **Предпросмотр в реальном времени**: создает URL HTML-демо для мгновенного просмотра в браузере
- **Редактирование через диалог**: продолжайте разговор и просите внести изменения, например: *"Сделай навигационную панель темной"*

<Callout type="tip">
**Пример**: *"Цвета выглядят не очень — хочу убрать требование черно-белой гаммы и сделать сайт более обычным."*
Kimi перестроит список задач и продолжит создание.
</Callout>

### Шаг 4: визуальное онлайн-редактирование
- **Многошаговая оптимизация**: уточняйте детали в продолжающемся диалоге
- **Режимы редактирования**:
  - **Режим аннотаций**: нажимайте на области и добавляйте комментарии на естественном языке
  - **Режим выбора**: выбирайте любой элемент и добавляйте комментарии
  - Используйте прямоугольники, стрелки, кисти и переключение цветов, чтобы отмечать предложения по правкам
- Отправьте все предложения по правкам Kimi одним сообщением
### Шаг 5: развертывание и публикация
| Способ развертывания | Описание |
|-------------------|------------|
| **Автопубликация** | Развертывание в один клик с созданием онлайн-ссылки |
| **Скачать и разместить самостоятельно** | Скачайте упакованные файлы кода и разверните их на своем сервере |
| **Собственный домен** | Привяжите сгенерированный сайт к собственному домену |

После генерации вы можете:
- Нажимать на разные версии развертывания, чтобы скачивать файлы версий
- Нажать кнопку «Поделиться», чтобы получить публичную ссылку на развернутый сайт (или сделать его приватным)
- Нажать кнопку редактирования, чтобы продолжить доработку
- Скачать полный HTML/CSS/JS-код для прямого развертывания или дальнейшей доработки

## Примеры сценариев
| Сценарий | Пример запроса |
|----------|---------------|
| **Лендинг с нуля** | Создай маркетинговый лендинг для SaaS с технологичной эстетикой — добавь hero-блок, обзор функций, цены и CTA |
| **Воссоздание сайта по видео** | [Загрузить запись экрана] Воссоздай сайт, показанный в этом видео, сохранив исходные эффекты взаимодействия |

| **Личное портфолио** | Создай сайт-портфолио фотографа — минималистичный черно-белый стиль с masonry-раскладкой изображений |
| **Страница визуализации данных** | Создай страницу визуализации с данными о финансировании ИИ-компаний в 2025 году, с графиками и фильтрами |
| **Сайт бренда** | Создай сайт кофейного бренда в приглушенных земляных тонах — добавь главную страницу, товары и страницы поиска магазинов |
| **Утилита / калькулятор** | Создай веб-страницу калькулятора BMI — чистый интерфейс, поддержка переключения единиц измерения и индикаторы уровня здоровья |
