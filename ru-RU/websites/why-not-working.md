# Full-stack-возможности Kimi Websites

## Обновление: создание сайтов полного цикла

Полноценный сайт обычно состоит из трех частей: **пользовательского интерфейса, серверной логики и хранилища данных**. Kimi Websites получил full-stack-возможности для создания сайтов: теперь он поддерживает сквозную генерацию и развертывание — от страниц интерфейса до серверных баз данных.

| Возможность         | Описание                                                           |
|--------------|----------------------------------------------------------------|
| Генерация интерфейса     | Структура страниц HTML/CSS/JavaScript, стили и логика взаимодействия                    |
| Серверная база данных   | Автоматически создает серверную базу данных, поддерживает постоянное чтение и запись данных, а также визуальное управление               |
| Вход пользователя     | Поддерживает вход через аккаунт Kimi, а также может создать систему входа по аккаунту и паролю через базу данных           |
| Управление версиями     | ИИ автоматически сохраняет версии и позволяет откатиться к любой предыдущей версии                      |
| Full-stack-предпросмотр     | Поддерживает полноценный предпросмотр интерфейса и серверной части; в некоторых сценариях требуется вручную запустить среду-песочницу                   |
| Публикация и развертывание   | Чтобы развернуть сайт в открытом интернете, нажмите «Опубликовать» вручную. До публикации сайт доступен только для предпросмотра. Поддерживается развертывание full-stack-контента  |

## Результаты работы агента

- Полный набор файлов для выполнения задачи, включая код интерфейса и серверной части
- Full-stack-сайт, который можно просмотреть онлайн и опубликовать
- Загружаемый Zip-пакет в каталоге `/mnt/agents/output/app/`

## Текущие ограничения

Следующие сценарии пока не поддерживаются и будут постепенно открываться в будущих версиях:

- Интеграция сторонних платежей, например Stripe и PayPal
- Вход через сторонний OAuth, например Google и GitHub. Сейчас поддерживаются только вход через аккаунт Kimi или вход по имени пользователя и паролю на базе данных
- Сложные серверные интеграции с API, например подключение к внешним SaaS-сервисам
