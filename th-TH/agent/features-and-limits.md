# ความสามารถและข้อจำกัดของ Agent

<SeoMeta
  title="Agent Features \u0026 Limitations - ศูนย์ช่วยเหลือ Kimi"
  description="เรียนรู้เกี่ยวกับความสามารถ เคล็ดลับการใช้งาน ข้อจำกัด และแนวทางปฏิบัติที่ดีที่สุดของ Kimi Agent เพื่อผลลัพธ์ที่ดีที่สุด"
/>

<Callout type="info">
**Kimi Agent** คือผู้ช่วยที่ขับเคลื่อนด้วย AI ซึ่งทำงานที่ซับซ้อนได้อย่างอิสระผ่านการให้เหตุผลแบบหลายขั้นตอนและการเชื่อมต่อกับเครื่องมือต่าง ๆ คู่มือนี้ครอบคลุมแนวทางปฏิบัติที่ดีที่สุด ข้อจำกัด และคำถามที่พบบ่อย เพื่อช่วยให้คุณใช้งานโหมด Agent ได้อย่างคุ้มค่าที่สุด
</Callout>

## เคล็ดลับการใช้งาน

**(1) ก่อนส่งงาน**

ระบุข้อมูลพื้นฐานและข้อจำกัดให้ชัดเจน เช่น บริบทของโปรเจกต์ กรณีการใช้งาน และข้อกำหนดพิเศษ เพื่อช่วยให้ Kimi เข้าใจเจตนาของคุณได้แม่นยำยิ่งขึ้น

**(2) ระหว่างการทำงาน**

Kimi Agent ทำงานแบบอะซิงโครนัสอยู่เบื้องหลัง หากหน้าเว็บดูเหมือนค้างหรือหยุดนิ่ง **อย่าคลิก "หยุด"** เพราะจะเป็นการขัดจังหวะการทำงาน คุณสามารถออกจากหน้านี้ได้ งานจะยังคงทำงานต่อในเบื้องหลัง และคุณจะได้รับการแจ้งเตือนเมื่องานเสร็จสิ้น สำหรับงานที่คาดว่าจะใช้เวลานาน (เช่น K2.6 Agent Swarm [Beta]) โปรดอดทนรอ

**(3) สถานการณ์การสร้างเว็บไซต์**

Agent สามารถสร้างเนื้อหาแบบ full-stack ได้ ทั้งส่วนหน้า บริการเบื้องหลัง และตรรกะการจัดเก็บข้อมูลถาวร หากโปรเจกต์ไม่ทำงานตามที่คาดไว้ ปัญหามักเกี่ยวข้องกับการเริ่มต้น sandbox การกำหนดค่าเริ่มต้นของฐานข้อมูล การตั้งค่าการยืนยันตัวตน หรือการขาดขั้นตอนการเผยแพร่ Agent มาตรฐานทำงานบนคลาวด์และไม่สามารถเข้าถึงไฟล์ในเครื่องหรือระบบอินทราเน็ตขององค์กรได้โดยตรง หากต้องการเข้าถึงไฟล์ในเครื่องหรืออินทราเน็ต ให้ใช้ Kimi Claw

<Callout type="tip">
**ต้องการเข้าถึงไฟล์ในเครื่องใช่หรือไม่?** ใช้ Kimi Claw เพื่อเข้าถึงไฟล์ในเครื่องและระบบอินทราเน็ตขององค์กรได้อย่างปลอดภัย เรียนรู้เพิ่มเติมใน[เอกสาร Kimi Claw](/kimi-claw/overview)
</Callout>

**(4) การสนทนาหลายรอบและการปรับงาน**
เมื่อผ่านการสนทนาและการแก้ไขหลายรอบ Agent อาจ "ลืม" รายละเอียดบางอย่างในช่วงต้นไป ทางที่ดีควรกำหนดกรอบงานและประเด็นสำคัญให้เรียบร้อยก่อน แล้วจึงค่อย ๆ ปรับแก้ทีละน้อย

**(5) การแบ่งงานขนาดใหญ่**
สำหรับงานขนาดใหญ่ที่ซับซ้อน ให้แบ่งออกเป็น 2–3 ระยะ แล้วส่งให้ Kimi เป็นชุด ๆ หรือใช้ K2.6 Agent Swarm [Beta]

**(6) ข้อจำกัดของไฟล์ผลลัพธ์**
ในโหมด Agent มาตรฐาน โดยทั่วไปจะสร้างไฟล์ได้เพียงไฟล์เดียวต่อหนึ่งงาน (เช่น เอกสารหรือสเปรดชีต) หากต้องการไฟล์หลายไฟล์ (เช่น ทั้งเอกสาร Word และ PPT) ให้ใช้ K2.6 Agent Swarm [Beta]

**(7) ข้อจำกัดของบริบทและความสมดุลของผลลัพธ์**
เนื่องจากข้อจำกัดของบริบทที่ 256K อักขระของโมเดลภาษาขนาดใหญ่ (ประมาณ 40,000–50,000 อักษรจีน / ~100,000 คำภาษาอังกฤษ) การประมวลผลไฟล์จำนวนมากจึงต้องสร้างสมดุลระหว่างปริมาณข้อมูลนำเข้าและผลลัพธ์

<Callout type="warning">
**หมายเหตุเรื่องข้อจำกัดของบริบท**: Agent ใช้หน้าต่างบริบทขนาด 256K อักขระ เพื่อผลลัพธ์ที่ดีที่สุด ควรให้บริบทที่กระชับและหลีกเลี่ยงการใส่ไฟล์ที่ไม่จำเป็นมากเกินไป
</Callout>

## ข้อควรทราบที่สำคัญ

<Callout type="warning">
**การใช้ เครดิต**: งานของ Agent ใช้ เครดิต จากพูลที่ใช้ร่วมกัน (ฟีเจอร์สมาชิกอื่น ๆ) ส่วน Kimi Code ใช้พูล เครดิต แยกต่างหาก งานของ Agent แต่ละงานมักใช้ เครดิต 1 หน่วย ดูข้อมูล เครดิต โดยละเอียดตามระดับสมาชิกได้ที่ [เครดิต และการเรียกเก็บเงิน](/agent/quota-and-billing)
ระดับฟรี: 6 งาน Agent/เดือน
ระดับเสียเงิน: 60–720 งาน Agent/เดือน ขึ้นอยู่กับแพ็กเกจของคุณ
</Callout>

- **เวลาในการทำงาน**: ในโหมด Agent งานหนึ่งงานมักใช้เวลา 5–20 นาที งาน K2.6 Agent Swarm [Beta] อาจใช้เวลานานกว่า คุณสามารถออกจากหน้านี้ได้ เพียงแต่อย่าคลิกหยุดเพื่อขัดจังหวะงาน
- **การใช้ เครดิต**: งานของ Agent ใช้ เครดิต จากพูลที่ใช้ร่วมกัน ส่วน Kimi Code ใช้พูล เครดิต แยกต่างหาก
- **งานง่าย ๆ**: สำหรับการถาม-ตอบง่าย ๆ แนะนำให้ใช้โหมดแชทมาตรฐานเพื่อการตอบสนองที่รวดเร็วกว่า

<Callout type="warning">
**การปฏิบัติตามข้อกำหนดด้านเนื้อหา**: ฟีเจอร์ของ Agent อยู่ภายใต้[ข้อตกลงผู้ใช้ Kimi](https://www.kimi.com/user/agreement/modelUse?version=v2) ไม่รองรับการสร้างเนื้อหาต้องห้าม การส่งเนื้อหาต้องห้ามอาจส่งผลให้มีการระงับบริการ
</Callout>

## คำถามที่พบบ่อย

**ถาม: Agent ทำอะไรได้บ้าง?**

Agent ตอบสนองความต้องการต่อไปนี้ผ่านการเรียกใช้เครื่องมือหลายตัว:
- **การสร้างและแก้ไขข้อความ**: สร้างบทความ รายงาน เอกสาร ฯลฯ พร้อมรองรับสไตล์การเขียนและรูปแบบที่หลากหลาย
- **การพัฒนาเว็บ**: สร้างส่วนติดต่อและบริการของโปรเจกต์แบบ full-stack รองรับการออกแบบส่วนติดต่อแอป การเชื่อมต่อกับเบื้องหลัง การจัดเก็บข้อมูลถาวร และการแสดงผลข้อมูลเชิงภาพ
- **การสร้างสไลด์**: เครื่องมือ PPT บนเว็บโดยเฉพาะสำหรับสร้างงานนำเสนอแบบสมบูรณ์
- **ผู้ช่วยด้านการเขียนโค้ด**: เขียนและแก้ไขข้อบกพร่องของโค้ดในภาษาโปรแกรมหลายภาษา

**ถาม: ทำไมเว็บไซต์ที่ Agent สร้างขึ้นถึงไม่ทำงาน?**

โปรเจกต์ที่สมบูรณ์มักประกอบด้วยสามส่วน ได้แก่ ส่วนติดต่อหน้า บริการเบื้องหลัง และการจัดเก็บข้อมูล Agent สามารถสร้างเนื้อหาโปรเจกต์แบบ full-stack ได้ครบทั้งสามชั้น หากโปรเจกต์ของคุณไม่ทำงานตามที่คาดไว้ ปัญหามักเกี่ยวข้องกับการเริ่มต้น sandbox การกำหนดค่าเริ่มต้นของฐานข้อมูล การตั้งค่าการยืนยันตัวตน หรือการขาดขั้นตอนการเผยแพร่

**ถาม: ผลงานที่ส่งมอบของ Agent มีอะไรบ้าง?**

- ไฟล์ที่ทำงานเสร็จสมบูรณ์
- ตัวอย่างโปรเจกต์ที่ปรับใช้แล้วและเวอร์ชันที่เผยแพร่
- ไฟล์เก็บถาวร Zip ที่ดาวน์โหลดได้ (อยู่ที่ `/mnt/okcomputer/output/`)

**ถาม: ความยาวบริบทของ Agent คือเท่าไร?**

Agent ใช้ความยาวบริบทที่ **256K อักขระ** (ประมาณ 40,000–50,000 อักษรจีน / ~100,000 คำภาษาอังกฤษ)

**ถาม: เครดิต ของ Agent คำนวณอย่างไร?**

Agent, PPT และฟีเจอร์สมาชิกอื่น ๆ ใช้พูล เครดิต เดียวกัน ส่วน Kimi Code ใช้พูล เครดิต แยกต่างหาก งานของ Agent แต่ละงานมักนับเป็น เครดิต หนึ่งหน่วย ดู เครดิต และการใช้งานปัจจุบันของคุณได้ที่ [Membership Credits](https://www.kimi.com/membership-credits)
