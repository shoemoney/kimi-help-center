# ฟีเจอร์และข้อจำกัดของ Agent

<SeoMeta
  title="ฟีเจอร์และข้อจำกัดของ Agent - ศูนย์ช่วยเหลือ Kimi"
  description="ทำความรู้จักความสามารถของ Kimi Agent เคล็ดลับการใช้งาน ข้อจำกัด และแนวทางปฏิบัติที่ช่วยให้ได้ผลลัพธ์ดีที่สุด"
/>

<Callout type="info">
**Kimi Agent** คือผู้ช่วยที่ขับเคลื่อนด้วย AI ซึ่งทำงานซับซ้อนได้เองผ่านการให้เหตุผลหลายขั้นตอนและการเชื่อมต่อเครื่องมือต่าง ๆ คู่มือนี้รวบรวมแนวทางปฏิบัติ ข้อจำกัด และคำถามที่พบบ่อย เพื่อช่วยให้คุณใช้โหมด Agent ได้อย่างคุ้มค่าที่สุด
</Callout>

## เคล็ดลับการใช้งาน

**(1) ก่อนส่งงาน**

ระบุข้อมูลพื้นหลังและเงื่อนไขให้ชัดเจน เช่น บริบทของโปรเจกต์ กรณีการใช้งาน และข้อกำหนดพิเศษ เพื่อช่วยให้ Kimi เข้าใจเจตนาของคุณได้แม่นยำยิ่งขึ้น

**(2) ระหว่างดำเนินงาน**

Kimi Agent ทำงานแบบอะซิงโครนัสอยู่เบื้องหลัง หากหน้าเว็บดูเหมือนค้างหรือหยุดนิ่ง **อย่าคลิก “หยุด”** เพราะจะเป็นการขัดจังหวะการทำงาน คุณสามารถออกจากหน้านั้นได้ งานจะยังดำเนินต่อในเบื้องหลัง และคุณจะได้รับการแจ้งเตือนเมื่อเสร็จสิ้น สำหรับงานที่คาดว่าจะใช้เวลานาน (เช่น Agent Swarm) โปรดรอสักครู่

**(3) กรณีการสร้างเว็บไซต์**

Agent สามารถสร้างเนื้อหาแบบฟูลสแต็กได้ครบถ้วน ทั้งอินเทอร์เฟซฝั่งหน้าเว็บ บริการแบ็กเอนด์ และตรรกะการจัดเก็บข้อมูลถาวร หากโปรเจกต์ไม่ทำงานตามที่คาด ปัญหามักเกี่ยวข้องกับการเริ่มต้น sandbox การเริ่มต้นฐานข้อมูล การตั้งค่าการยืนยันตัวตน หรือการไม่ได้เผยแพร่ โปรเจกต์มาตรฐานของ Agent ทำงานบนคลาวด์ จึงไม่สามารถเข้าถึงไฟล์ในเครื่องหรือระบบอินทราเน็ตขององค์กรได้โดยตรง หากต้องเข้าถึงไฟล์ในเครื่องหรืออินทราเน็ต ให้ใช้ Kimi Claw

<Callout type="tip">
**ต้องการเข้าถึงไฟล์ในเครื่องใช่ไหม?** ใช้ Kimi Claw เพื่อเข้าถึงไฟล์ในเครื่องและระบบอินทราเน็ตขององค์กรได้อย่างปลอดภัย ดูเพิ่มเติมได้ใน[เอกสาร Kimi Claw](/kimi-claw/overview)
</Callout>

**(4) การสนทนาหลายรอบและการปรับงาน**
เมื่อสนทนาและแก้ไขงานหลายรอบ Agent อาจ “ลืม” รายละเอียดบางอย่างที่ระบุไว้ตั้งแต่ช่วงต้นได้ วิธีที่เหมาะที่สุดคือกำหนดกรอบงานและประเด็นสำคัญให้ชัดเจนก่อน แล้วค่อยปรับเพิ่มทีละขั้น

**(5) การแบ่งงานขนาดใหญ่**
สำหรับงานขนาดใหญ่และซับซ้อน ให้แบ่งเป็น 2–3 ระยะแล้วส่งให้ Kimi เป็นชุด ๆ หรือใช้ Agent Swarm

**(6) ข้อจำกัดของไฟล์ผลลัพธ์**
ในโหมด Agent มาตรฐาน โดยทั่วไปหนึ่งงานจะส่งออกไฟล์ได้เพียงไฟล์เดียว (เช่น เอกสารหรือสเปรดชีต) หากต้องการหลายไฟล์ (เช่น ทั้งไฟล์ Word และ PPT) ให้ใช้ Agent Swarm

**(7) ขีดจำกัดบริบทและสมดุลของผลลัพธ์**
เนื่องจากโมเดลภาษาขนาดใหญ่มีขีดจำกัดบริบทที่ 256K ตัวอักษร (ประมาณ 40,000–50,000 ตัวอักษรจีน / ~100,000 คำภาษาอังกฤษ) การประมวลผลไฟล์จำนวนมากจึงต้องคำนึงถึงสมดุลระหว่างปริมาณข้อมูลนำเข้าและผลลัพธ์

<Callout type="warning">
**หมายเหตุเรื่องขีดจำกัดบริบท**: Agent ใช้หน้าต่างบริบทขนาด 256K ตัวอักษร เพื่อผลลัพธ์ที่ดีที่สุด ควรให้บริบทอย่างกระชับและหลีกเลี่ยงการใส่ไฟล์ที่ไม่จำเป็นมากเกินไป
</Callout>

## หมายเหตุสำคัญ

<Callout type="warning">
**การใช้ credit**: งานของ Agent ใช้ credit จากกองกลาง Kimi Code ก็ใช้ credit จากกองกลางเดียวกัน แต่มี rate limit ของตัวเองที่ 5 ชั่วโมง / ต่อสัปดาห์ ซึ่งใช้กับ Kimi Code เท่านั้น โดยทั่วไปงาน Agent แต่ละงานใช้ 1 หน่วย credit ดูรายละเอียด credit ตามระดับสมาชิกได้ที่ [Credits & Billing](/agent/quota-and-billing)

- 60–720 งาน Agent/เดือน ขึ้นอยู่กับแพ็กเกจของคุณ
</Callout>

- **เวลาในการดำเนินงาน**: ในโหมด Agent งานหนึ่งงานโดยทั่วไปใช้เวลา 5–20 นาที งาน Agent Swarm อาจใช้เวลานานกว่า คุณสามารถออกจากหน้าได้ เพียงอย่าคลิกหยุดจนขัดจังหวะงาน
- **การใช้ credit**: งานของ Agent ใช้ credit จากกองกลาง ซึ่ง Kimi Code ก็ใช้จากกองกลางนี้เช่นกัน (Kimi Code มี rate limit ของตัวเองที่ 5 ชั่วโมง / ต่อสัปดาห์)
- **งานง่าย ๆ**: สำหรับการถามตอบทั่วไป แนะนำให้ใช้โหมดแชตมาตรฐานเพื่อให้ได้รับคำตอบเร็วขึ้น

<Callout type="warning">
**การปฏิบัติตามข้อกำหนดด้านเนื้อหา**: ฟีเจอร์ Agent อยู่ภายใต้ [Kimi User Service Agreement](https://www.kimi.com/user/agreement/modelUse?version=v2) ไม่รองรับการสร้างเนื้อหาต้องห้าม และการส่งเนื้อหาต้องห้ามอาจทำให้บริการถูกระงับได้
</Callout>

## คำถามที่พบบ่อย

**ถาม: Agent ทำอะไรได้บ้าง?**

Agent ตอบสนองความต้องการต่อไปนี้ผ่านการเรียกใช้เครื่องมือหลายครั้ง:
- **การสร้างและแก้ไขข้อความ**: สร้างบทความ รายงาน เอกสาร และอื่น ๆ พร้อมรองรับสไตล์การเขียนและรูปแบบที่หลากหลาย
- **การพัฒนาเว็บ**: สร้างอินเทอร์เฟซและบริการของโปรเจกต์แบบฟูลสแต็ก รองรับการออกแบบอินเทอร์เฟซแอป การเชื่อมต่อแบ็กเอนด์ การจัดเก็บข้อมูลถาวร และการแสดงข้อมูลเป็นภาพ
- **การสร้างสไลด์**: เครื่องมือ PPT บนเว็บโดยเฉพาะสำหรับสร้างงานนำเสนอที่สมบูรณ์
- **ความช่วยเหลือด้านการเขียนโค้ด**: ช่วยเขียนโค้ดและดีบักในหลายภาษาโปรแกรม

**ถาม: ทำไมเว็บไซต์ที่ Agent สร้างจึงไม่ทำงาน?**

โปรเจกต์ที่สมบูรณ์โดยทั่วไปประกอบด้วย 3 ส่วน ได้แก่ อินเทอร์เฟซฝั่งหน้าเว็บ บริการแบ็กเอนด์ และการจัดเก็บข้อมูล Agent สามารถสร้างเนื้อหาโปรเจกต์แบบฟูลสแต็กได้ครบทั้งสามชั้น หากโปรเจกต์ของคุณไม่ทำงานตามที่คาด ปัญหามักเกี่ยวข้องกับการเริ่มต้น sandbox การเริ่มต้นฐานข้อมูล การตั้งค่าการยืนยันตัวตน หรือการไม่ได้เผยแพร่

**ถาม: ผลลัพธ์ที่ Agent ส่งมอบมีอะไรบ้าง?**

- ไฟล์งานที่ดำเนินการเสร็จสมบูรณ์
- ตัวอย่างโปรเจกต์ที่ปรับใช้แล้วและเวอร์ชันที่เผยแพร่
- ไฟล์บีบอัด Zip ที่ดาวน์โหลดได้ (อยู่ใน `/mnt/okcomputer/output/`)

**ถาม: ความยาวบริบทของ Agent คือเท่าไร?**

Agent ใช้ความยาวบริบท **256K ตัวอักษร** (ประมาณ 40,000–50,000 ตัวอักษรจีน / ~100,000 คำภาษาอังกฤษ)

**ถาม: credit ของ Agent คำนวณอย่างไร?**

ฟีเจอร์สมาชิกทั้งหมด รวมถึง Kimi Code ใช้กอง credit เดียวกัน โดยทั่วไปงาน Agent แต่ละงานนับเป็น 1 หน่วย credit
