# ภาพรวม Kimi Agent

Kimi Agent คือผู้ช่วย AI อัตโนมัติที่จัดการงานซับซ้อนได้ครบวงจร ขับเคลื่อนด้วย Kimi K3 พร้อมใช้เครื่องมือกว่า 20 ชนิดในการสร้างเว็บไซต์ สร้างเอกสาร วิเคราะห์ข้อมูล และอื่น ๆ อีกมากมาย

## พัฒนาการของผลิตภัณฑ์
- **5 กันยายน 2025**: เปิดตัว Kimi K2 — พารามิเตอร์ active 32B / รวม 1T
- **26 กันยายน 2025**: เปิดตัวโหมด Agent "OK Computer"
- **27 มกราคม 2026**: เปิดตัว Kimi K2.5 — ทักษะ Office และความสามารถ Agent ที่ดีขึ้น
- **กุมภาพันธ์ 2026**: เปิดให้ทดลองใช้ Kimi Claw แบบสาธารณะ
- **20 เมษายน 2026**: เปิดตัวและเปิดซอร์ส Kimi K2.6 — เป็นผู้นำด้านการเขียนโค้ด การทำงานในระยะยาว และ Agent Swarm
- **16 กรกฎาคม 2026**: เปิดตัว Kimi K3 — โมเดลระดับ 3T แบบเปิดตัวแรกของโลก (พารามิเตอร์ 2.8T, การมองเห็นแบบเนทีฟ, บริบท 1 ล้านโทเค็น) และเป็นโมเดลที่ทรงพลังที่สุดของ Kimi ขับเคลื่อนทั้งการสนทนา Agent และ Agent Swarm ใช้งานได้ผ่านแอป Kimi, kimi.com, Kimi Work, Kimi Code และ Kimi API พร้อมเปิดเผยน้ำหนักโมเดลทั้งหมดในวันที่ 27 กรกฎาคม 2026

## ความสามารถหลัก
| ฟีเจอร์ | รายละเอียด |
|---------|-------------|
| **เว็บไซต์** | สร้างและเผยแพร่เว็บแอประบบ responsive |
| **เอกสาร** | แก้ไขและสร้างไฟล์ Word, PDF, Markdown |
| **สเปรดชีต** | วิเคราะห์และแสดงผลข้อมูล Excel/CSV |
| **สไลด์** | สร้าง PPT อัตโนมัติ |
| **Deep Research** | รายงานวิจัยความยาวกว่า 10,000 คำ |
| **Agent Swarm** | sub-agent ทำงานพร้อมกันได้สูงสุด 300 ตัว |
| **Kimi Claw** | ระบบอัตโนมัติบนคลาวด์พร้อมทักษะกว่า 5,000 รายการ |

## ทำงานอย่างไร?
1. **วางแผนงาน**: แยกคำขอของคุณออกเป็นงานย่อย
2. **เรียกใช้เครื่องมือ**: ใช้เครื่องมือกว่า 20 ชนิดตามความจำเป็น
3. **ทำงานอัตโนมัติ**: ทำการวิจัย ออกแบบ และพัฒนาให้เสร็จสมบูรณ์
4. **จัดการข้อผิดพลาด**: แก้ไขด้วยตัวเองโดยไม่ต้องให้ผู้ใช้เข้ามาเกี่ยวข้อง
5. **ผลงานที่ได้**: ไฟล์ Office เว็บแอป หรือรายงาน

## เริ่มต้นใช้งาน
- **เว็บ**: [kimi.com/agent](https://www.kimi.com/agent)
- **มือถือ**: เปิดแอป Kimi แล้วเลือกโมเดล K3 หรือ K3 Swarm ที่ปุ่มสลับโมเดล
อธิบายงานของคุณให้ชัดเจน ดูความคืบหน้าการทำงาน จากนั้นดาวน์โหลดหรือแชร์ผลลัพธ์

## กรณีการใช้งาน
- พัฒนาเว็บไซต์ (ไม่ต้องเขียนโค้ด)
- สร้างเนื้อหาพร้อมมัลติมีเดีย
- เปรียบเทียบและแปลเอกสาร
- วิเคราะห์ข้อมูล (Excel สูงสุด 1,000 แถว)
- สร้างสไลด์
- แปลงไฟล์เอกสาร
