# เครดิตและการเรียกเก็บเงินของ Agent

<Callout type="info">
โหมด Agent ใช้ระบบ เครดิต ของ Kimi สิทธิประโยชน์สมาชิกทุกแบบมาพร้อม เครดิต สองชุด: Kimi Code ใช้ เครดิต แยกอีกชุดหนึ่ง ส่วนฟีเจอร์สมาชิกอื่น ๆ (Agent, Deep Research, สไลด์, เอกสาร, สเปรดชีต, Kimi Claw และอื่น ๆ) ใช้ เครดิต ร่วมกันชุดเดียว โดยหัก เครดิต ตามจำนวน โทเค็น ที่ใช้จริง
</Callout>

## รูปแบบการเรียกเก็บเงิน
- **เครดิต สองชุด**: สิทธิประโยชน์สมาชิกทุกแบบมาพร้อม เครดิต สองชุด Kimi Code ใช้ เครดิต แยกอีกชุดหนึ่ง ส่วนฟีเจอร์สมาชิกอื่น ๆ ใช้ เครดิต ร่วมกันชุดเดียว — แบ่งใช้งานได้ตามต้องการ
- **จ่ายตามการใช้งาน**: การใช้ เครดิต ขึ้นอยู่กับความซับซ้อนและระยะเวลาของงาน (กล่าวคือ จำนวน โทเค็น ที่ใช้) — งานง่ายใช้น้อย งานซับซ้อนใช้มาก
- **รีเฟรชรายเดือน**: เครดิต รีเซ็ตทุกเดือนตามรอบการสมัครสมาชิกของคุณ
- **ลำดับการใช้งาน**: เครดิต โบนัส (เช่น เครดิต ทดลองใช้ รางวัลโปรโมชัน) จะถูกใช้ก่อน ตามด้วย เครดิต ของแพ็กเกจ

<Callout type="tip">
**ตัวอย่าง**: หากใช้แพ็กเกจ Moderato การสร้าง PPT แบบง่าย ๆ อาจใช้ เครดิต ประมาณ 1–2% ขณะที่การใช้ Deep Research หนึ่งครั้งอาจใช้ประมาณ 5–10%
</Callout>

## เกิดอะไรขึ้นเมื่อ เครดิต หมด?
เมื่อ เครดิต ของคุณหมดลง:
- งานที่กำลังดำเนินอยู่จะทำงานจนเสร็จตามปกติ
- งานใหม่จะแสดงข้อความแจ้งว่า "เครดิต ไม่เพียงพอ"
- ตัวเลือกของคุณ:
  - รอให้ เครดิต รายเดือนรีเฟรชอัตโนมัติ
  - อัปเกรดเป็นสมาชิกระดับสูงขึ้นเพื่อรับ เครดิต เพิ่ม

## วิธีตรวจสอบการใช้ เครดิต?
- **เว็บ**: โปรไฟล์ → การตั้งค่า → การสมัครสมาชิก
- **แอป**: โปรไฟล์ → แพ็กเกจสมาชิก → การสมัครสมาชิก
สิ่งที่คุณดูได้:
1. ยอด เครดิต คงเหลือปัจจุบัน (เป็นเปอร์เซ็นต์)
2. วันที่รีเฟรชครั้งถัดไป
3. ประวัติการใช้งาน 10 รายการล่าสุด (เวลา ฟีเจอร์ที่ใช้ เปอร์เซ็นต์ที่ใช้ไป)

<Callout type="info">
ประวัติการใช้งานอาจล่าช้าเล็กน้อย โปรดยึดตามค่า เครดิต ที่แสดงจริงเพื่อข้อมูลล่าสุด
</Callout>

## งานที่ล้มเหลวยังหัก เครดิต หรือไม่?
- เครดิต จะถูกหักหลังจากงานทำงานสำเร็จ โดยอิงตามการใช้งานจริง
- หากงานล้มเหลวเพราะข้อผิดพลาดของระบบ (ไม่มีผลลัพธ์ที่ถูกต้องส่งกลับมา) ให้กดปุ่ม **👎** เพื่อรายงาน หลังตรวจสอบแล้ว เครดิต ส่วนนั้นจะได้รับการคืนให้
