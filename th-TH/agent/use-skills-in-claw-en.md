# การใช้ Skills ใน Kimi Claw

Kimi Claw คือผู้ช่วย AI ที่มีบุคลิกเฉพาะตัวและความสามารถด้านหน่วยความจำระยะยาว สามารถรันงานตามกำหนดเวลาเบื้องหลัง ทำงานร่วมกันข้ามแพลตฟอร์ม จดจำบริบทต่อเนื่อง และทำงานน่าเบื่อให้เป็นอัตโนมัติ เช่น การรวบรวมข้อมูล การเฝ้าติดตาม และการแจ้งเตือน

## การรับและจัดการ skills

### ดาวน์โหลด skills จาก Kimi

คุณสามารถดาวน์โหลด skills ทางการหรือ skills ที่ปรับแต่งเองจากแพลตฟอร์ม Kimi มายัง Claw ในเครื่องได้:

1. เปิด Kimi Claw แล้วไปที่ส่วน **Skills**
2. เรียกดูรายการ skills เลือก skill ที่ต้องการ แล้วเลือก **ดาวน์โหลดลง Claw**
3. เมื่อดาวน์โหลดเสร็จแล้ว คุณสามารถเรียกใช้ใน Claw ได้ทันที

<Callout type="info">
เมื่อ skills มีการอัปเดต เวอร์ชันในเครื่องจะไม่ถูกเขียนทับโดยอัตโนมัติ หากต้องการเนื้อหาล่าสุด โปรดดาวน์โหลดใหม่ด้วยตนเอง
</Callout>

### ซิงค์ skills จาก Kimi Agent

หากคุณเพิ่ม skills ไว้ใน Kimi Agent (เวอร์ชันเว็บ) แล้ว Kimi Claw สามารถซิงค์และแสดง skills เหล่านี้ได้โดยตรงโดยไม่ต้องตั้งค่าใหม่

เมื่อ Kimi Claw ตรวจพบว่าเวอร์ชันของ skill ระหว่างสองแพลตฟอร์มไม่ตรงกัน ระบบจะแสดงข้อความ **ต้องอัปเดต** ข้าง skill นั้น คลิกเพื่อซิงค์ไปยังเวอร์ชันล่าสุด

### การใช้คลัง skill ของ Clawhub

Kimi Claw มี **คลัง skill ของ Clawhub** มาในตัว ซึ่งรวม skills คุณภาพสูงที่ผ่านการตรวจสอบแล้ว ครอบคลุมสถานการณ์การทำงานทั่วไปหลากหลายรูปแบบ:

- **การจัดระเบียบข้อมูล**: สรุปข่าว เปรียบเทียบคู่แข่ง เทมเพลตบันทึกการประชุม
- **งานวิเคราะห์**: ทบทวนหุ้นและอุตสาหกรรม ตีความข้อมูล ระบุความเสี่ยง
- **การจัดการเวิร์กโฟลว์**: กระบวนการที่สมบูรณ์ตั้งแต่การแยกย่อยความต้องการไปจนถึงการส่งมอบผลลัพธ์

เข้าสู่คลัง skill เรียกดูหรือค้นหา skills ที่เหมาะกับสถานการณ์การทำงานของคุณ แล้วคลิกเพื่อติดตั้ง

## การเรียกใช้ skills

ในช่องป้อนข้อความของ Kimi Claw มีวิธีเรียกใช้ skills อยู่สามแบบ เช่นเดียวกับเวอร์ชันเว็บ:

- พิมพ์ `/` เพื่อเลือก skill จากรายการที่ปรากฏขึ้น
- คลิกปุ่ม **+** ข้างช่องป้อนข้อความ แล้วเลือกจากเมนู
- พิมพ์ชื่อ skill โดยตรง

<Callout type="warning">
ปัจจุบันยังไม่สามารถเข้าถึง skill ใน OpenClaw ของบุคคลที่สาม Kimi Claw ในเครื่อง และ Kimi Claw เดสก์ท็อปได้
</Callout>

## สอนวิธีการทำงานของคุณให้ Claw

นอกจากการใช้ skills สำเร็จรูปแล้ว คุณยังสามารถ "สอน" ประสบการณ์และวิธีการที่คุณสั่งสมมาให้ Claw ได้ เพื่อให้มันทำงานตามแนวทางของคุณในระยะยาว มีสามวิธีหลักดังนี้:

**ให้กระบวนการ**: บอก Claw ถึงขั้นตอนเฉพาะที่คุณใช้เมื่อจัดการงานประเภทใดประเภทหนึ่ง

**ให้มาตรฐาน**: บอก Claw ว่าสิ่งที่คุณให้ความสำคัญที่สุดคืออะไร—ความแม่นยำ ความเร็ว ความเป็นไปได้ หรือการควบคุมความเสี่ยง

**ให้เทมเพลต**: บอก Claw ถึงรูปแบบผลลัพธ์ที่คุณต้องการ เช่น หากโครงสร้างรายงานประจำวันของคุณคือ "งานที่ทำวันนี้ → ปัญหาที่พบ → แผนงานพรุ่งนี้ → ต้องการความช่วยเหลือ" ก็บอก Claw ได้โดยตรง แล้วมันจะจัดระเบียบรายงานในอนาคตตามรูปแบบนี้

### กรณีศึกษา

สมมติว่าคุณเป็นผู้จัดการผลิตภัณฑ์ที่ต้องการให้ Kimi Claw ช่วยทบทวนความคิดเห็นของผู้ใช้ทุกสัปดาห์ คุณสามารถสอน Claw ได้ดังนี้:

1. **กระบวนการ**: "ทุกวันจันทร์ หลังจากรวบรวมความคิดเห็นของผู้ใช้แล้ว ให้จัดหมวดหมู่ตามโมดูลฟีเจอร์ก่อน จากนั้นติดป้ายระดับความสำคัญ (P0-P3) และสุดท้ายดึงประเด็นที่พบบ่อยออกมา"

2. **มาตรฐาน**: "ฉันให้ความสำคัญกับความน่าเชื่อถือและความเป็นไปได้ของความคิดเห็นมากที่สุด ดังนั้นให้ตัดความคิดเห็นที่ซ้ำกันออก และเก็บไว้เฉพาะความคิดเห็นที่มีคำอธิบายกรณีใช้งานเฉพาะเจาะจง"

3. **เทมเพลต**: "รูปแบบผลลัพธ์: โมดูลฟีเจอร์ | เนื้อหาความคิดเห็น | ความสำคัญ | จำนวนผู้ใช้ | แนวทางแก้ไขที่แนะนำ"

เมื่อคุณบอก Claw ว่า "ช่วยจัดระเบียบความคิดเห็นของผู้ใช้สัปดาห์นี้ให้หน่อย" มันจะประมวลผลตามมาตรฐานเหล่านี้โดยอัตโนมัติ โดยที่คุณไม่ต้องอธิบายซ้ำทุกครั้ง

<Callout type="tip">
ด้วยการผสมผสานระหว่าง skills และวิธีการทำงานที่ปรับแต่งเอง Kimi Claw จึงสามารถทำงานได้เร็วขึ้นและแม่นยำขึ้น พร้อมสร้างผลลัพธ์ที่ตรงกับแนวทางของคุณได้อย่างต่อเนื่อง
</Callout>

## ข้อควรทราบสำหรับการใช้งานบนมือถือ

เมื่อใช้ skills บนมือถือ โปรดทราบข้อจำกัดต่อไปนี้:

- หากคุณเพิ่ม skills ไว้บนเวอร์ชันเว็บ เมนูเครื่องหมายบวกจะแสดงรายการ skill การคลิกจะแทรก skill เป็นข้อความในช่องป้อนข้อความ
- หากไม่ได้เพิ่ม skills ไว้บนเวอร์ชันเว็บ เมนูเครื่องหมายบวกบนมือถือจะไม่แสดงรายการ skill
- หากประวัติการสนทนามีเนื้อหาที่สร้างโดย skill จะมีข้อความแจ้งว่า: **สร้างด้วย skill ปัจจุบันรองรับเฉพาะบนแพลตฟอร์มเว็บ Kimi เท่านั้น**

เราแนะนำให้ดำเนินการจัดการ skill บางอย่าง (เช่น การสร้าง แก้ไข ลบ) บนแพลตฟอร์มเว็บ ส่วนมือถือใช้สำหรับเรียกใช้ skills ที่มีอยู่แล้วเป็นหลัก
