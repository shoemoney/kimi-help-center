# Skills คืออะไร?

<Frames
  src="./images/skills/what_is_skill.png"
  alt="what_is_skill"
/>

Skills คือชุดความรู้ที่นำกลับมาใช้ซ้ำได้ ออกแบบมาเพื่อขยายขีดความสามารถของ AI agent โดยแต่ละ skill ประกอบด้วย:

- **วิธีการทำงานและคำแนะนำเชิงปฏิบัติ** — ระเบียบวิธีที่ปรับให้เหมาะกับงานแต่ละประเภท
- **แนวทางปฏิบัติที่ดีและมาตรฐาน** — มาตรฐานอุตสาหกรรมและข้อกำหนดภายในที่ต้องปฏิบัติตาม
- **สคริปต์ เครื่องมือ และทรัพยากรอ้างอิง** — เครื่องมือและเอกสารเสริมที่ช่วยในการดำเนินงาน (ตามความเหมาะสม)

## ใช้งานอย่างไร?

เมื่อเริ่มต้นการสนทนา Agent จะเห็นรายการ skills ที่ใช้งานได้พร้อมชื่อและคำอธิบายสั้น ๆ หาก skill ใดเกี่ยวข้องกับงานปัจจุบัน Agent จะโหลดคำสั่งฉบับเต็มและดำเนินการตามนั้น

## เส้นทางการใช้งานของผู้ใช้

ตั้งแต่การค้นพบ skills ไปจนถึงการสร้าง skill ของคุณเอง เส้นทางทั้งหมดมีดังนี้:

1. **ค้นพบ skills** — เรียกดู skills อย่างเป็นทางการและที่แนะนำในแผง Skills เพื่อหาตัวที่เหมาะกับสถานการณ์ของคุณ
2. **ติดตั้ง skills** — คลิกปุ่ม "+" เพื่อเพิ่ม skill ได้ทันที
3. **เรียกใช้ skills** — พิมพ์ `/` ในกล่องแชทเพื่อเลือก skill หรือให้ Kimi เรียกใช้โดยอัตโนมัติตามคำถามของคุณ
4. **สร้างของคุณเอง** — หาก skills ที่มีอยู่ไม่ตอบโจทย์ ก็สามารถอัปโหลดเอกสารหรืออธิบายความต้องการเพื่อสร้าง skill เฉพาะ หรือใช้ `/skill-creator` เพื่อสร้างผ่านการสนทนา

## Skills ทำงานอย่างไร?

เมื่อคุณส่งคำขอ Kimi Agent จะประเมินว่างานปัจจุบันเกี่ยวข้องกับ skill ใดเป็นพิเศษหรือไม่ หากใช่ ก็จะโหลด skill ที่เกี่ยวข้องโดยอัตโนมัติและทำตามคำสั่งเพื่อทำงานให้เสร็จ

Skills จะถูกโหลดเฉพาะเมื่อเกี่ยวข้องกับงานเท่านั้น เพื่อให้มั่นใจว่าจะไม่รบกวนบริบทของการสนทนาอื่น ๆ

## Skills กับการ prompt โดยตรง: ต่างกันอย่างไร?

ลองใช้การเขียนรายงานประจำสัปดาห์เป็นตัวอย่าง:
- **การ prompt โดยตรง**: ถาม Kimi Agent โดยตรง แล้วมันจะเขียนตามความเข้าใจเรื่องรูปแบบของมันเอง
- **การใช้ Skills**: หลังจากติดตั้ง skill รายงานประจำสัปดาห์แล้ว ผลลัพธ์ทุกครั้งจะเป็นไปตามโครงสร้าง น้ำเสียง และความยาวที่คุณตั้งไว้ล่วงหน้า โดยไม่ต้องสั่งซ้ำ

| | การ prompt โดยตรง | การใช้ skills |
|---|---|---|
| **ต้องอธิบายความต้องการทุกครั้งไหม?** | ใช่ | ไม่ ใช้งานอัตโนมัติ |
| **ความเสถียรของรูปแบบผลลัพธ์** | ไม่แน่นอน | สม่ำเสมอตามที่กำหนด |
| **กรณีใช้งานที่เหมาะสม** | งานครั้งเดียวหรือชั่วคราว | งานที่ทำซ้ำและมีรูปแบบตายตัว |
| **ต้องตั้งค่าก่อนไหม?** | ไม่ | ต้องสร้างหรือติดตั้งก่อน |

## ประเภทของ Skill

### (1) Skills อย่างเป็นทางการและ skills ที่แนะนำ

**Skills อย่างเป็นทางการ**: สร้างและดูแลโดย Moonshot AI ใช้งานได้สำหรับผู้ใช้ทุกคน Kimi จะเรียกใช้โดยอัตโนมัติในสถานการณ์ที่เกี่ยวข้อง

Skills อย่างเป็นทางการที่พบบ่อย ได้แก่:
- `docx` — สร้างและแก้ไขเอกสาร Word เหมาะกับงาน .docx ทุกประเภท ทั้งการสร้างเอกสาร การแก้ไข ความคิดเห็น การปรับแก้ เชิงอรรถ สารบัญ และการแปลง Markdown เป็น Word
- `deep-research` — ทำการวิจัยเชิงลึกและสร้างรายงานฉบับยาวด้วยชุดเครื่องมือ โดยต้องวนรอบค้นหาซ้ำอย่างน้อย 10 ครั้ง มีการสะท้อนคิดแบบเรียกซ้ำ และต้องสร้างภาพข้อมูลด้วย IPython

**Skills ที่แนะนำ**: skills ที่คัดสรรตามสถานการณ์ พร้อมให้เพิ่มด้วยคลิกเดียว ครอบคลุมกรณีใช้งานทั่วไป เช่น การวิจัยการลงทุนและการจัดรูปแบบเอกสาร

Skills ที่แนะนำที่พบบ่อย ได้แก่:
- `sop-writer` — แปลงกระบวนการทางธุรกิจให้เป็นเอกสาร Standard Operating Procedure (SOP) ฉบับสมบูรณ์ ทั้งแผนผังกระบวนการ เมทริกซ์ RACI ขั้นตอนปฏิบัติโดยละเอียด และการจัดการข้อยกเว้น
- `event-etf-study` — เริ่มจากแนวคิดหรือเหตุการณ์ ระบุหุ้นที่เกี่ยวข้อง สร้างดัชนี ETF แบบถ่วงน้ำหนักตามมูลค่าตลาด วิเคราะห์การเปลี่ยนแปลงของมูลค่าตลาดในช่วงเหตุการณ์ และสร้างแดชบอร์ด HTML แบบโต้ตอบ ใช้เมื่อผู้ใช้สอบถามเกี่ยวกับหุ้นตามธีม ETF ตามธีม การวิเคราะห์ที่ขับเคลื่อนด้วยเหตุการณ์ หรือการวิจัยเหตุการณ์

**แปลงเอกสารสำนักงานเป็น skill**: อัปโหลดเอกสารเพื่อสร้าง skills และจำลองธีมสไตล์ได้อย่างง่ายดาย

### (2) Skills แบบโอเพนซอร์ส

ดาวน์โหลดหรือติดตั้ง Skills ที่เหมาะสมจากชุมชนโอเพนซอร์ส ใช้ร่วมกับ Local Agents (เช่น Kimi Code) หรือ Cloud Agents (เช่น Kimi Claw)

**แพลตฟอร์มศูนย์รวม AI Skill ที่พบบ่อย**

| แพลตฟอร์ม | URL | คำอธิบาย |
|----------|-----|-------------|
| SkillsMP | https://skillsmp.com | ตลาดกลาง skill สำหรับ AI agent ที่รวบรวมแพ็กเกจ SKILL.md จาก GitHub รองรับ Claude Code และ OpenAI Codex CLI |
| SkillsLLM | https://skillsllm.com | ตลาดกลาง skill สำหรับ AI agent แบบโอเพนซอร์ส มี skill ที่ผ่านการตรวจสอบความปลอดภัยกว่า 1,600 รายการ สำหรับ Claude Code, Codex CLI และ ChatGPT |
| LobeHub Skills | https://market.lobehub.com/s/skills | เรียกดูและเผยแพร่แพ็กเกจ SKILL.md ที่รองรับ Claude Code, Codex CLI และ ChatGPT |

### (3) ปรับแต่ง skills

skills ที่คุณสร้างเองสำหรับขั้นตอนงานส่วนตัวและงานเฉพาะด้าน เช่น:
- ใช้แนวทางสไตล์เฉพาะกับเอกสารหรืองานนำเสนอ
- สร้างอีเมลหรือเนื้อหาการสื่อสารจากเทมเพลตที่กำหนดไว้
- จัดทำบันทึกการประชุมในรูปแบบเฉพาะ
- ดำเนินขั้นตอนการวิเคราะห์ข้อมูลเฉพาะแบบ
