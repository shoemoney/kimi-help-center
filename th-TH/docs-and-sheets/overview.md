# Kimi Docs และ Kimi Sheets

<Callout type="info">
ในวันที่ 27 มกราคม 2026 Moonshot AI ได้เปิดตัว Kimi K2.5 ซึ่งยกระดับความสามารถด้านการทำงานของ Kimi Agent อย่างก้าวกระโดด ตอนนี้ Kimi Agent "เชี่ยวชาญ Office" พร้อมสร้างไฟล์ Word, PDF, Excel และ Slides ได้แบบครบวงจร
</Callout>

Kimi K2.5 มอบคุณภาพผลลัพธ์และประสิทธิภาพการเรียกใช้เครื่องมือที่ดีขึ้นอย่างชัดเจนในงานสำนักงาน โดยเฉพาะการสร้างผลลัพธ์แบบมีโครงสร้างด้วยความสามารถประมวลผลครบวงจร:
| รูปแบบ | ความสามารถ |
|--------|-------------|
| **Word** | จัดรูปแบบอัจฉริยะและติดตามการแก้ไข |
| **PDF** | ออกแบบเชิงภาพและจัดวางข้อความผสมรูปภาพ |
| **Excel** | วิเคราะห์ข้อมูลและสร้างโมเดลทางการเงิน |
| **Slides** | สร้างอัตโนมัติและเล่าเรื่องด้วยภาพ |

## Kimi Docs
Kimi Docs มีความสามารถในการปรับแต่งข้อความที่แข็งแกร่งและเข้าใจขั้นตอนการทำงานของ Office อย่างเป็นระบบ
### ความสามารถหลัก
**เอกสาร Word:**
- สร้างเอกสารระดับมืออาชีพแบบยาว เช่น สมุดปกขาว รายงานวิจัย สัญญา และข้อเสนอ
- แทรกความคิดเห็นและคำแนะนำในการแก้ไขลงในเอกสาร Word ที่มีอยู่
- จัดการลำดับหัวข้อ ระยะห่างย่อหน้า การอ้างอิง และการจัดรูปแบบรายการ
- ย่อวิทยานิพนธ์ความยาว 30,000 คำให้เป็นบทสรุปที่กระชับแม่นยำ
**เอกสาร PDF:**
- สร้างรายงาน PDF ระดับมืออาชีพที่มีภาพประกอบสมบูรณ์ พร้อมหน้าปก สารบัญ เนื้อหา และคำบรรยายภาพ
- แก้ไขและจัดรูปแบบ PDF ที่มีอยู่ใหม่โดยไม่ต้องใช้ซอฟต์แวร์จัดหน้ามืออาชีพ
- ดึงข้อมูลเฉพาะจาก PDF ความยาวหลายร้อยหน้า
- เปรียบเทียบความแตกต่างเล็กน้อยระหว่างสัญญาหลายเวอร์ชัน
### ใช้งาน Kimi Docs อย่างไร？
**จุดเข้าใช้งาน:**
- ทั่วไป: คลิกทางลัด Docs, Sheets หรือ Slides ในแถบด้านข้างหรือกล่องแชท
- เฉพาะทาง: คลิกปุ่ม "Docs" ที่ด้านล่างของกล่องแชท

1. **เปิดเบราว์เซอร์**: Chrome, Safari, Edge, Firefox หรือเบราว์เซอร์หลักอื่น ๆ

### วิธีที่ 2: แอปมือถือ
แอป Kimi รองรับทั้ง iOS และ Android แตะแถบงาน → สลับไปยังโหมด Docs Agent
#### วิธีที่ 3: โหมด Agent ทั่วไป
สลับไปยังโหมด K2.6 Agent แล้วป้อนงานที่เกี่ยวข้องกับเอกสาร Kimi จะเรียกใช้เครื่องมืออ่านและเขียนให้
## Kimi Sheets
Kimi Sheets เข้าใจความสัมพันธ์ของเซลล์ ตรรกะการเชื่อมโยงข้ามชีต และสร้างไฟล์ .xlsx ได้โดยตรงในเบราว์เซอร์
### ความสามารถหลัก
| ความสามารถ | คำอธิบาย |
|------------|-------------|
| **ป้อนข้อมูลจำนวนมาก** | ดึงข้อมูลจากเอกสาร เช่น ดึงข้อมูลผู้แสดงสินค้าจาก PDF ไปยังไฟล์ Excel 1,000 แถว |
| **รวมข้อมูลหลายแหล่ง** | รวมรายงาน Excel จาก 50 แผนกต่างกันเป็นสรุปบริษัทฉบับเดียว |
| **ป้อนด้วยภาษาธรรมชาติ** | ค้นหาเว็บอัตโนมัติพร้อมสร้างสเปรดชีตอัจฉริยะ |

### ใช้งาน Kimi Sheets อย่างไร？
คลิกปุ่ม "Agent" ที่ด้านล่างของกล่องแชท หรือเลือกทางลัด "Sheets" ในแถบด้านข้าง

คุณบอกได้ว่า: *"ค้นเว็บแล้วรวบรวมผลงานตีพิมพ์ล่าสุดในสาขา XX เป็นเอกสาร Excel"* หรืออัปโหลดไฟล์ Excel/CSV ที่มีอยู่แล้วระบุการดำเนินการ ดูตัวอย่างออนไลน์ แล้วดาวน์โหลดไฟล์ .xlsx
## กลุ่มผู้ใช้เป้าหมาย
| กลุ่มผู้ใช้ | กรณีการใช้งาน |
|:---|:---|
| **มืออาชีพในสำนักงาน** | สร้างข้อเสนองาน เอกสารสรุป และรายงานการประชุมได้อย่างรวดเร็ว |
| **นักวิจัย** | รวบรวมเอกสารวิจัย บันทึกการสัมภาษณ์ และรายงานอุตสาหกรรมเป็นสมุดปกขาว |
| **นักวิชาการ** | แปลงงานวิจัยและบทปริทัศน์วรรณกรรมเป็นบทสรุป คำนวณข้อมูลการทดลอง |
| **ผู้เชี่ยวชาญด้านกฎหมาย** | ใช้ความสามารถด้านการตรวจทานและคำอธิบายประกอบอันทรงพลังในการแก้ไขเอกสารกฎหมาย |
| **ผู้ประกอบการ** | สร้างแผนธุรกิจ ข้อเสนอความร่วมมือ และเอกสารสำหรับนักลงทุนได้อย่างรวดเร็ว |
| **นักวิเคราะห์การลงทุน** | ขับเคลื่อนการสร้างโมเดล DCF การพยากรณ์ทางการเงิน และการวิเคราะห์มูลค่าด้วยภาษาธรรมชาติ |
| **การตลาดและการดำเนินงาน** | รวบรวมข้อมูลหลายช่องทาง การเปรียบเทียบคู่แข่ง และการวิเคราะห์ผลแคมเปญ |
