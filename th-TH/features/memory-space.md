# พื้นที่ความจำ

## Memory คืออะไร
Kimi เรียนรู้ที่จะรับฟังอย่างแท้จริง ยิ่งคุณพูดคุยมากเท่าไหร่ Kimi ก็ยิ่งเข้าใจคุณมากขึ้นเท่านั้น นี่คือวิธีการทำงาน:

Kimi ไม่ได้ตอบสนองเฉพาะสิ่งที่อยู่ในกล่องแชทปัจจุบันเท่านั้น แต่จะบันทึกรายละเอียดสำคัญจากทุกบทสนทนา ไม่ว่าจะเป็นความชอบ นิสัย หรือสไตล์ของคุณ…

เมื่อใช้งานอย่างต่อเนื่อง Kimi จะเรียนรู้ไปเรื่อย ๆ ตลอดทุกเซสชัน และพัฒนาความเข้าใจที่มีต่อคุณให้ดียิ่งขึ้นอยู่เสมอ

คุณไม่จำเป็นต้องพูดซ้ำ Kimi จะคำนึงถึง "สิ่งที่เราเคยคุยกันมาก่อน" อย่างเป็นเชิงรุก เพื่อให้คำตอบที่ตรงประเด็นและต่อเนื่องมากขึ้น

## Kimi จดจำอะไรบ้าง
Kimi ใช้โมเดลที่ฝึกแยกต่างหาก เพื่อเลือกจดจำเฉพาะเนื้อหาในบทสนทนาที่มีคุณค่าต่อคุณ

ก่อนจะบันทึกสิ่งใด Kimi จะตั้งคำถามกับตัวเองสองข้อ:
- ผู้ใช้คนนี้คือใคร
- ผู้ใช้คนนี้ใส่ใจ ชื่นชอบ หรือต้องการหลีกเลี่ยงสิ่งใด

Kimi จะ**ไม่**จดจำข้อมูลส่วนตัวที่ไม่ได้รับอนุญาต (เช่น ข้อมูลสุขภาพ รหัสผ่าน ที่อยู่) เว้นแต่คุณจะร้องขออย่างชัดเจน

## วิธีเรียกใช้ Memory
Memory เป็นความสามารถที่ติดตั้งมาในตัวแล้ว เพียงสนทนาตามธรรมชาติก็เรียกใช้งานได้ทันที

วิธีอัปเดตหรือจัดการ Memory ของ Kimi:

**(1) สั่งงานโดยตรงในบทสนทนา (พบได้บ่อยที่สุด)**

คุณสามารถอัปเดต Memory ด้วยคำสั่งภาษาธรรมชาติได้:

| การกระทำ | สิ่งที่คุณพูดได้ | การตอบสนองของ Kimi |
|:---|:---|:---|
| เพิ่ม Memory | "จำไว้ว่าฉันชอบกาแฟ"<br>"จดไว้ว่ารหัสพนักงานของฉันคือ 9527"<br>"จำไว้ว่าฉันเป็นผู้จัดการโครงการ" | Kimi เรียกใช้เครื่องมือ Memory เพื่อบันทึก |
| อัปเดต Memory | "แก้ไขหน่อย ฉันย้ายไปนิวยอร์กแล้ว"<br>"อัปเดต: ตอนนี้ฉันเป็นวิศวกรอาวุโส" | Kimi แทนที่ Memory เดิม |
| ลบ Memory | "ลืมไปได้เลยว่าฉันชอบกาแฟ"<br>"ลบ Memory เกี่ยวกับรหัสพนักงานของฉัน"<br>"ล้าง Memory ทั้งหมด" | Kimi ลบ Memory ที่ระบุหรือทั้งหมด |

หมายเหตุ: Memory อยู่ภายใต้การควบคุมของคุณทั้งหมด ไม่ถูกนำไปใช้ฝึกโมเดล และสามารถปิดหรือล้างได้ทุกเมื่อ

**(2) จัดการผ่านการตั้งค่า (UI)**

คุณยังสามารถจัดการ Memory ผ่านหน้าตั้งค่าได้เช่นกัน:
- เว็บ / มือถือ: การตั้งค่า → การปรับแต่งส่วนบุคคล → พื้นที่ความจำ
- ที่นี่คุณสามารถดูรายการ Memory ที่บันทึกไว้ทั้งหมด
- คุณสามารถลบ Memory ที่ไม่ต้องการแล้วได้ด้วยตนเอง

### การเพิ่ม Memory
Memory จะถูกเรียกใช้โดยอัตโนมัติในบทสนทนา ตัวอย่างเช่น:
- "ฉันชื่อ xxx เพื่อน ๆ เรียกฉันว่า xxxx"
- "ฉันเป็นครูคณิตศาสตร์ระดับประถม ดังนั้นสื่อการสอนต้องเหมาะกับเด็ก"
- "กรุณาเลิกใช้อิโมจิในคำตอบของคุณ"
- "ฉันมักเขียนโค้ดด้วย C++"
- "อย่าพูดซ้ำหรือใช้เครื่องหมายวรรคตอนมากเกินไป"

### การอัปเดต Memory
ไปที่ โปรไฟล์ → การตั้งค่า → การปรับแต่งส่วนบุคคล → พื้นที่ความจำ เพื่อแก้ไขรายการ Memory แต่ละรายการ

### การลบ (ลืม) Memory
ไปที่ โปรไฟล์ → การตั้งค่า → การปรับแต่งส่วนบุคคล → พื้นที่ความจำ แล้วคลิกลบที่รายการแต่ละรายการ
