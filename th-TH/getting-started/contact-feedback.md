# ติดต่อและส่งความคิดเห็น

**ถาม: ฉันสามารถส่งความคิดเห็นได้ที่ไหน?**

เลือกช่องทางที่เหมาะสมตามประเภทความคิดเห็นของคุณ:

| ประเภทความคิดเห็น | ช่องทาง |
|--------------|---------|
| ปัญหาเกี่ยวกับผลิตภัณฑ์ | บนเว็บ: คลิกที่รูปโปรไฟล์ของคุณ (มุมล่างซ้าย) → User Feedback → Help & Feedback ในแอป: Profile → Settings → Feedback |
| ความคิดเห็นเกี่ยวกับคุณภาพการสนทนา | หลังจบการสนทนา คลิกปุ่ม **👎** แล้วอธิบายประเภทของปัญหาและจุดที่คลาดเคลื่อนโดยเฉพาะ |
| การอุทธรณ์บัญชี / การรายงาน | [support@moonshot.ai](mailto:support@moonshot.ai) |
| การสอบถามจากสื่อมวลชน | [pr@kimi.com](mailto:pr@kimi.com) |
| การสนับสนุน Kimi API | เข้าสู่ระบบที่ [Kimi Open Platform](https://platform.moonshot.ai/) เพื่อรับข้อมูลติดต่อฝ่ายบริการลูกค้าและชุมชนนักพัฒนา |
