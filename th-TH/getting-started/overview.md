# ภาพรวมของ Kimi

<Callout type="info">
Kimi คือผู้ช่วย AI ที่พัฒนาโดย Moonshot AI มาพร้อมกับ Web Search การคิดเชิงลึก การให้เหตุผลแบบหลายโหมด และการสนทนาที่รองรับบริบทยาวเป็นพิเศษในตัว
</Callout>

เข้าไปที่ [Kimi.com](https://www.kimi.com/) หรือดาวน์โหลดแอป Kimi เพื่อเริ่มแชต สร้างสรรค์ ค้นคว้า และพัฒนางาน นักพัฒนาสามารถไปที่ [แพลตฟอร์มเปิดของ Kimi](https://platform.kimi.ai/) เพื่อใช้ API และเครื่องมือต่าง ๆ ในการผสานความสามารถของ Kimi เข้ากับแอปพลิเคชันของตนเองได้
## แชตและโมเดล
Kimi มีให้เลือกหลายโมเดล คลิกปุ่มสลับโมเดลที่อยู่เหนือกล่องอินพุตเพื่อสลับโมเดล
| โมเดล | ระดับการคิด | เหมาะสำหรับ |
|-------|-------------------|----------|
| **K2.6** | Standard / High | การสนทนาและถาม-ตอบที่รวดเร็ว ตอบสนองไวกว่า |
| **K3** | Low / High / Max | งานสนทนาและงาน Agent มีความสามารถโดยรวมสูงสุด |
| **K3 Swarm** | Low / High / Max | การค้นหาขนาดใหญ่และการประมวลผลเป็นชุด เสร็จในครั้งเดียว |

<Callout type="tip">
การจะค้นหาออนไลน์หรือไม่นั้น Kimi จะตัดสินใจโดยอัตโนมัติจากคำถามของคุณ — ไม่ต้องสลับเปิด/ปิดด้วยตนเอง
</Callout>

## AI agent
Kimi เป็นมากกว่าผู้ช่วยแชต — มันคือ AI agent ที่สามารถวางแผนและดำเนินงานได้ด้วยตัวเอง:
| Agent | คำอธิบาย | ลิงก์ |
|-------|-------------|------|
| **Agent ทั่วไป** | วางแผนและทำงานให้เสร็จโดยอัตโนมัติ ทั้งการสร้างเว็บไซต์ สร้างสไลด์ Deep Research และการประมวลผลเอกสารและสเปรดชีต | [kimi.com/agent](https://www.kimi.com/agent) |
| **Agent Swarm** | รองรับการเรียกใช้เครื่องมือพร้อมกันได้กว่า 4,000 รายการ ประสานการทำงานของ Subagent ได้สูงสุด 300 ตัว สำหรับการค้นหาขนาดใหญ่ การเขียนงานยาว และการประมวลผลแบบกลุ่ม | [kimi.com/agent-swarm](https://www.kimi.com/agent-swarm) |
| **Kimi Code** | ชุดผู้ช่วยเขียนโค้ดที่ออกแบบมาเพื่อนักพัฒนา ทั้งเครื่องมือ CLI และส่วนขยายสำหรับ VS Code | [kimi.com/code](https://www.kimi.com/code) |
| **Kimi Claw** | แพลตฟอร์มอัตโนมัติบนคลาวด์ที่ไม่ต้องดีพลอย — เริ่มใช้ AI agent แบบทำงานต่อเนื่องได้ในเวลาไม่ถึง 30 วินาที พร้อมสกิลในตัวกว่า 5,000 รายการ (ClawHub) | [kimi.com/bot](https://www.kimi.com/bot) |
| **Kimi Work** | Agent ในเครื่องแบบอเนกประสงค์สำหรับผู้ทำงานด้านความรู้ สร้างขึ้นบน Kimi Code มอบพื้นฐาน Agent ในเครื่อง (สกิล งานตามกำหนดเวลา) พร้อมความสามารถของ Kimi Agent แบบออนไลน์ ทั้งการสร้างเว็บไซต์ PPT และฐานข้อมูลเฉพาะทาง | <a href="https://www.kimi.com/products/kimi-work">kimi.com/products/kimi-work</a> |

## ฟีเจอร์หลักอื่น ๆ
- **ไฮไลต์**: แก้โจทย์จากรูปภาพ สนทนาด้วยเสียง แปลภาษา ช่วยเขียนงาน
- **การจัดการไฟล์**: รองรับ PDF, Word, Excel, PPT, รูปภาพ, TXT และวิดีโอ (ไฟล์ละไม่เกิน 100 MB) สูงสุด 50 ไฟล์ต่อหนึ่งเซสชัน
- **พรีเซ็ต**: บันทึกพรอมต์ที่ใช้บ่อยไว้เรียกใช้ได้อย่างรวดเร็ว — เหมาะอย่างยิ่งสำหรับเทมเพลตพรอมต์คุณภาพสูงที่นำกลับมาใช้ซ้ำได้
