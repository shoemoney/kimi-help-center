# ภาพรวมของ Kimi

<Callout type="info">
Kimi คือผู้ช่วย AI ที่พัฒนาโดย Moonshot AI มาพร้อมกับ Web Search การคิดเชิงลึก การให้เหตุผลแบบหลายโหมด และการสนทนาที่รองรับบริบทยาวเป็นพิเศษในตัว
</Callout>

เข้าไปที่ [Kimi.com](https://www.kimi.com/) หรือดาวน์โหลดแอป Kimi เพื่อเริ่มแชต สร้างสรรค์ ค้นคว้า และพัฒนางาน นักพัฒนาสามารถไปที่ [Kimi Open Platform](https://platform.moonshot.ai/) เพื่อใช้ API และเครื่องมือต่าง ๆ ในการผสานความสามารถของ Kimi เข้ากับแอปพลิเคชันของตนเองได้
## โหมดแชต
| โหมด | คำอธิบาย |
|------|-------------|
| **Web Search (อัตโนมัติ/ปิด)** | เชื่อมต่ออินเทอร์เน็ตเพื่อข้อมูลแบบเรียลไทม์และผลการค้นหาบนเว็บ |
| **K2.6 Instant** | ตอบกลับอย่างรวดเร็วสำหรับคำถามทั่วไป |
| **K2.6 Thinking** | ให้เหตุผลแบบหลายขั้นตอนและค้นหาเชิงลึก — เหมาะอย่างยิ่งสำหรับงานเขียนโค้ด ตรรกะ หรือการวิเคราะห์ |

<Callout type="tip">
สำหรับการถาม-ตอบจากเอกสารแบบง่าย ๆ คุณสามารถปิดทั้ง Web Search และ Thinking mode ได้
</Callout>

## AI agent
Kimi เป็นมากกว่าผู้ช่วยแชต — มันคือ AI agent ที่สามารถวางแผนและดำเนินงานได้ด้วยตัวเอง:
| Agent | คำอธิบาย | ลิงก์ |
|-------|-------------|------|
| **K2.6 Agent** | วางแผนและทำงานให้เสร็จโดยอัตโนมัติ ทั้งการสร้างเว็บไซต์ สร้างสไลด์ Deep Research และการประมวลผลเอกสารและสเปรดชีต | [kimi.com/agent](https://www.kimi.com/agent) |
| **K2.6 Agent Swarm [Beta]** | รองรับการเรียกใช้เครื่องมือพร้อมกันได้สูงสุด 4,000 รายการ ประสานการทำงานของ Subagent กว่า 300 ตัว สำหรับการค้นหาขนาดใหญ่ การเขียนงานยาว และการประมวลผลแบบกลุ่ม | [kimi.com/agent-swarm](https://www.kimi.com/agent-swarm) |
| **Kimi Code** | ชุดผู้ช่วยเขียนโค้ดที่ออกแบบมาเพื่อนักพัฒนา ทั้งเครื่องมือ CLI และส่วนขยายสำหรับ VS Code | [kimi.com/code](https://www.kimi.com/code?from=kfc_overview_topbar) |
| **Kimi Claw** | แพลตฟอร์มอัตโนมัติบนคลาวด์ที่ไม่ต้องดีพลอย — เริ่มใช้ AI agent แบบทำงานต่อเนื่องได้ในเวลาไม่ถึง 30 วินาที พร้อมสกิลในตัวกว่า 5,000 รายการ (ClawHub) | [kimi.com/bot](https://www.kimi.com/bot) |

## ฟีเจอร์หลักอื่น ๆ
- **ไฮไลต์**: แก้โจทย์จากรูปภาพ สนทนาด้วยเสียง แปลภาษา ช่วยเขียนงาน
- **การจัดการไฟล์**: รองรับ PDF, Word, Excel, PPT, รูปภาพ, TXT และวิดีโอ (ไฟล์ละไม่เกิน 100 MB) สูงสุด 50 ไฟล์ต่อหนึ่งเซสชัน
- **พรีเซ็ต**: บันทึกพรอมต์ที่ใช้บ่อยไว้เรียกใช้ได้อย่างรวดเร็ว — เหมาะอย่างยิ่งสำหรับเทมเพลตพรอมต์คุณภาพสูงที่นำกลับมาใช้ซ้ำได้
