# Agentic Search

<Callout type="info">
Agentic Search ของ Kimi สร้างขึ้นบนสถาปัตยกรรม end-to-end agentic reinforcement learning ต่างจากแนวทางการจัดการเครื่องมือแบบเดิม โดยให้ AI ตัดสินใจเองว่าจะค้นหาเมื่อใด ควรเรียกใช้เครื่องมือใด และจะปรับกลยุทธ์อย่างไร — ทำให้รับมือกับงานรวบรวมและประมวลผลข้อมูลที่ซับซ้อนได้
</Callout>

เมื่อเทียบกับการค้นหาแบบจับคู่คำสำคัญแบบเดิม ความสามารถในการค้นหาของ Kimi ได้ผ่านการพัฒนาครั้งใหญ่ถึงสองช่วง:
- **Explorer Search** (ตุลาคม 2024) ผสานความเข้าใจเชิงความหมายของโมเดลภาษาขนาดใหญ่เข้ากับการสืบค้นข้อมูลแบบเรียลไทม์ พร้อมแยกย่อยคำถามที่ซับซ้อนและสืบหาแหล่งที่มาได้โดยอัตโนมัติ
- **Agentic Search** ก้าวไปไกลกว่านั้นด้วยการวางแผนและเรียกใช้เครื่องมือด้วยตนเอง รองรับการค้นหาข้อมูลทางการเงิน การสืบค้นเอกสารวิชาการ การค้นหารูปภาพ และงานหลายรูปแบบอื่น ๆ

## การตั้งค่า Web Search

<Frames
  src="./images/search/web-search.png"
  alt="Web search"
/>

Web Search (Auto/Off) ทลายกรอบเรื่องความสดใหม่ของข้อมูล มอบข้อมูลที่ทันสมัย น่าเชื่อถือ และตรวจสอบย้อนกลับได้แบบเรียลไทม์

คลิกสวิตช์ "Web search" ใต้ช่องพิมพ์แชท เมื่อเปิดใช้งาน Kimi จะพิจารณาเองว่าคำถามปัจจุบันต้องใช้ข้อมูลเรียลไทม์หรือไม่ และเรียกใช้เครื่องมือค้นหาและฐานข้อมูลเฉพาะทางอย่างชาญฉลาดเพื่อดึงและสังเคราะห์ข้อมูล

## ความสามารถหลัก

### 1. สดใหม่และน่าเชื่อถือไปพร้อมกัน
สืบค้นข้อมูลเว็บแบบเรียลไทม์ครอบคลุมแหล่งข้อมูลที่ผ่านการตรวจสอบและน่าเชื่อถือกว่า 100 แหล่ง (สำนักข่าวชั้นนำ ประกาศจากภาครัฐ แพลตฟอร์มข้อมูลทางการเงิน ฐานข้อมูลวารสารวิชาการ) — รับประกันว่าข้อมูลทั้งทันสมัยและน่าเชื่อถือ

### 2. การอ้างอิงแหล่งที่มา
คำตอบที่อิงจากการค้นหาทุกคำตอบจะมีลิงก์อ้างอิงแหล่งที่มา คลิกเข้าไปดูหน้าต้นฉบับเพื่อยืนยันความถูกต้องและบริบทได้อย่างครบถ้วน

### 3. การเข้าถึงข้อมูลทั่วโลก
รองรับการสนทนาด้วยภาษาธรรมชาติหลายภาษา Kimi สามารถค้นหาแหล่งข้อมูลที่ไม่ใช่ภาษาอังกฤษได้เอง (เช่น เอกสารทางเทคนิคภาษาญี่ปุ่น ข่าวภาษาฝรั่งเศส) และสังเคราะห์ข้อมูลหลายภาษาโดยอัตโนมัติ

## กรณีการใช้งานที่แนะนำ

- ข่าวและความเคลื่อนไหวแบบเรียลไทม์ (ข่าวด่วน ข้อมูลตลาดหุ้น การเปลี่ยนแปลงนโยบาย)
- การตรวจสอบข้อเท็จจริง (ข่าวลือออนไลน์ ข้อมูลในอดีต ระเบียบวิธีทางสถิติ)
- งานวิจัยเชิงวิชาชีพ (ข้อมูลคู่แข่ง พรมแดนความรู้ทางวิชาการ มาตรฐานอุตสาหกรรม)

## เครื่องหมายรับรองแหล่งข้อมูลที่น่าเชื่อถือ

Web Search ของ Kimi คัดกรองแหล่งข้อมูลตามสามมิติ — ความเกี่ยวข้อง ความน่าเชื่อถือ และความสดใหม่ — พร้อมกรองเว็บไซต์ที่มีความเสี่ยง เนื้อหาที่คัดลอกซ้ำ เนื้อหาเว็บคุณภาพต่ำ และข้อมูลที่ถูกแต่งขึ้นออกโดยอัตโนมัติ เพื่อให้ได้ผลลัพธ์ที่เชื่อถือได้

แหล่งข้อมูลคุณภาพสูงที่ผ่านการคัดกรองอย่างเข้มงวดของ Kimi จะถูกทำเครื่องหมายด้วยตราสัญลักษณ์รับรองความน่าเชื่อถือในคำตอบ (เช่น การรับรองเว็บไซต์ทางการ การรับรองทางวิชาการ ไอคอนรับรองสื่อ) ช่วยให้คุณระบุข้อมูลที่น่าเชื่อถือสูงได้อย่างรวดเร็ว

**กลไกการคัดกรองแหล่งข้อมูล**:
- **กรองออก**: เว็บไซต์รวบรวมข้อมูลคุณภาพต่ำ สื่อบุคคลที่ไม่ผ่านการตรวจสอบ หน้าแคชที่หมดอายุ
- **ให้ความสำคัญก่อน**: เว็บไซต์หน่วยงานราชการ สื่อที่น่าเชื่อถือ วารสารวิชาการ ช่องทางรายงานทางการเงินอย่างเป็นทางการ

### ตัวอย่างคำสั่งค้นหา

- "ค้นหาข้อมูลรายได้ของ Apple ในช่วงห้าปีที่ผ่านมา"
- "ค้นหางานวิจัยล่าสุดเกี่ยวกับการเพิ่มประสิทธิภาพการอนุมานของโมเดลภาษาขนาดใหญ่"
- "เปรียบเทียบ GDP, GDP ต่อหัว และอัตราการว่างงานของสามเศรษฐกิจที่ใหญ่ที่สุดในโลก"

### แหล่งข้อมูลที่รองรับ

| แหล่งข้อมูล | คำอธิบาย |
|--------|-------------|
| **Global Finance Data** | ข้อมูลหุ้น ฟิวเจอร์ส ดัชนี และข้อมูลทางการเงินอื่น ๆ ทั่วโลก |
| **Academic Data** | วารสาร งานวิจัย พรีปรินต์ วิทยานิพนธ์ สิทธิบัตร ฯลฯ |
| **Stock Finance Data** | ข้อมูลหุ้น ฟิวเจอร์ส ดัชนี และข้อมูลทางการเงินอื่น ๆ ของจีนและทั่วโลก |
| **World Bank Data** | GDP ประชากร การจ้างงาน การค้าของประเทศต่าง ๆ ฯลฯ |

## การค้นหาอัจฉริยะ

### การค้นหาด้วยรูปภาพ

Kimi รองรับการค้นหาและทำความเข้าใจด้วยรูปภาพ หลังจากอัปโหลดรูปภาพแล้ว Kimi สามารถเรียกใช้เครื่องมือค้นหารูปภาพโดยอัตโนมัติเพื่อระบุเนื้อหาและสืบค้นข้อมูลที่เกี่ยวข้อง

**ตัวอย่างคำสั่งค้นหา**:
- "สถานที่นี้อยู่ที่ไหน?"
- "มีม / รูปนี้เกิดอะไรขึ้น หรือคนในรูปกำลังพูดอะไร?"
- "หา McDonald's ตัวจริง"

**วิธีใช้งาน**:
- อัปโหลดรูปภาพโดยตรง (รองรับ JPG, PNG และรูปแบบอื่น ๆ)
- อธิบายเนื้อหาของรูปภาพหรือตั้งคำถามที่เกี่ยวข้องกับรูปภาพในคำสั่งของคุณ
- Kimi จะผสานการรู้จำรูปภาพเข้ากับ Web Search เพื่อบอกแหล่งที่มาของรูปภาพ รูปภาพที่คล้ายกัน และข้อมูลที่เกี่ยวข้อง

**สถานการณ์ทั่วไป**:
- ระบุวัตถุ สถานที่สำคัญ หรือรุ่นสินค้าที่ไม่รู้จัก
- ค้นหาแหล่งที่มาหรือต้นกำเนิดของรูปภาพ
- วิเคราะห์ข้อมูลในแผนภูมิหรือภาพหน้าจอและสืบค้นข้อมูลภูมิหลังที่เกี่ยวข้อง

### การเข้าถึง URL โดยตรง

Kimi Search รองรับการเข้าถึง URL โดยตรงเพื่อดึงทรัพยากรจากอินเทอร์เน็ต

<Frames
  src="./images/search/screenshot-22.png"

**วาง URL ลงในการสนทนาโดยตรง** แล้ว Kimi จะดึงและวิเคราะห์เนื้อหาของหน้านั้นโดยอัตโนมัติ

**ตัวอย่างการใช้งาน**:
- สรุปประเด็นสำคัญของบทความนี้
- ดึงข้อมูลสำคัญจาก PDF รายงานผลประกอบการนี้
- ค้นหาข้อมูลรูปภาพจาก URL

## เคล็ดลับ

<Callout type="warning">
- เลือกใช้ลิงก์ที่**เข้าถึงได้แบบสาธารณะ** (เช่น หน้าข่าว เอกสาร PDF สาธารณะ)
- บางหน้าที่**มีรหัสผ่านป้องกัน**หรือจำกัดการรวบรวมข้อมูลอาจเข้าถึงไม่ได้
- สำหรับหน้าที่**โหลดแบบไดนามิก** Kimi อาจดึงได้เพียงเนื้อหา HTML เริ่มต้นเท่านั้น
- Kimi **ไม่สามารถอ่านลิงก์การสนทนาที่แชร์มาได้** (กล่าวคือ ลิงก์ไปยังแชท Kimi อื่น ๆ)
</Callout>
