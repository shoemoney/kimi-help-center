# บัญชีและการยืนยันตัวตน

<Callout type="info">
คำถามที่พบบ่อยเกี่ยวกับบัญชีนักพัฒนา Kimi API การยืนยันตัวตน และการพิสูจน์ตัวตน
</Callout>

## บัญชีส่วนบุคคลขอใบกำกับภาษีแบบนิติบุคคลได้ไหม?
บัญชีส่วนบุคคล **ไม่สามารถรับใบกำกับภาษีแบบนิติบุคคลได้โดยตรง** หากคุณต้องการใบกำกับภาษีแบบนิติบุคคล ให้อัปเกรดบัญชีของคุณเป็นบัญชีองค์กรก่อน เมื่อยืนยันตัวตนเรียบร้อยแล้ว คุณจะสามารถขอใบกำกับภาษีในนามองค์กรของคุณได้

## อัปเกรดจากบัญชีส่วนบุคคลเป็นบัญชีองค์กรได้อย่างไร?
1. เข้าสู่ระบบคอนโซลที่ [platform.kimi.ai](https://platform.kimi.ai)
2. ไปที่ **Account Settings → Verification**
3. เลือก **Organization Verification** แล้วกรอกข้อมูลที่จำเป็น
4. ส่งเพื่อตรวจสอบ — เมื่อได้รับการอนุมัติ บัญชีของคุณจะถูกแปลงโดยอัตโนมัติ

<Callout type="tip">
ยอดคงเหลือและข้อมูลการใช้งานที่มีอยู่จะถูกเก็บรักษาไว้หลังการอัปเกรด
</Callout>

## ความแตกต่างระหว่างการยืนยันตัวตนแบบส่วนบุคคลและแบบองค์กร
| ด้าน | ส่วนบุคคล | องค์กร |
| --- | --- | --- |
| ประเภทใบกำกับภาษี | ใบกำกับภาษีส่วนบุคคล | ใบกำกับภาษีนิติบุคคล / VAT |
| Rate Limits | มาตรฐาน | มีสิทธิ์ได้ quota ที่สูงขึ้น |
| สัญญาทางธุรกิจ | — | สามารถลงนามในสัญญาได้ |
| ส่วนลดตามปริมาณ | — | ขอได้ตามความต้องการ |
| การสนับสนุนทางเทคนิค | มาตรฐาน | การสนับสนุนแบบลำดับความสำคัญ |

## อุทธรณ์การระงับบัญชีได้อย่างไร?
หากบัญชี API ของคุณถูกระงับเนื่องจากละเมิดนโยบาย:
1. ส่งอีเมลไปที่ **support@moonshot.ai** โดยตั้งหัวข้อว่า "API Account Appeal"
2. แนบข้อมูลบัญชีของคุณ (อีเมลที่ลงทะเบียนไว้) พร้อมคำอธิบายเหตุผลในการอุทธรณ์
3. ทีมงานจะตรวจสอบและตอบกลับภายใน 1–3 วันทำการ

<Callout type="info">
**อีเมลฝ่ายสนับสนุน**: support@moonshot.ai
</Callout>

## เปลี่ยนอีเมลที่ลงทะเบียนได้อย่างไร?
หากต้องการเปลี่ยนอีเมลที่ลงทะเบียนไว้ ให้ติดต่อฝ่ายสนับสนุน:
1. ส่งอีเมลไปที่ **support@moonshot.ai** โดยตั้งหัวข้อว่า "Email Change Request"
2. ระบุทั้งอีเมลปัจจุบันและอีเมลใหม่ของคุณ
3. อาจต้องมีการยืนยันตัวตนเพื่อความปลอดภัยของบัญชี

## ประโยชน์ของการยืนยันตัวตนให้เสร็จสมบูรณ์
- **Rate Limits ที่สูงขึ้น**: ผู้ใช้ที่ยืนยันตัวตนแล้วมีสิทธิ์ได้อัตราการเรียก API ที่สูงขึ้น
- **เข้าถึงฟีเจอร์ได้เต็มรูปแบบ**: ฟีเจอร์ขั้นสูงบางอย่างอาจใช้ได้เฉพาะผู้ใช้ที่ยืนยันตัวตนแล้วเท่านั้น
- **รองรับการออกใบกำกับภาษี**: บัญชีที่ยืนยันตัวตนแล้วสามารถขอใบกำกับภาษีได้
- **การสนับสนุนทางเทคนิค**: ผู้ใช้ที่ยืนยันตัวตนแล้วจะได้รับการสนับสนุนทางเทคนิคที่มีลำดับความสำคัญสูงกว่า
