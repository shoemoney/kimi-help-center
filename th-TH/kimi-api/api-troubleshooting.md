# การแก้ไขปัญหา API

<Callout type="info">
ปัญหาที่พบบ่อยและวิธีแก้ไขสำหรับนักพัฒนาที่ใช้ Kimi API
</Callout>

## จะจัดการข้อผิดพลาด 429 rate limit ได้อย่างไร?

ข้อผิดพลาด 429 หมายความว่าความถี่ในการส่งคำขอของคุณเกิน rate limit ของบัญชีปัจจุบันแล้ว วิธีแก้ไขมีดังนี้:

- ใช้กลยุทธ์ retry แบบ exponential backoff (รอ 1 วินาที, 2 วินาที, 4 วินาที… ก่อนลองใหม่)
- ควบคุมจำนวนคำขอที่ทำงานพร้อมกันด้วยกลไกคิว
- เพิ่มยอดเติมเงินสะสมเพื่ออัปเกรดระดับ rate limit ของคุณ
- ติดต่อทีมขายหากต้องการ quota ที่สูงขึ้น

## จะจัดการข้อผิดพลาดการยืนยันตัวตน 401 ได้อย่างไร?

ข้อผิดพลาด 401 หมายความว่าการยืนยันตัวตนด้วย API Key ล้มเหลว โปรดตรวจสอบสิ่งต่อไปนี้:

- ตรวจสอบให้แน่ใจว่าคัดลอก API Key ถูกต้อง (ระวังช่องว่างหน้า/หลัง)
- ตรวจสอบว่ารูปแบบส่วนหัวคำขอเป็น `Authorization: Bearer <your-api-key>`
- ยืนยันว่า API Key ยังไม่ถูกลบหรือปิดใช้งาน — ตรวจสอบได้ในคอนโซล
- ตรวจสอบว่าคุณไม่ได้ใช้คีย์จากแพลตฟอร์มอื่น (Kimi API Keys ขึ้นต้นด้วย `sk-`)

<Callout type="warning">
**รูปแบบ API Key**: Kimi API Keys ขึ้นต้นด้วย `sk-` โปรดตรวจสอบว่าคุณใช้รูปแบบคีย์ที่ถูกต้อง
</Callout>

## การอัปโหลดไฟล์มีค่าใช้จ่ายหรือไม่?

การอัปโหลดไฟล์ไม่มีค่าใช้จ่าย อย่างไรก็ตาม เมื่อคุณอ้างอิงไฟล์ที่อัปโหลดไว้ในบทสนทนา เนื้อหาของไฟล์จะถูกแปลงเป็น tokens และคิดค่าบริการเป็น input tokens ไฟล์ขนาดใหญ่จะสร้าง tokens มากขึ้น

## จะจัดการข้อผิดพลาด 403 ยอดคงเหลือไม่เพียงพอได้อย่างไร?

ข้อผิดพลาด 403 โดยทั่วไปหมายถึงยอดคงเหลือในบัญชีไม่เพียงพอ เติมเงินได้ในคอนโซล — เงินจะพร้อมใช้งานทันที คุณยังสามารถใช้ API สำหรับสอบถามยอดคงเหลือเพื่อตรวจสอบยอดปัจจุบันได้

## หากคำตอบถูกตัดขาดควรทำอย่างไร?

หากคำตอบจาก API ไม่สมบูรณ์หรือถูกตัดขาด:

- ตรวจสอบว่าพารามิเตอร์ `max_tokens` ตั้งไว้ต่ำเกินไปหรือไม่ และเพิ่มตามความเหมาะสม
- ตรวจสอบฟิลด์ `finish_reason` ในคำตอบ: `length` หมายความว่าผลลัพธ์ถูกตัดเนื่องจากถึงขีดจำกัด token; `stop` หมายความว่าจบตามปกติ
- สำหรับการสร้างข้อความยาว ควรแบ่งคำขอออกเป็นส่วนย่อย

<Callout type="tip">
**ตรวจสอบ `finish_reason`**: `length` = ถูกตัดขาด, `stop` = จบตามปกติ
</Callout>

## ฉันอัปโหลดรูปภาพผ่าน file API ได้หรือไม่?

ได้ API อัปโหลดไฟล์รองรับไฟล์รูปภาพ เมื่ออัปโหลดแล้ว สามารถอ้างอิงรูปภาพในบทสนทนาได้ สำหรับโมเดล Vision คุณยังสามารถส่งรูปภาพในข้อความโดยตรงผ่าน URL หรือการเข้ารหัส Base64 ได้ด้วย

## แหล่งข้อมูลของ Web Search คืออะไร?

ฟีเจอร์ Web Search ของ Kimi API ดึงข้อมูลสาธารณะจากอินเทอร์เน็ตแบบเรียลไทม์ ผลลัพธ์มาจากหน้าเว็บที่จัดทำดัชนีโดยเครื่องมือค้นหาหลัก การเรียกใช้ Web Search แต่ละครั้งมีค่าบริการเพิ่มเติม $0.004

## สมาชิก Kimi เกี่ยวข้องกับ API concurrency หรือไม่?

<Callout type="warning">
**แพ็กเกจสมาชิก Kimi** (เช่น Allegretto) และ **API** เป็นระบบคิดค่าบริการคนละระบบกัน จำนวน agent ที่ทำงานพร้อมกันซึ่งรวมอยู่ในแพ็กเกจสมาชิกใช้ได้เฉพาะกับผลิตภัณฑ์ Kimi สำหรับผู้ใช้ทั่วไป และไม่เกี่ยวข้องกับ API rate limit ขีดจำกัด API concurrency กำหนดตามระดับยอดเติมเงินสะสมของบัญชีคุณ
</Callout>

## ความแตกต่างระหว่าง API กับเว็บแอป Kimi

| ด้าน | Kimi Web App | Kimi API |
| --- | --- | --- |
| **กลุ่มเป้าหมาย** | ผลิตภัณฑ์สนทนาสำหรับผู้ใช้ทั่วไป | อินเทอร์เฟซสำหรับนักพัฒนาเพื่อเชื่อมต่อระบบ |
| **การเข้าถึง** | ผ่านเบราว์เซอร์ | เรียก API ด้วยโปรแกรม |
| **การคิดค่าบริการ** | ระบบสมาชิก/credit | จ่ายตามการใช้งานตามจำนวน tokens |
| **บัญชี** | ใช้บัญชีล็อกอินร่วมกัน | ใช้บัญชีล็อกอินร่วมกัน |
| **Credits** | โอนข้ามระบบไม่ได้ | โอนข้ามระบบไม่ได้ |

## มีการสร้าง PPT และ Deep Research ผ่าน API หรือไม่?

<Callout type="warning">
**การสร้าง PPT** และ **Deep Research** **ยังไม่พร้อมใช้งานผ่าน API** ในขณะนี้ ฟีเจอร์เหล่านี้เข้าถึงได้เฉพาะผ่านผลิตภัณฑ์ Kimi สำหรับผู้ใช้ทั่วไป โปรดติดตามประกาศของแพลตฟอร์มสำหรับความคืบหน้า
</Callout>

## รองรับการติดตั้งใช้งานภายในองค์กรหรือไม่?

ปัจจุบัน Kimi API ให้บริการ API แบบคลาวด์เท่านั้น และ**ไม่รองรับการติดตั้งแบบส่วนตัวภายในองค์กร** หากต้องการติดตั้งแบบส่วนตัว โปรดติดต่อทีมขายผ่าน [platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales)

## ฉันเรียกใช้ Kimi API จากนอกประเทศจีนได้หรือไม่?

Kimi API พร้อมให้บริการในต่างประเทศผ่าน `api.moonshot.ai` หากคุณพบปัญหาการเชื่อมต่อ โปรดติดต่อทีมขายเพื่อหารือเกี่ยวกับแนวทางที่เหมาะสมที่สุดสำหรับภูมิภาคของคุณ
