# การแก้ปัญหา API

<Callout type="info">
ปัญหาที่พบบ่อยและวิธีแก้ไขสำหรับนักพัฒนาที่ใช้ Kimi API
</Callout>

## จะจัดการกับข้อผิดพลาด rate limit 429 อย่างไร?

ข้อผิดพลาด 429 หมายความว่าความถี่ในการส่งคำขอของคุณเกิน rate limit ของบัญชีในปัจจุบัน วิธีแก้ไข:

- ใช้กลยุทธ์ลองใหม่แบบ exponential backoff (รอ 1 วินาที, 2 วินาที, 4 วินาที… ก่อนลองใหม่)
- ควบคุมจำนวนคำขอที่ทำงานพร้อมกันด้วยกลไกคิว
- เพิ่มยอดเติมเงินสะสมเพื่ออัปเกรดระดับ rate limit ของคุณ
- ติดต่อทีมขายหากคุณต้องการ quota ที่สูงขึ้น

## จะจัดการกับข้อผิดพลาดการยืนยันตัวตน 401 อย่างไร?

ข้อผิดพลาด 401 หมายความว่าการยืนยันตัวตนด้วย API Key ล้มเหลว ตรวจสอบสิ่งต่อไปนี้:

- ตรวจสอบให้แน่ใจว่าคัดลอก API Key ได้อย่างถูกต้อง (ระวังช่องว่างนำหน้าหรือต่อท้าย)
- ตรวจสอบว่ารูปแบบของ request header คือ `Authorization: Bearer <your-api-key>`
- ยืนยันว่า API Key ไม่ได้ถูกลบหรือปิดใช้งาน — ตรวจสอบได้ในคอนโซล
- ตรวจสอบให้แน่ใจว่าคุณไม่ได้ใช้คีย์จากแพลตฟอร์มอื่น (API Key ของ Kimi ขึ้นต้นด้วย `sk-`)

<Callout type="warning">
**รูปแบบ API Key**: API Key ของ Kimi ขึ้นต้นด้วย `sk-` ตรวจสอบให้แน่ใจว่าคุณใช้รูปแบบคีย์ที่ถูกต้อง
</Callout>

## การอัปโหลดไฟล์มีค่าใช้จ่ายหรือไม่?

การอัปโหลดไฟล์นั้นฟรี อย่างไรก็ตาม เมื่อคุณอ้างอิงไฟล์ที่อัปโหลดในการสนทนา เนื้อหาของไฟล์จะถูกแปลงเป็น token และคิดค่าใช้จ่ายเป็น input token ไฟล์ที่มีขนาดใหญ่กว่าจะสร้าง token มากกว่า

## จะจัดการกับข้อผิดพลาดยอดเงินไม่เพียงพอ 403 อย่างไร?

ข้อผิดพลาด 403 มักบ่งบอกว่ายอดเงินในบัญชีไม่เพียงพอ เติมเงินในคอนโซล — เงินจะพร้อมใช้งานทันที คุณยังสามารถใช้ API ตรวจสอบยอดเงินเพื่อดูยอดคงเหลือปัจจุบันได้

## จะทำอย่างไรหากการตอบกลับถูกตัดทอน?

หากการตอบกลับจาก API ไม่สมบูรณ์หรือถูกตัดทอน:

- ตรวจสอบว่าตั้งค่าพารามิเตอร์ `max_tokens` ต่ำเกินไปหรือไม่ และเพิ่มค่าตามความจำเป็น
- ตรวจสอบฟิลด์ `finish_reason` ในการตอบกลับ: `length` หมายความว่าผลลัพธ์ถูกตัดทอนเนื่องจากขีดจำกัด token; `stop` หมายความว่าเสร็จสมบูรณ์ตามปกติ
- สำหรับการสร้างข้อความยาว ให้พิจารณาแบ่งคำขอออกเป็นส่วน ๆ

<Callout type="tip">
**ตรวจสอบ `finish_reason`**: `length` = ถูกตัดทอน, `stop` = เสร็จสมบูรณ์ตามปกติ
</Callout>

## ฉันสามารถอัปโหลดรูปภาพผ่าน API ไฟล์ได้หรือไม่?

ได้ API การอัปโหลดไฟล์รองรับไฟล์รูปภาพ เมื่ออัปโหลดแล้ว สามารถอ้างอิงรูปภาพในการสนทนาได้ ด้วยโมเดล Vision คุณยังสามารถส่งรูปภาพในข้อความได้โดยตรงผ่าน URL หรือการเข้ารหัส Base64

## แหล่งที่มาของ web search?

ฟีเจอร์ web search ของ Kimi API ดึงข้อมูลที่เปิดเผยต่อสาธารณะจากอินเทอร์เน็ตแบบเรียลไทม์ ผลลัพธ์มาจากหน้าเว็บที่จัดทำดัชนีโดยเครื่องมือค้นหาหลัก ๆ การเรียกใช้ web search แต่ละครั้งมีค่าธรรมเนียมเพิ่มเติม $0.004

## มีความเกี่ยวข้องกันระหว่างสมาชิก Kimi กับ concurrency ของ API หรือไม่?

<Callout type="warning">
**แพ็กเกจสมาชิก Kimi** (เช่น Allegretto) และ **API** เป็นระบบการเรียกเก็บเงินที่แยกจากกัน ความสามารถในการทำงานแบบขนานของ agent ที่รวมอยู่ในแพ็กเกจสมาชิกใช้ได้เฉพาะกับผลิตภัณฑ์สำหรับผู้บริโภคของ Kimi เท่านั้น และไม่เกี่ยวข้องกับ rate limit ของ API ขีดจำกัด concurrency ของ API ถูกกำหนดโดยระดับยอดเติมเงินสะสมของบัญชีคุณ
</Callout>

## ความแตกต่างระหว่าง API กับเว็บแอป Kimi

| ด้าน | เว็บแอป Kimi | Kimi API |
| --- | --- | --- |
| **กลุ่มเป้าหมาย** | ผลิตภัณฑ์การสนทนาสำหรับผู้บริโภค | อินเทอร์เฟซการเชื่อมต่อสำหรับนักพัฒนา |
| **การเข้าถึง** | ผ่านเบราว์เซอร์ | การเรียกใช้ API ผ่านการเขียนโปรแกรม |
| **การเรียกเก็บเงิน** | ระบบสมาชิก/quota | จ่ายตามการใช้งานตาม token |
| **บัญชี** | ล็อกอินร่วมกัน | ล็อกอินร่วมกัน |
| **Credit** | ไม่สามารถโอนระหว่างระบบได้ | ไม่สามารถโอนระหว่างระบบได้ |

## การสร้าง PPT และ deep research ใช้งานผ่าน API ได้หรือไม่?

<Callout type="warning">
**การสร้าง PPT** และ **deep research** **ยังไม่พร้อมใช้งานผ่าน API** ฟีเจอร์เหล่านี้ขณะนี้เข้าถึงได้ผ่านผลิตภัณฑ์สำหรับผู้บริโภคของ Kimi เท่านั้น ติดตามประกาศของแพลตฟอร์มเพื่อรับการอัปเดต
</Callout>

## รองรับการติดตั้งแบบ on-premises หรือไม่?

ปัจจุบัน Kimi API ให้บริการ API บนคลาวด์เท่านั้น และ **ไม่รองรับการติดตั้งแบบ on-premises ส่วนตัว** สำหรับความต้องการการติดตั้งแบบส่วนตัว โปรดติดต่อทีมขายผ่าน [platform.moonshot.ai/contact-sales](https://platform.moonshot.ai/contact-sales)

## ฉันสามารถเรียกใช้ Kimi API จากนอกประเทศจีนได้หรือไม่?

Kimi API พร้อมให้บริการในระดับสากลผ่าน `api.moonshot.ai` หากคุณประสบปัญหาการเชื่อมต่อ โปรดติดต่อทีมขายเพื่อหารือเกี่ยวกับโซลูชันที่ดีที่สุดสำหรับภูมิภาคของคุณ
