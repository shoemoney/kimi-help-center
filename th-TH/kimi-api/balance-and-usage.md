# ยอดคงเหลือและการใช้งาน

Kimi API มีหลายวิธีให้คุณตรวจสอบยอดคงเหลือของบัญชีและรายละเอียดการใช้งาน ช่วยให้ติดตามปริมาณการใช้และค่าใช้จ่ายได้ง่ายขึ้น

## แดชบอร์ดคอนโซล

เข้าสู่ระบบที่ [platform.kimi.ai](https://platform.kimi.ai) แล้วไปที่หน้า **fee-detail** (รายละเอียดการเรียกเก็บเงิน) ในคอนโซลเพื่อดูข้อมูลต่อไปนี้:

- ยอดคงเหลือปัจจุบันของบัญชี
- รายละเอียดการใช้งานรายวัน
- การใช้งานและค่าใช้จ่ายแยกตามโมเดล
- แนวโน้มค่าใช้จ่ายย้อนหลัง

<Callout type="info">
ระบบจะอัปเดตการเรียกเก็บเงินรายวันภายใน **7:00 น. ของวันถัดไป** ข้อมูลการใช้งานแบบเรียลไทม์อาจล่าช้าเล็กน้อย
</Callout>

> **หมายเหตุ**: ระบบจะอัปเดตการเรียกเก็บเงินรายวันภายใน **7:00 น. ของวันถัดไป** ข้อมูลการใช้งานแบบเรียลไทม์อาจล่าช้าเล็กน้อย

## API สำหรับ Token Estimation

ก่อนส่งคำขอ คุณสามารถใช้ Token Estimation API เพื่อประเมินจำนวน token ที่การเรียกใช้นั้นจะใช้ได้ ซึ่งเป็นประโยชน์ต่อการควบคุมค่าใช้จ่าย

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "POST https://api.moonshot.ai/v1/tokenizers/estimate-token-count",
    },
  ]}
/>

ส่งรูปแบบ `messages` แบบเดียวกับคำขอ Chat Completion แล้ว API จะส่งคืนจำนวน token ที่ประเมินไว้

## API สำหรับ查询ยอดคงเหลือ

查询ยอดคงเหลือปัจจุบันของบัญชีผ่าน API ได้โดยตรง:

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "GET https://api.moonshot.ai/v1/users/me/balance",
    },
  ]}
/>

ใส่ API Key ของคุณในส่วนหัวของคำขอเพื่อดึงข้อมูลยอดคงเหลือที่ใช้ได้

## เคล็ดลับการติดตามการใช้งาน

<Callout type="tip">
**แนวทางปฏิบัติที่แนะนำ**:
- ตรวจสอบหน้า fee-detail เป็นประจำเพื่อติดตามแนวโน้มค่าใช้จ่าย
- เชื่อมต่อ Balance Query API และตั้งค่าเกณฑ์แจ้งเตือนยอดคงเหลือ
- ใช้ Token Estimation API ก่อนการเรียกใช้ที่สำคัญ เพื่อประเมินค่าใช้จ่ายล่วงหน้า
</Callout>
