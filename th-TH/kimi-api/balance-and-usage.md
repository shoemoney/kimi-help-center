# ยอดเงินและการใช้งาน

Kimi API มีหลายช่องทางให้คุณดูยอดเงินคงเหลือและรายละเอียดการใช้งานในบัญชี เพื่อช่วยติดตามการใช้งานและค่าใช้จ่ายของคุณ

## แดชบอร์ดในคอนโซล

เข้าสู่ระบบที่ [platform.moonshot.ai](https://platform.moonshot.ai) แล้วไปที่หน้า **fee-detail** (รายละเอียดการเรียกเก็บเงิน) ในคอนโซลเพื่อดู:

- ยอดเงินคงเหลือในบัญชีปัจจุบัน
- รายละเอียดการใช้งานรายวัน
- การใช้งานและค่าใช้จ่ายแยกตามโมเดล
- แนวโน้มการใช้จ่ายย้อนหลัง

<Callout type="info">
การเรียกเก็บเงินรายวันจะอัปเดตภายใน **เวลา 7:00 น. ของวันถัดไป** ข้อมูลการใช้งานแบบเรียลไทม์อาจมีความล่าช้าเล็กน้อย
</Callout>

> **หมายเหตุ**: การเรียกเก็บเงินรายวันจะอัปเดตภายใน **เวลา 7:00 น. ของวันถัดไป** ข้อมูลการใช้งานแบบเรียลไทม์อาจมีความล่าช้าเล็กน้อย

## Token Estimation API

ก่อนส่งคำขอ คุณสามารถใช้ Token Estimation API เพื่อประเมินว่าการเรียกใช้ครั้งนั้นจะใช้ token จำนวนเท่าใด ซึ่งมีประโยชน์สำหรับการควบคุมค่าใช้จ่าย

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "POST https://api.moonshot.ai/v1/tokenizers/estimate-token-count",
    },
  ]}
/>

ส่งข้อมูลในรูปแบบ `messages` แบบเดียวกับคำขอ Chat Completion แล้ว API จะคืนค่าจำนวน token โดยประมาณให้

## API ตรวจสอบยอดเงิน

ตรวจสอบยอดเงินคงเหลือในบัญชีปัจจุบันของคุณได้โดยตรงผ่าน API:

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "GET https://api.moonshot.ai/v1/users/me/balance",
    },
  ]}
/>

ใส่ API Key ของคุณไว้ในส่วนหัวของคำขอเพื่อดึงยอดเงินคงเหลือที่ใช้ได้

## เคล็ดลับการติดตามการใช้งาน

<Callout type="tip">
**แนวทางที่แนะนำ**:
- ตรวจสอบหน้า fee-detail เป็นประจำเพื่อติดตามแนวโน้มการใช้จ่าย
- เชื่อมต่อ API ตรวจสอบยอดเงินและตั้งค่าเกณฑ์แจ้งเตือนยอดเงิน
- ใช้ Token Estimation API ก่อนการเรียกใช้ที่สำคัญเพื่อประเมินค่าใช้จ่าย
</Callout>
