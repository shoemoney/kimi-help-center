# การเรียกเก็บเงินและการเงิน

<Callout type="info">
คำถามที่พบบ่อยเกี่ยวกับการเรียกเก็บเงิน ราคา และการชำระเงินของ Kimi API
</Callout>

## โครงสร้างราคาคิดอย่างไร?
Kimi API คิดค่าบริการตามจำนวน token ที่ใช้ โดย token ขาเข้าและ token ขาออกมีราคาคิดแยกกัน ราคาจะแตกต่างกันไปตามโมเดล และการใช้ Web Search จะมีค่าธรรมเนียมเพิ่มเติม $0.004 ต่อการเรียกใช้งานหนึ่งครั้ง

<Callout type="tip">
ดูรายละเอียดราคาได้ที่ [platform.kimi.ai/docs/pricing/chat](https://platform.kimi.ai/docs/pricing/chat)
</Callout>

## รองรับวิธีชำระเงินใดบ้าง?
คอนโซล API รองรับวิธีชำระเงินดังต่อไปนี้:
| วิธี | รายละเอียด |
| --- | --- |
| **บัตรเครดิต/เดบิต** | Visa, Mastercard และบัตรหลักอื่น ๆ |
| **การโอนเงินผ่านธนาคาร** | ผู้ใช้ที่ผ่านการยืนยันในนามองค์กรสามารถขอโอนเงินผ่านธนาคารได้ — ติดต่อฝ่ายขายเพื่อขอรายละเอียดบัญชีธนาคาร |

เงินที่เติมจะพร้อมใช้งานสำหรับ API ทันที
## ฉันจะขอใบแจ้งหนี้ได้อย่างไร?
1. เข้าสู่ระบบคอนโซล [platform.kimi.ai](https://platform.kimi.ai)
2. ไปที่ **การเรียกเก็บเงิน → การจัดการใบแจ้งหนี้**
3. เลือกรายการเติมเงินที่ต้องการออกใบแจ้งหนี้
4. กรอกรายละเอียดใบแจ้งหนี้ (บุคคลธรรมดาหรือธุรกิจ) แล้วส่งคำขอ
5. ใบแจ้งหนี้อิเล็กทรอนิกส์จะถูกส่งไปยังอีเมลของคุณ
