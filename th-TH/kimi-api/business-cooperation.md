# ความร่วมมือทางธุรกิจและฝ่ายขาย

<Callout type="info">
ทางเลือกความร่วมมือสำหรับลูกค้าองค์กร — ตั้งแต่ส่วนลดตามปริมาณการใช้งานไปจนถึง SLA แบบกำหนดเอง
</Callout>

Kimi API มีทางเลือกความร่วมมือหลากหลายสำหรับลูกค้าองค์กร เพื่อรองรับความต้องการทางธุรกิจในทุกขนาด
## ติดต่อทีมขายได้อย่างไร?
ไปที่ [platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales) เพื่อส่งแบบฟอร์มติดต่อ ทีมขายของเราจะติดต่อกลับภายใน 1–2 วันทำการ

<Callout type="tip">
**โปรดระบุในแบบฟอร์มที่ส่ง**:
- ชื่อบริษัทและอุตสาหกรรม
- ปริมาณการใช้งานโดยประมาณ
- กรณีการใช้งานหลัก
- รูปแบบความร่วมมือที่ต้องการ
</Callout>

## การลงนามสัญญา
ผู้ใช้ที่ยืนยันองค์กรแล้วสามารถทำข้อตกลงบริการอย่างเป็นทางการกับ Moonshot ได้:
- มีทั้งข้อตกลงบริการมาตรฐานและสัญญาที่ปรับแต่งได้ตามความต้องการ
- หลังลงนามแล้ว คุณจะสามารถชำระเงินผ่านการโอนเงินผ่านธนาคารและได้รับ SLA ระดับองค์กร
- ติดต่อทีมขายเพื่อพูดคุยเกี่ยวกับขั้นตอนโดยละเอียด

## ส่วนลดตามปริมาณการใช้งาน
ลูกค้าองค์กรที่มีปริมาณการใช้งานสูงสามารถขอรับส่วนลดพิเศษได้:
| ข้อกำหนด | รายละเอียด |
| --- | --- |
| **คุณสมบัติ** | การยืนยันองค์กร + สัญญาที่ลงนามแล้ว |
| **ระดับส่วนลด** | อิงตามปริมาณการใช้งานที่ตกลงล่วงหน้าและระยะเวลาสัญญา |
| **การสมัคร** | สมัครผ่านทีมขายโดยระบุปริมาณการใช้งานรายเดือนโดยประมาณ |

## บริการ API สำหรับองค์กร
บริการ API สำหรับองค์กรต่อยอดจากบริการ API มาตรฐาน โดยมาพร้อมกับ:
- **rate limit และ quota สำหรับ concurrency ที่สูงขึ้น**
- **ช่องทางสนับสนุนทางเทคนิคโดยเฉพาะ**
- **การรับประกัน SLA แบบกำหนดเอง**
- **สิทธิ์ทดลองใช้ฟีเจอร์ใหม่ก่อนใคร**
