# ความร่วมมือทางธุรกิจและการขาย

<Callout type="info">
ตัวเลือกความร่วมมือสำหรับลูกค้าองค์กร — ตั้งแต่ส่วนลดตามปริมาณการใช้งานไปจนถึง SLA แบบกำหนดเอง
</Callout>

Kimi API มีตัวเลือกความร่วมมือหลากหลายรูปแบบสำหรับลูกค้าองค์กร เพื่อตอบโจทย์ความต้องการทางธุรกิจในทุกระดับ
## ติดต่อทีมขายได้อย่างไร?
เข้าไปที่ [platform.moonshot.ai/contact-sales](https://platform.moonshot.ai/contact-sales) เพื่อกรอกแบบฟอร์มติดต่อ ทีมขายของเราจะติดต่อกลับภายใน 1–2 วันทำการ

<Callout type="tip">
**สิ่งที่ควรระบุในแบบฟอร์ม**:
- ชื่อบริษัทและประเภทอุตสาหกรรม
- ปริมาณการใช้งานโดยประมาณ
- กรณีการใช้งานหลัก
- รูปแบบความร่วมมือที่ต้องการ
</Callout>

## การลงนามสัญญา
ผู้ใช้ที่ผ่านการยืนยันตัวตนองค์กรสามารถทำสัญญาบริการอย่างเป็นทางการกับ Moonshot ได้:
- มีให้เลือกทั้งสัญญาบริการมาตรฐานและสัญญาแบบกำหนดเอง
- หลังลงนามแล้ว คุณจะสามารถชำระเงินผ่านการโอนเงินและได้รับ SLA ระดับองค์กร
- ติดต่อทีมขายเพื่อหารือรายละเอียดขั้นตอน

## ส่วนลดตามปริมาณการใช้งาน
ลูกค้าองค์กรที่มีปริมาณการใช้งานสูงสามารถขอรับส่วนลดพิเศษได้:
| ข้อกำหนด | รายละเอียด |
| --- | --- |
| **คุณสมบัติ** | ยืนยันตัวตนองค์กร + ลงนามสัญญา |
| **ระดับส่วนลด** | ขึ้นอยู่กับปริมาณการใช้งานที่ผูกพันและระยะเวลาของสัญญา |
| **การสมัคร** | สมัครผ่านทีมขายพร้อมแจ้งปริมาณการใช้งานต่อเดือนโดยประมาณ |

## บริการ Enterprise API
บริการ Enterprise API ต่อยอดจากบริการ API มาตรฐาน โดยเพิ่มเติม:
- **rate limit และ quota สำหรับ concurrency ที่สูงขึ้น**
- **ช่องทางสนับสนุนทางเทคนิคเฉพาะ**
- **การรับประกัน SLA แบบกำหนดเอง**
- **สิทธิ์เข้าถึงฟีเจอร์ใหม่ก่อนใคร**
