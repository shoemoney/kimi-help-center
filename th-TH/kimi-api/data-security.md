# การประมวลผลข้อมูลและความปลอดภัย

<Callout type="info">
คำถามที่พบบ่อยเกี่ยวกับความปลอดภัยของข้อมูลผู้ใช้และการคุ้มครองความเป็นส่วนตัวสำหรับ Kimi API
</Callout>

Kimi API ให้ความสำคัญอย่างยิ่งกับความปลอดภัยของข้อมูลผู้ใช้และการคุ้มครองความเป็นส่วนตัว
## ข้อมูลผู้ใช้ถูกนำไปใช้ฝึกโมเดลหรือไม่?

<Callout type="warning">
**ไม่** ข้อมูลผู้ใช้ที่ส่งผ่าน API (รวมถึงเนื้อหาที่ป้อนเข้าและผลลัพธ์ของโมเดล) **จะไม่ถูกนำไปฝึกหรือปรับปรุงโมเดลของ Kimi** ข้อมูลของคุณถูกใช้เพื่อตอบสนองคำขอ API ปัจจุบันเท่านั้น และจะไม่ถูกจัดเก็บถาวรเพื่อวัตถุประสงค์ในการฝึกโมเดล
</Callout>

## ความปลอดภัยของข้อมูลส่วนตัวได้รับการดูแลอย่างไร?
Kimi API ใช้มาตรการหลายชั้นเพื่อปกป้องข้อมูลส่วนตัวของคุณ:
| มาตรการ | คำอธิบาย |
| --- | --- |
| **การเข้ารหัสระหว่างการส่ง** | การสื่อสารผ่าน API ทั้งหมดใช้ HTTPS/TLS |
| **การแยกข้อมูล** | ข้อมูลของผู้ใช้แต่ละรายถูกแยกออกจากกันอย่างเด็ดขาด |
| **ไม่นำไปใช้ฝึกโมเดล** | ข้อมูลจาก API ไม่ถูกนำไปฝึกโมเดล |
| **การควบคุมการเข้าถึง** | ยืนยันตัวตนด้วย API Key เพื่อให้เข้าถึงได้เฉพาะผู้ที่ได้รับอนุญาตเท่านั้น |
| **การรับรองด้านการปฏิบัติตามมาตรฐาน** | แพลตฟอร์มได้รับการรับรองด้านความปลอดภัยที่เกี่ยวข้อง |

<Callout type="tip">
หากต้องการความปลอดภัยในระดับที่สูงกว่า โปรดติดต่อทีมขายเพื่อสอบถามเกี่ยวกับโซลูชันด้านความปลอดภัยระดับองค์กร
</Callout>

## การตรวจสอบความปลอดภัยของเนื้อหา
Kimi API มีกลไกตรวจสอบความปลอดภัยของเนื้อหาในตัว:
- ระบบจะตรวจจับและกรองเนื้อหาต้องห้ามโดยอัตโนมัติ (กิจกรรมที่ผิดกฎหมาย ความรุนแรง เนื้อหาทางเพศ ฯลฯ)
- เมื่อถูกตรวจพบ API จะส่งคืนการตอบกลับข้อผิดพลาดที่เหมาะสม
- การตรวจสอบเนื้อหาไม่มีการจัดเก็บหรือเปิดเผยข้อมูลต้นฉบับของคุณ
- หากคุณเชื่อว่าการตรวจสอบถูกกระตุ้นโดยไม่ถูกต้อง โปรดติดต่อฝ่ายสนับสนุนพร้อมแจ้ง `request_id`
## จะลบไฟล์ที่อัปโหลดได้อย่างไร?
ไฟล์ที่อัปโหลดผ่าน file API สามารถลบได้ทุกเมื่อ:

ใส่ API Key ของคุณในส่วนหัวของคำขอและระบุ ID ของไฟล์เพื่อลบ เมื่อลบแล้ว ไฟล์จะไม่สามารถถูกอ้างอิงได้อีก และข้อมูลของไฟล์จะถูกลบออกจากเซิร์ฟเวอร์

<Callout type="info">
คุณยังสามารถดูและลบไฟล์ที่อัปโหลดได้ที่หน้าจัดการไฟล์ในคอนโซล
</Callout>
