# รหัสข้อผิดพลาดของ API

<Callout type="info">
รหัสข้อผิดพลาดที่พบบ่อยเมื่อเรียกใช้ Kimi API พร้อมวิธีแก้ไข
</Callout>

## ตารางอ้างอิงรหัสข้อผิดพลาด

| รหัสข้อผิดพลาด | ความหมาย | วิธีแก้ไข |
| --- | --- | --- |
| 400 | คำขอไม่ถูกต้อง | ตรวจสอบรูปแบบ request body ชื่อและประเภทของพารามิเตอร์ สาเหตุที่พบบ่อย ได้แก่ JSON ผิดรูปแบบ ขาดพารามิเตอร์ที่จำเป็น หรือค่าที่ส่งอยู่นอกช่วงที่รองรับ |
| 401 | ไม่ได้รับอนุญาต | ตรวจสอบว่า API Key ถูกต้อง ยังไม่หมดอายุ และไม่ได้ถูกปิดใช้งาน ยืนยันรูปแบบ header: `Authorization: Bearer <your-api-key>` |
| 403 | ถูกปฏิเสธ (ยอดคงเหลือไม่เพียงพอ) | ยอดคงเหลือในบัญชีหมด — เติมเงินในคอนโซล บัญชีอาจถูกจำกัดการใช้งานได้เช่นกัน หากจำเป็นโปรดติดต่อฝ่ายสนับสนุน |
| 404 | ไม่พบ | ตรวจสอบ path ของ URL คำขอและชื่อโมเดล ยืนยันว่า endpoint คือ `https://api.moonshot.ai/v1/...` |
| 429 | Too Many Requests (คำขอมากเกินไป) | เกิน rate limit แล้ว ลดความถี่ในการเรียกใช้ ใช้ exponential backoff หรือติดต่อฝ่ายสนับสนุนเพื่อขอเพิ่มขีดจำกัด |
| 500 | Internal Server Error (ข้อผิดพลาดภายในเซิร์ฟเวอร์) | ปัญหาเซิร์ฟเวอร์ชั่วคราว — ลองใหม่ภายหลัง หากยังเกิดซ้ำ โปรดติดต่อ support@moonshot.ai พร้อม `request_id` |

## เคล็ดลับการแก้ไขปัญหาทั่วไป

<Callout type="tip">
1. **ตรวจสอบข้อความข้อผิดพลาดแบบเต็ม**: response JSON มี `error.message` พร้อมคำอธิบายโดยละเอียด
2. **จด request_id ไว้**: ช่วยให้ฝ่ายสนับสนุนค้นหาปัญหาได้รวดเร็ว
3. **อ้างอิงเอกสารทางการ**: ตรวจสอบให้แน่ใจว่าการเรียกใช้งานสอดคล้องกับเอกสารที่ [platform.kimi.ai](https://platform.kimi.ai)
4. **ใช้ตรรกะการลองใหม่**: สำหรับข้อผิดพลาด 429 และ 500 ให้ใช้ exponential backoff
</Callout>
