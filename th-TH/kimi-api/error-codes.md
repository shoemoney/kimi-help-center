# รหัสข้อผิดพลาดของ API

<Callout type="info">
รหัสข้อผิดพลาดที่พบบ่อยเมื่อเรียกใช้ Kimi API พร้อมวิธีแก้ไข
</Callout>

## คู่มืออ้างอิงรหัสข้อผิดพลาด

| รหัสข้อผิดพลาด | ความหมาย | วิธีแก้ไข |
| --- | --- | --- |
| 400 | Bad Request | ตรวจสอบรูปแบบเนื้อหาคำขอ ชื่อพารามิเตอร์ และชนิดข้อมูล สาเหตุที่พบบ่อย: JSON ผิดรูปแบบ ขาดพารามิเตอร์ที่จำเป็น หรือค่าอยู่นอกช่วงที่กำหนด |
| 401 | Unauthorized | ตรวจสอบว่า API Key ถูกต้อง ไม่หมดอายุ และไม่ถูกปิดใช้งาน ยืนยันรูปแบบ header: `Authorization: Bearer <your-api-key>` |
| 403 | Forbidden (Insufficient Balance) | ยอดเงินในบัญชีหมด — เติมเงินในคอนโซล บัญชีอาจถูกจำกัดการใช้งานด้วย หากจำเป็นโปรดติดต่อฝ่ายสนับสนุน |
| 404 | Not Found | ตรวจสอบเส้นทาง URL ของคำขอและชื่อโมเดล ยืนยันว่าปลายทางคือ `https://api.moonshot.ai/v1/...` |
| 429 | Too Many Requests | เกิน rate limit ลดความถี่ ใช้กลไก exponential backoff หรือติดต่อฝ่ายสนับสนุนเพื่อขอเพิ่ม limit |
| 500 | Internal Server Error | ปัญหาชั่วคราวที่ฝั่งเซิร์ฟเวอร์ — ลองใหม่ภายหลัง หากยังเกิดขึ้น โปรดติดต่อ support@moonshot.ai พร้อมแนบ `request_id` |

## เคล็ดลับการแก้ปัญหาทั่วไป

<Callout type="tip">
1. **อ่านข้อความข้อผิดพลาดให้ครบถ้วน**: JSON ในการตอบกลับมี `error.message` พร้อมคำอธิบายโดยละเอียด
2. **จดบันทึก request_id ไว้**: ช่วยให้ฝ่ายสนับสนุนค้นหาปัญหาได้รวดเร็วยิ่งขึ้น
3. **อ้างอิงเอกสารทางการ**: ตรวจสอบให้แน่ใจว่าการเรียกใช้สอดคล้องกับเอกสารที่ [platform.moonshot.ai](https://platform.moonshot.ai)
4. **เพิ่มกลไกการลองใหม่**: สำหรับข้อผิดพลาด 429 และ 500 ให้ใช้ exponential backoff
</Callout>
