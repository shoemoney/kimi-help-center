# ความสามารถของโมเดล

ด้านล่างนี้คือคำถามที่พบบ่อยเกี่ยวกับความสามารถของโมเดล Kimi API

## รองรับ JSON mode หรือไม่?

รองรับ Kimi API มี JSON Mode ซึ่งบังคับให้ผลลัพธ์ของโมเดลเป็น JSON ที่ถูกต้อง วิธีใช้งาน:

- ตั้งค่าพารามิเตอร์ `response_format` เป็น `{"type": "json_object"}` ในคำขอของคุณ
- พร้อมกันนี้ ให้สั่งโมเดลในพรอมต์อย่างชัดเจนให้ตอบกลับเป็น JSON และอธิบายโครงสร้างที่ต้องการ
- ใน JSON Mode โมเดลจะรับประกันว่าผลลัพธ์ที่ได้เป็นสตริง JSON ที่แยกวิเคราะห์ได้

## รองรับการปรับแต่งโมเดล (fine-tuning) หรือไม่?

ปัจจุบัน Kimi API **ยังไม่รองรับ** การปรับแต่งโมเดลที่ผู้ใช้เป็นผู้เริ่มเอง หากต้องการโมเดลแบบกำหนดเอง โปรดติดต่อทีมขายผ่าน [platform.moonshot.ai/contact-sales](https://www.platform.moonshot.ai/contact-sales) เพื่อสอบถามตัวเลือกการปรับแต่งสำหรับองค์กร

## รองรับ OCR หรือไม่?

โมเดล Vision ของ Kimi API มีความสามารถในการเข้าใจภาพและสามารถรู้จำข้อความภายในภาพได้ ให้ผลลัพธ์คล้ายกับ OCR:

- รองรับการรู้จำข้อความทั้งภาษาอังกฤษ จีน และภาษาอื่น ๆ อีกมากมาย
- สามารถรู้จำข้อความที่พิมพ์และลายมือเขียนบางส่วนได้
- แต่ละภาพคิดค่าใช้จ่ายในอัตราคงที่ 1,024 token
- นอกเหนือจากการรู้จำข้อความล้วนแล้ว โมเดลยังตีความตาราง แผนภูมิ และเนื้อหาที่มีโครงสร้างอื่น ๆ ภายในภาพได้อีกด้วย

## รองรับ TTS (text-to-speech) และ ASR (speech recognition) หรือไม่?

ปัจจุบัน Kimi API **ยังไม่รองรับ** TTS หรือ ASR สำหรับความสามารถด้านเสียง ควรพิจารณาใช้บริการเสียงจากบุคคลที่สามร่วมกับ Kimi API โปรดติดตามประกาศของแพลตฟอร์มเพื่อรับข่าวสารการอัปเดตฟีเจอร์ในอนาคต
