# การเลือกและเปรียบเทียบโมเดล

<Callout type="info">
เลือกโมเดล Kimi API ที่เหมาะสมโดยพิจารณาจากความสามารถ ความเร็ว และราคา
</Callout>

Kimi API มีโมเดลให้นักพัฒนาเลือกใช้หลายแบบ
## โมเดลที่ใช้งานได้
ดูรายการโมเดลทั้งหมดและข้อมูลจำเพาะโดยละเอียดได้ที่ [platform.kimi.ai/docs/models](https://platform.kimi.ai/docs/models)
เมื่อเลือกโมเดล คุณสามารถพิจารณาจาก:
| มิติ | สิ่งที่ควรพิจารณา |
| --- | --- |
| **ความยาวบริบท** | เลือกโมเดลที่รองรับบริบทขนาดใหญ่สำหรับการประมวลผลเอกสารยาว |
| **ความเร็วในการตอบสนอง** | โมเดลขนาดเล็กสำหรับสถานการณ์ที่ต้องการความหน่วงต่ำ |
| **คุณภาพการสร้างผลลัพธ์** | โมเดลระดับสูงสำหรับการให้เหตุผลที่ซับซ้อนและการเขียนเชิงสร้างสรรค์ |
| **ราคา** | เลือกโมเดลที่คุ้มค่าตามงบประมาณและปริมาณการใช้งาน |

## โมเดลด้านภาพ
โมเดลด้านภาพรองรับการป้อนรูปภาพเพื่อบรรยายภาพ ทำ OCR ตีความแผนภูมิ และอื่น ๆ:

<Callout type="info">
- แต่ละรูปภาพคิดค่าบริการแบบเหมาที่ **1,024 token** ไม่ว่าจะมีขนาดหรือความละเอียดเท่าใด
- รูปแบบที่รองรับ: JPEG, PNG, WebP ฯลฯ
- สามารถส่งรูปภาพผ่าน URL หรือการเข้ารหัส Base64
</Callout>

## ความสามารถที่ยังไม่รองรับในขณะนี้

<Callout type="warning">
- **มัลติโมดัลวิดีโอ**: ยังไม่รองรับการป้อนวิดีโอโดยตรง
- **PPT Generation API**: ยังไม่พร้อมใช้งานผ่าน API
- **Deep Research API**: ยังไม่พร้อมใช้งานผ่าน API
</Callout>

สำหรับความคืบหน้าของความสามารถเหล่านี้ โปรดติดตามประกาศจากแพลตฟอร์ม
