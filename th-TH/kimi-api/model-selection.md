# การเลือกและเปรียบเทียบโมเดล

<Callout type="info">
เลือกโมเดล Kimi API ให้เหมาะกับความสามารถ ความเร็ว และค่าใช้จ่าย
</Callout>

Kimi API มีโมเดลหลายแบบให้นักพัฒนาเลือกใช้
## โมเดลที่พร้อมใช้งาน
ดูรายชื่อโมเดลทั้งหมดและสเปกโดยละเอียดได้ที่ [platform.kimi.ai/docs/models](https://platform.kimi.ai/docs/models)
ในการเลือกโมเดล ควรพิจารณา:
| มิติ | สิ่งที่ควรพิจารณา |
| --- | --- |
| **ความยาวบริบท** | เลือกโมเดลที่รองรับบริบทขนาดใหญ่สำหรับการประมวลผลเอกสารยาว |
| **ความเร็วในการตอบกลับ** | ใช้โมเดลขนาดเบาสำหรับสถานการณ์ที่ต้องการความหน่วงต่ำ |
| **คุณภาพการสร้างคำตอบ** | ใช้โมเดลระดับสูงกว่าสำหรับการให้เหตุผลที่ซับซ้อนและงานเขียนเชิงสร้างสรรค์ |
| **ราคา** | เลือกโมเดลที่คุ้มค่าตามงบประมาณและปริมาณการใช้งาน |

## โมเดลด้านภาพ
โมเดลด้านภาพรองรับอินพุตรูปภาพสำหรับการใส่คำบรรยายภาพ, OCR, การตีความแผนภูมิ และอื่น ๆ:

<Callout type="info">
- รูปภาพแต่ละภาพคิดค่าบริการในอัตราคงที่ **1,024 tokens** ไม่ว่าจะมีขนาดหรือความละเอียดเท่าใด
- รูปแบบที่รองรับ: JPEG, PNG, WebP เป็นต้น
- ส่งรูปภาพได้ผ่าน URL หรือการเข้ารหัส Base64
</Callout>

## ความสามารถที่ยังไม่รองรับในขณะนี้

<Callout type="warning">
- **วิดีโอมัลติโมดัล**: ยังไม่รองรับการป้อนวิดีโอโดยตรง
- **PPT Generation API**: ยังไม่พร้อมให้ใช้งานผ่าน API
- **Deep Research API**: ยังไม่พร้อมให้ใช้งานผ่าน API
</Callout>

หากต้องการติดตามความคืบหน้าของความสามารถเหล่านี้ โปรดดูประกาศจากแพลตฟอร์ม
