# ราคา API

<Callout type="info">
การคิดค่าบริการ Kimi API อิงตามปริมาณ token ที่ใช้ โดยราคาแตกต่างกันตามโมเดลและฟีเจอร์
</Callout>

## พื้นฐานการคิดค่าบริการ

- **คิดค่าบริการตาม token**: การเรียก API แต่ละครั้งจะคิดค่าบริการ token ขาเข้าและ token ขาออกแยกกัน
- **หน่วย token**: 1M = 1,000,000 token
- **ราคาแตกต่างตามโมเดล**: โมเดลที่มีความสามารถสูงกว่าจะมีต้นทุนต่อ token สูงกว่า — เลือกโมเดลให้เหมาะกับกรณีการใช้งานของคุณที่สุด

## ค่าบริการฟีเจอร์เพิ่มเติม

| ฟีเจอร์ | ค่าธรรมเนียมเพิ่มเติม |
| --- | --- |
| **Web Search** | $0.004 ต่อการเรียกใช้งาน (ไม่ขึ้นกับปริมาณ token ที่ใช้) |

## การแคชบริบท

<Callout type="tip">
**การแคชบริบท** ช่วยให้คุณแคชเนื้อหาบริบทที่ใช้งานบ่อยได้ เช่น system prompt และเอกสารอ้างอิง token ที่พบในแคชจะคิดค่าบริการในอัตราพิเศษ จึงช่วยลดต้นทุนสำหรับบริบทที่ใช้ซ้ำได้อย่างมีประสิทธิภาพ
</Callout>

โปรดดูรายละเอียดราคาการแคชบริบทในเอกสารทางการ

## รายละเอียดราคา

สำหรับตารางราคาโมเดลและกฎการคิดค่าบริการฉบับสมบูรณ์:

คุณสามารถไปที่ [platform.kimi.ai/docs/pricing/chat](https://platform.kimi.ai/docs/pricing/chat)

## เคล็ดลับลดต้นทุน

<Callout type="tip">
- ตั้งค่าพารามิเตอร์ `max_tokens` ให้เหมาะสม เพื่อหลีกเลี่ยงเอาต์พุตที่ยาวเกินจำเป็น
- ใช้การแคชบริบทสำหรับ system prompt และบริบทที่ใช้ซ้ำ
- เลือกโมเดลให้เหมาะกับความซับซ้อนของงาน — ใช้โมเดลขนาดเบาสำหรับงานง่าย ๆ
- ปรับ prompt ให้กระชับ เพื่อลด token ขาเข้าที่ไม่จำเป็น
</Callout>
