# ราคา API

<Callout type="info">
Kimi API คิดค่าบริการตามปริมาณการใช้ token โดยมีราคาเฉพาะตามโมเดลและฟีเจอร์
</Callout>

## พื้นฐานการคิดค่าบริการ

- **คิดค่าบริการต่อ token**: การเรียกใช้ API แต่ละครั้งจะคิดค่าบริการแยกกันระหว่าง token ขาเข้าและ token ขาออก
- **หน่วย token**: 1M = 1,000,000 token
- **ราคาเฉพาะตามโมเดล**: โมเดลที่มีความสามารถสูงกว่าจะมีค่าใช้จ่ายต่อ token สูงกว่า เลือกโมเดลที่เหมาะกับการใช้งานของคุณมากที่สุด

## การคิดค่าบริการฟีเจอร์เพิ่มเติม

| ฟีเจอร์ | ค่าบริการเพิ่มเติม |
| --- | --- |
| **Web Search** | $0.004 ต่อการเรียกใช้หนึ่งครั้ง (ไม่ขึ้นกับปริมาณการใช้ token) |

## การแคชบริบท

<Callout type="tip">
**Context Caching** ช่วยให้คุณแคชเนื้อหาบริบทที่ใช้บ่อย (เช่น system prompt และเอกสารอ้างอิง) ได้ token ที่ตรงกับแคชจะคิดค่าบริการในอัตราส่วนลด ช่วยลดต้นทุนสำหรับบริบทที่ใช้ซ้ำได้อย่างมีประสิทธิภาพ
</Callout>

ดูราคา Context Caching โดยละเอียดได้ในเอกสารทางการ

## รายละเอียดราคา

สำหรับตารางราคาโมเดลและกฎการคิดค่าบริการฉบับสมบูรณ์:

คุณสามารถไปที่ [platform.moonshot.ai/docs/pricing/chat](https://www.platform.moonshot.ai/docs/pricing/chat)

## เคล็ดลับการลดต้นทุน

<Callout type="tip">
- ตั้งค่าพารามิเตอร์ `max_tokens` อย่างเหมาะสมเพื่อหลีกเลี่ยงผลลัพธ์ที่ยาวเกินจำเป็น
- ใช้ Context Caching สำหรับ system prompt และบริบทที่ใช้ซ้ำ
- เลือกโมเดลให้เหมาะกับความซับซ้อนของงาน ใช้โมเดลขนาดเล็กสำหรับงานง่าย ๆ
- ออกแบบ prompt ให้กระชับเพื่อลด token ขาเข้าที่ไม่จำเป็น
</Callout>
