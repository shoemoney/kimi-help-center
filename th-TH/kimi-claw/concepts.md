# แนวคิดหลักและเทอร์มินัล

## แนวคิดสำคัญ

| แนวคิด | คำอธิบาย |
|---------|-------------|
| **Memory** | ระบบความจำระยะยาวของ Kimi Claw จัดเก็บความชอบ พฤติกรรม และข้อมูลสำคัญของคุณข้ามบทสนทนาต่าง ๆ |
| **Skills** | โมดูลความสามารถที่ติดตั้งได้จากคลัง ClawHub เพื่อมอบความเชี่ยวชาญเฉพาะด้านให้แก่ Kimi Claw |
| **HEARTBEAT** | งานเบื้องหลังที่ตั้งเวลาไว้และทำงานตามตัวจับเวลา — เหมาะสำหรับการเตือนซ้ำ ดึงข้อมูล และสรุปประจำ |
| **Identity** | นิยามบทบาทของ Kimi Claw ได้แก่ ชื่อ อาชีพ และตัวตน ซึ่งคุณปรับแต่งได้ตามต้องการ |
| **Soul** | ลักษณะบุคลิกหลักและหลักการเชิงพฤติกรรมที่หล่อหลอมรูปแบบการโต้ตอบของ Kimi Claw |
| **Tools** | ชุดความสามารถที่ Kimi Claw เรียกใช้ได้ — ค้นหาเว็บ จัดการไฟล์ รันโค้ด และอื่น ๆ |
| **User** | นิยามความสัมพันธ์ระหว่างคุณกับ Kimi Claw ซึ่งกำหนดรูปแบบการโต้ตอบและการแชร์ข้อมูล |

## เทอร์มินัล

<Frames
  src="./images/concepts/screenshot-30.png"
  alt="screenshot 30"
/>

คุณสามารถเปิดอินเทอร์เฟซบรรทัดคำสั่งได้ผ่าน **Settings → Terminal** บนเว็บ แล้วรันคำสั่งเพื่อควบคุม Kimi Claw ได้โดยตรง

หรืออีกทางหนึ่ง เพียงบอก Kimi Claw ด้วยภาษาธรรมดาว่าต้องการรันคำสั่งใด แล้วมันจะรันให้คุณเอง

> หมายเหตุ: เทอร์มินัลและปลั๊กอินใช้ช่องทางการเชื่อมต่อร่วมกัน การรีสตาร์ต gateway OpenClaw จะทำให้เทอร์มินัลหลุดการเชื่อมต่อ

## ตารางอ้างอิงคำสั่ง

### ระบบ

| คำสั่ง | คำอธิบาย |
|---------|-------------|
| `/help` | แสดงข้อมูลความช่วยเหลือ |
| `/status` | ดูสถานะระบบปัจจุบัน |
| `/ping` | ทดสอบว่าการเชื่อมต่อยังทำงานอยู่หรือไม่ |
| `/cron` | จัดการงานที่ตั้งเวลาไว้ |
| `/config` | ดูหรือแก้ไขการตั้งค่า |
| `/new` | เริ่มบทสนทนาใหม่ (ล้างบริบทปัจจุบัน) |
| `/reset` | รีเซ็ต Kimi Claw |
| `/compact` | บีบอัดบริบทของบทสนทนาปัจจุบัน |
| `/stop` | หยุดงานที่กำลังทำงานอยู่ |

### Skills

| คำสั่ง | คำอธิบาย |
|---------|-------------|
| `/skills` | เรียกดู ติดตั้ง และจัดการ skills |

### งานที่ตั้งเวลาไว้

| คำสั่ง | คำอธิบาย |
|---------|-------------|
| `/cron` | ดูและจัดการตารางงาน |

### Memory

| คำสั่ง | คำอธิบาย |
|---------|-------------|
| `/memory` | ดูและจัดการความจำระยะยาว |

### การตั้งค่าและการดีบัก

| คำสั่ง | คำอธิบาย |
|---------|-------------|
| `/config` | ดูหรือแก้ไขการตั้งค่าระบบ |
| `/logs` | ดูบันทึกการทำงาน |
| `/debug` | เปิดโหมดดีบักเพื่อการวินิจฉัยอย่างละเอียด |
