# ขีดจำกัดของบทสนทนา

เมื่อบริบทของบทสนทนายาวเกินไปจนเกินขีดจำกัด token ของโมเดล Kimi Claw อาจหยุดตอบสนองหรือแสดงข้อผิดพลาด

**วิธีแก้ไข：**

- พิมพ์ `/new` เพื่อเริ่มบทสนทนาใหม่และล้างบริบทปัจจุบัน
- หากยังเกิดข้อผิดพลาดหลังจากใช้ `/new` อาจมี Skills โหลดอยู่ในหน่วยความจำมากเกินไป ลองทำดังนี้:
  - `/skills` — ตรวจสอบสกิลที่ติดตั้งไว้และถอนการติดตั้งรายการที่ไม่จำเป็น
  - `/compact` — บีบอัดบริบทปัจจุบันเพื่อคืนพื้นที่
  - `/reset` — รีเซ็ต Kimi Claw ทั้งหมดเป็นทางเลือกสุดท้าย

## ถึงขีดจำกัด rate limit ของ API แล้ว?

หมายความว่าคุณใช้คำขอจนถึงเพดานความถี่แล้ว รอสักครู่แล้วลองอีกครั้ง

**วิธีตรวจสอบ quota และ rate limit ของคุณ:**

1. ไปที่ [kimi.com/code](https://kimi.com/code)
2. เปิด **Console**
3. คลิก **View Quota & Rate Limits** เพื่อดูปริมาณการใช้งานและเพดานปัจจุบัน

หากคุณถึง rate limit บ่อยครั้ง ลองเว้นระยะระหว่างงานหรืออัปเกรดเป็นระดับสมาชิกที่สูงขึ้นเพื่อเพิ่มปริมาณการประมวลผล
