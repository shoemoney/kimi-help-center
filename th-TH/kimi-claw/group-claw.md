# ภาพรวม Claw Group Chat

Claw Group Chat คือพื้นที่ความร่วมมือแบบหลายเอเจนต์ที่ Kimi มอบให้ คุณสามารถสร้างกลุ่มแชท เชิญ Claw หลายตัวเข้าร่วม แล้วให้พวกมันแบ่งงานกันทำงานที่ซับซ้อนให้สำเร็จภายใต้การประสานงานของ Kimi

## บทบาทหลักในกลุ่มแชท

| บทบาท | ใคร | หน้าที่ |
|------|-----|-----------------|
| **Conductor** | Kimi กำหนดให้โดยอัตโนมัติ | ผู้บัญชาการของกลุ่ม — เข้าใจเป้าหมาย แบ่งย่อยงาน และสั่งการ Claw ตามนั้น |
| **Claw** | KimiClaw / OpenClaw / Android Claw ของคุณ | ดำเนินงานเฉพาะเจาะจงและรายงานผลลัพธ์ |

## ควรใช้กลุ่มแชทเมื่อใด?

กลุ่มแชทเหมาะที่สุดเมื่อ:

- งานต้องอาศัย Claw หลายตัวทำงานร่วมกัน โดยเฉพาะเมื่อข้ามหลายคน หลายอุปกรณ์ หรือหลายขอบเขตสิทธิ์
- งานที่ซับซ้อนหรือใช้เวลานานเป็นห่วงโซ่ต้องการการวางแผน แบ่งย่อย และติดตามอย่างเป็นเอกภาพโดยโมเดลผู้บัญชาการ
- คุณต้องการเปิดเวิร์กโฟลว์เพื่อให้สมาชิกในทีมร่วมสังเกตการณ์หรือมีส่วนร่วม

**กลุ่มแชทกับแชทแบบตัวต่อตัว:** ในแชทแบบตัวต่อตัว คุณสั่งการ Claw เพียงตัวเดียว ส่วนในกลุ่มแชท Kimi Conductor จะนำ Claw หลายตัวให้ทำงานร่วมกันเพื่อบรรลุเป้าหมายที่ใหญ่ขึ้น

## คู่มือการใช้งาน

### สร้างกลุ่มแชท

<Frames
  src="./images/group-chat/create-group.png"
  alt="สร้างกลุ่มแชท — ขั้นตอนที่ 1"
/>

1. คลิก **+** ในแถบด้านข้างของ Kimi Claw จากนั้นเลือก **Start Group Chat**
2. กรอก **Group Name** (จำเป็น) และ **Group Goal** (จำเป็น — อธิบายว่าคุณต้องการให้กลุ่มแชทนี้ทำอะไรให้สำเร็จ)
3. เลือก Claw ที่คุณต้องการรวมไว้จาก Claw ที่เชื่อมโยงไว้ จากนั้นคลิก **Create**
4. Kimi จะกำหนด Kimi Conductor ให้โดยอัตโนมัติ และกลุ่มแชทก็พร้อมใช้งานทันที

### ส่งข้อความในกลุ่มแชท

| วิธีส่ง | ผลลัพธ์ |
|----------------|--------|
| ส่งข้อความตรง (ไม่ใส่ @) | Kimi Conductor ตัดสินใจว่าจะตอบหรือไม่ อาจจัดการเงียบ ๆ ในเบื้องหลัง |
| @Claw ตัวใดตัวหนึ่ง | ข้อความถูกส่งไปยัง Claw ตัวนั้นเท่านั้น |
| @Claw หลายตัว | กระจายไปยัง Claw ทุกตัวที่เลือก โดยมี Kimi Conductor เป็นผู้ประสานงาน |
| @Kimi | การเรียกสั่งงานอย่างชัดเจน — ใช้เพื่อแจ้งความต้องการหรือขอให้วางแผนงาน |

### ดู Threads

Kimi Conductor จะแบ่งงานที่ซับซ้อนออกเป็น **Threads** หลายอัน โดยมอบหมาย Claw ที่เหมาะสมให้ติดตามแต่ละอัน Claw แต่ละตัวใน Thread มีบริบทของงานย่อยของตนเองที่แยกออกจากหน่วยความจำของกลุ่มแชทหลัก

### เชิญสมาชิกภายนอก

เจ้าของกลุ่มสามารถสร้างลิงก์เชิญหรือ QR code เพื่อเชิญผู้ใช้คนอื่นได้ ผู้ที่ได้รับเชิญสามารถเลือก:

- **เข้าร่วมคนเดียว** — เข้าร่วมการสนทนาในฐานะผู้ใช้
- **นำ Claw ของตนเองมาด้วย** — Claw ของพวกเขาจะเข้าร่วมกลุ่มในฐานะ Worker เพื่อทำงานร่วมกัน

<Callout type="warning">
ลิงก์เชิญอาจหมดอายุหลังจากผ่านเวลาที่กำหนด
</Callout>

### จัดการสมาชิกกลุ่มและสิทธิ์

**การจัดการสมาชิกกลุ่ม** — ผู้ดูแลกลุ่มแชทสามารถ:

- เชิญหรือลบสมาชิกคนใดก็ได้ (รวมถึง Claw ของผู้ใช้คนอื่น)
- ควบคุมสิทธิ์การพูดของผู้ใช้ทั่วไป (เปิดใช้งานโดยค่าเริ่มต้น)
- ดูและแก้ไขชื่อกลุ่มและเป้าหมายกลุ่มในการตั้งค่ากลุ่ม

**การตั้งค่าสิทธิ์ของกลุ่ม** — การมองเห็นกลุ่มแชทตั้งค่าเริ่มต้นเป็น **มองเห็นได้เฉพาะสมาชิก** เมื่อตั้งเป็น **มองเห็นได้ทุกคน** กลุ่มแชทจะสามารถแชร์สาธารณะผ่านลิงก์ได้ ผู้ชมสามารถอ่านเนื้อหาได้แต่ไม่สามารถส่งข้อความ

## เชื่อม Claw เข้ากับกลุ่มแชท

ก่อนเพิ่ม Claw เข้ากลุ่มแชท ตรวจสอบให้แน่ใจว่าคุณมีอินสแตนซ์ Claw ที่พร้อมใช้งาน รองรับวิธีเชื่อมต่อสองแบบ:

### KimiClaw (โฮสต์บนคลาวด์)

KimiClaw คือ Claw ที่ Kimi ปรับใช้ไปยังคลาวด์ด้วยคลิกเดียว — ไม่ต้องตั้งค่าเซิร์ฟเวอร์

1. ไปที่ **Add New Bot** แล้วเลือกแท็บ **On Cloud Server** เพื่อสร้าง KimiClaw บนคลาวด์ คุณยังสามารถเลือกปรับใช้บน PC หรือโทรศัพท์ Android ได้
2. Kimi จะกำหนดค่าให้เสร็จโดยอัตโนมัติ รวมถึงการเลือกโมเดลและ web search
3. หลังสร้างเสร็จ ให้เลือก Claw นี้เมื่อตั้งค่ากลุ่มแชทของคุณ

<Callout type="info">
การปรับใช้ด้วยคลิกเดียวต้องใช้แผนสมาชิก Allegretto ขึ้นไป
</Callout>

### เชื่อมโยง OpenClaw ที่มีอยู่

OpenClaw จากบุคคลที่สามคือ Claw ที่ไม่ใช่ของ Kimi ซึ่งปรับใช้บนอุปกรณ์ของคุณเอง (Mac / Windows / Linux / Android)

<Frames
  src="./images/group-chat/link.png"
  alt="เชื่อมโยง OpenClaw ที่มีอยู่"
/>

1. เลือก **Link Existing OpenClaw**
2. ทำตามคำแนะนำเพื่อติดตั้งปลั๊กอิน Kimi บนอุปกรณ์ที่รัน OpenClaw
3. เมื่อติดตั้งแล้ว OpenClaw จะปรากฏในรายการ Claw ที่พร้อมใช้งานเมื่อตั้งค่ากลุ่มแชท

## เคล็ดลับการใช้งาน

### ตั้งกฎกลุ่มผ่าน Kimi Conductor

<Frames
  src="./images/group-chat/conductor.png"
  alt="ตั้งกฎกลุ่มผ่าน Kimi Conductor"
/>

กฎกลุ่มคือคำสั่งถาวรสำหรับกลุ่มแชทของคุณ Kimi และ Claw ทุกตัวจะอ่านกฎกลุ่มก่อนเริ่มงานใด ๆ ดังนั้นทุกสิ่งที่คุณเขียนไว้ที่นี่จะมีผลโดยอัตโนมัติ โดยไม่ต้องพูดซ้ำทุกครั้ง

**วิธีตั้งกฎกลุ่ม** — บอก Kimi ว่าต้องการเพิ่มกฎอะไรด้วยภาษาธรรมดา แล้ว Kimi จะอัปเดตให้ ตัวอย่างเช่น:

<CodePreview

      name: "prompt.txt",
      language: "text",
      content: "Kimi, set the language of all reports to English.",
    },
  ]}
/>

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "All future analyses must include data sources.",
    },
  ]}
/>

หลังจากได้รับคำสั่งของคุณ Kimi จะแก้ไขกฎกลุ่มและแจ้งทุกคนในกลุ่มว่ากฎได้รับการอัปเดตแล้ว

**สิ่งที่ควรใส่ในกฎกลุ่ม** — กฎกลุ่มควรครอบคลุมข้อกำหนดที่ใช้อย่างสม่ำเสมอในกลุ่มแชทนี้ เช่น:

- **รูปแบบผลลัพธ์** — เทมเพลตรายงาน รูปแบบไฟล์ ว่าจะใส่สารบัญหรือไม่
- **ภาษาและสไตล์** — เป็นทางการหรือเป็นกันเอง การเลือกภาษา ข้อจำกัดความยาว
- **ข้อจำกัดในการทำงาน** — ข้อจำกัดด้านแหล่งข้อมูล หัวข้อต้องห้าม การตรวจสอบที่จำเป็นก่อนส่งมอบ
- **การแบ่งบทบาท** — Claw ตัวใดรับผิดชอบงานประเภทใด

### ดูพื้นที่ทำงาน

Kimi Conductor จะส่งผลลัพธ์สำคัญไปยังแชทหลัก หากต้องการดูไฟล์ทั้งหมดที่ Claw สร้างขึ้นระหว่างกระบวนการ ให้คลิก **Workspace** เพื่อแสดงตัวอย่างและดาวน์โหลดผลลัพธ์

## เทมเพลตเริ่มต้นอย่างรวดเร็ว

### คุณอยากได้ยินการปะทะกันของมุมมอง

แทนที่จะถาม AI ตัวเดียวเพื่อขอคำแนะนำที่สมดุล ให้มอบหมาย Claw ต่าง ๆ ให้โต้แย้งจากจุดยืนที่ต่างกัน คุณค่าของวิธีนี้คือความขัดแย้งของบทบาทช่วยอุดจุดบอด — AI ตัวเดียวจะไม่ท้าทายตัวเอง แต่ Claw หลายตัวจะท้าทายซึ่งกันและกัน

## คำถามที่พบบ่อย

### ควรทำอย่างไรหาก @Claw ในกลุ่มแชทแล้วไม่มีการตอบกลับ?

ก่อนอื่น ยืนยันสถานะของ Claw ในแชทส่วนตัว หากตัดการเชื่อมต่ออยู่ที่นั่น ให้ดู[คู่มือการแก้ปัญหา Kimi Claw](/help/kimi-claw/troubleshooting) เพื่อแก้ไข

หากแชทส่วนตัวตอบกลับตามปกติ คุณสามารถขอให้ Kimi วินิจฉัยเซสชันของกลุ่มได้:

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "Please find the groupId of the group \"xxx Chat Room\" and check the status of the group chat session.",
    },
  ]}
/>

### ควรทำอย่างไรหาก Claw ในกลุ่มแชทตอบไม่หยุด?

ส่ง `/stop` ไปยังแชทหลัก คำสั่งนี้จะขัดจังหวะการแสดงผลของ Claw โดยบังคับ
