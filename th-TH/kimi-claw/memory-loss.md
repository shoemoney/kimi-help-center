# การลืมความจำและบริบท

## ทำไมการสนทนาเมื่อวานถึงหายไป?

OpenClaw จะรีเซ็ตการสนทนาโดยอัตโนมัติ**ทุกวันเวลา 04:00 น.** เพื่อป้องกันไม่ให้บริบทที่ยาวเกินไปทำให้เกิดการหลอนหรือคุณภาพคำตอบลดลง

หากต้องการปรับเวลาที่จะให้รีเซ็ต คุณสามารถแก้ไขตารางเวลาได้ใน `config.yaml`

**แนวทางที่แนะนำ:** สำหรับสิ่งสำคัญใด ๆ ไม่ว่าจะเป็นความชอบ รายละเอียดโปรเจกต์ หรือคำสั่งที่ใช้ซ้ำเป็นประจำ ให้บอก Kimi Claw อย่างชัดเจนให้บันทึกไว้ว่า _“จำสิ่งนี้ไว้ใน Memory”_ ข้อมูลที่จัดเก็บใน Memory จะคงอยู่แม้การสนทนาจะถูกรีเซ็ต

## Kimi Claw ลืมความจำหรือ?

การรีเซ็ตประจำวันเวลา 04:00 น. จะล้างบริบทของการสนทนาที่กำลังใช้งานอยู่ หากมีสิ่งใดที่ไม่ได้บันทึกลงใน **Memory** สิ่งนั้นก็จะหายไป

**วิธีแก้ไข:**
- ระหว่างการสนทนา ให้พูดว่า _“จำ X ไว้ใน Memory”_ แล้ว Kimi Claw จะเขียนข้อมูลนั้นลงในที่จัดเก็บระยะยาว
- ตรวจสอบความจำที่จัดเก็บไว้ได้ผ่าน **Workspace → AGENTS.md → #MEMORY**

- ใช้คำสั่ง `/memory` ได้ตลอดเวลาเพื่อดูและจัดการความจำที่บันทึกไว้

## ความจำจะถูกเก็บไว้นานแค่ไหนหลังจากการสมัครสมาชิกสิ้นสุด?

ไฟล์ความจำจะอยู่ใน Workspace ของคุณ และคุณสามารถดูหรือดาวน์โหลดได้ตลอดเวลา

- หลังจากสมาชิกหมดอายุ อินสแตนซ์บนคลาวด์จะ**ถูกเก็บรักษาไว้ 7 วัน**
- หากต่ออายุภายใน 7 วัน ข้อมูลทั้งหมดทั้งความจำ การตั้งค่า และทักษะ จะถูกกู้คืนอย่างสมบูรณ์
- หลังจาก 7 วัน อินสแตนซ์อาจถูกเรียกคืนและข้อมูลจะถูกลบอย่างถาวร
- ฟีเจอร์การส่งออก/สำรองข้อมูลความจำกำลังอยู่ระหว่างการพัฒนาเพื่อให้ย้ายข้อมูลได้ง่ายขึ้น
