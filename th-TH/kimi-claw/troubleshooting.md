# การแก้ไขปัญหาทั่วไป

หน้านี้รวบรวมรหัสข้อผิดพลาดที่พบบ่อยและตัวเลือกการซ่อมแซมด้วยตนเองสำหรับ Kimi Claw

## รหัสข้อผิดพลาดที่พบบ่อย

| รหัส | ความหมาย | สิ่งที่ควรทำ |
|------|---------|------------|
| **400** | Bad Request — ข้อมูลที่ป้อนไม่ถูกต้องหรือพารามิเตอร์ไม่ถูกต้อง | ตรวจสอบข้อความของคุณว่ามีเนื้อหาที่ไม่รองรับหรือไม่ แล้วลองใหม่อีกครั้ง |
| **401** | Unauthorized — การยืนยันตัวตนล้มเหลว | ออกจากระบบ Kimi แล้วเข้าสู่ระบบใหม่ หากปัญหายังคงอยู่ ให้ตรวจสอบข้อมูลรับรอง API ในการตั้งค่า Kimi Claw |
| **403** | Forbidden — สิทธิ์ไม่เพียงพอ | ตรวจสอบว่าระดับสมาชิกของคุณรองรับฟีเจอร์ที่ใช้งานอยู่ และตรวจสอบให้แน่ใจว่าบัญชีของคุณไม่ถูกจำกัด |
| **429** | Too Many Requests — เกิน rate limit | รอสักครู่แล้วลองใหม่อีกครั้ง ดูรายละเอียดเกี่ยวกับการตรวจสอบ quota ได้ที่ [ขีดจำกัดการสนทนา](/kimi-claw/conversation-limits) |
| **500** | Internal Server Error — เกิดข้อผิดพลาดบางอย่างที่ฝั่งเซิร์ฟเวอร์ | รอสักครู่แล้วลองใหม่อีกครั้ง หากเกิดขึ้นซ้ำๆ ให้ใช้ตัวเลือกการซ่อมแซมด้วยตนเองด้านล่าง หรือติดต่อฝ่ายสนับสนุน |

## ตัวเลือกการซ่อมแซมด้วยตนเอง

Kimi Claw มีเครื่องมือซ่อมแซมในตัวที่เข้าถึงได้จาก **Settings** บนเว็บ:

| ตัวเลือก | สิ่งที่ทำงาน |
|--------|--------------|
| **Restart Kimi Claw** | รีสตาร์ทการเชื่อมต่อ gateway แก้ไขปัญหาชั่วคราวส่วนใหญ่ได้ (เช่น บริดจ์หลุดการเชื่อมต่อ หรือค้างชั่วคราว) |
| **Repair Kimi Claw** | เรียกใช้การวินิจฉัยอัตโนมัติที่ตรวจจับและแก้ไขปัญหาการตั้งค่า ลองใช้ตัวเลือกนี้เมื่อการรีสตาร์ทง่ายๆ ไม่ได้ผล |
| **Restore Initial Settings** | รีเซ็ต Kimi Claw กลับสู่สถานะเริ่มต้น ไฟล์ในเวิร์กสเปซและ Memory จะยังคงอยู่ แต่ต้องตั้งค่าการเชื่อมต่อแพลตฟอร์มแชท (เช่น Telegram) ใหม่ ใช้เป็นทางเลือกสุดท้าย |

## ขั้นตอนการส่งต่อปัญหา

หากตัวเลือกการซ่อมแซมด้วยตนเองไม่สามารถแก้ไขปัญหาได้:

1. เรียกใช้ `/logs` ใน Terminal เพื่อบันทึกผลลัพธ์ข้อผิดพลาดล่าสุด
2. เรียกใช้ `/debug` เพื่อเปิดใช้งานการวินิจฉัยแบบละเอียด
3. ติดต่อ **support@moonshot.ai** พร้อมรายละเอียดข้อผิดพลาดและบันทึกที่เกี่ยวข้อง
