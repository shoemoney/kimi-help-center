# สิทธิประโยชน์ของ Kimi Code

Kimi Code คือบริการที่รวมอยู่ในแพ็กเกจสมาชิก Kimi มอบการสนับสนุนและฟีเจอร์ด้านการเขียนโค้ด เพื่อช่วยให้สมาชิกทำงานด้านการเขียนโปรแกรมในเวิร์กโฟลว์การพัฒนาส่วนตัวได้อย่างมีประสิทธิภาพยิ่งขึ้น

> โปรดทราบว่าสิทธิประโยชน์นี้มีไว้สำหรับการพัฒนาส่วนตัวเท่านั้น ไม่เหมาะกับการใช้งานในรูปแบบการพัฒนาระดับองค์กร หากต้องการใช้งานสำหรับองค์กร โปรดไปที่ [แพลตฟอร์มเปิดของ Kimi](https://platform.kimi.ai/)

## การเรียกเก็บเงิน

- การใช้งาน Kimi Code **รวมอยู่ในค่าสมัครสมาชิกแล้ว** โดยไม่มีค่าใช้จ่ายเพิ่มเติม
- Kimi Code **ใช้เครดิตชุดเดียวกับแพ็กเกจสมาชิก Kimi ของคุณ** — คำขอจาก CLI, VS Code และเครื่องมือของบุคคลที่สามล้วนถูกหักจากเครดิตนี้ แต่ละแพ็กเกจมีจำนวนเครดิตแตกต่างกัน
- ระบบจะใช้ เครดิต โบนัสก่อนหัก เครดิต ของแพ็กเกจ

<Callout type="warning">
**ระบบสมาชิกใหม่กำลังจะมาถึงเร็ว ๆ นี้** สิทธิประโยชน์สมาชิก Kimi และสิทธิประโยชน์ Kimi Code จะถูกแยกออกจากกัน เพื่อให้คุณซื้อแยกกันได้ตามต้องการ — ยืดหยุ่นกว่าเดิม **ผู้ที่สมัครสมาชิกอยู่แล้วจะไม่ได้รับผลกระทบ** หากต้องการใช้สิทธิประโยชน์แบบรวมต่อไป โปรดซื้อแพ็กเกจปัจจุบันของคุณก่อนที่ระบบใหม่จะเปิดใช้งาน
</Callout>

## การรีเฟรช เครดิต

เครดิต จะรีเฟรชทุก ๆ รอบ **7 วัน**:

- เริ่มนับตั้งแต่วันที่สมัครสมาชิก (D1) โดย เครดิต จะรีเฟรชทุก 7 วัน
- ช่วงเวลารีเฟรช: D1–D7, D8–D14, D15–D21, D22–D28
- เครดิต ที่ใช้ไม่หมด**จะไม่**ยกยอดไปยังรอบถัดไป

> วางแผนการใช้งานในแต่ละสัปดาห์เพื่อใช้ เครดิต ให้คุ้มค่าที่สุด

## เครื่องมือที่รองรับ

สิทธิประโยชน์ของ Kimi Code ใช้งานได้กับเครื่องมือต่อไปนี้:

| เครื่องมือ | คำอธิบาย |
| --- | --- |
| **Kimi Code CLI** | AI agent แบบบรรทัดคำสั่งอย่างเป็นทางการของ Kimi |
| **Claude Code** | ผู้ช่วยเขียนโค้ดแบบบรรทัดคำสั่งจาก Anthropic |
| **Roo Code** | ส่วนขยายเขียนโค้ดด้วย AI สำหรับ VS Code |

การใช้ Kimi Code API Key ของคุณกับแพลตฟอร์มหรือเครื่องมือที่ไม่ได้อยู่ในรายการข้างต้นอาจถือเป็นการใช้งานที่ไม่เหมาะสม และอาจส่งผลให้ถูกจำกัดการเข้าถึง โปรดใช้เครื่องมือที่รองรับตามรายการข้างต้นเพื่อประสบการณ์และความครอบคลุมที่ดีที่สุด

## Extra Usage

เมื่อเครดิตในแพ็กเกจของคุณหมด คุณสามารถส่งคำขอต่อได้ด้วยยอดคงเหลือ **Extra Usage** โดยไม่ต้องรอการรีเฟรช เฉพาะสมาชิกที่สมัครแล้วเท่านั้นที่เปิดใช้งานได้ และ **Kimi บนเว็บกับ Kimi Code ใช้ยอด Extra Usage ชุดเดียวกัน** (เติมครั้งเดียว ใช้ได้ทั้งสองที่) ดูเงื่อนไขทั้งหมดได้ที่ [ข้อตกลง Extra Usage](https://www.kimi.com/user/agreement/extra-usage-rules-cn)

### ช่องทางการเติม

- **จากเว็บไซต์หลัก**: เปิด[หน้าการสมัครสมาชิก](https://www.kimi.com/membership/subscription?tab=quota) ของ Kimi เลื่อนไปที่โมดูล «Extra Usage» ด้านล่าง เลือกจำนวนเงิน แล้วชำระเงินให้เสร็จ
- **จาก Kimi Code Console**: เมื่อการใช้งานรายสัปดาห์หรือรอบ 5 ชั่วโมงของคุณเกิน **80%** การ์ดความคืบหน้าจะแสดงปุ่ม **ซื้อ Extra Usage** ที่พาไปยังหน้าการสมัครสมาชิก

### การเปิดใช้งานและจัดการ

เปิดสวิตช์ «Extra Usage»; เมื่อเครดิตในแพ็กเกจหมด ระบบจะหักจากยอด Extra Usage โดยอัตโนมัติ คลิก **ตั้งค่า** ในโมดูลเพื่อเปิด **วงเงินใช้จ่ายรายเดือน** และกำหนดจำนวนสูงสุดที่ใช้ได้ในเดือนนี้ แถบความคืบหน้าจะแสดงการใช้ Extra Usage ของเดือนนี้แบบเรียลไทม์

### การเรียกเก็บเงินและกฎเกณฑ์

- **การเรียกเก็บเงิน**: ตามการใช้งานจริง — ยิ่งอ่านและสร้างเนื้อหามากและงานยิ่งซับซ้อน ค่าใช้จ่ายยิ่งสูง ยอดคงเหลือแสดงเป็นเงินหยวน (RMB) ตามอัตราที่แสดงบนแพลตฟอร์ม ราคา Extra Usage ใกล้เคียงกับราคา API อย่างเป็นทางการของ [Kimi Open Platform](https://platform.kimi.com); หากใช้งานหนัก การอัปเกรดแพ็กเกจมักคุ้มค่ากว่า
- **ลำดับการหัก**: เครดิตที่มีกำหนดเวลา เช่น แพ็กเกจ จะถูกหักก่อน; **Extra Usage หักเป็นลำดับสุดท้าย** เพื่อเป็นตัวสำรอง เมื่อเปิดใช้แล้ว แม้เครดิตแพ็กเกจจะหมด Extra Usage ก็ถูกใช้อย่างต่อเนื่อง งานจะไม่หยุดหรือเกิดข้อผิดพลาด
- **การจำกัดวงเงิน**: เปิด «วงเงินใช้จ่ายรายเดือน» ในการตั้งค่าเพื่อจำกัดจำนวน Extra Usage ที่ใช้ได้ในเดือนนี้; หากไม่เปิด จะไม่มีการจำกัด
- **อายุการใช้งานและการสะสม**: ยอดคงเหลือไม่หมดอายุและสะสมข้ามการเติมได้ ยังใช้ได้หลังแพ็กเกจหมดอายุ แต่ไม่สามารถเติมได้ในช่วงที่ขาดสมาชิก — ต้องสมัครใหม่ก่อนจึงจะเติมได้อีก
- **การคืนเงิน**: โดยทั่วไปไม่สามารถคืนเงิน โอน หรือแลกเป็นเงินสดได้

<Callout type="info">
ตัวอย่างการเรียกเก็บเงิน (เพื่อให้เห็นภาพคร่าว ๆ อัตราจริงอ้างอิงตามแพลตฟอร์ม): คำของ่าย ๆ (เช่น «แนะนำเพลงร็อกสักเพลง») ราคาประมาณ **¥0.03**; งานซับซ้อนหลายขั้นตอน (เช่น «วางแผนทริปขับรถหนึ่งสัปดาห์จากเฉิงตูไปเสฉวนตะวันตก») ราคาประมาณ **¥1.6** ข้อจำกัดการเติม: ขั้นต่ำ ¥25 ต่อครั้ง สูงสุด 10 ครั้งและ ¥3,000 ต่อวัน ยอดคงเหลือสูงสุด ¥10,000
</Callout>

### การตรวจสอบการใช้งาน

- **Kimi เว็บ / แอป**: การตั้งค่า → การสมัครสมาชิกและใบแจ้งหนี้ → [เครดิตของฉัน](https://www.kimi.com/membership/subscription?tab=quota)
- **Kimi Code Console**: หลังจากเปิด Extra Usage แล้ว เข้าสู่ระบบ [Console](https://www.kimi.com/code/console) เพื่อดูยอดคงเหลือและการใช้งาน
- **Kimi Code CLI**: พิมพ์ `/usage` ในบรรทัดคำสั่งเพื่อตรวจสอบโดยตรง

### คำถามที่พบบ่อยเกี่ยวกับ Extra Usage

- **Kimi บนเว็บกับ Kimi Code ใช้กระเป๋าเงิน Extra Usage เดียวกันหรือไม่?** ใช่ — ยอดคงเหลือใช้ร่วมกันทั้งสองที่ เติมครั้งเดียวใช้ได้ทั้งคู่
- **อะไรถูกหักก่อน Extra Usage หรือเครดิตแพ็กเกจ?** เครดิตที่มีกำหนดเวลา เช่น แพ็กเกจ ถูกหักก่อน; Extra Usage จะถูกหักเป็นตัวสำรองเมื่อเครดิตที่มีกำหนดเวลาทั้งหมดหมดแล้วเท่านั้น
- **ถ้าถึงขีดจำกัดหรือถูกจำกัดอัตรา จะทำงานต่อได้ไหม?** ได้ เมื่อเปิด Extra Usage แล้ว คุณจะไม่ถูกจำกัดโดยขีดจำกัดของแพ็กเกจ: เมื่อถึงขีดจำกัดใด ๆ ระบบจะสลับไปใช้ยอด Extra Usage อย่างต่อเนื่อง งานไม่หยุด และหักเฉพาะ Extra Usage โดยไม่กระทบการรีเฟรชเครดิตสมาชิก
- **ยอดที่เหลือยกไปเดือนหน้าและสะสมได้ไหม?** ได้ — ไม่หมดอายุและสะสมได้ ยังใช้ได้หลังแพ็กเกจหมดอายุ แต่เติมไม่ได้ในช่วงที่ขาดสมาชิก
- **Extra Usage รองรับ Enterprise ไหม?** ยังไม่รองรับ
- **หลังปิดบัญชี ยอดคงเหลือจะได้รับคืนไหม?** โปรดส่งอีเมลไปที่ [membership@moonshot.cn](mailto:membership@moonshot.cn) เพื่อขอคืนเงิน
