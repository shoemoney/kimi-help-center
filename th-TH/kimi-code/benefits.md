# สิทธิประโยชน์ของ Kimi Code

Kimi Code คือบริการที่รวมอยู่ในแพ็กเกจสมาชิก Kimi มอบการสนับสนุนและฟีเจอร์ด้านการเขียนโค้ด เพื่อช่วยให้สมาชิกทำงานด้านการเขียนโปรแกรมในเวิร์กโฟลว์การพัฒนาส่วนตัวได้อย่างมีประสิทธิภาพยิ่งขึ้น

> โปรดทราบว่าสิทธิประโยชน์นี้มีไว้สำหรับการพัฒนาส่วนตัวเท่านั้น ไม่เหมาะกับการใช้งานในรูปแบบการพัฒนาระดับองค์กร หากต้องการใช้งานสำหรับองค์กร โปรดไปที่ [Kimi Open Platform](https://www.platform.moonshot.ai/)

## การเรียกเก็บเงิน

- การใช้งาน Kimi Code **รวมอยู่ในค่าสมัครสมาชิกแล้ว** โดยไม่มีค่าใช้จ่ายเพิ่มเติม
- ทุกคำขอจะหัก credit จาก **quota pool เฉพาะของ Kimi Code** ซึ่งแต่ละแพ็กเกจมีจำนวน credit แตกต่างกัน
- ระบบจะใช้ credit โบนัสก่อนหัก credit ของแพ็กเกจ

## การรีเฟรช credit

credit จะรีเฟรชทุก ๆ รอบ **7 วัน**:

- เริ่มนับตั้งแต่วันที่สมัครสมาชิก (D1) โดย credit จะรีเฟรชทุก 7 วัน
- ช่วงเวลารีเฟรช: D1–D7, D8–D14, D15–D21, D22–D28
- credit ที่ใช้ไม่หมด**จะไม่**ยกยอดไปยังรอบถัดไป

> วางแผนการใช้งานในแต่ละสัปดาห์เพื่อใช้ credit ให้คุ้มค่าที่สุด

## เครื่องมือที่รองรับ

สิทธิประโยชน์ของ Kimi Code ใช้งานได้กับเครื่องมือต่อไปนี้:

| เครื่องมือ | คำอธิบาย |
| --- | --- |
| **Kimi Code CLI** | AI agent แบบบรรทัดคำสั่งอย่างเป็นทางการของ Kimi |
| **Claude Code** | ผู้ช่วยเขียนโค้ดแบบบรรทัดคำสั่งจาก Anthropic |
| **Roo Code** | ส่วนขยายเขียนโค้ดด้วย AI สำหรับ VS Code |

การใช้ Kimi Code API Key ของคุณกับแพลตฟอร์มหรือเครื่องมือที่ไม่ได้อยู่ในรายการข้างต้นอาจถือเป็นการใช้งานที่ไม่เหมาะสม และอาจส่งผลให้ถูกจำกัดการเข้าถึง โปรดใช้เครื่องมือที่รองรับตามรายการข้างต้นเพื่อประสบการณ์และความครอบคลุมที่ดีที่สุด
