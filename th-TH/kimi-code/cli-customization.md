# การปรับแต่งและข้อมูลอ้างอิง

Kimi Code CLI มีตัวเลือกการปรับแต่งที่ครอบคลุม ให้คุณกำหนดพฤติกรรมและเวิร์กโฟลว์ของ AI ได้ตามต้องการ

## ไฟล์การตั้งค่า

Kimi Code CLI ใช้ `~/.kimi/config.toml` เป็นไฟล์การตั้งค่าส่วนกลาง รองรับทั้งรูปแบบ TOML และ JSON คุณสามารถตั้งค่าได้ดังนี้:

- **ผู้ให้บริการ API และโมเดล**: ตั้งค่าผู้ให้บริการโมเดล จุดเชื่อมต่อ API และคีย์ต่าง ๆ
- **โมเดลเริ่มต้น**: ระบุโมเดลที่จะใช้เป็นค่าเริ่มต้น
- **พารามิเตอร์ขณะรัน**: ปรับการตั้งค่าขณะรัน เช่น ระยะหมดเวลา concurrency รูปแบบผลลัพธ์ และอื่น ๆ

> ใช้คำสั่ง `/config` เพื่อเปิดไฟล์การตั้งค่าสำหรับแก้ไขได้อย่างรวดเร็ว

## การตั้งค่าโปรเจกต์ด้วย AGENTS.md

วางไฟล์ `AGENTS.md` ไว้ที่รากของโปรเจกต์เพื่อให้บริบทระดับโปรเจกต์แก่ AI:

- **ภูมิหลังของโปรเจกต์**: อธิบายฟังก์ชันการทำงาน สถาปัตยกรรม และเทคสแตกของโปรเจกต์
- **ขั้นตอนการ build**: วิธีติดตั้ง dependency, build โปรเจกต์ และรันการทดสอบ
- **แนวทางการเขียนโค้ด**: ข้อกำหนดการตั้งชื่อ กฎโครงสร้างไดเรกทอรี และรูปแบบโค้ดที่ต้องการ
- **หมายเหตุพิเศษ**: ข้อจำกัดด้านความปลอดภัย ข้อกำหนดด้านประสิทธิภาพ และข้อควรพิจารณาสำคัญอื่น ๆ

ใช้คำสั่ง `/init` เพื่อให้ AI สแกนโปรเจกต์ของคุณโดยอัตโนมัติและสร้าง `AGENTS.md` เริ่มต้น คุณยังสามารถแก้ไขไฟล์ด้วยตนเองเพื่อเพิ่มข้อมูลเฉพาะของโปรเจกต์ได้ ไฟล์ `AGENTS.md` สามารถวางไว้ในไดเรกทอรีย่อยใดก็ได้ — AI จะโหลดการตั้งค่าที่เกี่ยวข้องโดยอัตโนมัติ

## ปรับแต่ง system prompt

คุณสามารถปรับแต่ง system prompt ของ AI ได้หลายวิธี:

- **system prompt ส่วนกลาง**: เขียนไว้ใน `~/.kimi/AGENTS.md` — มีผลกับทุกโปรเจกต์
- **system prompt ระดับโปรเจกต์**: เขียนไว้ใน `AGENTS.md` ที่รากของโปรเจกต์ — มีผลเฉพาะโปรเจกต์ปัจจุบันเท่านั้น
- **พารามิเตอร์ตอนเปิดใช้งาน**: ใช้แฟล็ก `--system-prompt` เพื่อระบุตอนเริ่มต้น

การตั้งค่าระดับโปรเจกต์จะแทนที่การตั้งค่าส่วนกลาง และพารามิเตอร์ตอนเปิดใช้งานมีความสำคัญสูงสุด

## การผสาน MCP

Kimi Code CLI รองรับ Model Context Protocol (MCP) ซึ่งช่วยให้เชื่อมต่อกับเครื่องมือและแหล่งข้อมูลภายนอกเพื่อขยายความสามารถของ AI ได้:

- **การตั้งค่าเซิร์ฟเวอร์ MCP**: เพิ่มที่อยู่เซิร์ฟเวอร์ MCP ในไฟล์การตั้งค่าเพื่อให้ AI เรียกใช้เครื่องมือภายนอกได้
- **รองรับ MCP ในตัว**: เครื่องมือ MCP ที่ใช้บ่อยบางตัวมีอยู่ในตัวอยู่แล้วโดยไม่ต้องตั้งค่าเพิ่มเติม
- **เซิร์ฟเวอร์ MCP แบบกำหนดเอง**: คุณสามารถพัฒนาเซิร์ฟเวอร์ MCP ของคุณเองเพื่อมอบความสามารถเฉพาะด้านได้

การตั้งค่า MCP สามารถวางไว้ใน `~/.kimi/config.toml` หรือในไฟล์การตั้งค่าระดับโปรเจกต์ได้

## ตัวแปรสภาพแวดล้อม

Kimi Code CLI รองรับการตั้งค่าผ่านตัวแปรสภาพแวดล้อม — มีประโยชน์สำหรับ pipeline แบบ CI/CD และสคริปต์ต่าง ๆ:

| ตัวแปรสภาพแวดล้อม | คำอธิบาย |
| --- | --- |
| `KIMI_API_KEY` | API key |
| `KIMI_BASE_URL` | จุดเชื่อมต่อ API แบบกำหนดเอง |
| `KIMI_MODEL` | ชื่อโมเดลเริ่มต้น |
| `KIMI_MAX_TOKENS` | จำนวน token ผลลัพธ์สูงสุด |

ตัวแปรสภาพแวดล้อมมีความสำคัญเหนือกว่าการตั้งค่าในไฟล์การตั้งค่า

## ข้อมูลอ้างอิงเพิ่มเติม

- **ข้อมูลอ้างอิงคำสั่ง Slash**: ใช้ `/help` เพื่อดูคำสั่งทั้งหมดที่ใช้ได้
- **ข้อมูลอ้างอิงพารามิเตอร์ CLI**: รัน `kimi --help` เพื่อดูพารามิเตอร์ตอนเปิดใช้งานทั้งหมด
- **เอกสารทางการ**: เยี่ยมชม [Kimi Code Docs](https://www.kimi.com/code/docs/en/) เพื่อดูเอกสารฉบับสมบูรณ์ล่าสุด
