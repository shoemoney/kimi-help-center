# การโต้ตอบและการป้อนข้อมูล

Kimi Code CLI มีวิธีการโต้ตอบหลากหลายรูปแบบ เพื่อช่วยให้คุณทำงานร่วมกับ AI ได้อย่างมีประสิทธิภาพ

## Thinking mode

Thinking Mode ช่วยให้ AI คิดวิเคราะห์ในเชิงลึกก่อนตอบ เหมาะอย่างยิ่งสำหรับโจทย์ที่ซับซ้อน

- ใช้คำสั่ง `/model` เพื่อสลับโมเดลและเปิด/ปิด Thinking Mode
- คุณยังเปิด Thinking Mode ตั้งแต่ตอนเริ่มต้นได้ด้วยแฟล็ก `--thinking`

## การป้อนข้อมูลหลายบรรทัด

กด **Ctrl-J** เพื่อขึ้นบรรทัดใหม่สำหรับการป้อนข้อมูลหลายบรรทัด วิธีนี้มีประโยชน์สำหรับพรอมต์ที่ยาวหรือการวางโค้ดหลายบรรทัด

## การวางจากคลิปบอร์ด

กด **Ctrl-V** เพื่อวางเนื้อหาจากคลิปบอร์ด รองรับทั้งข้อความและรูปภาพ เมื่อวางรูปภาพ AI จะตีความเนื้อหาในภาพได้โดยตรง (เช่น ภาพหน้าจอ แบบดีไซน์ หรือภาพหน้าจอข้อผิดพลาด)

## คำสั่งสแลช

คำสั่งที่ขึ้นต้นด้วย `/` ใช้สำหรับควบคุมเซสชัน การตั้งค่า และการดีบัก คำสั่งที่ใช้บ่อยได้แก่:

| คำสั่ง | คำอธิบาย |
| --- | --- |
| `/help` | แสดงข้อมูลความช่วยเหลือ |
| `/login` | เข้าสู่ระบบและอนุญาตสิทธิ์ |
| `/model` | สลับโมเดลและ Thinking Mode |
| `/sessions` | แสดงรายการและสลับเซสชัน |
| `/clear` | ล้างบริบทปัจจุบัน |
| `/compact` | บีบอัดบริบท |
| `/init` | สร้าง AGENTS.md |
| `/exit` | ออกจาก CLI |

เมื่อพิมพ์ `/` ในช่องป้อนข้อมูล ระบบจะแสดงรายการคำสั่งที่ใช้ได้โดยอัตโนมัติ

## การเติมพาธอัตโนมัติด้วย @

ใช้สัญลักษณ์ `@` ในการป้อนข้อมูลเพื่ออ้างอิงพาธของไฟล์หรือไดเรกทอรี ระบบจะเติมข้อมูลให้อัตโนมัติ:

## การถาม-ตอบแบบมีโครงสร้าง

ในบางสถานการณ์ AI จะนำเสนอตัวเลือกแบบมีโครงสร้างให้คุณป้อนข้อมูล ใช้ **ปุ่มลูกศร** เพื่อเลือกตัวเลือก แล้วกด **Enter** เพื่อยืนยัน

## การยืนยันการอนุมัติ

เมื่อ AI จำเป็นต้องแก้ไขไฟล์ รันคำสั่งเชลล์ หรือดำเนินการอื่น ๆ ระบบจะขอให้คุณยืนยันก่อน โดยคุณสามารถเลือกได้ดังนี้:

| ตัวเลือก | คำอธิบาย |
| --- | --- |
| **Allow** | อนุญาตการดำเนินการครั้งนี้ |
| **Allow for Session** | อนุญาตการดำเนินการลักษณะเดียวกันตลอดเซสชันปัจจุบันโดยไม่ต้องถามอีก |
| **Deny** | ปฏิเสธการดำเนินการนี้ |

### YOLO mode

หากคุณไว้วางใจการดำเนินการของ AI คุณสามารถใช้ YOLO Mode เพื่อข้ามการยืนยันทั้งหมดได้:
