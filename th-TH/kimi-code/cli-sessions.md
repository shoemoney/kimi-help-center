# เซสชันและบริบท

Kimi Code CLI รองรับการจัดการหลายเซสชันและการคงบริบทไว้ ช่วยให้คุณหยุดพักและกลับมาทำงานต่อได้ทุกเมื่อ

## การกลับมาทำเซสชันต่อ

คุณสามารถกลับมาทำเซสชันก่อนหน้าต่อได้หลายวิธี:

### ทำเซสชันล่าสุดต่อ

<CodePreview
  files={[
    {
      name: "command.sh",
      language: "bash",
      content: "kimi --continue",
    },
  ]}
/>

ใช้แฟล็ก `--continue` (หรือ `-c`) เพื่อทำการสนทนาครั้งล่าสุดต่อ
### ระบุรหัสเซสชัน

<CodePreview
  files={[
    {
      name: "command.sh",
      language: "bash",
      content: "kimi --session \u003csession-id\u003e",
    },
  ]}
/>

ใช้แฟล็ก `--session` เพื่อกู้คืนเซสชันที่ต้องการ

### เรียกดูและสลับ

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "/sessions",
    },
  ]}
/>

รันคำสั่ง `/sessions` (หรือ `/resume`) เพื่อดูรายการเซสชันแล้วเลือกเซสชันที่จะกู้คืน
## การเล่นซ้ำตอนเริ่มต้น

เมื่อกลับมาทำเซสชันต่อ Kimi Code CLI จะเล่นประวัติการสนทนาซ้ำให้โดยอัตโนมัติ ช่วยให้คุณนึกถึงบริบทและความคืบหน้าก่อนหน้าได้อย่างรวดเร็ว

## การคงสถานะไว้

สถานะต่อไปนี้จะถูกบันทึกและกู้คืนโดยอัตโนมัติข้ามเซสชัน:

- **การตัดสินใจอนุมัติ**: การตัดสินใจอย่างเช่น "อนุญาตสำหรับเซสชันนี้" จะถูกจดจำไว้
- **Sub-agent แบบไดนามิก**: การตั้งค่า Sub-agent ที่สร้างขึ้นระหว่างเซสชันจะถูกคงไว้
- **ไดเรกทอรีเพิ่มเติม**: ไดเรกทอรีทำงานเพิ่มเติมที่เพิ่มผ่านคำสั่งก็จะถูกคงไว้เช่นกัน

นั่นหมายความว่าคุณสามารถทำงานก่อนหน้าต่อได้อย่างราบรื่นหลังกลับมาทำเซสชันต่อ

## การล้างและบีบอัด

Kimi Code CLI จะบีบอัดบริบทโดยอัตโนมัติเมื่อจำเป็น เพื่อให้การสนทนาดำเนินต่อไปได้ คุณยังจัดการบริบทด้วยตนเองผ่านคำสั่งสแลชได้ด้วย:

### ล้างบริบท

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "/clear",
    },
  ]}
/>

พิมพ์ `/clear` (หรือ `/reset`) เพื่อล้างบริบททั้งหมดในเซสชันปัจจุบันและเริ่มการสนทนาใหม่:

### บีบอัดบริบท

พิมพ์ `/compact` เพื่อบีบอัดบริบท โดยคงข้อมูลสำคัญไว้พร้อมลดการใช้ token:

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "/compact",
    },
  ]}
/>

คุณยังสามารถใส่คำสั่งเพิ่มเติมตอนบีบอัด เพื่อบอก AI ว่าควรให้ความสำคัญกับข้อมูลใด:

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "/compact Keep the discussion about database migrations",
    },
  ]}
/>

### สถานะบริบท

แถบสถานะที่ด้านล่างของ CLI จะแสดงการใช้งานบริบทปัจจุบันแบบเรียลไทม์ ช่วยให้คุณติดตามการใช้บริบทได้ เมื่อการใช้งานสูง ให้ใช้ `/compact` เพื่อบีบอัดบริบทและหลีกเลี่ยงการสูญเสียข้อมูลสำคัญ
