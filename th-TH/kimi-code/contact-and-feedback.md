# ติดต่อและส่งข้อเสนอแนะ

## ช่องทางส่งข้อเสนอแนะ

หากคุณพบปัญหาระหว่างใช้งาน Kimi Code หรือมีข้อเสนอแนะ สามารถแจ้งผ่านช่องทางต่อไปนี้ได้

### ทางเลือกที่ 1: ส่งข้อเสนอแนะจากใน CLI โดยตรง

ในโหมดโต้ตอบของ Kimi Code CLI ให้ป้อนคำสั่ง `/feedback` เพื่อส่งข้อเสนอแนะ ระบบจะรวบรวมข้อมูลเกี่ยวกับสภาพแวดล้อมปัจจุบันของคุณโดยอัตโนมัติ เพื่อช่วยให้คุณอธิบายปัญหาได้แม่นยำยิ่งขึ้น

### ทางเลือกที่ 2: GitHub Issues

ไปที่ [Kimi CLI GitHub Issues](https://github.com/MoonshotAI/kimi-cli/issues) แล้วค้นหาก่อนว่ามีปัญหาที่คล้ายกันอยู่แล้วหรือไม่ หากยังไม่มี คุณสามารถสร้าง Issue ใหม่และอธิบายสิ่งที่พบโดยละเอียดได้

### ทางเลือกที่ 3: ส่งข้อเสนอแนะทางอีเมล

คุณสามารถส่งอีเมลถึงทีม Kimi Code ได้ที่ [code@moonshot.ai](mailto:code@moonshot.ai) เพื่อรายงานปัญหา โปรดระบุข้อมูลต่อไปนี้ให้มากที่สุดเท่าที่ทำได้:

- **คำอธิบายปัญหา**: อธิบายปัญหาที่คุณพบหรือฟีเจอร์ที่ต้องการให้ชัดเจน
- **ขั้นตอนการทำซ้ำ**: วิธีทำให้เกิดปัญหาแบบทีละขั้นตอน
- **ข้อมูลสภาพแวดล้อม**: ระบบปฏิบัติการและเวอร์ชันของ Kimi Code CLI (รัน `kimi --version` เพื่อตรวจสอบ)
- **บันทึกข้อผิดพลาด**: หากมีข้อความแสดงข้อผิดพลาด โปรดวางข้อความทั้งหมด

### ทางเลือกที่ 4: เข้าร่วมกลุ่ม Feishu
สแกนโค้ด QR เพื่อเข้าร่วมกลุ่ม Feishu

## ตรวจสอบเบื้องต้นก่อนส่งข้อเสนอแนะ

ก่อนส่งข้อเสนอแนะ เราแนะนำให้ตรวจสอบสิ่งต่อไปนี้:

- คุณได้อัปเดต Kimi Code CLI เป็นเวอร์ชันล่าสุดแล้วหรือไม่ (รัน `kimi --version` เพื่อตรวจสอบ)
- การเชื่อมต่อเครือข่ายของคุณใช้งานได้หรือไม่ และคุณเข้าถึง `api.kimi.com` ได้หรือไม่
- API Key ของคุณยังใช้งานได้และยังไม่หมดอายุหรือไม่
- ไดเรกทอรีทำงานถูกต้องหรือไม่ และ Kimi มีสิทธิ์เข้าถึงไฟล์ที่เกี่ยวข้องหรือไม่

| การติดต่อจากสื่อมวลชน | [pr@kimi.com](mailto:pr@kimi.com) |
