# คำถามที่พบบ่อย

## การย้ายข้อมูลจากเวอร์ชันเดิม

<Callout type="info">
Kimi Code CLI ได้รับการอัปเกรดครั้งใหญ่ — เปลี่ยนจาก Python/uv มาเป็น Node.js ทำให้ติดตั้งง่ายขึ้น เริ่มทำงานเร็วขึ้น และมาพร้อม UI บนเทอร์มินัลที่ออกแบบใหม่ เวอร์ชันเดิมจะค่อย ๆ ถูกยกเลิกไป เราจึงแนะนำให้อัปเกรดโดยเร็วที่สุด
</Callout>

หากคุณกำลังย้ายข้อมูลจากเวอร์ชันเดิม ให้ทำตามขั้นตอนด้านล่าง — เพียงคำสั่งเดียวก็ย้ายการตั้งค่า เซิร์ฟเวอร์ MCP และประวัติเซสชันของคุณไปยังเวอร์ชันใหม่ได้

### มีอะไรใหม่

- **ไม่ต้องใช้ Python / uv อีกต่อไป**: สร้างขึ้นใหม่บน Node.js — ไม่ต้องมีสภาพแวดล้อม Python ติดตั้งง่ายกว่าเดิม
- **ไบนารีในตัว ใช้งานได้ทันที**: เริ่มทำงานเร็วขึ้น ใช้ทรัพยากรน้อยลง
- **UI บนเทอร์มินัลที่ออกแบบใหม่**: ลื่นไหลและตอบสนองได้ดีขึ้น
- **ย้ายข้อมูลครบทุกอย่าง**: การตั้งค่า เซิร์ฟเวอร์ MCP และประวัติเซสชัน ย้ายมาได้อย่างราบรื่น

### วิธีย้ายข้อมูล

มีสองวิธีในการย้ายข้อมูล

**เมื่อรัน `kimi` ครั้งแรก** หลังติดตั้ง kimi-code ระบบจะตรวจสอบโดยอัตโนมัติว่ามีข้อมูล kimi-cli อยู่ภายใต้ `~/.kimi/` หรือไม่ หากพบ จะมีข้อความแจ้งให้ย้ายข้อมูลปรากฏขึ้น โดยคุณสามารถเลือกย้ายตอนนี้ ทำภายหลัง หรือไม่ให้ถามอีก

คุณยังสามารถ **รันด้วยตนเองได้ทุกเมื่อ**:

<CodePreview
  files={[
    {
      name: "command.sh",
      language: "bash",
      content: "kimi migrate",
    },
  ]}
/>

คุณสามารถเลือกได้ว่าจะย้ายเซสชันการสนทนาด้วยหรือไม่ หากยังไม่ต้องการประวัติ ให้เลือก **Config only** มิฉะนั้นเลือก **Config + N sessions** เพื่อย้ายทุกอย่างในคราวเดียว เมื่อเสร็จสิ้นจะแสดงสรุปให้ดู

### สิ่งที่เกิดขึ้นระหว่างการย้ายข้อมูล

**สิ่งที่ถูกย้าย**: การตั้งค่า (`config.toml`) การตั้งค่าเซิร์ฟเวอร์ MCP ประวัติการป้อนข้อมูล และเซสชันการสนทนาที่คุณเลือกให้ย้าย

**สิ่งที่ไม่ถูกย้าย**: ข้อมูลรับรองการเข้าสู่ระบบ OAuth และการอนุญาตบริการ MCP จะไม่ถูกคัดลอกไป ดังนั้นหลังจากย้ายข้อมูลแล้วคุณจะต้องรัน `/login` อีกครั้งและให้สิทธิ์เซิร์ฟเวอร์ MCP ใหม่ ส่วนปลั๊กอินของ kimi-cli ก็อยู่นอกขอบเขตเช่นกัน

<Callout type="tip">
การย้ายข้อมูล**จะไม่แก้ไขหรือลบ**ข้อมูลเดิมใด ๆ ภายใต้ `~/.kimi/` kimi-cli ยังคงทำงานได้เหมือนเดิม และทั้งสองไม่รบกวนกัน คุณยังสามารถรันการย้ายข้อมูลซ้ำได้ — เซสชันที่ย้ายไปแล้วจะไม่ถูกนำเข้าซ้ำอีก
</Callout>

หลังการย้ายข้อมูล เซสชันที่นำเข้ามาจาก kimi-cli จะมีป้ายกำกับ `[imported]` ในตัวเลือกเซสชัน เพื่อให้คุณแยกออกจากเซสชันใหม่ได้

## การติดตั้งและการยืนยันตัวตน

### ไม่มีโมเดลให้ใช้งานเมื่อรัน `/login`

หากคุณเห็นข้อความ "No models available for the selected platform" เมื่อรัน `/login` อาจเกิดจาก:

- **API key ไม่ถูกต้องหรือหมดอายุ**: ตรวจสอบว่า API key ที่คุณป้อนถูกต้องและยังใช้งานได้
- **ปัญหาการเชื่อมต่อเครือข่าย**: ยืนยันว่าคุณสามารถเข้าถึงที่อยู่บริการ API ได้ (เช่น `api.kimi.com` หรือ `api.moonshot.cn`)

**โปรดสังเกตความแตกต่างของแพลตฟอร์ม**

สิทธิประโยชน์สมาชิก Kimi Code และ [Kimi Open Platform](https://platform.kimi.com) มี Base URL ต่างกัน โปรดตรวจสอบให้แน่ใจว่า Base URL ตรงกับ API Key เมื่อตั้งค่า

| แพลตฟอร์ม | Base URL | การเรียกเก็บเงิน | การสร้างคีย์ |
|------|---------|---------|-------------|
| **Kimi Code** | รองรับ Anthropic: `https://api.kimi.com/coding/` | การสมัครสมาชิก Kimi (รวม เครดิต) | [Kimi Code Console](https://www.kimi.com/code/console) |
| **Kimi Open Platform** | `https://api.moonshot.cn/v1` | จ่ายตามการใช้งานจริง | [Kimi Open Platform](https://platform.kimi.com) |

### API key ไม่ถูกต้อง

สาเหตุที่เป็นไปได้ที่ทำให้ API key ไม่ถูกต้อง:

- **ป้อนคีย์ผิด**: ตรวจสอบว่ามีช่องว่างเกินหรือตัวอักษรขาดหายไปหรือไม่
- **คีย์หมดอายุหรือถูกเพิกถอน**: ยืนยันสถานะของคีย์ในคอนโซลแพลตฟอร์ม

### สมาชิกหมดอายุหรือ เครดิต หมด

หากคุณใช้แพลตฟอร์ม Kimi Code คุณสามารถตรวจสอบ เครดิต ปัจจุบันและสถานะสมาชิกได้ด้วยคำสั่ง `/usage` หาก เครดิต หมดหรือสมาชิกหมดอายุ คุณต้องต่ออายุหรืออัปเกรดที่ [Kimi Code](https://kimi.com/code)

## การสมัครสมาชิก

### ฉันจะขอใบกำกับภาษีหรืออัปเกรดสมาชิกได้อย่างไร

ไปที่ [หน้าสมาชิก Kimi](https://www.kimi.com/membership/pricing#pricing-faq) แล้วทำตามคำแนะนำเพื่อส่งคำขอใบกำกับภาษีหรืออัปเกรดแพ็กเกจของคุณ

## ปัญหาการโต้ตอบ

### วางรูปภาพไม่สำเร็จ

เมื่อวางรูปภาพด้วย `Ctrl-V` หากคุณเห็นข้อความ "Current model does not support image input" แสดงว่าโมเดลปัจจุบันไม่รองรับการป้อนรูปภาพ

วิธีแก้ไข:

- **เปลี่ยนไปใช้โมเดลที่รองรับรูปภาพ**: ใช้โมเดลที่มีความสามารถ `image_in`
- **ตรวจสอบเนื้อหาคลิปบอร์ด**: ตรวจสอบให้แน่ใจว่าคลิปบอร์ดมีข้อมูลรูปภาพอยู่จริง ไม่ใช่เพียงพาธของไฟล์รูปภาพ

## การอัปเดตและอัปเกรด

### macOS เปิดครั้งแรกช้า

Gatekeeper ของ macOS จะตรวจสอบความปลอดภัยเมื่อรันโปรแกรมใหม่เป็นครั้งแรก ทำให้เริ่มทำงานช้าลง วิธีแก้ไข:

- **รอให้การตรวจสอบเสร็จสิ้น**: โปรดอดทนในการรันครั้งแรก ครั้งต่อ ๆ ไปจะกลับมาทำงานเร็วตามปกติ
- **เพิ่มลงใน Developer Tools**: เพิ่มแอปเทอร์มินัลของคุณใน **System Settings → Privacy & Security → Developer Tools**

### วิธีอัปเกรด Kimi Code CLI

รัน `kimi upgrade` เพื่อตรวจสอบเวอร์ชันล่าสุดและแสดงตัวเลือกการอัปเดต เลือก `Install update now` เพื่ออัปเกรด คุณยังสามารถอัปเกรดโดยตรงผ่านตัวจัดการแพ็กเกจได้:

## คำถามที่พบบ่อยเกี่ยวกับส่วนขยาย VS Code

ด้านล่างนี้คือคำถามที่พบบ่อยเกี่ยวกับ Kimi Code VS Code Extension

### VS Code แจ้งว่าไม่มี workspace ที่เปิดอยู่

โปรดเปิดโฟลเดอร์ใน VS Code ส่วนขยาย Kimi Code VS Code ต้องมี workspace จึงจะทำงานได้อย่างถูกต้อง

### VS Code แจ้งว่าหา CLI ไม่พบ

โปรดติดตั้ง Kimi Code CLI ด้วยตนเองและตั้งค่า `kimi.executablePath` ในการตั้งค่า VS Code หรือตรวจสอบให้แน่ใจว่ามี CLI ในตัวอยู่

### VS Code เข้าสู่ระบบไม่สำเร็จ

ลองข้ามการเข้าสู่ระบบแล้วใช้โหมด API key แทน ตรวจสอบการเชื่อมต่อเครือข่ายของคุณ หรือลองใหม่ภายหลังผ่านเมนูการดำเนินการของส่วนขยาย Kimi Code

### VS Code ส่งข้อความแล้วไม่มีการตอบกลับ

โปรดยืนยันว่า Kimi Code CLI พร้อมใช้งาน มีการตั้งค่าโมเดลแล้ว และเปิดโฟลเดอร์ workspace ใน VS Code อยู่ ตรวจสอบบันทึกข้อผิดพลาดผ่าน "Kimi Code: Show Logs"

### VS Code การเชื่อมต่อหมดเวลา

หากไม่มีการตอบกลับภายใน 30 วินาที จะหมดเวลา โปรดตรวจสอบเครือข่ายของคุณแล้วลองใหม่

### VS Code เกิดข้อผิดพลาดก่อนส่งข้อความ

ข้อผิดพลาดบางอย่างทำให้ไม่สามารถส่งข้อความใน VS Code ได้ เช่น หา Kimi Code CLI ไม่พบ เวอร์ชันต่ำเกินไป ยังไม่ได้เข้าสู่ระบบ หรือเซสชันกำลังทำงานอยู่ ข้อผิดพลาดจะแสดงเป็นการแจ้งเตือนแบบ toast และข้อความที่คุณป้อนจะถูกเก็บไว้เพื่อลองใหม่

## ข้อเสนอแนะและการติดต่อ

### เอกสารยังไม่ช่วยแก้ปัญหาของฉัน

หากข้อมูลข้างต้นยังไม่ช่วยแก้ปัญหาของคุณ สามารถติดต่อเราทางอีเมลได้ที่: [code@moonshot.ai](mailto:code@moonshot.ai) โปรดอธิบายปัญหาที่พบ ขั้นตอนที่คุณทำ และข้อมูลบันทึกที่เกี่ยวข้องในอีเมล แล้วเราจะตอบกลับโดยเร็วที่สุด

หากคุณมีปัญหาหรือข้อเสนอแนะ ก็สามารถให้ข้อเสนอแนะได้ที่ [GitHub Issues](https://www.github.com/MoonshotAI/kimi-cli/issues)
