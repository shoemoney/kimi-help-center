# การเตรียมความพร้อม

ก่อนใช้ Kimi Code คุณควรทำความเข้าใจแนวคิดพื้นฐานบางอย่าง ซึ่งจะช่วยให้ติดตั้งและใช้งาน Kimi Code ได้ราบรื่นขึ้น

## เทอร์มินัลคืออะไร?

**เทอร์มินัล** คือหน้าต่างสำหรับสั่งงานคอมพิวเตอร์ด้วยการพิมพ์คำสั่งแบบข้อความ

ลองนึกถึงเทอร์มินัลว่าเป็น “ตัวจัดการไฟล์แบบข้อความ”: แทนที่จะคลิกไอคอนด้วยเมาส์ คุณจะพิมพ์คำสั่ง เช่น `ls`, `cd` และ `mkdir` เพื่อดูเนื้อหาในโฟลเดอร์ เปลี่ยนไดเรกทอรี สร้างไฟล์ และอื่น ๆ

<Frames

  alt="ภาพประกอบเทอร์มินัล"
/>

### วิธีเปิดเทอร์มินัล

| ระบบปฏิบัติการ | วิธีเปิด |
|---------|---------|
| **macOS** | กด `Cmd + Space` พิมพ์ "Terminal" หรือ "终端" แล้วกด Enter |
| **Windows** | กด `Win + R` พิมพ์ `powershell` หรือ `wt`;<br>หรือค้นหา "PowerShell"/"Terminal" ในเมนู Start |
| **Linux** | กด `Ctrl + Alt + T` หรือค้นหา "Terminal" ในเมนูแอปพลิเคชัน |

### วิธีตรวจสอบระบบปฏิบัติการของคุณ

- **macOS**: คลิกไอคอน Apple ที่มุมซ้ายบนของหน้าจอ → "About This Mac"
- **Windows**: กด `Win + Pause/Break` หรือคลิกขวาที่ "This PC" → "Properties"
- **Linux**: รัน `uname -a` หรือ `cat /etc/os-release` ในเทอร์มินัล

## PowerShell คืออะไร?

<Frames
  src="./images/preparation/preparation-02.png"
  alt="ภาพประกอบ PowerShell"
/>

**PowerShell** เป็นเครื่องมือเทอร์มินัลที่ใช้กันทั่วไปบน Windows และมีความสามารถมากกว่า Command Prompt (CMD) มาตรฐาน บน Windows ต้องติดตั้งและใช้งาน Kimi Code CLI ใน PowerShell

Windows มีเครื่องมือ “บรรทัดคำสั่ง” อยู่สองแบบ อย่าสับสนกัน:

| เครื่องมือ | คำอธิบาย | เหมาะหรือไม่ |
|-----|------|---------|
| **CMD (Command Prompt)** | เครื่องมือบรรทัดคำสั่งพื้นฐานที่สุดใน Windows | ❌ ไม่แนะนำ |
| **PowerShell** | เครื่องมือบรรทัดคำสั่งที่ทันสมัยและทรงพลังกว่า | ✅ แนะนำ |

> **เคล็ดลับ**: ต้องรันคำสั่งติดตั้ง Kimi Code CLI ใน PowerShell คำสั่งอาจทำงานไม่ถูกต้องใน CMD

## ไดเรกทอรีทำงาน

เมื่อ Kimi Code CLI เริ่มทำงาน ระบบจะใช้โฟลเดอร์ปัจจุบันของคุณเป็น **ไดเรกทอรีทำงาน** โดยจะอ่านและแก้ไขได้เฉพาะไฟล์ภายในไดเรกทอรีทำงานนั้นเท่านั้น

**ก่อนเริ่ม ให้ตรวจสอบพาธปัจจุบันในเทอร์มินัลของคุณ**:

- พรอมป์ของเทอร์มินัลมักแสดงไดเรกทอรีปัจจุบัน เช่น `~/projects/my-app$`
- พิมพ์ `pwd` (macOS/Linux) หรือ `cd` (Windows) เพื่อดูพาธแบบเต็ม
- ใช้ `cd <folder-name>` เพื่อเข้าไปยังไดเรกทอรีของโปรเจกต์เป้าหมาย แล้วรัน `kimi`

> **ตัวอย่าง**: สมมติว่าโปรเจกต์ของคุณอยู่ใน `~/Documents/my-project` ให้เริ่มดังนี้:
> 1. เปิดเทอร์มินัล
> 2. พิมพ์ `cd ~/Documents/my-project`
> 3. พิมพ์ `kimi` เพื่อเริ่มใช้งาน

## วิธีรันคำสั่ง

<Frames
  src="./images/preparation/preparation-03.png"
  alt="ภาพประกอบการรันคำสั่ง"
/>

การรันคำสั่งในเทอร์มินัลหรือ PowerShell ทำได้ง่าย ๆ:

1. **คัดลอกคำสั่ง**: คัดลอกข้อความคำสั่งจากเอกสาร
   - macOS/Linux: `curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash`
   - Windows: `irm https://code.kimi.com/kimi-code/install.ps1 | iex`
2. **วางลงในเทอร์มินัล**: คลิกขวาในหน้าต่างเทอร์มินัล หรือกด `Cmd/Ctrl + V` เพื่อวาง
3. **กด Enter**: กดปุ่ม `Enter` เพื่อรันคำสั่ง
4. **รอให้ทำงานเสร็จ**: เทอร์มินัลจะแสดงกระบวนการทำงานและผลลัพธ์

> **หมายเหตุ**: ในเทอร์มินัล `Ctrl+C` โดยทั่วไปจะเป็นการ **หยุดคำสั่งปัจจุบัน** ไม่ใช่การคัดลอกข้อความ หากต้องการคัดลอก ให้ใช้ `Cmd/Ctrl + Shift + C`; หากต้องการวาง ให้ใช้ `Cmd/Ctrl + Shift + V`; หรือใช้เมนูคลิกขวา

> **เคล็ดลับ**: หากระบบขอให้คุณกรอกรหัสผ่านขณะคำสั่งกำลังทำงาน เทอร์มินัลจะไม่แสดงตัวอักษรใด ๆ ซึ่งเป็นกลไกความปลอดภัยตามปกติ ให้พิมพ์รหัสผ่านแล้วกด Enter ได้เลย

## CLI คืออะไร?

<Frames
  src="./images/preparation/preparation-04.png"
  alt="ภาพประกอบเทอร์มินัล"
/>

**CLI** ย่อมาจาก **C**ommand-**L**ine **I**nterface หมายถึงการใช้เครื่องมือด้วยการพิมพ์คำสั่งแบบข้อความ แทนการคลิกปุ่มในอินเทอร์เฟซแบบกราฟิก

Kimi Code CLI เป็นเครื่องมือบรรทัดคำสั่ง: คุณพิมพ์ `kimi` ในเทอร์มินัลเพื่อเริ่มใช้งาน จากนั้นโต้ตอบกับ AI ผ่านคำสั่งข้อความ เพื่อให้ช่วยอ่านโค้ด แก้ไขไฟล์ รันคำสั่ง และอื่น ๆ

## สภาพแวดล้อมเครือข่าย

ในการใช้ Kimi Code คุณต้องเชื่อมต่อกับเซิร์ฟเวอร์ของ Kimi ได้ หากสภาพแวดล้อมเครือข่ายของคุณมีข้อจำกัดต่อไปนี้ อาจต้องปรับการตั้งค่า:

- **เครือข่ายบริษัท/โรงเรียน**: บางสภาพแวดล้อมอินทราเน็ตอาจจำกัดการเข้าถึง API ภายนอก หากคุณมีพร็อกซี สามารถตั้งค่าที่อยู่พร็อกซีในไฟล์กำหนดค่าได้
- **VPN/พร็อกซี**: หากคุณใช้พร็อกซีแบบทั่วทั้งระบบ ให้ตรวจสอบว่าไม่ได้ดักจับหรือรบกวนคำขอไปยัง `api.kimi.com` หรือ `api.moonshot.cn`
- **ไฟร์วอลล์**: ตรวจสอบว่าไฟร์วอลล์ของระบบหรือเราเตอร์ไม่ได้บล็อกการเข้าถึงเครือข่ายจากโปรแกรมเทอร์มินัล

## ข้อควรพิจารณาด้านความปลอดภัย

Kimi Code CLI เป็น AI Agent ที่ทรงพลัง โดยอาจ:

- **อ่าน** เนื้อหาไฟล์บนคอมพิวเตอร์ของคุณ
- **แก้ไข** โค้ดและไฟล์กำหนดค่าของคุณ
- **รัน** คำสั่ง Shell เช่น ติดตั้ง dependencies หรือรันทดสอบ

**โปรดคำนึงถึงสิ่งต่อไปนี้เมื่อใช้งาน**:

- **อย่าเริ่มใช้งานในไดเรกทอรีที่มีข้อมูลอ่อนไหว**: หลีกเลี่ยงการรัน Kimi Code CLI ในไดเรกทอรีที่มีรหัสผ่าน คีย์ หรือไฟล์ส่วนตัวที่เป็นความลับ
- **ตรวจสอบการดำเนินการอย่างรอบคอบ**: Kimi Code จะขอให้คุณยืนยันก่อนแก้ไขไฟล์หรือรันคำสั่ง อย่าคลิก “ตกลง” เพียงเพราะเคยชิน
- **ทำความเข้าใจก่อนดำเนินการต่อ**: หากไม่แน่ใจว่าการดำเนินการหนึ่งจะส่งผลอย่างไร ให้ขอให้ Kimi Code อธิบายอย่างชัดเจนว่าจะทำอะไร ก่อนตัดสินใจว่าจะดำเนินการต่อหรือไม่
- **สำรองโค้ดสำคัญ**: ก่อนใช้ Kimi Code กับโปรเจกต์สำคัญ เราแนะนำให้ commit โค้ดของคุณลงระบบควบคุมเวอร์ชัน เช่น Git เพื่อให้ย้อนกลับได้ทุกเมื่อ

> **คำแนะนำ**: หากใช้งานครั้งแรก ให้ลองใช้ Kimi Code CLI กับโปรเจกต์ทดสอบหรือสำเนาของโปรเจกต์ก่อน เมื่อคุ้นเคยกับวิธีทำงานแล้ว ค่อยนำไปใช้กับโปรเจกต์จริง
