# การใช้งานหลักใน VS Code

<Callout type="warning">
**ส่วนขยาย VS Code อยู่ระหว่างการปรับให้รองรับ**

ขณะนี้ Kimi Code for VS Code เปิดให้ติดตั้งใหม่เฉพาะผู้ใช้ Python CLI รุ่นเดิมเท่านั้น ผู้ใช้เดิมที่ติดตั้งส่วนขยายไว้แล้วสามารถใช้งานต่อได้หลังอัปเกรดเป็น CLI รุ่นใหม่ ส่วนผู้ใช้ CLI เวอร์ชัน TS ยังไม่รองรับการติดตั้งในตอนนี้
</Callout>

## เปิดแผง

คลิกไอคอน Kimi ใน Activity Bar หรือเรียกใช้คำสั่ง "Kimi Code" จาก Command Palette

## การป้อนข้อมูลและการควบคุม

### การอ้างอิงไฟล์

พิมพ์ `@` แล้วเลือกชื่อไฟล์หรือโฟลเดอร์ ตัวอย่างเช่น ใช้ `@src/handlers/` เพื่ออ้างอิงโฟลเดอร์, `@app.ts` เพื่ออ้างอิงไฟล์ หรือ `@src/app.ts:10-20` เพื่ออ้างอิงช่วงบรรทัดที่ต้องการ

กด `Alt+K` เพื่อแทรกไฟล์ปัจจุบันหรือโค้ดที่เลือกไว้เป็นข้อมูลอ้างอิงอย่างรวดเร็ว

### คำสั่ง slash

พิมพ์ `/` เพื่อเปิดเมนูคำสั่ง ใช้ `/init` เพื่อสแกนโปรเจกต์และสร้างเอกสาร หรือใช้ `/compact` เพื่อบีบอัดบริบทที่ยาวเกินไป

### ประวัติการป้อนข้อความ

กด `↑` / `↓` ในช่องป้อนข้อความเพื่อเลื่อนดูข้อความที่คุณเพิ่งส่งไปได้อย่างรวดเร็ว ช่วยให้ถามซ้ำหรือปรับแก้คำถามได้ง่ายขึ้น

### การป้อนไฟล์สื่อ

คุณสามารถวาง ลากแล้วปล่อย หรือเลือกไฟล์สื่อได้ รูปแบบที่รองรับมีทั้งไฟล์ภาพ เช่น PNG, JPEG, GIF, WebP และ HEIC รวมถึงไฟล์วิดีโอ เช่น MP4, WebM และ MOV

- **วาง / ลากแล้วปล่อย**: รูปภาพหนึ่งไฟล์มีขนาดต้นฉบับได้สูงสุด 5MB ระบบจะบีบอัดให้อัตโนมัติ รวมถึงแปลง HEIC เป็น JPEG, ปรับขนาดรูปภาพที่ใหญ่เกินไป และลดคุณภาพให้อยู่ที่ประมาณ 2MB
- **ตัวเลือกไฟล์**: เมื่อเลือกไฟล์ผ่านปุ่ม "+" ในช่องป้อนข้อความหรือเมนู `@` รูปภาพมีขนาดได้สูงสุด 10MB และวิดีโอสูงสุด 20MB
- **ข้อจำกัดทั่วไป**: แต่ละข้อความแนบไฟล์ได้สูงสุด 9 ไฟล์ โดยมีขนาดรวมสูงสุด 80MB เมื่อแนบไฟล์สื่อ ระบบจะกรองโมเดลที่ไม่รองรับอินพุตหลายรูปแบบออกโดยอัตโนมัติ

### คิวข้อความ

ขณะที่ Kimi กำลังตอบ คุณยังสามารถพิมพ์และส่งข้อความในช่องป้อนข้อความต่อได้ ข้อความเหล่านี้จะไม่หายไป แต่จะถูกเพิ่มเข้าใน **คิวข้อความ** แถบเครื่องมือด้านล่างจะแสดงจำนวนในคิว และคุณสามารถคลิกเพื่อขยายแผงคิวได้:

- ดูรายการข้อความที่รอส่ง
- แก้ไขหรือลบข้อความในคิว
- จัดลำดับข้อความใหม่
- ขณะที่ Kimi กำลังตอบ ให้คลิกไอคอน ⚡ บนรายการในคิวเพื่อแทรกข้อความนั้นทันทีในฐานะ **Steer** ช่วยชี้นำให้ Kimi ปรับทิศทางของคำตอบปัจจุบัน

### โมเดลและ Thinking mode

สลับโมเดลได้จากเมนูดรอปดาวน์ในแถบป้อนข้อมูล

บางโมเดลรองรับความสามารถในการให้เหตุผลแบบขยาย สวิตช์ Thinking mode มีสามสถานะ: ซ่อนเมื่อโมเดลไม่รองรับ Thinking mode, เปิด/ปิดด้วยตนเองโดยผู้ใช้ หรือเปิดตลอดเวลาสำหรับโมเดลอย่าง k2-thinking

หลังจากเปิดใช้งานแล้ว ขั้นตอนการคิดจะถูกยุบไว้เป็นค่าเริ่มต้นในคำตอบ คุณสามารถขยายเพื่อดูขั้นตอนการให้เหตุผลได้ เปิด `kimi.alwaysExpandThinking` ในการตั้งค่าเพื่อให้ขยายขั้นตอนการคิดเป็นค่าเริ่มต้น

## โหมดการทำงาน

### การยืนยันการดำเนินการและการเรียกใช้เครื่องมือ

เมื่อ Kimi เสนอให้เรียกใช้เครื่องมือหรือเขียนลงไฟล์ จะมีกล่องยืนยันปรากฏขึ้นพร้อมสามตัวเลือก:

- **ใช่**: อนุมัติเฉพาะการดำเนินการปัจจุบัน
- **ใช่ สำหรับเซสชันนี้**: อนุมัติการดำเนินการลักษณะเดียวกันภายในเซสชันปัจจุบันจนกว่าจะเริ่มเซสชันใหม่
- **ไม่**: ปฏิเสธการดำเนินการ

เปิด `kimi.yoloMode` ในการตั้งค่าเพื่ออนุมัติการเรียกใช้เครื่องมือทั้งหมดโดยอัตโนมัติ เหมาะเมื่อคุณเชื่อมั่นในเวิร์กโฟลว์และต้องการทำงานให้เร็วขึ้น

### กล่องคำถาม

ระหว่างการดำเนินการ Kimi อาจถามคำถาม เช่น ให้คุณเลือกแนวทางการติดตั้งใช้งาน การ์ดคำถามจะปรากฏที่ด้านล่าง คุณสามารถเลือกตัวเลือกที่เตรียมไว้ได้โดยตรง หรือเลือก "การตอบกลับแบบกำหนดเอง..." เพื่อป้อนคำตอบของคุณเอง หลังจากคุณตอบแล้ว Kimi จะดำเนินการต่อ

### โหมดวางแผน

คลิกไอคอน 📋 ทางซ้ายของช่องป้อนข้อความเพื่อเข้าสู่โหมดวางแผน เมื่อเปิดใช้งาน Kimi จะแสดง Plan Card ที่ขยายได้ก่อนเริ่มดำเนินการจริง โดยระบุขั้นตอนที่ตั้งใจจะทำ คุณสามารถตรวจทานแผนก่อนอนุญาตให้ดำเนินการต่อ

- ปุ่มโหมดวางแผนจะคงค่าที่ตั้งไว้ก่อนหน้าสำหรับทุกเซสชันใหม่
- หาก Kimi กำลังสตรีมคำตอบอยู่ การออกจากโหมดวางแผนจะต้องยืนยันอีกครั้งเพื่อหลีกเลี่ยงการขัดจังหวะงานปัจจุบัน

### การติดตามการเปลี่ยนแปลงไฟล์

หลังจาก Kimi แก้ไขไฟล์ การเปลี่ยนแปลงทั้งหมดจะถูกติดตามและแสดงในส่วน "การเปลี่ยนแปลงไฟล์" คุณสามารถดูรายการไฟล์ที่แก้ไขและสถานะของไฟล์ เช่น เพิ่ม แก้ไข หรือลบ พร้อมสถิติจำนวนบรรทัดที่เพิ่มและลบ

สำหรับแต่ละไฟล์ คุณสามารถดูการเปลี่ยนแปลงในมุมมอง diff ดั้งเดิมของ VS Code, กู้คืนกลับเป็นสถานะเดิม หรือเก็บการเปลี่ยนแปลงไว้เพื่อล้างบันทึกการติดตามได้ รองรับการดำเนินการแบบกลุ่ม คุณจึงเก็บหรือละทิ้งการเปลี่ยนแปลงทั้งหมดได้ในครั้งเดียว สถานะฐานจะถูกบันทึกเมื่อไฟล์ถูกแก้ไขครั้งแรกในเซสชัน การย้อนกลับจะกู้คืนไฟล์ไปยังเวอร์ชันฐานนั้น

## การจัดการบริบท

### ประวัติเซสชัน

คลิกเมนูดรอปดาวน์ประวัติที่ด้านบนของแผงเพื่อดูเซสชันก่อนหน้า ข้อมูลเซสชันจะถูกจัดเก็บไว้ในเครื่องและรองรับการค้นหาด้วยคีย์เวิร์ด คุณสามารถลบเซสชันเก่า หรือโหลดเซสชันเพื่อสนทนาต่อจากครั้งก่อน

แถบสถานะจะแสดงเปอร์เซ็นต์การใช้บริบทและจำนวน token อินพุต/เอาต์พุต เมื่อการใช้บริบทสูง ให้ใช้คำสั่ง `/compact` เพื่อบีบอัด

### การสลับไดเรกทอรีทำงาน

คลิกไอคอนรูปเฟือง (Action Menu) ทางขวาของช่องป้อนข้อความ → **Working Directory** เพื่อสลับไดเรกทอรีทำงานระหว่างไดเรกทอรีย่อยต่าง ๆ ใน Workspace ปัจจุบัน หลังจากสลับแล้ว ระบบจะเริ่มเซสชันใหม่โดยอัตโนมัติ เพื่อให้ Kimi ทำงานตามบริบทของไดเรกทอรีใหม่ คุณสามารถเลือกไดเรกทอรีย่อยที่ลงทะเบียนไว้ได้โดยตรง หรือใช้ "เรียกดู..." เพื่อเรียกดูโฟลเดอร์ย่อยใดก็ได้

## เมนูการดำเนินการ

### รายการฟีเจอร์

ไอคอนรูปเฟืองทางขวาของช่องป้อนข้อความจะเปิดเมนูการดำเนินการ ซึ่งมีฟีเจอร์ต่อไปนี้:

- **Working Directory**: สลับไดเรกทอรีทำงานปัจจุบัน (ดู "การสลับไดเรกทอรีทำงาน" ด้านบน)
- **MCP Servers**: เปิดแผงการกำหนดค่าเซิร์ฟเวอร์ MCP
- **General Config**: เปิดหน้าการกำหนดค่า Kimi ในการตั้งค่า VS Code
- **Show Logs**: เปิดแผงบันทึกเอาต์พุตของ Kimi Code เพื่อใช้แก้ไขปัญหา
- **Reset Kimi**: รีเซ็ต Kimi Webview มีประโยชน์เมื่ออินเทอร์เฟซค้างหรือไม่ตอบสนอง
- **Sign out / Sign in**: ออกจากระบบหรือเข้าสู่ระบบบัญชี Kimi ของคุณอีกครั้ง

คุณยังสามารถเรียกใช้ "Kimi Code: Run CLI" จาก VS Code Command Palette เพื่อเริ่ม Kimi Code CLI ในเทอร์มินัลแบบรวมได้โดยตรง
