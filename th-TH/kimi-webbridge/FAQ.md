# คำถามที่พบบ่อย

## การติดตั้งและการตั้งค่า

### พบข้อความ "Cannot add apps from this website" ขณะติดตั้งส่วนขยาย?

โปรดติดตั้งจากเว็บสโตร์อย่างเป็นทางการเท่านั้น (Chrome Web Store หรือ Edge Add-ons) หากเข้าเว็บสโตร์ไม่ได้ ให้ใช้วิธีติดตั้งแบบกำหนดเองตามที่ระบุไว้บนเว็บไซต์ทางการ

### รันคำสั่งเชื่อมต่อแล้วไม่มีอะไรเกิดขึ้น?

โปรดตรวจสอบการเชื่อมต่ออินเทอร์เน็ตของคุณ หากปัญหายังคงอยู่ ให้ลองรีสตาร์ท Kimi Claw Desktop แล้วรันคำสั่งอีกครั้ง

### ใช้งานบนหลายเครื่องได้ไหม?

ได้ แต่ต้องติดตั้งและตั้งค่าแยกกันในแต่ละเครื่อง

### หา Kimi Claw Desktop ไม่เจอ?

Kimi Claw Desktop คือ Kimi Claw ที่ติดตั้งไว้บนคอมพิวเตอร์ของคุณ เปิด Kimi Desktop มองหา Kimi Claw ในแถบด้านซ้าย สร้าง Claw ใหม่ แล้วเลือก "Deploy on my computer"

## การเชื่อมต่อและการใช้งาน

### สถานะของส่วนขยายแสดงว่า "Disconnected"?

โปรดยืนยันว่าได้ติดตั้งส่วนขยายเบราว์เซอร์ Kimi WebBridge สำเร็จแล้ว จากนั้นทำตามขั้นตอนตามวิธีตั้งค่าของคุณ:

- **Kimi Desktop**: รีสตาร์ท Kimi Desktop แล้วลองใหม่อีกครั้ง

- **Local Agent อื่น ๆ**: ส่งคำสั่งต่อไปนี้อีกครั้งใน Agent ของคุณ แล้วรีสตาร์ท Agent หลังจากคำสั่งทำงานเสร็จ:

### บน Windows ติดตั้ง WebBridge แล้วขึ้นข้อผิดพลาด: Installation failed

Kimi WebBridge รองรับระบบปฏิบัติการ Windows และสามารถรันคำสั่งติดตั้งในสภาพแวดล้อม Linux ได้:

### หลังติดตั้ง WebBridge แสดงคำเตือนเรื่องความเข้ากันได้ของ Chrome หมายความว่าอย่างไร?

หาก WebBridge เปิดหน้าเว็บได้ตามปกติ แต่การทำงานอย่าง `snapshot`, `evaluate`, `screenshot` หรือ `click` ล้มเหลวอยู่เรื่อย ๆ สาเหตุที่พบบ่อยกว่าคือ **การขัดแย้งกับส่วนขยายเบราว์เซอร์อื่น ๆ**

ปัญหานี้พบบ่อยเป็นพิเศษกับเครื่องมือดึงข้อมูลเว็บ ส่วนขยายช่วยเหลือเว็บไซต์ ส่วนขยายบันทึกหน้าจอ และส่วนขยายผู้ช่วย AI

เราขอแนะนำขั้นตอนต่อไปนี้เพื่อแก้ปัญหา:

1. เปิดหน้าจัดการส่วนขยายในเบราว์เซอร์ของคุณ
2. ปิดการใช้งานส่วนขยายอื่น ๆ ชั่วคราว
3. เปิดใช้งานเฉพาะ Kimi WebBridge เท่านั้น
4. รีสตาร์ทเบราว์เซอร์แล้วลองใหม่อีกครั้ง
5. หาก WebBridge ทำงานได้ตามปกติ ให้เปิดใช้งานส่วนขยายอื่น ๆ ทีละตัวเพื่อหาส่วนขยายที่ก่อให้เกิดความขัดแย้ง


### WebBridge จะทำให้ข้อมูลการล็อกอินของฉันรั่วไหลหรือไม่?

ไม่ การทำงานทั้งหมดเกิดขึ้นภายในอุปกรณ์ของคุณ—สถานะการล็อกอินและเนื้อหาหน้าเว็บไม่เคยออกจากเครื่องของคุณ Agent เข้าถึงได้เฉพาะผลลัพธ์ของการทำงานที่คุณอนุญาตเท่านั้น

### ทำไมการทำงานบางอย่างจึงล้มเหลว?

โครงสร้างหน้าเว็บที่ซับซ้อนหรือการโหลดแบบไดนามิกอาจทำให้การทำงานล้มเหลวได้ ลองทำให้คำสั่งของคุณกระชับขึ้น หรือให้ Agent ถ่ายภาพหน้าจอก่อนเพื่อยืนยันสถานะของหน้าเว็บก่อนลงมือทำ

### รองรับเบราว์เซอร์ใดบ้าง?

ปัจจุบันรองรับ Chrome และ Edge เราแนะนำให้ใช้เวอร์ชันล่าสุดเพื่อประสบการณ์ใช้งานที่ดีที่สุด

## การทำงานร่วมกับ Agent อื่น ๆ

### รองรับ Agent อื่นใดบ้าง?

WebBridge รองรับ Local Agent ทั้งหมด รวมถึง Claude Code, Codex, Cursor, Kimi Code, Hermers Claw และอื่น ๆ

### การตั้งค่าสำหรับ Agent แต่ละตัวเหมือนกันไหม?

คำสั่งสำหรับติดตั้งเหมือนกันทั้งหมด—เพียงรันคำสั่ง curl คำสั่งเดียวก็ติดตั้งได้ ดูรายละเอียดได้จากการตั้งค่า Skill ของ Agent แต่ละตัว
