# ตัวอย่างกรณีใช้งาน ส่วนขยายเบราว์เซอร์ Kimi

งานทั้งหมดด้านล่างนี้สามารถมอบให้ Kimi ทำได้โดยตรง: สนทนาในแถบด้านข้าง หรือให้ Local Agent ดำเนินการแทน

## การค้นหาและจัดระเบียบข้อมูล

เมื่อคุณต้องค้นหาข้อมูลจากหลายเว็บไซต์ ส่วนขยายเบราว์เซอร์ Kimi ช่วยให้ Agent เปิดหน้าเป้าหมาย ดึงเนื้อหาสำคัญ และจัดระเบียบเป็นผลลัพธ์แบบมีโครงสร้างได้โดยอัตโนมัติ ลดงานน่าเบื่ออย่างการเปิดทีละหน้าแล้วคัดลอกวางด้วยตนเอง

## การวิจัยและวิเคราะห์เนื้อหา

ส่วนขยายเบราว์เซอร์ Kimi ช่วยให้ Agent เรียกดูผลการค้นหา เปิดหน้ารายละเอียด ดึงชื่อเรื่อง ข้อมูล ความคิดเห็น และข้อมูลอื่น ๆ แล้วนำมาวิเคราะห์และสรุปได้โดยอัตโนมัติ เหมาะอย่างยิ่งกับงานวิจัยที่ต้องเปิดอ่านเว็บจำนวนมาก

## เปลี่ยนเวิร์กโฟลว์ที่ทำซ้ำให้เป็น Skill

เมื่อต้องทำเวิร์กโฟลว์เดิมซ้ำแล้วซ้ำอีก คุณไม่จำเป็นต้องพิมพ์คำสั่งใหม่ทุกครั้ง Kimi สามารถเรียนรู้กระบวนการและบันทึกไว้เป็น Skill ได้ หลังจากนั้นเพียงพิมพ์ `/` เพื่อเรียกใช้ได้ทุกเมื่อ

### บันทึกการกระทำเป็น Skill

เหมาะสำหรับงานเว็บที่มีขั้นตอนคงที่ เช่น เปิดแดชบอร์ดเพื่อส่งออกข้อมูลทุกวัน หรือกรอกแบบฟอร์มเดิมซ้ำ ๆ

1. พิมพ์ `/` ในแถบด้านข้าง แล้วเลือก "บันทึกการกระทำเป็น Skill"
2. ทำตามขั้นตอนตามปกติหนึ่งครั้ง Kimi จะบันทึกทุกการกระทำของคุณ
3. คลิก "หยุดและสร้าง" Kimi จะกลั่นกระบวนการครั้งนี้ให้เป็น Skill
4. ตรวจสอบชื่อ ขั้นตอน และพารามิเตอร์ของ Skill แล้วบันทึก (ข้อมูลที่ละเอียดอ่อนอย่างรหัสผ่านสามารถตั้งเป็นพารามิเตอร์ลับและกรอกตอนเล่นซ้ำได้)

หลังจากนั้น พิมพ์ `/` แล้วเลือก Skill นั้น Kimi จะทำซ้ำตามขั้นตอนให้คุณ คุณสามารถแก้ไขขั้นตอนและเนื้อหาของ Skill ได้ทุกเมื่อ

### เปลี่ยนเว็บไซต์ให้เป็น Skill

เหมาะสำหรับเว็บไซต์ที่คุณใช้งานเป็นประจำ เช่น แดชบอร์ดข้อมูลหรือระบบภายในองค์กร

พิมพ์ `/` ในแถบด้านข้าง แล้วเลือก "เปลี่ยนเว็บไซต์ให้เป็น Skill" Kimi จะวิเคราะห์โครงสร้างและวิธีการทำงานของเว็บไซต์โดยอัตโนมัติ บรรจุเป็น Skill ที่พร้อมใช้งาน เมื่อบันทึกแล้วคุณก็เรียกใช้ผ่าน `/` ได้ทุกเมื่อ

### บันทึกเซสชันนี้เป็น Skill

หาก Kimi เพิ่งทำเวิร์กโฟลว์ในเซสชันปัจจุบันได้อย่างดีเยี่ยม คุณสามารถบันทึกไว้เพื่อใช้ซ้ำได้โดยตรง: พิมพ์ `/` แล้วเลือก "บันทึกเซสชันนี้เป็น Skill"
