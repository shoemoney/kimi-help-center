# Dashboard

dashboard คือที่เก็บ widgets โดยรวบรวม widgets ที่คุณสนใจมากที่สุดไว้ในมุมมองเดียวที่คงอยู่และปรับแต่งเฉพาะบุคคล จัดเรียงตามหัวข้อ โปรเจกต์ หรือเป้าหมาย dashboard ไม่ผูกกับการสนทนาใดการสนทนาหนึ่ง — คุณสามารถเปิดได้ทุกเมื่อ และจัดการ widgets จากแชทใดก็ได้

## การสร้างและจัดการ Dashboard

1. คลิก "Dashboard" ในแถบด้านข้างซ้ายเพื่อเปิดเมนู Dashboard
2. คลิก "Create" แล้วกรอกชื่อ (จำเป็น) และคำอธิบาย (ไม่บังคับ)
3. ผู้ใช้แต่ละคนสร้าง dashboard ได้สูงสุด 2 อัน

บน dashboard ที่ว่างเปล่า คุณสามารถอธิบาย widget ที่ต้องการได้โดยตรง และ Kimi จะสร้างมันลงใน dashboard นั้น

<Callout type="warning">
การลบ dashboard จะลบ widgets ทั้งหมดในนั้นและ widget task ที่เกี่ยวข้องไปด้วย การกระทำนี้ไม่สามารถย้อนกลับได้ — โปรดดำเนินการด้วยความระมัดระวัง
</Callout>

## เลย์เอาต์และคำอธิบายประกอบ

- แต่ละ dashboard ใส่ widgets ได้สูงสุด 20 อัน ลากเพื่อจัดเรียงใหม่และปรับขนาดได้ตามต้องการ
- คลิก "Refresh" เพื่ออัปเดตเนื้อหาของ widgets บน dashboard
- คลิก "Annotate" เพื่อเข้าสู่โหมดเขียนคำอธิบาย: เลือกองค์ประกอบใดก็ได้ใน widget เพื่อสร้างคำอธิบายตามตำแหน่งและบันทึกข้อเสนอแนะของคุณ คำอธิบายจะแสดงเรียงตามลำดับเวลา สูงสุด 10 รายการ คลิกคำอธิบายที่บันทึกไว้เพื่อแก้ไขอีกครั้ง

## การจัดการ Widgets บน Dashboard

เลื่อนเมาส์ไปวางบน widget เพื่อ:

- คลิก "Expand" เพื่อดูชื่อและประเภทของ widget
- สำหรับ live widget ให้จัดการ widget task ที่ผูกไว้: ดูชื่อและคำอธิบายของงาน เปิดหรือปิดงาน และตรวจสอบการรัน 10 ครั้งล่าสุด (เวลารันและสถานะ)
- คลิก "…" เพื่อเลือก:
  - **Delete**: ลบ widget ออกจากแชทต้นทางและทุก dashboard อย่างถาวร — ไม่สามารถย้อนกลับได้
  - **Pin to Desktop**: ปักหมุด widget ไว้บนเดสก์ท็อปของคอมพิวเตอร์เป็นหน้าต่างแยกอิสระที่ปรับขนาดได้ หน้าต่างจะปิดอัตโนมัติเมื่อคุณออกจากแอป

## การเปิด Dashboard จากแชท

โมเดลสามารถแสดงการ์ด dashboard ในแชทได้ คลิกการ์ดเพื่อเปิดหน้า dashboard ที่เกี่ยวข้องในแผงด้านขวา โดยไม่ต้องออกจากการสนทนาปัจจุบัน
