# คำถามที่พบบ่อยเกี่ยวกับ Kimi Work

## Kimi Work แตกต่างจากเวอร์ชันเว็บอย่างไร?

เว็บแอป Kimi เหมาะอย่างยิ่งสำหรับการแชตและถามตอบแบบรวดเร็ว ส่วน Kimi Work คือเอเจนต์ในเครื่องที่ออกแบบมาเพื่อเวิร์กโฟลว์เชิงลึก สามารถอ่านและจัดการโฟลเดอร์ในเครื่องของคุณ ท่องเว็บด้วยตัวเองผ่าน WebBridge รันโค้ด Python เบื้องหลัง และทำงานตามกำหนดเวลาได้ เรียกได้ว่าเป็นพนักงานดิจิทัลระดับระบบ

## Kimi Work ปกป้องความเป็นส่วนตัวของฉันอย่างไรเมื่อเข้าถึงไฟล์ในเครื่อง?

คุณควบคุมไฟล์ของตัวเองได้อย่างเต็มที่ Kimi Work มีการควบคุมสิทธิ์สามระดับ และคุณเลือกวิธีอนุญาตได้ดังนี้:

- **ค่าเริ่มต้น**: การทำงานทั่วไปจะรันโดยอัตโนมัติ — Kimi จะแจ้งให้คุณอนุญาตอย่างชัดเจนก่อนการทำงานที่ละเอียดอ่อน เช่น แก้ไข เขียนทับ หรือรันโค้ดภายในไฟล์ในเครื่องของคุณ;
- **อนุญาตด้วยตนเอง**: ขออนุญาตก่อนดำเนินการ;
- **อนุญาตทั้งหมด**: ดำเนินการได้ทันทีโดยไม่ต้องขออนุญาต

เมื่อคุณเลือก "อนุญาตด้วยตนเอง" จะไม่มีการดำเนินการใดเกิดขึ้นหากไม่ได้รับความยินยอมจากคุณ

## WebBridge (ระบบอัตโนมัติบนเบราว์เซอร์) ช่วยฉันทำอะไรได้บ้าง?

WebBridge ทำให้ Kimi ใช้เบราว์เซอร์ได้เหมือนมนุษย์ คุณสั่งให้ตรวจข่าวล่าสุดบนเว็บไซต์แล้วสรุปให้ หรือดึงข้อมูลหุ้นย้อนหลังลง Excel ในเครื่องของคุณก็ได้ ระบบจะคลิก เลื่อนหน้า และสกัดข้อมูลด้วยตัวเอง ช่วยประหยัดเวลางานมือได้หลายชั่วโมง

## งานตามกำหนดเวลาทำอะไรได้บ้าง? ถ้าคอมพิวเตอร์หลับอยู่ งานยังทำงานไหม?

งานตามกำหนดเวลาช่วยให้ Kimi รันงานที่กำหนดไว้โดยอัตโนมัติเมื่อถึงเวลาที่ตั้งไว้ — ไม่ว่าจะเป็นรายวัน รายสัปดาห์ รายเดือน หรือครั้งเดียว (ไม่ทำซ้ำ) — เหมาะสำหรับสรุปรายวัน การติดตามรายสัปดาห์ และการทำความสะอาดเป็นระยะ

บนเดสก์ท็อป Kimi Work งานตามกำหนดเวลาจะทำงาน **ในเครื่อง** และจะทำงานก็ต่อเมื่อ **แอปเปิดอยู่** เท่านั้น หากพลาดเวลาทริกเกอร์เพราะคอมพิวเตอร์อยู่ในโหมดสลีปหรือปิดเครื่อง หรือเพราะแอปถูกปิดอยู่ งานนั้นจะ **ไม่ถูกรันย้อนหลัง** เมื่อเปิดแอปครั้งถัดไป ดังนั้น หากคุณต้องการให้งานทำงานข้ามคืน ให้เปิดคอมพิวเตอร์และแอป Kimi Work ไว้ (ในทางกลับกัน งานที่สร้างใน Kimi จะทำงานบนคลาวด์และไม่จำเป็นต้องเปิดไคลเอนต์ค้างไว้)
