# คำถามที่พบบ่อยเกี่ยวกับ Kimi Work

## Kimi Work แตกต่างจากเวอร์ชันเว็บอย่างไร?

เว็บแอป Kimi เหมาะอย่างยิ่งสำหรับการแชตและค้นหาคำตอบอย่างรวดเร็ว ส่วน Kimi Work คือเอเจนต์ภายในเครื่องที่ออกแบบมาสำหรับเวิร์กโฟลว์เชิงลึก โดยสามารถอ่านและจัดการโฟลเดอร์ในเครื่องของคุณ ท่องเว็บได้เองผ่าน WebBridge รันโค้ด Python ในเบื้องหลัง และดำเนินงานตามกำหนดเวลาได้ เรียกได้ว่าเป็นพนักงานดิจิทัลระดับระบบของคุณ

## Kimi Work ปกป้องความเป็นส่วนตัวของฉันอย่างไรเมื่อเข้าถึงไฟล์ภายในเครื่อง?

คุณควบคุมไฟล์ของคุณได้อย่างเต็มที่ Kimi Work มีระบบควบคุมสิทธิ์ให้คุณเลือกวิธีอนุญาตได้เอง:

- **ขอสิทธิ์ก่อน**: ขออนุญาตก่อนดำเนินการ — Kimi จะแจ้งให้คุณอนุญาตอย่างชัดเจนก่อนแก้ไข เขียนทับ หรือรันโค้ดภายในไฟล์ในเครื่องของคุณ;
- **อนุญาตทั้งหมด**: ดำเนินการได้ทันทีโดยไม่ต้องขออนุญาต

เมื่อคุณเลือก "ขอสิทธิ์ก่อน" จะไม่มีการดำเนินการใดเกิดขึ้นหากคุณยังไม่ยินยอม

## WebBridge (การทำงานอัตโนมัติบนเบราว์เซอร์) ช่วยฉันทำอะไรได้บ้าง?

WebBridge ทำให้ Kimi ใช้เบราว์เซอร์ได้เหมือนมนุษย์ คุณอาจสั่งให้ตรวจข่าวล่าสุดบนเว็บไซต์แล้วสรุปให้ หรือดึงข้อมูลหุ้นย้อนหลังมาเก็บไว้ใน Excel ภายในเครื่องของคุณก็ได้ ระบบจะคลิก เลื่อนหน้า และดึงข้อมูลได้เอง ช่วยประหยัดเวลางานที่ต้องทำด้วยมือไปได้หลายชั่วโมง

## ฉันทำอะไรกับงานตามกำหนดเวลาได้บ้าง? งานจะทำงานไหมถ้าคอมพิวเตอร์อยู่ในโหมดพัก?

ตัวจัดตารางเวลา Cron ในตัวรองรับการเรียกใช้เอเจนต์ LLM การรัน Python/Shell และอื่น ๆ คุณสามารถตั้งให้งานทำงานรายวัน รายชั่วโมง หรือตามเงื่อนไขได้ หากต้องการให้งานทำงานต่อเนื่องข้ามคืน เพียงเปิดตัวเลือก "ปลุกคอมพิวเตอร์ให้พร้อมใช้งานเสมอ" ในการตั้งค่าของคุณ
