# ภาพรวม Kimi Work

Kimi Work คือ Agent ภายในเครื่องแบบอเนกประสงค์สำหรับคนทำงานสายความรู้ ใช้งานได้ในโหมด "Work" ของไคลเอนต์เดสก์ท็อป Kimi (Mac / Windows)

Kimi Work นำความสามารถของ Agent ที่ Kimi Code พิสูจน์แล้วในงานวิศวกรรม มาสู่การโต้ตอบบนเดสก์ท็อปที่คนทำงานสายความรู้ใช้ได้คุ้นมือในทุกวัน: คุณไม่ต้องเปิดเทอร์มินัล เขียนคำสั่ง หรือกำหนดค่าสภาพแวดล้อม เพียงอธิบายเป้าหมายด้วยภาษาธรรมชาติ Kimi Work ก็จะแบ่งงานเป็นส่วนย่อย ดำเนินขั้นตอนแบบขนาน เรียกใช้เครื่องมือ ใช้เบราว์เซอร์ สร้างและจัดระเบียบโฟลเดอร์ แล้วส่งมอบผลงาน เช่น เอกสาร สเปรดชีต และชุดสไลด์ — ทั้งหมดนี้ทำบนคอมพิวเตอร์ของคุณเอง

Kimi Code ออกแบบมาเพื่อผู้พัฒนาที่เขียนโค้ด ส่วน Kimi Work ออกแบบมาเพื่อคนทำงานสายความรู้ โดยครอบคลุมสถานการณ์ประจำวันเป็นหลัก เช่น การย้ายข้อมูลระหว่างที่ต่าง ๆ การจัดระเบียบไฟล์ การวิเคราะห์ข้อมูล และการจัดทำรายงาน

## ความสามารถหลัก

- **แกน Agent ภายในเครื่อง**: ขับเคลื่อนด้วย Kimi Code ในฐานะแกนหลักและโมเดล Kimi K3 มอบพื้นฐานของ Agent ภายในเครื่อง เช่น การติดตั้งและใช้งาน Skills รวมถึงการรันงานตามกำหนดเวลา
- **Skills ระดับมืออาชีพ**: สืบทอด Skills ระดับมืออาชีพของ Kimi Agent ออนไลน์ เช่น การสร้างเว็บไซต์และการสร้าง PPT พร้อมรองรับการแนะนำ Skills จากบุคคลที่สามและการอัปโหลด Skills ภายในเครื่อง
- **ปลั๊กอินและฐานข้อมูลระดับมืออาชีพ**: ใช้แอปและบริการภายนอกภายใน Kimi เช่น Canva, Notion และ WPS พร้อมเชื่อมต่อกับฐานข้อมูลระดับมืออาชีพในด้านการเงิน งานวิจัย กฎหมาย และสาขาอื่น ๆ
- **Widgets**: หน้าเชิงโต้ตอบที่โมเดลสร้างขึ้นในแชท สามารถเชื่อมต่อกับข้อมูลในเครื่องหรือปลั๊กอินภายนอกเพื่ออัปเดตอย่างต่อเนื่อง ทำให้คำตอบเห็นภาพชัดเจนและเข้าใจง่ายขึ้น ดู [Widgets](/kimi-work/widgets)
- **Dashboard**: รวบรวม widgets ที่คุณสนใจมากที่สุดไว้ในมุมมองเดียวที่คงอยู่และปรับแต่งเฉพาะบุคคล จัดเรียงตามหัวข้อ โปรเจกต์ หรือเป้าหมาย พร้อมดูและจัดการได้ทุกเมื่อ ดู [Dashboard](/kimi-work/dashboard)
- **Kimi WebBridge**: โซลูชันการทำงานกับเบราว์เซอร์ในตัว ที่ใช้เบราว์เซอร์ได้เหมือนคนจริง
- **Agent Swarm**: ประกอบทีมเอเจนต์ย่อยได้เองสูงสุด 300 ตัวตามความซับซ้อนของงาน เพื่อรับมืองานที่ซับซ้อนกว่าและใช้เวลานานกว่า
- **การทำงานระยะยาว**: ขับเคลื่อนด้วยความสามารถในการทำงานระยะยาวของโมเดล Kimi K3 รองรับการทำงานอัตโนมัติต่อเนื่องนานหลายสิบชั่วโมงและการเรียกใช้เครื่องมืออัตโนมัติหลายพันครั้ง

## อินเทอร์เฟซและการโต้ตอบ

- ไคลเอนต์มีสองโหมดคือ "Work" และ "Chat" แถบด้านข้างของโหมด Work ประกอบด้วย: งานใหม่, Dashboard, Plugins, Skills, งานตามกำหนดเวลา, WebBridge, โปรเจกต์ และ Chat
- พิมพ์ "/" ในช่องป้อนข้อความเพื่อใช้ Skills อย่างรวดเร็ว และพิมพ์ "@" เพื่อเพิ่มบริบท
- มีการควบคุมสิทธิ์ และคุณสามารถเลือกวิธีอนุญาตได้:
  - **ขอสิทธิ์ก่อน**: ขออนุญาตก่อนดำเนินการ
  - **อนุญาตทั้งหมด**: รันโดยตรงโดยไม่ต้องขออนุญาต
- สลับระหว่างโหมดการทำงานสองแบบได้: "Agent" และ "Agent Swarm"

## หมายเหตุเกี่ยวกับเวอร์ชัน

Kimi Work เปิดตัวเมื่อวันที่ 3 มิถุนายน 2026 และขณะนี้อยู่ในช่วง Beta โดยมีการปรับปรุงอย่างต่อเนื่องและถี่ขึ้นเรื่อย ๆ มีการเพิ่มฟีเจอร์ต่าง ๆ อย่างค่อยเป็นค่อยไป เช่น การแสดงตัวอย่างไฟล์ การบันทึกร่างอัตโนมัติ โหมด Goal, Plugin Center, Widgets และ Dashboard ตั้งแต่เวอร์ชัน 3.1.0 เป็นต้นมา Kimi Work ขับเคลื่อนด้วยโมเดล Kimi K3 จุดเน้นของการทดสอบในปัจจุบันอยู่ที่การแบ่งงาน การทำงานขนานของหลายเอเจนต์ การเรียกใช้เครื่องมือ การใช้งานเบราว์เซอร์ การจัดการไฟล์ภายในเครื่อง และการสร้างผลงานส่งมอบขนาดยาว โดยเสถียรภาพในการทำงาน คุณภาพของผลงาน และประสบการณ์ผู้ใช้จะได้รับการปรับปรุงต่อเนื่องตามความคิดเห็นจากผู้ใช้ Beta
