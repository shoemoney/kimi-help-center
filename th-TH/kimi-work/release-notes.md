# บันทึกการออกเวอร์ชัน

หน้านี้บันทึกการอัปเดตเวอร์ชันของ Kimi Work รวมถึงฟีเจอร์ใหม่ การเปลี่ยนแปลง และการแก้ไข และจะอัปเดตอย่างต่อเนื่อง ดาวน์โหลดเวอร์ชันล่าสุด: [kimi.com/products/kimi-work](https://www.kimi.com/products/kimi-work)

## 3.2.11 (2026-09-18)

**การเปลี่ยนแปลง**

- แผงรายละเอียดรองรับการแสดงกระบวนการทำงานของ sub-Agent แล้ว

**การแก้ไข**

- แก้ไขปัญหาที่ทางลัดในเมนู Start เสียหลังจากอัปเดตในแอปบน Windows
- แก้ไขข้อบกพร่องหลายส่วนและปรับปรุงการโต้ตอบและเสถียรภาพบางส่วน

## 3.2.10 (2026-09-16)

**การแก้ไข**

- ถอดแพ็กเกจเสริมของปลายทางการแชร์ Windows อย่างเร่งด่วนเพื่อแก้ไขปัญหาเด้งตอนเปิดเครื่อง ความสามารถในการแชร์กลับมาใน 3.2.11 หลังการแก้ไข
- ชื่อที่แสดงและคำอธิบายของสกิลในตัวจะถูกแปลตามภาษาของอินเทอร์เฟซ: เมนู “/” กรองตามชื่อที่แปลแล้ว โดยภาษาที่ยังไม่พร้อมจะใช้ภาษาอังกฤษ
- คลิกการ์ดแนบโฟลเดอร์เพื่อค้นหาไดเรกทอรีที่เกี่ยวข้องในแผนผังไฟล์ของเวิร์กเบนช์
- แก้ไขข้อบกพร่องหลายส่วนและปรับปรุงการโต้ตอบและเสถียรภาพบางส่วน

## 3.2.9 (2026-09-14)

**ฟีเจอร์ใหม่**

- รองรับการแชร์และเปิดไฟล์ด้วย Kimi สำหรับบางรูปแบบไฟล์:
  - แชร์ให้ Kimi: ส่งไฟล์และเนื้อหาไปให้ Kimi โดยตรงจากเมนูแชร์ของแอป เช่น WeChat
  - เปิดด้วย Kimi: คลิกขวาที่ไฟล์ที่รองรับแล้วเลือกเปิดด้วย Kimi
- อัปเกรดสัตว์เลี้ยงบนเดสก์ท็อป: UI ใหม่ทั้งหมด พร้อมการตอบกลับด่วนในบับเบิลสนทนาโดยไม่ต้องเปิดหน้าต่างหลัก
- เพิ่มแผงดัชนีในตัวแสดง PDF: รองรับสารบัญและการข้ามไปยังหมายเลขหน้า
- เพิ่มตัวเลือกโหมดพลังงาน “ปลุกค้างไว้หลังหน้าจอดับ”: หน้าจอดับได้ในขณะที่ระบบยังทำงานต่อ การควบคุมระยะไกลและงานเบื้องหลังไม่ถูกขัดจังหวะ

**การเปลี่ยนแปลง**

- ไฟล์ที่อัปโหลดและไฟล์ที่ลิงก์ด้วย “@” ในกล่องป้อนข้อความ สามารถคลิกเพื่อเปิดตัวอย่างในเวิร์กเบนช์ด้านขวาได้แล้ว
- ตัวอย่างรูปภาพรองรับการกระทำคัดลอก / บันทึก

**การแก้ไข**

- แก้ไขสภาวะการแข่งขันหลายจุด รวมถึงการกู้คืนการแก้ไขคิวและการปลดล็อกการนำทางหลังเบราว์เซอร์ขัดข้อง
- แก้ไขปัญหาสีในโหมดมืดสำหรับฟีเจอร์ของแอป
- แก้ไขข้อบกพร่องหลายส่วนและปรับปรุงการโต้ตอบและเสถียรภาพบางส่วน

## 3.2.7 (2026-09-11)

**ฟีเจอร์ใหม่**

**การเปลี่ยนแปลง**

- ศูนย์การแจ้งเตือนรองรับทำเครื่องหมายอ่านทั้งหมดด้วยคลิกเดียว
- ข้อความควบคุมระยะไกลแสดงเป็นส่วน ๆ การ์ด sub-Agent และการ์ดผลลัพธ์ตรงกับเดสก์ท็อป

**การแก้ไข**

- แก้ไขปัญหาฟีเจอร์อัปโหลดปลั๊กอินหายไป
- ลิงก์อีเมลและโทรศัพท์จะแจ้งอย่างชัดเจนเมื่อเปิดไม่ได้ ไม่ล้มเหลวแบบเงียบ ๆ อีกต่อไป

- แก้ไขประสิทธิภาพและการลากของสัตว์เลี้ยงบนเดสก์ท็อป
- แก้ไขข้อบกพร่องหลายส่วนและปรับปรุงการโต้ตอบและเสถียรภาพบางส่วน
