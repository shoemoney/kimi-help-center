# บันทึกการออกเวอร์ชัน

หน้านี้บันทึกการอัปเดตเวอร์ชันของ Kimi Work รวมถึงฟีเจอร์ใหม่ การเปลี่ยนแปลง และการแก้ไข และจะอัปเดตอย่างต่อเนื่อง ดาวน์โหลดเวอร์ชันล่าสุด: [kimi.com/products/kimi-work](https://www.kimi.com/products/kimi-work)

## 3.2.5 (2026-09-04)

**ฟีเจอร์ใหม่**

- เพิ่มฟีเจอร์ควบคุมระยะไกล: ควบคุม Kimi Work บนเดสก์ท็อปจากโทรศัพท์ของคุณ
- รองรับการควบคุมเบราว์เซอร์ผ่าน WebMCP: เพิ่มความเข้ากันได้และขีดจำกัดการทำงาน
- เพิ่มการค้นหาภายในการสนทนา: ค้นหารายการได้อย่างรวดเร็วภายในการสนทนา

**การเปลี่ยนแปลง**

- ปรับศูนย์การตั้งค่าใหม่ รองรับการใช้งานร่วมกันระหว่างโหมด Chat และ Work

**การแก้ไข**

- แก้ไขปัญหาที่ผู้ใช้บางรายเห็นสถานะการเข้าสู่ระบบแสดงผิดปกติ
- แก้ไขข้อบกพร่องหลายส่วนและปรับปรุงการโต้ตอบและเสถียรภาพบางส่วน

## 3.2.4 (2026-08-31)

**การเปลี่ยนแปลง**

- ปรับการแสดงการอ้างอิงแหล่งข้อมูล เช่น การค้นเว็บและไฟล์ในเครื่อง ในคำตอบของข้อความให้ดีขึ้น
- ปรับขนาดตัวอักษรและระยะห่างบรรทัดในคำตอบของข้อความให้ดีขึ้น

**การแก้ไข**

- แก้ไขปัญหาประสบการณ์การใช้งานบางส่วนในโหมดมืด
- ปรับการเฝ้าสังเกตกระบวนการบน Windows ให้ดีขึ้น
- แก้ไขข้อบกพร่องหลายส่วนและปรับปรุงการโต้ตอบและเสถียรภาพบางส่วน

## 3.2.3 (2026-08-28)

**ฟีเจอร์ใหม่**

- เพิ่มปุ่ม “สร้างปลั๊กอิน” ในตลาดปลั๊กอิน: สร้างปลั๊กอินได้โดยตรงในตลาด

**การแก้ไข**

- ปรับปรุงรายละเอียดสัตว์เลี้ยงบนเดสก์ท็อป: ปรับพฤติกรรมหน้าต่างให้ดีขึ้น และภาษาจะเปลี่ยนตามแอปแบบเรียลไทม์
- แก้ไขปัญหาความสอดคล้องของสถานะการสนทนาเมื่อแก้ไขและส่งข้อความซ้ำหลังเกิดข้อผิดพลาด
- เพิ่มประสิทธิภาพการใช้พลังงานของฟีเจอร์ที่ทำงานตลอดเวลา
- แก้ไขข้อบกพร่องหลายส่วนและปรับปรุงการโต้ตอบและเสถียรภาพบางส่วน

## 3.2.2 (2026-08-26)

**ฟีเจอร์ใหม่**

- เพิ่มสัตว์เลี้ยงบนเดสก์ท็อป: Kimi มาในรูปแบบสัตว์เลี้ยงบนเดสก์ท็อปที่คอยอยู่เคียงข้างและโต้ตอบกับคุณ
- เพิ่มคำสั่งลัด Slash: กล่องป้อนข้อความรองรับคำสั่ง compact (บีบอัดบริบท), fork (แยกการสนทนา) และ goal (เป้าหมาย)
- เพิ่มตัวเลือก “ค่าเริ่มต้น” สำหรับสิทธิ์การรัน: ตอนนี้รองรับสิทธิ์สามระดับทั่วโลก — “ค่าเริ่มต้น”, “อนุญาตด้วยตนเอง” และ “อนุญาตทั้งหมด”

**การเปลี่ยนแปลง**

- การควบคุมเบราว์เซอร์ในตัวโดย Agent เปิดใช้งานโดยค่าเริ่มต้นแล้ว
- การสนทนาในพื้นที่ “แชท” ไม่แชร์ไดเรกทอรีรากร่วมกันอีกต่อไป แต่ละการสนทนาจะมีไดเรกทอรีทำงานของตัวเอง

**การแก้ไข**

- แก้ไขปัญหาที่ข้อความแรกแสดงสถานะว่างเปล่าชั่วครู่หลังจากส่ง
- แก้ไขข้อบกพร่องหลายส่วนและปรับปรุงการโต้ตอบและเสถียรภาพบางส่วน

## 3.2.1 (2026-08-21)

**ฟีเจอร์ใหม่**

- เพิ่ม Launcher แบบโกลบอล: เรียกกล่องป้อนข้อความแบบแคปซูลลอยบนเดสก์ท็อปได้ทุกที่ทุกเวลาด้วยแป้นพิมพ์ลัดส่วนกลาง
  - เมื่อเรียกใช้ จะนำไฟล์ที่เลือกอยู่ใน Finder / File Explorer เข้ามาโดยอัตโนมัติ รองรับการวางรูปภาพ เพิ่มไฟล์แนบ และลากภาพหน้าจอเข้ามา
  - พิมพ์ “/” เพื่อเปิดเมนูปลั๊กอินและสกิล (รองรับการค้นหาด้วยพินอิน) และเลือกเวิร์กสเปซได้
  - กดแป้นพิมพ์ลัดค้างไว้เพื่อพิมพ์ด้วยเสียง หลังส่งจะยุบเหลือแคปซูลขนาดมินิ และสามารถกดครั้งเดียวเพื่อกลับไปยังแอปหลักเพื่อดูคำตอบ
- เพิ่มคิวข้อความ: ขณะที่ Agent กำลังตอบ คุณยังส่งข้อความต่อได้ ข้อความใหม่จะเข้าคิวโดยอัตโนมัติ รองรับการลากเพื่อจัดลำดับใหม่ แก้ไข ลบ และดูตัวอย่างรายละเอียด
- การพิมพ์ด้วยเสียงในกล่องป้อนข้อความของ Work: คลิกไมโครโฟนหรือกดแป้นพิมพ์ลัดค้างไว้เพื่อเริ่มพิมพ์ด้วยเสียง รองรับการรู้จำเสียงแบบผสมจีน-อังกฤษ

**การเปลี่ยนแปลง**

- อัปเดตตรรกะการแจ้งเตือนข้อความ: สามารถสลับกฎการแจ้งเตือนข้อความได้ในการตั้งค่า

**การแก้ไข**

- เพิ่มประสิทธิภาพการใช้พลังงานขณะสแตนด์บาย ลดการใช้ทรัพยากรเบื้องหลังเมื่อแอปไม่ได้ใช้งาน
- แก้ไขปัญหาที่ไอคอน Dock หายไปบน macOS
- แก้ไขข้อบกพร่องหลายส่วนและปรับปรุงการโต้ตอบและเสถียรภาพบางส่วน

## 3.2.0 (2026-08-19)

**ฟีเจอร์ใหม่**

- เพิ่มเบราว์เซอร์ในตัวของ Agent: แท็บเบราว์เซอร์จะผูกกับการสนทนาและแสดงอยู่ในพื้นที่แสดงตัวอย่าง Agent สามารถควบคุมเบราว์เซอร์ได้โดยตรง ทั้งการคลิก การพิมพ์ และอื่น ๆ บน Mac ยังสามารถนำเข้าคุกกี้จากเบราว์เซอร์ Chrome ในเครื่องเพื่อใช้สถานะการเข้าสู่ระบบที่มีอยู่ต่อได้ (ปิดไว้โดยค่าเริ่มต้นและสามารถเปิดได้ในการตั้งค่า)
- รองรับ 16 ภาษา: ไคลเอนต์รองรับ 16 ภาษาแล้ว จากเดิมที่รองรับเพียงภาษาจีนและภาษาอังกฤษ

**การเปลี่ยนแปลง**

- Kimi WebBridge เปลี่ยนเป็นปลั๊กอิน: การควบคุมเบราว์เซอร์จริงถูกย้ายไปอยู่ในรูปแบบปลั๊กอิน ซึ่งปิดไว้โดยค่าเริ่มต้นและสามารถเปิดได้ในการตั้งค่า
- ยกเลิกหน้ารายการแดชบอร์ดแล้ว ตอนนี้สลับแดชบอร์ดผ่านแถบแท็บด้านบน
- แดชบอร์ดกลายเป็นประเภทหนึ่งของพื้นที่แสดงตัวอย่าง: สามารถเปิดแดชบอร์ดได้ในพื้นที่แสดงตัวอย่างของแชท และเปิดหลายแดชบอร์ดพร้อมกันได้

**การแก้ไข**

- อัปเกรดการเรนเดอร์ข้อความแบบสตรีมมิง: คำตอบที่ยาวแสดงผลลื่นไหลยิ่งขึ้น
- แก้ไขข้อบกพร่องหลายส่วนและปรับปรุงการโต้ตอบและเสถียรภาพบางส่วน

## 3.1.8 (2026-08-11)

**ฟีเจอร์ใหม่**

- การนำทางประวัติข้อความ: แถบนำทางข้อความใหม่ทางด้านขวาของแชทยาว ๆ ช่วยให้คุณข้ามกลับไปยังข้อความก่อนหน้าได้อย่างรวดเร็ว
- การแยกสาขาการสนทนา: เริ่มสาขาใหม่จากเทิร์นใดก็ได้เพื่อสำรวจต่อ โดยนำประวัติการสนทนาเดิมติดไปด้วย
- แก้ไขและย้อนกลับ: แก้ไขข้อความล่าสุดของคุณและสร้างคำตอบขึ้นใหม่
- โฟลเดอร์โปรเจกต์: ย้ายการสนทนาเข้าหรือออกจากโปรเจกต์ และปักหมุดโปรเจกต์ไว้ในพื้นที่ปักหมุดของแถบด้านข้าง
- การแก้ไขไฟล์ที่โปร่งใส: หลัง Agent แก้ไขไฟล์ ระบบจะสร้างการ์ดสรุป diff — ตรวจสอบการเปลี่ยนแปลงทีละบรรทัดและย้อนกลับได้ในคลิกเดียว ไฟล์ใน workspace จะรีเฟรชอัตโนมัติเมื่อมีการเปลี่ยนแปลงบนดิสก์
- การค้นพบและสร้าง skill: ค้นพบและสร้าง skill ที่กำหนดเองใน Work พร้อมรองรับการค้นหา skill
- คอมโพเนนต์แดชบอร์ดที่ปักหมุดไว้บนเดสก์ท็อปตอนนี้มีสวิตช์ให้อยู่บนสุดเสมอ

**การเปลี่ยนแปลง**

- หน้าต่างการสนทนาแยกอิสระแบบใหม่รองรับ Chat แล้ว
- ข้อความของผู้ใช้ที่ยาวเกินไปในช่องป้อนข้อความจะถูกย่อไว้แล้ว

**การแก้ไข**

- แก้ไขการแสดงตัวอย่างลิงก์ไฟล์ PDF บน Windows การตั้งค่า Work ไม่กะพริบเป็นสีขาวในโหมดมืดอีกต่อไป และการวางจากคลิปบอร์ดของ Word จะคืนค่าเป็นข้อความแทนที่จะเป็นไฟล์แนบรูปภาพ
