# กรณีการใช้งาน

## การเงิน: วิเคราะห์กลยุทธ์การลงทุน

ให้ Kimi Work ศึกษาพอร์ตการถือครองของวอร์เรน บัฟเฟตต์ในช่วง 10 ปีที่ผ่านมา สรุปกลยุทธ์การลงทุนของเขา และสร้าง "Skill การลงทุนแบบบัฟเฟตต์" หลังจากติดตั้ง Skill แล้ว ให้เชื่อมต่อกับแหล่งข้อมูลการเงินระดับมืออาชีพของ Kimi เพื่อวิเคราะห์ว่าพอร์ตและกลยุทธ์ของคุณสอดคล้องกับแนวทางการลงทุนแบบเน้นคุณค่าของบัฟเฟตต์หรือไม่

**เวิร์กโฟลว์**: ค้นคว้า ▶ สร้าง Skill ▶ ติดตั้ง Skill ▶ ใช้ Skill และเรียกใช้แหล่งข้อมูลการเงินระดับมืออาชีพเพื่อวิเคราะห์

## งานวิจัย: ประมวลผลข้อมูลและช่วยเขียนบทความวิชาการ

ให้ Kimi Work ทำหน้าที่เป็นนักวิจัยด้าน urban computing: ทำความสะอาดชุดข้อมูลจำลองบนคอมพิวเตอร์ของคุณ สรุปลักษณะและรูปแบบสำคัญ สร้างกราฟเชิงวิชาการ จากนั้นช่วยเขียนบทความวิชาการให้เสร็จสมบูรณ์โดยอ้างอิงจากข้อมูลที่ทำความสะอาดแล้วและกราฟเหล่านั้น

**เวิร์กโฟลว์**: ทำความสะอาดข้อมูลในเครื่อง ▶ สร้างกราฟ ▶ ช่วยเขียนบทความวิชาการ

## งานสำนักงาน: วิจัยตลาดและสร้างผลงานส่งมอบ

ให้ Kimi Work อ่านแผนผลิตภัณฑ์ ต้นแบบการออกแบบอุตสาหกรรม และแผน GTM ในโฟลเดอร์ภายในเครื่อง จากนั้นใช้ WebBridge เพื่อเข้าสู่ระบบเว็บไซต์แดชบอร์ดข้อมูลที่สมัครใช้งานไว้ในเบราว์เซอร์เพื่อทำการวิจัย ระบบจะวิจัยเชิงลึกเกี่ยวกับภาพรวมตลาด กฎหมายและข้อบังคับในต่างประเทศ และสถานะธุรกิจของคู่แข่ง พร้อมผสานข้อมูลจากแดชบอร์ดเฉพาะเพื่อวิเคราะห์รีวิวผู้ใช้กว่า 2,400 รายการ และสร้างรายงานวิเคราะห์ตลาดอีคอมเมิร์ซข้ามพรมแดนความยาว 128 หน้า จากนั้นเรียกใช้ PPT Skill เฉพาะทางเพื่อเปลี่ยนเนื้อหารายงานและต้นแบบการออกแบบในเครื่องให้เป็นสไลด์นำเสนอได้ในคลิกเดียว

**เวิร์กโฟลว์**: อ่านไฟล์ในเครื่อง ▶ ดูฐานข้อมูลที่สมัครใช้งานไว้ในเบราว์เซอร์ภายในเครื่อง ▶ สร้างรายงานเชิงลึก ▶ เรียกใช้ PPT Skill ▶ ส่งออกแผนสำหรับนำเสนอลูกค้า
