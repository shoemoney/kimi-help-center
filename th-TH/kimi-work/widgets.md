# Widgets

widget คือหน้าเชิงโต้ตอบที่โมเดลสร้างขึ้นและแสดงทันทีในแชท คุณไม่จำเป็นต้องระบุผลงานส่งมอบอย่างชัดเจน — โมเดลจะสร้าง widget เมื่อเหมาะกับสถานการณ์ (เช่น การแสดงแผนที่ การร่างอีเมล การจัดระเบียบสูตรอาหาร หรือการแสดงข้อมูลเป็นภาพ) ช่วยให้คุณเข้าใจคำตอบได้เร็วและเป็นรูปธรรมยิ่งขึ้น

Widgets สามารถเชื่อมต่อกับข้อมูลในเครื่องหรือปลั๊กอินภายนอกเพื่ออัปเดตอย่างต่อเนื่อง และสามารถบันทึกลงใน [Dashboard](/kimi-work/dashboard) เพื่อดูและจัดการในระยะยาว

1. อธิบายสิ่งที่คุณต้องการด้วยภาษาธรรมชาติในแชท เช่น:

3. เมื่อสร้างเสร็จ widget พร้อมให้โต้ตอบได้ทันทีในแชท

## Widget Task และ Live Widget

- **Widget Task**: งานที่รันอัตโนมัติเมื่อเงื่อนไขที่กำหนดเป็นจริง — สามารถทริกเกอร์ตามกำหนดเวลาหรือตามเหตุการณ์ก็ได้
- **Live Widget**: widget ที่ผูกกับ widget task โดยเนื้อหาจะอัปเดตอัตโนมัติทุกครั้งที่งานรัน ตัวอย่างเช่น เมื่อ widget "สรุปข่าวเทคโนโลยีสหรัฐรายวัน" ถูกผูกกับงานที่รันทุกเช้า เนื้อหาของมันจะรีเฟรชอัตโนมัติทุกวัน

<Callout type="info">
มีขีดจำกัดจำนวน widget task ที่รันพร้อมกันได้ และขีดจำกัดนี้แตกต่างกันตามแพลน เมื่อถึงขีดจำกัด ให้หยุดงานบางส่วนชั่วคราวจากหน้า Dashboard ก่อนสร้างงานใหม่
</Callout>

## การบันทึกลงใน Dashboard

หลังจากสร้าง widget แล้ว ให้เลื่อนเมาส์ไปวางบน widget แล้วเลือก "Save to Dashboard" เพื่อบันทึกลงใน dashboard หนึ่ง widget สามารถอยู่ในหลาย dashboard พร้อมกันได้

ใน Dashboard คุณยังสามารถดูงานที่ผูกกับ live widget เปิดหรือปิดงาน และตรวจสอบการรัน 10 ครั้งล่าสุดได้ ดู [Dashboard](/kimi-work/dashboard)
