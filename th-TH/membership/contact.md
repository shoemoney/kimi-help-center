# ติดต่อเรา

ต้องการความช่วยเหลือใช่ไหม นี่คือช่องทางติดต่อเรา

## ฝ่ายดูแลการเรียกเก็บเงินและสมาชิก

**อีเมล:** membership@moonshot.ai

เหมาะสำหรับ:

- เครดิต ไม่ปรากฏหลังการซื้อ
- ปัญหาการชำระเงินหรือการเรียกเก็บเงิน
- การอัปเกรด ดาวน์เกรด หรือยกเลิกแพ็กเกจ
- การขอใบแจ้งหนี้

สมาชิกแบบชำระเงินจะได้รับการตอบกลับเป็นลำดับแรก กรุณาแนบอีเมลบัญชีและภาพหน้าจอที่เกี่ยวข้อง เพื่อให้เราช่วยแก้ไขปัญหาให้คุณได้เร็วยิ่งขึ้น

## ฝ่ายช่วยเหลือทั่วไป

**อีเมล:** support@moonshot.ai

เหมาะสำหรับ:

- คำถามเกี่ยวกับฟีเจอร์ของผลิตภัณฑ์
- ปัญหาทางเทคนิคขณะใช้งาน Kimi
- คำถามเกี่ยวกับบัญชี (ที่ไม่เกี่ยวกับการเรียกเก็บเงิน)
- การขอฟีเจอร์ใหม่และข้อเสนอแนะ

## ฝ่ายช่วยเหลือบริการ API

**อีเมล:** api-service@moonshot.ai
คุณยังสามารถเข้าไปที่ [Kimi OpenPlatform Community](https://forum.moonshot.ai/) ได้อีกด้วย

เหมาะสำหรับ:

- คำถามที่เกี่ยวกับ API
- ปัญหาทางเทคนิคขณะใช้งาน Kimi API
- การขอฟีเจอร์ใหม่และข้อเสนอแนะ

## ข้อเสนอแนะภายในผลิตภัณฑ์

คุณยังสามารถส่งข้อเสนอแนะได้โดยตรงภายใน Kimi:

- **เว็บ:** คลิกปุ่ม **Feedback** ที่มุมล่างซ้าย อธิบายปัญหาของคุณ แล้วกดส่ง
- **มือถือ:** ไปที่ **Profile → Help & Feedback → Submit Feedback**

รายงานที่ส่งภายในผลิตภัณฑ์จะแนบข้อมูลอุปกรณ์และบัญชีของคุณโดยอัตโนมัติ ซึ่งช่วยให้เราวิเคราะห์ปัญหาได้รวดเร็วยิ่งขึ้น
