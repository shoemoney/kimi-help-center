# ภาพรวมแพ็กเกจสมาชิก

Kimi มีแพ็กเกจสมาชิกให้เลือก 5 ระดับ รวมถึงแพ็กเกจฟรี ออกแบบมาให้รองรับทุกความต้องการ ตั้งแต่งานประจำวันไปจนถึงเวิร์กโฟลว์สำหรับผู้ใช้ระดับมืออาชีพ ทุกแพ็กเกจมี **เครดิต สองชุด**: Kimi Code ใช้ เครดิต แยกเป็นชุดของตัวเอง ส่วนฟีเจอร์สมาชิกอื่น ๆ ใช้ เครดิต ร่วมกันอีกชุดหนึ่ง

\* ค่าโดยประมาณอ้างอิงจากการใช้ token ของงานทั่วไป เครดิต รายเดือนถูกแปลงเป็นจำนวนงานที่เทียบเท่าสำหรับฟีเจอร์เดียวกัน ใช้เพื่อการอ้างอิงเท่านั้น

<Callout type="tip">
ใช้ เครดิต ทั้งหมดร่วมกันสำหรับฟังก์ชันเดียวกัน
</Callout>

## การคิดค่าบริการทำงานอย่างไร

- **เครดิต สองชุด** — Kimi Code ใช้ เครดิต แยกเป็นชุดของตัวเอง ส่วนฟีเจอร์สมาชิกอื่น ๆ ใช้ เครดิต ร่วมกันอีกชุดหนึ่ง โดยคิดตามการใช้ token
- **รีเฟรชรายเดือน** — เครดิต จะรีเซ็ตเมื่อเริ่มต้นรอบบิลใหม่
- **ลำดับการใช้งาน** — ใช้ เครดิต โบนัสก่อน แล้วจึงใช้ เครดิต ของแพ็กเกจ
