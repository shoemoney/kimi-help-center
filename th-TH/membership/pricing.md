# รายละเอียดราคา

## การจัดสรร เครดิต

ทุกแพ็กเกจมาพร้อมกับ เครดิต ชุดเดียวที่ใช้ร่วมกัน โดยทั้ง Agent series, Kimi Code และฟีเจอร์สมาชิกอื่น ๆ ต่างดึงจาก เครดิต ชุดเดียวกัน แพ็กเกจระดับสูงกว่าจะได้รับ เครดิต ในสัดส่วนที่มากกว่า รองรับเวิร์กโฟลว์ที่ซับซ้อนและใช้งานบ่อยกว่าได้ ดูรายละเอียดเพิ่มเติมได้ที่ [กฎการอัปเดตและการใช้งาน เครดิต](/membership/update-rules)
