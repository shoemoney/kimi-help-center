## การจัดสรร credit

ฟีเจอร์ทั้งหมดในสมาชิก Kimi ใช้กอง credit ร่วมกัน โดยคิดตามการใช้ token ส่วน Kimi Code มี rate limit แยกของตัวเองที่ 5 ชั่วโมงต่อสัปดาห์ ซึ่งมีผลเฉพาะกับ Kimi Code และไม่กระทบฟีเจอร์อื่น การสนทนา K2.6 ใน Chat ก็คิดจาก credit เช่นกัน แพ็กเกจระดับสูงขึ้นจะมี credit ในสัดส่วนที่มากขึ้น รองรับเวิร์กโฟลว์ที่ใช้งานบ่อยและซับซ้อนกว่า ดูรายละเอียดได้ที่ [การอัปเดต credit และกฎการใช้งาน](/membership/update-rules)

## คำถามที่พบบ่อยเกี่ยวกับ credit

### ตรวจสอบการใช้งาน credit ได้อย่างไร?

- **เว็บ**: คลิกที่รูปโปรไฟล์มุมล่างซ้าย → การตั้งค่า → การสมัครสมาชิก
- **แอป**: ฉัน → แพ็กเกจสมาชิก → การสมัครสมาชิก

คุณสามารถดูยอด credit คงเหลือปัจจุบันเป็นเปอร์เซ็นต์ เวลารีเฟรชครั้งถัดไป และประวัติการใช้งานล่าสุด 1,000 รายการ ซึ่งรวมถึงเวลาที่ใช้งาน ฟีเจอร์ที่ใช้ และเปอร์เซ็นต์ที่ถูกใช้ไป

<Callout type="tip">
รายละเอียดการใช้งานอาจมีความล่าช้าเล็กน้อย โปรดอ้างอิงจากยอด credit ที่แสดงอยู่ปัจจุบันเป็นหลัก
</Callout>

### หาก credit หมดจะเกิดอะไรขึ้น?

งานที่กำลังดำเนินการอยู่จะยังทำงานต่อได้ตามปกติ ส่วนงานใหม่จะแสดงข้อความแจ้งเตือนว่า credit ไม่เพียงพอ คุณสามารถ:

- รอให้ credit รีเฟรชอัตโนมัติในแต่ละเดือน (ขีดจำกัดการใช้งานแบบ 5 ชั่วโมง / รายสัปดาห์ของ Kimi Code ก็จะรีเซ็ตแยกต่างหากเช่นกัน และมีผลเฉพาะกับ Kimi Code เท่านั้น)
- อัปเกรดเป็นแพ็กเกจสมาชิกระดับสูงขึ้นเพื่อรับ credit เพิ่ม
- ซื้อ [แพ็กการใช้งานเพิ่มเติม](/membership/membership-extra-usage): เมื่อเปิดใช้งานแล้ว คุณจะจ่ายตามการใช้งานจริงโดยไม่ต้องรอ credit รีเฟรช
- เข้าร่วมแคมเปญทางการเพื่อรับ credit โบนัส

### ใช้ credit ทั้งหมดกับฟีเจอร์เดียวได้ไหม?

ได้ ฟีเจอร์สมาชิกทั้งหมดใช้พูล credit เดียวกัน คุณจึงจัดสรรได้ตามต้องการ แต่โปรดทราบว่าหากฟีเจอร์ใดฟีเจอร์หนึ่งใช้ credit จนหมด จะส่งผลกระทบต่อฟีเจอร์อื่นด้วยเช่นกัน ทั้งนี้ Kimi Code ยังมี rate limit แบบ 5 ชั่วโมง / รายสัปดาห์ ของตัวเองแยกต่างหาก ซึ่งมีผลเฉพาะกับ Kimi Code เท่านั้น

### รายการหัก “Claw-云主机” 0.6% ทุกวันเวลา 16:00 น. คืออะไร?

นี่คือค่าใช้จ่ายในการรัน sandbox ของโฮสต์บนคลาวด์ Kimi Claw ของคุณ Kimi Claw คือการติดตั้งใช้งาน OpenClaw บนคลาวด์ ทุกครั้งที่คุณเรียกใช้ Claw ระบบจะเปิด sandbox บนคลาวด์ที่แยกอิสระขึ้นมาเพื่อรันโค้ด ควบคุมเบราว์เซอร์ หรือเรียกใช้เครื่องมือต่าง ๆ sandbox ไม่ใช่ “โหมดสแตนด์บายฟรี”—แต่ถูกคิดค่าบริการอย่างต่อเนื่องตามระยะเวลาการทำงานและปริมาณทรัพยากรที่ใช้ แม้ในช่วงที่คุณไม่ได้รันงานอยู่ โฮสต์บนคลาวด์ที่ติดตั้งใช้งานแล้วจะยังคงเก็บสภาพแวดล้อมการทำงานและข้อมูลไว้ ดังนั้น credit สมาชิกของคุณจึงถูกหักประมาณ 0.6% ในแต่ละวัน โดยตัดยอดเวลา 16:00 น.

หากคุณไม่ได้วางแผนจะใช้ Kimi Claw ชั่วคราว ให้บันทึกไฟล์สำคัญ เช่น ไฟล์ memory, soul และ workspace ลงในเครื่องก่อน จากนั้นลบโฮสต์บนคลาวด์ เมื่อลบแล้วจะไม่มีการเรียกเก็บค่าบริการเพิ่ม และคุณสามารถติดตั้งใช้งานใหม่ได้ทุกเมื่อ

### รายการหัก “Agent Website - Cloud Service” 0.08% คืออะไร?

นี่คือค่าบริการคลาวด์สำหรับเว็บไซต์ที่คุณเผยแพร่ด้วย Agent เว็บไซต์ที่เผยแพร่แล้วจะใช้ทรัพยากรคลาวด์อย่างต่อเนื่องเพื่อให้ออนไลน์และเข้าถึงได้ตลอดเวลา จึงมีการหัก credit สมาชิกของคุณประมาณ 0.08% หากคุณไม่ต้องการให้เว็บไซต์ออนไลน์ต่อไป ให้คลิก “ยกเลิกเผยแพร่” เพื่อหยุดการเรียกเก็บค่าบริการ
