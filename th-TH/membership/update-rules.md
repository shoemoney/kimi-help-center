# กฎการอัปเดตและการใช้ เครดิต

<Callout type="info">
สิทธิประโยชน์สมาชิก Kimi ประกอบด้วย เครดิต สองกลุ่ม โดย Kimi Code ใช้ เครดิต แยกต่างหาก ส่วนฟีเจอร์สมาชิกอื่น ๆ ใช้ เครดิต ร่วมกันหนึ่งกลุ่ม และ เครดิต จะถูกหักตามการใช้งานจริง
</Callout>

## เครดิต สองกลุ่มคืออะไร?
แทนที่จะแยก เครดิต ให้แต่ละฟีเจอร์ สมาชิกของคุณจะได้ เครดิต สองกลุ่ม โดย Kimi Code ใช้ เครดิต แยกต่างหาก ส่วนฟีเจอร์สมาชิกอื่น ๆ ใช้ เครดิต ร่วมกันหนึ่งกลุ่มซึ่งใช้ได้ทุกที่:
| ฟีเจอร์ | คำอธิบาย |
|---------|-------------|
| **งาน Agent** | เว็บไซต์ เอกสาร สไลด์ สเปรดชีต deep research |
| **Kimi Claw** | ผู้ช่วย AI ส่วนตัวที่ติดตั้งบนคลาวด์ของคุณ |
| **ฟีเจอร์อื่น ๆ** | การสร้างภาพและอื่น ๆ |

> **Kimi Chat**: สนทนากับโมเดลรุ่นล่าสุด (ไม่หัก เครดิต)
> **Kimi Code**: ผู้ช่วยเขียนโค้ดด้วย AI (ใช้ เครดิต แยกต่างหาก)

<Callout type="tip">
นั่นหมายความว่าคุณจัดสรร เครดิต จากกลุ่มที่ใช้ร่วมกันได้ตามต้องการ — เดือนนี้ทุ่มไปกับงานวิจัยมากหน่อย เดือนหน้าก็เน้นทำเอกสารแทนได้ Kimi Chat ไม่หัก เครดิต และ Kimi Code ใช้ เครดิต แยกของตัวเอง
</Callout>

## เครดิต คำนวณอย่างไร?
เครดิต จะถูกหักตามจำนวน token ที่งานหนึ่งประมวลผล ยิ่งข้อมูลนำเข้าและผลลัพธ์ยาว ก็ยิ่งใช้ token มากขึ้น

<Callout type="info">
**แนวทางคร่าว ๆ สำหรับผู้ใช้แบบฟรี**:
- สร้างชุดสไลด์แบบง่าย ๆ ≈ 1–2% ของ เครดิต ของคุณ
- ทำรายงาน deep research ≈ 5–10%
- เขียนสนิปเปตโค้ด ≈ 0.5–2%
แพ็กเกจระดับสูงขึ้นจะมาพร้อม เครดิต ที่มากขึ้นตามสัดส่วน
</Callout>

## กฎการเติม เครดิต
| กฎ | คำอธิบาย |
|------|-------------|
| **รอบ** | ทั้งสมาชิกรายเดือนและรายปีจะได้รับ เครดิต ตามรอบ **รายเดือน** |
| **การหมดอายุ** | เครดิต ที่ไม่ได้ใช้จะหมดอายุเมื่อสิ้นสุดแต่ละรอบ — ไม่ทบไปรอบถัดไปและไม่แปลงเป็นเงินสด |
| **ข้อจำกัด** | งานแต่ละชิ้นอาจมีข้อจำกัด concurrency แบบ 5 ชั่วโมงและ 7 วันตามที่แสดงใน UI |

## ลำดับการใช้งาน
เมื่อมี เครดิต หลายประเภท จะถูกหักตามลำดับนี้:
1. **เครดิต โบนัส** — ได้รับจากการทดลองใช้ โปรโมชัน หรือรางวัลแนะนำเพื่อน
2. **เครดิต ของแพ็กเกจ** — รวมอยู่ในระดับสมาชิกของคุณ
## เมื่อ เครดิต หมด
- งานที่กำลังดำเนินอยู่จะทำงานต่อจนเสร็จตามปกติ
- งานใหม่จะแสดงข้อความแจ้งว่า "เครดิต ไม่เพียงพอ"
**ตัวเลือกของคุณ**:
- รอให้ เครดิต เติมใหม่ในรอบบิลถัดไป
- อัปเกรดเป็นแพ็กเกจระดับสูงขึ้นเพื่อรับเครดิตรายเดือนที่มากขึ้น
## เครดิต เติมใหม่อย่างไรกันแน่?
1. **อิงตามรอบ** — เครดิต จะเติมใหม่ในวันครบรอบการสมัครสมาชิกของคุณ ไม่ใช่ตามเดือนปฏิทิน
2. **ไม่ทบยอด** — เครดิต ที่เหลือจะถูกรีเซ็ตเป็นศูนย์ จากนั้นจึงเติมเครดิตเต็มจำนวนให้ใหม่
3. **ตัวอย่าง** — หากคุณสมัครเมื่อวันที่ 1 ธันวาคม เวลา 15:00 น. เครดิต ของคุณจะเติมใหม่ในวันที่ 1 มกราคม เวลา 15:00 น.

<Callout type="info">
**ข้อผิดพลาดของระบบ**: หากงานล้มเหลวเนื่องจากปัญหาของระบบ ให้ใช้ปุ่ม 👎 เพื่อรายงานและขอคืน เครดิต
</Callout>
