# ข้อมูลการสนทนาของฉันจะถูกใช้เพื่อฝึกโมเดลหรือไม่

ภายใต้เงื่อนไขที่ข้อมูลผ่านการประมวลผลด้วยเทคโนโลยีการเข้ารหัสที่ปลอดภัย ผ่านการทำให้ไม่ระบุตัวตนอย่างเข้มงวด และไม่สามารถระบุตัวตนของบุคคลใดบุคคลหนึ่งได้อีก แพลตฟอร์มอาจใช้ข้อมูลที่ผู้ใช้ป้อน คำสั่ง และคำตอบที่สร้างขึ้น เพื่อการฝึกโมเดล เพื่อปรับปรุงประสิทธิภาพของโมเดลและประสบการณ์การใช้งานผลิตภัณฑ์

หากคุณไม่ต้องการให้ข้อมูลการสนทนาของคุณถูกใช้เพื่อการฝึก คุณสามารถติดต่อฝ่ายบริการลูกค้าที่ [support@moonshot.ai](mailto:support@moonshot.ai) และแจ้งความประสงค์ หลังจากที่เรายืนยันตัวตนของคุณแล้ว เราจะหยุดใช้เนื้อหาของคุณเพื่อการฝึกโมเดล
