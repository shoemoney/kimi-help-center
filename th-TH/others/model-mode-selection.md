# วิธีเลือก: K2.6 / K3 / K3 Cluster, ความเข้มข้นในการคิด และ Agent

Kimi จะตัดสินใจเองว่าต้องใช้อินเทอร์เน็ตหรือไม่ตามคำถามของคุณ จึงไม่ต้องสลับเองด้วยมือ สิ่งที่คุณต้องเลือกคือ **โมเดล** และ **ความเข้มข้นในการคิด**; สำหรับงานที่ซับซ้อน คุณอาจใช้ **Agent** และ **Agent Cluster** ได้ด้วย

## ตัวเลือกโมเดล 3 แบบ

ใช้ตัวสลับโมเดลเหนือช่องป้อนข้อความเพื่อเลือก:

| โมเดล | ความเข้มข้นในการคิด | เหมาะกับ | credit |
|---|---|---|---|
| **K2.6** | มาตรฐาน / ขั้นสูง | การสนทนาและถาม-ตอบที่ต้องการความรวดเร็ว โดยตอบสนองได้ไวกว่า | **ไม่ใช้ credit สมาชิกใน Chat** |
| **K3** | มาตรฐาน / ขั้นสูง / สูงสุด | การสนทนาและงาน Agent พร้อมความสามารถโดยรวมที่แข็งแกร่งที่สุด | คิดจาก credit |
| **K3 Cluster** | มาตรฐาน / ขั้นสูง / สูงสุด | การค้นหาขนาดใหญ่ การประมวลผลเป็นชุด และการทำงานปริมาณมากให้เสร็จในคราวเดียว | คิดจาก credit |

- **K3** สามารถสร้างเอกสารที่แก้ไขได้แบบครบตั้งแต่ต้นจนจบ เช่น `.pptx`, `.docx`, `.xlsx` และ `.pdf`; ส่วน **K2.6** ปรับแต่งมาเพื่อการถาม-ตอบที่รวดเร็ว และส่งออกเป็นข้อความเท่านั้น เช่น โครงร่าง PPT, เนื้อหา Word, โค้ด ฯลฯ
- สำหรับ **การสร้างรูปภาพ / วิดีโอ / เสียง** ให้คลิก “+” → ปลั๊กอิน จากนั้นเลือกฟีเจอร์ที่เกี่ยวข้องและใช้ร่วมกับ **K3**

<Callout type="info">
K2.6 ที่ใช้งานฟรีและไม่หัก credit ใช้ได้เฉพาะใน Chat (ตัวสลับโมเดลเหนือช่องป้อนข้อความ) เท่านั้น หากใช้เป็น K2.6 Agent ภายใน Kimi Work จะยังคงหัก credit สมาชิก
</Callout>

## ความเข้มข้นในการคิด: มาตรฐาน / ขั้นสูง / สูงสุด

ยิ่งตั้งค่าความเข้มข้นในการคิดสูง โมเดลก็ยิ่งให้เหตุผลได้ครบถ้วนขึ้น และโดยทั่วไปผลลัพธ์จะฉลาดขึ้น แต่ก็จะ **ใช้ token มากขึ้น** ด้วย

- หากต้องการ **ความเร็วและใช้ credit น้อยลง** → เลือก **มาตรฐาน**;
- หากต้องการ **การให้เหตุผลที่แข็งแกร่งขึ้น** สำหรับการวิเคราะห์ที่ซับซ้อนหรือปัญหายาก → เลือก **ขั้นสูง** หรือ **สูงสุด** (K3 / K3 Cluster รองรับระดับสูงสุด)

## Agent และ Agent Cluster

- **Agent สำหรับงานทั่วไป**: วางแผนและทำงานให้เสร็จโดยอัตโนมัติ รวมถึงการสร้างเว็บไซต์ การสร้าง PPT, Deep Research (การวิจัยเชิงลึก) และการประมวลผลเอกสารกับสเปรดชีต
- **Agent Cluster**: รองรับการเรียกใช้เครื่องมือแบบขนานมากกว่า 4,000 ครั้ง และสามารถประสานงาน sub-agent (Sub-agents) ได้สูงสุด 300 ตัวพร้อมกันโดยอัตโนมัติ เหมาะอย่างยิ่งสำหรับงานขนาดใหญ่ เช่น **การค้นหาขนาดใหญ่ การเขียนเนื้อหายาว และการประมวลผลเป็นชุด**

## ควรเลือกอะไรในแต่ละสถานการณ์

- **การถาม-ตอบที่รวดเร็วและการสนทนาทั่วไป** → K2.6 (ไม่ใช้ credit ใน Chat)
- **การสนทนาที่ซับซ้อน การเขียนเอกสาร / การสร้าง PPT และสเปรดชีต / งานหลายขั้นตอน** → K3
- **การค้นหาขนาดใหญ่ การประมวลผลเป็นชุด และการเขียนเนื้อหาที่ยาวมาก** → K3 Cluster
- **ต้องการประหยัด credit** → ใช้ K2.6 หรือตั้งค่าความเข้มข้นในการคิดเป็น “มาตรฐาน”

## FAQ

### “Thinking Mode” ไม่มีให้ใช้งานแล้วหรือ?
Kimi ได้รวม “การสนทนา” และ “Agent” ไว้ในประสบการณ์เดียวกันแล้ว จึงไม่แยกเป็นโหมดต่างหากอีกต่อไป ตอนนี้ “การคิด” ควบคุมได้ด้วย **การเลือกโมเดลและความเข้มข้นในการคิด**—เช่น ใช้ K3 พร้อมความเข้มข้นในการคิดที่สูงขึ้น เพื่อให้ได้การให้เหตุผลที่ละเอียดรอบคอบยิ่งขึ้น

### K2.6 กับ K3 ต่างกันอย่างไร?
K2.6 ปรับแต่งมาเพื่อการถาม-ตอบที่รวดเร็ว ตอบสนองไวกว่า และไม่ใช้ credit สมาชิกใน Chat ส่วน K3 มีความสามารถโดยรวมแข็งแกร่งที่สุด โดดเด่นกับการสนทนาที่ซับซ้อนและงาน Agent สามารถสร้างเอกสารที่แก้ไขได้ครบตั้งแต่ต้นจนจบ และคิดจาก credit

### K3 กับ K3 Cluster ต่างกันอย่างไร?
K3 เหมาะกับการสนทนาทั่วไปและงาน Agent ส่วน K3 Cluster ใช้การทำงานแบบขนานขนาดใหญ่—ทั้งการเรียกใช้เครื่องมือนับพันครั้งและ sub-agent หลายร้อยตัว—เพื่อจัดการงานปริมาณมาก เช่น **การค้นหาขนาดใหญ่ การประมวลผลเป็นชุด และการเขียนเนื้อหาที่ยาวมาก**

### ในหนึ่งรอบสามารถประมวลผลเนื้อหาได้มากแค่ไหน?
K2.6 รองรับบริบทในหนึ่งรอบได้ประมาณ 128K token (ราว 50,000–60,000 ตัวอักษรจีน); K3 มีหน้าต่างบริบท 1 ล้าน token (ต้องมีสิทธิประโยชน์สมาชิกระดับสูงสุด) ดูรายละเอียดได้ที่ [ควรทำอย่างไรหากบทสนทนายาวเกิน 200,000 ตัวอักษรจีน?](/others/chat-issues)
