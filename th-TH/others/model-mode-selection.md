# วิธีเลือก: K2.6 / K3 / K3 Cluster, ระดับความเข้มข้นในการคิด และ Agent

Kimi จะตัดสินใจเองว่าจะใช้อินเทอร์เน็ตหรือไม่ตามคำถามของคุณ คุณจึงไม่ต้องสลับเอง สิ่งที่คุณต้องเลือกคือ **โมเดล** และ **ระดับความเข้มข้นในการคิด**; สำหรับงานที่ซับซ้อน คุณอาจใช้ **Agent** และ **Agent Cluster** ได้ด้วย

## ตัวเลือกโมเดล 3 แบบ

ใช้ตัวสลับโมเดลเหนือช่องป้อนข้อความเพื่อเลือก:

| โมเดล | ระดับความเข้มข้นในการคิด | เหมาะกับ | credit |
|---|---|---|---|
| **K2.6** | Standard / Advanced | การสนทนาและ Q&A ที่ต้องการความรวดเร็ว พร้อมการตอบสนองที่เร็วกว่า | **ไม่ใช้ credit สมาชิก** |
| **K3** | Standard / Advanced / Extreme | การสนทนาและงาน Agent พร้อมความสามารถโดยรวมที่แข็งแกร่งที่สุด | คิดจาก credit |
| **K3 Cluster** | Standard / Advanced / Extreme | การค้นหาขนาดใหญ่ การประมวลผลเป็นชุด และการทำงานปริมาณมากให้เสร็จในครั้งเดียว | คิดจาก credit |

- **K3** สามารถสร้างเอกสารที่แก้ไขได้แบบครบกระบวนการ เช่น `.pptx`, `.docx`, `.xlsx` และ `.pdf`; ส่วน **K2.6** ปรับแต่งมาเพื่อ Q&A ที่รวดเร็ว และส่งออกเป็นข้อความเท่านั้น เช่น โครงร่าง PPT, เนื้อหา Word, โค้ด และอื่น ๆ
- สำหรับ **การสร้างภาพ / วิดีโอ / เสียง** ให้คลิก “+” → ปลั๊กอิน จากนั้นเลือกฟีเจอร์ที่เกี่ยวข้องแล้วใช้งานร่วมกับ **K3**

## ระดับความเข้มข้นในการคิด: Standard / Advanced / Extreme

ยิ่งระดับความเข้มข้นในการคิดสูง โมเดลก็จะใช้เหตุผลได้ครบถ้วนมากขึ้น และโดยทั่วไปผลลัพธ์จะฉลาดขึ้นด้วย แต่ก็จะ **ใช้ token มากขึ้น** เช่นกัน

- หากต้องการ **ความเร็วและใช้ credit น้อยลง** → เลือก **Standard**;
- หากต้องการ **การใช้เหตุผลที่แข็งแกร่งขึ้น** สำหรับการวิเคราะห์ซับซ้อนหรือปัญหายาก → เลือก **Advanced** หรือ **Extreme** (Extreme รองรับโดย K3 / K3 Cluster)

## Agent และ Agent Cluster

- **Agent อเนกประสงค์**: วางแผนและทำงานให้เสร็จโดยอัตโนมัติ รวมถึงการสร้างเว็บไซต์ การสร้าง PPT, Deep Research (การวิจัยเชิงลึก) และการประมวลผลเอกสารกับสเปรดชีต
- **Agent Cluster**: รองรับการเรียกใช้เครื่องมือแบบขนานมากกว่า 4,000 ครั้ง และสามารถประสานงาน sub-agent (Sub-agents) ได้สูงสุด 300 ตัวแบบขนาน เหมาะอย่างยิ่งสำหรับงานขนาดใหญ่ เช่น **การค้นหาขนาดใหญ่ การเขียนเนื้อหายาว และการประมวลผลเป็นชุด**

## ควรเลือกอะไรในแต่ละสถานการณ์

- **Q&A ที่รวดเร็วและการสนทนาทั่วไปในชีวิตประจำวัน** → K2.6 (ไม่ใช้ credit)
- **การสนทนาซับซ้อน การเขียนเอกสาร / การสร้าง PPT และสเปรดชีต / งานหลายขั้นตอน** → K3
- **การค้นหาขนาดใหญ่ การประมวลผลเป็นชุด และการเขียนเนื้อหาที่ยาวมาก** → K3 Cluster
- **ต้องการประหยัด credit** → ใช้ K2.6 หรือปรับระดับความเข้มข้นในการคิดเป็น “Standard”

## FAQ

### “Thinking Mode” ยังไม่มีให้ใช้แล้วหรือ?
Kimi ได้รวม “การสนทนา” และ “Agent” ไว้ในประสบการณ์เดียว จึงไม่ได้แยกเป็นโหมดต่างหากอีกต่อไป ตอนนี้ “การคิด” ควบคุมได้ด้วย **การเลือกโมเดลและระดับความเข้มข้นในการคิด**—เช่น การใช้ K3 พร้อมระดับความเข้มข้นในการคิดที่สูงขึ้น จะให้การใช้เหตุผลที่ละเอียดรอบคอบกว่า

### K2.6 กับ K3 ต่างกันอย่างไร?
K2.6 ปรับแต่งมาเพื่อ Q&A ที่รวดเร็ว ตอบสนองเร็วกว่า และไม่ใช้ credit สมาชิก ส่วน K3 มีความสามารถโดยรวมแข็งแกร่งที่สุด โดดเด่นในการสนทนาซับซ้อนและงาน Agent สามารถสร้างเอกสารที่แก้ไขได้แบบครบกระบวนการ และคิดจาก credit

### K3 กับ K3 Cluster ต่างกันอย่างไร?
K3 เหมาะกับการสนทนาทั่วไปและงาน Agent ส่วน K3 Cluster ใช้การประมวลผลแบบขนานขนาดใหญ่—ทั้งการเรียกใช้เครื่องมือนับพันครั้งและ sub-agent หลายร้อยตัว—เพื่อจัดการงานปริมาณมาก เช่น **การค้นหาขนาดใหญ่ การประมวลผลเป็นชุด และการเขียนเนื้อหาที่ยาวมาก**

### ในหนึ่งรอบสามารถประมวลผลเนื้อหาได้มากแค่ไหน?
K2.6 รองรับบริบทแบบรอบเดียวประมาณ 128K token (ราว 50,000–60,000 ตัวอักษรจีน); K3 มีหน้าต่างบริบท 1 ล้าน token (ต้องใช้สิทธิประโยชน์สมาชิกระดับสูงสุด) ดูรายละเอียดที่ [ควรทำอย่างไรหากบทสนทนาเกิน 200,000 ตัวอักษรจีน?](/others/chat-issues)
