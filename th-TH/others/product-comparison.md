# Kimi, Kimi Work, Kimi Code และ Kimi Claw ต่างกันอย่างไร? ควรใช้ตัวไหนดี?

Kimi มีทั้งผู้ช่วยออนไลน์ที่พร้อมใช้งานทันที และผลิตภัณฑ์อีกหลายแบบที่ออกแบบมาสำหรับผู้ใช้และสถานการณ์ที่แตกต่างกัน ผลิตภัณฑ์เหล่านี้ใช้ความสามารถหลักของ Kimi ร่วมกัน สิ่งที่ต่างกันหลัก ๆ คือ **คุณใช้งานที่ไหน ออกแบบมาเพื่อใคร และถนัดงานประเภทใดเป็นพิเศษ**

## ภาพรวมโดยย่อ

| ผลิตภัณฑ์ | คืออะไร | เหมาะกับ / สถานการณ์ใช้งาน | ใช้งานได้ที่ไหน |
|---|---|---|---|
| **Kimi** (เว็บ / App) | ผู้ช่วย AI ออนไลน์ที่รวมแชตและ Agent ไว้ด้วยกัน | ถาม-ตอบทั่วไป งานเขียน ค้นหา สร้างเว็บไซต์ / PPT / เอกสารและสเปรดชีต Deep Research และอื่น ๆ | เว็บ, App มือถือ |
| **Kimi Work** | **Agent ในเครื่อง** สำหรับคนทำงานสายความรู้ (เดสก์ท็อป) | ทำงานกับไฟล์ในเครื่องคอมพิวเตอร์ อัตโนมัติงานข้ามแอปเดสก์ท็อป และส่งมอบงานที่ใช้เวลานาน | ไคลเอนต์ Mac / Windows |
| **Kimi Code** | ชุดผู้ช่วยเขียนโค้ดสำหรับ **นักพัฒนา** | เขียนโค้ดและดูแลรักษา codebase | CLI, ส่วนขยาย VS Code |
| **Kimi Claw** | แพลตฟอร์ม **อัตโนมัติบนคลาวด์แบบไม่ต้อง deploy** | ระบบอัตโนมัติบนคลาวด์ที่ทำงานตลอด 24×7, บอตที่เชื่อมต่อกับ Feishu / WeChat และอื่น ๆ | คลาวด์ (ไม่ต้องมีเซิร์ฟเวอร์) |

## ควรใช้ตัวไหนดี?

- **ถ้าต้องการแชตทั่วไป เขียนงาน ค้นหา หรือให้ Kimi สร้างเว็บไซต์ ทำ PPT และสเปรดชีต หรือทำ Deep Research** → ใช้ **Kimi** (เว็บ / App)
- **ถ้าต้องการให้ Kimi อ่านและเขียนไฟล์ในเครื่องคอมพิวเตอร์ อัตโนมัติงานข้ามหลายแอปเดสก์ท็อป หรือรันงานที่ใช้เวลานาน** → ใช้ **Kimi Work** (เดสก์ท็อป)
- **ถ้าคุณเป็นนักพัฒนาและต้องการความช่วยเหลือด้านการเขียนโค้ดหรือดูแลโปรเจกต์เป็นหลัก** → ใช้ **Kimi Code**
- **ถ้าต้องการบอตบนคลาวด์ที่ทำงานตลอดเวลา รันอัตโนมัติ และเชื่อมต่อกับ Feishu / WeChat รวมถึงแพลตฟอร์มอื่น ๆ ได้** → ใช้ **Kimi Claw**

<Callout type="tip">
ประสบการณ์ออนไลน์ของ Kimi รวม “แชต” และ “Agent” ไว้ด้วยกันแล้ว คุณไม่จำเป็นต้องสลับไปมา ในแอปเดสก์ท็อป Kimi Work มี 2 โหมด ได้แก่ “Work” (โหมด Agent ที่เน้นผลลัพธ์ส่งมอบ) และ “Chat” (สนทนาแบบรวดเร็ว)
</Callout>

## ควรเลือกสมาชิกแผนไหน?

สิทธิประโยชน์สมาชิกผูกกับบัญชี Kimi ของคุณ ฟีเจอร์สมาชิกทั้งหมด (แชต, Agent, Deep Research, Kimi Code และอื่น ๆ) **ใช้ credit pool เดียวกัน**; Kimi Code ยังมี rate limit แยกต่างหากที่ 5 ชั่วโมง / สัปดาห์ ซึ่งมีผลเฉพาะกับ Kimi Code เท่านั้น ดูรายละเอียดแผนและราคาได้ที่ [หน้าสมัครสมาชิก](/membership/membership-pricing)

หากการใช้งานของคุณส่วนใหญ่เป็น **งานประจำวัน + งานเป็นครั้งคราว** แผนสมาชิก Kimi ที่เหมาะสมจะครอบคลุมสถานการณ์ส่วนใหญ่ทั้งบนเว็บ / App / Kimi Work ส่วนผู้พัฒนาที่ **เขียนโค้ดเป็นประจำ** อาจควรให้ความสำคัญกับสิทธิประโยชน์ของ Kimi Code เป็นพิเศษ
