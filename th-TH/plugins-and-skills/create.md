# วิธีสร้างปลั๊กอินส่วนตัว

ใน Kimi Work คุณสามารถใช้ทักษะ **Plugin Builder** แบบในตัว เพื่อเปลี่ยนไอเดียหนึ่งประโยค คลังปลั๊กอินภายนอก หรือหน้าเว็บใดก็ได้ให้เป็นปลั๊กอินของคุณเอง ไม่ว่าจะเลือกวิธีไหน ปลั๊กอินจะมาถึงคุณผ่านเส้นทางเดียวกัน: **สร้าง / แปลง → ลงทะเบียนในตลาดปลั๊กอินส่วนตัว (แท็บ "ส่วนตัว") → คลิก + เพื่อติดตั้ง → ใช้งานในการสนทนา** เมื่อติดตั้งแล้ว ปลั๊กอินจะพร้อมใช้งานในการสนทนาปัจจุบันทันที ไม่ต้องรีสตาร์ท

ก่อนเริ่มต้น ตรวจสอบให้แน่ใจว่าคุณได้ติดตั้งแอปเดสก์ท็อป [Kimi Work](https://www.kimi.ai/products/kimi-work) เวอร์ชันล่าสุดแล้ว Plugin Builder เป็นทักษะแบบในตัว ไม่ต้องติดตั้งเพิ่มเติม: พิมพ์ "/" ในการสนทนาเพื่อเรียกใช้ หรือคลิก "ปลั๊กอินแบบกำหนดเอง" ในตลาดปลั๊กอินเพื่อเริ่มสร้างในการสนทนาหลัก

## สร้างปลั๊กอินใหม่ด้วยประโยคเดียว

เหมาะกับกรณี "มีไอเดียแต่ยังไม่มีโค้ด" คุณเพียงอธิบายความสามารถที่ต้องการ Plugin Builder จะจัดการ scaffolding การกรอกข้อมูล การตรวจสอบในเครื่อง และการลงทะเบียนให้โดยอัตโนมัติ คุณไม่ต้องเขียนไฟล์ใด ๆ ด้วยตนเองเลย

1. **อธิบายสิ่งที่ต้องการ** เรียกใช้ Plugin Builder ในการสนทนาแล้วอธิบายในหนึ่งประโยคว่าปลั๊กอินควรทำอะไร เช่น "สร้างปลั๊กอินที่ค้นหาข้อมูลการจดทะเบียนบริษัทให้หน่อย" ข้อมูลที่อนุมานได้ เช่น ชื่อ คำอธิบาย และหมวดหมู่ จะถูกกรอกให้โดยอัตโนมัติ เฉพาะข้อมูลที่อนุมานไม่ได้ เช่น URL ของ MCP server หรือไอคอน เท่านั้นที่จะมีการยืนยันกับคุณ
2. **รอให้สร้างเสร็จ** Plugin Builder จะสร้างไฟล์ปลั๊กอินในเครื่องของคุณ ผ่านการตรวจสอบโครงสร้างและข้อกำหนดโดยอัตโนมัติ จากนั้นลงทะเบียนปลั๊กอินในตลาดปลั๊กอินส่วนตัวของคุณ
3. **ติดตั้งและใช้งาน** เปิด **ปลั๊กอิน → ส่วนตัว** ค้นหาปลั๊กอินที่เพิ่งสร้าง แล้วคลิก + เพื่อติดตั้ง เมื่อติดตั้งแล้วจะพร้อมใช้งานในการสนทนาปัจจุบันทันที และคุณสามารถเรียกใช้ได้ทุกเมื่อด้วย "/"

## นำเข้าปลั๊กอินจากตลาดหรือคลัง

ส่งลิงก์คลังปลั๊กอินให้ Plugin Builder แล้วมันจะจดจำรูปแบบ แปลงรูปแบบ และติดตั้งไปยังแท็บ "ส่วนตัว" ของคุณโดยอัตโนมัติ ปลั๊กอินที่นำเข้าจะไม่รบกวนตลาดอย่างเป็นทางการ และสามารถถอนการติดตั้งได้ทุกเมื่อ

1. **รูปแบบปลั๊กอินที่รองรับ:** Plugin Builder จดจำ manifest ของปลั๊กอินจากแหล่งต่อไปนี้ และแปลงทั้งหมดเป็นรูปแบบ `kimi.plugin.json` ดั้งเดิมของ Kimi:

| รูปแบบ | หมายเหตุ |
| --- | --- |
| `kimi.plugin.json` | รูปแบบดั้งเดิมของ Kimi: ฟิลด์ที่จำเป็นจะถูกแก้ไขให้ถูกต้อง |
| manifest ของปลั๊กอินจากแพลตฟอร์ม agent อื่น | เช่น ไฟล์ `plugin.json` ในไดเรกทอรีอย่าง `.codex-plugin/plugin.json` หรือ `.claude-plugin/plugin.json` รวมถึงไฟล์ดัชนีตลาดที่แพลตฟอร์มเหล่านั้นแนบมาด้วย |
| `server.json` | รูปแบบ registry อย่างเป็นทางการของ MCP: จะถูกแปลงเป็นปลั๊กอินที่มีเฉพาะบริการ MCP |
| `plugin.json` ทั่วไป | manifest ทั่วไปที่อยู่ในไดเรกทอรีรากของปลั๊กอิน |

2. **วิธีนำเข้า:** ส่งลิงก์คลังให้ Plugin Builder มันจะจดจำรูปแบบคลังต่อไปนี้โดยอัตโนมัติ:

- **คลังปลั๊กอินเดี่ยว**: ทั้งคลังจะถูกแปลงเป็นปลั๊กอินหนึ่งตัว;
- **คลังหลายปลั๊กอิน (monorepo)**: แต่ละไดเรกทอรีย่อยจะถูกแปลงเป็นปลั๊กอินของตัวเอง;
- **คลังตลาดปลั๊กอิน / คลังดัชนี** (คลังที่มีดัชนี plugins.json หรือ marketplace.json): ทุกรายการในดัชนีจะถูกขยายและแปลงเป็นชุด;
- **คลังที่มีเฉพาะ Skills**: คลังที่ไม่มี manifest ของปลั๊กอิน มีเฉพาะไฟล์ skill จะถูกบรรจุเป็นปลั๊กอินประเภท skill

3. **ติดตั้งจากแท็บส่วนตัว:** เมื่อประมวลผลเสร็จ Plugin Builder จะบอกว่าปลั๊กอินใดใช้งานได้ ไปที่ **ปลั๊กอิน → ส่วนตัว** แล้วคลิก "ติดตั้ง" บนการ์ดที่เกี่ยวข้องเพื่อเริ่มใช้งานในการสนทนา

**การจัดการปลั๊กอินที่นำเข้า:**

- **อัปเดตปลั๊กอิน**: หากคลังต้นทางมีการอัปเดต หรือคุณต้องการเปลี่ยนชื่อหรือคำอธิบาย เพียงบอก Plugin Builder มันจะแปลงใหม่หรือแก้ไขแล้วลงทะเบียนอีกครั้ง
- **ถอนการติดตั้ง / ลบ**: ถอนการติดตั้งจากแท็บ "ส่วนตัว" เพื่อปิดใช้งานปลั๊กอิน รายการจะยังคงอยู่ในแท็บหลังจากถอนการติดตั้ง หากต้องการลบออกอย่างสมบูรณ์ให้ลบรายการนั้น
- **ไดเรกทอรีต้นทาง**: ผลลัพธ์ที่แปลงแล้วจะถูกเก็บไว้ในไดเรกทอรี plugins/ ของ workspace ในเครื่องของคุณ ซึ่งเป็น "ไฟล์ต้นฉบับ" ของปลั๊กอิน และ Plugin Builder จะอ้างอิงจากมันสำหรับการอัปเดตในอนาคต โปรดอย่าลบด้วยตนเอง

## เปลี่ยนหน้าเว็บให้เป็นปลั๊กอิน

เหมาะกับกรณี "เว็บไซต์ที่ใช้บ่อยไม่มี API สาธารณะ แต่อยากให้ Kimi ดึงข้อมูลและจัดการให้" ส่ง URL ให้ Plugin Builder พร้อมอธิบายสิ่งที่ต้องการ เช่น "เปลี่ยนเว็บไซต์ XX ให้เป็นปลั๊กอิน ฉันอยากค้นหา XX" มีตัวเลือกเบราว์เซอร์สองแบบสำหรับวิเคราะห์เว็บไซต์และรันปลั๊กอิน:

| วิธี | เหมาะกับ | สิ่งที่คุณต้องมี |
| --- | --- | --- |
| **เบราว์เซอร์ในตัว (ค่าเริ่มต้น)** | เว็บไซต์ส่วนใหญ่ ใช้เบราว์เซอร์ในตัวของ Kimi Work เพื่อวิเคราะห์เว็บไซต์และรันปลั๊กอิน | ไม่ต้องติดตั้งอะไรเลย เมื่อต้องเข้าสู่ระบบ ให้เข้าสู่ระบบหนึ่งครั้งในเบราว์เซอร์ในตัว |
| **WebBridge (wb)** | ใช้บัญชีที่คุณเข้าสู่ระบบอยู่แล้วใน Chrome ซ้ำ | ติดตั้ง WebBridge ก่อน แล้วใช้มันขับ Chrome ของคุณ |

1. **วิเคราะห์เว็บไซต์** Plugin Builder จะเปิด URL ในเบราว์เซอร์ที่คุณเลือก หากหน้าเว็บต้องเข้าสู่ระบบ ระบบจะขอให้คุณเข้าสู่ระบบหนึ่งครั้งในเบราว์เซอร์ โดยจะไม่ถามรหัสผ่าน cookie หรือข้อมูลประจำตัวใด ๆ ของคุณ
2. **วิศวกรรมย้อนกลับ API และสร้างปลั๊กอิน** มันจะใช้งานฟีเจอร์หลักบนหน้าเว็บจริง จับภาพ network request คาดคะเน API ข้อมูลภายในของเว็บไซต์ จากนั้นสร้างปลั๊กอินประเภท skill ที่มีสคริปต์ค้นหาในตัว
3. **ตรวจสอบ ลงทะเบียน ติดตั้ง** เช่นเดียวกับวิธีก่อนหน้า: เมื่อปลั๊กอินผ่านการตรวจสอบ จะถูกลงทะเบียนในแท็บ "ส่วนตัว" คลิก + เพื่อติดตั้งและเริ่มใช้งาน

จากนั้นเป็นต้นไป เพียงพูดว่า "ค้นหา XX ให้หน่อย" แล้ว Kimi จะใช้ปลั๊กอินดึงข้อมูลโดยตรงในเบราว์เซอร์และจัดระเบียบผลลัพธ์ หาก API ของเว็บไซต์เปลี่ยนและปลั๊กอินหยุดทำงาน ให้ขอ Plugin Builder วิเคราะห์เว็บไซต์ใหม่และอัปเดตปลั๊กอิน
