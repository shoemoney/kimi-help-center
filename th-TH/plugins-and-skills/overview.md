# ปลั๊กอิน Kimi คืออะไร?

ปลั๊กอินเชื่อมต่อเครื่องมือภายนอกเข้ากับ Kimi เพื่อให้ Kimi ใช้งานแอปและบริการต่าง ๆ ในการทำงานให้สำเร็จ เมื่อคุณติดตั้งปลั๊กอินแล้ว Kimi สามารถเรียกใช้ความสามารถของบุคคลที่สามที่เกี่ยวข้องได้โดยตรงระหว่างทำงาน เช่น ค้นคว้าข้อมูลการเงิน ใช้งานซอฟต์แวร์สำนักงาน หรือใช้เครื่องมือออกแบบ คุณสามารถระบุให้ใช้ปลั๊กอินที่ต้องการได้ชัดเจน และ Kimi ก็จะเรียกใช้ปลั๊กอินโดยอัตโนมัติเมื่อเหมาะสม

## ปลั๊กอิน Kimi คืออะไร?

ปลั๊กอิน Kimi เป็นไปตาม[นิยามปลั๊กอินของ Kimi Code](https://www.kimi.com/code/docs/kimi-code-cli/customization/plugins.html#plugin-manifest) และสามารถประกอบด้วยส่วนประกอบอย่างน้อยหนึ่งอย่างต่อไปนี้:

| ส่วนประกอบ | หน้าที่ |
| --- | --- |
| Skills | ให้ความรู้ ขั้นตอน และคำแนะนำการใช้งานที่จำเป็นในการทำงานให้สำเร็จ |
| MCP | เชื่อมต่อซอฟต์แวร์ บริการ ฐานข้อมูล หรือ API ภายนอก |
| Agents | มอบหมายงานที่ซับซ้อนให้ sub-agent เฉพาะทาง |
| Hooks | รันการกระทำที่กำหนดไว้ล่วงหน้าโดยอัตโนมัติเมื่อเกิดเหตุการณ์ที่ระบุ |
| Commands | ให้จุดเข้าใช้งานในรูปแบบคำสั่งที่ชัดเจนและนำกลับมาใช้ซ้ำได้ |
| System Prompt | เพิ่มคำสั่งระบบให้ Agent หลักขณะที่ปลั๊กอินถูกเปิดใช้งาน |

ประสบการณ์ Kimi บนเว็บปัจจุบันรองรับ MCP และ Skills ในปลั๊กอิน ส่วน Kimi Work และ Kimi Code เป็นไปตามนิยามปลั๊กอินฉบับเต็มข้างต้น และรองรับการผสมผสานส่วนประกอบของปลั๊กอินที่สมบูรณ์ยิ่งขึ้น

**ตัวอย่าง:**

- **ปลั๊กอิน Notion** = Notion MCP + Skill แนะนำการใช้งาน
- **ปลั๊กอินวิจัยการเงิน** = MCP การเงินหลายตัว + Skills วิเคราะห์หลายตัว + Agent ที่ปรับแต่งเอง

## ใช้ปลั๊กอินได้ที่ไหน

คุณสามารถใช้ปลั๊กอินได้เมื่อสลับโมเดลเป็น **K3** หรือ **K3 Swarm** และในสถานการณ์ **Deep Research, Websites และ PPT**

คุณยังใช้ปลั๊กอินได้ใน**แอปเดสก์ท็อป Kimi Work** สำหรับรายการปลั๊กอินในตัวบนเดสก์ท็อป ดูที่[ศูนย์ปลั๊กอิน Kimi Work](/kimi-work/plugin-center)

<Callout type="info">
ปลั๊กอินยังไม่รองรับใน Kimi Claw หรือการสนทนา Kimi Plus
</Callout>

## การติดตั้งปลั๊กอิน

- **จุดเข้าใช้งาน**: ใช้ปุ่ม **+** ในกล่องป้อนข้อความหรือพิมพ์ "/"; บนมือถือ ใช้ปุ่ม **+** ในกล่องป้อนข้อความหรือ "/"
- ค้นหาหรือเรียกดูในตลาดปลั๊กอิน เปิดรายละเอียดของปลั๊กอิน แล้วคลิกติดตั้ง
- ปลั๊กอินบางตัวต้องมี**การยืนยันตัวตนผ่าน OAuth** (ระบบจะพาคุณไปยังหน้าเข้าสู่ระบบของบุคคลที่สาม เมื่อยืนยันตัวตนแล้วก็ใช้งานได้ทันที); ปลั๊กอินบางตัว**ติดตั้งไว้ล่วงหน้า**และไม่ต้องติดตั้งด้วยตนเอง
- **ปลั๊กอินเฉพาะองค์กร**: ผู้ใช้ที่ไม่ใช่องค์กรจะเห็นปลั๊กอินเหล่านี้ แต่ปุ่ม "ติดตั้ง" จะเป็นสีเทา
- คุณไม่สามารถติดตั้งหรือใช้ปลั๊กอินในขณะที่ออกจากระบบอยู่

## การใช้งานปลั๊กอิน

- หลังจากติดตั้งแล้ว พิมพ์ "/" ในกล่องป้อนข้อความหรือคลิก **+** → ปลั๊กอิน แล้วเลือกปลั๊กอินเพื่อเรียกใช้ คุณสามารถ**เรียกใช้หลายปลั๊กอินพร้อมกัน**ได้
- คุณยังสามารถอธิบายสิ่งที่ต้องการได้โดยตรง (เช่น "ค้นหาบริษัทนี้ใน Tianyancha") แล้ว Kimi จะเลือกปลั๊กอินที่เหมาะสมโดยอัตโนมัติ
- เมื่อ Kimi เรียกใช้เครื่องมือของปลั๊กอิน จะแสดง "กำลังใช้ปลั๊กอิน xx" ในคำตอบ

## หมวดหมู่และรายการปลั๊กอิน

ตลาดปลั๊กอินแบ่งเป็นหมวดหมู่ด้านล่างนี้ ปลั๊กอินที่คุณเห็นจริงจะแตกต่างกันตาม**ภูมิภาค (ในประเทศ / ต่างประเทศ)** และ**แพลตฟอร์มที่ใช้งาน** และปลั๊กอินบางตัวอาจปรากฏในมากกว่าหนึ่งหมวดหมู่

- **การเงิน**: Financial Investment Analysis, Investment Banking & Private Equity, Corporate Finance & Accounting, Wind Financial Data, S&P Global Market Intelligence, Hundsun Gildata, Tonghuashun iFinD, SEC, Global Financial Database, World Bank Open Data, IMF (International Monetary Fund) Database, Stripe, Tianyancha
- **ประสิทธิภาพการทำงาน**: Notion, Baidu Netdisk
- **การพัฒนา**: GitHub, Supabase, Neon, Cloudflare
- **สร้างสรรค์**: Inspiration Pool, Image Generation, Video Generation, Audio Generation, Canva
- **ทั่วไป**: Vivify

## ข้อมูลและสิทธิ์การเข้าถึง

- เมื่อคุณเลือกหรือระบุให้ใช้ปลั๊กอินอย่างชัดเจน Kimi จะให้ความสำคัญกับเครื่องมือที่ปลั๊กอินนั้นมีให้ และสร้างคำตอบจากผลลัพธ์ที่เครื่องมือเหล่านั้นส่งกลับมา หลังจากเชื่อมต่อปลั๊กอินแล้ว Kimi จะเข้าถึงเนื้อหาที่เกี่ยวข้องภายในขอบเขตที่คุณอนุญาต
- หากปลั๊กอินให้บริการโดยบุคคลที่สาม กฎการประมวลผลข้อมูลจะถูกกำหนดโดยบริษัทนั้นอย่างอิสระ และข้อมูลจะอยู่ภายใต้ข้อกำหนดการให้บริการและนโยบายความเป็นส่วนตัวของบริษัทนั้น เราแนะนำให้อ่านก่อนยืนยันตัวตน
- คุณสามารถ**ถอนการติดตั้งปลั๊กอินหรือเพิกถอนการยืนยันตัวตนได้ทุกเมื่อ** หลังจากถอนการติดตั้ง การยืนยันตัวตน OAuth ที่เกี่ยวข้องจะถูกเพิกถอน หากต้องการใช้ปลั๊กอินอีกครั้ง คุณจะต้องติดตั้งและยืนยันตัวตนใหม่

## คำถามที่พบบ่อย

### ปลั๊กอินใช้ credit สมาชิกของฉันไหม?
บางตัวใช้ เมื่อ Kimi เรียกใช้เครื่องมือหรือบริการของปลั๊กอินเพื่อทำงานให้สำเร็จ credit จะถูกใช้ตามการใช้งานจริง ปลั๊กอินที่เรียกใช้โดยไม่มีค่าใช้จ่ายจะไม่มีการเรียกเก็บเพิ่ม

### ใช้หลายปลั๊กอินพร้อมกันได้ไหม?
ได้ คุณสามารถเรียกใช้หลายปลั๊กอินพร้อมกันผ่าน "/" หรือ **+**

### ทำไมฉันมองไม่เห็นปลั๊กอินบางตัว?
ปลั๊กอินที่ใช้ได้จะแตกต่างกันตามภูมิภาค (ในประเทศ / ต่างประเทศ) และแพลตฟอร์มที่ใช้งาน นอกจากนี้ ปลั๊กอินบางตัวมีให้เฉพาะผู้ใช้ส่วนบุคคลหรือผู้ใช้องค์กรเท่านั้น

### ใช้ปลั๊กอินจาก ChatGPT, Claude หรือแพลตฟอร์มอื่นได้ไหม?
ได้ ดูที่[วิธีสร้างปลั๊กอินส่วนตัว](/plugins-and-skills/create): ส่งไฟล์ปลั๊กอินหรือลิงก์โปรเจกต์ที่มีอยู่จากแพลตฟอร์มอื่นให้ Plugin Builder แล้วทำตามคำแนะนำเพื่อแปลงเป็นปลั๊กอิน Kimi
