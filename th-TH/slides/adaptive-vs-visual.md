# ความแตกต่างระหว่าง adaptive และ visual

Kimi Slides มีโหมดการสร้างให้เลือกสองแบบ เลือกแบบที่ตอบโจทย์คุณที่สุด:

| | Adaptive | Visual |
|--|---------|---------|
| **แนวทางการออกแบบ** | Kimi สร้างเลย์เอาต์และสไตล์ให้อย่างชาญฉลาด | เลือกจากเทมเพลตสำเร็จรูป |
| **เหมาะกับ** | ดีไซน์เฉพาะตัวที่ไม่ซ้ำใคร | ผลลัพธ์ที่รวดเร็วและมีประสิทธิภาพ |
| **เวลาโดยประมาณ** | 30–60 นาที | 5–10 นาที |

## โหมด Adaptive

Kimi ออกแบบเลย์เอาต์และสไตล์ให้อย่างชาญฉลาด โดย AI จะจับคู่สี ฟอนต์ ไอคอน และสไตล์กราฟให้เข้ากับเนื้อหาของคุณโดยอัตโนมัติ พร้อมรองรับสไตล์สำเร็จรูปหลากหลายรูปแบบ (ธุรกิจ วิชาการ เทคโนโลยี มินิมอล ฯลฯ) เหมาะกับงานที่ต้องการเอกลักษณ์ทางภาพและการนำเสนอที่เป็นเฉพาะตัว

## โหมด Visual

เลือกเทมเพลตจากคลังสำเร็จรูป โหมด Visual ขับเคลื่อนด้วย Nano Banana Pro เหมาะอย่างยิ่งสำหรับการสร้างงานนำเสนออย่างรวดเร็ว เทมเพลตครอบคลุมทั้งธุรกิจ การศึกษา เทคโนโลยี และอื่น ๆ เมื่อคุณเลือกเทมเพลตแล้ว Kimi จะเติมเนื้อหาให้โดยอัตโนมัติและสร้างสไลด์ที่เสร็จสมบูรณ์

## วิธีเลือกสถานการณ์และเทมเพลต

โหมด Adaptive มีตัวเลือกสถานการณ์ให้หลากหลาย ทั้งงานวิจัยวิชาการ ข้อมูลเชิงลึกทางธุรกิจ และการตลาดกับการโปรโมต ช่วยให้คุณสร้างงานนำเสนอที่ตรงกับการใช้งานจริงของคุณมากยิ่งขึ้น
- แต่ละสถานการณ์มาพร้อมเทมเพลตสำเร็จรูป การเลือกเทมเพลตใดเทมเพลตหนึ่งจะสร้างงานนำเสนอในสไตล์ของเทมเพลตนั้น
