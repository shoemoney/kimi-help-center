# ภาพรวมฟีเจอร์ Kimi Websites

## Kimi Websites คืออะไร

Kimi Websites คือผลิตภัณฑ์สร้างเว็บไซต์ฟูลสแต็กของ Kimi Agent ขับเคลื่อนโดย Kimi K3 โมเดล AI เชิงตัวแทนแบบมัลติโมดัลที่เข้าใจภาพ ความสามารถหลักคือการเขียนโปรแกรมเชิงภาพ (Vibe Coding): คุณสามารถสร้างเว็บไซต์ฟูลสแต็กที่สมบูรณ์จากภาษาธรรมชาติ ม็อกอัปงานออกแบบ หรือการบันทึกหน้าจอ จากนั้นพรีวิวออนไลน์และเผยแพร่ได้ในคลิกเดียว

เว็บไซต์ที่สร้างด้วย Kimi Websites สามารถมีองค์ประกอบต่อไปนี้:

- **ส่วนหน้า**: โครงสร้างหน้า HTML, เลย์เอาต์และสไตล์ด้วย CSS รวมถึงตรรกะการโต้ตอบด้วย JavaScript (เอฟเฟกต์การเคลื่อนไหว แอนิเมชัน ฯลฯ)
- **ส่วนหลัง**: การจัดเก็บฐานข้อมูลแบบถาวร การเข้าสู่ระบบของผู้ใช้ และการยืนยันตัวตน
- **งานวิศวกรรม**: การจัดการเวอร์ชันอัตโนมัติ พรีวิวฟูลสแต็ก และการปรับใช้สู่สาธารณะ

### ฟีเจอร์ผลิตภัณฑ์

| ฟีเจอร์        | คำอธิบาย                                                  |
|----------------|--------------------------------------------------------------|
| สร้างเว็บไซต์ด้วยการสนทนา | อธิบายสิ่งที่ต้องการด้วยภาษาธรรมชาติ แล้ว AI จะสร้างเว็บไซต์ฟูลสแต็กให้อัตโนมัติ |
| เข้าใจรูปภาพ/วิดีโอ | อัปโหลดม็อกอัปงานออกแบบ ภาพหน้าจอ หรือการบันทึกหน้าจอ แล้ว AI จะวิเคราะห์และสร้างหน้าเว็บให้อัตโนมัติ |
| พื้นที่จัดเก็บถาวร | สร้างฐานข้อมูลส่วนหลังโดยอัตโนมัติ พร้อมอ่าน เขียน และจัดการข้อมูลแบบถาวร |
| การจัดการฐานข้อมูล | มีแผงฐานข้อมูลแบบภาพสำหรับดำเนินการพื้นฐานกับข้อมูล เช่น ดู แก้ไข และลบ |
| การเข้าสู่ระบบของผู้ใช้ | รองรับการเข้าสู่ระบบด้วยบัญชี Kimi และยังสามารถสร้างระบบเข้าสู่ระบบด้วยชื่อผู้ใช้/รหัสผ่านผ่านฐานข้อมูลได้ |
| การจัดการเวอร์ชัน | AI สร้าง version commits (git commit) โดยอัตโนมัติ และรองรับการย้อนกลับไปยังเวอร์ชันเก่าใดก็ได้ |
| พรีวิวฟูลสแต็ก | รองรับการพรีวิวทั้งส่วนหน้าและส่วนหลังอย่างครบถ้วน; บางกรณีต้องเริ่มสภาพแวดล้อม sandbox ด้วยตนเอง |
| การแก้ไขหลายรอบ | รองรับการปรับแก้แบบวนซ้ำผ่านการสนทนาหลายรอบ และให้คุณเปรียบเทียบเวอร์ชันต่าง ๆ ได้ |
| การแก้ไขแบบภาพ | วงหรือทำเครื่องหมายองค์ประกอบบนหน้าพรีวิว แล้วส่งข้อเสนอแนะทั้งหมดให้ Kimi ได้ในครั้งเดียว |
| การเผยแพร่และปรับใช้ | หลังจากคุณคลิก "เผยแพร่" ด้วยตนเอง เว็บไซต์จะถูกปรับใช้สู่สาธารณะบนอินเทอร์เน็ต; ก่อนเผยแพร่จะเป็นเพียงโหมดพรีวิว รองรับการปรับใช้แบบฟูลสแต็ก |
| URL แบบกำหนดเอง | กำหนดโดเมนย่อยของเว็บไซต์เอง เช่น `abc` ใน `abc.ok.kimi.link` |
| การแชร์และควบคุมการเข้าถึง | รับลิงก์แชร์สาธารณะในคลิกเดียว หรือตั้งค่าเว็บไซต์เป็นส่วนตัว/มองเห็นได้เฉพาะคุณ |
| การเลือกเทมเพลต | มีเทมเพลตสำเร็จรูปหลายแบบให้เริ่มสร้างได้อย่างรวดเร็ว |
| การส่งออกโค้ด | รองรับการดาวน์โหลดแพ็กเกจโปรเจกต์ฉบับสมบูรณ์ (รวมทั้งส่วนหน้าและส่วนหลัง) เพื่อนำไปปรับใช้และดูแลเอง |

## วิธีใช้งาน

### วิธีที่ 1: เข้าผ่านเว็บ
ไปที่หน้า Kimi Websites โดยเฉพาะ

<Frames
  src="./images/overview/kimi-websites-homepage.png"
  alt="หน้าแรกของ Kimi Websites"
/>

1. เปิดเบราว์เซอร์: ใช้เบราว์เซอร์หลัก เช่น Chrome, Safari, Edge หรือ Firefox
2. เปิดที่อยู่อย่างเป็นทางการ: หน้าเฉพาะของ Kimi Websites: [https://www.kimi.com/zh/websites](https://www.kimi.com/zh/websites) (รองรับอินเทอร์เฟซทั้งภาษาจีนและภาษาอังกฤษ)
3. เข้าสู่ระบบบัญชีของคุณ: ลงชื่อเข้าใช้ด้วยบัญชี Kimi (รองรับการลงทะเบียนด้วยหมายเลขมือถือหรืออีเมล)
4. ป้อนงานสร้างเว็บไซต์ของคุณ Kimi Websites มี 3 วิธีหลักในการสร้างเว็บไซต์:
   1. **ป้อนข้อความ**: ป้อนงานในกล่องโต้ตอบและอธิบายเว็บไซต์ที่ต้องการด้วยภาษาธรรมชาติ;
   2. **remix รูปภาพ/เว็บไซต์**: อัปโหลดม็อกอัปงานออกแบบหรือภาพหน้าจอของเว็บไซต์ที่คุณชอบเพื่อเรียกใช้ฟีเจอร์ที่เกี่ยวข้อง;
   3. **สร้างเว็บไซต์จากเทมเพลต**: สร้างเว็บไซต์มาตรฐานได้รวดเร็วด้วยการเลือกเทมเพลตสำเร็จรูปและแก้ไขเนื้อหา;
5. เริ่มสร้าง: เข้าสู่อินเทอร์เฟซฟีเจอร์ Websites เลือกเทมเพลต หรือสร้างโดยตรงผ่านการสนทนา

### วิธีที่ 2: เข้าจากแอปมือถือ
เลือกเครื่องมือสร้างเว็บไซต์โดยเฉพาะใน App มือถือ

<Frames

Official Apps พร้อมใช้งานบน iOS, Android และ HarmonyOS (ชื่อแอป: "Kimi") เหนือกล่องป้อนข้อความ ให้แตะแถบเครื่องมือ (Taskbar) → เปลี่ยนเป็นโหมด Websites โหมดนี้มีเครื่องมือสร้างแบบมัลติโมดัลและความสามารถของ Agent ช่วยให้คุณป้อนข้อมูลเชิงภาพและสร้างโค้ดส่วนหน้าได้

### วิธีที่ 3: โหมด Agent ทั่วไป
ในโหมด Agent ทั่วไป ให้ป้อนความต้องการในการสร้างเว็บไซต์ของคุณ

บนเว็บไซต์อย่างเป็นทางการหรืออุปกรณ์มือถือ ให้เลือกโมเดล K3 แล้วป้อนคำสั่งงานที่เกี่ยวข้องกับการสร้างเว็บไซต์ Kimi จะเรียกใช้ความสามารถด้านการเขียนโปรแกรมเชิงภาพและเครื่องมือรันโค้ด

## ขั้นตอน

### สร้างเว็บไซต์ผ่านการสนทนา

อธิบายสิ่งที่ต้องการด้วยภาษาธรรมชาติในกล่องป้อนข้อความ แล้ว Kimi จะเข้าใจและดำเนินการ รองรับวิธีสร้าง 3 แบบ:

| วิธี             | คำอธิบาย                              |
|--------------------|------------------------------------------|
| คำอธิบายข้อความ   | ป้อนความต้องการของเว็บไซต์โดยตรง แล้ว AI จะสร้างเว็บไซต์ให้อัตโนมัติ |
| วิเคราะห์ม็อกอัปงานออกแบบ | อัปโหลดม็อกอัปงานออกแบบ แล้ว AI จะจดจำและสร้างขึ้นใหม่เป็นหน้าเว็บ |
| สร้างเว็บไซต์มาตรฐานอย่างรวดเร็ว | เลือกเทมเพลตสำเร็จรูปแล้วแก้ไขเนื้อหา |

Kimi Websites จะเปิดใช้ webapp-building SKILL ซึ่งเป็น agent สร้างโค้ดหลายรอบที่ออกแบบมาสำหรับการสร้างเว็บไซต์โดยเฉพาะ โดยดำเนินเวิร์กโฟลว์ต่อไปนี้ได้เอง:

1. วิเคราะห์ความต้องการ: วิเคราะห์โมดูลฟีเจอร์ของเว็บไซต์ สไตล์ภาพ และตรรกะการโต้ตอบโดยอัตโนมัติ
2. วางแผนงาน: แบ่งงานออกเป็นงานย่อย เช่น การออกแบบ การพัฒนา และการเตรียมทรัพยากร
3. แนวทางเทคนิค: เลือกสถาปัตยกรรมทางเทคนิคที่เหมาะสมโดยอัตโนมัติ (เช่น React + Tailwind CSS)
4. สร้างทรัพยากร: สร้างทรัพยากรภาพ เช่น รูปภาพและไอคอนตามความจำเป็น
5. สร้างโค้ด: เขียนโครงสร้างหน้า สไตล์ และโค้ดการโต้ตอบ
6. ปรับปรุงหลายรอบ: ปรับแก้เองตามผลพรีวิวจนกว่าเว็บไซต์จะเสร็จสมบูรณ์

### อินเทอร์เฟซแผงพรีวิว

หลังจากสร้างเว็บไซต์แล้ว แผงพรีวิวจะเปิดขึ้นทางด้านขวา และการ์ดเวอร์ชันจะปรากฏในบทสนทนาด้วย รายการปฏิบัติการหลักมีดังนี้:

**แถบเครื่องมือด้านบนของแผงพรีวิว** (จากซ้ายไปขวา):

| ปุ่ม | ฟังก์ชัน |
|--------|----------|
| พรีวิว / โค้ด | สลับระหว่างพรีวิวแบบภาพกับมุมมองซอร์สโค้ด/แผนผังไฟล์ |
| แก้ไข | เข้าสู่โหมดแก้ไข; คลิกบริเวณที่ต้องการเปลี่ยน เพิ่มหมายเหตุประกอบ แล้วส่งให้ Kimi |
| เผยแพร่ | เมื่อยังไม่ได้เผยแพร่ ให้คลิก "เผยแพร่" เพื่อเปิดเว็บไซต์สู่สาธารณะ |
| แชร์ | หลังเผยแพร่ ใช้การ์ดแชร์เพื่อคัดลอกลิงก์ ปรับโดเมนย่อย เปิดเว็บไซต์ คลิก "…" เพื่อยกเลิกการเผยแพร่ หรือคลิก "อัปเดตการเผยแพร่" เมื่อมีเวอร์ชันใหม่ |
| พรีวิวเต็มหน้าจอ | ดูเว็บไซต์แบบเต็มหน้าจอ |
| สลับโหมดพรีวิว | สลับระหว่างมุมมองเดสก์ท็อปและมือถือ |
| รีเฟรช | โหลดพรีวิวใหม่ |
| ความคิดเห็นจากผู้ใช้ | ส่งปัญหาที่พบระหว่างใช้งาน; คุณสามารถป้อนข้อความและอัปโหลดภาพหน้าจอได้ |
| ปิด | ยุบแผงพรีวิว |

**การ์ดเวอร์ชันในบทสนทนา**: แสดงชื่อเว็บไซต์ หมายเลขเวอร์ชัน (เช่น V2) และ URL คลิก **พรีวิว** เพื่อเปิดเวอร์ชันที่เกี่ยวข้อง; คลิก **กู้คืน** เพื่อย้อนกลับไปยังเวอร์ชันนั้น การ์ด **ไฟล์ทั้งหมด** ให้คุณดูหรือดาวน์โหลดไฟล์โปรเจกต์ฉบับสมบูรณ์ สำหรับวิธีใช้แต่ละปุ่มโดยละเอียด โปรดดูหัวข้อที่เกี่ยวข้องด้านล่าง

### การแก้ไขแบบภาพ

- **การปรับปรุงหลายรอบ**: ปรับแต่งรายละเอียดเว็บไซต์ผ่านการสนทนาต่อเนื่อง
- **วิธีแก้ไข**:
  - **โหมดหมายเหตุประกอบ**: คลิกส่วนของหน้าเว็บที่ต้องการเปลี่ยน แล้วเพิ่มความคิดเห็นด้วยภาษาธรรมชาติ
  - **โหมดเลือก**: เลือกองค์ประกอบใดก็ได้บนหน้าเว็บแล้วเพิ่มความคิดเห็น
  - ใช้สี่เหลี่ยม ลูกศร แปรง การสลับสี และเครื่องมือเลือกหรือแก้ไขอื่น ๆ เพื่อเพิ่มข้อเสนอแนะในการเปลี่ยนแปลง
- หลังจากเพิ่มหมายเหตุประกอบในหลายตำแหน่งแล้ว ให้เพิ่มทั้งหมดลงในบทสนทนาและส่งข้อเสนอแนะทั้งหมดให้ Kimi ในครั้งเดียว

### การปรับใช้และเผยแพร่โค้ด
| วิธีปรับใช้ | คำอธิบาย                                           |
|-------------------|------------------------------------------------------|
| เผยแพร่ในคลิกเดียว | คลิกปุ่ม "เผยแพร่" เพื่อปรับใช้เว็บไซต์สู่สาธารณะบนอินเทอร์เน็ตและสร้างลิงก์ออนไลน์ที่เข้าถึงได้ (ก่อนเผยแพร่จะเป็นเพียงพรีวิวเท่านั้น) |
| ดาวน์โหลดแล้วปรับใช้ | ดาวน์โหลดแพ็กเกจโค้ดและปรับใช้บนเซิร์ฟเวอร์ของคุณเอง |
| URL แบบกำหนดเอง | เปลี่ยน URL สุ่มเริ่มต้นเป็นชื่อที่จดจำง่าย เช่น กำหนด `abc` ใน `abc.ok.kimi.link` เอง |

> **เกี่ยวกับ "URL แบบกำหนดเอง"**: ต้องมี 3–30 อักขระ ใช้ได้เฉพาะตัวอักษรพิมพ์เล็ก ตัวเลข และขีดกลางเท่านั้น ห้ามขึ้นต้นหรือลงท้ายด้วยขีดกลาง และห้ามเป็นตัวเลขล้วน คำสงวนบางคำ (เช่น `kimi`, `www`, `login` ฯลฯ) ไม่สามารถใช้ได้ หากชื่อนั้นถูกใช้แล้วหรือใช้งานไม่ได้ โปรดเลือกชื่ออื่น

> **ขอบเขตของ "ดาวน์โหลดแล้วปรับใช้"**: **การเข้าสู่ระบบด้วยบัญชี Kimi** และ **ฐานข้อมูลคลาวด์ที่แพลตฟอร์มจัดการ** ให้บริการโดยแพลตฟอร์ม Kimi และจะไม่ย้ายไปพร้อมโค้ดที่ส่งออก หากคุณปรับใช้โค้ดบนเซิร์ฟเวอร์ของตนเอง ต้องเปลี่ยนวิธีเข้าสู่ระบบเป็นรูปแบบชื่อผู้ใช้/รหัสผ่านที่อิงกับฐานข้อมูลของคุณเอง และต้องย้ายข้อมูลไปยังฐานข้อมูลของคุณเองด้วย หากต้องการเพียงให้สาธารณะเข้าถึงได้ เราแนะนำให้ใช้ **เผยแพร่ในคลิกเดียว** โดยตรง ซึ่งการเข้าสู่ระบบด้วยบัญชี Kimi และข้อมูลบนคลาวด์จะยังทำงานได้ตามปกติ ดูรายละเอียดที่ [ทำไมเว็บไซต์ที่ฉันสร้างจึงใช้งานไม่ได้](/websites/websites-why-not-working)

#### เผยแพร่ แชร์ และยกเลิกการเผยแพร่
ก่อนเผยแพร่ เว็บไซต์จะพรีวิวได้เฉพาะในบทสนทนาเท่านั้น หากต้องการให้ผู้อื่นเข้าถึง ให้คลิก **แชร์** ที่มุมขวาบนของแผงพรีวิวเพื่อเปิดแผงเผยแพร่:

1. **URL แบบกำหนดเอง**: คุณสามารถแก้ไขชื่อใน URL เริ่มต้นได้ เช่น เปลี่ยนเป็น `yourname.ok.kimi.link`;
2. คลิก **คัดลอกลิงก์** เพื่อรับ URL สาธารณะ หรือคลิก **เปิดเว็บไซต์** เพื่อดูในแท็บใหม่ หลังเผยแพร่แล้ว ด้านบนของแผงจะแสดง **เผยแพร่แล้ว** และทุกคนที่มีลิงก์จะเข้าถึงได้;
3. หากต้องการนำเว็บไซต์ลงจากออนไลน์ ให้เลือก **ยกเลิกการเผยแพร่** จากเมนู **…** ที่มุมขวาบนของแผง เว็บไซต์จะไม่เปิดให้สาธารณะเข้าถึงอีกต่อไป (โค้ดและข้อมูลยังคงอยู่ และคุณสามารถเผยแพร่ใหม่ได้ทุกเมื่อ)

## เหมาะสำหรับใคร

- นักพัฒนา: ออกแบบต้นแบบผลิตภัณฑ์และเดโมส่วนหน้า ช่วยลดเวลาที่ต้องใช้ในการสร้างตั้งแต่ศูนย์ได้มาก
- ผู้ประกอบการ: สร้างเว็บไซต์ทางการ หน้า landing page และหน้าจัดแสดงผลิตภัณฑ์ได้รวดเร็วเมื่อมีทรัพยากรจำกัด
- ผู้จัดการผลิตภัณฑ์: เปลี่ยน PRD หรือม็อกอัปงานออกแบบให้เป็นต้นแบบเชิงโต้ตอบที่นำไปสาธิตได้อย่างรวดเร็ว โดยไม่ต้องรอตารางพัฒนา
- ผู้ใช้ที่ไม่ถนัดเทคนิค: ไม่จำเป็นต้องมีความรู้ด้านโค้ด เพียงอธิบายไอเดียหรืออัปโหลดภาพอ้างอิง ก็เปลี่ยนแนวคิดให้เป็นหน้าเว็บที่รันได้

| เครื่องมือ/เครื่องคำนวณ | สร้างหน้าเว็บเครื่องคำนวณ BMI ที่มีอินเทอร์เฟซเรียบง่าย สลับหน่วยได้ และมีคำแนะนำระดับสุขภาพ |
