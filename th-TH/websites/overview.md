# ภาพรวมฟีเจอร์ Kimi Websites

## Kimi Websites คืออะไร

Kimi Websites คือผลิตภัณฑ์สร้างเว็บไซต์ฟูลสแตกของ Kimi Agent ขับเคลื่อนด้วย Kimi K3 โมเดล AI แบบ agentic เชิงภาพหลายโมดัล ความสามารถหลักคือการเขียนโปรแกรมเชิงภาพ (Vibe Coding): คุณสามารถสร้างเว็บไซต์ฟูลสแตกที่สมบูรณ์จากภาษาธรรมชาติ ม็อกอัปดีไซน์ หรือการบันทึกหน้าจอ จากนั้นดูตัวอย่างออนไลน์และเผยแพร่ได้ในคลิกเดียว

เว็บไซต์ที่สร้างด้วย Kimi Websites สามารถประกอบด้วย:

- **Frontend**: โครงสร้างหน้า HTML, เลย์เอาต์และสไตล์ CSS รวมถึงตรรกะการโต้ตอบด้วย JavaScript (เอฟเฟกต์การเคลื่อนไหว แอนิเมชัน ฯลฯ)
- **Backend**: การจัดเก็บข้อมูลในฐานข้อมูลแบบถาวร การเข้าสู่ระบบของผู้ใช้ และการยืนยันตัวตน
- **Engineering**: การจัดการเวอร์ชันอัตโนมัติ การพรีวิวฟูลสแตก และการเผยแพร่สู่สาธารณะ

### ฟีเจอร์ของผลิตภัณฑ์

| ฟีเจอร์        | คำอธิบาย                                                  |
|----------------|--------------------------------------------------------------|
| สร้างเว็บไซต์ด้วยการสนทนา | อธิบายสิ่งที่ต้องการด้วยภาษาธรรมชาติ แล้ว AI จะสร้างเว็บไซต์ฟูลสแตกให้อัตโนมัติ |
| เข้าใจรูปภาพ/วิดีโอ | อัปโหลดม็อกอัปดีไซน์ ภาพหน้าจอ หรือการบันทึกหน้าจอ แล้ว AI จะวิเคราะห์และสร้างหน้าเว็บให้อัตโนมัติ |
| การจัดเก็บถาวร | สร้างฐานข้อมูล backend ให้อัตโนมัติ พร้อมอ่าน เขียน และจัดการข้อมูลแบบถาวร |
| การจัดการฐานข้อมูล | มีแผงฐานข้อมูลแบบภาพสำหรับงานพื้นฐาน เช่น ดู แก้ไข และลบข้อมูล |
| การเข้าสู่ระบบของผู้ใช้ | รองรับการเข้าสู่ระบบด้วยบัญชี Kimi และยังสร้างระบบเข้าสู่ระบบด้วยชื่อผู้ใช้/รหัสผ่านผ่านฐานข้อมูลได้ |
| การจัดการเวอร์ชัน | AI สร้าง version commits (git commit) ให้อัตโนมัติ และรองรับการย้อนกลับไปยังเวอร์ชันในอดีตใดก็ได้ |
| พรีวิวฟูลสแตก | รองรับการพรีวิว frontend และ backend อย่างครบถ้วน; บางสถานการณ์ต้องเริ่มสภาพแวดล้อม sandbox ด้วยตนเอง |
| แก้ไขแบบหลายรอบ | รองรับการปรับแก้แบบวนซ้ำผ่านบทสนทนาหลายรอบ และให้เปรียบเทียบเวอร์ชันต่าง ๆ ได้ |
| แก้ไขเชิงภาพ | วงหรือทำเครื่องหมายองค์ประกอบบนหน้าพรีวิว แล้วส่งข้อเสนอแนะทั้งหมดให้ Kimi พร้อมกัน |
| เผยแพร่และปรับใช้ | หลังจากคุณคลิก "เผยแพร่" ด้วยตนเอง เว็บไซต์จะถูกปรับใช้บนอินเทอร์เน็ตสาธารณะ; ก่อนเผยแพร่จะเป็นโหมดพรีวิวเท่านั้น รองรับการปรับใช้แบบฟูลสแตก |
| URL กำหนดเอง | ปรับแต่ง subdomain ของเว็บไซต์ เช่น `abc` ใน `abc.ok.kimi.link` |
| แชร์และควบคุมการเข้าถึง | รับลิงก์แชร์สาธารณะได้ในคลิกเดียว หรือตั้งค่าเว็บไซต์เป็นส่วนตัว/มองเห็นได้เฉพาะคุณ |
| เลือกเทมเพลต | มีเทมเพลตสำเร็จรูปหลายแบบให้เริ่มสร้างได้รวดเร็ว |
| ส่งออกโค้ด | รองรับการดาวน์โหลดแพ็กเกจโปรเจกต์ทั้งหมด (รวม frontend และ backend) เพื่อนำไปปรับใช้ด้วยตนเอง |

## วิธีใช้งาน

### วิธีที่ 1: เข้าถึงผ่านเว็บ
ไปที่หน้าเฉพาะของ Kimi Websites

1. เปิดเบราว์เซอร์: ใช้เบราว์เซอร์หลัก เช่น Chrome, Safari, Edge หรือ Firefox
2. เปิดที่อยู่ทางการสำหรับเข้าถึง: หน้าเฉพาะของ Kimi Websites: [https://www.kimi.com/zh/websites](https://www.kimi.com/zh/websites) (รองรับทั้งอินเทอร์เฟซภาษาจีนและอังกฤษ)
3. เข้าสู่ระบบบัญชีของคุณ: ลงชื่อเข้าใช้ด้วยบัญชี Kimi (รองรับการลงทะเบียนด้วยหมายเลขโทรศัพท์มือถือหรืออีเมล)
4. ป้อนงานสร้างเว็บไซต์ของคุณ Kimi Websites มีวิธีสร้างเว็บไซต์หลัก 3 วิธี:
   1. **ป้อนข้อความ**: ป้อนงานในกล่องโต้ตอบและอธิบายเว็บไซต์ที่ต้องการด้วยภาษาธรรมชาติ;
   2. **รูปภาพ/website remix**: อัปโหลดม็อกอัปดีไซน์หรือภาพหน้าจอของเว็บไซต์ที่คุณชอบเพื่อเรียกใช้ฟีเจอร์ที่เกี่ยวข้อง;
   3. **สร้างเว็บไซต์จากเทมเพลต**: สร้างเว็บไซต์มาตรฐานได้อย่างรวดเร็วด้วยการเลือกเทมเพลตสำเร็จรูปและแก้ไขเนื้อหา;
5. เริ่มสร้าง: เข้าสู่อินเทอร์เฟซฟีเจอร์ Websites เลือกเทมเพลต หรือสร้างโดยตรงผ่านการสนทนา

Official Apps มีให้ใช้งานสำหรับ iOS, Android และ HarmonyOS (ชื่อ app: "Kimi") เหนือกล่องป้อนข้อความ ให้แตะแถบเครื่องมือ (Taskbar) → สลับเป็นโหมด Websites ภายในมีเครื่องมือสร้างแบบหลายโมดัลและความสามารถ Agent ช่วยให้คุณป้อนข้อมูลเชิงภาพและสร้างโค้ด frontend ได้

### วิธีที่ 3: โหมด Agent ทั่วไป
ในโหมด Agent ทั่วไป ให้ป้อนข้อกำหนดการสร้างเว็บไซต์ของคุณ

บนเว็บไซต์ทางการหรืออุปกรณ์มือถือ ให้เลือกโมเดล K3 แล้วป้อนคำสั่งงานที่เกี่ยวข้องกับการสร้างเว็บไซต์ Kimi จะเรียกใช้ความสามารถด้านการเขียนโปรแกรมเชิงภาพและเครื่องมือรันโค้ด

## ขั้นตอน

### สร้างเว็บไซต์ผ่านการสนทนา

อธิบายสิ่งที่ต้องการด้วยภาษาธรรมชาติในกล่องป้อนข้อความ แล้ว Kimi จะทำความเข้าใจและดำเนินการให้ รองรับการสร้าง 3 วิธี:

| วิธี             | คำอธิบาย                              |
|--------------------|------------------------------------------|
| คำอธิบายข้อความ   | ป้อนข้อกำหนดเว็บไซต์โดยตรง แล้ว AI จะสร้างเว็บไซต์ให้อัตโนมัติ |
| วิเคราะห์ม็อกอัปดีไซน์ | อัปโหลดม็อกอัปดีไซน์ แล้ว AI จะจดจำและสร้างใหม่เป็นหน้าเว็บ |
| สร้างเว็บไซต์มาตรฐานอย่างรวดเร็ว | เลือกเทมเพลตสำเร็จรูปและแก้ไขเนื้อหา |

### อินเทอร์เฟซแผงพรีวิว

หลังจากสร้างเว็บไซต์แล้ว แผงพรีวิวจะเปิดขึ้นทางด้านขวา และการ์ดเวอร์ชันจะปรากฏในบทสนทนาด้วย รายการปฏิบัติการหลักมีดังนี้:

**แถบเครื่องมือด้านบนของแผงพรีวิว** (จากซ้ายไปขวา):

| ปุ่ม | ฟังก์ชัน |
|--------|----------|
| พรีวิว / โค้ด | สลับระหว่างพรีวิวเชิงภาพกับมุมมองซอร์สโค้ด/โครงสร้างไฟล์ |
| แก้ไข | เข้าสู่โหมดแก้ไข; คลิกบริเวณที่ต้องการเปลี่ยน เพิ่มหมายเหตุประกอบ แล้วส่งให้ Kimi |
| แชร์ | เผยแพร่เว็บไซต์ คัดลอกลิงก์ ปรับแต่ง URL หรือยกเลิกการเผยแพร่ |
| พรีวิวเต็มหน้าจอ | ดูเว็บไซต์แบบเต็มหน้าจอ |
| สลับโหมดพรีวิว | สลับระหว่างมุมมองเดสก์ท็อปและมือถือ |
| รีเฟรช | โหลดพรีวิวใหม่ |
| ความคิดเห็นผู้ใช้ | ส่งปัญหาที่พบระหว่างใช้งาน; คุณสามารถป้อนข้อความและอัปโหลดภาพหน้าจอได้ |
| ปิด | ยุบแผงพรีวิว |

**การ์ดเวอร์ชันในบทสนทนา**: แสดงชื่อเว็บไซต์ หมายเลขเวอร์ชัน (เช่น V2) และ URL คลิก **พรีวิว** เพื่อเปิดเวอร์ชันที่เกี่ยวข้อง; คลิก **กู้คืน** เพื่อย้อนกลับไปยังเวอร์ชันนั้น การ์ด **All Files** ให้คุณดูหรือดาวน์โหลดไฟล์โปรเจกต์ทั้งหมดได้ ดูวิธีใช้แต่ละปุ่มโดยละเอียดในหัวข้อที่เกี่ยวข้องด้านล่าง

- **ปรับให้เหมาะสมแบบหลายรอบ**: ปรับรายละเอียดเว็บไซต์ผ่านการสนทนาต่อเนื่อง
- **วิธีแก้ไข**:
  - **โหมดหมายเหตุประกอบ**: คลิกส่วนของหน้าเว็บที่ต้องการเปลี่ยน แล้วเพิ่มความคิดเห็นด้วยภาษาธรรมชาติ
  - **โหมดเลือก**: เลือกองค์ประกอบใดก็ได้บนหน้าเว็บแล้วเพิ่มความคิดเห็น
  - ใช้สี่เหลี่ยม ลูกศร แปรง การสลับสี และเครื่องมือเลือก/แก้ไขอื่น ๆ เพื่อเพิ่มข้อเสนอแนะการเปลี่ยนแปลง
- หลังจากเพิ่มหมายเหตุประกอบในหลายตำแหน่งแล้ว ให้เพิ่มทั้งหมดลงในบทสนทนาและส่งข้อเสนอแนะทั้งหมดให้ Kimi พร้อมกัน

### การ deploy และเผยแพร่โค้ด
| วิธี deploy | คำอธิบาย                                           |
|-------------------|------------------------------------------------------|
| เผยแพร่ในคลิกเดียว | คลิกปุ่ม "เผยแพร่" เพื่อ deploy เว็บไซต์สู่อินเทอร์เน็ตสาธารณะและสร้างลิงก์ออนไลน์ที่เข้าถึงได้ (ก่อนเผยแพร่จะเป็นพรีวิวเท่านั้น) |
| ดาวน์โหลดและ deploy | ดาวน์โหลดแพ็กเกจโค้ดแล้ว deploy ไปยังเซิร์ฟเวอร์ของคุณเอง |
| URL กำหนดเอง | เปลี่ยน URL สุ่มเริ่มต้นให้เป็นชื่อที่จดจำง่าย เช่น ปรับแต่ง `abc` ใน `abc.ok.kimi.link` |

> **เกี่ยวกับ "URL กำหนดเอง"**: 3–30 อักขระ ใช้ได้เฉพาะตัวอักษรพิมพ์เล็ก ตัวเลข และยัติภังค์ ต้องไม่ขึ้นต้นหรือลงท้ายด้วยยัติภังค์ และต้องไม่เป็นตัวเลขล้วน คำสงวนบางคำ (เช่น `kimi`, `www`, `login` เป็นต้น) ไม่สามารถใช้ได้ หากถูกใช้แล้วหรือไม่พร้อมใช้งาน โปรดเลือกชื่ออื่น

> **เกี่ยวกับขอบเขตของ "ดาวน์โหลดและ deploy"**: **การเข้าสู่ระบบด้วยบัญชี Kimi** และ **ฐานข้อมูล cloud ที่แพลตฟอร์มจัดการ** จัดให้โดยแพลตฟอร์ม Kimi และจะไม่ย้ายตามโค้ดที่ส่งออก หากคุณ deploy โค้ดไปยังเซิร์ฟเวอร์ของคุณเอง ต้องเปลี่ยนวิธีเข้าสู่ระบบเป็นรูปแบบชื่อผู้ใช้/รหัสผ่านที่อิงฐานข้อมูลของคุณเอง และต้องย้ายข้อมูลไปยังฐานข้อมูลของคุณเองด้วย หากต้องการให้เข้าถึงแบบสาธารณะเท่านั้น เราแนะนำให้ใช้ **เผยแพร่ในคลิกเดียว** โดยตรง แล้วการเข้าสู่ระบบด้วยบัญชี Kimi และข้อมูล cloud จะยังทำงานได้ตามปกติ ดูรายละเอียดที่ [ทำไมเว็บไซต์ที่ฉันสร้างถึงใช้งานไม่ได้?](/websites/websites-why-not-working)

#### เผยแพร่ แชร์ และยกเลิกการเผยแพร่
ก่อนเผยแพร่ เว็บไซต์จะพรีวิวได้เฉพาะในบทสนทนาเท่านั้น หากต้องการให้ผู้อื่นเข้าถึง ให้คลิก **แชร์** ที่มุมขวาบนของแผงพรีวิวเพื่อเปิดแผงเผยแพร่:

1. **URL กำหนดเอง**: คุณสามารถแก้ไขชื่อใน URL เริ่มต้นได้ เช่น เปลี่ยนเป็น `yourname.ok.kimi.link`;
2. คลิก **คัดลอกลิงก์** เพื่อรับ URL สาธารณะ หรือคลิก **เปิดเว็บไซต์** เพื่อดูในแท็บใหม่ หลังเผยแพร่แล้ว ด้านบนของแผงจะแสดง **เผยแพร่แล้ว** และทุกคนที่มีลิงก์จะเข้าถึงได้;
3. หากต้องการนำเว็บไซต์ออฟไลน์ ให้เลือก **ยกเลิกการเผยแพร่** จากเมนู **…** ที่มุมขวาบนของแผง เว็บไซต์จะไม่สามารถเข้าถึงแบบสาธารณะได้อีกต่อไป (โค้ดและข้อมูลจะยังคงอยู่ และคุณสามารถเผยแพร่ใหม่ได้ทุกเมื่อ)

## เหมาะสำหรับใคร

- นักพัฒนา: ออกแบบต้นแบบผลิตภัณฑ์และเดโม frontend ช่วยลดเวลาสร้างจากศูนย์ได้อย่างมาก
- ผู้ประกอบการ: สร้างเว็บไซต์ทางการ landing page และหน้าจัดแสดงผลิตภัณฑ์ได้รวดเร็วเมื่อทรัพยากรมีจำกัด
- ผู้จัดการผลิตภัณฑ์: เปลี่ยน PRD หรือม็อกอัปดีไซน์ให้เป็นต้นแบบโต้ตอบที่สาธิตได้อย่างรวดเร็ว โดยไม่ต้องรอคิวพัฒนา
- ผู้ใช้ที่ไม่ใช่สายเทคนิค: ไม่จำเป็นต้องมีความรู้เขียนโค้ด แค่อธิบายไอเดียหรืออัปโหลดภาพอ้างอิง ก็เปลี่ยนจากแนวคิดเป็นหน้าเว็บที่รันได้

## ตัวอย่าง Prompt
**คุณสามารถอ้างอิงสถานการณ์และ prompt ต่อไปนี้เพื่อสร้างเนื้อหา**

| สถานการณ์         | ตัวอย่าง prompt                                                   |
|------------------|------------------------------------------------------------------|
| สร้าง landing page ตั้งแต่ต้น | ช่วยสร้าง marketing landing page สำหรับผลิตภัณฑ์ SaaS สไตล์เทคโนโลยี มี hero section, แนะนำฟีเจอร์, ราคา และ CTA |
| สร้างเว็บไซต์ใหม่จากวิดีโอ | [อัปโหลดการบันทึกหน้าจอ] สร้างเว็บไซต์ที่แสดงในวิดีโอขึ้นใหม่และคงการโต้ตอบเดิมไว้ |
| สร้างใหม่จากภาพหน้าจอ | [อัปโหลดม็อกอัปดีไซน์] ทำดีไซน์นี้ให้เป็นโค้ดหน้าเว็บที่รันได้ |
| พอร์ตโฟลิโอส่วนตัว | ช่วยสร้างเว็บไซต์พอร์ตโฟลิโอส่วนตัวสำหรับช่างภาพ ใช้สไตล์มินิมอลขาวดำและรองรับเลย์เอาต์ภาพแบบ masonry |
| หน้าภาพข้อมูล | สร้างหน้าเว็บแสดงภาพข้อมูลเงินทุนของบริษัท AI ในปี 2025 พร้อมกราฟและตัวกรอง |
| เว็บไซต์แบรนด์ | ช่วยสร้างเว็บไซต์ทางการสำหรับแบรนด์กาแฟ ใช้พาเลตสี Morandi พร้อมหน้าแรก หน้าผลิตภัณฑ์ และหน้าร้าน |
| เครื่องมือ/เครื่องคำนวณ | สร้างหน้าเว็บเครื่องคำนวณ BMI พร้อมอินเทอร์เฟซสะอาดตา การสลับหน่วย และคำแนะนำระดับสุขภาพ |
