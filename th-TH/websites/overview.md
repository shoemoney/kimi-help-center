# Kimi Websites

<Callout type="info">
**Kimi Websites** เป็นฟีเจอร์ของผลิตภัณฑ์ Kimi Agent ที่ขับเคลื่อนด้วยโมเดล AI เอเจนต์มัลติโมดัลเชิงภาพ Kimi K2.6 รุ่นล่าสุด ความสามารถหลักคือ **Vibe Coding** — การสร้างเว็บไซต์จากภาษาธรรมชาติและเผยแพร่ออนไลน์
</Callout>

ด้วยการทำความเข้าใจอินพุตเชิงภาพ (แบบจำลอง UI ภาพหน้าจอ วิดีโอการโต้ตอบ) และคำสั่งภาษาธรรมชาติ Kimi จะแปลงอินพุตของผู้ใช้ให้กลายเป็นโค้ดฟรอนต์เอนด์ที่สมบูรณ์และรันได้ ครอบคลุมไม่เพียงแค่ UI แบบคงที่ แต่รวมถึงพฤติกรรมการโต้ตอบแบบไดนามิกด้วย

## ภาพรวมฟีเจอร์

| ฟีเจอร์ | คำอธิบาย |
|---------|------------|
| **สร้างเว็บไซต์ผ่านบทสนทนา** | อธิบายความต้องการด้วยภาษาธรรมชาติ แล้ว AI จะสร้างเว็บไซต์ให้โดยอัตโนมัติ |
| **เข้าใจภาพ/วิดีโอ** | อัปโหลดแบบจำลองดีไซน์/ภาพหน้าจอ/การบันทึกหน้าจอ แล้ว AI จะวิเคราะห์และสร้างหน้า HTML |
| **เผยแพร่อัตโนมัติ** | เผยแพร่ทันทีด้วยการคลิกเพียงครั้งเดียว |
| **แก้ไขหลายรอบ** | ปรับปรุงเว็บไซต์ซ้ำๆ พร้อมเปรียบเทียบเวอร์ชัน |
| **แชร์ด้วยคลิกเดียว** | สร้างลิงก์ที่เข้าถึงได้เพื่อแชร์ได้ง่าย |
| **เลือกเทมเพลต** | มีเทมเพลตสำเร็จรูปหลากหลายให้เริ่มสร้างเว็บไซต์ได้อย่างรวดเร็ว |
| **ส่งออกโค้ด** | ดาวน์โหลดไฟล์ HTML/CSS/JS ที่แพ็กรวมแล้วเพื่อนำไปโฮสต์เอง |

### วิธีที่ 1: เข้าหน้า Kimi Websites

1. **เปิดเบราว์เซอร์**: ใช้ Chrome, Safari, Edge, Firefox หรือเบราว์เซอร์หลักใดก็ได้
2. **ไปที่**: [kimi.com/websites](https://www.kimi.com/zh/websites) (รองรับภาษาจีนและภาษาอังกฤษ)
3. **เข้าสู่ระบบ**: ด้วยบัญชี Kimi ของคุณ (เบอร์โทรศัพท์หรืออีเมล)

| **ป้อนข้อความ** | พิมพ์คำขอของคุณด้วยภาษาธรรมชาติ |
| **โคลนภาพ/เว็บไซต์** | อัปโหลดแบบจำลองดีไซน์หรือภาพหน้าจอ |
| **ใช้เทมเพลต** | เลือกเทมเพลตสำเร็จรูปแล้วแก้ไขเนื้อหา |

5. **เริ่มสร้าง**: เลือกเทมเพลตหรือเริ่มจากบทสนทนา

### วิธีที่ 2: แอปมือถือ

ทั้ง iOS, Android และ HarmonyOS ต่างก็มีแอป Kimi อย่างเป็นทางการ ในพื้นที่ป้อนข้อมูล ให้แตะ **Taskbar** → สลับไปที่ **โหมด Websites Agent** ซึ่งมีเครื่องมือสร้างแบบมัลติโมดัลและความสามารถของ Agent

### วิธีที่ 3: ใช้โหมด K2.6 Agent

สลับไปที่โหมด K2.6 Agent แล้วป้อนงานสร้างเว็บไซต์ Kimi จะเรียกใช้ความสามารถการเขียนโค้ดเชิงภาพและเครื่องมือรันโค้ด

| วิธี | คำอธิบาย |
|--------|------------|
| **อธิบายด้วยข้อความ** | ป้อนความต้องการของเว็บไซต์โดยตรง แล้ว AI จะสร้างให้โดยอัตโนมัติ |

### ขั้นที่ 2: กระบวนการสร้าง

<Frames
  src="./images/overview/screenshot-26.png"
  alt="screenshot 26"
/>

Kimi website จะเปิดใช้งาน **webapp-building SKILL** — เอเจนต์สร้างโค้ดแบบหลายรอบเฉพาะทาง:
1. **วิเคราะห์ความต้องการ**: วิเคราะห์โมดูลของเว็บไซต์ สไตล์เชิงภาพ และตรรกะการโต้ตอบ
2. **วางแผนงาน**: แบ่งย่อยเป็นงานออกแบบ พัฒนา และเตรียมแอสเซ็ต
3. **เลือกเทคสแต็ก**: เลือกสถาปัตยกรรมที่เหมาะสม (เช่น React + Tailwind CSS)
4. **สร้างแอสเซ็ต**: สร้างรูปภาพ ไอคอน และแอสเซ็ตเชิงภาพอื่นๆ
5. **สร้างโค้ด**: เขียนโครงสร้างหน้า สไตล์ และโค้ดการโต้ตอบ
6. **ปรับปรุงหลายรอบ**: ปรับด้วยตัวเองตามผลพรีวิวจนกว่าจะเสร็จสมบูรณ์

### ขั้นที่ 3: พรีวิวและปรับแต่ง
- **พรีวิวสด**: สร้าง URL เดโม HTML เพื่อดูในเบราว์เซอร์ได้ทันที
- **แก้ไขผ่านบทสนทนา**: สนทนาต่อเพื่อขอเปลี่ยนแปลง เช่น *"ทำให้แถบนำทางเป็นสีเข้ม"*

Kimi จะจัดระเบียบรายการสิ่งที่ต้องทำใหม่และสร้างต่อ

### ขั้นที่ 4: แก้ไขเชิงภาพแบบออนไลน์
- **ปรับปรุงหลายรอบ**: ปรับรายละเอียดให้ละเอียดผ่านบทสนทนาที่ต่อเนื่อง
- **โหมดการแก้ไข**:
  - **โหมดคำอธิบายประกอบ**: คลิกที่บริเวณต่างๆ เพื่อเพิ่มคำอธิบายประกอบด้วยภาษาธรรมชาติ
  - **โหมดเลือก**: เลือกองค์ประกอบใดก็ได้แล้วเพิ่มคำอธิบายประกอบ
  - ใช้รูปสี่เหลี่ยม ลูกศร แปรง และการสลับสีเพื่อทำเครื่องหมายข้อเสนอแนะการแก้ไข
- ส่งข้อเสนอแนะการแก้ไขทั้งหมดให้ Kimi ในคราวเดียว
### ขั้นที่ 5: เผยแพร่และนำขึ้นออนไลน์
| วิธีการเผยแพร่ | คำอธิบาย |
|-------------------|------------|
| **เผยแพร่อัตโนมัติ** | เผยแพร่ด้วยคลิกเดียวพร้อมลิงก์ออนไลน์ที่สร้างให้ |
| **ดาวน์โหลดและโฮสต์เอง** | ดาวน์โหลดไฟล์โค้ดที่แพ็กรวมแล้วและนำไปติดตั้งบนเซิร์ฟเวอร์ของคุณเอง |
| **โดเมนกำหนดเอง** | ผูกเว็บไซต์ที่สร้างขึ้นกับโดเมนของคุณเอง |

หลังจากสร้างเสร็จ คุณสามารถ:
- คลิกเวอร์ชันการเผยแพร่ต่างๆ เพื่อดาวน์โหลดไฟล์เวอร์ชัน
- คลิกปุ่มแชร์เพื่อรับลิงก์ที่เผยแพร่ต่อสาธารณะ (หรือตั้งเป็นส่วนตัว)
- คลิกปุ่มแก้ไขเพื่อปรับปรุงต่อ
- ดาวน์โหลดโค้ด HTML/CSS/JS ฉบับสมบูรณ์เพื่อนำไปติดตั้งโดยตรงหรือปรับแต่งเพิ่มเติม

## กลุ่มเป้าหมาย
| กลุ่มเป้าหมาย | กรณีการใช้งาน |
|----------|----------|
| **นักพัฒนา** | ออกแบบต้นแบบผลิตภัณฑ์และเดโมฟรอนต์เอนด์ ลดเวลาการสร้างจากศูนย์ได้อย่างมาก |
| **ผู้ประกอบการ** | สร้างแลนดิ้งเพจ หน้าแสดงผลิตภัณฑ์ และเว็บไซต์บริษัทได้อย่างรวดเร็วแม้มีทรัพยากรจำกัด |
| **ผู้จัดการผลิตภัณฑ์** | เปลี่ยน PRD หรือแบบจำลองดีไซน์ให้เป็นต้นแบบเชิงโต้ตอบที่สาธิตได้อย่างรวดเร็ว |
| **ผู้ใช้ที่ไม่มีพื้นฐานทางเทคนิค** | ไม่ต้องเขียนโค้ด — แค่อธิบายไอเดียหรืออัปโหลดภาพอ้างอิงเพื่อแปลงจากแนวคิดเป็นหน้าเว็บที่ใช้งานได้ |

## สถานการณ์อ้างอิง
| สถานการณ์ | ตัวอย่างพรอมต์ |
|----------|---------------|
| **แลนดิ้งเพจจากศูนย์** | สร้างแลนดิ้งเพจการตลาด SaaS ที่มีกลิ่นอายเทคโนโลยี — ประกอบด้วยส่วนฮีโร่ ภาพรวมฟีเจอร์ ราคา และ CTA |
| **แปลงวิดีโอเป็นเว็บไซต์** | [อัปโหลดการบันทึกหน้าจอ] สร้างเว็บไซต์ที่แสดงในวิดีโอนี้ขึ้นมาใหม่ โดยคงเอฟเฟกต์การโต้ตอบดั้งเดิมไว้ |
| **แปลงภาพหน้าจอ** | [อัปโหลดแบบจำลองดีไซน์] เปลี่ยนดีไซน์นี้ให้เป็นโค้ดหน้าเว็บที่รันได้ |
| **พอร์ตโฟลิโอส่วนตัว** | สร้างเว็บไซต์พอร์ตโฟลิโอของช่างภาพ — สไตล์ขาวดำมินิมอลพร้อมเลย์เอาต์รูปภาพแบบ masonry |
| **หน้าแสดงข้อมูลภาพ** | สร้างหน้าแสดงข้อมูลภาพที่นำเสนอข้อมูลการระดมทุนของบริษัท AI ปี 2025 พร้อมแผนภูมิและตัวกรอง |
| **เว็บไซต์แบรนด์** | สร้างเว็บไซต์แบรนด์กาแฟด้วยโทนสีเอิร์ธโทนนุ่มนวล — ประกอบด้วยหน้าโฮม ผลิตภัณฑ์ และค้นหาร้านค้า |
| **เครื่องมือ / เครื่องคิดเลข** | สร้างหน้าเว็บคำนวณ BMI — อินเทอร์เฟซเรียบสะอาด รองรับการสลับหน่วย พร้อมตัวบ่งชี้ระดับสุขภาพ |
