# ความสามารถแบบฟูลสแตกของ Kimi Websites

## อัปเกรดการสร้างเว็บไซต์แบบฟูลสแตก

โดยทั่วไป เว็บไซต์ที่สมบูรณ์ประกอบด้วย 3 ส่วน ได้แก่ **อินเทอร์เฟซฝั่งหน้าเว็บ, บริการฝั่งหลังบ้าน และการจัดเก็บข้อมูล** ตอนนี้ Kimi Websites ได้อัปเกรดความสามารถในการสร้างเว็บไซต์แบบฟูลสแตกแล้ว รองรับการสร้างและปรับใช้เว็บไซต์ครบวงจร ตั้งแต่หน้าเว็บฝั่งผู้ใช้ไปจนถึงฐานข้อมูลฝั่งหลังบ้าน

| ความสามารถ         | คำอธิบาย                                                           |
|--------------|----------------------------------------------------------------|
| การสร้างหน้าเว็บฝั่งผู้ใช้     | โครงสร้างหน้า HTML/CSS/JavaScript, สไตล์ และตรรกะการโต้ตอบ                    |
| ฐานข้อมูลฝั่งหลังบ้าน   | สร้างฐานข้อมูลฝั่งหลังบ้านโดยอัตโนมัติ รองรับการอ่าน/เขียนข้อมูลแบบถาวรและการจัดการผ่านหน้าจอแบบภาพ               |
| การเข้าสู่ระบบของผู้ใช้     | รองรับการเข้าสู่ระบบด้วยบัญชี Kimi และยังสามารถสร้างระบบเข้าสู่ระบบด้วยบัญชีและรหัสผ่านผ่านฐานข้อมูลได้           |
| การจัดการเวอร์ชัน     | AI commit เวอร์ชันโดยอัตโนมัติ และรองรับการย้อนกลับไปยังเวอร์ชันใดก็ได้ในประวัติ                      |
| การพรีวิวแบบฟูลสแตก     | รองรับการพรีวิวทั้งฝั่งหน้าเว็บและฝั่งหลังบ้านแบบครบถ้วน; บางสถานการณ์ต้องเริ่มสภาพแวดล้อม sandbox ด้วยตนเอง                   |
| การเผยแพร่และปรับใช้   | คลิก "เผยแพร่" ด้วยตนเองเพื่อปรับใช้ขึ้นอินเทอร์เน็ตสาธารณะ ก่อนเผยแพร่ เว็บไซต์จะเปิดให้พรีวิวเท่านั้น รองรับการปรับใช้เนื้อหาแบบฟูลสแตก  |

## สิ่งที่ Agent ส่งมอบ

- ไฟล์การทำงานของงานแบบครบถ้วน รวมถึงโค้ดฝั่งหน้าเว็บและฝั่งหลังบ้าน
- เว็บไซต์แบบฟูลสแตกที่สามารถพรีวิวออนไลน์และเผยแพร่ได้
- แพ็กเกจ Zip สำหรับดาวน์โหลด อยู่ในไดเรกทอรี `/mnt/agents/output/app/`

## กรณีใช้งาน

| สถานการณ์             | ตัวอย่าง prompt                                                       |
|------------------|------------------------------------------------------------------|
| สร้างหน้า landing page ตั้งแต่ต้น   | สร้างหน้า landing page สำหรับทำการตลาดให้ผลิตภัณฑ์ SaaS ในสไตล์เทคโนโลยี มีส่วน hero, การแนะนำฟีเจอร์, ราคา และคำกระตุ้นให้ดำเนินการ |
| สร้างใหม่จากภาพหน้าจอ         | [อัปโหลดภาพหน้าจอดีไซน์] แปลงดีไซน์นี้เป็นโค้ดหน้าเว็บที่รันได้               |
| พอร์ตโฟลิโอส่วนตัว       | สร้างเว็บไซต์พอร์ตโฟลิโอส่วนตัวสำหรับช่างภาพ ใช้สไตล์ขาวดำแบบมินิมอล และรองรับเลย์เอาต์ภาพแบบ masonry        |
| หน้าการแสดงผลข้อมูล     | สร้างหน้าเว็บแสดงภาพข้อมูลเกี่ยวกับข้อมูลการระดมทุนของบริษัท AI ในปี 2025 พร้อมกราฟและตัวกรอง |
| เว็บไซต์แบรนด์         | สร้างเว็บไซต์ทางการสำหรับแบรนด์กาแฟ ใช้พาเลตสี Morandi พร้อมหน้าแรก หน้าสินค้า และหน้าร้าน      |
| แอปที่ต้องเข้าสู่ระบบ     | สร้างเว็บไซต์ฐานความรู้ภายในทีม โดยเนื้อหาจะดูได้หลังเข้าสู่ระบบเท่านั้น                   |
| ผู้ดูแลระบบจัดการข้อมูล     | สร้างระบบลงทะเบียนกิจกรรมที่ผู้ใช้ส่งข้อมูลแล้วบันทึกลงฐานข้อมูลได้ และผู้ดูแลสามารถดูรายชื่อผู้ลงทะเบียนได้ |
| เครื่องมือ/เครื่องคำนวณ    | สร้างหน้าเว็บคำนวณ BMI พร้อมอินเทอร์เฟซเรียบง่าย การสลับหน่วย และคำแนะนำตามหมวดหมู่สุขภาพ     |

## ข้อจำกัดปัจจุบัน

สถานการณ์ต่อไปนี้ยังไม่รองรับ และจะค่อย ๆ เปิดให้ใช้งานในเวอร์ชันต่อ ๆ ไป:

- การเชื่อมต่อระบบชำระเงินของบุคคลที่สาม เช่น Stripe และ PayPal
- การเข้าสู่ระบบด้วย OAuth ของบุคคลที่สาม เช่น Google และ GitHub ขณะนี้รองรับเฉพาะการเข้าสู่ระบบด้วยบัญชี Kimi หรือการเข้าสู่ระบบด้วยชื่อผู้ใช้/รหัสผ่านบนฐานข้อมูลเท่านั้น
- การเชื่อมต่อ API ฝั่งเซิร์ฟเวอร์ที่ซับซ้อน เช่น การเชื่อมต่อกับบริการ SaaS ภายนอก
