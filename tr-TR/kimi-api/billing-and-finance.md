# Faturalandırma ve finans

<Callout type="info">
Kimi API faturalandırma, fiyatlandırma ve ödeme hakkında sıkça sorulan sorular.
</Callout>

## Fiyatlandırma yapısı nasıldır?
Kimi API, tüketilen token başına faturalandırılır — giriş token'ları ile çıkış token'ları ayrı ayrı fiyatlandırılır. Fiyatlandırma modele göre değişir ve Web Search her çağrı için 0,004 $ ek ücrete tabidir.

<Callout type="tip">
Detaylı fiyatlandırma için bkz. [platform.moonshot.ai/docs/pricing/chat](https://platform.moonshot.ai/docs/pricing/chat).
</Callout>

## Hangi ödeme yöntemleri destekleniyor?
API konsolu aşağıdaki ödeme yöntemlerini destekler:
| Yöntem | Ayrıntılar |
| --- | --- |
| **Kredi/Banka Kartı** | Visa, Mastercard ve diğer başlıca kartlar |
| **Havale** | Kuruluş doğrulaması yapılmış kullanıcılar havale talep edebilir — banka bilgileri için satış ekibiyle iletişime geçin |

Yüklenen bakiye, API kullanımı için anında kullanıma hazırdır.
## Fatura nasıl talep ederim?
1. [platform.moonshot.ai](https://platform.moonshot.ai) konsoluna giriş yapın.
2. **Faturalandırma → Fatura Yönetimi** bölümüne gidin.
3. Fatura almak istediğiniz yükleme kayıtlarını seçin.
4. Fatura bilgilerini (bireysel veya kurumsal) doldurun ve gönderin.
5. E-posta adresinize elektronik bir fatura gönderilecektir.
