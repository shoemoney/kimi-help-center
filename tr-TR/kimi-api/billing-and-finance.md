# Faturalandırma ve finans

<Callout type="info">
Kimi API faturalandırması, fiyatlandırması ve ödemeleri hakkında sık sorulan sorular.
</Callout>

## Fiyatlandırma yapısı nasıl?
Kimi API, tüketilen token başına ücretlendirilir — giriş token’ları ve çıkış token’ları ayrı ayrı fiyatlandırılır. Ücretler modele göre değişir; web search ise her çağrı için ek $0.004 ücrete tabidir.

<Callout type="tip">
Ayrıntılı fiyatlandırma için [platform.kimi.ai/docs/pricing/chat](https://platform.kimi.ai/docs/pricing/chat) sayfasına bakın.
</Callout>

## Hangi ödeme yöntemleri destekleniyor?
API konsolu aşağıdaki ödeme yöntemlerini destekler:
| Yöntem | Ayrıntılar |
| --- | --- |
| **Kredi/Banka Kartı** | Visa, Mastercard ve diğer başlıca kartlar |
| **Banka Havalesi** | Kurum doğrulaması tamamlanmış kullanıcılar banka havalesi talep edebilir — banka bilgileri için satış ekibiyle iletişime geçin |

Yüklenen bakiye API kullanımına hemen açılır.
## Nasıl fatura talep ederim?
1. [platform.kimi.ai](https://platform.kimi.ai) konsolunda oturum açın.
2. **Faturalandırma → Fatura Yönetimi** bölümüne gidin.
3. Fatura almak istediğiniz bakiye yükleme kayıtlarını seçin.
4. Fatura bilgilerini (bireysel veya kurumsal) doldurup gönderin.
5. Elektronik fatura e-posta adresinize gönderilir.
