# Kimi API’ye genel bakış

Kimi API platformu, geliştiricilere güçlü büyük dil modeli yetenekleri sunarak yapay zekâyı ürün ve hizmetlerinize hızla entegre etmenize yardımcı olur.

## Platforma genel bakış

Kimi API, Moonshot'un tescilli büyük dil modellerinden güç alır; metin üretimi, çok turlu konuşmalar, dosya ayrıştırma, web araması ve diğer temel yetenekleri sunar. Platform, OpenAI API formatıyla uyumludur; böylece geliştiriciler en az çabayla geçiş yapıp entegrasyon gerçekleştirebilir.

**Platform URL’si**: [platform.kimi.ai](https://platform.kimi.ai)

## Hedef kitle

- **Bağımsız Geliştiriciler**: Yapay zekâ destekli kişisel proje ve araçları hızla geliştirin.
- **Kurumsal Mühendislik Ekipleri**: Kullanıcı deneyimini ve operasyonel verimliliği artırmak için yapay zekâ yeteneklerini kurumsal ürünlere dahil edin.
- **Girişimler**: Ürün iterasyonunu hızlandırmak için üst düzey yapay zekâ yeteneklerine düşük maliyetle erişin.

## Başlıca kullanım senaryoları

- **Akıllı Müşteri Hizmetleri**: Destek verimliliğini ve müşteri memnuniyetini artıran, bağlama duyarlı otomatik soru-cevap.
- **İçerik Üretimi**: Makale yazımı, pazarlama metinleri, kod üretimi ve diğer yaratıcı iş akışları.
- **Veri Analizi**: Belge yorumlama, rapor analizi, bilgi çıkarımı ve özetleme.
- **Bilgi Soru-Cevap**: Özel belge depolarıyla desteklenen akıllı erişim ve soru-cevap sistemleri.

## Hızlı başlangıç

1. Geliştirici hesabı oluşturmak için [platform.kimi.ai](https://platform.kimi.ai) adresini ziyaret edin.
2. Konsolda bir API anahtarı oluşturun.
3. İlk çağrınızı yapmak için API dokümantasyonuna bakın.
4. Kullanım senaryonuza uygun modeli ve parametreleri seçin.
