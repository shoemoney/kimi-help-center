# Kimi API'ye genel bakış

Kimi API platformu, geliştiricilere güçlü büyük dil modeli yetenekleri sunarak yapay zekâyı ürün ve hizmetlerinize hızla entegre etmenize yardımcı olur.

## Platforma genel bakış

Kimi API, Moonshot'ın kendi geliştirdiği büyük dil modelleriyle çalışır; metin üretimi, çok turlu sohbetler, dosya ayrıştırma, web araması ve diğer temel yetenekleri sunar. Platform, OpenAI API formatıyla uyumludur ve geliştiricilerin en az çabayla geçiş yapıp entegrasyon gerçekleştirmesine olanak tanır.

**Platform URL'si**: [platform.kimi.ai](https://platform.kimi.ai)

## Hedef kitle

- **Bağımsız Geliştiriciler**: Yapay zekâ destekli kişisel projeler ve araçlar hızlıca oluşturun.
- **Kurumsal Mühendislik Ekipleri**: Kullanıcı deneyimini ve operasyonel verimliliği artırmak için yapay zekâ yeteneklerini kurumsal ürünlere yerleştirin.
- **Girişimler**: Düşük maliyetle üst düzey yapay zekâ yeteneklerine erişerek ürün gelişimini hızlandırın.

## Başlıca kullanım senaryoları

- **Akıllı Müşteri Hizmetleri**: Bağlama duyarlı otomatik soru-cevap ile destek verimliliğini ve müşteri memnuniyetini artırın.
- **İçerik Üretimi**: Makale yazımı, pazarlama metinleri, kod üretimi ve diğer yaratıcı iş akışları.
- **Veri Analizi**: Belge yorumlama, rapor analizi, bilgi çıkarımı ve özetleme.
- **Bilgi Soru-Cevabı**: Özel belge depolarıyla desteklenen akıllı arama ve soru-cevap sistemleri.

## Hızlı başlangıç

1. Geliştirici hesabı oluşturmak için [platform.kimi.ai](https://platform.kimi.ai) adresini ziyaret edin.
2. Konsolda bir API Key oluşturun.
3. İlk çağrınızı yapmak için API belgelerine başvurun.
4. Kullanım senaryonuza uygun model ve parametreleri seçin.
