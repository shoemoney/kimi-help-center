# Lựa chọn và so sánh mô hình

<Callout type="info">
Chọn mô hình Kimi API phù hợp dựa trên năng lực, tốc độ và giá.
</Callout>

Kimi API cung cấp nhiều mô hình để nhà phát triển lựa chọn.
## Các mô hình hiện có
Truy cập [platform.kimi.ai/docs/models](https://platform.kimi.ai/docs/models) để xem danh sách mô hình đầy đủ và thông số chi tiết.
Khi chọn mô hình, bạn có thể cân nhắc:
| Tiêu chí | Điều cần cân nhắc |
| --- | --- |
| **Độ dài ngữ cảnh** | Chọn mô hình hỗ trợ ngữ cảnh lớn để xử lý tài liệu dài |
| **Tốc độ phản hồi** | Dùng mô hình nhẹ cho các tình huống nhạy cảm với độ trễ |
| **Chất lượng sinh nội dung** | Dùng mô hình cao cấp hơn cho suy luận phức tạp và viết sáng tạo |
| **Giá** | Chọn mô hình tối ưu chi phí theo ngân sách và lưu lượng sử dụng |

## Mô hình thị giác
Mô hình thị giác hỗ trợ đầu vào hình ảnh để tạo chú thích, OCR, diễn giải biểu đồ, v.v.:

<Callout type="info">
- Mỗi hình ảnh được tính phí cố định **1.024 token**, bất kể kích thước hay độ phân giải
- Định dạng được hỗ trợ: JPEG, PNG, WebP, v.v.
- Có thể truyền hình ảnh qua URL hoặc mã hóa Base64
</Callout>

## Các năng lực hiện chưa được hỗ trợ

<Callout type="warning">
- **Đa phương thức video**: Chưa hỗ trợ đầu vào video trực tiếp
- **PPT Generation API**: Chưa khả dụng qua API
- **Deep Research API**: Chưa khả dụng qua API
</Callout>

Để cập nhật về các năng lực này, hãy theo dõi thông báo trên nền tảng.
