# Lựa chọn và so sánh mô hình

<Callout type="info">
Chọn mô hình Kimi API phù hợp dựa trên năng lực, tốc độ và giá cả.
</Callout>

Kimi API cung cấp nhiều mô hình để nhà phát triển lựa chọn.
## Các mô hình hiện có
Truy cập [platform.kimi.ai/docs/models](https://platform.kimi.ai/docs/models) để xem danh sách mô hình đầy đủ cùng thông số kỹ thuật chi tiết.
Khi chọn mô hình, bạn có thể cân nhắc:
| Tiêu chí | Điểm cần lưu ý |
| --- | --- |
| **Độ dài ngữ cảnh** | Chọn mô hình ngữ cảnh lớn để xử lý tài liệu dài |
| **Tốc độ phản hồi** | Mô hình nhẹ cho các tình huống nhạy cảm với độ trễ |
| **Chất lượng sinh nội dung** | Mô hình cấp cao cho suy luận phức tạp và viết sáng tạo |
| **Giá cả** | Chọn mô hình tối ưu chi phí dựa trên ngân sách và khối lượng sử dụng |

## Mô hình thị giác
Các mô hình thị giác hỗ trợ nhập ảnh để mô tả ảnh, OCR, diễn giải biểu đồ và nhiều tác vụ khác:

<Callout type="info">
- Mỗi ảnh được tính phí cố định ở mức **1.024 token**, bất kể kích thước hay độ phân giải
- Định dạng được hỗ trợ: JPEG, PNG, WebP, v.v.
- Có thể truyền ảnh qua URL hoặc mã hóa Base64
</Callout>

## Các năng lực hiện chưa hỗ trợ

<Callout type="warning">
- **Đa phương thức video**: Chưa hỗ trợ nhập video trực tiếp
- **API tạo PPT**: Chưa khả dụng qua API
- **Deep Research API**: Chưa khả dụng qua API
</Callout>

Để cập nhật về các năng lực này, hãy theo dõi các thông báo trên nền tảng.
