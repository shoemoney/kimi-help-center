# Liên hệ & Phản hồi

## Kênh phản hồi

Nếu gặp sự cố khi sử dụng Kimi Code hoặc có đề xuất, bạn có thể gửi phản hồi qua các kênh sau.

### Cách 1: Gửi phản hồi trực tiếp trong CLI

Ở chế độ tương tác của Kimi Code CLI, nhập lệnh `/feedback` để gửi phản hồi. Hệ thống sẽ tự động thu thập thông tin về môi trường hiện tại của bạn, giúp bạn mô tả sự cố chính xác hơn.

### Cách 2: GitHub Issues

Truy cập [Kimi CLI GitHub Issues](https://github.com/MoonshotAI/kimi-cli/issues) và tìm kiếm xem đã có sự cố tương tự hay chưa. Nếu chưa, bạn có thể tạo một Issue mới và mô tả chi tiết những gì mình gặp phải.

### Cách 3: Gửi phản hồi qua email

Bạn cũng có thể gửi email cho đội ngũ Kimi Code qua [code@moonshot.ai](mailto:code@moonshot.ai) để báo cáo sự cố. Vui lòng cung cấp càng đầy đủ càng tốt các thông tin sau:

- **Mô tả sự cố**: Mô tả rõ sự cố bạn gặp phải hoặc tính năng bạn mong muốn
- **Các bước tái hiện**: Cách kích hoạt sự cố theo từng bước
- **Thông tin môi trường**: Hệ điều hành và phiên bản Kimi Code CLI (chạy `kimi --version` để kiểm tra)
- **Nhật ký lỗi**: Nếu có thông báo lỗi, vui lòng dán đầy đủ nội dung

### Cách 4: Tham gia nhóm Feishu
Quét mã QR để tham gia nhóm Feishu

## Kiểm tra trước khi gửi phản hồi

Trước khi gửi phản hồi, bạn nên kiểm tra các mục sau:

- Bạn đã cập nhật lên phiên bản Kimi Code CLI mới nhất hay chưa (chạy `kimi --version` để kiểm tra)
- Kết nối mạng của bạn có hoạt động bình thường hay không và bạn có truy cập được `api.kimi.com` hay không
- Khóa API của bạn có hợp lệ và chưa hết hạn hay không
- Thư mục làm việc có đúng hay không và Kimi có quyền truy cập các tệp liên quan hay không
