# 什么是技能（Skills）

技能是可复用的知识包，用于扩展智能体的能力边界了，每个技能包含：

- **处理思路与操作指引** — 针对特定任务类型的方法论
- **最佳实践与规范约定** — 应遵循的行业标准与内部规范
- **可选的脚本工具与参考资源** — 辅助执行的实用工具与素材

## 使用方式

对话开始时，智能体将看到可用技能列表及其名称与简介。若某项技能与当前任务相关，智能体会读取完整说明并遵照执行。

## 使用路径

从发现技能到创建自己的技能，完整路径如下：

1. **发现技能** — 在技能面板浏览官方技能和推荐技能，找到适合你场景的技能。
2. **安装技能** — 点击加号一键添加
3. **调用技能** — 在对话输入框输入 `/` 选择技能（Skills），或让 Kimi 根据你的问题自动触发。
4. **创建自己的技能** — 如果现有技能不满足需求，上传文档或通过对话描述需求，生成专属技能，或通过 `/skill-creator` 对话创建自定义技能。

## 技能（Skills）如何工作？

当你发起一个请求，Kimi 会判断当前任务是否涉及某个技能，若涉及则自动加载对应技能，并按其中的指令完成任务。

技能只在任务相关时才会加载，不影响其他对话的上下文。

## 技能（Skills）和直接提问有什么区别？

直接问 Kimi，每次对话都从零开始，Kimi 用通用能力回答，不带任何个人设定。技能相当于在通用能力之上预装了一套专属规则，每次触发时这套规则自动生效。

以写周报为例：直接问 Kimi，它会按自己理解的格式写；装了周报技能之后，每次都按你设定的结构、语气、长度来输出，不需要重复说明。

| | 直接问 Kimi | 使用技能（Skills） |
|---|---|---|
| 每次是否需要说明要求 | 是 | 否，自动应用 |
| 输出格式是否稳定 | 不固定 | 按技能定义一致 |
| 适合场景 | 一次性、临时任务 | 反复执行的固定流程 |
| 是否需要提前设置 | 不需要 | 需要创建或安装技能 |

## 技能（Skills）类型

### Kimi 推荐技能（Skills）

Kimi 提供推荐技能，可一键添加，涵盖投资研究、文档排版、SEO 分析等常用场景。由 Moonshot AI 创建和维护，对所有用户开放，Kimi 在相关场景中自动调用。

常见推荐技能包括：

- `docx` — 创建和编辑 Word 文档，适用于任何 .docx 任务，包括文档创建、编辑、批注、修订、脚注、目录以及 Markdown 到 Word 的转换
- `deep-research` — 利用工具套件实现深度研究与长篇报告构建，要求至少10轮迭代搜索周期、递归反思，且须包含强制性的IPython可视化与特定段落逻辑。
- `sop-writer` — 将业务流程梳理成完整的标准操作流程文档（SOP），包括流程图、RACI分工矩阵、详细操作步骤以及异常情况处理。
- `event-etf-study` — 从概念或事件出发，识别相关股票，构建市值加权ETF指数，分析事件窗口期间的市值变化，并生成交互式HTML仪表盘。当用户询问概念股、概念ETF、事件驱动分析或事件研究时使用。

### 自定义技能（Skills）

由你自己创建，用于个人工作流和特定领域任务，例如：

- 将特定风格规范应用于文档或演示文稿
- 按固定模板生成邮件或沟通内容
- 使用特定格式整理会议纪要
- 执行特定的数据分析工作流

自定义技能（Skills）只需要用文字写清楚你希望 Kimi 怎么做，无需编程基础。
