# Agent 功能与限制

<SeoMeta
  title="Agent 功能与限制 - Kimi 帮助中心"
  description="了解 Kimi Agent 的能力、使用技巧、限制与最佳实践，获得更理想的使用效果。"
/>

<Callout type="info">
**Kimi Agent** 是一款由 AI 驱动的助手，可通过多步推理和工具集成自主执行复杂任务。本指南将介绍最佳实践、使用限制和常见问题，帮助你更高效地使用 Agent 模式。
</Callout>

## 使用技巧

**(1) 提交任务前**

请清楚说明背景信息和约束条件，包括项目背景、使用场景和特殊要求，帮助 Kimi 更准确地理解你的意图。

**(2) 执行过程中**

Kimi Agent 会在后台异步运行。如果网页看起来卡住或无响应，**请不要点击“停止”**，否则会中断任务执行。你可以离开页面，任务会继续在后台运行，并在完成后通知你。对于预计耗时较长的任务（例如 K2.6 Agent Swarm [Beta]），请耐心等待。

**(3) 网站场景**

Agent 可以生成全栈内容，包括前端界面、后端服务和持久化存储逻辑。如果项目未按预期运行，问题通常与沙盒启动、数据库初始化、认证配置或缺少发布操作有关。标准 Agent 运行在云端，无法直接访问本地文件或企业内网系统。如需访问本地文件或内网，请使用 Kimi Claw。

<Callout type="tip">
**需要访问本地文件？** 请使用 Kimi Claw 安全访问本地文件和企业内网系统。更多信息请参阅 [Kimi Claw 文档](/kimi-claw/overview)。
</Callout>

**(4) 多轮对话与任务调整**
经过多轮对话和修改后，Agent 可能会“忘记”部分早期细节。建议先搭建好任务框架并明确关键点，再逐步进行增量调整。

**(5) 大任务拆分**
对于规模较大、较复杂的任务，建议拆分为 2–3 个阶段分批提交给 Kimi，或使用 K2.6 Agent Swarm [Beta]。

**(6) 文件输出限制**
在标准 Agent 模式下，每个任务通常只能输出一个文件（例如一份文档或一张表格）。如需多个文件（例如同时输出 Word 文档和 PPT），请使用 K2.6 Agent Swarm [Beta]。

**(7) 上下文限制与输出平衡**
由于大语言模型的上下文限制为 256K 个字符（约 40,000–50,000 个中文字符 / 约 100,000 个英文单词），处理大量文件时需要在输入量和输出量之间做好平衡。

<Callout type="warning">
**上下文限制提示**：Agent 使用 256K 字符的上下文窗口。为获得最佳效果，请提供简洁的上下文，避免上传不必要的文件造成负担。
</Callout>

## 重要说明

<Callout type="warning">
**额度使用**：Agent 任务会消耗共享池（其他会员功能）的额度。Kimi Code 使用单独的额度池。每个 Agent 任务通常消耗 1 个额度单位。不同会员等级的详细额度信息，请参阅[额度与计费](/agent/quota-and-billing)。

- 免费等级：每月 6 个 Agent 任务
- 付费等级：每月 60–720 个 Agent 任务，具体取决于你的套餐
</Callout>

- **执行时间**：在 Agent 模式下，单个任务通常需要 5–20 分钟。K2.6 Agent Swarm [Beta] 任务可能需要更长时间。你可以离开页面，但不要点击“停止”来中断任务。
- **额度使用**：Agent 任务会消耗共享池中的额度。Kimi Code 使用单独的额度池。 
- **简单任务**：对于简单问答，建议使用标准聊天模式，以获得更快的响应。

<Callout type="warning">
**内容合规**：Agent 功能受 [《Kimi 用户服务协议》](https://www.kimi.com/user/agreement/modelUse?version=v2) 约束。不支持生成违规内容；提交违规内容可能导致服务暂停。
</Callout>

## 常见问题

**问：Agent 可以做什么？**

Agent 可通过多次工具调用满足以下需求：
- **文本生成与编辑**：生成文章、报告、文档等，支持多种写作风格和格式。
- **网页开发**：构建全栈项目界面与服务，支持应用界面设计、后端集成、数据持久化和数据可视化。
- **幻灯片生成**：提供专用的网页端 PPT 工具，用于生成完整演示文稿。
- **编程辅助**：支持多种编程语言的代码编写与调试。

**问：为什么 Agent 搭建的网站无法运行？**

一个完整项目通常由三部分组成：前端界面、后端服务和数据存储。Agent 可以生成覆盖这三层的全栈项目内容。如果你的项目未按预期运行，问题通常与沙盒启动、数据库初始化、认证配置或缺少发布操作有关。

**问：Agent 会交付哪些内容？**

- 完整的任务执行文件
- 已部署的项目预览与已发布版本
- 可下载的 Zip 压缩包（位于 `/mnt/okcomputer/output/`）

**问：Agent 的上下文长度是多少？**

Agent 使用 **256K 个字符** 的上下文长度（约 40,000–50,000 个中文字符 / 约 100,000 个英文单词）。

**问：Agent 额度如何计算？**

Agent、PPT 及其他会员功能共用一个额度池。Kimi Code 使用单独的额度池。每个 Agent 任务通常计为 1 个额度单位。你可以在[会员额度](https://www.kimi.com/membership-credits)查看当前额度和使用情况。
