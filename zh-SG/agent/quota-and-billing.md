# Agent 配额与计费

<Callout type="info">
Agent 模式使用 Kimi 的配额系统。所有会员权益包含两个配额池：Kimi Code 使用独立配额池；其他会员功能（Agent、Deep Research（深度研究）、Slides、Docs、Sheets、Kimi Claw 等）共享同一个配额池，并按实际 token 消耗扣减配额。
</Callout>

## 计费方式
- **两个配额池**：所有会员权益包含两个配额池。Kimi Code 使用独立配额池；其他会员功能共享同一个配额池——你可以按需分配使用
- **按量使用**：配额消耗取决于任务复杂度和耗时（即 token 用量）——任务越简单，消耗越少；任务越复杂，消耗越多
- **按月刷新**：配额每月重置，与你的订阅周期保持一致
- **使用优先级**：优先消耗赠送配额（如试用额度、活动奖励），之后再消耗套餐配额

<Callout type="tip">
**示例**：使用 Moderato 方案时，生成一份简单 PPT 可能消耗约 1–2% 的配额；完成一次 Deep Research（深度研究）可能消耗约 5–10%。
</Callout>

## 配额用完后会怎样？
当配额耗尽时：
- 正在进行中的任务会正常完成
- 新任务会提示“配额不足”
- 你可以选择：
  - 等待每月配额自动刷新
  - 升级到更高等级的会员，获得更多配额

## 如何查看配额使用情况？
- **网页版**：个人资料 → 设置 → 订阅
- **App**：个人资料 → 会员方案 → 订阅
你可以查看：
1. 当前配额余额（百分比）
2. 下次刷新日期
3. 最近 10 条使用记录（时间戳、使用的功能、消耗百分比）

<Callout type="info">
使用记录可能会有短暂延迟。请以实际显示的配额为准，获取最新信息。
</Callout>

## 任务失败还会消耗配额吗？
- 任务成功执行后，才会根据实际消耗扣减配额
- 如果任务因系统错误失败（未返回有效结果），请点击 **👎** 按钮进行反馈。核实后，相应配额将退还
