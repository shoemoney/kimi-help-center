# Agent 额度与计费

<Callout type="info">
Agent 模式使用 Kimi 的额度系统。所有会员权益包含两个额度池：Kimi Code 使用独立额度池；其他会员功能（Agent、Deep Research（深度研究）、Slides、Docs、Sheets、Kimi Claw 等）共享同一个额度池，并按实际 token 消耗扣减额度。
</Callout>

## 计费方式
- **两个额度池**：所有会员权益包含两个额度池。Kimi Code 使用独立额度池；其他会员功能共享同一个额度池——你可以按需分配使用
- **按量使用**：额度消耗取决于任务复杂度和耗时（即 token 用量）——任务越简单，消耗越少；任务越复杂，消耗越多
- **按月刷新**：额度每月重置，与你的订阅周期保持一致
- **使用优先级**：优先消耗赠送额度（如试用额度、活动奖励），之后再消耗套餐额度

<Callout type="tip">
**示例**：使用 Moderato 方案时，生成一份简单 PPT 可能消耗约 1–2% 的额度；完成一次 Deep Research（深度研究）可能消耗约 5–10%。
</Callout>

## 额度用完后会怎样？
当额度耗尽时：
- 正在进行中的任务会正常完成
- 新任务会提示“额度不足”
- 你可以选择：
  - 等待每月额度自动刷新
  - 升级到更高等级的会员，获得更多额度

## 如何查看额度使用情况？
- **网页版**：个人资料 → 设置 → 订阅
- **App**：个人资料 → 会员方案 → 订阅
你可以查看：
1. 当前额度余额（百分比）
2. 下次刷新日期
3. 最近 10 条使用记录（时间戳、使用的功能、消耗百分比）

<Callout type="info">
使用记录可能会有短暂延迟。请以实际显示的额度为准，获取最新信息。
</Callout>

## 任务失败还会消耗额度吗？
- 任务成功执行后，才会根据实际消耗扣减额度
- 如果任务因系统错误失败（未返回有效结果），请点击 **👎** 按钮进行反馈。核实后，相应额度将退还
