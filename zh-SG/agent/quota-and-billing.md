# Agent 额度与计费

<Callout type="info">
Agent 模式采用 Kimi 的额度体系。所有会员功能（Agent、Deep Research（深度研究）、幻灯片、文档、表格、Kimi Code、Kimi Work、Kimi Claw 等）共用同一个额度池，并会根据实际 token 消耗扣减额度。
</Callout>

## 计费方式
- **共享额度池**：所有会员功能共用同一个额度池，你可以按需分配使用。Kimi Code 另有每周 5 小时的专属速率限制，仅适用于 Kimi Code，不影响其他功能
- **按量计费**：额度消耗取决于任务复杂度与执行时长（即 token 用量）——简单任务消耗较少，复杂任务消耗较多
- **每月刷新**：额度按月重置，与订阅周期保持一致
- **使用优先级**：优先消耗赠送额度（如试用额度、活动奖励），之后再消耗套餐额度

<Callout type="tip">
**示例**：使用 Moderato 套餐时，生成一份简单 PPT 可能消耗约 1–2% 的额度；而一次 Deep Research（深度研究）可能消耗约 5–10%。
</Callout>

## 额度用完后会怎样？
当你的额度耗尽时：
- 正在进行中的任务会正常完成
- 新任务会显示“额度不足”提示
- 你可以：
  - 等待每月额度自动刷新
  - 升级至更高等级的会员，获得更多额度

## 如何查看额度使用情况？
- **网页端**：个人资料 → 设置 → 订阅
- **App**：个人资料 → 会员套餐 → 订阅
你可以查看：
1. 当前额度余额（以百分比显示）
2. 下次刷新日期
3. 最近 10 条使用记录（时间戳、使用的功能、消耗百分比）

<Callout type="info">
使用记录可能会有短暂延迟。请以实际显示的额度信息为准。
</Callout>

## 任务失败也会消耗额度吗？
- 任务成功执行后，系统会根据实际消耗扣减额度
- 如果任务因系统错误失败（未返回有效结果），请点击 **👎** 按钮进行反馈。核实后，相应额度将会退回
