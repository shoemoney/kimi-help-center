# 什么是技能？

<Frames
  src="./images/skills/what_is_skill.png"
  alt="what_is_skill"
/>

技能是可复用的知识包，用于拓展 AI 智能体的能力边界。每个技能包含：

- **工作方法与操作指引** — 面向特定任务类型定制的方法论。
- **最佳实践与规范** — 需要遵循的行业标准和内部流程。
- **脚本、工具与参考资源** — 用于辅助执行的可选工具和材料。

## 如何使用？

对话开始时，Agent 会看到可用技能列表，包括技能名称和简要说明。如果某个技能与当前任务相关，Agent 会加载完整说明并按要求执行。

## 用户路径

从发现技能到创建自己的技能，完整流程如下：

1. **发现技能** — 在技能面板浏览官方和推荐技能，找到适合你场景的技能。
2. **安装技能** — 点击“+”按钮即可立即添加技能。
3. **调用技能** — 在聊天框输入 `/` 选择技能，或让 Kimi 根据你的问题自动触发相关技能。
4. **创建自己的技能** — 如果现有技能不能满足需求，可以上传文档或描述要求来生成自定义技能，也可以使用 `/skill-creator` 通过对话创建。

## 技能如何工作？

当你发送请求时，Kimi Agent 会判断当前任务是否需要特定技能。如果需要，它会自动加载对应技能，并按照技能说明完成任务。

技能只会在与任务相关时加载，因此不会干扰其他对话的上下文。

## 技能与直接提示有什么区别？

以撰写周报为例：
- **直接提示**：直接让 Kimi Agent 撰写，它会根据自己对格式的理解生成内容。
- **使用技能**：安装周报技能后，每次输出都会遵循你预设的结构、语气和长度，无需反复说明。

| | 直接提示 | 使用技能 |
|---|---|---|
| **每次都需要说明要求吗？** | 是 | 否，会自动应用 |
| **输出格式稳定性** | 不固定 | 按定义保持一致 |
| **最适合的场景** | 一次性、临时任务 | 重复性、固定流程 |
| **是否需要设置？** | 否 | 需要创建或安装 |

## 技能类型

### (1) 官方技能与推荐技能

**官方技能**：由 Moonshot AI 创建并维护，面向所有用户开放。Kimi 会在相关场景中自动触发这些技能。

常见官方技能包括：
- `docx` — 创建和编辑 Word 文档，适用于任何 .docx 任务，包括文档创建、编辑、批注、修订、脚注、目录，以及 Markdown 转 Word。
- `deep-research` — 使用工具集开展深度研究并生成长篇报告，要求至少进行 10 轮迭代搜索、递归反思，并强制使用 IPython 可视化。

**推荐技能**：按场景精选的技能，可一键添加，覆盖投资研究、文档排版等常见用例。

常见推荐技能包括：
- `sop-writer` — 将业务流程转化为完整的标准作业程序（SOP）文档，包括流程图、RACI 矩阵、详细操作步骤和异常处理。
- `event-etf-study` — 从一个概念或事件出发，识别相关股票，构建按市值加权的 ETF 指数，分析事件窗口期内的市值变化，并生成交互式 HTML 看板。适用于用户询问概念股、概念 ETF、事件驱动分析或事件研究的场景。

**办公文档生成技能**：上传文档即可生成技能，轻松复用风格主题。

### (2) 开源技能

从开源社区下载或安装合适的技能，并结合本地 Agent（如 Kimi Code）或云端 Agent（如 Kimi Claw）使用。

**常见 AI 技能中心平台**

| 平台 | URL | 描述 |
|----------|-----|-------------|
| SkillsMP | https://skillsmp.com | AI agent 技能市场，从 GitHub 收集 SKILL.md 包，兼容 Claude Code 和 OpenAI Codex CLI |
| SkillsLLM | https://skillsllm.com | 开源 AI agent 技能市场，提供 1,600+ 个经过安全审核的技能，适用于 Claude Code、Codex CLI 和 ChatGPT |
| LobeHub Skills | https://lobehub.com/skills | 浏览和分发兼容 Claude Code、Codex CLI 与 ChatGPT 的 SKILL.md 包 |

### (3) 自定义技能

由你为个人工作流和特定领域任务创建的自定义技能，例如：
- 为文档或演示文稿应用特定风格指南。
- 基于固定模板生成邮件或沟通内容。
- 按特定格式整理会议纪要。
- 执行特定的数据分析流程。
