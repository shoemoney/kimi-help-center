# Deep Research（深度研究）

<Callout type="info">
**Deep Research（深度研究）** 是 Kimi 首个 Agent 产品，由 Kimi-Researcher 模型驱动。它不只是回答问题，更像真正的研究员，能够从任务规划到报告交付，自主完成整个工作流。
</Callout>

## Kimi-Research 是如何工作的？

面对每个问题，Kimi-Researcher 会独立完成完整的研究流程：
| 步骤 | 说明 |
| --- | --- |
| **意图澄清** | 主动追问，以厘清研究意图并建立更清晰的问题空间 |
| **深入思考** | 每个任务平均进行 23 步推理，梳理并拆解需求 |
| **主动搜索** | 规划约 74 个关键词，发现 206 个 URL，并筛选出质量最高的前 3.2% 内容 |
| **深度推理** | 评估结果，判断是否需要进一步搜索并动态调整研究路径 |
| **工具调用** | 调用浏览器、代码执行等工具处理数据 |
| **报告生成** | 将信息整合为结构化长篇报告，并附上引用 |

<Callout type="info">
Deep Research（深度研究）采用异步运行，会用 10–25 分钟逐步完成推理、检索与写作。
</Callout>

## 交付内容
每个研究任务都会生成两项交付内容：
### 1. 文本研究报告
- 平均长度：10,000+ 字
- 约 26 个高质量、可追溯来源
- 引用以内联方式嵌入，点击即可跳转到来源

## 应用场景

<Callout type="tip">
**最适合**：投资分析、行业研究、学术主题、战略规划、监管审查、知识综合
</Callout>

| 类别 | 示例 |
| --- | --- |
| **专业研究** | 投资分析、行业研究、学术主题、战略规划 |
| **信息综合** | 监管审查、复杂文档检索、多来源整合 |
| **知识与教育** | 教学资料、系统性综述、深度主题探索 |
| **日常探索** | 了解感兴趣的话题 |

<Callout type="warning">
**不适合**：创意写作（小说、剧本）、占卜、简历写作、固定格式模板、可编辑幻灯片
</Callout>

## 如何使用 Deep Research（深度研究）？
**入口**：
- **Web**：[kimi.com/deep-research](https://www.kimi.com/deep-research)
- **Mobile**：Kimi app → 任务栏 → Deep Research Agent 模式
**步骤**：
1. 输入你的研究问题并发送
2. 回答意图澄清问题以确认方向（或点击“包含全部”跳过）
3. 实时查看搜索关键词、推理过程和已访问的 URL
4. 完成后接收两项交付内容：
   - **Deep Research（深度研究）报告**（Markdown）：10,000+ 字，包含目录与可追溯来源
   - **可视化报告**（HTML）：可交互、可公开分享的可视化报告
5. 根据需要预览、下载（PDF/Word）或分享
## 获得最佳效果的小贴士
### 1. 聚焦范围
提交前，建议明确：
- **时间范围**：“2023 年至今”
- **地域范围**：“仅限美国市场”
- **来源类型**：“优先参考官方报告和学术论文”
- **问题拆解**：将宽泛问题拆分为子问题

### 2. 在意图澄清阶段校准方向
- 说明你 *不希望* 涵盖的方向
- 补充希望重点关注的具体维度或角度
- 对复杂问题提供背景信息

<Callout type="warning">
意图澄清回复请保持简洁、具体——过长或不清晰的输入可能导致研究方向偏移。
</Callout>

### 3. 执行过程中耐心等待
Deep Research（深度研究）通常需要 10–25 分钟。系统会在后台运行，你无需一直停留在页面上。

<Callout type="warning">
**不要点击“停止输出”**——这会终止研究。如果页面看起来无响应，直接刷新即可。
</Callout>

## 重要说明
1. **执行时间**：10–25 分钟。任务会异步运行，完成后你将收到通知
2. **额度返还**：因工具调用错误导致失败时会自动返还额度；如研究方向偏离，请提交反馈
3. **输入质量**：简洁、定义清晰的问题通常会带来更好的结果
4. **范围边界**：对于简单问答，建议使用标准聊天模式，以获得更快回复
5. **条款**：适用 [《Kimi 用户服务协议》](https://www.kimi.com/user/agreement/modelUse?version=v2)
