# Deep Research（深度研究）用例与提示词库

## 用例概览

| 场景 | 示例提示词 |
|:---|:---|
| 行业/市场研究 | 研究 2025 年国内人形机器人行业的竞争格局与主要玩家 |
| 竞品分析 | 对比分析 Notion 与 Obsidian 在产品策略上的差异 |
| 投资尽调 | 汇总过去两年主要大语言模型（LLM）公司的融资轮次与估值变化 |
| 学术文献综述 | 梳理 RAG（检索增强生成）技术的发展脉络及当前主要优化方向 |
| 政策分析 | 分析最新数据安全法规对企业出海的影响 |
| 个人决策 | 我想买一台用于视频剪辑的笔记本电脑——帮我调研主流选择 |
