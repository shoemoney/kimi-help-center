# Kimi 文档与 Kimi 表格

<Callout type="info">
2026 年 1 月 27 日，Moonshot AI 发布 Kimi K2.5，为 Kimi Agent 的生产力能力带来重大升级。如今，Kimi Agent 已能“驾驭 Office”，端到端输出 Word、PDF、Excel 和幻灯片文件。
</Callout>

在办公场景中，Kimi K2.5 的输出质量与工具调用效率均显著提升，尤其擅长具备端到端处理能力的结构化输出：
| 格式 | 能力 |
|--------|-------------|
| **Word** | 智能排版与修订追踪 |
| **PDF** | 视觉设计与图文混排 |
| **Excel** | 数据分析与财务建模 |
| **幻灯片** | 自动生成与视觉化叙事 |

## Kimi 文档
Kimi 文档具备出色的文本适配能力，并能系统理解 Office 工作流。
### 核心能力
**Word 文档：**
- 生成长篇专业文档：白皮书、研究报告、合同、提案
- 在现有 Word 文档中插入批注和修订建议
- 处理标题层级、段落间距、引用与列表格式
- 将一篇 30,000 字的论文浓缩为精准摘要
**PDF 文档：**
- 生成图文并茂的专业 PDF 报告，包含封面、目录、正文与图注
- 无需专业排版软件，即可重新编辑和调整现有 PDF 的格式
- 从上百页 PDF 中提取特定信息
- 对比多个合同版本之间的细微差异
### 如何使用 Kimi 文档？
**入口：**
- 通用入口：点击侧边栏或聊天框中的文档、表格或幻灯片快捷入口
- 专属入口：点击聊天框底部的“文档”按钮
### 方法一：访问 Kimi 文档页面

<Frames
  src="./images/overview/screenshot-1.png"
  alt="截图 1"
/>

1. **打开浏览器**：Chrome、Safari、Edge、Firefox，或任何主流浏览器
2. **前往**：[kimi.com/docs](https://www.kimi.com/docs)
3. **登录**：使用你的 Kimi 账号登录（Google 或邮箱）
4. **输入任务**：
   - **文本输入**：用自然语言描述任务
   - **上传文档** 进行编辑
   - **浏览示例**：点击“照这个做一个”，自定义后发送
5. **开始创作**：选择模板，或通过对话创建

<Frames
  src="./images/overview/screenshot-2.png"
  alt="截图 2"
/>

<Callout type="tip">
直接描述你的需求即可，例如：“帮我创建一份 XX 报告。” 也可以上传现有 Word/PDF/Excel 文件并指定操作。下载原格式文件（.docx / .xlsx / .pdf）后，可在本地继续编辑。
</Callout>

### 方法二：移动端应用
Kimi app 支持 iOS 和 Android。点击任务栏 → 切换到 Docs Agent 模式。
#### 方法三：通用 Agent 模式
切换到 K2.6 Agent 模式，并输入与文档相关的任务。Kimi 会调用读写工具。
## Kimi 表格
Kimi 表格能够理解单元格关系和跨表联动逻辑，并可直接在浏览器中生成 .xlsx 文件。
### 核心能力
| 能力 | 说明 |
|------------|-------------|
| **批量数据录入** | 从文档中提取数据——例如，将 PDF 中的参展商信息整理成 1,000 行的 Excel 文件 |
| **多源汇总** | 将 50 份不同部门的 Excel 报告合并为一份公司总览 |
| **自然语言输入** | 自主进行网页搜索，并智能生成电子表格 |

### 如何使用 Kimi 表格？
点击聊天框底部的“Agent”按钮，或选择侧边栏中的“表格”快捷入口。

  src="./images/overview/screenshot-4.png"

/>

你可以这样说：*“搜索网络并将 XX 领域的最新出版物整理成一份 Excel 文档，”* 也可以上传现有 Excel/CSV 文件并指定操作。在线预览后，再下载 .xlsx 文件。
