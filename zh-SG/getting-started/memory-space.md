# 记忆空间

## 什么是记忆？
Kimi 真的学会了倾听——你聊得越多，它就越懂你。它的工作方式如下：

Kimi 不只会回应当前聊天框里的内容。它会在一次次对话中记录重要细节——你的偏好、习惯、风格……

随着你持续使用，Kimi 会在不同会话之间不断学习，持续优化对你的理解。

你不必反复说明同一件事。Kimi 会主动参考“我们之前聊过什么”，给出更相关、更连贯的回答。

## Kimi 会记住什么？
Kimi 使用一个单独训练的模型，有选择地记住对你有价值的对话内容。

在记录任何内容前，Kimi 会先问自己两个问题：
- 这位用户是谁？
- 这位用户关心什么、偏好什么，或者想避免什么？

除非你明确要求，否则 Kimi **不会**记住未经授权的私人信息（例如健康数据、密码、地址）。

## 如何触发记忆
记忆现在是内置能力——只要自然对话，就能触发。

你可以通过以下方式更新或管理 Kimi 的记忆：

**(1) 在对话中直接指示（最常用）**

你可以用自然语言命令更新记忆：

| 操作 | 你可以这样说 | Kimi 的回应 |
|:---|:---|:---|
| 添加记忆 | “记住我喜欢咖啡”<br>“记录一下我的工号是 9527”<br>“记住我是项目经理” | Kimi 会调用记忆工具进行保存 |
| 更新记忆 | “更正一下——我已经搬到纽约了”<br>“更新：我现在是高级工程师” | Kimi 会替换旧记忆 |
| 删除记忆 | “忘掉我喜欢咖啡这件事”<br>“删除关于我工号的记忆”<br>“清空所有记忆” | Kimi 会删除指定记忆或全部记忆 |

注意：记忆完全由你掌控。它不会用于模型训练，并且你可以随时关闭或清除。

**(2) 通过设置管理（UI）**

你也可以在设置界面中管理记忆：
- 网页端 / 移动端：设置 → 个性化 → 记忆空间
- 你可以在这里查看所有已保存的记忆条目
- 你可以手动删除任何不再需要的记忆

### 添加记忆
记忆会在对话中自动触发。例如：
- “我的名字是 xxx，朋友们叫我 xxxx”
- “我是小学数学老师，所以课件内容需要适合孩子”
- “请不要在回复里使用 emoji”
- “我通常用 C++ 写代码”
- “不要重复表达，也不要使用过多标点”

如果你特别希望 Kimi 记住某件事，可以强调一下：
- “记住……”
- “请记住……”
- “……别忘了这件事”

### 更新记忆
前往个人资料 → 设置 → 个性化 → 记忆空间，即可编辑单条记忆。

### 删除（忘记）记忆
前往个人资料 → 设置 → 个性化 → 记忆空间，在单个条目上点击删除即可。
