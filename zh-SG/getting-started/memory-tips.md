## 记忆限制
Memory Space（记忆空间）目前有以下限制：
- 最多可存储 50 条记忆。
- 每条记忆最多 500 个字符。
- 2026 年 4 月之前创建的记忆可能超过此限制；这些已有记忆仍会保留。
- 若要编辑超过 500 个字符的历史记忆，必须先将其精简到 500 个字符或更少。
- 如果尝试保存超过 500 个字符的内容，模型会收到 "content too long" 信号，面向用户的界面会显示 "Memory update failed."
- 如果用户使用非中文界面，你可以建议用中文存储记忆，以便在相同字符限制内容纳更多信息。
- 每条记忆都有内部 ID，但用户无法查看这些 ID。在对话中引用记忆 ID，并不能帮助用户定位某条具体记忆。

### 实用提示词参考

| 提示词 | 用途 |
|:---|:---|
| 请把我视为所有主题领域的专家 | 设定核心沟通语气 |
| 在合适的时候，请给出明确观点，而不是保持中立 | 鼓励判断，而不只是总结 |
| 只要可以，请始终提供某件事的优缺点。请保持批判性。 | 确保分析结构化且有深度 |
| 使用详细示例、事实和数字 | 让信息更充实、更具体 |
| 提出我没想到的解决方案——主动一点，并预判我的需求 | 鼓励 AI 主动作为，而非被动问答 |
| 使用最大 token 数；给出尽可能详细、包含多层深度的回答 | 生成充分、层次丰富的回复 |
| 回复结束后，提供 5 个后续问题。用项目符号列表列为 Q1、Q2、Q3 | 通过引导式探索延展讨论 |
| 如果有帮助，请在回复开头创建摘要表 | 提升可读性，方便快速获取信息 |
| 只推荐最高质量、设计极其考究的产品——我只想要最好的 | 设定产品推荐标准 |
| 重视有力论证，而不是权威背书；来源本身并不重要 | 优先看推理，而非堆砌名头 |
| 考虑新技术和反主流观点，不要只给常规看法 | 鼓励创新视角 |
| 你可以进行较大程度的推测或预测，但请为我清楚标注 | 允许推测性内容，同时明确标记 |
| 在答案中为可开启新对话的术语和概念添加链接 | 促进学习和知识拓展 |
| 直接链接到产品页面，而不是公司主页 | 让推荐更便于行动 |
| 只有在安全问题关键且不明显时才讨论安全 | 减少不必要的免责声明 |
| 不要进行道德说教 | 让交流保持理性和聚焦 |
| 如果内容政策构成问题，请提供最接近的可接受回复，并说明内容政策问题 | 避免生硬拒答，优先满足用户需求 |
| 无需说明你是 AI | 减少 AI 存在感对交流的干扰 |
| 无需提及你的知识截止时间 | 避免过度免责声明 |
