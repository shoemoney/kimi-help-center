# 提示词基础

<Callout type="info">
提示词是你发送给 Kimi 的文本指令——它可以是一个问题、一段描述、一组要求，甚至是一份完整的任务说明。Kimi 会根据你的提示词理解意图、组织回答并执行任务。

简而言之：**你怎么提问，决定 Kimi 怎么回答。** 清晰、具体的提示词，通常能带来更准确、更有价值的回答。
</Callout>

## 优质提示词的四个核心要素

### 1. 明确角色与背景

告诉 Kimi 你是谁、处在什么场景，有助于它匹配合适的回答深度和语气。

| 模糊的提示词 | 更好的提示词 |
|-------------|--------------|
| 写一篇关于 AI 的文章 | 我是一名科技媒体编辑。请为普通读者写一篇 2,000 字的 AI 科普文章，风格通俗易懂、有吸引力 |
| 帮我分析数据 | 我是一名市场分析师。请分析这个 Excel 文件中各渠道的转化率，重点关注环比变化 |

### 2. 具体描述任务

描述得越具体，后续需要修改的次数就越少。一个好的任务描述通常包括：

- **要做什么**：明确的动作（分析、总结、翻译、生成、比较……）
- **输出格式**：表格、列表、段落、代码、Markdown……
- **范围与限制**：字数、条目数量、时间范围、地域范围……
- **质量要求**：学术语气、口语化、简洁、详细……

### 3. 提供示例或参考

如果你对格式有明确要求，给 Kimi 一个示例（few-shot）会非常有效：

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "请按以下格式整理会议纪要：\n\n会议主题：xxx\n参会人员：xxx\n关键决策：\nxxx\nxxx行动事项：\n[ ] xxx（负责人：xxx，截止日期：xxx）",
    },
  ]}
/>

### 4. 将复杂任务拆分成步骤
对于复杂任务，可以把工作拆成更小的步骤，引导 Kimi 逐步完成：

<CodePreview
  files={[
    {
      name: "prompt.txt",
      language: "text",
      content: "我需要一份竞品分析报告。请按以下步骤完成：\n列出国内排名前 3 的竞争对手及其核心功能\n比较它们的定价策略\n分析各产品的优势与不足\n为我们的产品提出差异化建议",
    },
  ]}
/>

## 实用技巧
### 使用追问与迭代
对第一次回答不满意？直接追问即可，不必重新交代所有背景：
- "请展开说明第 2 点"
- "语气再正式一些"
- "补充数据来源"
- "换一个角度重新分析"
### 善用文件和链接
Kimi 支持上传 PDF、Word 文档、Excel 文件、图片等内容。你也可以直接粘贴 URL。将文件与提示词结合使用，可以大幅提升效率：
| 任务 | 提示词示例 |
|------|---------------|
| 总结 PDF | "总结这份 PDF 的要点" |
| 分析数据 | "请基于这份 Excel 数据分析销售趋势" |
| 从 URL 提取信息 | "阅读链接中的这篇文章，并提取关键结论" |

### 指定输出格式
明确告诉 Kimi 你想要的格式：
| 需求 | 提示词示例 |
|------|---------------|
| 对比表 | "用表格比较 A 和 B 的优缺点" |
| 代码输出 | "用 Python 实现，并添加注释" |
| 结构化列表 | "整理成编号列表，每项不超过 20 个字" |
| Markdown | "以 Markdown 格式输出，并包含标题层级" |

### 用记忆保存长期偏好
如果你有反复使用的偏好和要求，可以使用 Kimi 的 **记忆** 功能长期保存：
- "请记住，我是一名前端工程师，偏好使用 React 技术栈"
- "始终使用英语并以 Markdown 格式回复"
- "回答技术问题时，请包含代码示例"

<Callout type="tip">
这样你就不用反复说明同样的要求——Kimi 会在今后的对话中自动应用这些偏好。
</Callout>

## 常见错误
| 错误 | 更好的做法 |
|---------|----------------|
| 把多个互不相关的任务塞进同一条消息 | 每个独立任务都开启一个新会话，保持上下文清晰 |
| 提示词过于笼统（例如“帮我写点东西”） | 说明要写什么、写给谁看、采用什么风格、篇幅多长 |
| 期待第一次就得到完美结果 | 先生成初稿，再通过追问逐步迭代 |
| 不核查 AI 输出 | 务必核实日期、数据和事实性表述 |
