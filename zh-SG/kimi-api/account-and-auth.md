# 账户与认证

<Callout type="info">
关于 Kimi API 开发者账户、认证与身份验证的常见问题。
</Callout>

## 个人账户可以开具企业发票吗？
个人账户**不能直接开具企业发票**。如需企业发票，请先将账户升级为组织账户。认证通过后，你即可使用组织名称申请开票。

## 如何从个人账户升级为组织账户？
1. 登录 [platform.moonshot.ai](https://platform.moonshot.ai) 控制台。
2. 前往 **账户设置 → 认证**。
3. 选择 **组织认证**，并填写所需信息。
4. 提交审核——审核通过后，你的账户将自动完成转换。

<Callout type="tip">
升级后，现有余额和使用数据会保留。
</Callout>

## 个人认证与组织认证的区别
| 方面 | 个人 | 组织 |
| --- | --- | --- |
| 发票类型 | 个人发票 | 企业 / 增值税发票 |
| 速率限制 | 标准 | 可申请更高配额 |
| 商务合同 | — | 可签署合同 |
| 阶梯折扣 | — | 可按需申请 |
| 技术支持 | 标准 | 优先支持 |

## 如何申诉账户暂停？
如果你的 API 账户因违反政策被暂停：
1. 发送邮件至 **support@moonshot.ai**，邮件主题为“API 账户申诉”。
2. 请提供你的账户信息（注册邮箱地址）以及申诉说明。
3. 团队将在 1–3 个工作日内完成审核并回复。

<Callout type="info">
**支持邮箱**：support@moonshot.ai
</Callout>

## 如何变更注册邮箱？
如需变更注册邮箱，请联系支持团队：
1. 发送邮件至 **support@moonshot.ai**，邮件主题为“邮箱变更申请”。
2. 请提供当前邮箱地址和新邮箱地址。
3. 为保障账户安全，可能需要进行身份验证。

## 完成认证的好处
- **更高的速率限制**：已认证用户可获得更高的 API 调用速率。
- **完整功能访问权限**：部分高级功能可能仅向已认证用户开放。
- **发票支持**：已认证账户可以申请开具发票。
- **技术支持**：已认证用户可获得更高优先级的技术支持。
