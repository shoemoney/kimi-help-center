# API 调用常见问题

这里汇总了开发者在使用 Kimi API 时最常遇到的问题与处理方法。

## 收到 429 速率限制错误怎么办？

429 错误表示请求频率超过了当前账户适用的速率限制。可按以下方式处理：

- 采用指数退避重试策略（等待 1s、2s、4s… 后重试）。
- 控制并发请求数量，并使用队列机制。
- 通过提高累计充值金额来提升速率限制等级。
- 如需更高配额，请联系销售团队。

## 收到 401 认证失败错误怎么办？

401 错误表示 API Key 认证失败。请检查：

- API Key 是否已正确复制（注意首尾是否有空格）。
- 请求头格式是否为 `Authorization: Bearer <your-api-key>`。
- API Key 是否已被删除或禁用，可前往控制台确认。
- 是否误用了其他平台的 Key（Kimi API Key 以 `sk-` 开头）。

## 文件上传是否计费？

单独上传文件不会产生费用。但当你在对话中引用已上传的文件时，文件内容会被解析为 token，并计入输入 token 计费。文件越大，解析后产生的 token 通常越多。

## 收到 403 余额不足错误怎么办？

403 错误通常表示账户余额不足。请前往控制台充值，充值完成后即可继续使用。你也可以通过余额查询接口确认当前余额。

## 返回内容被截断怎么办？

如果 API 返回的内容不完整或被截断：

- 检查 `max_tokens` 参数是否设置过小，并根据需要适当调高。
- 查看响应中的 `finish_reason` 字段：`length` 表示因 token 限制而截断，`stop` 表示正常结束。
- 对于较长文本的生成需求，建议拆分为多段请求。

## 文件接口可以上传图片吗？

可以。文件上传接口支持上传图片文件，上传后可在对话中引用。若使用 Vision 模型，也可以直接在消息中通过 URL 或 Base64 传入图片。

## 联网搜索的来源是什么？

Kimi API 的联网搜索功能会实时检索互联网上的公开信息，搜索结果来自主流搜索引擎索引的网页内容。每次联网搜索将额外收取 ¥0.03。

## Allegretto 会员与 API 并发有关系吗？

Kimi 会员（如 Allegretto 等）与 API 采用独立的计费体系。会员套餐中的 Agent 并行能力仅适用于 Kimi 产品端，与 API 的速率限制无关。API 的并发限制取决于账户累计充值金额对应的等级。

## API 和网页版 Kimi 有什么区别？

- **网页版 Kimi**：面向普通用户的对话产品，可直接通过浏览器使用。
- **Kimi API**：面向开发者的接口服务，用于将 AI 能力集成到自有产品中。
- 两者采用独立的计费体系，账号可通用，但额度不互通。

## PPT 生成和深度研究有 API 吗？

目前 PPT 生成和深度研究功能**暂未开放 API 接口**。这些功能仅可在 Kimi 产品端使用。请关注平台公告，了解最新动态。

## 支持本地化部署吗？

Kimi API 目前仅提供云端 API 服务，**暂不支持本地化私有部署**。如有私有化部署需求，请通过 [platform.kimi.com/contact-sales](https://platform.kimi.com/contact-sales) 联系销售团队咨询。

## 国外可以调用 Kimi API 吗？

Kimi API 主要面向中国大陆用户提供服务。海外地区访问可能受网络环境影响，稳定性无法完全保障。如有海外使用需求，建议联系销售团队了解可行方案。
