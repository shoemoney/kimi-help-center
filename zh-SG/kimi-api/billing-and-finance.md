# 账单与财务

<Callout type="info">
关于 Kimi API 计费、价格与付款的常见问题。
</Callout>

## 价格结构是怎样的？
Kimi API 按实际消耗的 token 计费——输入 token 与输出 token 分别计价。不同模型的价格不同；使用网页搜索会额外按每次调用 $0.004 收费。

<Callout type="tip">
如需查看详细价格，请参阅 [platform.kimi.ai/docs/pricing/chat](https://platform.kimi.ai/docs/pricing/chat)。
</Callout>

## 支持哪些付款方式？
API 控制台支持以下付款方式：
| 方式 | 说明 |
| --- | --- |
| **信用卡/借记卡** | Visa、Mastercard 及其他主要银行卡 |
| **电汇** | 已完成组织认证的用户可申请电汇——请联系销售获取银行信息 |

充值资金到账后可立即用于 API 调用。
## 如何申请发票？
1. 登录 [platform.kimi.ai](https://platform.kimi.ai) 控制台。
2. 前往 **账单 → 发票管理**。
3. 选择需要开具发票的充值记录。
4. 填写发票信息（个人或企业）并提交。
5. 电子发票将发送至你的邮箱。
