# 商务合作与销售

<Callout type="info">
面向企业客户的合作方案——从用量折扣到定制 SLA。
</Callout>

Kimi API 为企业客户提供多种合作方案，满足不同规模的业务需求。
## 如何联系销售团队？
访问 [platform.moonshot.ai/contact-sales](https://platform.moonshot.ai/contact-sales) 提交联系表单。我们的销售团队将在 1–2 个工作日内与您联系。

<Callout type="tip">
**提交时请包含以下信息**：
- 公司名称和所属行业
- 预计使用量
- 主要使用场景
- 偏好的合作模式
</Callout>

## 合同签署
已完成组织认证的用户可以与 Moonshot 签署正式服务协议：
- 支持标准服务协议和定制合同。
- 签署后，您将可使用电汇付款，并获得企业级 SLA。
- 如需了解具体流程，请联系销售团队。

## 用量折扣
高用量企业客户可申请专属折扣：
| 要求 | 详情 |
| --- | --- |
| **申请资格** | 完成组织认证 + 签署合同 |
| **折扣等级** | 根据承诺使用量和合同期限确定 |
| **申请方式** | 通过销售团队申请，并提供预计月使用量 |

## 企业 API 服务
企业 API 服务在标准 API 服务基础上提供：
- **更高的速率限制和并发配额**
- **专属技术支持渠道**
- **定制 SLA 保障**
- **新功能优先体验**
