# Kimi API 概览

Kimi API 平台为开发者提供强大的大语言模型能力，帮助你将 AI 快速集成到自己的产品和服务中。

## 平台概览

Kimi API 由 Moonshot 自研大语言模型驱动，提供文本生成、多轮对话、文件解析、网页搜索等核心能力。平台兼容 OpenAI API 格式，开发者可以以极低成本完成迁移与集成。

**平台地址**： [platform.kimi.ai](https://platform.kimi.ai)

## 适用对象

- **独立开发者**：快速构建由 AI 驱动的个人项目和工具。
- **企业工程团队**：将 AI 能力嵌入企业产品，提升用户体验与运营效率。
- **初创公司**：以较低成本接入一流 AI 能力，加速产品迭代。

## 典型场景

- **智能客服**：基于上下文的自动问答，提升支持效率与客户满意度。
- **内容生成**：文章写作、营销文案、代码生成等创意工作流。
- **数据分析**：文档解读、报告分析、知识提取与摘要生成。
- **知识问答**：基于私有文档库的智能检索与问答系统。

## 快速开始

1. 访问 [platform.kimi.ai](https://platform.kimi.ai) 注册开发者账号。
2. 在控制台创建 API 密钥。
3. 参考 API 文档发起你的第一次调用。
4. 根据使用场景选择合适的模型和参数。
