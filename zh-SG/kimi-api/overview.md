# Kimi API 简介

Kimi API 开放平台让开发者轻松接入强大的大语言模型能力，帮助你快速将 AI 集成到自己的产品和服务中。

## 平台概览

Kimi API 基于 Moonshot 自研的大语言模型，提供文本生成、多轮对话、文件解析、联网搜索等核心能力。平台兼容 OpenAI API 格式，开发者可以以较低成本完成迁移与接入。

**平台地址**：[platform.kimi.ai](https://platform.kimi.ai/)

## 适用人群

- **独立开发者**：快速构建由 AI 驱动的个人项目或工具。
- **企业技术团队**：将 AI 能力嵌入企业产品，提升用户体验与业务效率。
- **创业公司**：以较低成本获取顶尖 AI 能力，加快产品迭代。

## 主要应用场景

- **智能客服**：基于上下文理解的自动问答，提升客服效率和用户满意度。
- **内容生成**：适用于文章撰写、营销文案、代码生成等创作场景。
- **数据分析**：用于文档解读、报表分析、知识提取与总结。
- **知识问答**：基于私有文档库构建智能检索和问答系统。

## 快速入门

1. 访问 [platform.kimi.ai](https://platform.kimi.ai/)注册开发者账号。
2. 在控制台创建 API Key。
3. 参考 API 文档完成首次调用。
4. 根据业务需求选择合适的模型和参数。
