# 核心概念与终端

## 关键概念

| 概念 | 说明 |
|---------|-------------|
| **记忆** | Kimi Claw 的长期记忆系统。可在多轮对话中保存你的偏好、习惯和重要信息。 |
| **技能** | 来自 ClawHub 库的可安装能力模块，为 Kimi Claw 提供特定领域的专业能力。 |
| **HEARTBEAT** | 按定时器运行的计划后台任务，适用于周期性提醒、数据拉取和摘要汇总等场景。 |
| **身份** | Kimi Claw 的角色定义，包括名称、职业和人设，可由你完全自定义。 |
| **灵魂** | 塑造 Kimi Claw 互动风格的核心人格特质与行为原则。 |
| **工具** | Kimi Claw 可调用的一组能力，包括网页搜索、文件处理、代码执行等。 |
| **用户** | 你与 Kimi Claw 之间的关系定义，用于决定互动模式和信息共享方式。 |

## 终端

<Frames
  src="./images/concepts/screenshot-30.png"
  alt="截图 30"
/>

你可以在网页版中通过 **设置 → 终端** 打开命令行界面，并运行命令来直接控制 Kimi Claw。

也可以直接用自然语言告诉 Kimi Claw 要运行什么命令，它会替你执行。

> 注意：终端和插件共用同一个连接通道。重启 OpenClaw gateway 会导致终端断开连接。

## 命令参考

### 系统

| 命令 | 说明 |
|---------|-------------|
| `/help` | 显示帮助信息 |
| `/status` | 查看当前系统状态 |
| `/ping` | 测试连接是否正常 |
| `/cron` | 管理计划任务 |
| `/config` | 查看或编辑配置 |
| `/new` | 开始新的对话（清除当前上下文） |
| `/reset` | 重置 Kimi Claw |
| `/compact` | 压缩当前对话上下文 |
| `/stop` | 停止当前正在运行的任务 |

### 技能

| 命令 | 说明 |
|---------|-------------|
| `/skills` | 浏览、安装和管理技能 |

### 计划任务

| 命令 | 说明 |
|---------|-------------|
| `/cron` | 查看并管理任务计划 |

### 记忆

| 命令 | 说明 |
|---------|-------------|
| `/memory` | 查看并管理长期记忆 |

### 配置与调试

| 命令 | 说明 |
|---------|-------------|
| `/config` | 查看或编辑系统配置 |
| `/logs` | 查看运行日志 |
| `/debug` | 启用调试模式，进行详细诊断 |
