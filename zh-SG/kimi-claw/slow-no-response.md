# 没有响应或速度很慢？

<Callout type="info">
如果 Kimi Claw 没有回复，或响应速度异常缓慢，可能有多种原因。请按照下面的排查路径操作。
</Callout>

## 常见原因

| 原因 | 说明 |
|-------|-------------|
| **桥接断开** | Kimi Claw 与服务器之间的连接已断开；需要重启 gateway |
| **资源繁忙** | 服务器负载较高；响应可能会延迟 |
| **实例离线** | Kimi Claw 实例已离线，需要修复 |

## 如何修复？

请按顺序尝试以下步骤，直到问题解决：

1. **再发送一条消息** — 有时只是短暂延迟；追加一条消息可能会触发回复
2. **刷新页面** — 关闭并重新打开 Kimi Claw 对话
3. **重启 gateway** — 前往**设置**，点击**重启 Kimi Claw**。等待它重新上线
4. **自动修复** — 在设置中，点击**修复 Kimi Claw**。系统会自动检测并修复配置问题
5. **恢复初始设置** — 如果以上方法都无效，请在设置中选择**恢复初始设置**

## 关于恢复初始设置

<Callout type="warning">
这会将 Kimi Claw 重置为出厂状态，但：

- **会保留：** 工作区文件和长期记忆
- **需要重新配置：** 聊天平台连接（Telegram 等）需要重新设置
</Callout>
