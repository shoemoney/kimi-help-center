# 常见故障排查

本页介绍 Kimi Claw 的常见错误代码和自助修复选项。

## 常见错误代码

| 代码 | 含义 | 处理方法 |
|------|---------|------------|
| **400** | 错误请求 — 输入格式错误或参数无效 | 检查消息中是否包含不支持的内容，然后重试。 |
| **401** | 未授权 — 认证失败 | 退出 Kimi 后重新登录。如果问题仍然存在，请在 Kimi Claw 设置中检查你的 API 凭据。 |
| **403** | 禁止访问 — 权限不足 | 确认你的会员等级支持正在使用的功能，并确保账号未受限制。 |
| **429** | 请求过多（Too Many Requests）— 已超出速率限制（rate limit） | 等待几分钟后重试。有关如何查看配额的详情，请参阅[对话限制](/kimi-claw/conversation-limits)。 |
| **500** | 服务器内部错误（Internal Server Error）— 服务器端出现问题 | 稍等片刻后重试。如果问题反复出现，请使用下方自助修复选项，或联系支持团队。 |

## 自助修复选项

Kimi Claw 在网页端的**设置**中提供了内置修复工具：

| 选项 | 作用 |
|--------|--------------|
| **重启 Kimi Claw** | 重启网关连接，可解决大多数临时性问题（如桥接断开、短暂卡住）。 |
| **修复 Kimi Claw** | 运行自动诊断，检测并修复配置问题。如果简单重启无效，请尝试此选项。 |
| **恢复初始设置** | 将 Kimi Claw 重置为默认状态。工作区文件和记忆会保留，但聊天平台连接（Telegram 等）需要重新配置。请仅在其他方法无效时使用。 |

## 升级处理路径

如果自助修复选项无法解决问题：

1. 在终端中运行 `/logs`，获取近期错误输出。
2. 运行 `/debug`，启用详细诊断。
3. 将错误详情及相关日志发送至 **support@moonshot.ai** 联系支持团队。
