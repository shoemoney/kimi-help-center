# 自定义与参考

Kimi Code CLI（命令行界面）提供丰富的自定义选项，让你可以按需调整 AI 的行为与工作流程。

## 配置文件

Kimi Code CLI（命令行界面）使用 `~/.kimi/config.toml` 作为全局配置文件，并支持 TOML 与 JSON 两种格式。你可以配置：

- **API 提供方与模型**：设置不同的模型提供方、API 端点和密钥。
- **默认模型**：指定默认使用的模型。
- **运行时参数**：调整超时、并发、输出格式等运行时设置。

> 使用 `/config` 命令可快速打开配置文件进行编辑。

## AGENTS.md 项目配置

在项目根目录放置 `AGENTS.md` 文件，可为 AI 提供项目级上下文：

- **项目背景**：说明项目的功能、架构和技术栈。
- **构建步骤**：如何安装依赖、构建项目并运行测试。
- **代码规范**：命名约定、目录结构规则、代码风格偏好。
- **特别说明**：安全限制、性能要求及其他重要注意事项。

使用 `/init` 命令可让 AI 自动扫描你的项目并生成初始 `AGENTS.md`。你也可以手动编辑该文件，补充项目专属信息。`AGENTS.md` 文件可以放在任意子目录中，AI 会自动加载相关配置。

## 自定义系统提示词

你可以通过以下几种方式自定义 AI 的系统提示词：

- **全局系统提示词**：写入 `~/.kimi/AGENTS.md`，适用于所有项目。
- **项目级系统提示词**：写入项目根目录下的 `AGENTS.md`，仅适用于当前项目。
- **启动参数**：启动时使用 `--system-prompt` 标志指定。

项目级配置会覆盖全局配置，启动参数的优先级最高。

## MCP 集成

Kimi Code CLI（命令行界面）支持模型上下文协议（MCP），可连接外部工具与数据源，扩展 AI 的能力：

- **MCP 服务器配置**：在配置文件中添加 MCP 服务器地址，让 AI 可以调用外部工具。
- **内置 MCP 支持**：部分常用 MCP 工具已内置，无需额外配置。
- **自定义 MCP 服务器**：你可以开发自己的 MCP 服务器，提供特定领域的能力。

MCP 配置可以放在 `~/.kimi/config.toml` 中，也可以放在项目级配置文件中。

## 环境变量

Kimi Code CLI（命令行界面）支持通过环境变量进行配置，适用于 CI/CD 流水线和脚本：

| 环境变量 | 说明 |
| --- | --- |
| `KIMI_API_KEY` | API 密钥 |
| `KIMI_BASE_URL` | 自定义 API 端点 |
| `KIMI_MODEL` | 默认模型名称 |
| `KIMI_MAX_TOKENS` | 最大输出 token 数 |

环境变量的优先级高于配置文件中的设置。
