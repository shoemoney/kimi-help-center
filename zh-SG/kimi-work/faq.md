# Kimi Work 常见问题

## Kimi Work 与网页端有什么不同？

Kimi 网页应用很适合快速对话和提问，而 Kimi Work 是一款面向深度工作流的本地 Agent。它可以读取并处理你的本地文件夹，通过 WebBridge 自主浏览网页，在后台运行 Python 代码，并执行计划任务。你可以把它看作一位系统级数字员工。

## Kimi Work 访问本地文件时，如何保护我的隐私？

你对自己的文件拥有完全控制权。Kimi Work 提供权限控制，你可以自行选择授权方式：

- **请求权限**：执行操作前先请求授权 —— 在修改、覆盖本地文件或在其中运行代码之前，Kimi 会提示你进行明确授权；
- **全部允许**：无需请求授权，直接运行。

当你选择“请求权限”时，未经你的同意，任何操作都不会发生。

## WebBridge（浏览器自动化）具体能帮我做什么？

WebBridge 让 Kimi 能像人一样使用浏览器。你可以让它查看某个网站上的最新新闻并总结，也可以让它抓取历史股票数据并保存到本地 Excel。它会自主点击、滚动和提取数据，帮你省下大量手动操作的时间。

## 计划任务可以做什么？电脑休眠时还会运行吗？

内置的 Cron 调度器支持大语言模型（LLM）Agent 调用、Python/Shell 执行等能力。你可以按天、按小时或按条件触发任务。若想确保任务在夜间也能顺畅运行，只需在设置中开启“保持电脑唤醒”选项。
