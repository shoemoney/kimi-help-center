# Kimi Work 概览

Kimi Work 是面向知识工作者的通用型本地 Agent，可在 Kimi 桌面客户端（Mac / Windows）的“工作”模式中使用。

它把 Kimi Code 在工程场景中验证过的 Agent 能力，带到了知识工作者熟悉的桌面交互中：无需打开终端、编写命令或配置环境。你只需用自然语言描述目标，Kimi Work 就会拆解任务、并行执行步骤、调用工具、使用浏览器、创建并整理文件夹，并在你的电脑上交付文档、电子表格、演示文稿等工作成果。

Kimi Code 服务于编写代码的开发者；Kimi Work 服务于知识工作者，主要覆盖信息流转、文件整理、数据分析、报告生成等日常工作场景。

## 核心能力

- **本地 Agent 内核**：以 Kimi Code 作为内核，提供本地 Agent 的基础能力，包括安装和使用技能、执行定时任务等。
- **专业技能**：继承线上 Kimi Agent 的专业技能，例如搭建网站、制作 PPT；同时支持推荐第三方技能和上传本地技能。
- **插件与专业数据库**：在 Kimi 中使用 Canva、Notion、WPS 等外部应用和服务，并连接金融、科研、法律等领域的专业数据库。
- **Kimi WebBridge**：内置浏览器操作方案，像真人一样使用浏览器。
- **Agent Swarm**：根据任务复杂度，自主组建最多 300 个子 Agent 的团队，处理更复杂、耗时更长的任务。
- **长周期任务执行**：由 Kimi K2.6 模型的长周期任务执行能力驱动，支持连续 13 小时编码、300 个子 Agent 并行工作，以及超过 4,000 次自主工具调用。

## 界面与交互

- 客户端提供“工作”和“聊天”两种模式。“工作”模式侧边栏包含：新建任务、技能、定时任务、WebBridge、项目和聊天。
- 在输入框中输入“/”可快速使用技能，输入“@”可添加上下文。
- 提供权限控制，你可以选择授权方式：
  - **请求权限**：执行操作前先请求授权
  - **全部允许**：无需请求授权，直接运行
- 可在“Agent”和“Agent Swarm”两种执行模式之间切换。

## 版本说明

Kimi Work 于 2026 年 6 月 3 日上线，目前仍处于 Beta 版，并在高频迭代中。它已陆续新增文件预览、草稿自动保存、目标模式、插件中心等功能。当前测试重点包括任务拆解、多 Agent 并行、工具调用、浏览器操作、本地文件处理和长篇交付物生成；执行稳定性、交付质量和用户体验将根据 beta 用户的反馈持续优化。
