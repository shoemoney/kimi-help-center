# 创建并提交插件

如果您希望将产品或服务接入 Kimi，让用户可以在对话中使用其功能，请按照本指南创建、测试并提交插件，以申请在 Kimi 官方插件市场上线。

## 什么是 Kimi 插件？

Kimi 插件将您的产品与 Kimi 连接起来。它帮助 Kimi 了解何时您的产品有用，并为 Kimi 提供帮助用户所需的工作流程或工具。插件可以包含：

- **仅技能**：为您的产品或使用场景定制的可重用工作流程。
- **仅 MCP**：通过 MCP 服务器向 Kimi 公开的工具和服务。
- **技能和 MCP**：结合产品工具和帮助 Kimi 有效使用它们的工作流程。

## 准备工作

首先，<a class="leading-7 text-(--Colors-KMBlue) decoration-(--hc-pill-border) decoration-2 transition-colors hover:text-(--Colors-KMBlue-hover)" href="https://www.kimi.com/products/kimi-work">下载并安装 Kimi Work</a>。准备好以下内容：

- 插件名称、描述和图标
- 用户应能通过自然语言完成的核心任务
- MCP 服务器 URL（如适用）

<Callout type="warning">
如果插件图标包含第三方产品、品牌或商标，请在提交前联系相关权利持有人并获得必要的书面授权。
</Callout>

## 步骤 1：创建并测试插件

1. 打开 Kimi Work，在对话中输入 "/"，然后选择 **插件构建器**。
2. 描述插件并提供您准备的信息。如果您已有 Codex、Claude 或其他平台的插件，请提供其文件或项目 URL，并按照说明进行转换。

3. 转到 **插件** → **个人**，找到插件并安装。

4. 在新对话中测试核心功能，包括正常和边缘情况。保留至少三个有代表性的测试提示。
5. 按照插件构建器的说明获取完整的插件 ZIP 文件。

对于 MCP 支持的插件，还需测试其认证流程：

- **无认证**：用户安装后即可立即使用插件。
- **OAuth**：首次安装时应打开第三方授权页面。
- **CLI 认证**：安装不会启动授权。用户首次调用插件时，在对话中完成授权。授权成功后，通常不需要在其他对话中再次授权。

## 步骤 2：提交申请

创建并测试插件后，填写 [Kimi 插件提交表单](https://moonshot.feishu.cn/share/base/form/shrcnZcnxlNJlbw845KoVgjEhkh) 并上传插件 ZIP 文件。

表单要求提供：

| 项目 | 要求 |
| --- | --- |
| 插件名称、描述和 ZIP 文件 | 必填 |
| 插件类型 | 仅技能、仅 MCP 或混合 |
| MCP 认证 | 仅 MCP 和混合插件必填 |
| 目标地区 | 中国大陆、海外或两者 |
| 亮点和推荐测试提示 | 至少三个测试提示 |
| 联合营销意向和材料 | 材料可选，仅在希望讨论联合营销时需要 |
| 授权和合规状态 | 披露需要进一步讨论的项目 |
| 联系邮箱 | 用于审核更新和附加信息请求 |
| 公司或团队、相关网站和备注 | 可选 |

<Callout type="warning">
不要在表单或插件 ZIP 中包含密码、token、API 密钥、私钥或其他机密信息。如果用户需要自己的密钥，仅解释他们如何获取和配置。
</Callout>

## 后续流程

Kimi 团队将审核申请和插件 ZIP。如果插件通过审核，或我们需要更多信息或修改，我们将通过提供的邮箱联系您并分享后续步骤。

## 常见问题

### 我可以提交没有 MCP 服务器的插件吗？

可以。支持仅技能插件。选择 **仅技能** 作为插件类型。

### 我可以提交 Codex、Claude 或其他平台的插件吗？

可以。在步骤 1 中，向插件构建器提供现有插件文件或项目 URL，并按照说明进行转换。在 Kimi Work 中安装并测试转换后的插件，然后提交生成的 ZIP 文件。

### 支持哪些 MCP 认证方法？

目前支持以下三种方法：

- **无认证**：用户安装后无需登录或完成任何其他身份验证即可立即使用插件。
- **OAuth**：用户首次安装插件时会自动重定向到第三方产品的授权页面。授权后即可使用插件。
- **CLI 认证**：安装不会启动授权流程。用户首次在对话中调用插件时，使用对话中显示的说明完成授权。授权成功后，通常不需要在其他对话中再次授权。

测试与插件实际认证方法匹配的流程。如果 OAuth 插件在首次安装时未重定向，或 CLI 认证插件反复要求用户授权，请在提交申请前检查 MCP 服务器的认证配置，并在 **附加备注** 中描述问题。

### OAuth 授权流程是什么样的？

对于启用 OAuth 的 MCP 服务器，插件构建器从 MCP 服务器 URL 中识别相关授权信息。创建插件后，用户首次安装时会被带到第三方产品的授权页面。

### 如果我希望与 Kimi 探索更广泛的合作怎么办？

首先完成本指南中的插件创建、测试和提交流程。如果您希望在插件上线之外探索其他形式的合作，请在 **附加备注** 中简要描述您的提案。Kimi 团队可能会根据情况与您联系。

### 提交申请是否保证上线？

否。Kimi 团队会评估插件的功能、用户体验、安全性、服务可靠性和相关授权状态。
