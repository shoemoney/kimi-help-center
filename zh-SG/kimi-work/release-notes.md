# 发布日志

本文记录 Kimi Work 的版本更新内容，包括新增功能、变更与修复，并持续更新。最新版本下载：[kimi.com/products/kimi-work](https://www.kimi.com/products/kimi-work)

## 3.1.7（2026-08-05）

**新增**

- 支持消息级用户反馈：可对助手回复中的具体消息点赞或点踩

**变更**

- 固定至桌面的看板组件取消强制置顶

**修复**

- 修复了一些 Bug，优化了一些交互

## 3.1.6（2026-07-29）

**新增**

- PPT 幻灯片编辑器上线：直接在工作台内打开编辑，改完即所得
- 支持预览区文件与浏览器的截图批注，完成后可直接发给 Agent 修改
- 支持 Windows 端存储盘迁移：Work 数据可迁移到其他磁盘
- Windows 端安装支持自选安装位置

**变更**

- 优化了部分 token efficiency 问题

**修复**

- 修复了一些 Bug，优化了一些交互
