# 取消订阅

你可以随时取消自动续订。取消后，会员权益仍会保留至当前计费周期结束。

## 如何取消自动续订？

请根据你最初订阅的渠道选择对应方式：

### 通过 Kimi 网站或应用

1. 登录 Kimi（网页版或移动端）。
2. 前往 **设置 → 订阅**。
3. 点击 **取消自动续订** 或 **管理订阅**。
4. 确认取消。

### 通过 Apple ID（iOS / Mac）

1. 在 iPhone 上打开 **设置**，然后轻点顶部的你的姓名。
2. 轻点 **订阅**。
3. 找到 **Kimi**，然后轻点 **取消订阅**。

在 Mac 上：打开 App Store → 点击你的个人资料 → **账户设置** → 在 **订阅** 下找到 Kimi → **管理** → **取消订阅**。

### 通过 Google Play（Android）

1. 打开 **Google Play Store** 应用。
2. 轻点你的个人资料图标 → **付款和订阅** → **订阅**。
3. 找到 **Kimi**，然后轻点 **取消订阅**。
4. 按照屏幕提示确认。

> 取消后，你的权益会持续有效至已付费周期结束。你可以随时在 Kimi 订阅页面重新订阅。
