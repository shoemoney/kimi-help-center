# 联系我们

需要帮助？你可以通过以下方式联系我们。

## 账单与会员支持

**Email:** membership@moonshot.ai

适用于：

- 购买后额度未到账
- 付款或扣费问题
- 套餐升级、降级或取消
- 发票申请

付费会员将获得优先响应。请在邮件中提供你的账号邮箱及相关截图，方便我们更快定位并解决问题。

## 常规支持

**Email:** support@moonshot.ai

适用于：

- 产品功能咨询
- 使用 Kimi 时遇到的技术问题
- 账号相关问题（非账单类）
- 功能建议与反馈

## API 服务支持

**Email:** api-service@moonshot.ai.
你也可以前往 [Kimi OpenPlatform Community](https://forum.moonshot.ai/)

适用于：

- API 相关问题
- 使用 Kimi API 时遇到的技术问题
- 功能建议与反馈

## 产品内反馈

你也可以直接在 Kimi 内提交反馈：

- **Web:** 点击左下角的 **反馈** 按钮，描述你遇到的问题并提交。
- **Mobile:** 前往 **个人资料 → 帮助与反馈 → 提交反馈**。

通过产品内提交的问题报告会自动附带你的设备和账号上下文信息，有助于我们更快诊断问题。
