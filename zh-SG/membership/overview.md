# 会员套餐概览

Kimi 提供五档会员套餐（含免费套餐），可满足从日常提效到高阶工作流的不同需求。所有套餐都包含 **两个额度池**：Kimi Code 使用独立配额池；其他会员功能共用一个配额池。

## 计费方式

- **两个额度池** — Kimi Code 使用独立配额池；其他会员功能共用一个配额池，并按 token 用量计量。
- **按月刷新** — 每个计费周期开始时，额度会重置。
- **扣减顺序** — 优先消耗奖励额度，然后消耗套餐额度。
