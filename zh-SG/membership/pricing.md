# 价格详情

Kimi 提供四档会员方案，均支持按月或按年订阅。选择年付，最高可省 **$480/年**。

## 方案速览

| 功能 | Moderato ($19/月) | Allegretto ($39/月) | Allegro ($99/月) | Vivace ($199/月) |
|---------|-------------------|---------------------|-------------------|-------------------|
| Agent 额度* | 60 | 150 | 360 | 720 |
| Agent 并发任务 | 2 | 2 | 4 | 4 |
| Agent 速度优先级 | 4× | 4× | 4× | 4× |
| Agent Swarm (beta) | 25 次使用 | 50 次使用 | 120 次使用 | 240 次使用 |
| Agent Swarm 并发子任务 | 2 | 4 | 4 | 8 |
| Kimi Code 额度 | 1× | 5× | 15× | 30× |
| Kimi Claw | — | ✅ | ✅ | ✅ |
| Kimi Claw Android | — | ✅ | ✅ | ✅ |
| 专业数据库 | 2,000 次调用 | 5,000 次调用 | 12,000 次调用 | 24,000 次调用 |

\* 估算值基于典型任务的 token 消耗。月度额度会折算为同一功能下的等效任务次数，仅供参考。

## 月付与年付价格

| 方案 | 月付 | 年付（折合每月） | 年付总额 | 可省 |
| --- | --- | --- | --- | --- |
| Moderato | $19/月 | $15/月 | $180/年 | $48/年 |
| Allegretto | $39/月 | $31/月 | $372/年 | $96/年 |
| Allegro | $99/月 | $79/月 | $948/年 | $240/年 |
| Vivace | $199/月 | $159/月 | $1,908/年 | $480/年 |

## 额度分配

所有 Kimi 会员功能共用同一个额度池，并按 token 用量计费。Kimi Code 另有独立的 5 小时 / 每周速率限制，仅适用于 Kimi Code，不影响其他功能。在聊天中，K2.6 免费且不消耗额度。更高档位会提供按比例增加的额度池，以支持更高频、更复杂的工作流。详情请参阅[额度更新与使用规则](/membership/update-rules)。
