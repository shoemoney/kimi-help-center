# 额度更新与使用规则

<Callout type="info">
Agent 系列功能与其他 Kimi 会员功能共享一个额度池；Kimi Code 单独享有独立额度池，并会根据实际使用量消耗额度。
</Callout>

## 什么是共享额度池？
你的会员权益不会为每个功能单独分配额度，而是提供一个可在各处使用的共享额度池。Agent 系列及其他 Kimi 功能都从中扣减：
| 功能 | 说明 |
|---------|-------------|
| **Agent 任务** | 网页、文档、幻灯片、电子表格、深度研究 |
| **Kimi Claw** | 你的个人云端部署 AI 助手 |
| **其他功能** | 图像生成等 |

> **K2.6**：与 K2.6 模型对话不消耗额度
> **Kimi Code**：AI 驱动的编程助手（独立额度池）

<Callout type="tip">
这意味着你可以在共享额度池中按需分配额度——这个月多用于研究，下个月多用于文档。K2.6 不消耗额度。
</Callout>

## 额度如何计算？
额度会根据任务处理的 token 数量消耗。输入和输出越长，使用的 token 越多。

<Callout type="info">
**免费档用户大致参考**：
- 生成一份简单幻灯片 ≈ 消耗 1–2%额度
- 运行一份深度研究报告 ≈ 消耗 5–10%
- 编写一段代码片段 ≈ 消耗 0.5–2%
更高级别套餐会相应提供更大的额度池。
</Callout>

## 额度刷新规则
| 规则 | 说明 |
|------|-------------|
| **周期** | 月度和年度订阅用户都会按**每月**周期获得额度 |
| **过期** | 未使用的额度会在每个周期结束时失效——不会结转，也不能兑换现金 |
| **限制** | 单个任务可能受到 5 小时和 7 天并发限制，具体以界面显示为准 |

## 额度用完后
- 已在进行中的任务会正常完成
- 新任务会显示“额度不足”提示

**你可以选择**：

- 等待下一个账单周期刷新额度
- 升级到更高级别套餐，获得更大的月度额度
## 额度具体如何刷新？
1. **按周期刷新**——额度会在你的订阅周年日刷新，而不是按自然月刷新
2. **不结转**——剩余额度会清零，然后重新发放完整额度
3. **示例**——如果你在 12 月 1 日下午 3:00 订阅，额度将在 1 月 1 日下午 3:00 刷新

<Callout type="info">
**系统错误**：如果任务因系统问题失败，请使用 👎 按钮反馈并申请退还额度。
</Callout>
