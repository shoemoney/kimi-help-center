# 额度更新与使用规则

<Callout type="info">
所有 Kimi 会员功能（Agent、深度研究、幻灯片、文档、表格、Kimi Code、Kimi Work、Kimi Claw 等）共用同一个额度池。额度会根据实际使用量扣除。
</Callout>

## 共享额度池如何运作？
Kimi 会员功能共用一个全局额度池。Agent 功能和其他 Kimi 功能都会从中扣除额度：
| 功能 | 说明 |
|---------|-------------|
| **Agent 任务** | 网页、文档、幻灯片、电子表格、深度研究 |
| **Kimi Code** | 面向开发者的 AI 编程助手 |
| **Kimi Work** | Kimi 桌面应用 |
| **Kimi Claw** | 你的个人云端部署 AI 助手 |
| **其他功能** | 图像生成等 |

> **K2.6**：在 Chat 中，K2.6 同样会消耗会员额度，计费方式与在 Kimi Work 中作为 K2.6 Agent 使用时相同。
> **Kimi Code**：使用同一个共享额度池，但有专属于 Kimi Code 的 5 小时 / 每周速率限制。

<Callout type="tip">
这意味着你可以在共享额度池中自由分配额度——这个月多用于研究，下个月多用于文档。
</Callout>

## 额度如何计算？
额度会根据任务处理的 token 数量扣除。输入和输出内容越长，使用的 token 越多。

<Callout type="info">
**免费层级用户的大致参考**：
- 生成一份简单的幻灯片 ≈ 1–2% 额度
- 运行一份深度研究报告 ≈ 5–10%
- 编写一段代码片段 ≈ 0.5–2%
更高层级的方案会配备相应更大的额度池。
</Callout>

## 额度刷新规则
| 规则 | 说明 |
|------|-------------|
| **周期** | 月度和年度订阅用户都会按**月度**周期获得额度 |
| **到期** | 未使用的额度会在每个周期结束时失效——不会结转，也不能兑换现金 |
| **限制** | 单个任务可能受 5 小时和 7 天并发限制约束，具体以界面显示为准 |

## 额度用完时
- 已在进行中的任务会正常完成
- 新任务会显示“额度不足”提示

**你可以选择**：

- 等待下一个账单周期刷新额度
- 升级到更高层级的方案，获得更高的月度额度
## 额度究竟如何刷新？
1. **按周期刷新** — 额度会在你的订阅周年日刷新，而不是按自然月刷新
2. **不结转** — 剩余额度会清零，然后重新发放完整额度
3. **示例** — 如果你在 12 月 1 日下午 3:00 订阅，额度会在 1 月 1 日下午 3:00 刷新

<Callout type="info">
**系统错误**：如果任务因系统问题失败，请使用 👎 按钮报告问题并申请退还额度。
</Callout>
