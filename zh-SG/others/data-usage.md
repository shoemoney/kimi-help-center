# 对话数据会用于模型训练吗？

在经安全加密技术处理、严格去标识化且无法重新识别特定个人的前提下，平台可能会将用户的输入数据、指令及生成回复用于模型训练，以优化模型效果和产品体验。

如果你不希望对话数据用于训练，可以通过 [support@moonshot.ai](mailto:support@moonshot.ai) 联系客服并提出要求；我们将在验证您的身份后，停止将您的内容用于模型训练。
