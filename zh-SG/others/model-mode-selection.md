# 如何选择：K2.6 / K3 / K3 Cluster、思考强度与 Agent

Kimi 会根据你的问题自行判断是否需要联网，你无需手动切换。你需要选择的是**模型**和**思考强度**；遇到复杂任务时，也可以使用 **Agent** 和 **Agent 集群**。

## 三种模型选项

在输入框上方的模型切换器中选择：

| 模型 | 思考强度 | 适合场景 | 额度 |
|---|---|---|---|
| **K2.6** | 标准 / 高级 | 快速对话与问答，响应更快 | **在对话中不消耗会员额度** |
| **K3** | 标准 / 高级 / 极致 | 对话与 Agent 任务，综合能力最强 | 按额度计费 |
| **K3 Cluster** | 标准 / 高级 / 极致 | 大规模搜索、批量处理，以及一次性完成高工作量任务 | 按额度计费 |

- **K3** 可端到端生成可编辑文档，例如 `.pptx`、`.docx`、`.xlsx` 和 `.pdf`；**K2.6** 针对快速问答进行了优化，仅输出文本，例如 PPT 大纲、Word 正文、代码等。
- 如需**生成图片 / 视频 / 音频**，点击“+”→ 插件，然后选择对应功能并搭配 **K3** 使用。

<Callout type="info">
K2.6 免费且不消耗额度仅适用于对话（输入框上方的模型切换器）。如果在 Kimi Work 中作为 K2.6 Agent 使用，仍会消耗会员额度。
</Callout>

## 思考强度：标准 / 高级 / 极致

思考强度越高，模型推理越充分，通常结果也越智能；但同时也会**消耗更多 token**。

- 如果你希望**更快响应、减少额度消耗** → 选择**标准**；
- 如果复杂分析或难题需要**更强推理能力** → 选择**高级**或**极致**（极致由 K3 / K3 Cluster 支持）。

## Agent 与 Agent 集群

- **通用 Agent**：自动规划并完成任务，包括网站生成、PPT 制作、Deep Research（深度研究），以及文档和电子表格处理。
- **Agent 集群**：支持超过 4,000 次并行工具调用，并可自主协调最多 300 个子 Agent（Sub-agents）并行工作。非常适合**大规模搜索、长文写作、批量处理**等大型任务。

## 按场景选择

- **快速问答与日常对话** → K2.6（在对话中不消耗额度）。
- **复杂对话、文档写作 / PPT 与电子表格生成 / 多步骤任务** → K3。
- **大规模搜索、批量处理、超长篇写作** → K3 Cluster。
- **想节省额度** → 使用 K2.6，或将思考强度设为“标准”。

## FAQ

### “Thinking Mode” 不再可用了吗？
Kimi 已将“对话”和“Agent”整合为同一种体验，因此它们不再是彼此独立的模式。现在，“思考”通过**选择模型和思考强度**来控制——例如，使用 K3 并调高思考强度，就能获得更充分的推理。

### K2.6 和 K3 有什么区别？
K2.6 针对快速问答优化，响应更快，并且在对话中不消耗会员额度。K3 综合能力最强，擅长复杂对话和 Agent 任务，可端到端生成可编辑文档，并按额度计费。

### K3 和 K3 Cluster 有什么区别？
K3 适合常规对话和 Agent 任务。K3 Cluster 采用大规模并行能力——数千次工具调用与数百个子 Agent——来处理**大规模搜索、批量处理、超长篇写作**等高工作量任务。

### 单轮最多可以处理多少内容？
K2.6 支持约 128K tokens 的单轮上下文（约 5 万–6 万个中文字符）；K3 提供 100 万 token 上下文窗口（需要最高档会员权益）。详情请参阅[如果一段对话超过 20 万中文字符该怎么办？](/others/chat-issues)。
