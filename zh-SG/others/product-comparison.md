# Kimi、Kimi Work、Kimi Code 和 Kimi Claw 有什么区别？我该用哪一个？

Kimi 既有开箱即用的在线助手，也提供面向不同用户和场景的多款产品。它们共享 Kimi 的核心能力，主要区别在于：**在哪里使用、适合谁使用，以及最擅长做什么**。

## 快速概览

| 产品 | 是什么 | 适合人群 / 场景 | 使用入口 |
|---|---|---|---|
| **Kimi**（网页版 / App） | 融合聊天与智能体（Agent）能力的在线 AI 助手 | 日常问答、写作、搜索、搭建网站 / 制作 PPT / 处理文档和表格、Deep Research（深度研究）等 | 网页端、移动 App |
| **Kimi Work** | 面向知识工作者的**本地智能体（Agent）**（桌面端） | 处理电脑中的本地文件、跨桌面应用自动化执行任务、交付长时间运行的任务 | Mac / Windows 客户端 |
| **Kimi Code** | 面向**开发者**的编程助手套件 | 编写代码、维护代码库 | CLI、VS Code 扩展 |
| **Kimi Claw** | **零部署云端自动化**平台 | 7×24 小时持续运行的云端自动化、可接入 Feishu / WeChat 等平台的机器人 | 云端（无需服务器） |

## 我该用哪一个？

- **日常聊天、写作、搜索，或让 Kimi 搭建网站、生成 PPT 和表格、执行 Deep Research（深度研究）** → 使用 **Kimi**（网页版 / App）。
- **如果你需要 Kimi 读写电脑上的本地文件、跨多个桌面应用自动化操作，或运行耗时较长的任务** → 使用 **Kimi Work**（桌面端）。
- **如果你是开发者，主要需要协助编写代码或维护项目** → 使用 **Kimi Code**。
- **如果你想要一个持续在线、自动运行，并且能连接 Feishu / WeChat 等平台的云端机器人** → 使用 **Kimi Claw**。

<Callout type="tip">
Kimi 的在线体验已经将“聊天”和“智能体（Agent）”融合在一起，你无需在两者之间切换。在 Kimi Work 桌面应用中，有两种模式：“Work”（以交付成果为导向的 Agent 模式）和“Chat”（快速对话）。
</Callout>

## 我该选择哪种会员？

会员权益与你的 Kimi 账号绑定。所有会员功能（聊天、Agent、Deep Research（深度研究）、Kimi Code 等）**共用同一个额度池**；Kimi Code 另有仅适用于 Kimi Code 的 5 小时 / 每周速率限制。套餐详情和价格请参见[会员订阅页面](/membership/membership-pricing)。

如果你的使用场景主要是**日常工作 + 偶发任务**，选择合适的 Kimi 会员套餐即可覆盖网页端 / App / Kimi Work 的大多数场景。对于**经常写代码**的开发者，也建议重点关注 Kimi Code 的相关权益。
