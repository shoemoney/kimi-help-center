# Kimi 网页

<Callout type="info">
**Kimi 网页** 是由最新 Kimi K3 多模态视觉 Agent AI 模型驱动的 Kimi Agent 产品功能。它的核心能力是 **Vibe Coding（氛围编程）**——通过自然语言生成网站，并将其部署上线。
</Callout>

Kimi 能理解视觉输入（UI 设计稿、截图、交互视频）和自然语言指令，将用户输入转化为完整、可运行的前端代码——不仅覆盖静态 UI，也能实现动态交互行为。

## 功能概览

| 功能 | 说明 |
|---------|------------|
| **对话式建站** | 用自然语言描述需求，AI 自动生成网站 |
| **图像/视频理解** | 上传设计稿、截图或屏幕录制，AI 解析并生成 HTML 页面 |
| **自动部署** | 一键部署，立即发布上线 |
| **多轮编辑** | 通过版本对比迭代修改网站 |
| **一键分享** | 生成可访问链接，轻松分享 |
| **模板选择** | 提供多种预设模板，快速开始建站 |
| **代码导出** | 下载打包好的 HTML/CSS/JS 文件，用于自托管 |

## 如何使用 Kimi 网页？

### 方法一：访问 Kimi 网页页面

<Frames
  src="./images/overview/kimi-websites-homepage.png"
  alt="Kimi 网页首页"
/>

1. **打开浏览器**：使用 Chrome、Safari、Edge、Firefox 或其他主流浏览器
2. **访问**：[kimi.com/websites](https://www.kimi.com/zh/websites)（支持中文和英文）
3. **登录**：使用你的 Kimi 账号登录（手机号或邮箱）
4. **输入任务**：

| 方式 | 说明 |
|----------|-------------|
| **文本输入** | 用自然语言输入你的需求 |
| **图像/网站复刻** | 上传设计稿或截图 |
| **基于模板** | 选择预设模板并修改内容 |

5. **开始构建**：选择模板，或直接从对话开始

<Frames
  src="./images/overview/screenshot-27.png"
  alt="截图 27"

### 方法二：移动端 App

iOS、Android 和 HarmonyOS 均提供官方 Kimi App。在输入区域，点击 **任务栏** → 切换到 **网页模式**，即可使用多模态生成工具和 Agent 能力。

### 方法三：使用通用 Agent 模式

选择 K3 模型并输入建站任务。Kimi 会调用其视觉编码能力和代码执行工具。

## Kimi 网页如何工作？

### 第 1 步：通过对话创建网站

用自然语言描述你的需求。支持以下三种创建方式：

| 方法 | 说明 |
|--------|------------|
| **文本描述** | 直接输入网站需求，AI 自动生成 |
| **设计稿解析** | 上传设计文件，AI 识别并复刻为网页 |
| **快速模板建站** | 选择预设模板并修改内容 |

### 第 2 步：构建过程

<Frames
  src="./images/overview/screenshot-26.png"
  alt="截图 26"
/>

Kimi 网页会启用 **webapp-building SKILL**——一个专门用于多轮代码生成的 Agent：
1. **需求分析**：分析网站模块、视觉风格和交互逻辑
2. **任务规划**：拆解为设计、开发和素材准备等子任务
3. **技术栈选择**：选择合适的架构（例如 React + Tailwind CSS）
4. **素材生成**：生成图片、图标及其他视觉素材
5. **代码构建**：编写页面结构、样式和交互代码
6. **多轮优化**：根据预览结果自我调整，直到完成

### 第 3 步：预览与调整
- **实时预览**：生成 HTML 演示 URL，可立即在浏览器中查看
- **对话式编辑**：继续对话并提出修改需求，例如 *"把导航栏改成深色"*

<Callout type="tip">
**示例**：*"配色不太理想——我想去掉黑白配色要求，做成一个更常规的网站。"*
Kimi 会重新整理待办事项，并继续构建。
</Callout>

### 第 4 步：在线可视化编辑
- **多轮优化**：通过持续对话精细调整细节
- **编辑模式**：
  - **批注模式**：点击页面区域，添加自然语言批注
  - **选择模式**：选择任意元素并添加批注
  - 使用矩形、箭头、画笔和颜色切换来标注修改建议
- 一次性将所有修改建议发送给 Kimi
### 第 5 步：部署与发布
| 部署方式 | 说明 |
|-------------------|------------|
| **自动部署** | 一键部署并生成在线链接 |
| **下载并自托管** | 下载打包好的代码文件，部署到你自己的服务器 |
| **自定义域名** | 将生成的网站绑定到你自己的域名 |

生成完成后，你可以：
- 点击不同部署版本，下载对应版本文件
- 点击分享按钮，获取公开部署链接（也可设为私密）
- 点击编辑按钮，继续修改
- 下载完整的 HTML/CSS/JS 代码，用于直接部署或进一步完善

## 适用人群
| 人群 | 使用场景 |
|----------|----------|
| **开发者** | 设计产品原型和前端演示，大幅减少从零构建的时间 |
| **创业者** | 在资源有限的情况下，快速搭建落地页、产品展示页和公司官网 |
| **产品经理** | 将 PRD 或设计稿快速转化为可演示的交互原型 |
| **非技术用户** | 无需编写代码——描述你的想法或上传参考图，即可从概念生成可运行网页 |

## 参考场景
| 场景 | 示例提示词 |
|----------|---------------|
| **从零创建落地页** | 搭建一个具有科技感的 SaaS 营销落地页——包含首屏主视觉、功能概览、定价和 CTA |

| **个人作品集** | 搭建一个摄影师作品集网站——极简黑白风格，采用图片瀑布流布局 |
| **数据可视化页面** | 创建一个可视化页面，用图表和筛选器展示 2025 年 AI 公司融资数据 |
| **品牌官网** | 搭建一个咖啡品牌网站，采用柔和的大地色系——包含首页、产品页和门店查询页 |
| **工具/计算器** | 搭建一个 BMI 计算器网页——界面简洁，支持单位切换，并显示健康等级指标 |
