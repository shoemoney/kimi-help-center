# Kimi 网页全栈能力

## 全栈网站构建升级

一个完整的网站通常由三部分组成：**前端界面、后端服务和数据存储**。Kimi 网页已升级全栈网站构建能力，支持从前端页面到后端数据库的端到端网站生成与部署。

| 能力         | 说明                                                           |
|--------------|----------------------------------------------------------------|
| 前端生成     | HTML/CSS/JavaScript 页面结构、样式与交互逻辑                    |
| 后端数据库   | 自动构建后端数据库，支持持久化数据读写与可视化管理               |
| 用户登录     | 支持 Kimi 账号登录，也可通过数据库构建账号密码登录系统           |
| 版本管理     | AI 自动提交版本，并支持回滚到任意历史版本                      |
| 全栈预览     | 支持完整的前后端预览；部分场景需要手动启动沙盒环境                   |
| 发布与部署   | 手动点击 "发布" 即可部署到公网。发布前，网站仅可预览。支持全栈内容部署  |

## 智能体交付内容

- 完整的任务执行文件，包括前端与后端代码
- 可在线预览并发布的全栈网站
- 位于 `/mnt/agents/output/app/` 目录下的可下载 Zip 压缩包

## 当前限制

以下场景暂不支持，将在后续版本逐步开放：

- 第三方支付集成，例如 Stripe 和 PayPal
- 第三方 OAuth 登录，例如 Google 和 GitHub。目前仅支持 Kimi 账号登录，或基于数据库的用户名/密码登录
- 复杂的服务端 API 集成，例如连接外部 SaaS 服务
