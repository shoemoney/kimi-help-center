# Agent 功能與限制

<SeoMeta
  title="Agent 功能與限制 - Kimi 說明中心"
  description="了解 Kimi Agent 的能力、使用技巧、限制與最佳實務，讓你獲得更理想的結果。"
/>

<Callout type="info">
**Kimi Agent** 是一款由 AI 驅動的助理，能透過多步推理與工具整合，自主執行複雜任務。本指南整理了最佳實務、限制與常見問題，協助你充分發揮 Agent 模式的效益。
</Callout>

## 使用技巧

**(1) 提交任務前**

請清楚說明背景資訊與限制條件，例如專案脈絡、使用情境與特殊需求，幫助 Kimi 更準確理解你的意圖。

**(2) 執行期間**

Kimi Agent 會在背景非同步執行。如果網頁看起來像是凍結或停住，**請不要點擊「停止」**，否則會中斷任務執行。你可以離開頁面；任務會繼續在背景執行，完成後你會收到通知。若任務預期耗時較長（例如 K2.6 Agent Swarm [Beta]），請耐心等候。

**(3) 網站類情境**

Agent 可以生成全端內容，包括前端介面、後端服務，以及持久化儲存邏輯。如果專案未能如預期執行，通常與沙盒啟動、資料庫初始化、驗證設定，或缺少發布動作有關。標準 Agent 在雲端執行，無法直接存取本機檔案或企業內網系統。若需要存取本機檔案或內網，請使用 Kimi Claw。

<Callout type="tip">
**需要存取本機檔案嗎？** 使用 Kimi Claw，即可安全存取本機檔案與企業內網系統。詳情請參閱 [Kimi Claw 文件](/kimi-claw/overview)。
</Callout>

**(4) 多輪對話與任務調整**
經過多輪對話與修改後，Agent 可能會「忘記」一些較早提出的細節。建議先確立任務框架與關鍵要點，再逐步做增量調整。

**(5) 大型任務拆解**
對於龐大且複雜的任務，建議拆成 2–3 個階段分批提交給 Kimi，或使用 K2.6 Agent Swarm [Beta]。

**(6) 檔案輸出限制**
在標準 Agent 模式中，每個任務通常只能輸出一個檔案（例如文件或試算表）。若需要多個檔案（例如同時輸出 Word 文件與 PPT），請使用 K2.6 Agent Swarm [Beta]。

**(7) 上下文限制與輸出平衡**
由於大型語言模型的上下文上限為 256K 字元（約 40,000–50,000 個中文字 / 約 100,000 個英文單字），處理大量檔案時，需要在輸入量與輸出量之間取得平衡。

<Callout type="warning">
**上下文限制提醒**：Agent 使用 256K 字元的上下文視窗。為獲得最佳結果，請提供精簡的上下文，避免載入不必要的檔案造成負擔。
</Callout>

## 重要注意事項

<Callout type="warning">
**額度 使用量**：Agent 任務會消耗共用池中的額度（其他會員功能亦使用此池）。Kimi Code 使用獨立的額度池。每個 Agent 任務通常消耗 1 個額度 單位。各會員方案的詳細額度 資訊，請參閱 [額度 與帳單](/agent/quota-and-billing)。
免費方案：每月 6 個 Agent 任務
付費方案：依方案不同，每月 60–720 個 Agent 任務
</Callout>

- **執行時間**：在 Agent 模式中，單一任務通常需要 5–20 分鐘。K2.6 Agent Swarm [Beta] 任務可能需要更長時間。你可以離開頁面，但請不要點擊停止而中斷任務。
- **額度 使用量**：Agent 任務會消耗共用池中的額度。Kimi Code 使用獨立的額度池。 
- **簡單任務**：若只是簡單問答，建議使用標準聊天模式，以獲得更快回應。

<Callout type="warning">
**內容合規**：Agent 功能須遵守 [Kimi 使用者協議](https://www.kimi.com/user/agreement/modelUse?version=v2)。不支援生成禁止內容；提交禁止內容可能導致服務暫停。
</Callout>

## 常見問題

**問：Agent 可以做什麼？**

Agent 可透過多次工具呼叫滿足以下需求：
- **文字生成與編修**：生成文章、報告、文件等，並支援多種寫作風格與格式。
- **Web 開發**：建置全端專案介面與服務，支援應用程式介面設計、後端整合、資料持久化與資料視覺化。
- **簡報生成**：提供專用的網頁版 PPT 工具，用於生成完整簡報。
- **程式輔助**：支援多種程式語言的程式碼撰寫與除錯。

**問：為什麼 Agent 建置的網站無法運作？**

完整專案通常由三個部分組成：前端介面、後端服務與資料儲存。Agent 可以跨這三層生成全端專案內容。如果你的專案未能如預期執行，通常與沙盒啟動、資料庫初始化、驗證設定，或缺少發布動作有關。

**問：Agent 的交付成果有哪些？**

- 完整的任務執行檔案
- 已部署的專案預覽與發布版本
- 可下載的 Zip 壓縮檔（位於 `/mnt/okcomputer/output/`）

**問：Agent 的上下文長度是多少？**

Agent 使用 **256K 字元** 的上下文長度（約 40,000–50,000 個中文字 / 約 100,000 個英文單字）。

**問：Agent額度 如何計算？**

Agent、PPT 與其他會員功能共用同一個額度池。Kimi Code 使用獨立的額度池。每個 Agent 任務通常計為一個額度 單位。你可以在 [會員額度](https://www.kimi.com/membership-額度) 查看目前額度 與使用量。
