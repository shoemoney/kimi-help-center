# Agent quota 與計費

<Callout type="info">
Agent 模式採用 Kimi 的 quota 系統。所有會員權益都包含兩個 quota 池：Kimi Code 使用獨立的 quota 池；其他會員功能（Agent、Deep Research、Slides、Docs、Sheets、Kimi Claw 等）共用同一個 quota 池，並依實際 token 消耗扣除 quota。
</Callout>

## 計費模式
- **兩個 quota 池**：所有會員權益都包含兩個 quota 池。Kimi Code 使用獨立的 quota 池；其他會員功能共用同一個 quota 池——可依你的需求自由分配使用
- **按量計費**：quota 消耗取決於任務複雜度與執行時間（也就是 token 用量）——簡單任務消耗較少，複雜任務消耗較多
- **每月更新**：quota 會依你的訂閱週期每月重置
- **使用優先順序**：獎勵 quota（例如試用 credit、促銷獎勵）會優先消耗，之後才會使用方案 quota

<Callout type="tip">
**範例**：使用 Moderato 方案時，產生一份簡單的 PPT 可能消耗約 1–2% 的 quota；而一次 Deep Research 可能消耗約 5–10%。
</Callout>

## quota 用完時會怎樣？
當你的 quota 已用盡：
- 目前正在進行的任務會正常完成
- 新任務會顯示「quota 不足」提示
- 你可以：
  - 等待每月 quota 自動更新
  - 升級至更高階的會員方案，以取得更多 quota

## 如何查看 quota 使用情況？
- **網頁版**：個人資料 → 設定 → 訂閱
- **App**：個人資料 → 會員方案 → 訂閱
你可以查看：
1. 目前 quota 餘額（以百分比顯示）
2. 下次更新日期
3. 最近 10 筆使用記錄（時間戳記、使用功能、消耗百分比）

<Callout type="info">
使用記錄可能會有短暫延遲。最新資訊請以實際顯示的 quota 為準。
</Callout>

## 任務失敗仍會消耗 quota 嗎？
- 任務成功執行後，才會依實際消耗扣除 quota
- 如果任務因系統錯誤而失敗（未傳回有效結果），請點選 **👎** 按鈕回報。經核實後，將退還對應的 quota
