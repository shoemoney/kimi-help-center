# 深度研究常見問題

## 深度研究卡住了/一直沒有結果怎麼辦？

深度研究會進行大量網頁檢索、資料驗證與推理，介面未及時刷新不代表任務中斷。可嘗試：

1. 重新整理瀏覽器頁面；
2. 暫時離開目前對話（不影響任務執行）；
3. 稍後回來查看，任務仍在背景執行。

若重新整理後仍無結果，請檢查網路連線是否穩定後再等待片刻。

<Callout type="info">
深度研究通常需要 10–25 分鐘。執行期間可離開頁面，任務會在背景非同步執行，完成後會發送通知。若頁面顯示異常，請重新整理頁面，切勿點擊「停止輸出」。
</Callout>

## 搜尋或思考方向出現了錯誤？

我們發現在極小機率的情況下，深度研究會搜尋偏離研究主題。

若發現深度研究的搜尋方向或推理結論明顯偏離預期，可立即點擊頁面底部的「👎」按鈕，在彈窗中簡要說明「問題類型 + 具體偏差」（例如：搜尋偏離主題／結論與事實不符）。平台會在 1–3 個工作天內完成核查，確認屬實時自動退還本次消耗的額度。

**如何減少方向偏差**：

- **聚焦問題範圍**：限定時間範圍、地區範圍與來源類型，避免問題過於寬泛；
- **善用意圖釐清環節**：提交問題後 Kimi 會回覆意圖釐清確認，在此環節明確指出不希望涵蓋的方向，並補充需要重點關注的維度；
- **保持輸入簡潔**：若在意圖釐清環節輸入內容過長、表意混亂，或偏離原始問題，可能導致研究方向跑偏。

## 深度研究的上下文長度是多少？

Kimi-Researcher 的上下文長度（context length）為 **128K tokens**（約 6–10 萬漢字），指模型單次能處理的最大 token 數量（包括輸入 + 輸出）。這表示它在單次研究任務中可以**參考**大量文字資訊，足以支撐複雜、深入的研究分析。但需注意：**生成內容的長度上限通常遠小於上下文視窗**。

| 概念 | 含義 | 說明 |
|------|------|------|
| **上下文視窗** | 模型支援的最大 token 上限 | 128K tokens，包含輸入和輸出 |
| **輸入限制** | 單次可傳送的參考資料 + 指令長度 | 建議控制在 100K tokens 以內 |
| **輸出限制** | 模型單次生成的最大長度 | 通常約 8K–16K tokens，遠小於上下文視窗 |

<Callout type="info">
**常見誤解**：128K 上下文 ≠ 能一次輸出 128K 內容。輸出長度通常為上下文視窗的 1/8 到 1/16。
</Callout>

**為什麼會出現「輸出不完」？** 當研究報告過長時，模型可能主動截斷（達到單次輸出上限後停止）、建議續寫，或分段輸出——這不是故障，而是輸出限制的正常表現。若報告未完成，直接回覆「繼續」或「請完成剩餘部分」；複雜研究建議主動要求分章節生成。

**使用建議**：將核心資訊置於提示詞前後兩端（避免「Lost in the Middle」現象）；超長參考資料先提煉摘要，而非全文貼上；多輪對話及時開啟新對話或進行對話總結；主題過於寬泛時拆分為多個子問題分次研究。

## 沒有完成任務就扣除了額度？

深度研究同樣區分「一般對話」與「執行任務」，選擇「深度研究」任務後即依任務類型計費。

- **計費方式**：任務會根據實際 token 消耗扣除額度。深度研究與其他會員功能共用一個額度池，Kimi Code 使用單獨額度池。
- **任務失敗退還**：若任務執行失敗（未回傳有效結果），不會扣除 token 消耗。

在「我的 → 管理 → 訂閱」可查看目前會員帳戶的 Token 額度使用情況。

<Callout type="info">
如需進一步協助，可透過產品內「👎」意見回饋管道聯絡工作人員，或寄送電子郵件至 [support@moonshot.ai](mailto:support@moonshot.ai)。
</Callout>

## 我主動停止了任務，卻被扣除了額度？

深度研究一旦啟動，系統即調用算力進行檢索、驗證與推理，資源已被鎖定，因此主動點擊「停止」或關閉頁面均視為已消耗額度。

若頁面長時間無更新，建議先重新整理瀏覽器或稍後再查看，避免因誤判「卡住」而中斷任務。深度研究通常需要 10–25 分鐘，執行期間可離開頁面，任務會在背景非同步執行，完成後會發送通知。

## 深度研究報告無法下載和儲存？

深度研究會生成兩種報告形式，均可儲存。

**文字研究報告**

點擊右上角「下載」或「複製」按鈕，支援本機儲存或貼上使用。報告支援匯出為 PDF、Word 格式。

**視覺化報告**

點擊「預覽」→「分享」→「複製連結」→ 在瀏覽器中開啟 → 按右鍵「另存新檔」，可儲存為 HTML、PDF 等格式。視覺化報告還支援：

- **預覽**：點擊「預覽」，支援切換網頁版、行動版兩種檢視預覽；
- **HTML 原始碼複製**：點擊預覽，切換為「程式碼模式」，支援複製貼上視覺化報告原始碼；
- **公開分享**：點擊分享，支援取得公開分享連結。
