# Deep Research

<Callout type="info">
**Deep Research** 是 Kimi 的首款 Agent 產品，由 Kimi-Researcher 模型驅動。它不只是回答問題，而是像真正的研究員一樣，自主完成從任務規劃到報告交付的完整流程。
</Callout>

## Kimi-Research 如何運作？

面對每一個問題，Kimi-Researcher 都會獨立完成完整的研究流程：
| 步驟 | 說明 |
| --- | --- |
| **Clarification** | 主動追問，以建立更清晰的問題空間 |
| **深度推理** | 每個任務平均進行 23 個推理步驟，梳理並拆解需求 |
| **主動搜尋** | 規劃約 74 個關鍵字，發現 206 個 URL，篩選出品質最高的前 3.2% 內容 |
| **Iterative reasoning** | 評估搜尋結果，判斷是否需要追加搜尋 |
| **工具呼叫** | 呼叫瀏覽器、程式碼執行及其他工具來處理資料 |
| **報告生成** | 將資訊整合為結構化的長篇報告，並附上引用來源 |

<Callout type="info">
Deep Research 以非同步方式運作，會花 10–25 分鐘逐步完成推理、檢索與寫作。
</Callout>

## 適用情境

<Callout type="tip">
**最適合**：投資分析、產業研究、學術主題、策略規劃、法規審查、知識整合
</Callout>

| 類別 | 範例 |
| --- | --- |
| **專業研究** | 投資分析、產業研究、學術主題、策略規劃 |
| **資訊整合** | 法規審查、複雜文件檢索、多來源彙整 |
| **知識與教育** | 教學材料、系統性綜述、深度主題探索 |
| **日常探索** | 了解感興趣的主題 |

<Callout type="warning">
**不適合**：創意寫作（小說、劇本）、算命、履歷撰寫、固定格式範本、可編輯幻燈片
</Callout>

## 如何使用 Deep Research？
**入口**：
- **Web**：[kimi.com/deep-research](https://www.kimi.com/deep-research)
- **Mobile**：Kimi app → 任務列 → Deep Research Agent 模式
**步驟**：
1. 輸入你的研究問題並送出
2. 回答釐清問題以確認方向（或點擊「納入全部內容」跳過）
3. 即時查看搜尋關鍵字、推理過程與已造訪的 URL
4. 完成後接收兩份交付成果：
   - **Deep Research 報告**（Markdown）：10,000+ 字，含目錄與可追溯來源
   - **視覺化報告**（HTML）：可互動、可公開分享的視覺化報告
5. 依需求預覽、下載（PDF/Word）或分享
## 取得最佳結果的技巧
### 1. 聚焦範圍
提交前，可考慮明確指定：
- **時間範圍**：「從 2023 年至今」
- **地理範圍**：「僅限美國市場」
- **來源類型**：「優先採用官方報告與學術論文」
- **問題拆解**：將寬泛問題拆分為子問題

### 2. 在 Clarification 階段校準方向
- 說明你*不*希望涵蓋的方向
- 補充需要聚焦的具體面向或角度
- 為複雜問題提供背景脈絡

<Callout type="warning">
Clarification 回覆請保持簡潔且具體——過長或不清楚的輸入可能導致研究方向偏移。
</Callout>

### 3. 執行期間請耐心等待
Deep Research 通常需要 10–25 分鐘。系統會在背景執行——你不需要停留在頁面上。

<Callout type="warning">
**請勿點擊「停止輸出」**——這會終止研究。如果頁面看似沒有回應，直接重新整理即可。
</Callout>

## 重要事項
1. **執行時間**：10–25 分鐘。任務會以非同步方式執行——完成後你會收到通知
2. **credit 退還**：工具呼叫錯誤會自動退還；若研究方向偏移，請提交回饋
3. **輸入品質**：簡潔、明確的問題能產生更好的結果
4. **範圍界線**：若只是簡單問答，建議使用標準聊天模式，以獲得更快回覆
5. **條款**：須遵守 [Kimi User Service Agreement](https://www.kimi.com/user/agreement/modelUse?version=v2)
