## 審閱專家

Kimi 就像細心嚴謹的稿件審閱者，能拆解修改意見，精準定位文件中的相關段落，並自動插入詳盡的批註與建議。

**提示詞範例**：

## PDF 設計與出版服務

Kimi 就像版面設計師，能協助你規劃視覺特色，自動編排文字與圖片，並產出具出版品質的 PDF 作品集。

<CodePreview
  files={[
    {
      name: "prompt.md",
      language: "markdown",
      content: "你是一位策展出版 AI，專精於現代藝術，尤其是畢卡索研究。\n你的任務：運用大量圖像，協助觀眾理解為什麼畢卡索值得\n一再被重新觀看。\n\n請直接輸出為 PDF。\n\nI. 核心要求\n大量使用圖像\n每個時期、每位參照藝術家、每場運動都必須有相應圖片支持\n優先使用有來源的圖片\n僅在無法取得來源圖片時，才使用高保真 AI 生成圖片\n\nII. 視覺系統\nMAP 標誌作為全頁浮水印\n非對稱版面\n清晰網格，並在局部加入受控的打破秩序\n高對比黑白 + 原色點綴\n\nIII. 內容結構（生成所有章節）\n1. 封面\n畢卡索\n展覽副標題（英文與中文）\nMAP 標誌浮水印\n\n2. 為何是畢卡索（含圖片）\n不同時期的畢卡索肖像\n並置不同時期作品\n\n3. 時期與運動（以圖像為核心）\n每個時期必須包含 8–12 張圖片：\n藍色時期\n玫瑰時期\n立體主義（分析 / 綜合）\n戰爭與政治\n晚期實驗\n\n圖片類型：\n完整作品\n細節裁切\n結構解構圖（必要時由 AI 生成）\n\n4. 代表作品\n不少於 25 件作品\n單件作品可佔滿整頁\n強調結構、透視與解構\n\n5. 如何觀看畢卡索\n以圖像為基礎的比較式解說\n同一主題的並列處理\n\n6. 展廳與節奏\n高密度觀看區\n反思緩衝區\n\n7. MAP 的當代定位\n上海為何需要畢卡索\n為何此刻如此重要",
