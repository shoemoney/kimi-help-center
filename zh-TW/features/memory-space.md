# 記憶空間（記憶空間）

## 什麼是記憶？
Kimi 真的學會了傾聽——聊得越多，它越懂你。運作方式如下：

Kimi 不只會回應目前聊天視窗中的內容。它會在每一次對話中記下重要細節——你的偏好、習慣、風格……

隨著你持續使用，Kimi 會在不同對話之間不斷學習，持續調整對你的理解。

你不需要反覆說明。Kimi 會主動參考「我們之前聊過什麼」，給出更貼切、更連貫的回覆。

## Kimi 會記住哪些內容？
Kimi 會使用另行訓練的模型，有選擇地記住對你有價值的對話內容。

在記錄任何內容之前，Kimi 會先問自己兩個問題：
- 這位使用者是誰？
- 這位使用者在意什麼、偏好什麼，或想避免什麼？

除非你明確要求，否則 Kimi **不會** 記憶未經授權的私人資訊（例如健康資料、密碼、地址）。

## 如何觸發記憶
記憶現在是內建能力——只要自然對話，就能觸發。

更新或管理 Kimi 記憶的方式：

**(1) 在對話中直接指示（最常見）**

你可以用自然語言指令更新記憶：

| 操作 | 你可以這樣說 | Kimi 的回應 |
|:---|:---|:---|
| 新增記憶 | 「記住我喜歡咖啡」<br>「記一下我的員工編號是 9527」<br>「記住我是一名專案經理」 | Kimi 會呼叫記憶工具並儲存 |
| 更新記憶 | 「更正一下——我搬到紐約了」<br>「更新：我現在是資深工程師」 | Kimi 會取代舊的記憶 |
| 刪除記憶 | 「忘記我喜歡咖啡這件事」<br>「刪除關於我員工編號的記憶」<br>「清除所有記憶」 | Kimi 會移除指定記憶或全部記憶 |

注意：記憶完全由你掌控。它不會用於模型訓練，且你可以隨時關閉或清除。

**(2) 透過設定管理（UI）**

你也可以透過設定介面管理記憶：
- Web / Mobile：設定 → 個人化 → 記憶空間（記憶空間）
- 你可以在這裡查看所有已儲存的記憶項目
- 也可以手動刪除不再需要的任何記憶

### 新增記憶
記憶會在對話中自動觸發。例如：
- 「我的名字是 xxx，朋友都叫我 xxxx」
- 「我是一名國小數學老師，所以教材需要適合小朋友」
- 「請不要在回覆裡使用 emoji」
- 「我通常用 C++ 寫程式」
- 「不要重複自己說過的話，也不要使用過多標點符號」

如果有特別希望 Kimi 記住的事，可以加以強調：
- 「記住……」
- 「請記在心裡……」
- 「……別忘了這件事」

### 更新記憶
前往個人檔案 → 設定 → 個人化 → 記憶空間（記憶空間），即可編輯個別記憶項目。

### 刪除（遺忘）記憶
前往個人檔案 → 設定 → 個人化 → 記憶空間（記憶空間），並在個別項目上點選刪除。
