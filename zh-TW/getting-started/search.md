# Agentic Search

<Callout type="info">
Kimi 的 Agentic Search 建構於端到端 agentic 強化學習架構。不同於傳統的工具編排方式，它能讓 AI 自主判斷何時需要搜尋、該呼叫哪些工具，以及如何調整策略——從而勝任複雜的資訊蒐集與處理任務。
</Callout>

相較於傳統以關鍵字比對為主的搜尋，Kimi 的搜尋能力已歷經兩次重要演進：
- **Explorer Search（探索式搜尋）**（2024 年 10 月）結合大型語言模型的語意理解與即時資訊檢索，可自動拆解複雜問題並追溯來源。
- **Agentic Search** 更進一步具備自主規劃與工具呼叫能力，支援金融資料查詢、學術文獻檢索、圖片搜尋等多模態任務。

## Web Search（網頁搜尋）設定

<Frames
  src="./images/search/web-search.png"
  alt="Web Search（網頁搜尋）"
/>

Web Search（網頁搜尋，自動/關閉）突破知識新鮮度的邊界，提供即時、可信且可追溯的資訊。

點擊聊天輸入框下方的「Web Search（網頁搜尋）」開關。啟用後，Kimi 會自主判斷目前問題是否需要即時資料，並智慧呼叫搜尋引擎與垂直資料庫來檢索、整合資訊。

## 核心能力

### 1. 兼顧即時性與權威性
即時網路檢索涵蓋 100+ 個經驗證且可信賴的來源（主要新聞媒體、政府公告、金融資料平台、學術期刊資料庫），確保資訊既新且具權威。

### 2. 來源標註
所有基於搜尋生成的回答都會附上參考來源連結。點擊即可查看原始頁面，完整核對準確性與脈絡。

### 3. 全球資訊取用
支援多語言自然語言對話。Kimi 能主動搜尋非英文來源（例如日本技術文件、法文新聞），並自動整合多語資訊。

## 建議使用情境

- 即時新聞與動態（突發新聞、股市資料、政策變更）
- 事實查證（網路謠言、歷史資料、統計方法）
- 專業研究（競品情報、學術前沿、產業標準）

## 權威來源標章

Kimi 的 Web Search（網頁搜尋）會從相關性、權威性與即時性三個維度篩選來源，自動排除高風險網站、重複轉載、低品質網頁內容與幻覺資訊，確保結果可靠。

通過 Kimi 嚴格篩選的優質來源，會在回覆中標示權威標章（例如官方網站認證、學術認證、媒體認證圖示），協助你快速辨識高度可信的資訊。

**來源篩選機制**：
- **排除**：低品質聚合網站、未經驗證的自媒體、過期快取頁面
- **優先採用**：政府機關網站、權威媒體、學術期刊、官方財務報告管道

## 智慧搜尋

### 圖片搜尋

Kimi 支援以圖搜尋與圖片理解。上傳圖片後，Kimi 可自動呼叫圖片搜尋工具，辨識內容並檢索相關資訊。

**查詢範例**：
- 「這是哪裡？」
- 「這個迷因在發生什麼事／這個人在說什麼？」
- 「找出真正的 McDonald's」

**使用方式**：
- 直接上傳圖片（支援 JPG、PNG 等格式）
- 在提示詞中描述圖片內容，或提出與圖片相關的問題
- Kimi 會結合圖片辨識與 Web Search（網頁搜尋），提供圖片來源、相似圖片與相關資訊

**典型情境**：
- 辨識未知物件、地標或產品型號
- 尋找圖片的來源或出處
- 分析圖表或螢幕截圖中的資料，並檢索相關背景資訊

**將 URL 直接貼到對話中**，Kimi 會自動抓取並分析頁面內容。

**使用範例**：
- 摘要這篇文章的重點
- 從這份財報 PDF 中擷取關鍵資料
- 搜尋該 URL 中的圖片資訊

## 提示

<Callout type="warning">
- 優先使用**公開可存取**的連結（例如新聞頁面、公開 PDF 文件）
- 某些**受密碼保護**或限制爬取的頁面可能無法存取
- 對於**動態載入**的頁面，Kimi 可能只能擷取初始 HTML 內容
- Kimi **無法重新讀取共享對話連結**（也就是其他 Kimi 聊天的連結）
</Callout>
