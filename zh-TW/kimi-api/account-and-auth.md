# 帳號與認證

以下是 Kimi API 開發者帳號與認證相關的常見問題。

## 個人認證可以開立企業發票嗎？

個人認證帳號**無法直接開立企業發票**。如需企業發票，請先將帳號升級為企業認證，完成後即可開立企業抬頭發票。

## 個人帳號如何轉為企業帳號？

1. 登入 [platform.kimi.ai](https://platform.kimi.ai/) 控制台。
2. 進入「帳號設定 → 認證資訊」。
3. 選擇「企業認證」，依要求填寫企業資訊並上傳相關資質文件。
4. 提交後等待審核，審核通過後將自動切換為企業帳號。

<Callout type="info">
注意：個人轉企業後，原有餘額與用量資料將會保留。
</Callout>

## 個人認證和企業認證有什麼差別？

| 對比項 | 個人認證 | 企業認證 |
| --- | --- | --- |
| 發票類型 | 個人普通發票 | 企業普通／專用發票 |
| rate limit | 標準 | 可申請更高 quota |
| 商務合作 | — | 支援簽署合約 |
| 企業折扣 | — | 可申請 |
| 技術支援 | 標準 | 優先支援 |

## 帳號遭停權後如何申訴？

如果你的 API 帳號因違規遭到停權：

1. 傳送郵件至 **api-service@moonshot.ai**，主旨請註明「API 帳號申訴」。
2. 在郵件中提供你的帳號資訊（註冊手機號碼／電子郵件）與申訴說明。
3. 平台將於 1–3 個工作天內審核並回覆。

## 如何變更綁定手機號碼？

目前變更綁定手機號碼需聯絡客服協助處理：

1. 傳送郵件至 **api-service@moonshot.ai**，主旨請註明「手機號碼換綁」。
2. 提供原手機號碼與新手機號碼資訊。
3. 可能需要進行身分驗證，以確保帳號安全。

## 完成認證有什麼好處？

- **更高 rate limit**：認證使用者可獲得更高的 API 呼叫速率。
- **完整功能**：部分進階功能可能僅對認證使用者開放。
- **發票支援**：通過認證後即可正常開立發票。
- **技術支援**：認證使用者享有更高優先級的技術支援。
