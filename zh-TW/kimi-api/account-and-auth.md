# 帳戶與身分驗證

<Callout type="info">
關於 Kimi API 開發者帳戶、驗證與身分驗證的常見問題。
</Callout>

## 個人帳戶可以開立企業發票嗎？
個人帳戶**無法直接開立企業發票**。如需企業發票，請先將帳戶升級為組織帳戶。通過驗證後，即可用組織名稱申請發票。

## 如何從個人帳戶升級為組織帳戶？
1. 登入 [platform.moonshot.ai](https://platform.moonshot.ai) 控制台。
2. 前往 **帳戶設定 → 驗證**。
3. 選擇 **組織驗證**，並填寫所需資訊。
4. 提交審核；審核通過後，帳戶會自動轉換。

<Callout type="tip">
升級後，既有餘額與使用資料都會保留。
</Callout>

## 個人驗證與組織驗證的差異
| 項目 | 個人 | 組織 |
| --- | --- | --- |
| 發票類型 | 個人發票 | 企業／VAT 發票 |
| Rate Limits（速率限制） | 標準 | 可申請更高 quota（配額） |
| 商務合約 | — | 可簽署合約 |
| 用量折扣 | — | 可依需求申請 |
| 技術支援 | 標準 | 優先支援 |

## 如何申訴帳戶停權？
如果你的 API 帳戶因違反政策而遭停權：
1. 請寄信至 **support@moonshot.ai**，主旨填寫「API 帳戶申訴」。
2. 請附上你的帳戶資訊（註冊電子郵件地址）與申訴說明。
3. 團隊會進行審查，並於 1–3 個工作天內回覆。

<Callout type="info">
**支援信箱**：support@moonshot.ai
</Callout>

## 如何變更註冊電子郵件？
如需變更註冊電子郵件，請聯絡支援團隊：
1. 請寄信至 **support@moonshot.ai**，主旨填寫「變更電子郵件申請」。
2. 請提供目前使用的電子郵件地址與新的電子郵件地址。
3. 為確保帳戶安全，可能需要進行身分驗證。

## 完成驗證的好處
- **更高的 Rate Limits（速率限制）**：通過驗證的使用者可獲得更高的 API 呼叫頻率。
- **完整功能存取**：部分進階功能可能僅開放給已驗證使用者。
- **發票支援**：已驗證帳戶可申請發票。
- **技術支援**：已驗證使用者可獲得更高優先級的技術支援。
