# 商務合作與聯絡銷售團隊

Kimi API 為企業客戶提供多種合作方案，滿足不同規模與情境的業務需求。

## 如何聯絡銷售團隊？

請前往 [platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales) 填寫聯絡表單，我們的銷售團隊將於 1-2 個工作天內與你聯絡。

你也可以在表單中註明以下資訊，方便我們更快回覆：

- 公司名稱與產業
- 預估用量規模
- 主要應用情境
- 期望的合作方式

## 演算法備案相關

Kimi 大模型已完成中國境內演算法備案。如需查閱備案資訊，或取得備案相關材料以符合合規要求，請聯絡銷售團隊索取。

## 合約簽署

完成企業認證的使用者可與 Moonshot 簽署正式服務合約：

- 支援標準服務協議與客製合約。
- 合約簽署後，可享有對公轉帳儲值與企業級 SLA。
- 具體流程請聯絡銷售團隊洽談。

## 企業折扣

大用量企業客戶可申請專屬折扣：

- 折扣幅度與承諾用量及合作期限相關。
- 需完成企業認證並簽署合約。
- 請透過銷售團隊申請，並提供預估每月用量。

## 企業級 API 服務

企業級 API 服務在標準 API 基礎上提供：

- 更高的 rate limit 與 concurrency quota
- 專屬技術支援通道
- 客製化 SLA 保障
- 優先體驗新功能

如需瞭解詳情，請前往 [platform.kimi.ai/contact-sales](https://platform.kimi.ai/contact-sales) 聯絡銷售團隊。
