# 商務合作與銷售

<Callout type="info">
面向企業客戶的合作方案——從用量折扣到自訂 SLA。
</Callout>

Kimi API 為企業客戶提供多元合作方案，滿足各種規模的業務需求。
## 如何聯絡銷售團隊？
請造訪 [platform.moonshot.ai/contact-sales](https://platform.moonshot.ai/contact-sales) 提交聯絡表單。我們的銷售團隊會在 1–2 個工作天內與您聯繫。

<Callout type="tip">
**提交時請提供**：
- 公司名稱與所屬產業
- 預估使用量
- 主要使用場景
- 偏好的合作模式
</Callout>

## 簽署合約
已完成組織驗證的使用者可與 Moonshot 簽署正式服務協議：
- 可選擇標準服務協議，也可洽談客製化合約。
- 簽署後，您將可使用電匯付款，並享有企業級 SLA。
- 如需了解具體流程，請聯絡銷售團隊洽談。

## 用量折扣
高用量企業客戶可申請專屬折扣：
| 條件 | 詳細資訊 |
| --- | --- |
| **申請資格** | 完成組織驗證 + 已簽署合約 |
| **折扣級距** | 依承諾使用量與合約期限而定 |
| **申請方式** | 透過銷售團隊申請，並提供預估每月使用量 |

## 企業 API 服務
企業 API 服務在標準 API 方案的基礎上，提供：
- **更高的 rate limits（速率限制）與 concurrency quotas（併發配額）**
- **專屬技術支援管道**
- **客製化 SLA 保證**
- **新功能優先體驗**
