# Kimi API 介紹

Kimi API Open Platform 為開發者提供強大的大型語言模型（LLM）能力串接，協助你快速將 AI 能力整合到自己的產品與服務中。

## 平台概述

Kimi API 基於 Moonshot 自主研發（in-house）的大型語言模型（LLM），提供文字生成、多輪對話、檔案解析、網路搜尋等核心能力。平台相容於 OpenAI API 格式，開發者可用較低成本完成遷移與串接。

**平台網址**：[platform.kimi.com](https://platform.kimi.com/)

## 適用對象

- **獨立開發者**：快速打造 AI 驅動的個人專案或工具。
- **企業技術團隊**：將 AI 能力嵌入企業產品，提升使用者體驗與業務效率。
- **新創公司**：以較低成本取得頂尖 AI 能力，加速產品迭代。

## 主要應用場景

- **智慧客服**：以脈絡理解為基礎的自動問答，提升客服效率與使用者滿意度。
- **內容生成**：文章撰寫、行銷文案、程式碼生成等創作場景。
- **資料分析**：文件解讀、報表分析、知識擷取與摘要。
- **知識問答**：基於私有文件庫的智慧檢索與問答系統。

## 快速開始

1. 前往 [platform.kimi.com](https://platform.kimi.com/)註冊開發者帳號。
2. 在控制台建立 API Key。
3. 參考 API 文件完成首次呼叫。
4. 依業務需求選擇合適的模型與參數。
