# Kimi API 概覽

Kimi API 平台為開發者提供強大的大型語言模型能力，協助你快速將 AI 整合進產品與服務。

## 平台概覽

Kimi API 由 Moonshot 自研的大型語言模型驅動，提供文字生成、多輪對話、檔案解析、Web Search 等核心能力。平台相容 OpenAI API 格式，讓開發者能以極低成本完成遷移與整合。

**平台網址**： [platform.moonshot.ai](https://www.platform.moonshot.ai)

## 適用對象

- **獨立開發者**：快速打造由 AI 驅動的個人專案與工具。
- **企業工程團隊**：將 AI 能力嵌入企業產品，提升使用者體驗與營運效率。
- **新創團隊**：以低成本取得頂尖 AI 能力，加速產品迭代。

## 主要使用情境

- **智慧客服**：具備上下文理解的自動問答，提升支援效率與客戶滿意度。
- **內容生成**：文章撰寫、行銷文案、程式碼生成等創意工作流程。
- **資料分析**：文件解讀、報告分析、知識擷取與摘要整理。
- **知識問答**：基於私有文件庫的智慧檢索與問答系統。

## 快速開始

1. 前往 [platform.moonshot.ai](https://platform.moonshot.ai) 註冊開發者帳號。
2. 在主控台建立 API Key。
3. 參考 API 文件，發起你的第一次呼叫。
4. 依照使用情境選擇合適的模型與參數。
