# 核心概念與終端機

## 重要概念

| 概念 | 說明 |
|---------|-------------|
| **記憶** | Kimi Claw 的長期記憶系統。可跨對話保存你的偏好、習慣與重要資訊。 |
| **技能** | 可從 ClawHub 資源庫安裝的能力模組，讓 Kimi Claw 具備特定領域的專業能力。 |
| **HEARTBEAT** | 依排程在背景執行的定時任務，適合用於週期性提醒、資料擷取與摘要彙整。 |
| **身分** | Kimi Claw 的角色定義：名稱、職業與人設。你可以完全自訂。 |
| **靈魂** | 形塑 Kimi Claw 互動風格的核心性格特質與行為原則。 |
| **工具** | Kimi Claw 可調用的能力集合，包括網頁搜尋、檔案處理、程式碼執行等。 |
| **使用者** | 你與 Kimi Claw 之間的關係定義，會影響互動模式與資訊共享方式。 |

## 終端機

<Frames
  src="./images/concepts/screenshot-30.png"
  alt="截圖 30"
/>

你可以在網頁版透過 **設定 → 終端機** 開啟命令列介面，並執行指令直接控制 Kimi Claw。

或者，你也可以直接用自然語言告訴 Kimi Claw 要執行哪個指令，它會替你完成。

> 注意：終端機與外掛共用同一個連線通道。重新啟動 OpenClaw gateway 會中斷終端機連線。

## 指令參考

### 系統

| 指令 | 說明 |
|---------|-------------|
| `/help` | 顯示說明資訊 |
| `/status` | 查看目前系統狀態 |
| `/ping` | 測試連線是否存活 |
| `/cron` | 管理排程任務 |
| `/config` | 查看或編輯設定 |
| `/new` | 開始新對話（清除目前上下文） |
| `/reset` | 重設 Kimi Claw |
| `/compact` | 壓縮目前對話上下文 |
| `/stop` | 停止目前正在執行的任務 |

### 技能

| 指令 | 說明 |
|---------|-------------|
| `/skills` | 瀏覽、安裝與管理技能 |

### 排程任務

| 指令 | 說明 |
|---------|-------------|
| `/cron` | 查看與管理任務排程 |

### 記憶

| 指令 | 說明 |
|---------|-------------|
| `/memory` | 查看與管理長期記憶 |

### 設定與除錯

| 指令 | 說明 |
|---------|-------------|
| `/config` | 查看或編輯系統設定 |
| `/logs` | 查看執行階段日誌 |
| `/debug` | 啟用除錯模式以進行詳細診斷 |
