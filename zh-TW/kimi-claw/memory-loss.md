# 記憶遺失與上下文

## 為什麼昨天的對話不見了？

OpenClaw 每天凌晨 **4:00 AM** 會自動重設對話，避免過長的上下文導致幻覺或回覆品質下降。

如果你需要調整重設時間，可以在 `config.yaml` 中修改排程。

**最佳做法：** 任何重要資訊——偏好設定、專案細節、反覆使用的指示——都請明確告訴 Kimi Claw 儲存：_「把這個記到記憶裡。」_ 儲存在記憶中的資訊會在對話重設後保留下來。

## Kimi Claw 的記憶不見了？

每天凌晨 4 點的重設會清除目前的對話上下文。若某些內容沒有儲存到 **記憶**，就會消失。

**解決方法：**
- 對話過程中，說 _「把 X 記到記憶裡」_，Kimi Claw 就會將它寫入長期儲存。
- 透過 **工作區 → AGENTS.md → #MEMORY** 查看已儲存的記憶。

- 你也可以隨時使用 `/memory` 指令查看並管理已儲存的記憶。

## 訂閱結束後，記憶會保留多久？

記憶檔案會存放在你的工作區中，你可以隨時查看或下載。

- 會員資格到期後，雲端執行個體會**保留 7 天**。
- 在 7 天內續費，所有資料——記憶、設定、技能——都會完整復原。
- 7 天後，執行個體可能會被回收，資料也會永久刪除。
- 記憶匯出／備份功能正在開發中，未來可更方便地遷移。
