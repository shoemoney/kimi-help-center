# 沒有回應或速度很慢？

<Callout type="info">
如果 Kimi Claw 沒有回覆，或回應異常緩慢，可能有幾種原因。請依照下方的疑難排解步驟處理。
</Callout>

## 常見原因

| 原因 | 說明 |
|-------|-------------|
| **Bridge 中斷連線** | Kimi Claw 與伺服器之間的連線已中斷；需要重新啟動閘道 |
| **資源忙碌** | 伺服器負載偏高；回應可能會延遲 |
| **Instance 離線** | Kimi Claw instance 已離線，需要修復 |

## 如何修復？

請依序嘗試以下步驟，直到問題解決：

1. **再傳送一則訊息** — 有時只是短暫延遲；補上一則訊息可能會觸發回應
2. **重新整理頁面** — 關閉並重新開啟 Kimi Claw 對話
3. **重新啟動閘道** — 前往 **設定**，點擊 **重新啟動 Kimi Claw**。等待它重新上線
4. **自動修復** — 在設定中點擊 **修復 Kimi Claw**。系統會自動偵測並修復設定問題
5. **還原初始設定** — 如果上述方法都無效，請在設定中選擇 **還原初始設定**

## 關於還原初始設定

<Callout type="warning">
這會將 Kimi Claw 重設為出廠狀態，但：

- **會保留：** 工作區檔案與長期記憶
- **需要重新設定：** 聊天平台連線（Telegram 等）必須重新設定
</Callout>
