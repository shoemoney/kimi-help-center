# 一般疑難排解

本頁說明 Kimi Claw 常見錯誤代碼與自行修復選項。

## 常見錯誤代碼

| 代碼 | 含義 | 處理方式 |
|------|---------|------------|
| **400** | 錯誤請求 — 輸入格式不正確或參數無效 | 檢查訊息中是否含有不支援的內容，然後重試。 |
| **401** | 未授權 — 驗證失敗 | 登出 Kimi 後再重新登入。如果問題仍然存在，請在 Kimi Claw 設定中檢查你的 API 憑證。 |
| **403** | 禁止存取 — 權限不足 | 確認你的會員等級支援目前使用的功能，並確保帳戶未受限制。 |
| **429** | Too Many Requests — 已超過 rate limit | 等待幾分鐘後再試。如何查看你的 quota，詳情請參閱[對話限制](/kimi-claw/conversation-limits)。 |
| **500** | Internal Server Error — 伺服器發生問題 | 稍等片刻後重試。如果反覆發生，請使用下方的自行修復選項，或聯絡支援團隊。 |

## 自行修復選項

Kimi Claw 內建修復工具，可從網頁版的 **設定** 開啟：

| 選項 | 功能 |
|--------|--------------|
| **重新啟動 Kimi Claw** | 重新啟動閘道連線，可修復多數暫時性問題（例如橋接中斷、短暫卡住）。 |
| **修復 Kimi Claw** | 執行自動診斷，偵測並修正設定問題。若單純重新啟動無法解決，請嘗試此選項。 |
| **還原初始設定** | 將 Kimi Claw 重設為預設狀態。工作區檔案與記憶會保留，但聊天平台連線（Telegram 等）需要重新設定。請僅在不得已時使用。 |

## 升級處理流程

如果自行修復選項無法解決問題：

1. 在終端機執行 `/logs`，擷取近期錯誤輸出。
2. 執行 `/debug`，啟用詳細診斷。
3. 將錯誤詳情與任何相關記錄寄至 **support@moonshot.ai**。
