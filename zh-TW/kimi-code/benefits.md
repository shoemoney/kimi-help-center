# Kimi Code 權益

Kimi Code 是 Kimi 會員方案包含的服務，提供程式開發相關支援與功能，協助會員在個人開發流程中更有效率地完成程式設計任務。

> 請注意，此權益僅供個人開發使用，不適用於企業開發情境。如有企業需求，請造訪 [Kimi 開放平台](https://platform.kimi.ai/)。

## 計費

- Kimi Code 使用量**已包含在你的訂閱費用中**——不會額外收費。
- Kimi Code **與 Kimi 會員方案共用同一套額度**——來自 CLI、VS Code 及第三方工具的請求都會計入該額度；不同方案包含的額度數量不同。
- 系統會優先消耗贈送額度，再消耗方案額度。

<Callout type="warning">
**全新會員體系即將上線。** 屆時 Kimi 會員權益將與 Kimi Code 權益拆分，可依需求分別購買、更有彈性。**目前訂閱中的用戶不受影響。** 若想繼續使用合併權益，可在新體系上線前購買你目前的方案。
</Callout>

## 額度更新

額度會以 **7 天**為週期更新：

- 自你的訂閱日（D1）起，每 7 天更新一次額度。
- 更新週期：D1–D7、D8–D14、D15–D21、D22–D28。
- 未使用的額度**不會**結轉至下一個週期。

> 建議妥善規劃每週用量，充分運用你的額度。

## 支援工具

Kimi Code 權益可搭配以下工具使用：

| 工具 | 說明 |
| --- | --- |
| **Kimi Code CLI** | Kimi 官方命令列 AI agent |
| **Claude Code** | Anthropic 的命令列程式設計助理 |
| **Roo Code** | 適用於 VS Code 的 AI 程式設計擴充功能 |

若將你的 Kimi Code API Key 用於上述未列出的平台或工具，可能會被視為誤用，並可能導致存取權受限。為獲得最佳體驗與完整保障，請使用上方列出的支援工具。

## Extra Usage

當訂閱額度用盡後，你可以使用「加值額度（Extra Usage）」餘額繼續發送請求，不必等待刷新。僅訂閱會員可開啟，且**網頁版 Kimi 與 Kimi Code 共用同一份 Extra Usage 餘額**（儲值一次，兩端通用）。完整條款請見 [Extra Usage 條款](https://www.kimi.com/user/agreement/extra-usage-rules-cn)。

### 儲值入口

- **從主站儲值**：開啟 Kimi [訂閱頁面](https://www.kimi.com/membership/subscription?tab=quota)，捲動至頁面底部的「Extra Usage」模組 → 選擇金額 → 完成付款。
- **從 Kimi Code Console 儲值**：當你的週額度或 5 小時額度任一項使用量超過 **80%** 時，進度卡片會出現「購買 Extra Usage」按鈕，點擊即可前往訂閱頁完成購買。

### 開啟與管理

開啟「Extra Usage」開關後，當訂閱額度用盡時，系統會自動從 Extra Usage 餘額中扣除。點擊模組的「設定」可開啟**每月消費上限**、設定本月最多可花費的金額；進度條會即時顯示本月 Extra Usage 的消耗情況。

### 計費與規則

- **計費**：依實際用量計費——讀取與生成的內容越多、任務越複雜，花費越高。餘額以人民幣（RMB）顯示，費率以平台顯示為準。Extra Usage 價格接近 [Kimi Open Platform](https://platform.kimi.com) 的官方 API 價格；用量較大時，升級訂閱通常更划算。
- **扣除優先順序**：先扣除訂閱等有時效的額度，**Extra Usage 最後扣除**，作為備援。開啟後即使訂閱額度用盡，Extra Usage 也能無縫消耗，任務不中斷、不報錯。
- **消費上限**：可在設定中開啟「每月消費上限」，限制本月可花費的 Extra Usage 金額；未開啟則不限額。
- **有效期與累積**：餘額不會過期，並可跨儲值累積；訂閱失效後餘額仍可使用，但失效期間無法儲值——需重新訂閱後才能再次儲值。
- **退款**：一般不可退款、轉讓或兌現。

<Callout type="info">
計費範例（僅供感受量級，實際費率以平台為準）：一次簡單請求（例如「推薦一首搖滾歌曲」）約 **¥0.03**；一次複雜的多步驟任務（例如「規劃一週從成都到川西的自駕行程」）約 **¥1.6**。儲值限制：單次最低 ¥25，每日最多 10 次、¥3,000，餘額上限 ¥10,000。
</Callout>

### 查詢用量

- **Kimi 網頁 / App**：設定 → 訂閱與發票 → [我的額度](https://www.kimi.com/membership/subscription?tab=quota)。
- **Kimi Code Console**：開啟 Extra Usage 後，登入 [Console](https://www.kimi.com/code/console) 即可查看餘額與用量。
- **Kimi Code CLI**：在命令列輸入 `/usage` 即可直接查詢。

### Extra Usage 常見問題

- **網頁版 Kimi 和 Kimi Code 的 Extra Usage 是同一個錢包嗎？** 是的——餘額於兩端共用，儲值一次即可通用。
- **Extra Usage 和訂閱額度誰先扣？** 先扣訂閱等有時效的額度；Extra Usage 只有在所有有時效額度耗盡後才作為備援扣除。
- **達到上限或被限流時還能繼續嗎？** 可以。開啟 Extra Usage 後即不受訂閱上限影響：任一額度觸頂時會無縫切換至 Extra Usage 餘額，任務不中斷，且只扣 Extra Usage，不影響會員額度刷新。
- **未用完的餘額可以留到下個月並累積嗎？** 可以——不會過期且可累積；訂閱失效後仍可使用，但失效期間無法儲值。
- **Extra Usage 支援企業版嗎？** 暫不支援。
- **註銷帳號後餘額會退回嗎？** 請寄信至 [membership@moonshot.ai](mailto:membership@moonshot.ai) 申請退款。
