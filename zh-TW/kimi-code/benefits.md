# Kimi Code 權益

Kimi Code 是 Kimi 會員方案包含的服務，提供程式開發相關支援與功能，協助會員在個人開發流程中更有效率地完成程式設計任務。

> 請注意，此權益僅供個人開發使用，不適用於企業開發情境。如有企業需求，請造訪 [Kimi 開放平台](https://www.platform.moonshot.ai/)。

## 計費

- Kimi Code 使用量**已包含在你的訂閱費用中**——不會額外收費。
- 每次請求都會消耗你 **Kimi Code 專屬額度池**中的額度；不同方案包含的額度數量不同。
- 系統會優先消耗贈送額度，再消耗方案額度。

## 額度更新

額度會以 **7 天**為週期更新：

- 自你的訂閱日（D1）起，每 7 天更新一次額度。
- 更新週期：D1–D7、D8–D14、D15–D21、D22–D28。
- 未使用的額度**不會**結轉至下一個週期。

> 建議妥善規劃每週用量，充分運用你的額度。

## 支援工具

Kimi Code 權益可搭配以下工具使用：

| 工具 | 說明 |
| --- | --- |
| **Kimi Code CLI** | Kimi 官方命令列 AI agent |
| **Claude Code** | Anthropic 的命令列程式設計助理 |
| **Roo Code** | 適用於 VS Code 的 AI 程式設計擴充功能 |

若將你的 Kimi Code API Key 用於上述未列出的平台或工具，可能會被視為誤用，並可能導致存取權受限。為獲得最佳體驗與完整保障，請使用上方列出的支援工具。
