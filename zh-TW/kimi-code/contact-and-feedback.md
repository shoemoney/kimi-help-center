# 聯絡與回饋

## 回饋管道

如果你在使用 Kimi Code 時遇到任何問題，或有建議想提出，可以透過以下管道提供回饋。

### 方式 1：直接在 CLI 中提交回饋

在 Kimi Code CLI 的互動模式中，輸入 `/feedback` 指令即可提交回饋。系統會自動收集你目前的環境資訊，協助你更精確地描述問題。

### 方式 2：GitHub Issues

前往 [Kimi CLI GitHub Issues](https://github.com/MoonshotAI/kimi-cli/issues)，先搜尋是否已有類似問題。若沒有，你可以建立新的 Issue，並詳細描述你遇到的情況。

### 方式 3：透過電子郵件回饋

你也可以寄信至 Kimi Code 團隊信箱 [code@moonshot.ai](mailto:code@moonshot.ai) 回報問題。請盡可能附上以下資訊：

- **問題描述**：清楚說明你遇到的問題，或希望新增的功能
- **重現步驟**：逐步說明如何觸發該問題
- **環境資訊**：作業系統與 Kimi Code CLI 版本（執行 `kimi --version` 查看）
- **錯誤日誌**：若有錯誤訊息，請完整貼上

## 提交回饋前的疑難排解

提交回饋前，建議你先檢查以下事項：

- 是否已更新至最新版 Kimi Code CLI（執行 `kimi --version` 查看）
- 網路連線是否正常，以及是否能存取 `api.kimi.com`
- 你的 API Key 是否有效且尚未過期
- 工作目錄是否正確，以及 Kimi 是否有權限存取相關檔案
