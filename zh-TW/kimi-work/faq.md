# Kimi Work 常見問題

## Kimi Work 和網頁版有什麼差異？

Kimi 網頁版適合快速對話與查詢；Kimi Work 則是為深度工作流程打造的本機 Agent。它能讀取並處理你的本機資料夾、透過 WebBridge 自主瀏覽網頁、在背景執行 Python 程式碼、執行排程任務，是一個系統層級的「數位員工」。

## 存取本機檔案時，Kimi Work 如何保護我的隱私？

你對自己的檔案擁有絕對控制權。Kimi Work 提供三檔權限控制，由你自行選擇授權方式：

- **預設**：常規操作自動執行，Kimi 在修改、覆寫本機檔案或執行程式碼等敏感操作前會請求你的明確授權；
- **手動允許**：操作前先請求授權；
- **全部**：無需授權直接執行。

選擇「手動允許」時，未經你同意不會發生任何操作。

<Callout type="exclamation">
開啟「全部」（全自動）權限後，AI 將直接讀寫檔案、執行程式碼、修改系統設定，也會自動處理原本需要你決定的步驟。這可能會產生：

- 檔案被覆寫、誤刪或損毀；
- 系統設定被更改，導致軟體異常；
- 磁碟加密、分割區或韌體變更，導致裝置受限或無法啟動等問題。

部分操作不可逆，資料可能永久遺失且無法復原。請知悉該模式的風險，謹慎使用並做好資料備份。

開啟「全部」（全自動）權限即視為你知悉並接受上述風險，並授權 AI 自主執行相關操作，基於你的授權所執行操作的結果將由你自行承擔。
</Callout>

## WebBridge（瀏覽器自動化）具體能做什麼？

WebBridge 讓 Kimi 能像人一樣使用瀏覽器。你可以請它查看某個網站的最新資訊並總結，或把歷史股價資料擷取到本機 Excel。它會自主點擊、捲動、擷取資料，替你省下大量手動操作的時間。

## 排程任務能做什麼？電腦休眠時還會執行嗎？

定時任務讓 Kimi 到設定的時間自動執行一段固定的任務，支援每天、每週、每月與永不重複（單次），適合每日簡報、每週監控、定期整理等重複性工作。

在 Kimi Work 桌面端，定時任務在**本地執行**，需要**應用處於開啟狀態**才會執行；電腦休眠、關機或應用關閉期間錯過的觸發**不會在下次開啟時補跑**。因此如需任務在夜間執行，請保持電腦與 Kimi Work 應用處於開啟執行狀態。（相比之下，在 Kimi 中建立的定時任務在雲端執行，不需要保持客戶端開啟。）

更多說明見[定時任務](/features/scheduled-tasks)。
