# Kimi Work 常見問題

## Kimi Work 和網頁版有什麼不同？

Kimi 網頁版很適合快速聊天和查詢；Kimi Work 則是為深度工作流程打造的本機 Agent。它能讀取並處理你的本機資料夾，透過 WebBridge 自主瀏覽網頁，在背景執行 Python 程式碼，並執行排程任務。它就像一位系統層級的數位員工。

## 存取本機檔案時，Kimi Work 如何保護我的隱私？

你對自己的檔案擁有完全控制權。Kimi Work 提供權限控管，你可以自行選擇授權方式：

- **請求權限**：執行操作前先請求授權 —— 當 Kimi 要修改、覆寫你的本機檔案，或在其中執行程式碼時，會先提示你明確授權；
- **全部允許**：不再詢問授權，直接執行。

選擇「請求權限」後，未經你同意，任何操作都不會發生。

## WebBridge（瀏覽器自動化）究竟能為我做什麼？

WebBridge 讓 Kimi 能像人一樣使用瀏覽器。你可以請它查看某個網站的最新消息並整理摘要，或把歷史股價資料擷取到本機 Excel。它會自主點擊、捲動並擷取資料，替你省下數小時的手動作業。

## 我可以用排程任務做什麼？電腦休眠時也會執行嗎？

內建的 Cron 排程器支援 LLM Agent 呼叫、Python/Shell 執行等功能。你可以設定每日、每小時或依條件觸發任務。若要確保任務能在夜間順利執行，只要在設定中開啟「保持電腦喚醒」選項即可。
