# 目標模式

目標模式支援 Agent 圍繞單一目標連續工作（最長可達 24 小時），相當於一位會持續推進任務的專案助理。

## 運作原理：Loop 循環機制

- **以目標為導向的自主循環**：你只需設定一個明確的終點，Kimi 便會自動進入持續循環，無需人工介入，Agent 自主推進直到達成目標。
- **策略的自我演進**：執行過程中，Agent 會持續比對目前狀態與目標的差距，不斷收斂並演化思路。
- **目標不漂移，狀態不堆積**：Agent 會先從目標中抽取出「怎樣才算成功」的判斷標準，並提供穩定的追蹤能力；模型每一步都對著同一個終點做決策，只根據真實的現況執行，錨點不動，不會偏離。
- **人在 Loop 中**：AI 的運行過程完全透明，你可隨時中斷循環；一旦發現方向偏離或鑽牛角尖，只要手動調整目前狀態或補充指令，即可調整方向讓 Agent 繼續執行。

## 啟用方式

1. 開啟最新版 Kimi 電腦用戶端，在左側邊欄切換至「Work」模式；
2. 點擊輸入框左下角的「+」號，選擇「目標」；
3. 輸入一個需要長時間才能完成的目標，Kimi 便會開始持續推進任務。

## 適用任務

目標模式最適合同時滿足「目標清楚、路徑不確定、需要多輪嘗試、結果能驗證」四個條件的任務，例如：遷移程式碼、整理海量資料、研究復現論文結果、建立個人知識庫等長任務。

<Callout type="tip">
範例：Kimi Work 可花幾個小時，將 80 篇論文、2,000 頁 PDF、100 萬字自動整理成 Obsidian 知識庫。
