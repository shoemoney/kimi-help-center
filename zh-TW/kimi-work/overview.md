# Kimi Work 概覽

Kimi Work 是一款面向知識工作者的通用型本機 Agent，可在 Kimi 桌面用戶端（Mac / Windows）的「工作」模式中使用。

它把 Kimi Code 已在工程場景中驗證的 Agent 能力，帶到知識工作者日常熟悉的桌面互動中：你不需要開啟終端機、撰寫命令，也不必設定環境。只要用自然語言描述目標，Kimi Work 就能拆解任務、平行執行步驟、呼叫工具、使用瀏覽器、建立與整理資料夾，並在你的電腦上交付文件、試算表、簡報等工作成果。

Kimi Code 服務的是撰寫程式碼的開發者；Kimi Work 則服務知識工作者，主要涵蓋日常工作中常見的資訊搬運、檔案整理、資料分析與報告產出等場景。

## 核心能力

- **本機 Agent 核心**：以 Kimi Code 作為核心，提供本機 Agent 的基礎能力，包括安裝與使用技能，以及執行排程任務。
- **專業技能**：繼承線上 Kimi Agent 的專業技能，例如網站建置與 PPT 製作，同時支援推薦第三方技能及上傳本機技能。
- **外掛與專業資料庫**：可在 Kimi 中使用 Canva、Notion、WPS 等外部應用程式與服務，並連接金融、研究、法律等領域的專業資料庫。
- **Kimi WebBridge**：內建的瀏覽器操作方案，能像真人一樣使用瀏覽器。
- **Agent Swarm**：會依據任務複雜度，自主組建最多 300 個 sub-agents 的團隊，以處理更複雜、執行時間更長的任務。
- **長時程任務執行**：由 Kimi K2.6 模型的長時程任務執行能力驅動，支援 13 小時連續編碼、300 個 sub-agents 平行工作，以及超過 4,000 次自主工具呼叫。

## 介面與互動

- 用戶端提供「工作」與「聊天」兩種模式。工作模式的側邊欄包含：新任務、技能、排程任務、WebBridge、專案與聊天。
- 在輸入框輸入「/」可快速使用技能，輸入「@」可加入脈絡。
- 提供權限控制，你可以選擇授權方式：
  - **請求權限**：執行動作前先請求授權
  - **全部允許**：不再詢問授權，直接執行
- 可在「Agent」與「Agent Swarm」兩種執行模式之間切換。

## 版本說明

Kimi Work 於 2026 年 6 月 3 日推出，目前仍處於 Beta 階段，並持續快速迭代。它已陸續新增檔案預覽、自動儲存草稿、目標模式與外掛中心等功能。目前測試重點集中在任務拆解、多 Agent 平行協作、工具呼叫、瀏覽器操作、本機檔案處理，以及長篇交付物生成；執行穩定性、交付品質與使用者體驗都會依據 Beta 使用者的回饋持續改善。
