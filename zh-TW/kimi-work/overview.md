# Kimi Work 產品介紹

Kimi Work 是一款面向知識工作者的通用型本機 Agent，可在 Kimi 電腦用戶端（Mac / Windows）的「Work」模式中使用。

它把 Kimi Code 已在工程場景中驗證的 Agent 能力，帶到知識工作者日常熟悉的桌面互動中：你不需要開啟終端機、撰寫命令，也不必設定環境。只要用自然語言描述目標，Kimi Work 就能拆解任務、平行執行、呼叫工具、使用瀏覽器、建立與整理資料夾，並在你的電腦上交付文件、試算表、PPT 等工作成果。

Kimi Code 服務撰寫程式碼的開發者；Kimi Work 則服務知識工作者，主要涵蓋資訊搬運、檔案整理、資料分析與報告產出等日常工作場景。

## 核心能力

- **本機 Agent 核心**：以 Kimi Code 為核心、搭載 Kimi K3 模型，提供本機 Agent 的基礎能力，包括安裝與使用技能（Skill）、執行排程任務等。
- **專業 Skills**：繼承線上版 Kimi Agent 的網站建置、PPT 等專業 Skills，也支援推薦第三方技能與上傳本機技能。
- **外掛與專業資料庫**：可在 Kimi 中使用外部應用程式與服務，例如 Canva、Notion、WPS 等，也可連接金融、研究、法律等領域的專業資料庫。
- **小組件（Widgets）**：在對話中由模型即時生成的可互動頁面，可連接本機資料或外部外掛持續更新，讓答案更直觀、更好理解。詳見[小組件](/kimi-work/widgets)。
- **看板（Dashboard）**：將你最關心的小組件匯總到一個持久的個人化視圖，圍繞主題、專案或目標組織，隨時查看和管理。詳見[看板](/kimi-work/dashboard)。
- **Kimi WebBridge**：內建瀏覽器操作方案，能像真人一樣使用瀏覽器。
- **Agent 集群**：可依任務複雜度，自主建立最多包含 300 個子 Agent 的團隊，處理更複雜、耗時更久的任務。
- **長程任務執行**：依託 Kimi K3 模型的長程任務執行能力，可持續數十小時自主工作，並完成數千次自主工具呼叫。

## 介面與互動

- 用戶端分為「Work」與「Chat」兩種模式。Work 模式側邊欄包含：新增任務、看板、外掛、技能、排程任務、WebBridge、專案、對話。
- 在輸入框輸入「/」可快速使用技能，輸入「@」可加入上下文。
- 提供權限控制，你可自行選擇授權方式：
  - **請求權限**：操作前先請求授權
  - **全部允許**：無需授權直接執行
- 支援在「Agent」與「Agent 集群」兩種執行模式之間切換。

## 版本說明

Kimi Work 於 2026 年 6 月 3 日推出，目前處於 Beta 測試階段並保持高頻迭代，已陸續新增檔案預覽、自動儲存草稿、目標模式、外掛中心、小組件與看板等功能。自 3.1.0 版本起，Kimi Work 搭載 Kimi K3 模型。目前階段的測試重點為任務拆解、多 Agent 平行、工具呼叫、瀏覽器操作、本機檔案處理與長交付物生成等方向；執行穩定性、交付品質與使用者體驗將持續依內測使用者的回饋優化。
