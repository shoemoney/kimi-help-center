# 外掛中心

Kimi Work 外掛中心匯集 Kimi 官方提供的專業資料庫外掛和精選外部應用外掛，幫助你在對話中快速取得專業資訊、操作常用工具，或擴充 Kimi 的任務能力。

除了使用外掛中心提供的外掛，你也可以在 Kimi Work 中建立和測試個人自訂外掛，接入更多符合自身工作需求的工具和服務。

## 內建專業資料庫外掛

Kimi Work 內建金融、法律、學術等領域的專業資料庫外掛，為專業人士提供專業、可信的資料來源，涵蓋國內與全球資料：

- **金融資料**：Wind 萬得金融數據服務、恆生聚源金融數據、標普全球市場財智、全球金融資料庫、IMF（國際貨幣基金組織）資料庫、同花順等
- **工商 / 法律**：天眼查、華宇元典等

## 精選外部應用外掛

外掛中心提供官方精選的外部應用外掛，包括：

- **辦公協作類**：百度網盤、釘釘、飛書、WPS
- **設計類**：Canva
- **筆記類**：Notion
- **網站開發類**：Cloudflare
- **其他**：Kimi Computer Use（AI 控制桌面進行系統層級操作）、GitHub、Neon（雲端 PostgreSQL 資料庫平台）、Supabase（開源後端與資料庫平台）等

安裝外掛後，Kimi Work 可以直接呼叫相關應用程式和服務。你只需用一句話描述任務，Kimi 就能根據需求選擇合適的外掛，減少重複操作，提升工作效率。

## 外掛啟用方式

1. 開啟最新版 Kimi 電腦用戶端，在左側邊欄切換至「Work」模式，點擊「外掛」進入外掛中心；
2. 在「已安裝」或「精選外掛」中找到需要使用的外掛並安裝；
3. 在對話框輸入斜線「/」，選擇要呼叫的外掛即可使用。

## 在 Kimi Work 中自訂外掛

除了使用外掛中心中的官方外掛，你還可以透過 Plugin Builder 在 Kimi Work 中建立個人自訂外掛，將自己的工作流程、專業知識或外部服務接入 Kimi。

建立完成後，可以在「外掛」→「個人」中安裝外掛，並在新會話中透過斜線「/」喚起和測試。

具體建立步驟和使用說明，請參考 [Plugins](https://www.kimi.com/help/features/plugins) 文章中的「如何在 Kimi Work 中自訂外掛」部分。
