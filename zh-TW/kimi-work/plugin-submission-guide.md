# 建立與提交外掛程式

若您希望將產品或服務與 Kimi 連接，讓使用者能在對話中使用其功能，請遵循本指南來建立、測試並提交外掛程式至官方 Kimi 外掛程式市集。

## 什麼是 Kimi 外掛程式？

Kimi 外掛程式將您的產品與 Kimi 連接。它能協助 Kimi 判斷何時需使用您的產品，並提供所需的工作流程或工具來幫助使用者。外掛程式可包含：

- **僅限技能**：專為您產品或使用情境設計的可重複使用工作流程。
- **僅限 MCP**：透過 MCP 伺服器向 Kimi 開放的工具與服務。
- **技能與 MCP**：結合產品工具與能幫助 Kimi 有效使用它們的工作流程。

## 開始前的準備

首先，<a class="leading-7 text-(--Colors-KMBlue) decoration-(--hc-pill-border) decoration-2 transition-colors hover:text-(--Colors-KMBlue-hover)" href="https://www.kimi.com/products/kimi-work">下載並安裝 Kimi Work</a>。請準備以下項目：

- 外掛程式名稱、描述與標誌
- 使用者應能以自然語言完成的核心任務
- MCP 伺服器 URL（如適用）

<Callout type="warning">
若外掛程式標誌包含第三方產品、品牌或商標，請先聯繫相關權利持有者並取得必要的書面授權後再提交。
</Callout>

## 步驟 1：建立與測試外掛程式

1. 開啟 Kimi Work，在對話中輸入「/」並選擇 **Plugin Builder**。
2. 描述外掛程式並提供您準備的資訊。若您已有 Codex、Claude 或其他平台的外掛程式，請提供其檔案或專案 URL 並依指示進行轉換。

3. 前往 **Plugins** → **Personal**，找到該外掛程式並安裝。

4. 在新的對話中測試核心功能，包含正常與邊緣案例。請保留至少三個具代表性的測試提示語。
5. 遵循 Plugin Builder 的指示取得完整的外掛程式 ZIP 檔案。

對於 MCP 支援的外掛程式，請同時測試其驗證流程：

- **無驗證**：使用者安裝後可立即使用外掛程式。
- **OAuth**：首次安裝時應開啟第三方授權頁面。
- **CLI 驗證**：安裝時不會啟動授權程序。使用者首次呼叫外掛程式時，需在對話中完成授權。成功授權後，通常不需在其他對話中再次授權。

## 步驟 2：提交申請

建立並測試外掛程式後，填寫 [Kimi 外掛程式提交表單](https://moonshot.feishu.cn/share/base/form/shrcnZcnxlNJlbw845KoVgjEhkh) 並上傳外掛程式 ZIP 檔案。

表單要求以下項目：

| 項目 | 需求 |
| --- | --- |
| 外掛程式名稱、描述與 ZIP 檔案 | 必填 |
| 外掛程式類型 | 僅限技能、僅限 MCP 或混合型 |
| MCP 驗證 | 僅限 MCP 與混合型外掛程式需提供 |
| 目標區域 | 中國大陸、海外或兩者 |
| 亮點與推薦測試提示語 | 至少三個測試提示語 |
| 聯合行銷意願與素材 | 素材為選填，僅在討論聯合行銷時需要 |
| 授權與合規狀態 | 需說明需進一步討論的事項 |
| 聯絡電子郵件 | 用於審核更新與額外資訊請求 |
| 公司或團隊、相關網站與備註 | 選填 |

<Callout type="warning">
請勿在表單或外掛程式 ZIP 中包含密碼、token、API 金鑰、私鑰或其他機密資訊。若使用者需自行提供金鑰，僅需說明如何取得與設定。
</Callout>

## 後續流程

Kimi 團隊將審核申請與外掛程式 ZIP 檔案。若外掛程式通過審核，或我們需要更多資訊或修改，將透過您提供的電子郵件聯繫您並分享後續步驟。

## 常見問題

### 我可以提交沒有 MCP 伺服器的外掛程式嗎？

可以。僅限技能的外掛程式是支援的。請選擇 **僅限技能** 作為外掛程式類型。

### 我可以提交 Codex、Claude 或其他平台的外掛程式嗎？

可以。在步驟 1 中，請向 Plugin Builder 提供現有外掛程式檔案或專案 URL，並依指示進行轉換。在提交產生的 ZIP 檔案前，請先在 Kimi Work 中安裝並測試轉換後的外掛程式。

### 支援哪些 MCP 驗證方法？

目前支援以下三種方法：

- **無驗證**：使用者安裝後可立即使用外掛程式，無需登入或完成任何其他身分驗證。
- **OAuth**：使用者首次安裝外掛程式時，會自動重新導向至第三方產品的授權頁面。授權後即可使用外掛程式。
- **CLI 驗證**：安裝時不會啟動授權流程。使用者首次在對話中呼叫外掛程式時，需依對話中顯示的指示完成授權。成功授權後，通常不需在其他對話中再次授權。

請測試與您外掛程式實際驗證方法相符的流程。若 OAuth 外掛程式在首次安裝時未重新導向，或 CLI 驗證外掛程式重複要求使用者授權，請在提交申請前檢查 MCP Server 的驗證設定，並在 **其他備註** 中描述問題。

### OAuth 授權流程是什麼樣子？

對於啟用 OAuth 的 MCP Server，Plugin Builder 會從 MCP Server URL 識別相關授權資訊。建立外掛程式後，使用者首次安裝時會被帶往第三方產品的授權頁面。

### 若我想與 Kimi 探討更廣泛的合作怎麼辦？

請先完成本指南中的外掛程式建立、測試與提交流程。若您希望探討外掛程式上架之外的其他合作形式，請在 **其他備註** 中簡要說明您的提案。Kimi 團隊將視情況與您聯繫。

### 提交申請保證能上架嗎？

不保證。Kimi 團隊會評估外掛程式的功能、使用者體驗、安全性、服務可靠性與相關授權狀態。
