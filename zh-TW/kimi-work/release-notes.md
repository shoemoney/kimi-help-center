# 發布日誌

本文記錄 Kimi Work 的版本更新內容，包括新增功能、變更與修復，並持續更新。最新版本下載：[kimi.com/products/kimi-work](https://www.kimi.com/products/kimi-work)

## 3.2.0（2026-08-19）

**新增**

- 新增 Agent 內建瀏覽器：瀏覽器分頁綁定對話並歸入預覽區，Agent 可直接操作瀏覽器完成點擊、輸入等操作，Mac 端還支援從本機 Chrome 匯入 Cookie 複用現有登入狀態（預設關閉，可在設定中開啟）
- 16 語言本地化：用戶端語言從中英雙語擴展到 16 種語言

**變更**

- Kimi WebBridge 外掛化：真實瀏覽器控制改為外掛形態，預設關閉、可在設定中開啟
- 看板區的列表頁取消，改為透過頂部分頁欄切換
- 預覽區新增看板類型，可在對話預覽區開啟看板，支援多看板並行開啟

**修復**

- 訊息串流渲染升級：長回覆輸出更平順
- 修復了一些 Bug，最佳化了一些互動與穩定性

## 3.1.10（2026-08-16）

**修復**

- 修復了 Windows 端部分用戶的升級閃退問題

## 3.1.9（2026-08-15）

**新增**

- 個人外掛市場上線：外掛市場新增「個人外掛」板塊，可瀏覽、安裝個人開發者外掛

**修復**

- 修復串流 Markdown 內容偶發不重新整理等問題
- 修復了一些 Bug，最佳化了一些互動與穩定性

## 3.1.8（2026-08-11）

**新增**

- 訊息記錄導覽：長對話右側新增訊息導覽列，可快速切回過往訊息
- 對話分支：可從任意回合開出新分支繼續探索，繼承原對話的聊天記錄
- 訊息編輯重發：支援修改上一則提問後重新生成
- 專案資料夾：對話可移入／移出專案，專案可置頂到側邊欄固定區
- 檔案編輯透明化：Agent 修改檔案後產生 diff 摘要卡片，可逐行檢視變更並一鍵還原；工作區檔案隨磁碟變化自動重新整理
- 技能探索與建立：Work 內可探索並建立自訂技能，支援技能搜尋
- 固定至桌面的看板元件新增置頂開關

**變更**

- 新開的獨立對話視窗支援 Chat 功能
- 輸入框內，過長的使用者訊息新增摺疊功能

**修復**

- 修復 Windows 端 PDF 檔案連結預覽問題；深色模式下開啟 Work 設定不再閃白；Word 剪貼簿貼上還原為文字而非圖片附件
- 修復了一些 Bug，最佳化了一些互動與穩定性

## 3.1.7（2026-08-05）

**新增**

- 支援訊息級用戶回饋：可對助理回覆中的具體訊息按讚或倒讚

**變更**

- 固定至桌面的看板元件取消強制置頂

**修復**

- 修復了一些 Bug，最佳化了一些互動

## 3.1.6（2026-07-29）

**新增**

- PPT 投影片編輯器上線：直接在工作台內開啟編輯，改完即所得
- 支援預覽區檔案與瀏覽器的截圖標註，完成後可直接發給 Agent 修改
- 支援 Windows 端儲存磁碟遷移：Work 資料可遷移到其他磁碟
- Windows 端安裝支援自選安裝位置

**變更**

- 最佳化了部分 token efficiency 問題

**修復**

- 修復了一些 Bug，最佳化了一些互動
