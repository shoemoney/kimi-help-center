# 發布日誌

本文記錄 Kimi Work 的版本更新內容，包括新增功能、變更與修復，並持續更新。最新版本下載：[kimi.com/products/kimi-work](https://www.kimi.com/products/kimi-work)

## 3.2.7（2026-09-10）

**新增**

- 截圖能力大升級：Launcher 截圖支援捲動長截圖；截圖編輯內一鍵 OCR 提取圖中文字；截圖可固定為置頂小窗釘在桌面
- 對話設定注入：Work 新對話自動攜帶你的對話設定（系統提示詞）
- 支援將檔案拖曳到視窗任意位置加入附件，支援資料夾拖曳
- 新增網站部署插件，安裝後本機網站專案可一步雲端部署

**變更**

- Windows 開機自啟改為僅常駐系統匣，不再彈出主視窗
- 「自動操控」設定流程優化：安裝與登入引導更清晰
- Markdown 表格全新設計，超寬表格可橫向捲動
- 提醒中心支援一鍵全部已讀
- 遠端控制訊息分段展示，子 Agent 卡與產物卡對齊桌面形態

**修復**

- 無麥克風裝置自動禁用語音輸入，拔麥即停
- 修復插件上傳功能遺失問題
- 郵件 / 電話外鏈無法開啟時明確告知，不再靜默失敗
- 修復額度耗盡時排程任務頁卡死的問題
- 桌面寵物效能與拖曳修復
- 修復了一些 Bug，最佳化了一些互動與穩定性

## 3.2.1（2026-08-21）

**新增**

- 新增全域喚起 Launcher：支援透過全域快速鍵隨時隨地喚起桌面懸浮膠囊輸入框
  - 喚起時自動帶入 Finder / 檔案總管中目前選取的檔案，支援貼上圖片、加入附件與拖曳截圖
  - 輸入「/」可呼出外掛與技能選單（支援拼音搜尋），並可選擇工作區
  - 按住快速鍵即可語音輸入，提交後收起為迷你膠囊，可一鍵跳回主應用查看回答
- 新增訊息佇列：Agent 回答期間可繼續傳送訊息，新訊息自動排隊，支援拖曳重排、編輯、刪除與詳情預覽
- Work 輸入框支援語音聽寫：點擊麥克風或按住快速鍵即可開始聽寫，支援中英混合辨識

**變更**

- 訊息通知邏輯更新：可在設定裡切換訊息通知規則

**修復**

- 最佳化待機能耗，減少應用閒置時的背景資源佔用
- 修復了 macOS 端 Dock 圖示消失的問題
- 修復了一些 Bug，最佳化了一些互動與穩定性

## 3.2.0（2026-08-19）

**新增**

- 新增 Agent 內建瀏覽器：瀏覽器分頁綁定對話並歸入預覽區，Agent 可直接操作瀏覽器完成點擊、輸入等操作，Mac 端還支援從本機 Chrome 匯入 Cookie 複用現有登入狀態（預設關閉，可在設定中開啟）
- 16 語言本地化：用戶端語言從中英雙語擴展到 16 種語言

**變更**

- Kimi WebBridge 外掛化：真實瀏覽器控制改為外掛形態，預設關閉、可在設定中開啟
- 看板區的列表頁取消，改為透過頂部分頁欄切換
- 預覽區新增看板類型，可在對話預覽區開啟看板，支援多看板並行開啟

**修復**

- 訊息串流渲染升級：長回覆輸出更平順
- 修復了一些 Bug，最佳化了一些互動與穩定性
