# 典型應用情境

## 金融情境：投資策略分析

讓 Kimi Work 研究巴菲特近 10 年的持倉，總結其投資策略，並生成一個「巴菲特投資 Skill」；安裝該 Skill 後，接入 Kimi 專業財經資料源，分析你的持倉與投資策略是否符合巴菲特的價值投資策略。

**工作流程**：研究 ▶ 生成 Skill ▶ 安裝 Skill ▶ 使用 Skill 並呼叫專業金融資料源進行分析

## 研究情境：資料處理與論文輔助

讓 Kimi Work 化身城市運算研究員，清理本機電腦上的模擬資料集，總結核心特徵規律並繪製學術圖表，再依據清理後的資料與圖表輔助完成論文。

**工作流程**：本機資料清理 ▶ 圖表繪製 ▶ 輔助完成論文

## 辦公情境：市場研究與方案輸出

讓 Kimi Work 讀取本機資料夾中的產品方案、工業設計原型圖及 GTM 方案，並呼叫 WebBridge 使用瀏覽器登入已訂閱的資料儀表板網站進行研究；深入研究市場大盤、出海法規、競品經營現況，結合自研儀表板分析 2,400+ 則使用者評論，生成一份 128 頁的跨境電商市場分析報告；再呼叫專用 PPT Skill，將報告內容與本機設計原型一鍵轉換成簡報。

**工作流程**：本機檔案讀取 ▶ 本機瀏覽器查看訂閱資料庫 ▶ 深度報告生成 ▶ 呼叫 PPT Skill ▶ 客戶方案輸出
