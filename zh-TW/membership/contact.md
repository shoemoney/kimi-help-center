# 聯絡我們

需要協助？以下是聯絡我們的方式。

## 帳務與會員支援

**電子郵件：** membership@moonshot.ai

適合處理：

- 購買後額度（點數）未顯示
- 付款或扣款問題
- 方案升級、降級或取消
- 發票申請

付費會員享有優先回覆。請附上你的帳號電子郵件與相關螢幕截圖，協助我們更快處理問題。

## 一般支援

**電子郵件：** support@moonshot.ai

適合處理：

- 產品功能問題
- 使用 Kimi 時遇到的技術問題
- 帳號相關問題（非帳務）
- 功能建議與意見回饋

## API 服務支援

**電子郵件：** api-service@moonshot.ai。
你也可以前往 [Kimi OpenPlatform Community](https://forum.moonshot.ai/)

適合處理：

- API 相關問題
- 使用 Kimi API 時遇到的技術問題
- 功能建議與意見回饋

## 產品內意見回饋

你也可以直接在 Kimi 內提交意見回饋：

- **網頁版：** 點擊左下角的 **意見回饋** 按鈕，描述你的問題並送出。
- **行動版：** 前往 **個人檔案 → 說明與意見回饋 → 提交意見回饋**。

透過產品內回報時，系統會自動附上你的裝置與帳號情境資訊，協助我們更快診斷問題。
