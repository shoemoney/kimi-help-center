# 會員方案總覽

Kimi 提供四種會員等級，從日常生產力到重度使用者工作流程，都能隨你的需求彈性升級。

所有 Kimi 會員功能共用同一個 credit（點數）池。網站部署、Deep Research、Slides、Kimi Code、Kimi Work、Kimi Claw 等會員功能都會消耗會員 credit（點數）。在 Chat 中，K2.6 對所有使用者免費，且不會消耗 credit（點數）。

## 方案比較

| 功能 | Moderato $19/月 | Allegretto $39/月 | Allegro $99/月 | Vivace $199/月 |
| --- | --- | --- | --- | --- |
| Agent credit（點數）* | 60 | 150 | 360 | 720 |
| Agent 並行任務數 | 2 | 2 | 4 | 4 |
| Agent 速度優先級 | 4× | 4× | 4× | 4× |
| Agent Swarm (beta) | 25 次 | 50 次 | 120 次 | 240 次 |
| Agent Swarm 並行子任務數 | 2 | 4 | 4 | 8 |
| Kimi Code credit（點數） | 1× | 5× | 15× | 30× |
| Kimi Claw | — | ✅ | ✅ | ✅ |
| Kimi Claw Android | — | ✅ | ✅ | ✅ |
| 專業資料庫 | 2,000 次呼叫 | 5,000 次呼叫 | 12,000 次呼叫 | 24,000 次呼叫 |

\* 約略值依典型任務的 token 消耗量估算。每月 credit（點數）會換算為同一功能可執行的等效任務數；僅供參考。

<Callout type="tip">
同一功能可使用全部 credit（點數）額度
</Callout>

## 計費方式

- **credit（點數）池** — 所有會員功能（網站部署、Deep Research、Slides、Kimi Code、Kimi Work、Kimi Claw、K3 與 K3 Swarm）共用同一個 credit（點數）池，並依 token 用量計量。任一功能用完 credit（點數），都會影響其他功能可用額度。
- **Kimi Code rate limit（速率限制）** — Kimi Code 另有 5 小時／每週的 rate limit（速率限制），此限制僅適用於 Kimi Code，不會影響其他會員功能。
- **每月重置** — credit（點數）會在每個計費週期開始時重置。
