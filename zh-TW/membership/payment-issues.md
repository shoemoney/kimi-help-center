# 付款問題

付款或帳務遇到問題？以下整理常見情況與解決方式。

## 已完成註冊卻尚未成為會員？

如果你已完成結帳流程，但會員資格尚未啟用：

| 問題 | 解決方式 |
|-------|----------|
| **授權 ≠ 扣款** | 部分付款方式需要額外完成授權步驟。請查看銀行或信用卡帳單，確認款項是否已實際扣款入帳 |
| **處理延遲** | 付款可能需要幾分鐘才會完成處理。請稍候片刻後重新整理頁面 |
| **帳號不一致** | 請確認你登入的是結帳時使用的同一個 Kimi 帳號 |

<Callout type="info">
如果款項已扣款入帳，但會員資格仍未啟用，請將付款收據寄至 **membership@moonshot.ai**。
</Callout>

## 付款失敗？

常見原因與處理方式：

| 原因 | 處理方式 |
|-------|-----|
| **餘額不足** | 請確認你的帳戶或卡片有足夠餘額 |
| **卡片額度限制** | 銀行可能設有單筆或每日交易限額。請聯絡銀行，或改用其他付款方式 |
| **網路問題** | 請檢查網路連線後再試一次 |
| **付款服務商維護中** | 服務商有時會暫時無法使用。請稍後再試 |
| **防詐騙保護** | 銀行可能基於安全原因阻擋交易。請聯絡銀行授權此筆扣款 |

<Callout type="info">
如果問題持續發生，請將錯誤畫面截圖寄至 **membership@moonshot.ai**。
</Callout>

## 出現非預期扣款？

如果你看到來自 Kimi、但不認得的扣款：

1. **檢查訂閱狀態** — 登入 Kimi，查看目前啟用中的訂閱。你可能有一個已忘記的自動續訂方案
2. **試用期轉為付費** — 如果你曾開始免費試用，且未在試用結束前取消，系統會自動將其轉為付費訂閱
3. **查看付款授權** — 檢查你的 Apple ID、Google Play 或卡片設定，確認是否有 Kimi 的定期扣款
4. **需要時取消** — 請參閱[取消訂閱](/membership/membership-cancel-subscription)，以停止日後扣款

<Callout type="warning">
如果你認為這筆扣款未經授權，請立即寄信至 **membership@moonshot.ai**，我們會協助調查。
</Callout>
