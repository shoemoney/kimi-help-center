# 價格詳情

Kimi 提供四種會員方案，每種都可選擇月繳或年繳。選擇年繳，每年最高可省 **$480/年**。

## 方案一覽

| 功能 | Moderato（$19/月） | Allegretto（$39/月） | Allegro（$99/月） | Vivace（$199/月） |
|---------|-------------------|---------------------|-------------------|-------------------|
| Agent credit* | 60 | 150 | 360 | 720 |
| Agent 並行任務數 | 2 | 2 | 4 | 4 |
| Agent 速度優先級 | 4× | 4× | 4× | 4× |
| Agent Swarm（beta） | 25 次 | 50 次 | 120 次 | 240 次 |
| Agent Swarm 並行子任務數 | 2 | 4 | 4 | 8 |
| Kimi Code credit | 1× | 5× | 15× | 30× |
| Kimi Claw | — | ✅ | ✅ | ✅ |
| Kimi Claw Android | — | ✅ | ✅ | ✅ |
| 專業資料庫 | 2,000 次呼叫 | 5,000 次呼叫 | 12,000 次呼叫 | 24,000 次呼叫 |

\* 約略值，依典型任務的 token 消耗量估算。每月 credit 會換算為同一功能的等效任務數；僅供參考。

## 月繳與年繳價格

| 方案 | 月繳 | 年繳（折合每月） | 年費總額 | 可省金額 |
| --- | --- | --- | --- | --- |
| Moderato | $19/月 | $15/月 | $180/年 | $48/年 |
| Allegretto | $39/月 | $31/月 | $372/年 | $96/年 |
| Allegro | $99/月 | $79/月 | $948/年 | $240/年 |
| Vivace | $199/月 | $159/月 | $1,908/年 | $480/年 |

## credit 分配

所有 Kimi 會員功能共用同一個 credit 池，並依 token 使用量計量。Kimi Code 另有專屬的 5 小時／每週 rate limit，僅適用於 Kimi Code，不影響其他功能。在 Chat 中，K2.6 免費使用，不會消耗 credit。較高級方案包含更大的 credit 池，可支援更頻繁、更複雜的工作流程。詳情請參閱 [credit 更新與使用規則](/membership/update-rules)。
