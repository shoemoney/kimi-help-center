# 額度更新與使用規則

<Callout type="info">
Agent 系列與其他 Kimi 會員功能共用同一個額度池；Kimi Code 則擁有獨立的額度池。額度依實際使用量消耗。
</Callout>

## 什麼是共用額度池？
Kimi 會員權益的各項功能共用一個可在各處使用的額度池。Agent 系列與其他 Kimi 功能都會從中扣用額度：
| 功能 | 說明 |
|---------|-------------|
| **Agent 任務** | 網站、文件、簡報、試算表、deep research |
| **Kimi Claw** | 你的個人雲端部署 AI 助理 |
| **其他功能** | 圖片生成等更多功能 |

> **K2.6**：使用 K2.6 模型對話不消耗額度
> **Kimi Code**：AI 程式輔助助理（獨立額度池）

<Callout type="tip">
這表示你可以依自己的需求，在共用池中自由分配額度——這個月多用於研究，下個月多用於文件。K2.6 不消耗額度。
</Callout>

## 額度如何計算？
額度會依任務處理的 token 數量消耗。輸入與輸出越長，使用的 token 就越多。

<Callout type="info">
**免費方案使用者的粗略參考**：
- 生成一份簡單的簡報 ≈額度的 1–2%
- 執行一份 deep research 報告 ≈ 5–10%
- 撰寫一段程式碼片段 ≈ 0.5–2%
較高階的方案會提供按比例更大的額度池。
</Callout>

## 額度更新規則
| 規則 | 說明 |
|------|-------------|
| **週期** | 月繳與年繳訂閱者都會以**每月**為週期獲得額度 |
| **到期** | 未使用的額度會在每個週期結束時到期，不會累積到下個週期，也不能兌換現金 |
| **限制** | 個別任務可能受到 UI 所示的 5 小時與 7 天 concurrency（併發）限制 |

## 額度用完時
- 已在進行中的任務會正常完成
- 新任務會顯示「額度不足」提示

**你可以選擇**：

- 等待下一個帳單週期自動更新額度
- 升級至更高階方案，以取得更大的每月額度
## 額度究竟如何更新？
1. **依週期更新** ——額度會在你的訂閱週年日更新，而不是依日曆月份
2. **不累積** —— 剩餘額度會歸零，然後重新發放完整額度
3. **範例** —— 如果你在 12 月 1 日下午 3:00 訂閱，額度會在 1 月 1 日下午 3:00 更新

<Callout type="info">
**系統錯誤**：如果任務因系統問題失敗，請使用 👎 按鈕回報並申請退還額度。
</Callout>
