# 如何聯絡 Kimi 支援？

請依照你的問題類型選擇合適管道，讓我們能更快協助你。

## 人工客服（WeCom）

追蹤 WeChat 官方帳號「**月之暗面Kimi**」，再點選底部選單中的「**聯絡我們**」→「**聯絡客服**」，即可找到官方 WeCom 人工客服團隊。

## 電子郵件支援

| 問題類型 | 電子郵件 |
|---|---|
| **付費會員問題**（未收到會員權益、付款扣款異常、升級或降級、發票／invoice 等） | membership@moonshot.ai |
| **一般問題**（產品功能諮詢、技術問題、非付費帳號問題、功能建議） | support@moonshot.ai |
| **帳號申訴／投訴與檢舉** | support@moonshot.ai |
| **Kimi API 開發者支援** | 登入 [Kimi Open Platform (localize)](https://platform.kimi.ai/) 查看支援聯絡方式與開發者社群 |

<Callout type="tip">
寄信給我們時，請附上你的帳號資訊（註冊手機號碼或電子郵件地址）以及問題截圖。付費會員來信會優先處理，這也能協助我們更快定位問題。
</Callout>

## 產品內意見回饋

你也可以直接在 Kimi 內提交意見回饋。系統會自動帶入你的裝置與帳號資訊，協助我們進一步查明問題：

- **Web**：點選左下角「帳號 → 使用者回饋 → 說明與回饋」。
- **Mobile App**：前往「帳號 → 設定 → 意見回饋」。

## 回覆品質回饋

如果你對某則回覆不滿意，請點選回覆下方的「👎」，並簡要說明問題類型與具體情況。你的回饋能幫助我們持續改進。

<Callout type="info">
會員相關問題也可參考[會員問題聯絡資訊](/membership/membership-contact)。媒體採訪請寄信至 pr@kimi.com。
</Callout>
