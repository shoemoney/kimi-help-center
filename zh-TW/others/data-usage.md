# 對話資料會用於模型訓練嗎？

在經安全加密技術處理、嚴格去識別化且無法重新識別特定個人的前提下，平台可能會將使用者的輸入資料、指令及生成回覆用於模型訓練，以將模型效果和產品體驗最佳化。

如果你不希望對話資料用於訓練，可以透過 [support@moonshot.ai](mailto:support@moonshot.ai) 聯繫客服並提出要求；我們將在驗證您的身分後，停止將您的內容用於模型訓練。
