# 如何選擇：K2.6 / K3 / K3 Cluster、思考強度與 Agent

Kimi 會依照你的問題自行判斷是否需要連網，因此你不必手動切換。你需要選擇的是**模型**與**思考強度**；處理複雜任務時，也可以使用 **Agent** 與 **Agent Cluster**。

## 三種模型選項

使用輸入框上方的模型切換器進行選擇：

| 模型 | 思考強度 | 適合用途 | credit |
|---|---|---|---|
| **K2.6** | 標準 / 進階 | 快速對話與問答，回應速度更快 | **不消耗會員 credit（點數）** |
| **K3** | 標準 / 進階 / 極限 | 對話與 Agent 任務，整體能力最強 | 依 credit（點數）計費 |
| **K3 Cluster** | 標準 / 進階 / 極限 | 大規模搜尋、批次處理，以及一次完成大量任務 | 依 credit（點數）計費 |

- **K3** 可以端到端產生可編輯文件，例如 `.pptx`、`.docx`、`.xlsx` 與 `.pdf`；**K2.6** 則針對快速問答最佳化，僅輸出文字，例如 PPT 大綱、Word 正文、程式碼等。
- 如需**生成圖片 / 影片 / 音訊**，請點擊「+」→ Plugins，選擇對應功能後搭配 **K3** 使用。

## 思考強度：標準 / 進階 / 極限

思考強度越高，模型推理越充分，通常結果也更聰明；但同時也會**消耗更多 token（詞元）**。

- 如果你想要**速度更快、credit（點數）用量更低** → 選擇**標準**；
- 如果你需要**更強推理能力**來處理複雜分析或難題 → 選擇**進階**或**極限**（極限由 K3 / K3 Cluster 支援）。

## Agent 與 Agent Cluster

- **通用 Agent**：會自動規劃並完成任務，包括網站生成、PPT 製作、Deep Research（深度研究），以及文件與試算表處理。
- **Agent Cluster**：支援超過 4,000 次平行工具呼叫，並可自主協調最多 300 個 sub-agents（Sub-agents）並行作業。非常適合**大規模搜尋、長篇寫作與批次處理**等大型任務。

## 依情境選擇

- **快速問答與日常對話** → K2.6（不消耗 credit）。
- **複雜對話、文件撰寫 / PPT 與試算表製作 / 多步驟任務** → K3。
- **大規模搜尋、批次處理與超長篇寫作** → K3 Cluster。
- **想節省 credit** → 使用 K2.6，或將思考強度設為「標準」。

## FAQ

### 「Thinking Mode」不再提供了嗎？
Kimi 已將「對話」與「Agent」整合為同一套體驗，因此不再拆分成不同模式。「思考」現在由**模型與思考強度的選擇**來控制——例如使用 K3 並調高思考強度，就能獲得更充分的推理。

### K2.6 與 K3 有什麼不同？
K2.6 針對快速問答最佳化，回應更快，且不消耗會員 credit。K3 的整體能力最強，擅長複雜對話與 Agent 任務，可以端到端產生可編輯文件，並依 credit 計費。

### K3 與 K3 Cluster 有什麼不同？
K3 適合一般對話與 Agent 任務。K3 Cluster 採用大規模並行能力——數千次工具呼叫與數百個 sub-agents——用來處理**大規模搜尋、批次處理與超長篇寫作**等高量級任務。

### 單次對話最多可處理多少內容？
K2.6 支援約 128K token 的單輪上下文（約 50,000–60,000 個中文字）；K3 提供 100 萬 token 上下文視窗（需最高階會員權益）。詳情請參閱[對話超過 20 萬中文字時該怎麼辦？](/others/chat-issues)。
