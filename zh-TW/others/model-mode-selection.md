# 如何選擇：K2.6 / K3 / K3 Cluster、思考強度與 Agent

Kimi 會依據你的問題自行判斷是否需要連網，不必手動切換。你需要選擇的是**模型**與**思考強度**；面對複雜任務時，也可以使用 **Agent** 和 **Agent Cluster**。

## 三種模型選項

可透過輸入框上方的模型切換器選擇：

| 模型 | 思考強度 | 適用情境 | credit |
|---|---|---|---|
| **K2.6** | 標準 / 進階 | 快速對話與問答，回覆速度更快 | 依 credit 計費 |
| **K3** | 標準 / 進階 / 極致 | 對話與 Agent 任務，整體能力最強 | 依 credit 計費 |
| **K3 Cluster** | 標準 / 進階 / 極致 | 大規模搜尋、批次處理，以及一次完成大量任務 | 依 credit 計費 |

- **K3** 可端到端產出可編輯文件，例如 `.pptx`、`.docx`、`.xlsx`、`.pdf`；**K2.6** 則針對快速問答最佳化，僅輸出文字，例如 PPT 大綱、Word 內文、程式碼等。
- 若要進行**圖片 / 影片 / 音訊生成**，請點擊「+」→「外掛程式」，再選擇相應功能並搭配 **K3** 使用。

<Callout type="info">
K2.6 無論是在聊天中（輸入框上方的模型切換器），還是在 Kimi Work 中作為 K2.6 Agent 使用，都會消耗會員 credit。
</Callout>

## 思考強度：標準 / 進階 / 極致

思考強度越高，模型推理越充分，通常結果也更聰明；但同時也會**消耗更多 token**。

- 如果你重視**速度與較低的 credit 使用量** → 選擇**標準**；
- 如果複雜分析或難題需要**更強推理能力** → 選擇**進階**或**極致**（極致由 K3 / K3 Cluster 支援）。

## Agent 與 Agent Cluster

- **通用 Agent**：會自動規劃並完成任務，包括網站生成、PPT 製作、Deep Research（深度研究），以及文件與試算表處理。
- **Agent Cluster**：支援超過 4,000 次平行工具呼叫，並可自主協調最多 300 個子 Agent（Sub-agents）並行運作。非常適合**大規模搜尋、長篇寫作、批次處理**等大型任務。

## 依情境選擇

- **快速問答與日常對話** → K2.6。
- **複雜對話、文件撰寫 / PPT 與試算表製作 / 多步驟任務** → K3。
- **大規模搜尋、批次處理、超長篇寫作** → K3 Cluster。
- **想節省 credit** → 將思考強度設為「標準」。

## FAQ

### 「Thinking Mode」已不再提供了嗎？
Kimi 已將「對話」與「Agent」整合為同一種體驗，因此不再分成不同模式。「思考」現在由**模型與思考強度**控制——例如使用 K3 並提高思考強度，就能獲得更充分的推理。

### K2.6 和 K3 有什麼差異？
K2.6 針對快速問答最佳化，回覆更快。K3 的整體能力最強，擅長複雜對話與 Agent 任務，可端到端產出可編輯文件。兩者都依 credit 計費。

### K3 和 K3 Cluster 有什麼差異？
K3 適合一般對話與 Agent 任務。K3 Cluster 透過大規模並行能力——數千次工具呼叫與數百個子 Agent——來處理**大規模搜尋、批次處理、超長篇寫作**等高負載任務。

### 單輪最多能處理多少內容？
K2.6 支援約 128K token 的單輪上下文（約 50,000–60,000 個中文字）；K3 提供 100 萬 token 的上下文視窗（需最高等級會員權益）。詳情請參閱[如果對話超過 20 萬中文字，該怎麼辦？](/others/chat-issues)。
