# Kimi、Kimi Work、Kimi Code 和 Kimi Claw 有什麼不同？我該用哪一個？

Kimi 包含可立即使用的線上助理，也提供多款針對不同使用者與情境設計的產品。它們共享 Kimi 的核心能力；主要差異在於**使用位置、適用對象，以及最擅長的事情**。

## 快速總覽

| 產品 | 是什麼 | 最適合 / 情境 | 使用位置 |
|---|---|---|---|
| **Kimi**（網頁版 / App） | 結合聊天與 Agent 的線上 AI 助理 | 日常問答、寫作、搜尋、建立網站 / PPT / 文件與試算表、Deep Research（深度研究）等 | 網頁版、手機 App |
| **Kimi Work** | 面向知識工作者的 **本機 Agent**（桌面端） | 處理電腦上的本機檔案、跨桌面應用程式自動執行任務、交付長時間執行的任務 | Mac / Windows 用戶端 |
| **Kimi Code** | 面向 **開發者** 的程式設計助理套件 | 撰寫程式碼與維護程式碼庫 | CLI、VS Code 擴充功能 |
| **Kimi Claw** | **零部署雲端自動化** 平台 | 7×24 全天候雲端自動化、與 Feishu / WeChat 等整合的機器人 | 雲端（無需伺服器） |

## 我該用哪一個？

- **如果你要日常聊天、寫作、搜尋，或請 Kimi 建立網站、製作 PPT 與試算表，或執行 Deep Research（深度研究）** → 使用 **Kimi**（網頁版 / App）。
- **如果你需要 Kimi 讀寫電腦上的本機檔案、跨多個桌面 App 自動執行任務，或處理長時間任務** → 使用 **Kimi Work**（桌面端）。
- **如果你是開發者，主要需要協助撰寫程式碼或維護專案** → 使用 **Kimi Code**。
- **如果你想要一個全天候在線、自動執行，且能連接 Feishu / WeChat 等平台的雲端機器人** → 使用 **Kimi Claw**。

<Callout type="tip">
Kimi 的線上體驗已經把「聊天」與「Agent」整合在一起——你不需要在兩者之間切換。Kimi Work 桌面 App 提供兩種模式：「Work」（以交付成果為重點的 Agent 模式）與「Chat」（快速對話）。
</Callout>

## 該選哪種會員方案？

會員權益與你的 Kimi 帳號綁定。**Kimi Code 使用獨立的 credit（點數）池**，其他會員功能（聊天、Agent、Deep Research（深度研究）等）則共用同一個 credit（點數）池。方案細節與價格請參閱[會員訂閱頁面](/membership/membership-pricing)。

如果你的使用情境主要是**日常工作 + 偶發任務**，合適的 Kimi 會員方案就能涵蓋網頁版 / App / Kimi Work 的大多數場景。**經常撰寫程式碼**的開發者，也建議特別留意 Kimi Code 的相關權益。
