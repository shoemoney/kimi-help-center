# Kimi、Kimi Work、Kimi Code 和 Kimi Claw 有什麼不同？我該用哪一個？

Kimi 提供開箱即用的線上助手，也有多款為不同使用者與情境打造的產品。它們共享 Kimi 的核心能力；主要差異在於**使用位置、適合對象，以及最擅長的事**。

## 快速總覽

| 產品 | 這是什麼 | 適合用途／情境 | 使用位置 |
|---|---|---|---|
| **Kimi**（網頁版 / App） | 結合對話與 Agent 的線上 AI 助手 | 日常問答、寫作、搜尋、建立網站 / PPT / 文件與試算表、Deep Research（深度研究）等 | 網頁版、行動 App |
| **Kimi Work** | 面向知識工作者的**本機 Agent**（桌面端） | 處理電腦上的本機檔案、跨桌面應用程式自動化工作、交付長時間執行的任務 | Mac / Windows 用戶端 |
| **Kimi Code** | 為**開發者**打造的程式開發助手套件 | 撰寫程式碼與維護程式碼庫 | CLI、VS Code 擴充功能 |
| **Kimi Claw** | **零部署雲端自動化**平台 | 7×24 全天候雲端自動化、整合 Feishu / WeChat 等平台的 bot | 雲端（不需要伺服器） |

## 我該用哪一個？

- **如果你要日常對話、寫作、搜尋，或請 Kimi 建立網站、製作 PPT 與試算表，或執行 Deep Research（深度研究）** → 使用 **Kimi**（網頁版 / App）。
- **如果你需要 Kimi 讀寫電腦上的本機檔案、跨多個桌面應用程式自動化操作，或執行耗時較長的任務** → 使用 **Kimi Work**（桌面端）。
- **如果你是開發者，主要需要協助撰寫程式碼或維護專案** → 使用 **Kimi Code**。
- **如果你想要一個常駐雲端、可自動執行，並能串接 Feishu / WeChat 等平台的 bot** → 使用 **Kimi Claw**。

<Callout type="tip">
Kimi 的線上體驗已將「對話」與「Agent」整合在一起，你不需要在兩者之間切換。Kimi Work 桌面應用程式則提供兩種模式：「Work」（著重交付成果的 Agent 模式）與「Chat」（快速對話）。
</Callout>

## 我該選哪種會員方案？

會員權益會綁定到你的 Kimi 帳號。所有會員功能（對話、Agent、Deep Research（深度研究）、Kimi Code 等）**共用同一個 credit（額度）池**；Kimi Code 另有專屬的每週 5 小時 rate limit（使用上限），且僅適用於 Kimi Code。方案細節與價格請參閱[會員訂閱頁面](/membership/membership-pricing)。

如果你的使用以**日常工作 + 偶爾執行任務**為主，合適的 Kimi 會員方案即可涵蓋網頁版 / App / Kimi Work 的大多數情境。若你是**經常寫程式碼**的開發者，也建議特別留意 Kimi Code 的相關權益。
