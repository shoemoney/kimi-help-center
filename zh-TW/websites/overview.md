# Kimi Websites

<Callout type="info">
**Kimi Websites** 是由最新 Kimi K2.6 多模態視覺 Agent AI 模型驅動的 Kimi Agent 產品功能。其核心能力是 **Vibe Coding（氛圍式編程）**——透過自然語言產生網站並部署上線。
</Callout>

Kimi 能理解視覺輸入（UI 設計稿、螢幕截圖、互動影片）與自然語言指令，將使用者輸入轉換為完整、可執行的前端程式碼；不只涵蓋靜態 UI，也能實作動態互動行為。

## 功能概覽

| 功能 | 說明 |
|---------|------------|
| **對話式建站** | 用自然語言描述需求，AI 會自動產生網站 |
| **圖片／影片理解** | 上傳設計稿、螢幕截圖或螢幕錄影，AI 會解析並產生 HTML 頁面 |
| **自動部署** | 一鍵部署，立即發布 |
| **多輪編輯** | 透過反覆對話修改網站，並支援版本比較 |
| **一鍵分享** | 產生可存取連結，方便分享 |
| **範本選擇** | 提供多種預設範本，快速開始建站 |
| **程式碼匯出** | 下載打包好的 HTML/CSS/JS 檔案，自行託管 |

## 如何使用 Kimi Websites？

### 方法一：前往 Kimi Websites 頁面

<Frames
  src="./images/overview/kimi-websites-homepage.png"
  alt="Kimi websites 首頁"
/>

1. **開啟瀏覽器**：使用 Chrome、Safari、Edge、Firefox，或任何主流瀏覽器
2. **前往**：[kimi.com/websites](https://www.kimi.com/zh/websites)（支援中文與英文）
3. **登入**：使用你的 Kimi 帳號（手機號碼或電子郵件）
4. **輸入任務**：

| 方式 | 說明 |
|----------|-------------|
| **文字輸入** | 用自然語言輸入你的需求 |
| **圖片／網站仿製** | 上傳設計稿或螢幕截圖 |
| **範本建站** | 選擇預設範本並修改內容 |

5. **開始建置**：選擇範本，或從對話開始

<Frames
  src="./images/overview/screenshot-27.png"
  alt="螢幕截圖 27"
/>

### 方法二：行動 App

iOS、Android 與 HarmonyOS 都有官方 Kimi app。在輸入區點選 **工作列** → 切換至 **Websites Agent 模式**；此模式包含多模態生成工具與 Agent 能力。

### 方法三：使用 K2.6 Agent 模式

切換至 K2.6 Agent 模式，並輸入建站任務。Kimi 會呼叫其視覺編程能力與程式碼執行工具。

## Kimi Websites 如何運作？

### 步驟一：透過對話建立網站

用自然語言描述你的需求。支援三種建立方式：

| 方法 | 說明 |
|--------|------------|
| **文字描述** | 直接輸入網站需求，AI 會自動產生 |
| **設計稿解析** | 上傳設計檔，AI 會辨識並重建為網頁 |
| **快速範本建置** | 選擇預設範本並修改內容 |

### 步驟二：建置流程

<Frames
  src="./images/overview/screenshot-26.png"
  alt="螢幕截圖 26"
/>

Kimi website 會啟用 **webapp-building SKILL**——一個專門用於多輪程式碼生成的 Agent：
1. **需求分析**：分析網站模組、視覺風格與互動邏輯
2. **任務規劃**：拆解為設計、開發與素材準備等子任務
3. **技術棧選擇**：選擇合適的架構（例如 React + Tailwind CSS）
4. **素材生成**：產生圖片、圖示與其他視覺素材
5. **程式碼建構**：撰寫頁面結構、樣式與互動程式碼
6. **多輪最佳化**：根據預覽結果自行調整，直到完成

### 步驟三：預覽與調整
- **即時預覽**：產生 HTML demo URL，可立即在瀏覽器中查看
- **對話式編輯**：繼續對話提出修改需求，例如 *"Make the navbar dark"*

<Callout type="tip">
**範例**：*"The colors aren't great — I'd like to drop the black-and-white requirement and make it a normal-looking website."*
Kimi 會重新整理待辦清單並繼續建置。
</Callout>

### 步驟四：視覺化線上編輯
- **多輪最佳化**：透過持續對話微調細節
- **編輯模式**：
  - **標註模式**：點選區域並加入自然語言標註
  - **選取模式**：選取任意元素並加入標註
  - 使用矩形、箭頭、筆刷與顏色切換來標示修改建議
- 一次將所有修改建議傳送給 Kimi
### 步驟五：部署與發布
| 部署方式 | 說明 |
|-------------------|------------|
| **自動部署** | 一鍵部署並產生線上連結 |
| **下載並自行託管** | 下載打包好的程式碼檔案，部署到你自己的伺服器 |
| **自訂網域** | 將產生的網站綁定到你自己的網域 |

生成後，你可以：
- 點選不同部署版本，下載版本檔案
- 點選分享按鈕，取得公開部署連結（或設為私人）
- 點選編輯按鈕，繼續修改
- 下載完整 HTML/CSS/JS 程式碼，以便直接部署或進一步調整

## 適用對象
| 對象 | 使用情境 |
|----------|----------|
| **開發者** | 設計產品原型與前端 demo，大幅減少從零建置所需時間 |
| **創業者** | 在資源有限的情況下，快速建立著陸頁、產品展示頁與公司網站 |
| **產品經理** | 將 PRD 或設計稿快速轉換為可展示的互動原型 |
| **非技術使用者** | 無需撰寫程式碼——只要描述想法或上傳參考圖片，就能從概念變成可運作的網頁 |
