# Kimi Websites 功能概覽

## 什麼是 Kimi Websites

Kimi Websites 是 Kimi Agent 的全端網站建置產品，由 Kimi K3 這款多模態視覺 agentic AI 模型驅動。它的核心能力是視覺化程式設計（Vibe Coding）：你可以透過自然語言、設計稿或螢幕錄影生成一個完整的全端網站，線上預覽後一鍵發布。

Kimi Websites 生成的網站可包含：

- **前端**：HTML 頁面結構、CSS 版面與樣式，以及 JavaScript 互動邏輯（動態效果、動畫等）
- **後端**：持久化資料庫儲存、使用者登入與驗證
- **工程能力**：自動版本管理、全端預覽與公開部署

### 產品功能

| 功能        | 說明                                                  |
|----------------|--------------------------------------------------------------|
| 對話式建站 | 用自然語言描述需求，AI 會自動生成全端網站 |
| 圖片／影片理解 | 上傳設計稿、截圖或螢幕錄影，AI 會自動解析並生成頁面 |
| 持久化儲存 | 自動建立後端資料庫，支援資料持久化讀取、寫入與管理 |
| 資料庫管理 | 提供視覺化資料庫面板，可進行檢視、編輯、刪除等基本資料操作 |
| 使用者登入 | 支援 Kimi 帳號登入，也可透過資料庫建立使用者名稱／密碼登入系統 |
| 版本管理 | AI 會自動建立版本提交（git commit），並支援回復到任一歷史版本 |
| 全端預覽 | 支援完整前端與後端預覽；部分情境需手動啟動沙盒環境 |
| 多輪編輯 | 支援透過多輪對話反覆修改，並可比較不同版本 |
| 視覺化編輯 | 在預覽頁面圈選或標註元素後，一次將所有建議送給 Kimi |
| 發布與部署 | 手動點擊「發布」後，網站會部署到公開網路；發布前僅可預覽。支援全端部署 |
| 自訂 URL | 自訂網站子網域，例如 `abc.ok.kimi.link` 中的 `abc` |
| 分享與存取控制 | 一鍵取得公開分享連結，或將網站設為私密／僅自己可見 |
| 範本選擇 | 提供多種預設範本，協助你快速開始建置 |
| 程式碼匯出 | 支援下載完整專案套件（包含前端與後端），供自行部署管理 |

## 如何使用

### 方法一：透過網頁存取
前往 Kimi Websites 專屬頁面

<Frames
  src="./images/overview/kimi-websites-homepage.png"
  alt="Kimi Websites 首頁"
/>

1. 開啟瀏覽器：使用 Chrome、Safari、Edge 或 Firefox 等主流瀏覽器。
2. 開啟官方存取網址：Kimi Websites 專屬頁面：[https://www.kimi.com/zh/websites](https://www.kimi.com/zh/websites)（支援中文與英文介面）
3. 登入帳號：使用 Kimi 帳號登入（支援以手機號碼或電子郵件註冊）
4. 輸入你的建站任務。Kimi Websites 提供三種主要建站方式：
   1. **文字輸入**：在對話框中輸入任務，用自然語言描述你想要的網站；
   2. **圖片／網站 remix**：上傳設計稿或你喜歡的網站截圖，以觸發相應功能；
   3. **範本建站**：選擇預設範本並編輯內容，快速建立標準網站；
5. 開始建置：進入 Websites 功能介面，選擇範本，或直接透過對話建立。

Kimi Websites 會啟用 webapp-building SKILL，這是一個專為網站建置而設計的多輪程式碼生成 Agent。它會自主執行以下流程：

1. 需求解析：自動分析網站功能模組、視覺風格與互動邏輯
2. 任務規劃：將工作拆分為設計、開發、素材準備等子任務
3. 技術方案：自動選擇合適的技術架構（例如 React + Tailwind CSS）
4. 素材生成：依需求生成圖片、圖示等視覺素材
5. 程式碼建構：撰寫頁面結構、樣式與互動程式碼
6. 多輪最佳化：根據預覽自主調整，直到網站完成

### 預覽面板介面

網站生成後，右側會開啟預覽面板，對話中也會出現版本卡片。主要操作入口如下：

**預覽面板頂部工具列**（由左至右）：

| 按鈕 | 功能 |
|--------|----------|
| 預覽／程式碼 | 在視覺化預覽與原始碼／檔案樹檢視之間切換 |
| 編輯 | 進入編輯模式；點選想修改的區域，加入標註說明，並送交 Kimi |
| 分享 | 發布網站、複製連結、自訂 URL 或取消發布 |
| 全螢幕預覽 | 以全螢幕檢視網站 |
| 切換預覽模式 | 在桌面版與行動版檢視之間切換 |
| 重新整理 | 重新載入預覽 |
| 使用者回饋 | 提交使用過程中遇到的問題；可輸入文字並上傳截圖 |
| 關閉 | 收合預覽面板 |

**對話中的版本卡片**：顯示網站名稱、版本號（例如 V2）與 URL。點擊 **預覽** 可開啟對應版本；點擊 **還原** 可回復到該版本。**所有檔案** 卡片可讓你檢視或下載完整專案檔案。各按鈕的詳細用法，請參閱下方對應章節。

### 視覺化編輯

<Frames
  src="./images/overview/web-case1.png"
  alt="視覺化編輯介面"
/>

- **多輪最佳化**：透過連續對話微調網站細節
- **編輯方式**：
  - **標註模式**：點選想修改的網頁部分，並以自然語言加入註解
  - **選取模式**：選取網頁上的任意元素並加入註解
  - 使用矩形、箭頭、畫筆、切換顏色等選取與編輯工具，加入修改建議
- 在多處加入標註後，將它們加入對話，一次把所有建議送給 Kimi

### 程式碼部署與發布
| 部署方式 | 說明                                           |
|-------------------|------------------------------------------------------|
| 一鍵發布 | 點擊「發布」按鈕，將網站部署到公開網路並生成可存取的線上連結（發布前僅可預覽） |
| 下載並部署 | 下載程式碼套件並部署到自己的伺服器 |
| 自訂 URL | 將預設的隨機 URL 改成容易記憶的名稱，例如自訂 `abc.ok.kimi.link` 中的 `abc` |

> **關於「自訂 URL」**：長度 3–30 個字元，僅可使用小寫英文字母、數字與連字號。不可用連字號開頭或結尾，也不可為純數字。部分保留字（例如 `kimi`、`www`、`login` 等）無法使用。若已被占用或不可用，請改選其他名稱。

> **關於「下載並部署」的邊界**：**Kimi 帳號登入**與**平台託管的雲端資料庫**由 Kimi 平台提供，不會隨匯出的程式碼一併遷移。若你將程式碼部署到自己的伺服器，登入方式必須改為基於自有資料庫的使用者名稱／密碼方案，資料也必須遷移到自己的資料庫。若只是要公開存取，建議直接使用**一鍵發布**，Kimi 帳號登入與雲端資料仍可正常運作。詳情請見[為什麼我建立的網站無法運作？](/websites/websites-why-not-working)。

#### 發布、分享與取消發布
發布前，網站只能在對話中預覽。若要讓其他人存取，請點擊預覽面板右上角的 **分享**，開啟發布面板：

1. **自訂 URL**：你可以修改預設 URL 中的名稱，例如改成 `yourname.ok.kimi.link`；
2. 點擊 **複製連結** 取得公開 URL，或點擊 **開啟網站** 在新分頁中查看。發布後，面板頂部會顯示 **已發布**，任何取得連結的人都能存取；
3. 若要將網站下線，請從面板右上角的 **…** 選單中選擇 **取消發布**。網站將不再公開可存取（程式碼與資料會保留，你可隨時重新發布）。

### 多輪編輯

如果對某個部分不滿意，可點擊預覽視窗中的編輯按鈕持續調整。
你也可以用自然語言向 Kimi 發送指令，並透過 Agent 繼續編輯。
確認結果後，可下載完整 HTML/CSS/JS 程式碼並直接部署，或在編輯器中繼續打磨。

## 適用對象

- 開發者：設計產品原型與前端 demo，大幅縮短從零建置所需時間。
- 創業者：在資源有限時，快速建立官方網站、landing page 與產品展示頁。
- 產品經理：無需等待開發排期，即可快速將 PRD 或設計稿轉成可展示的互動原型。
- 非技術使用者：不需要具備程式設計知識。只要描述你的想法或上傳參考圖片，就能從概念變成可執行網頁。
