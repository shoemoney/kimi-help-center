# Kimi Websites 全端能力

## 全端建站能力升級

一個完整網站通常由三個部分組成：**前端介面、後端服務與資料儲存**。Kimi Websites 已升級全端建站能力，支援從前端頁面到後端資料庫的端到端網站生成與部署。

| 能力         | 說明                                                           |
|--------------|----------------------------------------------------------------|
| 前端生成     | HTML/CSS/JavaScript 頁面結構、樣式與互動邏輯                    |
| 後端資料庫   | 自動建立後端資料庫，支援持久化資料讀寫與視覺化管理               |
| 使用者登入     | 支援 Kimi 帳號登入，也可透過資料庫建立帳號密碼登入系統           |
| 版本管理     | AI 會自動提交版本，並支援回復到任一歷史版本                      |
| 全端預覽     | 支援完整的前端與後端預覽；部分情境需要手動啟動沙盒環境                   |
| 發布與部署   | 手動點擊「發布」即可部署到公開網路。發布前，網站僅可預覽。支援全端內容部署  |

## Agent 交付內容

- 完整的任務執行檔案，包含前端與後端程式碼
- 可線上預覽並發布的全端網站
- 可下載的 Zip 壓縮包，位於 `/mnt/agents/output/app/` 目錄

## 使用情境

| 情境             | 範例提示詞                                                       |
|------------------|------------------------------------------------------------------|
| 從零建立 landing page   | 為一款 SaaS 產品建立具科技感風格的行銷 landing page，包含 hero section、功能介紹、定價與 CTA |
| 依截圖重建         | [上傳設計截圖] 將這份設計轉換成可執行的網頁程式碼               |
| 個人作品集       | 為攝影師建立個人作品集網站，採極簡黑白風格，並支援瀑布流圖片版面        |
| 資料視覺化頁面     | 建立一個展示 2025 年 AI 公司融資資料的資料視覺化網頁，包含圖表與篩選功能 |
| 品牌官網         | 為咖啡品牌建立官方網站，使用 Morandi 色系，包含首頁、產品頁與門市頁      |
| 需登入的應用     | 建立一個內部團隊知識庫網站，內容僅限登入後查看                   |
| 資料管理後台     | 建立活動報名系統，使用者可提交資訊並儲存至資料庫，管理員可查看報名名單 |
| 工具／計算器    | 建立一個 BMI 計算器網頁，具備簡潔介面、單位切換與健康分類提示     |

## 目前限制

以下情境尚未支援，將在未來版本逐步開放：

- 第三方付款整合，例如 Stripe 與 PayPal
- 第三方 OAuth 登入，例如 Google 與 GitHub。目前僅支援 Kimi 帳號登入，或以資料庫為基礎的使用者名稱／密碼登入
- 複雜的伺服器端 API 整合，例如連接外部 SaaS 服務
